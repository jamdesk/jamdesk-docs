---
title: Frame
description: Styled container with optional caption
---

Frame wraps content in a bordered container, ideal for images and demos.

## Basic Frame

<Frame>
  ![Example screenshot](/images/logo-light.svg)
</Frame>

```mdx
<Frame>
  ![Example screenshot](/images/logo-light.svg)
</Frame>
```

## With Caption

Add a caption below the frame:

<Frame caption="The Jamdesk dashboard">
  ![Dashboard](/images/logo-dark.svg)
</Frame>

```mdx
<Frame caption="The Jamdesk dashboard">
  ![Dashboard](/images/logo-dark.svg)
</Frame>
```

## Framing Other Content

Frame works with any content, not just images:

<Frame caption="Example code output">
  ```
  ✓ Build completed successfully
  ✓ 42 pages generated
  ✓ Deployed to production
  ```
</Frame>

## Use Cases

### Screenshots

## Props

| Prop | Type | Description |
|------|------|-------------|
| `caption` | string | Optional text below the frame |
