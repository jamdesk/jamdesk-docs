Jamdesk ships a set of MDX components you can drop into any page. This overview helps you choose the right component, see common patterns, and jump into detailed docs and examples. You will see example snippets and recommended defaults, plus guidance on when this fits into a Jamdesk documentation workflow.

## Usage

Drop components directly into your MDX:

```mdx
<Card title="Quickstart" icon="rocket" href="/quickstart">
  Launch your docs in minutes.
</Card>
```
