Jamdesk includes MDX components you can use on any page.

## Usage

Add components to your MDX:

```mdx
<Card title="Quickstart" icon="rocket" href="/quickstart">
  Launch your docs in minutes.
</Card>
```

## Layout & Navigation

<Columns cols={3}>
  <Card title="Accordion" icon="chevron-down" href="/components/accordion">

  </Card>
  <Card title="Card" icon="square" href="/components/card">
    Clickable, styled containers with icons, images, links, and CTAs, arranged in grid layouts.
  </Card>
  <Card title="Columns" icon="columns" href="/components/columns">
    Responsive grid layout that places Cards, Tiles, and other content side by side. It adapts to screen size.
  </Card>
  <Card title="Frame" icon="image" href="/components/frame">
    Frame wraps images and demos in a bordered container with an optional caption.
  </Card>
  <Card title="Panel" icon="sidebar" href="/components/panel">
    Pin custom content like warnings or quick references in the sidebar, where it stays visible while readers scroll.
  </Card>
  <Card title="Steps" icon="list-ol" href="/components/steps">
    Numbered step-by-step guides for setup flows, tutorials, and troubleshooting, with icons, code blocks, and nested content.
  </Card>
  <Card title="Tabs" icon="folder" href="/components/tabs">
    Switchable panels for mutually exclusive content like package managers or languages. Matching tab titles sync across the page.
  </Card>
  <Card title="Tile" icon="grid-2" href="/components/tile">
    Tiles display content previews with a styled pattern background and prominent image area. Use them for integrations, templates, or visual galleries.
  </Card>
  <Card title="Tree" icon="folder-tree" href="/components/tree">
    Display file and folder hierarchies with interactive expand/collapse and keyboard navigation. Use it to document project structure.
  </Card>
  <Card title="View" icon="window-maximize" href="/components/view">
    Show content for the reader's chosen framework or language. Whole sections switch with the selection.
  </Card>

## Content & Emphasis

<Columns cols={3}>
  <Card title="Badge" icon="tag" href="/components/badge">
    Inline labels for status, categories, and metadata, with 11 color variants, 4 sizes, icons, pill/rounded shapes, and stroke outlines.
  </Card>
  <Card title="Callouts" icon="circle-info" href="/components/callouts">
    Note, Tip, Warning, Danger, Check, and custom Callout components that highlight key information.
  </Card>
  <Card title="Expandable" icon="expand" href="/components/expandable">
    Expandable creates a show/hide toggle for optional content outside the main flow.
  </Card>
  <Card title="Tooltip" icon="message" href="/components/tooltip">
    Display definitions and context on hover. Define terms, explain acronyms, or link to related content without cluttering the page.
  </Card>
  <Card title="Update" icon="clock-rotate-left" href="/components/update">
    Timeline-style changelog entries with dates, descriptions, and category tags. Entries appear in the Table of Contents.
  </Card>
  <Card title="Visibility" icon="eye" href="/components/visibility">
    Show different content to human readers and AI agents on the same page. Agent-only context, instructions, and definitions that stay out of the rendered docs.
  </Card>
</Columns>

  </Card>
  <Card title="Prompt" icon="wand-magic-sparkles" href="/components/prompt">
