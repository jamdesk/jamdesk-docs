Latest updates to Jamdesk platform, CLI, and documentation features.

<Update label="February 5, 2026" tags={["feature"]}>
**Multi-Language Support**

Configure multiple languages in your documentation with a built-in language switcher. Each language gets its own navigation and content directory.

```json
{
  "navigation": {
    "languages": [
      { "language": "en", "tabs": [...] },
      { "language": "es", "tabs": [...] }
    ]
  }
}
```

See [Multi-Language Support](/setup/languages).
</Update>

<Update label="February 1, 2026" tags={["feature"]}>
**MCP Integration**

AI agents can now query your documentation directly using the Model Context Protocol. Every Jamdesk site exposes an MCP endpoint at `/_mcp`.

See [MCP Integration](/development/mcp-integration).
</Update>

<Update label="January 28, 2026" tags={["feature"]}>
**Snippets**

Reusable content blocks for shared content across pages. Create MDX or React components in `/snippets` and import them anywhere.

See [Snippets](/content/snippets).
</Update>

<Update label="January 20, 2026" tags={["feature"]}>
**Custom CSS Support**

Override theme styles with your own CSS file. Reference it in `docs.json` under `styling.css`.

See [Custom CSS](/customization/custom-css).
</Update>

<Update label="January 15, 2026" tags={["feature"]}>
**Redirects**

Set up URL redirects for moved pages and legacy URLs. Supports exact and wildcard patterns.

```json
{
  "redirects": [
    { "source": "/old-page", "destination": "/new-page" }
  ]
}
```

See [Redirects](/setup/redirects).
</Update>

<Update label="January 10, 2026" tags={["feature"]}>
**CLI Improvements**

- `jamdesk validate` now checks for broken internal links
- `jamdesk migrate` handles component deprecations automatically
- `jamdesk doctor` diagnoses common setup issues
</Update>

<Update label="December 15, 2025" tags={["feature"]}>
**AI-Ready Documentation**

Every Jamdesk site now generates `llms.txt` automatically—a structured file optimized for AI assistants and LLM context windows.

See [AI-Ready Documentation](/development/ai-documentation).
</Update>

<Update label="November 20, 2025" tags={["feature"]}>
**Subpath Hosting**

Host documentation at `yourdomain.com/docs` alongside your existing website using reverse proxy configuration.

See [Subpath Hosting](/deploy/subpath-hosting).
