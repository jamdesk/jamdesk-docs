<Update label="October 2026" date="2026-10-15">
**Clearer failures for pushes from non-members.** The failed build names who pushed and how to fix it. The project owner gets an email with an invite link, at most once a week per person. [GitHub →](/integrations/github#builds-arent-triggering)

**Rename the Ask AI button and give it your own icon.** Add `chat.label` and `chat.icon` to `docs.json`. The label replaces "Ask AI" on the chat button, the panel header and the search shortcut. The icon can be a Font Awesome name, an image URL or an image in your project. [AI Chat →](/ai/chat#custom-name-and-icon)

**Center or right-align the top tabs.** Set `tabsAlignment` to `"center"` or `"end"` when your tabs sit in the header. The default, `"start"`, keeps them on the left. [Navigation →](/navigation/overview)

**Open a Mermaid diagram full screen.** Click a diagram, or focus it and press Enter, to see it larger. Close it with Escape. Add `noZoom` to a `<Mermaid>` component to turn it off for that diagram. Colors you set with `style` and `classDef` now stay the same in dark mode. [Mermaid →](/components/mermaid#click-to-expand)

**Search API and MCP on login-protected sites.** The Search API and the MCP server now accept your project API key in place of a login. You no longer need `/_api/search` in your public paths. Send the key to the MCP server as `Authorization: Bearer <key>`. A request without the key gets a 401 that says what to send, not a redirect to your login page. [MCP Server →](/ai/mcp-server#login-protected-sites)

**Full pages and Markdown links for AI tools on login-protected sites.** MCP `getPage` returns the whole page as Markdown, and your project API key opens `.md` URLs, `llms.txt` and `llms-full.txt`. Send the key as `Authorization: Bearer <key>`; requests with a key share 120 per minute. HTML pages and the AI chat still need a login. [llms.txt →](/ai/llms-txt#login-protected-sites)

**Custom JavaScript runs in `jamdesk dev`.** Requires CLI 1.1.222 or later. [Custom JavaScript →](/customization/custom-javascript)

**Set your own page title format.** Add `seo.titleTemplate` to `docs.json` to change the title shown in the browser tab and in search results. Every `%s` becomes the page title. `"%s | Acme"` gives `Getting started | Acme`. `"%s"` alone leaves out the site name. Link preview titles still show the page title alone. [SEO →](/content/seo#page-titles)

**Build warning for text in SVG logos.** The social card can't draw text inside an SVG logo. The build now suggests converting text in the logo to outlines (paths). The suggestion appears in the dashboard Suggestions list, in `jamdesk validate` and in `jamdesk dev`. Logos set to a full URL aren't checked. [SEO →](/content/seo#customize-the-social-card)

**A fifth theme: Dusk.** Set `"theme": "dusk"` in `docs.json` for a flat look. Type is Inter for body text and IBM Plex Serif for headings. The accent is ink blue. Content sits on one tinted surface with 1px borders instead of raised cards. Custom colors, fonts, and CSS overrides work the same as on Jam, Nebula, Pulsar, and Halo. [Theming →](/customization/theming)

**Customize your social cards.** Add `seo.socialCard` to `docs.json`. Color the bar and section badge with `colors.primary`, switch to a dark card, hide the bar or the site name, or use your own `og:image` as the whole card with no text. [SEO →](/content/seo#customize-the-social-card)
</Update>

**Custom CSS and JavaScript examples.** A new guide shows how to add a branded header and a floating Ask AI button, with screenshots. You need a `style.css`, a `script.js` and a few lines of `docs.json`. The examples target stable hooks, not class names. They keep working when Jamdesk updates. [CSS & JS Examples →](/customization/custom-code-examples)

**One llms-full.txt per language.** `/fr/llms-full.txt` now holds only the French pages of a multilingual site. `/en/llms-full.txt` holds the default language. The root `/llms-full.txt` still holds every language. The default language's index also answers at `/en/llms.txt`. Single-language sites are unchanged. [llms.txt →](/ai/llms-txt#multilingual-sites)

**Send readers straight to their own language.** Set `"localization": { "autoRedirect": true }` in `docs.json`. First-time visitors land on their browser's language, such as `/fr`, instead of your default. The choice sticks for a year. Picking a language from the switcher overrides it. Only the site root redirects. Crawlers are never redirected. Your `hreflang` tags still decide what gets indexed. Requires two or more languages. [Automatic language routing →](/setup/languages)

**Override the "last updated" date on a page.** `metadata.timestamp` shows a "Last updated on …" line taken from the page's last Git commit. Add `lastUpdatedDate: "2026-09-01"` to a page's frontmatter to replace that date. The date also goes into your sitemap's `<lastmod>` and the page's structured-data `dateModified`, even when the footer line is off. Use it after you review a page, or when a formatting-only commit moved the date. [Frontmatter →](/content/frontmatter)

**Turn off the copy button on a code block.** Add `nocopy` to the code block's opening line. It works with a title and every other option. It applies per tab inside a `<CodeGroup>`. Use it for terminal transcripts, redacted examples, and "don't do this" snippets. [Code Blocks →](/content/code-blocks)

{/* **Connect a Bitbucket Cloud repository.** Choose **Bitbucket** when you connect a project's repository, then sign in. Jamdesk creates a starter docs repo in your workspace or connects a repository and branch you name. Every push builds. A branch check every five minutes catches pushes whose webhook Bitbucket dropped. The web editor, Fix with AI, and AI translation are GitHub-only for now. [Connect Bitbucket →](/setup/connecting-bitbucket) */}

**Sign readers in with your own login.** Turn on `auth.jwt` in `docs.json`. Generate an Ed25519 signing key in **Settings**. Your backend signs a short-lived JWT at sign-in. Jamdesk verifies the token. Sessions last up to 30 days. Add `groups: ["admin"]` to a page to restrict it to tokens with that group. Other visitors get a 404. The page is hidden from their sidebar. Public paths, frontmatter `public: true`, and public navigation groups stay open to everyone. Pre-fill the API playground with credentials from the token. Included on every plan. Switch from password protection without downtime. [JWT Authentication →](/setup/jwt-authentication)

**The site root exports Markdown too.** Fetch your docs root, or a language root such as `/fr`, with `Accept: text/markdown` or as `/index.md`. You get the first page in that navigation, the same page the HTML root shows. Sites without an `index.mdx` used to return a 404 here. That broke the first request most agents make. [Markdown Source →](/ai/markdown-source#site-root-and-language-roots)
</Update>

**Jamdesk translates your docs into 27 languages.** Pick up to five languages per project in **Settings → Translations**. Jamdesk commits the translated pages to your GitHub repository after each build. Later builds retranslate only pages whose English source changed. Existing and hand-edited translations are kept until you click **Replace with AI translation**. Included on every plan. [AI Translation →](/setup/ai-translation)

**Choose your own docs URL.** Subpath hosting is no longer tied to `/docs`. Enter one path segment, such as `help` or `guide`, in the subpath field on the Custom Domain card. `/docs` keeps serving. Canonical URLs move to the new path right away. Only the most recent custom subpath redirects to the new one. [Subpath Hosting →](/deploy/subpath-hosting)

**Fix with AI, now faster.** Reopening the fix preview is close to instant. Jamdesk keeps the scan results until your docs change. The first open is also quicker, including on large sites. [Fix with AI →](/builds/fix-with-ai)

**A fourth theme: Halo.** Set `"theme": "halo"` in `docs.json` for a rounded look. Type is Figtree. Content sits on a raised card over a sand background. Corners are the roundest of any built-in theme. Custom colors, fonts, and CSS overrides work the same as on Jam, Nebula, and Pulsar. [Theming →](/customization/theming)

**Serve your docs only from your own domain.** Turn on **Custom domain only** in the Custom Domain card. Direct visits to `YOUR_SLUG.jamdesk.app` then return a 404. Your CNAME or proxy keeps working. Jamdesk checks your live domain before the toggle turns on. The subdomain serves again while your DNS is broken. Use password protection or JWT authentication to restrict who can read your docs. [Custom domain only →](/deploy/custom-domain-only)

**Build your whole API reference from a spec.** Point a navigation tab at your OpenAPI file with `"openapi": { "source": "/openapi/api.yaml", "generate": true }`. Each build creates a page per operation, grouped in the sidebar by tag. Endpoint pages you already committed keep their slugs. Migrate one page at a time. A renamed path redirects from its old URL instead of returning a 404. [Generated API pages →](/config/docs-json-reference#openapi)

**Code samples follow the selected API server.** A picker appears beside the endpoint URL when the spec lists more than one `servers` entry. Choosing a server updates the copy button, every code sample, and the playground request. Single-server endpoints are unchanged. [API Playground →](/api-reference/playground#multiple-servers)

**Markdown in every OpenAPI description.** Parameter, request-body, response, and schema descriptions now render tables, lists, links, `code`, and **bold**, like operation descriptions already did. [OpenAPI Example →](/api-reference/openapi-example)

**Endpoint Markdown exports carry authentication.** The `.md` version of an API reference page now ends with an `## Authentication` section. It lists the schemes the operation needs: type, header name, bearer format, OAuth 2 scopes, and which combinations are valid. An agent can build a working request without opening your spec. [Markdown Source →](/ai/markdown-source#what-an-endpoint-page-exports)

**Keep a page out of search without hiding it.** Add `search: false` to the page's frontmatter. AI chat answers and the MCP server skip it too. The sidebar, sitemap, and llms.txt still list it. Use it for a superseded page you still want linked and indexed. Hidden and noindexed pages are now also left out of AI answers. [Keep a page out of search only →](/content/hidden-pages#keep-a-page-out-of-search-only)

**`jamdesk validate` flags ignored config.** It names `docs.json` keys that Jamdesk accepts but never renders, such as `asyncapi`. It also catches `api.mdx.server` entries after the first. [CLI overview →](/cli/overview)

</Update>

<Update label="June 2026" date="2026-06-24">

**Fix broken links automatically.** One command now fixes broken internal-link warnings with an unambiguous target, such as typo'd anchors and cross-locale anchor drift. Preview planned changes with `jamdesk fix --dry-run`. Apply them with `jamdesk fix`. It only touches warnings where the correct anchor resolves to a real heading. Ambiguous cases are left for manual review. [CLI overview →](/cli/overview)

**Announce anything with a banner.** Add a `banner` to your `docs.json` to pin a message bar to the top of every page. It sits above the header in your theme's accent color. Use links, **bold**, and *italic* inline. Set `dismissible: true` to give readers a close button. A closed banner stays closed until you change the message. [Banner →](/config/docs-json-reference#banner)

**Show when each page was last updated.** Set `metadata.timestamp: true` in your `docs.json` to add a "Last updated on June 15, 2026"-style line to every page footer. The date comes from the last Git commit that changed the page. It stays accurate on each build with no manual upkeep. [Page Metadata →](/config/docs-json-reference#metadata)

**Style your navigation icons.** Sidebar, group, tab, anchor, and search icons now honor the `style` on an icon object (`{ "name": "rocket", "style": "duotone" }`) or a style prefix (`duotone/rocket`). Use light, thin, duotone, and the sharp family, not only solid. [Icons →](/content/icons#icon-object-form)

**Customize the search bar.** Set your own placeholder text with `search.prompt`. Pick the quick links in the empty search panel with `search.popularPages`. Each link has a title, a page slug, and a Font Awesome icon. [Search configuration →](/config/docs-json-reference#search)

**Collect email signups with no embed required.** Connect Resend, Mailchimp, Kit, Loops, beehiiv, Brevo, or SendGrid in **Integrations → Email Signups**. A Jamdesk-hosted form adds readers straight to your own audience. Your API key stays on our backend, never in your published site. Add the [`EmailSubscribe`](/components/email-subscribe) component to any page, or set `placement: changelog` to put a signup box on every changelog page. [Email Signups →](/integrations/email-signups)

**Gate analytics behind cookie consent.** Add an `integrations.cookies` key to your `docs.json`. Jamdesk then withholds every analytics and tracking script until a visitor consents. That covers Google Analytics, GTM, Plausible, Crisp, custom JavaScript, and Jamdesk's own built-in analytics. Consent is read from a `localStorage` flag your consent banner sets. You can also load an Osano or Termly banner from `docs.json`. A short bridge snippet flips the flag the moment a reader accepts. Scripts load with no page reload. [Cookie Consent →](/integrations/cookie-consent)

**llms.txt, organized.** Every site's `llms.txt` now follows the llmstxt.org structure. Your navigation tabs and groups become `##` sections. AI agents see your docs the way your sidebar organizes them. Multilingual sites get one index per language. The root file lists your default language and links each translated index (for example `/fr/llms.txt`). Each index stays small enough that no agent truncates it. [llms.txt →](/ai/llms-txt)

**Agents find your docs faster.** Every page now carries an invisible, screen-reader-silent directive pointing AI agents at `llms.txt` and the `.md` version of the page. Every Markdown export opens with a blockquote linking the index. Agents that fetch your HTML no longer have to guess that a Markdown path exists. [AI Overview →](/ai/overview)

**Embed your changelog anywhere.** Add a "What's new?" launcher to your own app with one `<script>` tag. It opens your Jamdesk changelog in a modal, with a per-visitor unread dot. Generate the snippet from **Integrations → What's New widget**. Tune the launcher mode, corner, modal size, and dot color with `data-` attributes. In your Jamdesk docs, the [`<Widget>`](/components/widget) MDX component adds the same live launcher to any page with one tag and no script. [Embed Your Changelog →](/development/embed-page)

**Download your API specs as a zip.** The AI Actions menu on API reference pages now has a **Download API spec** option. It bundles every OpenAPI spec your site references, local files and remote URLs, into one `api-specs.zip`. Multi-file specs keep their `$ref` folder structure. The download drops straight into Postman, a client generator, or your own tooling. [AI Actions →](/ai/ai-actions)

**OpenAPI specs validated at build time.** Every deploy now strictly validates the OpenAPI specs your `docs.json` references. A problem shows up as a **non-fatal build warning** instead of failing the build. Your docs still publish. You get the exact error (a YAML parse error with line and column, an unresolved `$ref`, or a duplicate `operationId`) by email and in the dashboard's build list. Locally, `jamdesk dev` still stops on an invalid spec. You catch it before pushing. [CLI overview →](/cli/overview)
</Update>

**PDF Export.** Render your whole docs site to one [PDF](/builds/pdf-export) from **Settings → PDF Exports** in the dashboard. Paid plans only. Pick a locale per export on multi-language projects. Results are cached per commit. You get an email with a download link when rendering finishes.

Favicons, `og:image`, and `twitter:image` stay in their original format for social crawler compatibility. A new **Optimizing images** step shows live progress in the dashboard and CLI during each build. [Automatic Image Conversion →](/builds/image-optimization)

Two-step install from the plugin marketplace. Pairs with [CLAUDE.md](/ai/claude-code) and the [MCP server](/ai/mcp-server) for AI-assisted doc writing.

**Build Warnings for Missing Branding.** Builds now warn when `favicon` or `logo` paths in `docs.json` reference files that don't exist in your project. Warnings appear in the dashboard build details and in the CLI via `jamdesk dev` and `jamdesk validate`. No email is sent. The warning is informational only.
