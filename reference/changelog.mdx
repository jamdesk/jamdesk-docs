New features, platform changes, and CLI updates for Jamdesk.

<Update label="February 2026">
**Custom Domain TXT Verification** — All custom domains now require a TXT record (`_jamdesk.yourdomain.com`) before routing activates. This prevents domain takeover on unclaimed subdomains. Newly added domains will see the TXT record in the dashboard setup flow. See the [DNS setup guide](/deploy/custom-domains) or the [dashboard walkthrough](/help/custom-domains).

**Multi-Language Support** — Define separate navigation trees and content directories per locale. Readers switch languages from a dropdown in the top bar. See [Multi-Language Support](/setup/languages).

**Builds API** — Trigger rebuilds from CI pipelines, cron jobs, or scripts without pushing a commit. Authenticate with a project API key and POST to the rebuild endpoint. See [Builds API](/reference/builds-api).

**Search Analytics** — See what readers search for, which queries return zero results, and what they click. Useful for finding content gaps. See [Search Analytics](/setup/search-analytics).
</Update>

<Update label="January 2026">
Jamdesk launches — a docs-as-code platform that builds documentation sites from MDX and GitHub, deploys to a global CDN, and generates AI-ready output. Typical builds complete in under 60 seconds.

### Authoring

**MDX + Custom React Components** — Write in standard Markdown with optional JSX. Create reusable `.tsx` components with full Tailwind and React hook support. See [MDX Basics](/content/mdx-basics) and [Custom React Components](/content/react-components).

**20+ Built-in Components** — [Tabs](/components/tabs), [accordions](/components/accordion), [steps](/components/steps), [code groups](/components/code-group), [Mermaid diagrams](/components/mermaid), [KaTeX math](/content/math), and 7,000+ [Font Awesome Pro icons](/content/icons). See [Components Overview](/components/overview).

**Code Blocks** — Syntax highlighting, line numbers, filename labels, and line highlighting out of the box. See [Code Blocks](/content/code-blocks).

**Snippets & Custom CSS** — Extract shared content into [reusable snippets](/content/snippets) and override any theme style with a [custom CSS file](/customization/custom-css).

**OpenAPI / API Documentation** — Point `api.openapi` in `docs.json` at your spec file and Jamdesk generates endpoint pages with request/response schemas and auth details. See [OpenAPI Example](/api-reference/openapi-example).

### Building & Deploying

**GitHub-Connected Builds** — Push to your branch, Jamdesk builds and deploys to a global CDN automatically. Builds are debounced (10s) so rapid pushes don't queue redundant jobs. See [How Jamdesk Works](/how-jamdesk-works).

**Host at /docs** — Serve documentation at `yourdomain.com/docs` alongside your existing site. Dedicated guides for [Vercel](/deploy/vercel), [AWS CloudFront](/deploy/aws), [Cloudflare](/deploy/cloudflare), and a [reverse proxy guide](/deploy/reverse-proxy) covering nginx, Apache, Caddy, Traefik, and HAProxy. See [Subpath Hosting](/deploy/subpath-hosting).

**Custom Domains** — Point your own domain at your docs with automatic SSL provisioning. See [Custom Domains](/deploy/custom-domains).

**Monorepo Support** — Keep docs in a subdirectory of an existing repo. Set the path to `docs.json` in project settings and Jamdesk scopes builds to that directory. See [Monorepo Support](/setup/monorepo-support).

**Redirects** — Exact and wildcard URL redirects in `docs.json` for moved pages and legacy URLs. See [Redirects](/setup/redirects).

### AI Integration

**LLM-Ready by Default** — Every site generates [`llms.txt`](/ai/llms-txt) for LLM context windows, exposes raw Markdown at [`.md` URLs](/ai/markdown-source), and includes a built-in [MCP server](/ai/mcp-server) at `/_mcp` with `searchDocs` and `getPage` tools. Your docs are queryable by Claude, Cursor, Codex, and any MCP-compatible tool without extra configuration.

### Tooling & Integrations

**CLI** — `jamdesk dev` for local preview with hot reload, `jamdesk validate` for broken links, `jamdesk migrate` to convert from Mintlify, GitBook, or Docusaurus, and `jamdesk doctor` to diagnose setup issues. Install via npm, curl, or Homebrew. See [CLI Overview](/cli/overview).

**Built-in Search** — Cmd+K full-text search that indexes your content automatically. Zero configuration.

**Analytics** — Privacy-focused, cookie-free page analytics built in. Track page views, traffic sources, and visitor trends. See [Analytics Overview](/setup/analytics-overview).

**Integrations** — [Google Analytics 4](/help/google-analytics), [Google Tag Manager](/help/google-tag-manager), and [Slack build notifications](/help/slack-integration) (Pro).

**SEO** — Auto-generated sitemaps, Open Graph images, AI endpoints (`llms.txt`, MCP), and per-page meta control. See [SEO](/content/seo).

### Customization

**Theming** — Three built-in themes (`jam`, `nebula`, `pulsar`), custom brand colors, logos, favicons, navbar links, and footer configuration. See [Theming](/customization/theming) and [Branding](/customization/branding).
</Update>
