Latest updates to the Jamdesk platform, CLI, and documentation tools.

<Update label="February 2026">
**Multi-Language Support** — Configure multiple languages in your documentation with a built-in language switcher. Each language gets its own navigation and content directory. See [Multi-Language Support](/setup/languages).

**MCP Integration** — AI agents can now query your documentation directly using the Model Context Protocol. Every Jamdesk site exposes an MCP endpoint at `/_mcp`. See [MCP Server](/ai/mcp-server).
</Update>

<Update label="January 2026">
**Snippets** — Reusable content blocks for shared content across pages. Create MDX or React components in `/snippets` and import them anywhere. See [Snippets](/content/snippets).

**Custom React Components** — Define inline React components in MDX or create reusable `.tsx` components with full Tailwind and hook support. See [Custom React Components](/content/react-components).

**Custom CSS** — Override theme styles with your own CSS file. Reference it in `docs.json` under `styling.css`. See [Custom CSS](/customization/custom-css).

**Redirects** — Set up URL redirects for moved pages and legacy URLs. Supports exact and wildcard patterns. See [Redirects](/setup/redirects).

**CLI Improvements**
- `jamdesk validate` checks for broken internal links
- `jamdesk migrate` handles component deprecations automatically
- `jamdesk doctor` diagnoses common setup issues
</Update>

<Update label="December 2025">
**AI-Ready Documentation** — Every Jamdesk site now generates `llms.txt` automatically — a structured file optimized for AI assistants and LLM context windows. See [Automated Doc Updates](/ai/automated-updates).

**Monorepo Support** — Run documentation from a subdirectory in an existing repo. Configure the path to `docs.json` in dashboard project settings and Jamdesk scopes builds to that directory. See [Monorepo Support](/setup/monorepo-support).

**Math & LaTeX** — Render mathematical expressions with KaTeX. Inline math with `$...$` and display blocks with `$$...$$`. See [Math](/content/math).

**Build Performance**
- 40% faster builds for large documentation sites
- Incremental builds for unchanged pages
- Improved asset optimization

**Dashboard Updates**
- Real-time build progress with detailed status
- Search analytics to see what users search for
- Improved GitHub integration flow
</Update>

<Update label="November 2025">
**Subpath Hosting** — Host documentation at `yourdomain.com/docs` alongside your existing website using reverse proxy configuration. See [Subpath Hosting](/deploy/subpath-hosting).

**Migration CLI** — Migrate from Mintlify, GitBook, Docusaurus, and other platforms. The CLI handles component mapping, frontmatter conversion, and navigation structure automatically. See [Migration Guide](/setup/migration).

**New Components**
- `Mermaid` — Render diagrams from text
- `Frame` — Image containers with captions
- `Expandable` — Collapsible content sections

**Theme Improvements**
- Better dark mode contrast
- Improved mobile navigation
- Faster page transitions
</Update>

<Update label="October 2025">
**Platform Launch** — Jamdesk launches with a full documentation platform: MDX authoring, GitHub-connected builds, CLI tooling, and CDN deployment.

**Local Development** — Preview documentation locally with hot reload using `jamdesk dev`. See [Local Preview](/development/local-preview).

**Deployment Options** — Custom domains, Cloudflare, AWS CloudFront, Vercel Edge Middleware, and reverse proxy guides for nginx, Apache, Caddy, Traefik, and HAProxy. See [Deployment](/deploy/overview).

**SEO** — Auto-generated sitemaps, Open Graph images, JSON-LD structured data, and per-page indexing control. See [SEO](/content/seo).

**Branding & Theming** — Three built-in themes, custom colors, logos, favicons, navbar links, footer socials, and link columns. See [Theming](/customization/theming) and [Branding](/customization/branding).

**Icons** — Access to 7,000+ Font Awesome Pro icons with solid, regular, light, thin, and duotone variants. See [Icons](/content/icons).

**Media Embeds** — Images with dimension syntax, light/dark mode variants, YouTube, Vimeo, and iframe embeds. See [Media Embeds](/content/media-embeds).

**AI-Assisted Writing** — Guides for writing documentation with Claude Code, Cursor, Codex, and other AI tools. See [AI Overview](/ai/overview).
</Update>
