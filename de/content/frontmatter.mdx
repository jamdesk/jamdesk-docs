---
title: Frontmatter
description: Konfigurieren Sie Seitentitel, Beschreibungen, Symbole, Seitenleistenüberschreibungen und SEO-Metadaten im YAML-Frontmatter jeder MDX-Datei.
---

Jede MDX-Datei beginnt mit einem YAML-Block zwischen `---`-Markierungen. Diese Metadaten steuern den Seitentitel, die Darstellung der Seitenleiste und das Erscheinungsbild der Seite beim Teilen in sozialen Medien oder in Suchergebnissen.

## Grundlegendes Frontmatter

Jede Seite benötigt mindestens einen Titel:

```yaml
---
title: Getting Started
description: Learn the basics in 5 minutes
---
```

## Verfügbare Felder

### Erforderlich

| Feld | Typ | Beschreibung |
|-------|------|-------------|
| `title` | string | Seitentitel, der in der Navigation und im Browser-Tab angezeigt wird |

### Empfohlen

| Feld | Typ | Beschreibung |
|-------|------|-------------|
| `description` | string | Kurze Zusammenfassung für SEO und Suchergebnisse (50-160 Zeichen) |

### Optional

| Feld | Typ | Standard | Beschreibung |
|-------|------|---------|-------------|
| `icon` | string | - | Font Awesome-Symbol, das neben dem Seitentitel in der Seitenleistennavigation angezeigt wird |
| `sidebarTitle` | string | `title` | Kürzerer Titel für die Seitenleistennavigation |
| `mode` | string | - | Auf `"wide"` setzen, um ein Layout mit voller Breite zu verwenden |
| `hideFooter` | boolean | `false` | Social-Footer auf dieser Seite ausblenden |
| `rss` | boolean | `false` | RSS-Feed-Generierung aus den [Update](/de/components/update)-Komponenten auf dieser Seite aktivieren |
| `search` | boolean | `true` | Auf `false` setzen, um die Seite aus der Seitensuche, den Antworten des KI-Chats und MCP fernzuhalten. Sie bleibt in der Seitenleiste, der Sitemap und llms.txt. Siehe [Nur eine Seite aus der Suche entfernen](/de/content/hidden-pages#nur-eine-seite-aus-der-suche-entfernen) |
| `private` | boolean | `false` | Das [Passwort der Website](/de/setup/password-protection) verlangen, um diese Seite anzuzeigen. Wenn dies auf einer beliebigen Seite gesetzt wird, aktiviert der nächste Build den Modus für bestimmte Seiten. |
| `public` | boolean | `false` | Diese Seite vom Passwortschutz ausnehmen (wird verwendet, wenn die gesamte Website über `auth.password.enabled` geschützt ist). Hat Vorrang vor `private: true`, wenn beide gesetzt sind. |

### SEO & soziale Medien

Steuern Sie, wie die Seite in Suchergebnissen und sozialen Vorschauen angezeigt wird. Legen Sie diese als flache Schlüssel auf oberster Ebene oder in einem verschachtelten `seo:`-Block fest. Beides funktioniert, und seitenbezogene Werte überschreiben die `seo.metatags`-Standardeinstellungen aus Ihrer `docs.json`.

| Feld | Typ | Standard | Beschreibung |
|-------|------|---------|-------------|
| `keywords` | string[] | - | Suchbegriffe, die als `<meta name="keywords">`-Tag ausgegeben werden |
| `canonical` | string | auto | Kanonische URL für diese Seite, die die automatisch generierte URL überschreibt |
| `noindex` | boolean | `false` | Diese Seite aus Suchmaschinen und der Sitemap ausschließen |
| `og:*` / `twitter:*` | string | - | Open-Graph- und Twitter/X-Tags für soziale Vorschauen (z. B. `og:title`, `og:image`, `twitter:card`) |
| `seo` | object | - | Verschachtelter Block mit allen oben genannten sowie beliebigen benutzerdefinierten Meta-Tags |

```yaml
---
title: API Reference
description: REST endpoints and authentication
"og:image": /images/api-card.png
"twitter:card": summary_large_image
canonical: https://docs.acme.com/api-reference
---
```

Eine vollständige Liste der unterstützten Tags und Beispiele finden Sie unter [SEO-Optimierung](/de/content/seo).

<Tip>
Fügen Sie nach einem Build die URL der Seite in das kostenlose Tool [OpenGraph Preview](https://jamdesk.com/utilities/opengraph-preview) ein, um zu sehen, wie diese Tags auf X, Facebook, LinkedIn, Slack, Discord und weiteren Plattformen dargestellt werden.
</Tip>

## Beispiele

### Standard-Dokumentationsseite

```yaml
---
title: Authentication
description: Secure your API with OAuth 2.0 and API keys
icon: lock
---
```

### Langer Titel mit Seitenleistenüberschreibung

```yaml
---
title: Configuring Single Sign-On with SAML 2.0
sidebarTitle: SSO Setup
description: Set up enterprise SSO for your organization
---
```

Der vollständige Titel wird auf der Seite angezeigt, während der kürzere `sidebarTitle` für eine übersichtliche Navigation sorgt.

### Layout mit voller Breite

```yaml
---
title: API Reference
description: Complete API documentation
mode: wide
---
```

Der breite Modus entfernt das Inhaltsverzeichnis und erweitert den Inhalt auf die volle Breite. Dies ist nützlich für API-Referenzseiten oder Inhalte mit breiten Tabellen.

### Footer ausblenden

```yaml
---
title: Custom Landing
description: A focused landing page experience
hideFooter: true
---
```

Verwenden Sie `hideFooter` für Landingpages, Changelog-Seiten oder andere Seiten, auf denen Sie einen übersichtlicheren unteren Bereich ohne soziale Links wünschen.

## Best Practices für SEO

<AccordionGroup>
  <Accordion title="Überzeugende Titel schreiben" icon="heading" defaultOpen>
    Ihr Titel erscheint in:
    - Browser-Tabs
    - Suchmaschinenergebnissen
    - Seitenleistennavigation
    - Geteilten Inhalten in sozialen Medien

    Halten Sie Titel unter 60 Zeichen. Platzieren Sie wichtige Suchbegriffe möglichst am Anfang.

    ```yaml
    # Good - clear and keyword-rich
    title: Deploy to Production

    # Avoid - vague or too long
    title: How to Deploy Your Application to Production Servers
    ```
  </Accordion>

  <Accordion title="Nützliche Beschreibungen erstellen" icon="align-left">
    Beschreibungen erscheinen in Suchergebnissen und sozialen Vorschauen. Streben Sie 50–160 Zeichen an, die:
    - den Seiteninhalt zusammenfassen
    - relevante Suchbegriffe enthalten
    - Nutzer zum Klicken anregen

    ```yaml
    # Good - actionable and specific
    description: Deploy your docs to production in under 2 minutes with zero configuration

    # Avoid - generic or missing
    description: Documentation page
    ```
  </Accordion>

  <Accordion title="Konsistente Symbole verwenden" icon="icons">
    Symbole helfen Nutzern, die Navigation schnell zu überblicken. Verwenden Sie für verwandte Seiten dasselbe Symbol:

    | Thema | Empfohlenes Symbol |
    |-------|----------------|
    | Erste Schritte | `rocket` |
    | Authentifizierung | `lock` |
    | API-Referenz | `code` |
    | Einstellungen | `gear` |
    | Abrechnung | `credit-card` |

    Durchsuchen Sie die Symbole bei [Font Awesome](https://fontawesome.com/icons).
  </Accordion>
</AccordionGroup>

## Validierung

Jamdesk validiert das Frontmatter während des Builds. Häufige Fehler:

<Accordion title="Erforderliche Felder fehlen">
```text
Error: Page "api/auth.mdx" is missing required field: title
```

**Lösung:** Fügen Sie das Feld `title` zu Ihrem Frontmatter hinzu.
</Accordion>

<Accordion title="Ungültige YAML-Syntax">
```text
Error: Invalid frontmatter in "guide.mdx": unexpected token
```

**Lösung:** Prüfen Sie Folgendes:
- Fehlende Anführungszeichen um Zeichenfolgen mit Sonderzeichen
- Falsche Einrückung
- Fehlende Doppelpunkte nach Schlüsseln

Fügen Sie den Block zwischen den `---`-Markierungen in den kostenlosen [YAML Validator](https://jamdesk.com/utilities/yaml-validator) ein, um Zeile und Spalte des Fehlers zu ermitteln.
</Accordion>
