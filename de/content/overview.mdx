Jamdesk-Seiten sind MDX-Dateien: standardmäßiges Markdown mit React-Komponenten, die Sie überall dort verwenden können, wo Sie sie benötigen. Eine Seite besteht lediglich aus Frontmatter und Inhalt.

```mdx
---
title: Rate Limits
description: How rate limiting works across API tiers.
---

Requests are limited per API key.

<Note>Enterprise plans have custom limits.</Note>
```

Das meiste, was Sie schreiben werden, ist einfaches Markdown. Die Seiten in diesem Abschnitt behandeln den Rest: Codeblöcke mit Syntaxhervorhebung, Bilder und Videos, mathematische Notation, wiederverwendbare Snippets sowie die Frontmatter-Felder, die Titel, Symbole und SEO-Metadaten steuern.
