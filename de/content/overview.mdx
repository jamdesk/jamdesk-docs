Jamdesk-Seiten sind MDX-Dateien: Standard-Markdown mit React-Komponenten, die überall dort verfügbar sind, wo Sie sie brauchen. Eine Seite besteht aus Frontmatter und Inhalt.

```mdx
---
title: Rate Limits
description: How rate limiting works across API tiers.
---

Requests are limited per API key.

<Note>Enterprise plans have custom limits.</Note>
```

Der größte Teil dessen, was Sie schreiben, ist reines Markdown. Die Seiten in diesem Bereich behandeln den Rest: Code-Blöcke mit Syntax-Hervorhebung, Bilder und Videos, mathematische Notation, wiederverwendbare Snippets sowie die Frontmatter-Felder, die Titel, Icons und SEO-Metadaten steuern.
