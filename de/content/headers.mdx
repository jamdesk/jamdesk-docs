---
title: Überschriften
description: Strukturiere Seiten mit H2- und H3-Überschriften, die das Inhaltsverzeichnis rechts automatisch befüllen und teilbare Anker-Links erzeugen.
---

Markdown-Überschriften (`##`, `###`) gliedern deine Seite in Abschnitte. Jamdesk fügt H2- und H3-Überschriften dem Inhaltsverzeichnis auf der rechten Seite hinzu. Außerdem erzeugt es für jede Überschrift einen teilbaren Anker-Link.

## Grundlegende Verwendung

Verwende Standard-Markdown-Überschriften, um deinen Inhalt zu strukturieren:

```markdown
## Section Title

Content goes here...

### Subsection

More detailed content...
```

Das **Inhaltsverzeichnis** auf der rechten Seite listet H2- und H3-Überschriften auf. Leser nutzen es, um zwischen Abschnitten langer Seiten zu springen.

## Anchor-Links

Jede Überschrift erzeugt eine Anker-ID aus ihrem Text:

| Überschrift               | Erzeugter Anker        |
| ------------------------- | ---------------------- |
| `## Loslegen`             | `#loslegen`            |
| `## API-Referenz`         | `#api-referenz`        |
| `### Benutzerauthentifizierung` | `#benutzerauthentifizierung` |

### Überschriftenlinks teilen

Fahre mit der Maus über eine beliebige H2- oder H3-Überschrift, um ein **Link-Symbol** anzuzeigen:

- **Klicke auf das Link-Symbol**, um die URL in die Zwischenablage zu kopieren
- **Klicke auf den Überschriftentext**, um die URL zu kopieren und zu diesem Abschnitt zu navigieren

Das Link-Symbol erscheint in einem kleinen umrandeten Kasten links neben der Überschrift. Das Symbol wechselt kurz die Farbe, um das Kopieren zu bestätigen.

<Note>
  Mobilgeräte haben keinen Hover-Zustand. Das Link-Symbol ist dort ausgeblendet.
  Überschriften funktionieren für die Navigation trotzdem.
</Note>

### Auf Überschriften verlinken

Verweise mithilfe des Ankers auf bestimmte Abschnitte anderer Seiten:

```markdown
See the [headings section](/content/mdx-basics#headings) for details.
```

## Best Practices

<AccordionGroup>
  <Accordion title="Verwende eine klare Hierarchie" icon="sitemap" defaultOpen>
    Beginne mit H2 für Hauptabschnitte und H3 für Unterabschnitte:

    ```markdown
    ## Installation

    ### Prerequisites

    ### Quick Install

    ## Configuration

    ### Basic Options

    ### Advanced Options
    ```

    Vermeide das Überspringen von Ebenen (z. B. von H2 direkt zu H4).

  </Accordion>

  <Accordion title="Halte Überschriften kurz" icon="text-width">
    Kurze Überschriften lassen sich leichter überfliegen:

    ```markdown
    {/* Good */}
    ## Authentication

    {/* Avoid */}
    ## How to Set Up Authentication in Your Application
    ```

  </Accordion>

  <Accordion title="Verwende Satzschreibweise" icon="font">
    Schreibe nur das erste Wort und Eigennamen groß:

    ```markdown
    {/* Good */}
    ## Getting started with the API

    {/* Avoid */}
    ## Getting Started With The API
    ```

  </Accordion>
</AccordionGroup>
