Jamdesk rendert LaTeX-Mathematik mit [KaTeX](https://katex.org/).

<Note>
Mathematik-Unterstützung erfordert `styling.latex: true` in deiner `docs.json`-Datei.
</Note>

## Matheunterstützung aktivieren

Füge Folgendes zu deiner `docs.json` hinzu:

```json docs.json
{
  "styling": {
    "latex": true
  }
}
```

## Inline-Mathematik

Verwende einfache Dollarzeichen für Gleichungen innerhalb des Textes:

```md
The Pythagorean theorem states that $a^2 + b^2 = c^2$.
```

**Wird dargestellt als:** The Pythagorean theorem states that $a^2 + b^2 = c^2$.

## Blockgleichungen

Verwende doppelte Dollarzeichen für zentrierte Gleichungen im Anzeigemodus:

```md
$$
E = mc^2
$$
```

**Wird dargestellt als:**

$$
E = mc^2
$$

## Komplexe Gleichungen

KaTeX rendert eine breite Palette an LaTeX-Notation:

### Brüche

```md
$$
\frac{n!}{k!(n-k)!} = \binom{n}{k}
$$
```

### Integrale

```md
$$
\int_0^\infty e^{-x^2} dx = \frac{\sqrt{\pi}}{2}
$$
```

### Summen

```md
$$
\sum_{i=1}^{n} i = \frac{n(n+1)}{2}
$$
```

### Matrizen

```md
$$
\begin{bmatrix}
a & b \\
c & d
\end{bmatrix}
$$
```

## Die Latex-Komponente verwenden

Verwende die `<Latex>`-Komponente direkt für mehr Kontrolle:

```mdx
<Latex>E = mc^2</Latex>
```

Für den Block- bzw. Anzeigemodus:

```mdx
<Latex block>
\int_0^\infty e^{-x^2} dx = \frac{\sqrt{\pi}}{2}
</Latex>
```

## Codeblöcke sind geschützt

Dollarzeichen innerhalb von Codeblöcken werden **nicht** als Mathematik behandelt:

```bash
echo $HOME
export PRICE=$100
```

## Unterstützte Befehle

KaTeX deckt die meisten gängigen LaTeX-Mathematikbefehle ab. Die [KaTeX-Dokumentation](https://katex.org/docs/supported.html) listet jede unterstützte Funktion auf.

<Tip>
Teste komplexe Gleichungen zuerst auf [KaTeX's Demoseite](https://katex.org/).
</Tip>
