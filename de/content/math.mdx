Jamdesk unterstützt LaTeX zum Rendern mathematischer Ausdrücke und Gleichungen mit [KaTeX](https://katex.org/).

<Note>
Die Matheunterstützung erfordert `styling.latex: true` in Ihrer Datei `docs.json`.
</Note>

## Matheunterstützung aktivieren

Fügen Sie Folgendes zu Ihrer `docs.json` hinzu:

```json docs.json
{
  "styling": {
    "latex": true
  }
}
```

## Inline-Mathematik

Verwenden Sie einzelne Dollarzeichen für Inline-Gleichungen:

```md
The Pythagorean theorem states that $a^2 + b^2 = c^2$.
```

**Wird gerendert als:** The Pythagorean theorem states that $a^2 + b^2 = c^2$.

## Blockgleichungen

Verwenden Sie doppelte Dollarzeichen für zentrierte Gleichungen im Anzeigeformat:

```md
$$
E = mc^2
$$
```

**Wird gerendert als:**

$$
E = mc^2
$$

## Komplexe Gleichungen

KaTeX unterstützt eine große Bandbreite an LaTeX-Notation:

### Brüche

```md
$$
\frac{n!}{k!(n-k)!} = \binom{n}{k}
$$
```

### Integrale

```md
$$
\int_0^\infty e^{-x^2} dx = \frac{\sqrt{\pi}}{2}
$$
```

### Summen

```md
$$
\sum_{i=1}^{n} i = \frac{n(n+1)}{2}
$$
```

### Matrizen

```md
$$
\begin{bmatrix}
a & b \\
c & d
\end{bmatrix}
$$
```

## Die Latex-Komponente verwenden

Für mehr Kontrolle verwenden Sie die Komponente `<Latex>` direkt:

```mdx
<Latex>E = mc^2</Latex>
```

Für den Block- bzw. Anzeigemodus:

```mdx
<Latex block>
\int_0^\infty e^{-x^2} dx = \frac{\sqrt{\pi}}{2}
</Latex>
```

## Codeblöcke sind geschützt

Dollarzeichen innerhalb von Codeblöcken werden **nicht** als Mathematik behandelt:

```bash
echo $HOME
export PRICE=$100
```

Dies wird als normaler Code und nicht als Gleichungen gerendert.

## Unterstützte Befehle

KaTeX unterstützt die meisten gängigen LaTeX-Mathebefehle. Eine vollständige Liste der unterstützten Funktionen finden Sie in der [KaTeX-Dokumentation](https://katex.org/docs/supported.html).

<Tip>
Testen Sie komplexe Gleichungen zunächst auf der [KaTeX-Demoseite](https://katex.org/).
</Tip>
