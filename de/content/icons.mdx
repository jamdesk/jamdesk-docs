Jamdesk wird mit **Font Awesome Pro** ausgeliefert: Tausende kostenlose und Pro-Icons.

## Icons in Komponenten verwenden

Die meisten Komponenten akzeptieren eine `icon`-Eigenschaft mit einem Font-Awesome-Icon-Namen:

```mdx
<Card title="Quickstart" icon="rocket" href="/quickstart">
  Learn how to set up your documentation site.
</Card>
```

<Card title="Quickstart" icon="rocket" href="/de/quickstart">
  Learn how to set up your documentation site.
</Card>

Icons funktionieren in Karten, Akkordeons, Tabs und Navigationseinträgen.

## Die Icon-Komponente

Verwende die `<Icon>`-Komponente, um Icons inline mit Text anzuzeigen:

```mdx
<Icon icon="check" color="green" /> Task completed
```

<Icon icon="check" color="green" /> Task completed

### Icon-Props

| Eigenschaft | Typ | Standard | Beschreibung |
|------|------|---------|-------------|
| `icon` | string | erforderlich | Font-Awesome-Icon-Name |
| `color` | string | - | Benannte Farbe (red, blue, green) oder Hex (#FF5733) |
| `size` | number | 16 | Größe in Pixel |

### Beispiele

```mdx
<Icon icon="star" color="yellow" size={24} />
<Icon icon="circle-check" color="green" />
<Icon icon="triangle-exclamation" color="orange" />
<Icon icon="heart" color="#E91E63" size={20} />
```

<Icon icon="star" color="yellow" size={24} /> <Icon icon="circle-check" color="green" /> <Icon icon="triangle-exclamation" color="orange" /> <Icon icon="heart" color="#E91E63" size={20} />

## Icons finden

Durchsuche die vollständige Icon-Bibliothek unter [fontawesome.com/icons](https://fontawesome.com/icons). Suche nach dem, was du brauchst, und verwende dann den Icon-Namen in deiner Dokumentation.

<Tip>
Auf der Font-Awesome-Website findest du den Namen unter dem Icon (z. B. "circle-check", "arrow-right"). Verwende genau diesen Namen in deiner Dokumentation.
</Tip>

## Icon-Varianten

Font-Awesome-Icons gibt es in mehreren Stilvarianten, die das visuelle Gewicht steuern. Stelle dem Icon-Namen ein Präfix voran, um eine Variante auszuwählen.

### Verfügbare Varianten

| Variante | Präfix | Beispiel | Beschreibung |
|---------|--------|---------|-------------|
| Solid | `solid/` | `solid/star` | Gefüllte Icons, schwerstes Gewicht |
| Regular | `regular/` | `regular/star` | Umrandete Icons, mittleres Gewicht |
| Light | `light/` | `light/star` | Dünnere umrandete Icons |
| Thin | `thin/` | `thin/star` | Dünnste umrandete Icons |
| Duotone | `duotone/` | `duotone/star` | Zweifarbige Icons mit überlagerten Farben |

Font Awesomes **Sharp**-Familie ist ebenfalls verfügbar, mit eckigen Ecken: `sharp-solid/`, `sharp-regular/`, `sharp-light/`, `sharp-thin/` und `sharp-duotone-solid/` (z. B. `sharp-duotone-solid/star`).

### Beispiele

```mdx
<Icon icon="solid/bell" size={24} />
<Icon icon="regular/bell" size={24} />
<Icon icon="light/bell" size={24} />
<Icon icon="thin/bell" size={24} />
<Icon icon="duotone/bell" size={24} />
```

<Icon icon="solid/bell" size={24} /> <Icon icon="regular/bell" size={24} /> <Icon icon="light/bell" size={24} /> <Icon icon="thin/bell" size={24} /> <Icon icon="duotone/bell" size={24} />

### Varianten in Komponenten verwenden

Varianten funktionieren überall dort, wo Icons verwendet werden: in Komponenten, der Navigation und im Frontmatter.

```mdx
<Card title="Callouts" icon="light/bell" href="/components/callouts">
  Add important notices to your documentation.
</Card>
```

```yaml page.mdx
---
title: Settings
icon: light/gear
---
```

```json docs.json
{
  "group": "Account",
  "icon": "regular/user",
  "pages": ["profile", "settings"]
}
```

### Objektform für Icons

Überall dort, wo `docs.json` ein Icon akzeptiert (Navigationsgruppen, Tabs, Anker, Seiten-Icons und `popularPages` der Suche), kannst du es statt als Zeichenkette als Objekt schreiben. Die Icon-Auswahl im Dashboard erzeugt diese Form:

```json docs.json
{
  "group": "Security",
  "icon": { "name": "shield", "style": "duotone" }
}
```

| Feld | Typ | Beschreibung |
|-------|------|-------------|
| `name` | string | Font-Awesome-Icon-Name (erforderlich) |
| `style` | string | Eine der oben genannten Varianten: `solid`, `regular`, `light`, `thin`, `duotone` oder eine `sharp-*`-Variante |
| `library` | string | `fontawesome` oder `lucide`, aus Kompatibilitätsgründen akzeptiert; Icons werden über Font Awesome gerendert |

`{ "name": "shield", "style": "duotone" }` entspricht der Zeichenkette `"duotone/shield"`. Verwende, was dir lieber ist. Das Frontmatter-Feld `icon` (Seiten-Icons) akzeptiert nur die Zeichenkettenform.

### Standardvariante

Icons werden standardmäßig in der **Solid**-Variante gerendert. Überschreibe sie pro Icon mit einem Stil-Präfix (`light/gear`) oder, in `docs.json`, mit dem Feld `style` der Objektform.

### Varianten vergleichen

Dasselbe Icon in jeder Variante:

| Variante | Icon | Geeignet für |
|---------|------|--------------|
| Solid | <Icon icon="solid/folder" size={20} /> | Primäre Aktionen, Hervorhebung |
| Regular | <Icon icon="regular/folder" size={20} /> | Sekundäre UI-Elemente |
| Light | <Icon icon="light/folder" size={20} /> | Minimalistisches Design, Navigation |
| Thin | <Icon icon="thin/folder" size={20} /> | Ultraminimalistische Ästhetik |
| Duotone | <Icon icon="duotone/folder" size={20} /> | Visuelles Interesse, Branding |

<Note>
Duotone-Icons verwenden zwei Farben: eine Primär- und eine Sekundärfarbe. Die Sekundärebene wird automatisch auf eine hellere Deckkraft der Primärfarbe gesetzt.
</Note>

## Navigations-Icons

Icons können in der Seitennavigation auf drei Ebenen erscheinen: Anker, Gruppen und einzelne Seiten.

### Seiten-Icons

Füge einer Seite über das Frontmatter ein Icon hinzu:

```yaml authentication.mdx
---
title: Authentication
icon: lock
---
```

Das Icon erscheint in der Seitenleiste neben dem Seitentitel.

### Gruppen-Icons

Füge Navigationsgruppen in `docs.json` Icons hinzu:

```json docs.json
{
  "group": "Security",
  "icon": "shield",
  "pages": ["authentication", "api-keys"]
}
```

### Anker-Icons

Füge Anker der obersten Ebene in `docs.json` Icons hinzu:

```json docs.json
{
  "navigation": {
    "anchors": [
      {
        "anchor": "Docs",
        "icon": "book-open",
        "groups": [...]
      },
      {
        "anchor": "API",
        "icon": "code",
        "groups": [...]
      }
    ]
  }
}
```

## Kostenlose und Pro-Icons

Jamdesk enthält Font Awesome Pro, was bedeutet:

- **7.000+ Icons** verfügbar (gegenüber ca. 2.000 in der kostenlosen Version)
- Alle kostenlosen Icons funktionieren ohne Änderungen
- Pro-exklusive Icons wie Duotone-Varianten sind enthalten
- Icons in den Gewichten Light und Thin sind verfügbar

Icons aus einer Dokumentationsplattform, die Font Awesome Free nutzte, funktionieren nach der Migration weiterhin.
