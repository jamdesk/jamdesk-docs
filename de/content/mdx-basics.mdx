Jede Jamdesk-Seite ist eine `.mdx`-Datei: Standard-Markdown mit JSX-Komponenten wie `<Card>`, `<Tabs>` und `<Accordion>`.

## Was ist MDX?

Mit MDX können Sie Standard-Markdown schreiben und JSX-Komponenten in derselben Datei einbetten. Verfassen Sie Überschriften, Listen und Codeblöcke in Markdown und fügen Sie Komponenten wie `<Card>` oder `<Tabs>` überall dort ein, wo Sie Interaktivität benötigen.

MDX eignet sich auch gut für Dokumentation, die von KI-Tools verarbeitet werden soll: Das Format besteht aus Klartext, den diese Tools nativ lesen und schreiben können, lässt sich in Git versionieren und ist strukturiert genug für Komponenten, ohne ein proprietäres Format zu erfordern.

```mdx
# Welcome to My Docs

This is regular **Markdown** with a component below:

<Card title="Quickstart" icon="rocket" href="/quickstart">
  Jump right in with our quickstart guide.
</Card>
```

<Tip>
  Zwei kostenlose Browser-Tools unterstützen Sie beim Schreiben: Der [MDX Validator](https://jamdesk.com/utilities/mdx-validator)
  erkennt Syntaxfehler vor einem Build, und der [MDX Formatter](https://jamdesk.com/utilities/mdx-formatter)
  vereinheitlicht Abstände und Einrückungen. Fügen Sie eine Seite ein, um sie zu prüfen oder aufzuräumen – ganz ohne CLI.
</Tip>

## Seitenstruktur

Jede MDX-Seite beginnt mit Frontmatter – Metadaten zwischen drei Bindestrichen:

```mdx
---
title: My Page Title
description: A brief description for search and previews
---

Your content starts here...
```

<Note>
`title` und `description` erscheinen in Suchergebnissen, Browser-Tabs und Vorschauen in sozialen Medien. Formulieren Sie sie sorgfältig.
</Note>

## Markdown-Grundlagen

### Überschriften

Verwenden Sie `##` für Hauptabschnitte und `###` für Unterabschnitte. Jamdesk erstellt automatisch ein Inhaltsverzeichnis aus Ihren Überschriften.

```markdown
## Main Section
Content under the main section.

### Subsection
More detailed content here.
```

<Tip>
Beginnen Sie Ihre erste Überschrift mit `##` (h2). Der Seitentitel aus dem Frontmatter dient als h1.
</Tip>

### Textformatierung

| Syntax | Ergebnis |
|--------|--------|
| `**bold**` | **fett** |
| `*italic*` | *kursiv* |
| `~~strikethrough~~` | ~~durchgestrichen~~ |
| `` `inline code` `` | `inline code` |

### Listen

```markdown
Unordered list:
- First item
- Second item
  - Nested item

Ordered list:
1. First step
2. Second step
3. Third step
```

### Zitate

```markdown
> This is a blockquote. Use it for callouts or
> highlighting important information.
```

> Dies ist ein Zitat. Verwenden Sie es für hervorgehobene Hinweise oder wichtige Informationen.

## Komponenten hinzufügen

Komponenten sind JSX-Elemente, die Sie überall in Ihrem MDX verwenden können. Sie stehen entweder für sich allein oder umschließen Inhalte:

```mdx
{/* Self-closing component */}
<Card title="Example" icon="star" href="/introduction" />

{/* Component wrapping content */}
<Accordion title="Click to expand">
  This content is inside the accordion.
</Accordion>
```

## Tabellen

Standard-Markdown-Tabellen funktionieren direkt:

```markdown
| Feature | Starter | Team |
|---------|------|-----|
| Pages | 10 | Unlimited |
| Custom domain | No | Yes |
```

| Funktion | Starter | Team |
|---------|------|-----|
| Seiten | 10 | Unbegrenzt |
| Eigene Domain | Nein | Ja |

Für erweiterte Funktionen wie das Hervorheben von Zeilen, die Ausrichtung von Zellen und das Zusammenführen von Zellen verwenden Sie die Table-Komponente:

<Table striped>
  <Row header>
    <Cell>Funktion</Cell>
    <Cell align="center">Starter</Cell>
    <Cell align="center">Team</Cell>
  </Row>
  <Row>
    <Cell>Seiten</Cell>
    <Cell align="center">10</Cell>
    <Cell align="center" highlight highlightColor="success">Unbegrenzt</Cell>
  </Row>
  <Row>
    <Cell>Eigene Domain</Cell>
    <Cell align="center">Nein</Cell>
    <Cell align="center" highlight highlightColor="success">Ja</Cell>
  </Row>
</Table>

<Note>
Ausführliche Informationen zu Tabellenkomponenten, einschließlich der Hervorhebung von Zeilen und Zellen, dem Zusammenführen von Spalten und Formatierungsoptionen, finden Sie unter [Tabellen](/de/components/tables).
</Note>

## Kommentare

Fügen Sie Kommentare hinzu, die nicht in der gerenderten Ausgabe erscheinen:

```mdx
{/* This is a comment - it won't be visible to readers */}
```
