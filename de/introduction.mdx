Jamdesk ist ein [Tool für Softwaredokumentation](https://jamdesk.com), das aus Ihren Markdown-Dateien Dokumentationswebsites erstellt. Verbinden Sie ein GitHub-Repository, schreiben Sie in MDX und stellen Sie Ihre Dokumentation in Sekunden weltweit bereit. Sie müssen keine Build-Pipeline einrichten und kein DevOps selbst übernehmen. Jede Website erzeugt eine `llms.txt`-Datei, damit KI-Tools Ihre Inhalte indexieren können.

<Info>
**Mit KI schreiben.** Verwenden Sie Cursor, Claude oder einen beliebigen KI-Assistenten, um Ihre Dokumentation zu erstellen und zu bearbeiten. MDX ist ein Textformat, das KI-Tools nativ verstehen, sodass keine speziellen Prompts erforderlich sind.
</Info>

## Ein minimales Jamdesk-Projekt

```text
my-docs/
├── docs.json
└── introduction.mdx
```

Das ist alles, was Sie benötigen. In der [Schnellstartanleitung](/de/quickstart) erfahren Sie, wie Sie Ihr eigenes Projekt erstellen.

<Tip>
Sehen Sie sich den [Quellcode dieser Dokumentation](https://github.com/jamdesk/jamdesk-docs) auf GitHub an. Es handelt sich um ein funktionierendes Jamdesk-Projekt, das Sie als Referenz verwenden können.
</Tip>

## Funktionsweise

<Steps>
  <Step title="In MDX schreiben">
    Erstellen Sie Dokumentation mit Markdown und optionalen React-Komponenten. Verwenden Sie Ihren bevorzugten Editor: VS Code, Cursor oder einen beliebigen Texteditor. KI-Tools wie Claude können MDX nativ erstellen und bearbeiten.
  </Step>
  <Step title="An GitHub übertragen">
    Committen Sie Ihre Änderungen und übertragen Sie sie. Sie müssen keinen Build-Befehl ausführen und kein Bereitstellungsskript pflegen.
  </Step>
  <Step title="In Sekunden live">
    Jamdesk erkennt Ihre Übertragung, erstellt Ihre Website und stellt sie in einem globalen CDN bereit. Ihre Dokumentation ist unter `your-project.jamdesk.app` live.
  </Step>
</Steps>
