Jamdesk ist ein [Tool für Software-Dokumentation](https://jamdesk.com), das aus Ihren Markdown-Dateien Dokumentationsseiten erstellt. Verbinden Sie ein GitHub-Repository, schreiben Sie in MDX und stellen Sie in Sekunden weltweit bereit. Sie müssen keine Build-Pipeline einrichten und keine DevOps-Aufgaben selbst übernehmen. Jede Seite erzeugt eine Datei `llms.txt`, die KI-Tools zum Indexieren Ihrer Inhalte nutzen.

<Info>
**Mit KI schreiben.** Verwenden Sie Cursor, Claude oder einen beliebigen KI-Assistenten, um Ihre Dokumentation zu erstellen und zu bearbeiten. KI-Tools lesen MDX nativ. Sie benötigen keine speziellen Prompts.
</Info>

## Ein minimales Jamdesk-Projekt

```text
my-docs/
├── docs.json
└── introduction.mdx
```

Mehr brauchen Sie nicht. Eine Anleitung zum Erstellen Ihres ersten Projekts finden Sie im [Quickstart](/de/quickstart).

<Tip>
Sehen Sie sich den [Quellcode dieser Dokumentation](https://github.com/jamdesk/jamdesk-docs) auf GitHub an. Es ist ein funktionierendes Jamdesk-Projekt, das Sie als Referenz verwenden können.
</Tip>

## Funktionsweise

<Steps>
  <Step title="In MDX schreiben">
    Erstellen Sie Dokumentation mit Markdown und optionalen React-Komponenten. Verwenden Sie Ihren bevorzugten Editor: VS Code, Cursor oder einen beliebigen Texteditor. KI-Tools wie Claude können MDX nativ erzeugen und bearbeiten.
  </Step>
  <Step title="Zu GitHub pushen">
    Committen Sie Ihre Änderungen und pushen Sie sie. Sie müssen keinen Build-Befehl ausführen und kein Deploy-Skript pflegen.
  </Step>
  <Step title="In Sekunden live">
    Jamdesk erkennt Ihren Push, baut Ihre Website und stellt sie in einem globalen CDN bereit. Ihre Dokumentation ist unter `your-project.jamdesk.app` erreichbar.
  </Step>
</Steps>
