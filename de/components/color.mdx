title: Farbe

  Dokumentation der Color-Komponente, die Hex-, RGB- und RGBA-Farbfelder in
  kompakten Rastern oder gruppierten Tabellen mit optionalen Werten pro Theme anzeigt
---

Color zeigt Hex-, RGB- und RGBA-Werte als Farbfelder an, die sich per Klick kopieren lassen. Es gibt zwei Layout-Varianten: ein kompaktes Raster und eine gruppierte Tabelle. Ein Farbfeld kann für jedes Theme einen eigenen Wert erhalten.

Verwende Color, wenn du:
- **Design-Systeme dokumentierst** mit Markenfarben
- **Theme-Farben zeigst**, die sich mit dem Theme ändern
- **Farbskalen darstellst** (primary-100 bis primary-900)
- **Markenrichtlinien mit Hex-/RGB-Werten teilst**

## Verwendung

```mdx
<Color>
  <ColorItem name="Primary" value="#635BFF" />
</Color>
```

## Kompakte Variante

Das Standard-Layout zeigt Farben in einem responsiven Raster an:

<Color>
  <ColorItem name="Primary" value="#3b82f6" />
  <ColorItem name="Success" value="#22c55e" />
  <ColorItem name="Warning" value="#f59e0b" />
  <ColorItem name="Error" value="#ef4444" />
</Color>

```mdx
<Color>
  <ColorItem name="Primary" value="#3b82f6" />
  <ColorItem name="Success" value="#22c55e" />
  <ColorItem name="Warning" value="#f59e0b" />
  <ColorItem name="Error" value="#ef4444" />
</Color>
```

## Tabellenvariante

Gruppiere Farben in beschriftete Zeilen:

<Color variant="table">
  <ColorRow title="Markenfarben">
    <ColorItem name="Primary" value="#3b82f6" />
    <ColorItem name="Secondary" value="#6366f1" />
  </ColorRow>
  <ColorRow title="Feedback-Farben">
    <ColorItem name="Success" value="#22c55e" />
    <ColorItem name="Error" value="#ef4444" />
  </ColorRow>
</Color>

```mdx
<Color variant="table">
  <ColorRow title="Brand Colors">
    <ColorItem name="Primary" value="#3b82f6" />
    <ColorItem name="Secondary" value="#6366f1" />
  </ColorRow>
  <ColorRow title="Feedback Colors">
    <ColorItem name="Success" value="#22c55e" />
    <ColorItem name="Error" value="#ef4444" />
  </ColorRow>
</Color>
```

## Konventionen für Farbnamen

| Muster | Beispiel | Verwendung für |
|---------|---------|---------|
| Semantisch | `success`, `error`, `warning` | Feedback-Farben |
| Numerische Skala | `primary-500`, `gray-100` | Farbpaletten |
| Beschreibend | `brand-blue`, `accent-gold` | Markenfarben |

## Theme-abhängige Farben

Übergib ein Objekt mit den Eigenschaften `light` und `dark`, um pro Theme eine Farbe festzulegen:

<Color>
  <ColorItem name="Background" value={{ light: "#ffffff", dark: "#0a0a0a" }} />
  <ColorItem name="Foreground" value={{ light: "#171717", dark: "#ededed" }} />
  <ColorItem name="Border" value={{ light: "#e5e5e5", dark: "#404040" }} />
</Color>

```mdx
<Color>
  <ColorItem name="Background" value={{ light: "#ffffff", dark: "#0a0a0a" }} />
  <ColorItem name="Foreground" value={{ light: "#171717", dark: "#ededed" }} />
  <ColorItem name="Border" value={{ light: "#e5e5e5", dark: "#404040" }} />
</Color>
```

## Farbformate

Die Komponente akzeptiert Hex-, RGB- und RGBA-Werte:

<Color>
  <ColorItem name="Hex" value="#3b82f6" />
  <ColorItem name="RGB" value="rgb(59, 130, 246)" />
  <ColorItem name="RGBA" value="rgba(59, 130, 246, 0.8)" />
</Color>

```mdx
<Color>
  <ColorItem name="Hex" value="#3b82f6" />
  <ColorItem name="RGB" value="rgb(59, 130, 246)" />
  <ColorItem name="RGBA" value="rgba(59, 130, 246, 0.8)" />
</Color>
```

## Props

### Color

<ParamField name="variant" type="string" default="compact">
  Layout-Stil: `compact` (Raster) oder `table` (gruppierte Zeilen).
</ParamField>

<ParamField name="children" type="node">
  `ColorItem`- oder `ColorRow`-Elemente.
</ParamField>

### ColorRow

<ParamField name="title" type="string">
  Beschriftung über der Zeile.
</ParamField>

<ParamField name="children" type="node">
  `ColorItem`-Elemente.
</ParamField>

### ColorItem

<ParamField name="name" type="string">
  Anzeigename für die Farbe.
</ParamField>

<ParamField name="value" type="string | object">
  Farbwert als CSS-String oder `{ light: string, dark: string }` für theme-abhängige Farben.
</ParamField>
