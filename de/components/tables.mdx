Tabellen organisieren Daten in Zeilen und Spalten. Verwenden Sie **Markdown-Tabellen** für schnelle, einfache Tabellen. Verwenden Sie **Table-Komponenten** für Hervorhebungen, Ausrichtung und weitere Optionen.

## Verwendung

```mdx
<Table>
  <Row header>
    <Cell>Name</Cell>
    <Cell>Type</Cell>
  </Row>
  <Row>
    <Cell>id</Cell>
    <Cell>string</Cell>
  </Row>
</Table>
```

## Markdown-Tabellen

Der schnellste Weg, eine Tabelle zu erstellen. Verwenden Sie Pipes (`|`), um Spalten zu trennen, und Bindestriche (`-`) für die Kopfzeile:

```markdown
| Name | Type | Description |
|------|------|-------------|
| id | string | Unique identifier |
| email | string | User email address |
```

| Name | Type | Description |
|------|------|-------------|
| id | string | Unique identifier |
| email | string | User email address |

<Tip>
Verwenden Sie Markdown-Tabellen für einfache Referenzdaten. Wechseln Sie zur Table-Komponente für Hervorhebungen, Ausrichtung oder visuelle Betonung.
</Tip>

## Table-Komponente

Für mehr Kontrolle verwenden Sie die Komponenten `<Table>`, `<Row>` und `<Cell>`:

```mdx
<Table>
  <Row header>
    <Cell>Name</Cell>
    <Cell>Type</Cell>
    <Cell>Description</Cell>
  </Row>
  <Row>
    <Cell>id</Cell>
    <Cell>string</Cell>
    <Cell>Unique identifier</Cell>
  </Row>
  <Row>
    <Cell>email</Cell>
    <Cell>string</Cell>
    <Cell>User email address</Cell>
  </Row>
</Table>
```

## Gestreifte Zeilen

Fügen Sie abwechselnde Zeilenhintergründe hinzu, um die Lesbarkeit zu verbessern:

```mdx
<Table striped>
  <Row header>
    <Cell>Parameter</Cell>
    <Cell>Value</Cell>
  </Row>
  <Row><Cell>timeout</Cell><Cell>30s</Cell></Row>
  <Row><Cell>retries</Cell><Cell>3</Cell></Row>
  <Row><Cell>backoff</Cell><Cell>exponential</Cell></Row>
  <Row><Cell>maxDelay</Cell><Cell>60s</Cell></Row>
</Table>
```

## Zeilen hervorheben

Heben Sie ganze Zeilen hervor, um Aufmerksamkeit zu lenken:

```mdx
<Table>
  <Row header>
    <Cell>Field</Cell>
    <Cell>Required</Cell>
    <Cell>Description</Cell>
  </Row>
  <Row highlight highlightColor="warning">
    <Cell>api_key</Cell>
    <Cell>Yes</Cell>
    <Cell>Your API authentication key</Cell>
  </Row>
  <Row>
    <Cell>limit</Cell>
    <Cell>No</Cell>
    <Cell>Maximum results (default: 100)</Cell>
  </Row>
</Table>
```

  <Row header>
    <Cell>Field</Cell>
    <Cell>Required</Cell>
    <Cell>Description</Cell>
  </Row>
  <Row highlight highlightColor="warning">
    <Cell>api_key</Cell>
    <Cell>Yes</Cell>
    <Cell>Your API authentication key</Cell>

## Spalten- und Zeilenzusammenführung

Verbinden Sie Zellen über Spalten oder Zeilen hinweg:

```mdx

  <Row header>

  </Row>

    <Cell>$0.50</Cell>
```

## Sortierbare Spalten

Aktivieren Sie die Spaltensortierung mit der Prop `sortable`. Klicken Sie auf eine Spaltenüberschrift, um zu sortieren:

```mdx
<Table sortable>
  <Row header>
    <Cell>Name</Cell>
    <Cell>Price</Cell>
    <Cell>Stock</Cell>
  </Row>
  <Row><Cell>Widget A</Cell><Cell>$29.99</Cell><Cell>150</Cell></Row>
  <Row><Cell>Gadget B</Cell><Cell>$49.99</Cell><Cell>75</Cell></Row>
  <Row><Cell>Tool C</Cell><Cell>$19.99</Cell><Cell>200</Cell></Row>
  <Row><Cell>Device D</Cell><Cell>$99.99</Cell><Cell>25</Cell></Row>
</Table>
```

    <Cell>Price</Cell>
    <Cell>Stock</Cell>
  </Row>
  <Row><Cell>Widget A</Cell><Cell>$29.99</Cell><Cell>150</Cell></Row>
  <Row><Cell>Gadget B</Cell><Cell>$49.99</Cell><Cell>75</Cell></Row>
  <Row><Cell>Tool C</Cell><Cell>$19.99</Cell><Cell>200</Cell></Row>
  <Row><Cell>Device D</Cell><Cell>$99.99</Cell><Cell>25</Cell></Row>
</Table>

<Tip>
Klicken Sie einmal auf eine Spaltenüberschrift, um aufsteigend zu sortieren, ein zweites Mal für absteigend und ein drittes Mal, um zurückzusetzen. Zahlen werden numerisch sortiert, Text alphabetisch.
</Tip>

Kombinieren Sie `sortable` mit anderen Props wie `striped`:

```mdx
<Table sortable striped>
  <Row header>
    <Cell>Team</Cell>
    <Cell>Wins</Cell>
    <Cell>Losses</Cell>
  </Row>
  <Row><Cell>Eagles</Cell><Cell>12</Cell><Cell>4</Cell></Row>
  <Row><Cell>Bears</Cell><Cell>8</Cell><Cell>8</Cell></Row>
  <Row><Cell>Lions</Cell><Cell>10</Cell><Cell>6</Cell></Row>
</Table>
```

## Eigenschaften

### Table

| Prop | Type | Default | Description |
|------|------|---------|-------------|
| `striped` | boolean | false | Abwechselnde Zeilenhintergründe |
| `bordered` | boolean | false | Rahmen zwischen allen Zellen |
| `compact` | boolean | false | Reduziertes Zellen-Padding |
| `fullWidth` | boolean | true | Tabelle erstreckt sich über die volle Breite |
| `caption` | string | - | Tabellenbeschriftung |
| `captionVisible` | boolean | false | Beschriftung visuell anzeigen (Standard: nur für Screenreader) |
| `stickyHeader` | boolean | false | Kopfzeile beim Scrollen sichtbar halten |
| `sortable` | boolean | false | Klick-zum-Sortieren auf Spaltenüberschriften aktivieren |

### Row

| Prop | Type | Default | Description |
|------|------|---------|-------------|
| `header` | boolean | false | Als Kopfzeile darstellen |
| `highlight` | boolean | false | Zeile hervorheben |
| `highlightColor` | string | primary | Farbe: primary, success, warning, error, info |

### Cell

| Prop | Type | Default | Description |
|------|------|---------|-------------|
| `align` | string | left | Textausrichtung: left, center, right |
| `colSpan` | number | - | Anzahl zu überspannender Spalten |
| `rowSpan` | number | - | Anzahl zu überspannender Zeilen |
| `highlight` | boolean | false | Zelle hervorheben |
| `highlightColor` | string | primary | Farbe: primary, success, warning, error, info |
| `header` | boolean | false | Kopfzeilen-Styling erzwingen |
