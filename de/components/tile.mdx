Kacheln zeigen bildorientierte Vorschauen mit gemusterten Hintergründen. Verwenden Sie sie statt Cards, wenn ein Screenshot oder Logo wichtiger ist als Text: auf Integrationsseiten, in Vorlagengalerien und auf bildlastigen Seiten.

Die Screenshots zeigen die Benutzeroberfläche auf Englisch.

Verwenden Sie Kacheln, wenn:
- **Visuelle Vorschauen** wichtiger sind als Textbeschreibungen
- **Integrationen präsentiert** werden sollen, etwa mit Logos oder Screenshots
- **Galerien** mit Vorlagen, Themes oder Beispielen erstellt werden
- **Screenshots angezeigt** werden sollen, mit Titeln und optionalen Beschreibungen

## Verwendung

```mdx
<Tile href="/components/tabs" title="Tabs Component">

</Tile>
```

## Kachel vs. Karte

| Merkmal | Tile | Card |
|---------|------|------|
| Visuelle Betonung | Bildorientiert mit gemustertem Hintergrund | Icon + Titel + Beschreibung |
| Geeignet für | Integrationen, Vorlagen, Galerien | Navigation, Funktionslisten, CTAs |
| Umgang mit Bildern | Großer Vorschaubereich | Kleines Icon |
| Textinhalt | Titel + optionale Beschreibung | Titel + Beschreibung + Icon |

**Faustregel:** Verwenden Sie Tile für einen Screenshot oder ein Logo. Verwenden Sie Card für textlastige Inhalte.

## Bilder im Dark Mode

Verwenden Sie Tailwind-Klassen, um im hellen und dunklen Modus unterschiedliche Bilder anzuzeigen:

```mdx
<Tile href="/customization/theming" title="Theming">
  <img src="/images/logo-light.webp" alt="Theme" class="dark:hidden" noStyle />
  <img src="/images/logo-dark.webp" alt="Theme" class="hidden dark:block" noStyle />
</Tile>
```

Das Attribut `noStyle` deaktiviert die standardmäßige Bildformatierung. Ohne dieses Attribut funktionieren die Klassen für den Dark Mode nicht korrekt.

## Eigenschaften

<ParamField name="href" type="string" required>
  Die URL, auf die die Kachel verweist. Akzeptiert interne Pfade (`/docs/intro`) oder externe URLs (`https://example.com`). Externe Links werden in einem neuen Tab geöffnet.
</ParamField>

<ParamField name="title" type="string">
  Titel, der unter dem Vorschaubereich angezeigt wird.
</ParamField>

<ParamField name="description" type="string">
  Optionale Beschreibung, die unter dem Titel angezeigt wird.
</ParamField>

<ParamField name="children" type="ReactNode">
  Inhalt, der im Vorschaubereich angezeigt wird. In der Regel Bilder oder SVGs.
</ParamField>
