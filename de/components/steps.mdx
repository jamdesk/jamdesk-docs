Verwenden Sie Steps für nummerierte Anleitungen wie Einrichtungs- und Fehlerbehebungsabläufe.

## Verwendung

```mdx
<Steps>
  <Step title="Install">Add the package.</Step>
  <Step title="Configure">Set your options.</Step>
  <Step title="Run">Start the build.</Step>
</Steps>
```

## Grundlegende Steps

<Steps>
  <Step title="Das Paket installieren">
    ```bash
    npm install @jamdesk/cli
    ```
  </Step>
  <Step title="Ihr Projekt initialisieren">
    ```bash
    jamdesk init
    ```
  </Step>
  <Step title="Den Dev-Server starten">
    ```bash
    jamdesk dev
    ```
  </Step>
</Steps>

````mdx
<Steps>
  <Step title="Install the package">
    ```bash
    npm install @jamdesk/cli
    ```
  </Step>
  <Step title="Initialize your project">
    ```bash
    jamdesk init
    ```
  </Step>
  <Step title="Start the dev server">
    ```bash
    jamdesk dev
    ```
  </Step>
</Steps>
````

## Umfangreiche Inhalte in Steps

Jeder Schritt kann beliebige Inhalte enthalten:

<Steps>
  <Step title="Ihre API konfigurieren">
    Erstellen Sie eine Konfigurationsdatei:

    ```json config.json
    {
      "apiKey": "your-api-key",
      "endpoint": "https://api.example.com"
    }
    ```

    <Note>
    Halten Sie Ihren API-Schlüssel geheim! Committen Sie ihn niemals in die Versionsverwaltung.
    </Note>
  </Step>
  <Step title="Die erste Anfrage stellen">
    Verwenden Sie das SDK, um eine Anfrage zu stellen:

    ```javascript
    const response = await client.getData();
    console.log(response);
    ```
  </Step>
</Steps>

## Steps mit Symbolen

Ersetzen Sie die Nummern durch Icons:

<Steps>
  <Step title="Das Repository klonen" icon="code-branch">
    Von GitHub auf Ihren lokalen Rechner klonen.
  </Step>
  <Step title="Abhängigkeiten installieren" icon="download">
    Führen Sie den Installationsbefehl des Paketmanagers aus.
  </Step>
  <Step title="Mit der Entwicklung beginnen" icon="rocket">
    Starten Sie den Entwicklungsserver.
  </Step>
</Steps>

```mdx
<Steps>
  <Step title="Clone the repository" icon="code-branch">
    Clone from GitHub to your local machine.
  </Step>
  <Step title="Install dependencies" icon="download">
    Run the package manager install command.
  </Step>
  <Step title="Start developing" icon="rocket">
    Launch the development server.
  </Step>
</Steps>
```

## Titelgröße

Steuern Sie die Überschriftenhierarchie mit `titleSize` am Steps-Container:

<Steps titleSize="h3">
  <Step title="Erster Schritt">
    Dieser Titel wird als h3-Element dargestellt.
  </Step>
  <Step title="Zweiter Schritt">
    Nützlich für SEO und Dokumentstruktur.
  </Step>
</Steps>

```mdx
<Steps titleSize="h3">
  <Step title="First Step">
    This title renders as an h3 element.
  </Step>
  <Step title="Second Step">
    Useful for SEO and document structure.
  </Step>
</Steps>
```

## Props

### Steps

<ParamField name="titleSize" type="p | h2 | h3" default="p">
  Überschriftenelement für Schritttitel.
</ParamField>

### Step

<ParamField name="title" type="string">
  Optionaler Schritttitel.
</ParamField>

<ParamField name="icon" type="string">
  Icon-Name, URL oder Pfad (ersetzt die Schrittnummer).
</ParamField>

<ParamField name="iconType" type="solid | regular | light | thin | sharp-solid | duotone | brands" default="solid">
  Font-Awesome-Icon-Stil.
</ParamField>

<ParamField name="titleSize" type="p | h2 | h3">
  Überschreibt das titleSize des übergeordneten Steps. Wird vom übergeordneten Element übernommen, wenn nicht gesetzt.
</ParamField>

<ParamField name="stepNumber" type="number">
  Schrittnummer manuell festlegen (wird automatisch vergeben, wenn weggelassen).
</ParamField>
