Verwenden Sie Tabs für parallele Alternativen: Paketmanager, Programmiersprachen oder betriebssystemspezifische Anleitungen. Leser wählen einmal aus und bleiben im Kontext. Gleichnamige Tab-Titel werden auf der Seite synchronisiert. Wenn Sie in einer Gruppe „yarn“ auswählen, wechseln alle anderen npm/yarn/pnpm-Gruppen entsprechend.

Verwenden Sie Tabs, wenn:
- **mehrere Umsetzungen** desselben Konzepts existieren (npm/yarn/pnpm, JavaScript/Python)
- **parallele Optionen** sich gegenseitig ausschließen (der Leser wählt eine aus)
- **Konsistenz wichtig ist**: Die Auswahl des Lesers sollte auf der gesamten Seite erhalten bleiben

## Verwendung

```mdx
<Tabs>
  <Tab title="npm">npm install jamdesk</Tab>
  <Tab title="pnpm">pnpm add jamdesk</Tab>
</Tabs>
```

## Tabs vs. CodeGroup vs. Accordion

| Komponente | Geeignet für | Synchronisiert |
|-----------|----------|--------------|
| **Tabs** | Sich gegenseitig ausschließende Inhaltsauswahl | Ja (seitenübergreifend) |
| **CodeGroup** | Codeblöcke in mehreren Sprachen | Nein |
| **Accordion** | Einklappbare Abschnitte, FAQs | Nein |

**Faustregel:** Verwenden Sie Tabs, wenn die Auswahl des Lesers (etwa der bevorzugte Paketmanager) auf der gesamten Seite erhalten bleiben soll. Verwenden Sie CodeGroup für reine Code-Vergleiche. Verwenden Sie Accordion für Inhalte, die alle relevant sein können.

## Unterer Rand

Verwenden Sie die Prop `borderBottom`, um unterhalb des Tab-Inhalts eine visuelle Trennlinie hinzuzufügen:

<Tabs borderBottom>
  <Tab title="Overview">

  </Tab>
  <Tab title="Details">
    Useful when tabs contain varying content lengths.
  </Tab>

## Synchronisierte Tabs

Tabs mit gleichnamigen Titeln werden auf der gesamten Seite synchronisiert. Klicken Sie in einer Gruppe auf „yarn“, und alle npm/yarn/pnpm-Gruppen auf der Seite wechseln mit:

**Installieren:**

<Tabs>
  <Tab title="npm">
    ```bash
    npm install my-package
    ```
  </Tab>
  <Tab title="yarn">
    ```bash
    yarn add my-package
    ```
  </Tab>
</Tabs>

**Ausführen:**

<Tabs>
  <Tab title="npm">
    ```bash
    npm run dev
    ```
  </Tab>
  <Tab title="yarn">
    ```bash
    yarn dev
    ```
  </Tab>
</Tabs>

Die Synchronisierung erfolgt, wenn Tab-Titel übereinstimmen (Groß-/Kleinschreibung wird nicht beachtet).

## Eigenschaften

### Tabs

<ParamField name="borderBottom" type="boolean" default="false">
  Fügt dem Container des Tab-Inhalts einen unteren Rahmen und Innenabstand hinzu. Verwenden Sie dies, um getabbten Inhalt vom Rest der Seite abzugrenzen.
</ParamField>

### Tab

<ParamField name="title" type="string" required>
  Die in der Tab-Leiste angezeigte Beschriftung. Tabs mit gleichnamigen Titeln synchronisieren ihre Auswahl auf der gesamten Seite.
</ParamField>

<ParamField name="icon" type="string">
  Name des Font-Awesome-Icons, das vor dem Titel angezeigt wird (z. B. „react“, „code“, „terminal“).
</ParamField>

<ParamField name="iconType" type="string" default="solid">
  Font-Awesome-Icon-Stil. Optionen: `regular`, `solid`, `light`, `thin`, `sharp-solid`, `duotone`, `brands`.
</ParamField>
