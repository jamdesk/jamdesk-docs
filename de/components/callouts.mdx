Verwenden Sie Hinweisboxen, um wichtige Kontextinformationen wie Warnungen, Tipps oder Voraussetzungen hervorzuheben, ohne den Lesefluss zu unterbrechen.

## Verfügbare Callouts

<Note>
**Note**: Hilfreicher Kontext oder zusätzliche Informationen.
</Note>

<Info>
**Info**: Neutrale Informationen oder Fakten. Für ergänzende Details verwenden.
</Info>

<Tip>
**Tip**: Empfohlene Vorgehensweisen oder Optimierungen.
</Tip>

<Warning>
**Warning**: Wichtige Einschränkungen oder Voraussetzungen. Verwenden Sie diese Box, wenn das Ignorieren eines Hinweises Probleme verursachen könnte.
</Warning>

<Danger>
**Danger**: Kritische Warnungen. Verwenden Sie diese Box für Aktionen, die zu Datenverlust oder Sicherheitsproblemen führen könnten.
</Danger>

<Check>
**Check**: Erfolgsbestätigungen. Verwenden Sie diese Box, um korrektes Verhalten oder einen erfolgreichen Abschluss zu bestätigen.
</Check>

## Verwendung

```mdx
<Note>
This is helpful context for the reader.
</Note>

<Warning>
This could cause issues if you skip this step.
</Warning>

<Danger>
This action cannot be undone. Proceed with caution.
</Danger>
```

## Mit Titeln

Fügen Sie jeder Hinweisbox einen eigenen Titel hinzu:

```mdx
<Note title="Did you know?">
You can use **Markdown** inside callouts, including `code` and [links](/introduction).
</Note>
```

<Note title="Did you know?">
You can use **Markdown** inside callouts, including `code` and [links](/de/components/card).
</Note>

## Mit Codeblöcken

Hinweisboxen können Code enthalten:

<Warning title="Breaking Change in v2.0">
The `getData()` function signature changed:

```javascript
// Before (v1.x)
getData(id)

// After (v2.0)
getData({ id, options })
```
</Warning>

## Best Practices

<AccordionGroup>
  <Accordion title="Sparsam einsetzen" icon="hand" defaultOpen>
    Zu viele Hinweisboxen verwässern ihre Wirkung. Streben Sie maximal 1–2 pro Seite an.

    Reservieren Sie Hinweisboxen für Informationen, die der Leser nicht übersehen darf.
  </Accordion>

  <Accordion title="Den richtigen Typ wählen" icon="list-check">
    | Scenario | Callout |
    |----------|---------|
    | Helpful tip | `<Tip>` |
    | Extra context | `<Note>` or `<Info>` |
    | Potential gotcha | `<Warning>` |
    | Irreversible action | `<Danger>` |
    | Confirmation | `<Check>` |
    | Custom branding | `<Callout>` |
  </Accordion>

  <Accordion title="Kurz halten" icon="text-width">
    Halten Sie Hinweisboxen überschaubar. Verwenden Sie ein Accordion für mehrere Absätze.

    **Gut:** Ein bis zwei Sätze
    **Vermeiden:** Mehrere Absätze Text
  </Accordion>

  <Accordion title="Strategisch platzieren" icon="arrows-up-down">
    Platzieren Sie Hinweisboxen:
    - **Vor** Code mit Voraussetzungen
    - **Nach** Anleitungen mit wichtigen Einschränkungen
    - **Nahe** dem Inhalt, auf den sie sich beziehen
  </Accordion>
</AccordionGroup>

## Props

Jede Hinweisbox akzeptiert diese Props:

<ParamField name="title" type="string">
  Eigener Titel (ersetzt den Standardtitel).
</ParamField>

## Barrierefreiheit

Hinweisboxen verwenden semantisches HTML und ARIA-Rollen:
- Screenreader kündigen den Typ der Hinweisbox an
- Farbe ist nicht das einzige Unterscheidungsmerkmal (Icons sind enthalten)
- Ausreichender Farbkontrast im Dunkelmodus

## Benutzerdefinierter Callout

Legen Sie mit der Komponente `Callout` ein eigenes Icon und eine eigene Farbe fest:

<Callout icon="key" color="#FFC107">
**Custom**: Use any icon and color to match your content.
</Callout>

<Callout icon="rocket" color="#9333EA">
Deploy your changes with confidence using our CI/CD pipeline.
</Callout>

<Callout icon="regular/star" color="#EC4899">
Use icon style prefixes like `regular/`, `light/`, or `duotone/` for different weights.
</Callout>

### Verwendung benutzerdefinierter Callouts

```mdx
<Callout icon="key" color="#FFC107">
  This callout uses a key icon with amber color.
</Callout>

<Callout icon="rocket" color="#9333EA">
  This callout uses a rocket icon with purple color.
</Callout>

<Callout icon="regular/star" color="#EC4899">
  Use style prefixes for different icon weights.
</Callout>
```

### Props benutzerdefinierter Callouts

<ParamField name="icon" type="string" default="circle-info">
  Icon-Name (siehe [Icons](/de/content/icons)).
</ParamField>

<ParamField name="color" type="string">
  Hex-Farbcode (z. B. `#FFC107`). Standardmäßig die Akzentfarbe.
</ParamField>

**Icon-Stilpräfixe:** Fügen Sie ein Präfix hinzu, um die Strichstärke des Icons zu ändern:
- `solid/` - Gefüllte Icons (Standard)
- `regular/` - Umrissene Icons
- `light/` - Dünn umrissene Icons
- `duotone/` - Zweifarbige Icons
