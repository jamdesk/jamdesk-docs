Mit Panel können Sie benutzerdefinierte Inhalte in der rechten Seitenleiste anstelle des standardmäßigen Inhaltsverzeichnisses anzeigen. Die Inhalte bleiben sichtbar, während Leser durch Ihre Seite scrollen. Verwenden Sie Panel für Informationen, die immer sichtbar sein sollen: Kurzhinweise, wichtige Warnungen oder Support-Links.

Verwenden Sie Panel, wenn:
- **Kritische Informationen** nicht aus dem Sichtfeld verschwinden sollen
- **Kurzhinweise** den Hauptinhalt ergänzen
- **Dauerhafte Handlungsaufforderungen** sichtbar bleiben müssen (Support-Links, API-Schlüssel)

## Grundlegende Verwendung

Umschließen Sie beliebige Inhalte mit Panel, damit sie in der rechten Seitenleiste angezeigt werden:

```mdx
<Panel>
  <Info>This content appears in the sidebar!</Info>
</Panel>
```

## Häufige Anwendungsfälle

Panels eignen sich gut für angeheftete Warnungen, Kurzhinweiskarten und Support-Links:

```mdx
<Panel>
  <Warning>
    API rate limits: 100 requests/minute
  </Warning>
  <Card title="Quick Reference" icon="list">
    **Methods:** GET, POST, PUT, DELETE
    **Auth:** Bearer token required
  </Card>
  <Card title="Need Help?" icon="circle-question" href="https://example.com/support">
    Contact our support team
  </Card>
</Panel>
```

## Wann Sie Panel NICHT verwenden sollten

- **Kurze Seiten** – Das Inhaltsverzeichnis hilft Benutzern bei der Navigation. Ersetzen Sie es nur, wenn Sie wertvollere Inhalte anbieten
- **Standarddokumentation** – Die meisten Seiten funktionieren besser mit dem standardmäßigen Inhaltsverzeichnis
- **Benutzer auf Mobilgeräten** – Panel-Inhalte werden auf kleineren Bildschirmen ausgeblendet. Stellen Sie daher sicher, dass kritische Informationen auch im Hauptinhalt enthalten sind

## Verhalten

- Wird auf Desktop-Geräten in der rechten Seitenleiste angezeigt (1280 px+), auf kleineren Bildschirmen ausgeblendet
- Ein Panel pro Seite; ersetzt das Inhaltsverzeichnis vollständig
- Unterstützt beliebige Komponenten: Callouts, Cards, CodeGroup, Accordions usw.
