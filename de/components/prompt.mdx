title: Prompt
description: Verwenden Sie Prompt, um wiederverwendbare KI-Anweisungen mit Kopieren-Funktion, integrierten Öffnen-in-Aktionen, benutzerdefinierten Zielen, Symbolen und kompakten Anzeigeoptionen darzustellen.
---

Die Komponente `<Prompt>` macht einen wiederverwendbaren Satz von Anweisungen zu einer Karte, die Leser kopieren oder in einem unterstützten KI-Tool öffnen können. Kopieren- und Öffnen-in-Aktionen verwenden den exakten, für Menschen sichtbaren Inhalt zwischen den Tags.

## Grundlegende Verwendung

Jeder Prompt hat eine Kopieren-Aktion. Die einfachste Variante benötigt keine Props:

<Prompt>
Erkläre, wie die Rotation von API-Schlüsseln funktioniert, für einen Entwickler, der unsere REST-API zum ersten Mal verwendet.
</Prompt>

```mdx
<Prompt>
Explain how API key rotation works for a developer using our REST API for the first time.
</Prompt>
```

## Titel und Beschreibung

Verwenden Sie `title`, um die Aufgabe zu benennen. Das mit Mintlify kompatible Prop `description` ersetzt die sichtbare Vorschau durch eine kürzere Zusammenfassung. Kopieren- und Öffnen-in-Aktionen verwenden weiterhin den vollständigen, für Menschen sichtbaren Inhalt zwischen den Tags.

<Prompt
  title="Eine Release-Notiz entwerfen"
  description="Schreibe eine prägnante Release-Notiz für eine Entwicklerzielgruppe."
  actions={["copy", "claude"]}
>
Schreibe eine Release-Notiz für den neuen Endpunkt zur Rotation von API-Schlüsseln.

- Richte dich an Backend-Entwickler.
- Beginne mit dem Nutzen für den Anwender.
- Füge ein Anfragebeispiel hinzu.
</Prompt>

```mdx
<Prompt
  title="Draft a release note"
  description="Write a concise release note for a developer audience."
  actions={["copy", "claude"]}
>
Write a release note for the new API key rotation endpoint.

- Address backend developers.
- Lead with the user benefit.
- Include one request example.
</Prompt>
```

Kopieren ist immer vorhanden. Eine explizite Aktion `"copy"` wird aus Kompatibilitätsgründen akzeptiert, ist aber nie nötig.

<Note>
  Prompt kopiert den exakten, für Menschen sichtbaren Inhalt. In einem Prompt, der [Visibility](/de/components/visibility) enthält, entfernt Jamdesk nur für Menschen bestimmte Wrapper-Tags aus dem kopierten Text und behält deren Inhalte bei. Teilbäume nur für Agenten werden ausgeschlossen. Jamdesk schließt außerdem Visibility mit einem ausdrucksbasierten `for`-Prop aus oder mit einer Zielgruppe, die durch ein späteres Spread-Attribut verborgen wird. Diese Zielgruppe kann nicht statisch bestimmt werden. Visibility ohne `for`-Prop, mit Kurzschreibweise für `for` oder mit einer ungültigen wörtlichen Zielgruppe bleibt sichtbar. Ein Prompt, der innerhalb von nur für Agenten bestimmter oder durch Ausdruck/Spread verdeckter Visibility versteckt ist, hat keine kopierbare Quelle.
</Note>

## Öffnen-in-Aktionen

Fügen Sie `claude`, `cursor`, `chatgpt`, `perplexity` oder `gemini` hinzu, damit Leser den Prompt in diesen Tools öffnen können. Jede Aktion zeigt ihr Marken-Symbol. Die erste gültige Öffnen-in-Aktion erscheint neben Kopieren. Die übrigen erscheinen im Menü „Mehr“.

<Prompt
  title="Authentifizierungsabläufe vergleichen"
  actions={["claude", "cursor", "chatgpt", "perplexity", "gemini"]}
>
Vergleiche die Abläufe für Session-Token und API-Schlüssel-Authentifizierung in diesem Repository. Nenne ihre Sicherheitsabwägungen und empfiehl, welchen Ablauf jeder Client-Typ verwenden sollte.
</Prompt>

```mdx
<Prompt
  title="Compare authentication flows"
  actions={["claude", "cursor", "chatgpt", "perplexity", "gemini"]}
>
Compare the session-token and API-key authentication flows in this repository.
List their security tradeoffs and recommend which flow each client type should use.
</Prompt>
```

<Warning>
  Ein Klick auf eine Öffnen-in-Aktion sendet den vollständigen kopierbaren Prompt an den ausgewählten Drittanbieter. Fügen Sie keine Geheimnisse, personenbezogenen Daten oder proprietären Inhalte ein, es sei denn, Sie möchten sie unter der Datenschutzrichtlinie dieses Anbieters teilen. Kopieren öffnet keinen Drittanbieter-Dienst.
</Warning>

## Benutzerdefinierte URL-Aktionen

Benutzerdefinierte Aktionen erhalten ein `label`, eine HTTPS- oder HTTP-`url` und ein optionales Symbol. Platzieren Sie `{prompt}` in einem Pfadsegment, einem Query-Wert oder einem Fragment, um zu steuern, wohin der URL-kodierte Prompt geht. Wenn Sie den Platzhalter weglassen, fügt Jamdesk einen Query-Parameter `prompt` hinzu.

<Prompt
  title="Diese Migration recherchieren"
  actions={[
    {
      label: "Im Web suchen",
      url: "https://www.google.com/search?q={prompt}",
      icon: "magnifying-glass",
    },
    "claude",
  ]}
>
Vergleiche diesen Migrationsplan mit dem aktuellen öffentlichen API-Vertrag. Identifiziere Breaking Changes, fehlende Rollback-Schritte und die Tests, die vor dem Release nötig sind.
</Prompt>

```mdx
<Prompt
  title="Research this migration"
  actions={[
    {
      label: "Search the web",
      url: "https://www.google.com/search?q={prompt}",
      icon: "magnifying-glass",
    },
    "claude",
  ]}
>
Compare this migration plan with the current public API contract. Identify
breaking changes, missing rollback steps, and tests needed before release.
</Prompt>
```

Benutzerdefinierte Aktions-URLs müssen `http:`- oder `https:`-URLs ohne Zugangsdaten sein. Jamdesk lehnt andere Schemata, Platzhalter in Ursprüngen oder Query-Schlüsseln und endgültige Aktions-URLs ab, die länger als 8.000 Zeichen sind. Kopieren bleibt verfügbar, wenn eine Öffnen-in-Aktion abgelehnt wird.

## Benutzerdefiniertes Symbol

Setzen Sie `icon` auf einen Font-Awesome-Namen, eine Bild-URL oder einen Bildpfad oder inline SVG. Verwenden Sie `iconType`, um den Stil für einen Font-Awesome-Namen ohne Präfix auszuwählen.

<Prompt title="Ein Tutorial planen" icon="pen-nib" iconType="duotone">
Skizziere ein praxisnahes Tutorial, das einen neuen Nutzer von der Installation bis zu einer erfolgreichen API-Anfrage in unter zehn Minuten führt.
</Prompt>

```mdx
<Prompt title="Plan a tutorial" icon="pen-nib" iconType="duotone">
  Outline a hands-on tutorial that gets a new user from installation to a
  successful API request in under ten minutes.
</Prompt>
```

Verfügbare Namen und Stile finden Sie unter [Symbole](/de/content/icons).

## Kompakte Darstellungen

Die Vorschau zeigt bis zu drei Zeilen und scrollt bei einem längeren Prompt. Die Schaltfläche Erweitern öffnet den vollständigen Prompt. Setzen Sie `singleLine`, um die Vorschau auf eine Zeile zu kürzen. Kopieren- und Öffnen-in-Aktionen verwenden weiterhin den vollständigen, für Menschen sichtbaren Prompt.

<Prompt title="Die API zusammenfassen">
Fasse die öffentliche API in fünf Stichpunkten zusammen:

- Authentifizierung und Lebensdauer der Token.
- Konventionen für die Paginierung.
- Ratenbegrenzungen und Hinweise zum Wiederholen.
- Fehlerformat und häufige Codes.
- Versionierung und Richtlinie zur Abkündigung.
</Prompt>

Verwenden Sie `hidePrompt` mit einem Titel, wenn das Label allein den Lesern genug Kontext gibt:

<Prompt title="Eine Migrationscheckliste erstellen" hidePrompt actions={["claude"]}>
Erstelle eine Migrationscheckliste für den Wechsel von API v1 zu v2. Enthalte Voraussetzungen, Code-Änderungen, Validierungsschritte, Rollback-Kriterien und die Freigabe durch den Verantwortlichen.
</Prompt>

```mdx
<Prompt title="Summarize the API">
  Summarize the public API in five bullets:

  - Authentication and token lifetimes.
  - Pagination conventions.
  - Rate limits and retry guidance.
  - Error format and common codes.
  - Versioning and deprecation policy.
</Prompt>

<Prompt title="Generate a migration checklist" hidePrompt actions={["claude"]}>
  Create a migration checklist for moving from API v1 to v2. Include
  prerequisites, code changes, validation steps, and rollback criteria.
</Prompt>
```

`hidePrompt` blendet die Vorschau nur aus, wenn `title` gesetzt ist. Ohne Titel bleibt der Prompt sichtbar.

## Props

<ParamField name="children" type="ReactNode">
  Der Prompt-Inhalt zwischen öffnendem und schließendem Tag. Jamdesk bewahrt das exakte, für Menschen sichtbare, vom Autor geschriebene Markdown für Kopieren und Öffnen-in-Aktionen. Außerdem rendert es diesen Inhalt als Vorschau, sofern `description` die Vorschau nicht ersetzt oder `hidePrompt` sie nicht ausblendet. Die Filterung der Sichtbarkeit folgt den obigen Regeln.
</ParamField>

<ParamField name="title" type="string">
  Bezeichnung im Kartenkopf. Standardmäßig wird kein Titel angezeigt.
</ParamField>

<ParamField name="description" type="string">
  Kompakte Vorschau mit Inline-Markdown, akzeptiert zur Kompatibilität mit Mintlify. Sie verändert nur die sichtbare Vorschau. Kopieren- und Öffnen-in-Aktionen verwenden weiterhin den für Menschen sichtbaren Inhalt zwischen den Tags.
</ParamField>

<ParamField name="icon" type="string | ReactElement" default="sparkles">
  Symbol im Kopfbereich. Akzeptiert einen Font-Awesome-Namen, eine Bild-URL oder einen Bildpfad oder ein inline SVG-Element.
</ParamField>

<ParamField name="iconType" type="regular | solid | light | thin | sharp-solid | duotone | brands">
  Font-Awesome-Stil, der auf ein Zeichenketten-Symbol ohne Präfix angewendet wird. Er verändert keine Bild-URLs, Pfade, bereits präfixierten Namen oder inline SVG-Elemente.
</ParamField>

<ParamField name="actions" type="('copy' | 'cursor' | 'claude' | 'chatgpt' | 'perplexity' | 'gemini' | CustomAction)[]" default="[]">
  Öffnen-in-Aktionen in Anzeigereihenfolge. `CustomAction` ist `{ label: string; url: string; icon?: string }`. Kopieren wird immer angezeigt. Ein expliziter Eintrag `copy` wird akzeptiert und dedupliziert. Ungültige, doppelte oder zu große Öffnen-in-Aktionen werden weggelassen.
</ParamField>

<ParamField name="singleLine" type="boolean | string" default="false">
  Kürzt die sichtbare Vorschau auf eine Zeile, wenn auf den booleschen Wert `true` oder den String `"true"` gesetzt. Der String `"false"` deaktiviert dies. Jede Aktion verwendet weiterhin den vollständigen Prompt.
</ParamField>

<ParamField name="hidePrompt" type="boolean | string" default="false">
  Blendet die sichtbare Vorschau aus, wenn ein Titel vorhanden ist und der Wert der boolesche Wert `true` oder der String `"true"` ist. Ohne Titel bleibt die Vorschau sichtbar. Der String `"false"` deaktiviert dies.
</ParamField>

<ParamField name="className" type="string">
  Zusätzliche CSS-Klassennamen, die auf das Root-Element der Prompt-Karte angewendet werden.
</ParamField>
