Füge Hinweistexte hinzu, um Begriffe zu erklären, Abkürzungen aufzulösen oder auf verwandte Seiten zu verlinken, ohne den Hauptinhalt zu überladen.

Verwende Tooltips, wenn du:
- **Begriffe definierst**, ohne den Lesefluss zu unterbrechen
- **Abkürzungen erklärst**, die manche Leser möglicherweise nicht kennen
- **Kontext bereitstellst**, der hilfreich, aber nicht unverzichtbar ist
- **Auf verwandte Inhalte verlinkst** mit einem Call-to-Action

## Einfacher Tooltip

Fahre mit der Maus über <Tooltip tip="Eine Gruppe von Protokollen, über die Softwareanwendungen miteinander kommunizieren.">API</Tooltip>, um die Definition zu sehen.

```jsx
<Tooltip tip="A set of protocols for software applications to communicate.">
  API
</Tooltip>
```

## Mit Überschrift

Füge eine Überschrift über dem Tipp-Text hinzu:

Fahre mit der Maus über <Tooltip headline="API" tip="Application Programming Interface: eine Gruppe von Protokollen, über die Softwareanwendungen miteinander kommunizieren.">API</Tooltip>, um die Definition mit Überschrift zu sehen.

```jsx
<Tooltip
  headline="API"
  tip="Application Programming Interface: a set of protocols for software applications to communicate."
>
  API
</Tooltip>
```

## Mit Link für eine Handlungsaufforderung

Füge einen Link zu weiteren Details hinzu:

Erfahre mehr über <Tooltip headline="API" tip="Application Programming Interface: eine Gruppe von Protokollen, über die Softwareanwendungen miteinander kommunizieren." cta="Mehr erfahren" href="/de/components/overview">APIs</Tooltip> in unserer Dokumentation.

```jsx
<Tooltip
  headline="API"
  tip="Application Programming Interface: a set of protocols..."
  cta="Learn more"
  href="/components/overview"
>
  API
</Tooltip>
```

## Inline-Verwendung

Tooltips funktionieren inline im Text. Du kannst Begriffe wie <Tooltip tip="HyperText Markup Language">HTML</Tooltip>, <Tooltip tip="Cascading Style Sheets">CSS</Tooltip> oder <Tooltip tip="JavaScript">JS</Tooltip> direkt im Text erklären.

```jsx
Explain <Tooltip tip="HyperText Markup Language">HTML</Tooltip>,
<Tooltip tip="Cascading Style Sheets">CSS</Tooltip>, or
<Tooltip tip="JavaScript">JS</Tooltip> terms inline.
```

## Tooltips im Vergleich zu anderen Komponenten

| Bedarf | Komponente |
|------|-----------|
| Einen Begriff inline definieren | **Tooltip** |
| Ein Konzept ausführlich erklären | Expandable oder separater Abschnitt |
| Vor etwas Wichtigem warnen | Callout (Note, Warning) |
| Kontextbezogenen Code zeigen | CodeGroup oder Inline-Code |

**Faustregel:** Tooltips eignen sich für schnelle Definitionen (1–2 Sätze). Längere Erklärungen gehören in den Hauptinhalt oder in ein Expandable.

## Props

<ParamField name="tip" type="string" required>
  Der Tooltip-Text, der beim Überfahren angezeigt wird.
</ParamField>

<ParamField name="headline" type="string">
  Text, der über dem Tipp angezeigt wird.
</ParamField>

<ParamField name="cta" type="string">
  Text des Call-to-Action-Links.
</ParamField>

<ParamField name="href" type="string">
  URL für den Call-to-Action (erforderlich mit `cta`).
</ParamField>

<ParamField name="children" type="ReactNode">
  Der Text, der den Tooltip auslöst.
</ParamField>

## Barrierefreiheit

- Tooltips sind per Tastatur bedienbar (Tab zum Fokussieren, wird bei Fokus angezeigt)
- Verwendet `role="tooltip"` für Screenreader
- Der Auslösetext ist gestrichelt unterstrichen, um die Interaktivität anzuzeigen
