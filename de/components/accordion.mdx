---
title: Akkordeon
description: Einklappbare Inhaltsabschnitte, die Leser für Details aufklappen. Geeignet für FAQs, Funktionslisten und Konfigurationsoptionen.
---

Akkordeons sind einklappbare Abschnitte. Leser sehen die Überschrift und klappen sie auf, um Details zu erhalten. Ein Akkordeon kann ein Icon und eine Beschreibung haben. Außerdem lassen sich Akkordeons gruppieren.

Verwende Akkordeons, wenn:
- **FAQs**: Leser Fragen überfliegen und die Antworten aufklappen
- **Funktionslisten**: jede Funktion erhält einen Abschnitt mit Details
- **Konfigurationsoptionen**: Einstellungen nach Kategorie gruppieren
- **Schritt-für-Schritt-Anleitungen** mit aufklappbaren Details

## Verwendung

```mdx
<Accordion title="Advanced Configuration">
  Optional details go here.
</Accordion>
```

## Einfaches Accordion

<Accordion title="Zum Aufklappen klicken">
  Dieser Inhalt ist verborgen, bis das Akkordeon aufgeklappt wird.

  Hier kann jeder Inhalt stehen: Text, Code, Bilder oder andere Komponenten.
</Accordion>

```mdx
<Accordion title="Click to expand">
  This content is hidden until the accordion is expanded.

  You can include any content here: text, code, images, or other components.
</Accordion>
```

## Mit Beschreibung

Füge mit der Prop `description` einen Untertitel hinzu:

<Accordion title="API Reference" description="Authentication endpoints">
  Dokumentation für Authentifizierungs-API-Endpunkte steht hier.
</Accordion>

```mdx
<Accordion title="API Reference" description="Authentication endpoints">
  Documentation for authentication API endpoints goes here.
</Accordion>
```

## Standardmäßig geöffnet

Mit `defaultOpen` startet das Akkordeon aufgeklappt:

<Accordion title="Already Expanded" defaultOpen>
  Dieses Akkordeon startet im geöffneten Zustand.
</Accordion>

```mdx
<Accordion title="Already Expanded" defaultOpen>
  This accordion starts in the open state.
</Accordion>
```

## Mit Icon

<Accordion title="Settings" icon="gear">
  Konfigurationsoptionen und Einstellungen.
</Accordion>

```mdx
<Accordion title="Settings" icon="gear">
  Configuration options and settings.
</Accordion>
```

## Accordion oder Expandable

| Feature | Accordion | Expandable |
|---------|-----------|------------|
| Icons | Yes | No |
| Descriptions | Yes (subtitle) | No |
| Grouping | AccordionGroup | Standalone |
| Visual weight | Heavier, section-like | Lighter, inline |
| Best for | FAQs, feature lists | Supplementary content |

**Faustregel:** Verwende Accordion, wenn die Abschnitte gleich wichtig sind und Leser zwischen ihnen wählen. Verwende Expandable für „nice to have“-Details, die keine visuelle Hervorhebung brauchen.

## Eigenschaften

<ParamField name="title" type="string" required>
  Text der Akkordeon-Überschrift.
</ParamField>

<ParamField name="description" type="string">
  Untertitel unterhalb des Titels.
</ParamField>

<ParamField name="icon" type="string">
  Font-Awesome-Icon-Name (z. B. "gear", "settings").
</ParamField>

<ParamField name="iconType" type="string" default="light">
  Icon-Stilvariante: light, regular oder solid.
</ParamField>

<ParamField name="defaultOpen" type="boolean" default="false">
  Startet im aufgeklappten Zustand.
</ParamField>
