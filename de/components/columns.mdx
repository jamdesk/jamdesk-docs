Columns ordnet Inhalte in einem responsiven Raster nebeneinander an. Auf Mobilgeräten stapelt sich das Raster, auf Desktops wird es erweitert.

Die Screenshots zeigen die Benutzeroberfläche auf Englisch.

Füge Cards, Tiles, Bilder oder eigene Komponenten ein.


## Spaltenanzahl auswählen

| Inhaltstyp | Empfohlene Spalten |
|--------------|---------------------|
| Tiles mit Bildern | 2–3 |
| Textlastige Elemente | 2 |
| Kleine Kennzahlen/Statistiken | 3–4 |
| Bildvergleiche | 2 |

## Responsives Verhalten

Die Spaltenanzahl ändert sich je nach Bildschirmbreite:
- **Mobilgeräte** (< 768px): 1 Spalte
- **Tablet** (768px - 1024px): maximal 2 Spalten
- **Desktop** (> 1024px): volle Spaltenanzahl

## Props

<ParamField name="cols" type="number" default="2">
  Anzahl der Spalten pro Zeile. Zulässige Werte: 1 bis 4.
</ParamField>
