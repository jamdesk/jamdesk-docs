Sie pushen zu GitHub (oder führen `jamdesk deploy` aus), Jamdesk erstellt die Website, und die Änderungen werden live geschaltet. Das ist der gesamte Ablauf. Die Seiten in diesem Abschnitt behandeln jeden Teil davon: die CLI für den täglichen Einsatz, die Vorgänge während eines Builds, den Bereitstellungsort Ihrer Website und die Analytics, die Jamdesk auf jeder Seite ohne zusätzliche Skripte erfasst.

<Tip>
  **Schlägt der Build fehl?** [Build-Fehlerbehebung](/de/builds/troubleshooting) ordnet häufige Fehlermeldungen den Ursachen und Lösungen zu.
</Tip>
