Fügen Sie Google Analytics 4 zu Ihrer Dokumentationsseite hinzu, um zu sehen, wie Leser Ihre Inhalte nutzen.

<Info>
Die Integration akzeptiert GA4-Messungs-IDs (Google Analytics 4), die mit `G-` beginnen.
</Info>

## Mess-ID abrufen

1. Gehen Sie zu [Google Analytics](https://analytics.google.com/)
2. Wählen Sie Ihre Property aus (oder erstellen Sie eine)
3. Gehen Sie zu **Admin** → **Datenstreams**
4. Wählen Sie Ihren Web-Stream aus (oder erstellen Sie einen)
5. Kopieren Sie die **Messungs-ID** (beginnt mit `G-`)

## GA4 zu Ihrer Dokumentation hinzufügen

Fügen Sie die Messungs-ID zu Ihrer `docs.json` hinzu:

```json docs.json
{
  "name": "My Docs",
  "integrations": {
    "ga4": {
      "measurementId": "G-XXXXXXXXXX"
    }
  }
}
```

Ersetzen Sie `G-XXXXXXXXXX` durch Ihre Messungs-ID.

## Daten anzeigen

Prüfen Sie, ob Daten eintreffen:

1. Lösen Sie einen neuen Build Ihrer Dokumentation aus
2. Besuchen Sie Ihre live Dokumentationsseite
3. Gehen Sie in Google Analytics zu **Berichte** → **Echtzeit**
4. Ihr Besuch erscheint innerhalb von 30 Sekunden

<Note>
Es kann 24–48 Stunden dauern, bis Daten in den Standardberichten erscheinen. Verwenden Sie die Echtzeitberichte für eine sofortige Überprüfung.
</Note>

## Mit Google Tag Manager verwenden

Wenn Sie bereits den Google Tag Manager verwenden, konfigurieren Sie GA4 über den GTM, anstatt es direkt hinzuzufügen. Details finden Sie unter [Google Tag Manager-Integration](/de/integrations/google-tag-manager).

Richten Sie Cookie-Einwilligungsbanner selbst für alle Tags ein, die Sie über den Google Tag Manager laden. Jamdesk lädt Ihren GTM-Container für alle Besucher ohne Einwilligungssperre. Unter [Cookie-Einwilligung](/de/integrations/cookie-consent) erfahren Sie, wie Sie Analysen sperren, bis Besucher zustimmen.

<Warning>
Fügen Sie dieselbe GA4-Property nicht sowohl direkt in `docs.json` als auch über den Google Tag Manager hinzu. Das führt zu doppeltem Tracking.
</Warning>

## Datenschutzaspekte

Google Analytics erfasst Besucherdaten. Berücksichtigen Sie Folgendes:

- Fügen Sie ein Cookie-Einwilligungsbanner hinzu, falls DSGVO/CCPA gilt. Jamdesk lädt GA4 standardmäßig für jeden Besucher. [Cookie-Einwilligung](/de/integrations/cookie-consent) sperrt es, bis Besucher zustimmen.
- Aktualisieren Sie Ihre Datenschutzerklärung, um Analysen zu erwähnen
- Nutzen Sie bei Bedarf die [IP-Anonymisierung](https://support.google.com/analytics/answer/2763052)

## Fehlerbehebung

<Accordion title="Keine Daten sichtbar">
  1. **Überprüfen Sie Ihre Messungs-ID**: Sie muss mit `G-` beginnen
  2. **Prüfen Sie auf Werbeblocker**: Diese können Analyse-Skripte blockieren
  3. **Warten Sie auf den Rebuild**: Änderungen erfordern einen neuen Build
  4. **Verwenden Sie die Echtzeitberichte**: Standardberichte haben eine Verzögerung von 24–48 Stunden
</Accordion>

<Accordion title="Fehlermeldung „Invalid Measurement ID“">
  Die ID muss:
  - Mit `G-` beginnen
  - Nach `G-` nur Buchstaben und Ziffern enthalten
  - Exakt aus Google Analytics kopiert sein (ohne zusätzliche Leerzeichen)
</Accordion>
