Fügen Sie Google Analytics 4 zu Ihrer Dokumentationsseite hinzu, um zu verstehen, wie Benutzer mit Ihren Inhalten interagieren.

<Info>
Die Google-Analytics-Integration funktioniert mit GA4-Mess-IDs (Google Analytics 4), die mit `G-` beginnen.
</Info>

## Mess-ID abrufen

1. Gehen Sie zu [Google Analytics](https://analytics.google.com/)
2. Wählen Sie Ihre Property aus (oder erstellen Sie eine)
3. Gehen Sie zu **Admin** → **Data Streams**
4. Wählen Sie Ihren Web-Datenstream aus (oder erstellen Sie einen)
5. Kopieren Sie die **Measurement ID** (beginnt mit `G-`)

## GA4 zu Ihrer Dokumentation hinzufügen

Fügen Sie die Mess-ID zu Ihrer `docs.json` hinzu:

```json docs.json
{
  "name": "My Docs",
  "integrations": {
    "ga4": {
      "measurementId": "G-XXXXXXXXXX"
    }
  }
}
```

Ersetzen Sie `G-XXXXXXXXXX` durch Ihre tatsächliche Mess-ID.

## Daten anzeigen

Nach dem Hinzufügen der Integration:

1. Lösen Sie einen neuen Build Ihrer Dokumentation aus
2. Besuchen Sie Ihre Live-Dokumentationsseite
3. Gehen Sie in Google Analytics zu **Reports** → **Real-time**
4. Ihr Besuch sollte innerhalb von 30 Sekunden angezeigt werden

<Note>
Es kann 24–48 Stunden dauern, bis Daten in Standardberichten angezeigt werden. Verwenden Sie Echtzeitberichte zur sofortigen Überprüfung.
</Note>

## Mit Google Tag Manager verwenden

Wenn Sie Google Tag Manager bereits verwenden, können Sie GA4 über GTM konfigurieren, anstatt es direkt hinzuzufügen. Weitere Informationen finden Sie unter [Google-Tag-Manager-Integration](/de/integrations/google-tag-manager).

Sie sind dafür verantwortlich, Einwilligungsbanner für Cookies für alle Tags einzurichten, die Sie über Google Tag Manager laden, sofern Sie diese benötigen. Jamdesk lädt Ihren GTM-Container für alle Besucher ohne Einwilligungsprüfung. Unter [Cookie-Einwilligung](/de/integrations/cookie-consent) erfahren Sie, wie Sie Analytics erst nach der Einwilligung von Besuchern aktivieren.

<Warning>
Fügen Sie dieselbe GA4-Property nicht sowohl direkt in `docs.json` als auch über Google Tag Manager hinzu, da dies zu doppeltem Tracking führt.
</Warning>

## Datenschutzaspekte

Google Analytics erfasst Besucherdaten. Erwägen Sie Folgendes:

- Fügen Sie ein Einwilligungsbanner für Cookies hinzu, wenn die DSGVO/CCPA gilt. Jamdesk lädt GA4 standardmäßig für jeden Besucher. Verwenden Sie daher [Cookie-Einwilligung](/de/integrations/cookie-consent), um GA4 erst nach der Einwilligung zu aktivieren.
- Aktualisieren Sie Ihre Datenschutzrichtlinie, um Analytics zu erwähnen
- Verwenden Sie bei Bedarf [IP-Anonymisierung](https://support.google.com/analytics/answer/2763052)

## Fehlerbehebung

<Accordion title="Keine Daten sichtbar">
  1. **Überprüfen Sie Ihre Mess-ID** – Sie muss mit `G-` beginnen
  2. **Prüfen Sie Werbeblocker** – Sie können Analytics-Skripte blockieren
  3. **Warten Sie auf den Build** – Änderungen erfordern einen neuen Build, bevor sie wirksam werden
  4. **Verwenden Sie Echtzeitberichte** – Standardberichte haben eine Verzögerung von 24–48 Stunden
</Accordion>

<Accordion title="Fehler „Invalid Measurement ID“ wird angezeigt">
  Die ID muss:
  - Mit `G-` beginnen
  - Nach `G-` nur Buchstaben und Zahlen enthalten
  - Exakt aus Google Analytics kopiert sein (ohne zusätzliche Leerzeichen)
</Accordion>
