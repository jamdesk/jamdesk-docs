Verbinde Slack, um Build-Benachrichtigungen im Kanal deines Teams zu erhalten.

<Note>
Die Slack-Integration ist in Pro-Tarifen verfügbar.
</Note>

## Slack einrichten

<Steps>
  <Step title="Slack-Webhook erstellen">
    In Slack:
    1. Öffne die Einstellungen deines Workspaces
    2. Navigiere zu **Apps** → **Incoming Webhooks**
    3. Klicke auf **Add to Slack**
    4. Wähle einen Kanal
    5. Kopiere die Webhook-URL
  </Step>
  <Step title="Zu Jamdesk hinzufügen">
    In deinem Jamdesk-Projekt:
    1. Öffne **Integrations**
    2. Klicke auf **Connect Slack**
    3. Füge deine Webhook-URL ein
    4. Klicke auf **Save**
  </Step>
  <Step title="Verbindung testen">
    Klicke auf **Send Test**, um zu prüfen, ob die Integration funktioniert.
  </Step>
</Steps>

## Benachrichtigungseinstellungen

Wähle aus, welche Build-Ergebnisse Benachrichtigungen auslösen:

| Ereignis | Standard | Beschreibung |
|-------|---------|-------------|
| Build succeeded | An | Benachrichtigt, wenn ein Build erfolgreich abgeschlossen wird |
| Build failed | An | Benachrichtigt, wenn ein Build fehlschlägt |

Aktiviere oder deaktiviere die Kontrollkästchen und klicke nach der Einrichtung auf **Update**, um die Einstellungen zu ändern.

## Nachrichtenformat

Benachrichtigungen enthalten:

- Projektname
- Build-Status
- Commit-Nachricht und Autor
- Link zu den Build-Details
- Dauer (bei abgeschlossenen Builds)

Beispiel:
``` text
✓ Docs build succeeded
Project: My Docs
Commit: "Add authentication guide" by @username
Duration: 45s
View build →
```

## Slack entfernen

So trennst du die Verbindung:

1. Öffne **Integrations**
2. Klicke neben Slack auf **Disconnect**
3. Bestätige die Entfernung

## Fehlerbehebung

<Accordion title="Benachrichtigungen erscheinen nicht">
  1. Prüfe, ob die Webhook-URL korrekt ist
  2. Stelle sicher, dass der Kanal noch existiert
  3. Sende eine Test-Benachrichtigung
  4. Prüfe die Einstellungen für eingehende Webhooks in Slack
</Accordion>

<Accordion title="Geänderte Einstellungen werden nicht gespeichert">
  Klicke auf die Schaltfläche **Update**, die erscheint, nachdem du ein Kontrollkästchen aktiviert hast. Änderungen werden nicht automatisch gespeichert.
</Accordion>
