Verbinden Sie Slack, um Build-Benachrichtigungen direkt in Ihrem Teamkanal zu erhalten.

<Note>
Die Slack-Integration ist in Pro-Tarifen verfügbar.
</Note>

## Slack einrichten

<Steps>
  <Step title="Slack-Webhook erstellen">
    In Slack:
    1. Öffnen Sie die Workspace-Einstellungen
    2. Navigieren Sie zu **Apps** → **Incoming Webhooks**
    3. Klicken Sie auf **Add to Slack**
    4. Wählen Sie einen Kanal aus
    5. Kopieren Sie die Webhook-URL
  </Step>
  <Step title="Zu Jamdesk hinzufügen">
    In Ihrem Jamdesk-Projekt:
    1. Navigieren Sie zu **Integrations**
    2. Klicken Sie auf **Connect Slack**
    3. Fügen Sie Ihre Webhook-URL ein
    4. Klicken Sie auf **Save**
  </Step>
  <Step title="Verbindung testen">
    Klicken Sie auf **Send Test**, um zu überprüfen, ob die Integration funktioniert.
  </Step>
</Steps>

## Benachrichtigungseinstellungen

Wählen Sie aus, welche Build-Ergebnisse Benachrichtigungen auslösen:

| Ereignis | Standard | Beschreibung |
|-------|---------|-------------|
| Build erfolgreich | On | Benachrichtigt, wenn ein Build erfolgreich abgeschlossen wurde |
| Build fehlgeschlagen | On | Benachrichtigt, wenn ein Build fehlschlägt |

Beide Optionen sind standardmäßig aktiviert. Um die Einstellungen nach der Einrichtung zu ändern, aktivieren oder deaktivieren Sie die Kontrollkästchen und klicken Sie auf **Update**.

## Nachrichtenformat

Benachrichtigungen enthalten:

- Projektname
- Build-Status
- Commit-Nachricht und Autor
- Link zu den Build-Details
- Dauer (bei abgeschlossenen Builds)

Beispiel:
``` text
✓ Docs build succeeded
Project: My Docs
Commit: "Add authentication guide" by @username
Duration: 45s
View build →
```

## Slack entfernen

So trennen Sie die Verbindung:

1. Navigieren Sie zu **Integrations**
2. Klicken Sie neben Slack auf **Disconnect**
3. Bestätigen Sie die Entfernung

## Fehlerbehebung

<Accordion title="Benachrichtigungen werden nicht angezeigt">
  1. Überprüfen Sie, ob die Webhook-URL korrekt ist
  2. Stellen Sie sicher, dass der Kanal noch vorhanden ist
  3. Senden Sie eine Testbenachrichtigung
  4. Überprüfen Sie die Einstellungen für eingehende Webhooks in Slack
</Accordion>

<Accordion title="Geänderte Einstellungen werden nicht gespeichert">
  Klicken Sie nach dem Aktivieren oder Deaktivieren der Benachrichtigungs-Kontrollkästchen auf die angezeigte Schaltfläche **Update**. Änderungen werden nicht automatisch gespeichert.
</Accordion>
