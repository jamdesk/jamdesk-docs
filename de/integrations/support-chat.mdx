Jamdesk kann auf jeder Seite Ihrer Dokumentation ein Live-Chat-Widget laden. Fügen Sie den Block des Anbieters unter `integrations` in `docs.json` hinzu. Jamdesk bindet das Widget-Skript ein.

<Info>
Jamdesk prüft jeden Wert vor dem Laden des Widgets anhand eines strikten Formats. Ein Wert im falschen Format wird stillschweigend übersprungen. Sie erhalten weder eine Fehlerseite noch ein defektes Skript-Tag.
</Info>

## Über das Dashboard konfigurieren

Öffnen Sie **Dashboard → Integrations**, wählen Sie die Karte des Anbieters aus und fügen Sie dessen ID ein. Jamdesk übernimmt den `docs.json`-Block und startet einen Neuaufbau (nur bei mit GitHub verbundenen Projekten). Verwenden Sie die folgenden Abschnitte, um `docs.json` direkt zu bearbeiten, oder bei Projekten, die nur über die CLI verwaltet werden.

## Intercom

**Format:** Die App-ID besteht aus 6 bis 16 Buchstaben oder Ziffern.

<Info>
Ihre App-ID finden Sie in Intercom unter **Settings → Installation → Web**. Sie ist Ihre Workspace-ID.
</Info>

```json docs.json
{
  "integrations": {
    "intercom": {
      "appId": "abc12345"
    }
  }
}
```

## Front Chat

**Format:** Die Chat-ID besteht aus 8 bis 64 Zeichen in Kleinbuchstaben-Hexadezimalformat (`0-9`, `a-f`).

```json docs.json
{
  "integrations": {
    "frontchat": {
      "snippetId": "3f8a2e1c9b6d4a7f"
    }
  }
}
```

## Einwilligungsprüfung

Die Widgets von Intercom und Front Chat berücksichtigen `integrations.cookies`. Ist dies gesetzt, wartet das Chat-Skript, bis Ihr Einwilligungsbanner die Zustimmung erfasst hat. Die Einrichtung finden Sie unter [Cookie-Einwilligung](/de/integrations/cookie-consent). Ohne diese Einstellung wird das Widget beim Laden der Seite für jeden Besucher geladen.
