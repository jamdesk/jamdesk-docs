---

Jamdesk kann auf jeder Seite Ihrer Dokumentationswebsite ein Live-Chat-Widget laden. Fügen Sie den Block des Anbieters unter `integrations` in `docs.json` hinzu. Jamdesk fügt das Widget-Skript dann automatisch ein.

<Info>
Jeder Wert wird anhand eines strengen Formats geprüft, bevor Jamdesk das Widget lädt. Ein Wert im falschen Format wird stillschweigend übersprungen und nie gerendert – keine Fehlerseite, kein beschädigtes Script-Tag.
</Info>

## Vom Dashboard aus konfigurieren

Am schnellsten richten Sie einen dieser Anbieter über **Dashboard → Integrations** ein. Wählen Sie die Karte des Anbieters aus, fügen Sie dessen ID ein. Jamdesk trägt den `docs.json`-Block für Sie ein und löst einen neuen Build aus (nur für GitHub-verbundene Projekte). Die folgenden Abschnitte dienen zum direkten Bearbeiten von `docs.json` oder für reine CLI-Projekte.

## Intercom

**Format:** Die App ID besteht aus 6–16 Buchstaben oder Ziffern.

<Info>
Ihre App ID finden Sie in Intercom unter **Settings → Installation → Web** – sie ist die ID Ihres Workspace.
</Info>

```json docs.json
{
  "integrations": {
    "intercom": {
      "appId": "abc12345"
    }
  }
}
```

## Front Chat

**Format:** Die Chat ID besteht aus 8–64 Hexadezimalzeichen in Kleinbuchstaben (`0-9`, `a-f`).

```json docs.json
{
  "integrations": {
    "frontchat": {
      "snippetId": "3f8a2e1c9b6d4a7f"
    }
  }
}
```

## Einwilligungssteuerung

Beide Widgets berücksichtigen `integrations.cookies`. Wenn dieser Wert gesetzt ist, wird das Chat-Skript erst geladen, wenn Ihr Einwilligungsbanner die Zustimmung erfasst – unter [Cookie-Einwilligung](/de/integrations/cookie-consent) finden Sie die vollständige Einrichtung. Ohne diesen Wert wird das Widget beim Laden der Seite für jeden Besucher geladen.
