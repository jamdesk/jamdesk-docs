Jamdesk kann auf jeder Seite Ihrer Dokumentationswebsite ein Live-Chat-Widget laden. Fügen Sie den Block des Anbieters unter `integrations` in `docs.json` hinzu, und Jamdesk fügt das Widget-Skript automatisch ein.

<Info>
Jeder Wert wird anhand eines strikten Formats geprüft, bevor Jamdesk das Widget lädt. Ein Wert im falschen Format wird stillschweigend übersprungen und nie gerendert – keine Fehlerseite, kein fehlerhaftes Script-Tag.
</Info>

## Über das Dashboard konfigurieren

So richten Sie einen dieser Anbieter am schnellsten ein: **Dashboard → Integrations**. Wählen Sie die Karte des Anbieters aus, fügen Sie die ID ein, und Jamdesk schreibt den `docs.json`-Block für Sie und löst einen neuen Build aus (nur für mit GitHub verbundene Projekte). Die folgenden Abschnitte sind für die direkte Bearbeitung von `docs.json` oder für reine CLI-Projekte vorgesehen.

## Intercom

**Format:** Die App-ID besteht aus 6–16 Buchstaben oder Ziffern.

<Info>
Ihre App-ID finden Sie in Intercom unter **Settings → Installation → Web** – sie ist die ID Ihres Workspace.
</Info>

```json docs.json
{
  "integrations": {
    "intercom": {
      "appId": "abc12345"
    }
  }
}
```

## Front Chat

**Format:** Die Chat-ID besteht aus 8–64 Kleinbuchstaben im Hexadezimalformat (`0-9`, `a-f`).

```json docs.json
{
  "integrations": {
    "frontchat": {
      "snippetId": "3f8a2e1c9b6d4a7f"
    }
  }
}
```

## Einwilligungsprüfung

Beide Widgets berücksichtigen `integrations.cookies`. Wenn diese Einstellung aktiviert ist, wird das Chat-Skript erst geladen, wenn Ihr Einwilligungsbanner die Zustimmung erfasst – eine vollständige Einrichtung finden Sie unter [Cookie-Einwilligung](/de/integrations/cookie-consent). Ohne diese Einstellung wird das Widget beim Laden der Seite für jeden Besucher geladen.
