Füge deine GTM-Container-ID in `docs.json` hinzu, um Google Tag Manager auf jeder Seite deiner Dokumentation zu laden. Dein Marketingteam richtet anschließend Analysen, Conversion-Pixel und Event-Tracking in GTM ein.

<Info>
GTM-Container-IDs beginnen mit `GTM-`. Für reines Google Analytics siehe [Google Analytics-Integration](/de/integrations/google-analytics) für eine einfachere Einrichtung.
</Info>

## Wann Sie GTM verwenden sollten

Verwende Google Tag Manager, wenn du Folgendes benötigst:

- **Mehrere Tracking-Tools**: GA4, Facebook Pixel, LinkedIn usw.
- **Kontrolle durch das Marketingteam**: Marketer fügen Tags ohne Hilfe von Entwicklern hinzu
- **Erweiterte Trigger**: Klicks auf Schaltflächen, Formularabsendungen, Videoaufrufe verfolgen
- **A/B-Testing-Integration**: Tools wie Google Optimize anbinden

Für einfache Analysen ist das direkte Hinzufügen von GA4 einfacher.

## Ihre Container-ID abrufen

1. Öffne [Google Tag Manager](https://tagmanager.google.com/)
2. Wähle dein Konto und deinen Container aus (oder erstelle neue)
3. Kopiere die **Container-ID** oben auf der Seite (beginnt mit `GTM-`)

## GTM zu Ihrer Dokumentation hinzufügen

Füge die Container-ID zu deiner `docs.json` hinzu:

```json docs.json
{
  "name": "My Docs",
  "integrations": {
    "gtm": {
      "tagId": "GTM-XXXXXXX"
    }
  }
}
```

Ersetze `GTM-XXXXXXX` durch deine Container-ID.

## Cookie-Einwilligung

Richte Cookie-Banner zur Einwilligung selbst ein, falls du sie benötigst. Jamdesk lädt deinen GTM-Container auf jeder Seite. Jedes Tag, das du konfigurierst, wird für jeden Besucher ausgelöst. Wenn DSGVO, CCPA oder ähnliche Vorschriften für deine Leser gelten, konfiguriere den [Consent Mode](https://support.google.com/tagmanager/answer/10718549) in GTM oder verwende eine Consent-Management-Plattform. Jamdesk kann GTM selbst auch hinter einer Einwilligung sperren. Siehe [Cookie-Einwilligung](/de/integrations/cookie-consent).

## GA4 über GTM einrichten

Lade GA4 über GTM statt es direkt hinzuzufügen:

1. Gehe in GTM zu **Tags** → **Neu**
2. Wähle **Google Analytics: GA4-Konfiguration**
3. Gib deine GA4-Messungs-ID ein (beginnt mit `G-`)
4. Setze den Trigger auf **All Pages**
5. **Veröffentliche** deinen Container

<Warning>
Wenn du GA4 über GTM konfigurierst, füge es nicht zusätzlich direkt in `docs.json` hinzu. Das führt zu doppeltem Tracking.
</Warning>

## Installation überprüfen

### GTM-Vorschaumodus verwenden

1. Klicke in GTM oben rechts auf **Vorschau**
2. Gib die URL deiner Dokumentationsseite ein
3. Ein Debug-Fenster zeigt, welche Tags auf jeder Seite ausgelöst werden

### Browser-Entwicklertools verwenden

1. Öffne deine Seite mit den Entwicklertools (F12)
2. Wechsle zum Tab **Netzwerk**
3. Filtere nach `gtm.js` oder `googletagmanager`
4. Bestätige, dass die Anfragen erscheinen

## Häufige GTM-Tags für Dokumentationen

### Ausgehende Links verfolgen

Verfolge Klicks auf externe Links mit diesem Tag:

1. **Tag**: Google Analytics: GA4-Ereignis
2. **Ereignisname**: `click`
3. **Trigger**: Klick – Nur Links, bei dem Click URL deine Domain nicht enthält

### Suchnutzung verfolgen

Verfolge die Nutzung der Suche:

1. **Tag**: Google Analytics: GA4-Ereignis
2. **Ereignisname**: `search`
3. **Trigger**: Benutzerdefiniertes Ereignis, das deiner Sucheingabe entspricht

### Verweildauer auf der Seite verfolgen

Miss, wie lange Leser auf einer Seite bleiben:

1. **Tag**: Google Analytics: GA4-Ereignis
2. **Ereignisname**: `timing`
3. **Trigger**: Timer-Trigger (z. B. alle 30 Sekunden)

## Fehlerbehebung

<Accordion title="Tags werden nicht ausgelöst">
  1. **Container-ID prüfen**: Sie muss mit `GTM-` beginnen
  2. **Container veröffentlichen**: Nicht veröffentlichte Änderungen erscheinen nicht auf deiner Seite
  3. **Vorschaumodus verwenden**: Die GTM-Vorschau zeigt, welche Tags auf jeder Seite ausgelöst werden
</Accordion>

<Accordion title="Doppelte Daten in Google Analytics">
  GA4, das an zwei Stellen eingerichtet ist, zählt jeden Seitenaufruf doppelt:
  - Direkt in `docs.json` (`integrations.ga4`)
  - Über GTM als GA4-Tag

  Entferne eine der beiden Einrichtungen.
</Accordion>
