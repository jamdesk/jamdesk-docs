Jede Jamdesk-Website enthält einen Chatassistenten, der Fragen von Besuchern anhand Ihrer Dokumentation beantwortet. Er ruft relevante Abschnitte ab, sendet sie an Claude und gibt eine Antwort mit Links zu den Quellseiten aus. Der Chat ist standardmäßig in allen Tarifen ohne zusätzliche Kosten aktiviert.

## Anwendungsfälle

<Tabs>
  <Tab title="API-Einführung">
    Ein Entwickler, der Ihre API integriert, fragt *„Wie authentifiziere ich Anfragen?“* und erhält die genauen Schritte mit einem Codebeispiel sowie einen Link zur Quellseite.
  </Tab>
  <Tab title="Fehlerbehebung">
    *„Mein Build schlägt mit einem Timeout-Fehler fehl“*

    Statt mehrere Seiten zu durchsuchen, erhält der Besucher innerhalb von Sekunden die passende Lösung aus Ihrem Leitfaden zur Fehlerbehebung.
  </Tab>
  <Tab title="Schnellreferenz">
    Wiederkehrende Nutzer fragen beispielsweise: *„Welche Parameter akzeptiert der /users-Endpoint?“* Der Chat ruft die Endpoint-Dokumentation ab und gibt die Parametertabelle direkt zurück.
  </Tab>
</Tabs>

## Funktionsweise

<Steps>
  <Step title="Build indexiert Ihre Dokumentation">
    Bei jedem Build teilt Jamdesk Ihre Seiten in Abschnitte auf und speichert sie als durchsuchbare Embeddings.
  </Step>
  <Step title="Besucher stellt eine Frage">
    Über die Schaltfläche „Ask AI“ (oder Cmd+I / Ctrl+I) wird auf jeder Seite ein Chatfenster geöffnet.
  </Step>
  <Step title="KI beantwortet Fragen anhand Ihrer Dokumentation">
    Relevante Abschnitte werden abgerufen und als Kontext an Claude gesendet. Die Antwort wird mit Zitierlinks zu den Quellseiten ausgegeben.
  </Step>
</Steps>

## Funktionen

| Funktion | Details |
|---------|--------|
| Gestreamte Antworten | Antworten werden in Echtzeit ausgegeben |
| Zitierlinks | Jede Antwort verlinkt auf die Dokumentationsseiten, aus denen sie stammt |
| Mehrdeutigkeit auflösen | Wenn eine Frage zu mehreren Themen passt, fragt die KI, welches davon der Besucher meint |
| Gesprächskontext | Verlauf mit 10 Nachrichten, pro Browser-Tab gespeichert |
| Vorschlagsfragen | Automatisch aus Ihrer Dokumentation generiert oder von Ihnen in docs.json festgelegt |
| Tastenkürzel | Cmd+I / Ctrl+I zum Ein- und Ausschalten, Escape zum Schließen |
| Markdown-Darstellung | Codeblöcke, Tabellen und Listen werden in Antworten dargestellt |

## Konfiguration

Der Chat funktioniert sofort und erfordert keine Konfiguration. Fügen Sie nur dann einen `chat`-Block zu Ihrer `docs.json` hinzu, wenn Sie die Vorschlagsfragen anpassen, die Schaltfläche umbenennen, ihr Symbol ändern oder den Chat deaktivieren möchten. Das Feld `chat` ist optional, und für jede Einstellung gibt es einen Standardwert.

```json docs.json
{
  "chat": {
    "enabled": true,
    "starterQuestions": [
      "How do I get started?",
      "What API endpoints are available?"
    ]
  }
}
```

| Feld | Typ | Standardwert | Beschreibung |
|-------|------|---------|-------------|
| `enabled` | boolean | `true` | Setzen Sie den Wert auf `false`, um die Schaltfläche „Ask AI“, das Chatfenster und das Tastenkürzel auf Ihrer Website zu entfernen |
| `starterQuestions` | string[] | automatisch generiert | Bis zu 4 Fragen, die beim Öffnen des Fensters angezeigt werden (jeweils 5–200 Zeichen). Wird automatisch aus Ihrer Dokumentation generiert, wenn das Feld fehlt; setzen Sie es auf `[]`, um keine Fragen anzuzeigen |
| `label` | string | „Ask AI“ in der Sprache der Seite | Ersetzt „Ask AI“ auf der Chat-Schaltfläche, in der Kopfzeile des Chatfensters und beim Suchkürzel. Bis zu 40 Zeichen. Gilt für alle Sprachen. |
| `icon` | string | `sparkles` | Ein Font Awesome-Symbolname, eine Bild-URL oder ein Pfad zu einem Bild in Ihrem Projekt. Ein Font Awesome-Symbol übernimmt Ihre Akzentfarbe; ein Bild wird unverändert angezeigt. Wählen Sie daher eines, das auf hellem und dunklem Hintergrund gut erkennbar ist. |

### Vorschlagsfragen

Vorschlagsfragen sind die vorgeschlagenen Eingaben, die im Chatfenster angezeigt werden, bevor ein Besucher etwas eingibt: Beispiele, die mit einem Klick übernommen werden können und zeigen, wonach man fragen kann. Wenn Sie `starterQuestions` in Ihrer `docs.json` weglassen, generiert Jamdesk sie bei jedem Build automatisch aus Ihrer Dokumentation. So bleiben sie relevant, wenn Ihre Dokumentation wächst.

Um eigene Fragen festzulegen, listen Sie sie im Array `starterQuestions` auf. Das ist praktisch, wenn Ihr Supportteam immer wieder dieselben Fragen beantwortet und Sie diese zuerst anzeigen möchten:

```json docs.json
{
  "chat": {
    "starterQuestions": [
      "How do notifications work?",
      "Tell me more about analytics"
    ]
  }
}
```

Sie können bis zu 4 Vorschlagsfragen mit jeweils 5 bis 200 Zeichen festlegen. Wenn keine Vorschlagsfragen angezeigt werden sollen, setzen Sie `starterQuestions` auf ein leeres Array (`[]`).

### Benutzerdefinierter Name und Symbol

Standardmäßig zeigen die Chat-Schaltfläche, die Kopfzeile des Chatfensters und das Suchkürzel „Ask AI“ an und verwenden ein Funkel-Symbol. Passen Sie `label` und `icon` an Ihr Produkt an:

```json docs.json
{
  "chat": {
    "label": "Acme Assistant",
    "icon": "/images/assistant.svg"
  }
}
```

Die Bezeichnung ist in allen Sprachen Ihrer Website gleich. Ein Wert für `icon` wie `robot` ist ein Font Awesome-Name. Ein Wert, der mit `http://`, `https://` oder `/` beginnt oder mit einer Bilddateiendung endet, wird als Bild behandelt.

### Chat deaktivieren

Der Chat ist standardmäßig in jedem Tarif aktiviert. Um ihn zu deaktivieren, setzen Sie `enabled` auf `false`. Dadurch werden die Schaltfläche „Ask AI“, das Chatfenster und das Tastenkürzel `Cmd+I` / `Ctrl+I` entfernt:

```json docs.json
{
  "chat": {
    "enabled": false
  }
}
```

<Note>
Das Deaktivieren des Chats wirkt sich nicht auf die Suche aus. KI-Chat und Suche sind separate Funktionen. Ihre Dokumentation bleibt also auch bei deaktiviertem Chat vollständig durchsuchbar.
</Note>

## Einschränkungen

| Einschränkung | Wert |
|-------|-------|
| Maximale Nachrichtenlänge | 2,000 Zeichen |
| Maximale Antwortlänge | 2,048 Tokens |
| Ratenlimit | 10 Anfragen / 60 Sekunden pro Besucher und Website |
| Gesprächsverlauf | 10 Nachrichten pro Tab |
| Vorschlagsfragen | Maximal 4 |

Der Chat funktioniert auf [benutzerdefinierten Domains](/de/deploy/custom-domains). Der Endpoint `/_chat` verwendet denselben Ursprung und funktioniert daher auf jeder Domain, unter der Ihre Dokumentation bereitgestellt wird.

<Accordion title="Funktionsweise der Abrufpipeline">
  Bei jedem Build teilt Jamdesk Ihre Seiten in Abschnitte auf und speichert für jeden davon Vektor-Embeddings. Wenn ein Besucher eine Frage stellt, führt das System eine hybride Suche durch (Schlüsselwortabgleich kombiniert mit semantischer Ähnlichkeit), um die relevantesten Abschnitte in Ihrer Dokumentation zu finden. Diese Abschnitte werden mit der Anweisung, ausschließlich anhand der bereitgestellten Dokumentation zu antworten, als Kontext an Claude gesendet. Zitate werden ermittelt, indem Seitenverweise in Claudes Antwort mit den abgerufenen Abschnitten abgeglichen werden.
</Accordion>
