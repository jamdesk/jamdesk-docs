Wenn Sie möchten, dass KI-Tools wie ChatGPT, Claude oder Copilot genaue Antworten zu Ihrem Produkt geben, benötigen sie strukturierten Zugriff auf Ihre Dokumentation und nicht nur auf Inhalte aus ihren Trainingsdaten.

Jede Jamdesk-Website erstellt gemäß der Spezifikation von [llmstxt.org](https://llmstxt.org) automatisch `llms.txt` und `llms-full.txt`. KI-Tools lesen diese Dateien, anstatt einzelne Seiten zu crawlen.

<Note>
  Google prüft `llms.txt` jetzt als Teil der [agentischen Browsing-Prüfungen von Lighthouse](https://developer.chrome.com/docs/lighthouse/agentic-browsing/llms-txt). Websites, die eine gültige `llms.txt` veröffentlichen, werden für KI-Agenten und zunehmend auch für Google selbst besser auffindbar, wenn Inhalte für KI-gestützte Antworten gerankt werden. Jamdesk stellt dies kostenlos bereit.
</Note>

<Tip>
  **Prüfen Sie Ihren Score.** Mit dem kostenlosen Tool [AI Score](https://jamdesk.com/ai-score) sehen Sie, wie gut jede Dokumentationswebsite für Agenten geeignet ist. Die Veröffentlichung einer gültigen `llms.txt` gehört zu den ersten Prüfungen. Außerdem gibt es eine [AI Score Chrome-Erweiterung](https://chromewebstore.google.com/detail/jamdesk-ai-score/mhihkkgpcbmapmojnakhjfhjmiagkhlj), mit der Sie Websites beim Browsen bewerten können.
</Tip>

## Was Jamdesk generiert

| Datei | Inhalt |
|------|---------|
| `llms.txt` | Seitentitel, Beschreibungen und URLs (ein strukturiertes Inhaltsverzeichnis) |
| `llms-full.txt` | Vollständiger Dokumentationsinhalt in einer einzigen Datei |

Jamdesk generiert beide Dateien während des Builds und stellt sie über dasselbe CDN wie Ihre Dokumentation bereit.

## Dateien überprüfen

Prüfen Sie, ob Ihre Dateien nach dem ersten Build vorhanden sind:

<Tabs>
  <Tab title="Stammdomain">
    Wenn sich Ihre Dokumentation im Stammverzeichnis Ihrer Domain befindet (z. B. `docs.acme.com` oder `acme.jamdesk.app`):

    ```bash
    curl https://docs.acme.com/llms.txt
    curl https://docs.acme.com/llms-full.txt
    ```
  </Tab>
  <Tab title="/docs-Unterpfad">
    Wenn sich Ihre Dokumentation unter `/docs` auf Ihrer Hauptwebsite befindet (wie auf dieser Website unter `jamdesk.com/docs`):

    ```bash
    curl https://jamdesk.com/docs/llms.txt
    curl https://jamdesk.com/docs/llms-full.txt
    ```
  </Tab>
</Tabs>

## Dateiformat

Die Datei `llms.txt` führt jede Seite mit ihrem Titel, ihrer Beschreibung und ihrer URL auf. Die Seiten sind in Abschnitte gruppiert, die Ihrer Navigation entsprechen:

```text
# Your Project Documentation

> Documentation for Your Project

## Get Started

- [Getting Started](https://your-project.jamdesk.app/getting-started): Set up your first project in 5 minutes
- [Configuration](https://your-project.jamdesk.app/configuration): Configure your project settings

## API Reference

- [Authentication](https://your-project.jamdesk.app/authentication): How to authenticate API requests
```

Die Datei `llms-full.txt` enthält den vollständigen Markdown-Inhalt jeder Seite. Die Inhalte werden an Seitengrenzen zusammengefügt, die durch Überschriften markiert sind.

## Struktur

`llms.txt` folgt dem Vorschlag von [llmstxt.org](https://llmstxt.org/): einem H1-Titel, einer Zusammenfassung als Blockquote sowie Ihren Navigation-Tabs und -Gruppen als `##`-Abschnitte mit Markdown-Links.

Mehrsprachige Websites erhalten einen Index pro Sprache. Die Stammdatei `llms.txt` führt Ihre Standardsprache auf und verlinkt am Ende auf jeden übersetzten Index, zum Beispiel `/fr/llms.txt` für Französisch. Jede Sprachdatei verlinkt zurück auf ihre jeweiligen Schwesterdateien.

Jede Sprache erhält außerdem eine eigene Datei mit dem vollständigen Inhalt, etwa `/fr/llms-full.txt`. Auch Ihre Standardsprache verfügt über eine solche Datei (zum Beispiel `/en/llms-full.txt`). Die Stammdatei `llms-full.txt` enthält weiterhin alle Sprachen.

## Anweisung für Agenten auf jeder Seite

Jede Seite enthält außerdem einen unsichtbaren, für Screenreader stummen Hinweis für KI-Agenten, der auf `llms.txt` verweist. Jeder Markdown-Export beginnt mit einem Blockquote-Link zum Index. Agenten, die auf Ihrem HTML landen, finden den Markdown-Pfad, ohne die Website zu crawlen.

## So wird es erstellt

- Während des Builds zusammen mit Ihrem HTML generiert
- Über das CDN mit derselben Cache-Richtlinie wie Ihre Dokumentation bereitgestellt
- Bei jedem Build automatisch aktualisiert
- Keine Konfiguration erforderlich; standardmäßig werden alle Seiten einbezogen

## llms.txt deaktivieren

`llms.txt` und `llms-full.txt` werden standardmäßig veröffentlicht. Um ihre Generierung zu deaktivieren (beispielsweise wenn KI-Tools Ihre Inhalte nicht verarbeiten sollen), setzen Sie `seo.ai.llmsTxt` in Ihrer `docs.json` auf `false`:

```json docs.json
{
  "seo": {
    "ai": {
      "llmsTxt": false
    }
  }
}
```

Beim nächsten Build überspringt Jamdesk beide Dateien. Die Live-URLs `/llms.txt` und `/llms-full.txt` geben dann `404` zurück.

<Note>
  **KI-Verarbeitung und Suchindexierung sind getrennte Einstellungen.** `seo.ai.llmsTxt` steuert nur die Dateien `llms.txt`/`llms-full.txt`, die von KI-Tools gelesen werden. Die Einstellung ändert nicht, wie Suchmaschinen Ihre Website indexieren. Dies wird durch [`robots`-Metadaten und seitenweises `noindex`](/de/content/seo#indexierung-steuern) gesteuert. Eine Seite kann von Google indexiert und gleichzeitig von der KI-Verarbeitung ausgeschlossen werden oder umgekehrt.
</Note>

## KI-Crawler

Die standardmäßige `robots.txt` von Jamdesk erlaubt allen wichtigen KI-Crawlern (Claude, ChatGPT, Copilot, Gemini den Zugriff). Ihre Dokumentation ist für KI-Tools sofort verfügbar.

<Accordion title="Wie sich llms.txt von sitemap.xml unterscheidet">
  `sitemap.xml` führt URLs auf, die Suchmaschinen crawlen und indexieren sollen. Die Datei enthält keine Inhalte, sondern nur Links und Metadaten wie das Datum der letzten Änderung.

  `llms.txt` wurde für KI-Modelle entwickelt. Die Datei enthält Seitentitel, Beschreibungen und in `llms-full.txt` auch den eigentlichen Inhalt. KI-Tools können die vollständige Datei lesen, um Ihre Dokumentation zu verstehen, ohne mehrere HTTP-Anfragen zu stellen.
</Accordion>
