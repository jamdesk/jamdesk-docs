Jede Seite Ihrer Jamdesk-Website verfügt über ein Menü „KI-Aktionen", ein kleines Dropdown oberhalb des Titels. Leser können die Seite als Markdown kopieren, in ChatGPT öffnen oder Ihren MCP-Server in Cursor installieren. Es ist keine Konfiguration erforderlich.

## Integrierte Optionen

Das Menü enthält acht Optionen, standardmäßig aktiviert:

| Option | Schlüssel | Funktion |
|--------|-----------|----------|
| **Copy page** | `copy` | Ruft das rohe Markdown ab und kopiert es in die Zwischenablage |
| **View as Markdown** | `view` | Öffnet die `.md`-Datei in einem neuen Tab |
| **Open in ChatGPT** | `chatgpt` | Öffnet ChatGPT mit einem Prompt zum Lesen der aktuellen Seite |
| **Open in Claude** | `claude` | Öffnet Claude mit demselben Prompt |
| **Open in Perplexity** | `perplexity` | Öffnet Perplexity mit demselben Prompt |
| **Copy MCP config** | `mcp` | Kopiert die JSON-Konfiguration für den [MCP-Server](/de/ai/mcp-server) Ihrer Website |
| **Add to Cursor** | `cursor` | Deep-Link zur Installation des MCP-Servers in Cursor |
| **Add to VS Code** | `vscode` | Deep-Link zur Installation des MCP-Servers in VS Code |

Gemini ist ebenfalls als `gemini` verfügbar. Es ist nicht in den Standardoptionen enthalten, da es Prompts aus einer URL nicht zuverlässig vorausfüllt. Fügen Sie es explizit hinzu, wenn Ihre Leser es verwenden.

`copy` wird zur primären Schaltfläche, wenn es in der Optionsliste enthalten ist. Die übrigen erscheinen in einem Dropdown hinter einem Pfeil. Ohne `copy` klappt das Menü in ein einzelnes Dropdown „AI Actions" zusammen.

### API-Spezifikation herunterladen

API-Referenzseiten erhalten einen weiteren Eintrag: **Download API spec**. Er bündelt alle OpenAPI-Spezifikationen, auf die Ihre Website verweist, einschließlich externer Spezifikations-URLs, in einer einzigen `api-specs.zip`. Übergeben Sie die ZIP-Datei an Postman, einen Client-Generator oder Ihre eigenen Werkzeuge. Mehrteilige Spezifikationen behalten ihre Ordnerstruktur im ZIP bei. `$ref`-Verknüpfungen zwischen Dateien werden weiterhin aufgelöst.

Es ist nichts zu konfigurieren. Der Eintrag erscheint nur auf Seiten, die von einer OpenAPI-Spezifikation gespeist werden. Jamdesk erstellt die ZIP-Datei bei jedem Download neu. Sie entspricht immer Ihren aktuellen Spezifikationen.

## Konfiguration

Bearbeiten Sie `docs.json` nur, um festzulegen, welche Optionen angezeigt werden, oder um das Menü zu deaktivieren.

### Eine Teilmenge der Optionen anzeigen

```json docs.json
{
  "contextual": {
    "options": ["copy", "claude", "mcp"]
  }
}
```

### Das Menü deaktivieren

```json docs.json
{
  "contextual": {
    "enabled": false
  }
}
```

### Benutzerdefinierte Optionen hinzufügen

Kombinieren Sie integrierte Optionen mit eigenen. Eine eigene Option öffnet ihre URL in einem neuen Tab.

```json docs.json
{
  "contextual": {
    "options": [
      "copy",
      "claude",
      {
        "title": "Ask on Discord",
        "description": "Get help from the community",
        "icon": "discord",
        "href": "https://discord.gg/your-server"
      }
    ]
  }
}
```

Eigene Optionen akzeptieren ein optionales Feld `icon`. Jeder [Font-Awesome-Symbolname](/de/content/icons) funktioniert, einschließlich Markensymbolen wie `discord` oder `slack`. Optionen ohne Symbol zeigen ein Link-Symbol.

Eigene Optionen akzeptieren außerdem Abfrageparameter:

```json docs.json
{
  "contextual": {
    "options": [
      "copy",
      {
        "title": "Search in Notion",
        "description": "Find related internal docs",
        "href": {
          "base": "https://notion.so/search",
          "query": [
            { "key": "q", "value": "docs" }
          ]
        }
      }
    ]
  }
}
```

## Funktionsweise

Das Menü läuft clientseitig. Seine URLs werden bei jeder Seitennavigation aktualisiert, auch bei der Navigation über die Seitenleiste ohne vollständiges Neuladen der Seite. Der Link „Open in Claude" verweist immer auf die aktuelle Seite.

Die Links zu KI-Diensten fügen die `.md`-URL der Seite in den Prompt ein. ChatGPT, Claude und Perplexity rufen die Seite über diesen Link ab.

MCP-Optionen nutzen den Endpunkt `/_mcp` auf jeder Jamdesk-Website. „Copy MCP config" kopiert das JSON für jeden MCP-Client. „Add to Cursor" und „Add to VS Code" sind Deep-Links, die den Installationsablauf des Editors öffnen. Was KI-Werkzeuge damit tun können, erfahren Sie unter [MCP-Server](/de/ai/mcp-server).
