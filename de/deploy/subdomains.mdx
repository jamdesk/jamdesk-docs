Jedes Jamdesk-Projekt erhält eine kostenlose Subdomain unter `yourproject.jamdesk.app`. Sie ist Ihre Standard-URL für die Dokumentation.

## Funktionsweise von Subdomains

Jamdesk weist beim Erstellen eines Projekts anhand des Projekt-Slugs eine Subdomain zu:

| Projekt-Slug | Subdomain |
|--------------|-----------|
| `my-docs` | `my-docs.jamdesk.app` |
| `acme-api` | `acme-api.jamdesk.app` |
| `company-help` | `company-help.jamdesk.app` |

Ihre Subdomain ist aktiv, sobald der erste Build abgeschlossen ist.

## Regeln für Subdomain-Namen

- Nur Kleinbuchstaben, Zahlen und Bindestriche
- Muss mit einem Buchstaben beginnen
- Darf nicht mit einem Bindestrich beginnen oder enden
- 3 bis 63 Zeichen lang
- Muss über alle Jamdesk-Projekte hinweg eindeutig sein

## Subdomain ändern

1. Öffnen Sie Ihr Projekt im [Dashboard](https://dashboard.jamdesk.com)
2. Öffnen Sie **Settings** → **General**
3. Aktualisieren Sie das Feld **Project Slug**
4. Klicken Sie auf **Save**

<Warning>
Das Ändern Ihrer Subdomain unterbricht bestehende Links. Suchmaschinen und externe Websites, die auf Ihre alte Subdomain verlinken, erhalten 404-Fehler. Richten Sie stattdessen eine eigene Domain ein, wenn Sie stabile URLs benötigen.
</Warning>

Was sich ändert:
- Ihre neue Subdomain ist sofort aktiv
- Die alte Subdomain liefert 404
- Lesezeichen und externe Links funktionieren nicht mehr
- Suchmaschinen-Rankings werden zurückgesetzt

## SSL-Zertifikate

Jamdesk stellt für jede `*.jamdesk.app`-Subdomain SSL-Zertifikate bereit. HTTP-Anfragen werden auf HTTPS umgeleitet.

## Ratenbegrenzungen

Jamdesk-Subdomains teilen sich die Infrastruktur mit anderen Projekten. Für stark frequentierte Dokumentation gilt:
- Verwenden Sie eine eigene Domain für dedizierte Ressourcen
- Kontaktieren Sie den Support, wenn Sie dauerhaft hohen Traffic erwarten

## Wann Sie eine benutzerdefinierte Domain verwenden sollten

Wählen Sie eine eigene Domain, wenn:
- Sie URL-Stabilität benötigen (Änderungen an der Subdomain unterbrechen Links)
- Ihre Dokumentation unter `docs.yourcompany.com` erreichbar sein soll
- Sie zur Domain Ihres Unternehmens passen möchten
- Ihre Dokumentation für Kunden bestimmt ist

Anleitung zur Einrichtung finden Sie unter [Eigene Domains](/de/deploy/custom-domains).

## Subdomain oder benutzerdefinierte Domain

| Merkmal | Subdomain | Eigene Domain |
|---------|-----------|---------------|
| Einrichtungszeit | Sofort | 10 bis 30 Minuten |
| Kosten | Kostenlos | Kostenlos (Domain stellen Sie bereit) |
| URL-Format | `project.jamdesk.app` | `docs.yourdomain.com` |
| SSL | Automatisch | Automatisch |
| Branding | Jamdesk-Branding | Ihre Marke |
| URL-Stabilität | An Projekt-Slug gebunden | Dauerhaft |
