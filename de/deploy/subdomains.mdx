Jedes Jamdesk-Projekt erhält eine kostenlose Subdomain unter `yourproject.jamdesk.app`. Dies ist Ihre standardmäßige Dokumentations-URL und sie funktioniert unmittelbar nach Ihrer ersten Bereitstellung.

## Funktionsweise von Subdomains

Wenn Sie ein Projekt erstellen, weist Jamdesk anhand des Projekt-Slugs automatisch eine Subdomain zu:

| Projekt-Slug | Subdomain |
|--------------|-----------|
| `my-docs` | `my-docs.jamdesk.app` |
| `acme-api` | `acme-api.jamdesk.app` |
| `company-help` | `company-help.jamdesk.app` |

Ihre Subdomain ist aktiv, sobald Ihr erster Build abgeschlossen ist.

## Regeln für Subdomain-Namen

Subdomains müssen folgende Regeln erfüllen:
- Nur Kleinbuchstaben, Zahlen und Bindestriche
- Müssen mit einem Buchstaben beginnen
- Dürfen nicht mit einem Bindestrich beginnen oder enden
- 3–63 Zeichen lang
- Müssen über alle Jamdesk-Projekte hinweg eindeutig sein

## Subdomain ändern

So ändern Sie Ihre Subdomain:

1. Öffnen Sie Ihr Projekt im [Dashboard](https://dashboard.jamdesk.com)
2. Öffnen Sie **Settings** → **General**
3. Aktualisieren Sie das Feld **Project Slug**
4. Klicken Sie auf **Save**

<Warning>
Durch das Ändern Ihrer Subdomain werden bestehende Links ungültig. Suchmaschinen und externe Websites, die auf Ihre alte Subdomain verweisen, erhalten 404-Fehler. Wenn Sie eine stabile URL benötigen, sollten Sie stattdessen eine benutzerdefinierte Domain einrichten.
</Warning>

Nach der Änderung:
- Ihre neue Subdomain ist sofort aktiv
- Die alte Subdomain gibt 404 zurück
- Lesezeichen und externe Links funktionieren nicht mehr
- Rankings in Suchmaschinen werden zurückgesetzt

## SSL-Zertifikate

SSL-Zertifikate werden für alle `*.jamdesk.app`-Subdomains automatisch bereitgestellt. HTTPS ist erforderlich; HTTP-Anfragen werden zu HTTPS weitergeleitet.

## Ratenbegrenzungen

Jamdesk-Subdomains nutzen die Infrastruktur gemeinsam mit anderen Projekten. Für Dokumentationen mit hohem Datenverkehr:
- Ziehen Sie eine benutzerdefinierte Domain für dedizierte Ressourcen in Betracht
- Wenden Sie sich an den Support, wenn Sie anhaltend hohen Datenverkehr erwarten

## Wann Sie eine benutzerdefinierte Domain verwenden sollten

Verwenden Sie eine benutzerdefinierte Domain, wenn:
- Sie eine stabile URL benötigen (Änderungen der Subdomain machen Links ungültig)
- Ihre Dokumentation unter `docs.yourcompany.com` erreichbar sein soll
- Sie die Domain Ihres Unternehmens verwenden müssen
- Ihre Dokumentation für Kunden bestimmt ist

Unter [Benutzerdefinierte Domains](/de/deploy/custom-domains) finden Sie Anweisungen zur Einrichtung.

## Subdomain oder benutzerdefinierte Domain

| Funktion | Subdomain | Benutzerdefinierte Domain |
|---------|-----------|---------------|
| Einrichtungszeit | Sofort | 10–30 Minuten |
| Kosten | Kostenlos | Kostenlos (Domain wird von Ihnen bereitgestellt) |
| URL-Format | `project.jamdesk.app` | `docs.yourdomain.com` |
| SSL | Automatisch | Automatisch |
| Branding | Jamdesk-Branding | Ihr Branding |
| URL-Stabilität | An den Projekt-Slug gebunden | Permanent |
