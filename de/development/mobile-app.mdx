## Anmelden

Verwenden Sie dieselben Zugangsdaten wie im [Web-Dashboard](https://dashboard.jamdesk.com):

- E-Mail-Adresse und Passwort
- Google-Anmeldung

Nach der ersten Anmeldung entsperren Face ID oder Touch ID die App.

## Push-Benachrichtigungen

Aktivieren oder deaktivieren Sie diese unter **Settings** in der App:

- **Build erfolgreich**: eine Bereitstellung wird abgeschlossen.
- **Build fehlgeschlagen**: ein Build schlägt fehl. Die Benachrichtigung enthält die Fehlermeldung.

Benachrichtigungseinstellungen gelten pro Gerät. Warnungen können auf Ihr Telefon gehen und Ihr Tablet auslassen.

## Schreibgeschützt konzipiert

Die mobile App löst keine Neuerstellungen aus. Builds starten, wenn Sie zu Ihrem Git-Anbieter pushen. Einen manuellen Neu-Build starten Sie im [Web-Dashboard](https://dashboard.jamdesk.com). Die App ist ein Monitor, kein Bedienfeld.

Verwenden Sie das Web-Dashboard, um Projekteinstellungen zu ändern, Mitglieder einzuladen, API-Schlüssel zu rotieren oder einen manuellen Build auszulösen.

## Datenschutz

Die App kommuniziert direkt mit demselben Firebase-Backend wie das Web-Dashboard. Es gibt keine separate API-Schicht und kein Analyse-Relay, das Ihre Aktivitäten sammelt. Ihre Projektdaten verlassen niemals die Infrastruktur von Jamdesk.
