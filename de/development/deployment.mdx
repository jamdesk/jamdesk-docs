Pushen Sie in Ihren verbundenen GitHub-Branch. Ihre Dokumentation ist innerhalb weniger Minuten live.

## CLI-Bereitstellung

Stellen Sie direkt aus dem Terminal bereit, ohne zu GitHub zu pushen. Das eignet sich für schnelle Iterationen, zum Testen von Änderungen oder für Projekte ohne verbundenes Repository.

```bash
jamdesk login     # First time only
jamdesk deploy
```

Die CLI packt Ihre Dateien und lädt sie hoch. Dabei wird der Build-Fortschritt live angezeigt. Mit `--detach` wird der Build in die Warteschlange gestellt und die CLI sofort beendet.

## Der Workflow

<Steps>
  <Step title="Änderungen lokal vornehmen">
    Bearbeiten Sie Ihre MDX-Dateien und zeigen Sie eine Vorschau mit `jamdesk dev` an.
  </Step>
  <Step title="Zu GitHub pushen">
    Committen und pushen Sie in Ihren verbundenen Branch:

    ```bash
    git add .
    git commit -m "Update authentication docs"
    git push
    ```
  </Step>
  <Step title="Automatische Bereitstellung">
    Jamdesk erkennt Ihren Push und baut Ihre Dokumentation. Anschließend wird sie im CDN bereitgestellt. Die meisten Seiten werden in 30 bis 90 Sekunden erstellt.
  </Step>
</Steps>

## Bereitstellungsstatus

Prüfen Sie den Status im Dashboard unter **Deployments**:

| Status | Bedeutung |
|--------|---------|
| **Building** | Build läuft |
| **Deployed** | Unter Ihrer Domain live |
| **Failed** | Build-Fehler – Logs prüfen |
| **Queued** | Wartet auf den vorherigen Build |

## Manueller Build

Lösen Sie einen Neuaufbau aus, ohne zu pushen:

1. Öffnen Sie **Settings** in Ihrem Projekt
2. Klicken Sie auf **Rebuild**

Verwenden Sie dies nach Änderungen an Umgebungsvariablen oder um einen hängenden Build zu beheben.

## Build-Logs

Öffnen Sie **Deployments**, klicken Sie auf eine Bereitstellung und lesen Sie die Logs. Häufige Fehler:
- Ungültige MDX-Syntax
- Fehlende Bilder
- Defekte interne Links
- Konfigurationsfehler

## Rollbacks

1. Öffnen Sie **Deployments**
2. Suchen Sie die Bereitstellung, die wiederhergestellt werden soll
3. Klicken Sie auf **Rollback**

Die vorherige Version wird sofort live geschaltet.
