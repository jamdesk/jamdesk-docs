Führen Sie `jamdesk dev` (oder `npx jamdesk dev`) in einem Verzeichnis aus, das eine `docs.json` enthält. Es startet einen lokalen Server mit Hot Reload und Suche. Komponenten werden so dargestellt, wie in der Produktion.

## Voraussetzungen

- **Node.js 20+** - Prüfen mit `node --version`
- **Ein Dokumentationsprojekt** - Mit einer `docs.json`-Konfigurationsdatei

## Dev-Server starten

<Tabs>
  <Tab title="npm (Globale Installation)">
    Installieren Sie die CLI global und führen Sie sie dann in Ihrem Dokumentationsverzeichnis aus:

    ```bash
    npm install -g jamdesk
    cd your-docs
    jamdesk dev
    ```
  </Tab>
  <Tab title="npx (Ohne Installation)">
    Direkt ausführen, ohne zu installieren:

    ```bash
    cd your-docs
    npx jamdesk dev
    ```
  </Tab>
</Tabs>

Ihre Dokumentation ist unter **http://localhost:3000** verfügbar.

## Benutzerdefinierter Port

Der Standardport ist 3000. Übergeben Sie mit `--port` einen anderen:

```bash
jamdesk dev --port 3001
```

Oder legen Sie in `~/.jamdeskrc` einen dauerhaften Standard fest:

```json
{
  "defaultPort": 3001
}
```

## Ausführlicher Modus

Zeigen Sie Build-Details mit dem Flag `--verbose` an:

```bash
jamdesk dev --verbose
```

Dies zeigt:
- Erkennung von Dateiänderungen
- Build-Dauer
- Analyse der Navigation
- Warnungen oder Fehler

## Leistung beim ersten Start

<Note>
Der erste Lauf von `jamdesk dev` installiert Abhängigkeiten in `~/.jamdesk`. Das dauert 30–60 Sekunden. Spätere Läufe starten in unter 5 Sekunden.
</Note>

Leeren Sie den Cache und erzwingen Sie eine frische Installation:

```bash
jamdesk clean
jamdesk dev
```

## Fehlerbehebung

<AccordionGroup>
  <Accordion title="Port wird bereits verwendet">
    Ein anderer Prozess verwendet Port 3000.

    **Option 1:** Verwenden Sie einen anderen Port
    ```bash
    jamdesk dev --port 3001
    ```

    **Option 2:** Finden und beenden Sie den Prozess
    ```bash
    lsof -i :3000
    kill -9 <PID>
    ```
  </Accordion>

  <Accordion title="docs.json nicht gefunden">
    Führen Sie den Befehl im Verzeichnis aus, das Ihre `docs.json`-Datei enthält:

    ```bash
    ls docs.json  # Should show the file
    jamdesk dev
    ```
  </Accordion>

  <Accordion title="Änderungen werden nicht angezeigt">
    1. Prüfen Sie das Terminal auf Fehler
    2. Laden Sie den Browser hart neu (Cmd+Shift+R)
    3. Starten Sie den Dev-Server neu
    4. Führen Sie `jamdesk clean` aus und versuchen Sie es erneut
  </Accordion>

  <Accordion title="Langsamer Start">
    Diagnose ausführen:
    ```bash
    jamdesk doctor
    ```

    Es prüft Ihre Umgebung und meldet Probleme.
  </Accordion>
</AccordionGroup>
