---
title: Lokale Vorschau
description: Mit der Jamdesk CLI kannst du deine Dokumentation lokal prüfen, bevor du sie in die Produktion stellst. Änderungen werden sofort angezeigt.
---

Führe `jamdesk dev` (oder `npx jamdesk dev`) in einem beliebigen Verzeichnis aus, das eine `docs.json` enthält, um einen lokalen Server mit Hot Reload, vollständiger Suche und allen Komponenten zu starten, die exakt wie in der Produktion funktionieren.

## Voraussetzungen

Stelle vor dem Start sicher, dass Folgendes vorhanden ist:

- **Node.js 20+** – Überprüfe dies mit `node --version`
- **Ein Dokumentationsprojekt** – Mit einer `docs.json`-Konfigurationsdatei

## Dev-Server starten

<Tabs>
  <Tab title="npm (Globale Installation)">
    Installiere die CLI global und führe sie anschließend aus deinem Dokumentationsverzeichnis aus:

    ```bash
    npm install -g jamdesk
    cd your-docs
    jamdesk dev
    ```
  </Tab>
  <Tab title="npx (Keine Installation)">
    Führe den Befehl direkt aus, ohne etwas zu installieren:

    ```bash
    cd your-docs
    npx jamdesk dev
    ```
  </Tab>
</Tabs>

Deine Dokumentation ist unter **http://localhost:3000** verfügbar.

## Benutzerdefinierter Port

Der Standardport ist 3000. Wenn er bereits verwendet wird, gib einen anderen Port an:

```bash
jamdesk dev --port 3001
```

Oder lege einen dauerhaften Standardwert in `~/.jamdeskrc` fest:

```json
{
  "defaultPort": 3001
}
```

## Ausführlicher Modus

Zeige detaillierte Build-Informationen mit dem Flag `--verbose` an:

```bash
jamdesk dev --verbose
```

Dies zeigt:
- Erkennung von Dateiänderungen
- Build-Zeit
- Analyse der Navigation
- Alle Warnungen oder Fehler

## Leistung beim ersten Start

<Note>
Beim ersten Ausführen von `jamdesk dev` werden Abhängigkeiten in `~/.jamdesk` installiert. Dies dauert 30–60 Sekunden. Nachfolgende Starts erfolgen in weniger als 5 Sekunden.
</Note>

So löschst du den Cache und erzwingst eine neue Installation:

```bash
jamdesk clean
jamdesk dev
```

## Fehlerbehebung

<AccordionGroup>
  <Accordion title="Port wird bereits verwendet">
    Ein anderer Prozess verwendet Port 3000.

    **Option 1:** Verwende einen anderen Port
    ```bash
    jamdesk dev --port 3001
    ```

    **Option 2:** Finde den Prozess und beende ihn
    ```bash
    lsof -i :3000
    kill -9 <PID>
    ```
  </Accordion>

  <Accordion title="docs.json nicht gefunden">
    Stelle sicher, dass du dich in dem Verzeichnis befindest, das deine `docs.json`-Datei enthält:

    ```bash
    ls docs.json  # Should show the file
    jamdesk dev
    ```
  </Accordion>

  <Accordion title="Änderungen werden nicht angezeigt">
    Führe diese Schritte aus:
    1. Überprüfe das Terminal auf Fehler
    2. Aktualisiere den Browser vollständig (Cmd+Shift+R)
    3. Starte den Dev-Server neu
    4. Führe `jamdesk clean` aus und versuche es erneut
  </Accordion>

  <Accordion title="Langsamer Start">
    Führe eine Diagnose aus:
    ```bash
    jamdesk doctor
    ```

    Dabei werden deine Umgebung überprüft und Probleme erkannt.
  </Accordion>
</AccordionGroup>
