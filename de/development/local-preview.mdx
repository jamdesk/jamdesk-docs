Führe `jamdesk dev` (oder `npx jamdesk dev`) in einem Verzeichnis aus, das eine `docs.json` enthält. Dabei wird ein lokaler Server mit Hot Reload und Suche gestartet. Komponenten werden so dargestellt, wie in der Produktion.

## Voraussetzungen

- **Node.js 22.18+ oder 24.11+** - Prüfe es mit `node --version`
- **Ein Dokumentationsprojekt** - Mit einer `docs.json`-Konfigurationsdatei

## Dev-Server starten

<Tabs>
  <Tab title="npm (globale Installation)">
    Installiere die CLI global und führe sie anschließend in deinem Dokumentationsverzeichnis aus:

    ```bash
    npm install -g jamdesk
    cd your-docs
    jamdesk dev
    ```
  </Tab>
  <Tab title="npx (ohne Installation)">
    Führe sie direkt aus, ohne sie zu installieren:

    ```bash
    cd your-docs
    npx jamdesk dev
    ```
  </Tab>
</Tabs>

Deine Dokumentation ist dann unter **http://localhost:3000** verfügbar.

## Benutzerdefinierter Port

Der Standardport ist 3000. Mit `--port` kannst du einen anderen angeben:

```bash
jamdesk dev --port 3001
```

Oder lege einen dauerhaften Standard in `~/.jamdeskrc` fest:

```json
{
  "defaultPort": 3001
}
```

## Ausführlicher Modus

Zeige Build-Details mit dem Flag `--verbose` an:

```bash
jamdesk dev --verbose
```

Dies zeigt:
- Erkennung von Dateiänderungen
- Build-Dauer
- Analyse der Navigation
- Warnungen oder Fehler

## Leistung beim ersten Start

<Note>
Beim ersten Lauf von `jamdesk dev` werden Abhängigkeiten nach `~/.jamdesk` installiert. Das dauert 30–60 Sekunden. Spätere Starts dauern weniger als 5 Sekunden.
</Note>

Leere den Cache und erzwinge eine frische Installation:

```bash
jamdesk clean
jamdesk dev
```

## Fehlerbehebung

<AccordionGroup>
  <Accordion title="Port wird bereits verwendet">
    Ein anderer Prozess verwendet Port 3000.

    **Option 1:** Verwende einen anderen Port
    ```bash
    jamdesk dev --port 3001
    ```

    **Option 2:** Finde den Prozess und beende ihn
    ```bash
    lsof -i :3000
    kill -9 <PID>
    ```
  </Accordion>

  <Accordion title="docs.json nicht gefunden">
    Führe den Befehl in dem Verzeichnis aus, das deine `docs.json`-Datei enthält:

    ```bash
    ls docs.json  # Should show the file
    jamdesk dev
    ```
  </Accordion>

  <Accordion title="Änderungen werden nicht angezeigt">
    1. Prüfe das Terminal auf Fehler
    2. Lade den Browser hart neu (Cmd+Shift+R)
    3. Starte den Entwicklungsserver neu
    4. Führe `jamdesk clean` aus und versuche es erneut
  </Accordion>

  <Accordion title="Langsamer Start">
    Führe die Diagnose aus:
    ```bash
    jamdesk doctor
    ```

    Sie prüft deine Umgebung und meldet Probleme.
  </Accordion>
</AccordionGroup>
