Zeigen Sie eine Vorschau Ihrer Dokumentation an, ohne Visual Studio Code zu verlassen. Die Jamdesk-Erweiterung fügt eine Schaltfläche zur Statusleiste hinzu, die `jamdesk dev` startet, den Server überwacht und Ihren Browser öffnet, sobald er bereit ist. Kein Terminal erforderlich.

## Voraussetzungen

- [Jamdesk CLI](/de/cli/overview) installiert (`npm install -g jamdesk`)
- Ein Workspace mit einer Datei `docs.json`

## Erweiterung installieren

Suchen Sie im VS-Code-Bereich **Extensions** nach **Jamdesk** (`Cmd+Shift+X` unter macOS, `Ctrl+Shift+X` unter Windows/Linux) und klicken Sie auf **Install**. Alternativ können Sie die Erweiterung direkt über den [VS Code Marketplace](https://marketplace.visualstudio.com/items?itemName=Jamdesk.jamdesk) installieren.

Die Erweiterung wird automatisch aktiviert, wenn Ihr Workspace eine Datei `docs.json` enthält. In der Statusleiste wird eine Wiedergabeschaltfläche angezeigt.

## Dev-Server starten

Klicken Sie auf die Wiedergabeschaltfläche in der Statusleiste, um den Dev-Server zu starten. Die Erweiterung:

1. Startet `jamdesk dev` als untergeordneten Prozess
2. Überwacht die Ausgabe, um zu erkennen, wann der Server bereit ist
3. Öffnet Ihren Browser mit der lokalen Vorschau, sofern das automatische Öffnen aktiviert ist

Die Statusleiste zeigt den aktuellen Serverstatus an: wird gestartet, läuft oder angehalten.

## Befehle

Öffnen Sie die Command Palette (`Cmd+Shift+P` / `Ctrl+Shift+P`) und geben Sie „Jamdesk“ ein, um auf Folgendes zuzugreifen:

| Befehl | Beschreibung |
|---------|-------------|
| **Jamdesk: Start Dev Server** | Dev-Server starten |
| **Jamdesk: Stop Dev Server** | Laufenden Server stoppen |
| **Jamdesk: Restart Dev Server** | Server neu starten |
| **Jamdesk: Show Output** | CLI-Ausgabekanal anzeigen |

## Einstellungen

Konfigurieren Sie die Erweiterung in den VS-Code-Einstellungen (`Cmd+,` / `Ctrl+,`) unter **Jamdesk**:

| Einstellung | Standard | Beschreibung |
|---------|---------|-------------|
| `jamdesk.port` | `3000` | Bevorzugter Port des Dev-Servers |
| `jamdesk.verbose` | `false` | Ausführliche CLI-Ausgabe aktivieren |
| `jamdesk.clean` | `false` | Build-Cache beim nächsten Start leeren |
| `jamdesk.browserMode` | `external` | Ort zum Öffnen der Vorschau: `external` (Systembrowser) oder `embedded` (VS-Code-Seitenleiste) |
| `jamdesk.autoOpenBrowser` | `true` | Browser öffnen, sobald der Server bereit ist |

<Tip>
Setzen Sie `browserMode` auf `embedded`, um die Dokumentationsvorschau in einer VS-Code-Seitenleiste zu öffnen. So können Sie Dokumentation bearbeiten und Vorschau nebeneinander anzeigen, ohne zwischen Fenstern zu wechseln.
</Tip>

## Intelligente Portverwaltung

Wenn der bevorzugte Port bereits verwendet wird, erhöht die CLI die Portnummer automatisch auf den nächsten verfügbaren Port. Die Erweiterung erkennt den tatsächlichen Port aus der CLI-Ausgabe, sodass der Browser immer die richtige URL öffnet.

## Ausgabekanal

Die Erweiterung streamt die gesamte CLI-Ausgabe in einen dedizierten **Jamdesk**-Ausgabekanal. Öffnen Sie ihn mit dem Befehl **Jamdesk: Show Output** oder über das Dropdownmenü im Bereich Output.

Verwenden Sie ihn, um:

- den Build-Fortschritt zu überwachen
- Serverprobleme zu debuggen
- ausführliche Protokolle anzuzeigen, wenn `jamdesk.verbose` aktiviert ist
