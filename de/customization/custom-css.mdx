Jamdesk-Themes bieten sinnvolle Standardeinstellungen. Sie können jedoch eigenes CSS hinzufügen, um Ihr Branding umzusetzen oder bestimmte Stile anzupassen.

## Eigenes CSS hinzufügen

Erstellen Sie im Stammverzeichnis Ihres Projekts eine Datei namens `style.css` (im selben Ordner wie Ihre `docs.json`). Jamdesk wendet sie automatisch auf jede Seite an; ein Eintrag in `docs.json` ist nicht erforderlich.

Im Stammverzeichnis des Projekts funktioniert jede `.css`-Datei, nicht nur `style.css`. Das ist praktisch, wenn Sie von einem anderen Tool migrieren. Gibt es mehrere Dateien, kombiniert Jamdesk sie alphabetisch nach Dateiname.

Führen Sie `jamdesk dev` aus, um das Ergebnis lokal in der Vorschau anzuzeigen. Ihr eigenes CSS wird dabei genauso gerendert wie auf der veröffentlichten Website.

```css style.css
/* Your custom styles */
article h1 {
  font-size: 2.5rem;
}
```

Eine ausführlichere Anleitung zum Neufärben des Headers und Hinzufügen einer schwebenden Schaltfläche finden Sie unter [CSS- und JS-Beispiele](/de/customization/custom-code-examples).

## CSS-Variablen

Farben und Eckenradien werden über CSS-Variablen festgelegt. Überschreiben Sie sie in `:root`, und jede Komponente, die sie verwendet, übernimmt die Werte:

```css style.css
:root {
  /* Page and text colors */
  --color-bg-primary: #ffffff;      /* page background */
  --color-bg-secondary: #f8fafc;    /* inputs, subtle panels */
  --color-text-primary: #0a0a0a;    /* headings */
  --color-text-secondary: #404144;  /* body text */
  --color-text-muted: #737373;      /* captions and hints */
  --color-border: #e2e8f0;

  /* Corner radius for cards, buttons and panels */
  --radius-sm: 6px;
  --radius-md: 8px;
  --radius-lg: 12px;
}
```

Die obigen Werte sind die Standardeinstellungen des Jam-Themes. Andere Themes verwenden ihre eigenen Werte. Sie können diese in den Entwicklertools Ihres Browsers am Element `<html>` einsehen.

Ihre Markenfarben gehören in `docs.json`, nicht hierher. Jamdesk verwendet `colors.primary` als Akzentfarbe für Links, Schaltflächen und den aktiven Eintrag in der Seitenleiste. Siehe [Benutzerdefinierte Farben](/de/customization/theming#benutzerdefinierte-farben).

Auch Schriftarten gehören in `docs.json`. Das Feld `fonts` lädt eine Google Font oder Ihre eigene Schriftdatei und wendet sie überall an. Eine Angabe von `font-family` in CSS funktioniert nur mit `!important`, da Themes Schriftarten mit spezifischeren Selektoren festlegen. Siehe [Typografie](/de/customization/theming#typografie).

## Häufige Anpassungen

### Schriftart für Code ändern

Codeblöcke verwenden die Monospace-Schriftart des Themes, sofern Sie sie nicht mit `!important` überschreiben:

```css
@import url('https://fonts.googleapis.com/css2?family=Fira+Code&display=swap');

article pre,
article pre code,
article code {
  font-family: 'Fira Code', monospace !important;
  font-variant-ligatures: common-ligatures;
}
```

### Linkstile anpassen

Links im Seiteninhalt haben immer Klassen. Wählen Sie sie daher anhand ihrer Position aus und nicht mit `a:not([class])`:

```css
article .prose a {
  text-decoration: underline;
  text-underline-offset: 3px;
}

article .prose a:hover {
  text-decoration-thickness: 2px;
}
```

### Abstände bei Überschriften anpassen

```css
article .prose h2 {
  margin-top: 3rem;
  margin-bottom: 1rem;
}

article .prose h3 {
  margin-top: 2rem;
  margin-bottom: 0.75rem;
}
```

### Hinweisfelder gestalten

Hinweisfelder beziehen ihre Farben aus Variablen mit den Endungen `-bg`, `-border` und `-text`:

| Hinweisfeld | Variablenpräfix |
|---------|-----------------|
| `<Note>` | `--color-note-` |
| `<Info>` | `--color-info-` |
| `<Warning>` | `--color-warning-` |
| `<Tip>`, `<Check>` | `--color-success-` |
| `<Danger>` | `--color-error-` |

```css
/* Warmer Note callouts */
:root {
  --color-note-bg: #fef3c7;
  --color-note-border: #f59e0b;
}
```

### Aktiven Tab gestalten

```css
article [role="tab"][aria-selected="true"] {
  border-bottom-width: 3px;
}
```

## Dunkler Modus

Im dunklen Modus fügt Jamdesk die Klasse `dark` zu `<html>` hinzu. Platzieren Sie CSS-Überschreibungen für den dunklen Modus unter `html.dark`:

```css
/* Light mode */
:root {
  --color-bg-primary: #fffdf7;
}

.custom-banner {
  background: #f0f4ff;
  color: #1e3a5f;
}

/* Dark mode */
html.dark {
  --color-bg-primary: #14110f;
}

html.dark .custom-banner {
  background: #1e293b;
  color: #e2e8f0;
}
```

<Warning>
`[data-theme="dark"]` trifft nie zu. `data-theme` auf `<body>` enthält den Namen Ihres Themes (`jam`, `nebula` usw.), nicht „light“ oder „dark“.
</Warning>

## Zu verwendende Selektoren

Die Klassennamen von Jamdesk stammen aus Tailwind und können sich mit jeder Version ändern. Diese Hooks bleiben stabil:

| Selektor | Trifft zu auf |
|----------|---------|
| `html.dark` | Die Seite, wenn der dunkle Modus aktiviert ist |
| `body[data-theme="jam"]` | Das aktive Theme anhand seines Namens |
| `header[data-has-tabs]` | Den Website-Header |
| `article` | Die aktuelle Seite einschließlich ihres Titels |
| `article .prose` | Den Inhalt der Seite |
| `#content-scroll-container` | Die Inhaltsspalte der Seite |
| `[role="tab"][aria-selected="true"]` | Den ausgewählten Tab in einer `<Tabs>`-Gruppe |

## Externe Schriftarten

Laden Sie Schriftarten nach Möglichkeit über `docs.json`. Das Feld [`fonts`](/de/customization/theming#typografie) unterstützt Google Fonts und selbst gehostete Dateien, darunter `.woff2`-Dateien in Ihrem Repository, und wendet sie auf Überschriften und Fließtext an.

CSS ist die Ausweichlösung für alles, was `fonts` nicht abdeckt, etwa die obige Schriftart für Code oder eine andere Schriftart für ein einzelnes Element. Laden Sie die Schriftart mit `@import` oder `@font-face` und legen Sie sie anschließend mit `!important` fest:

```css
@font-face {
  font-family: 'CustomFont';
  src: url('/fonts/custom-font.woff2') format('woff2');
  font-weight: 400;
  font-display: swap;
}

article .prose blockquote {
  font-family: 'CustomFont', serif !important;
}
```

## Responsive Stile

Verwenden Sie Media Queries, um Stile an die Bildschirmgröße anzupassen:

```css
/* Phones */
@media (max-width: 768px) {
  article h1 {
    font-size: 1.75rem;
  }
}
```

## Fehlerbehebung

Klicken Sie mit der rechten Maustaste auf ein Element und wählen Sie **Inspect**, um herauszufinden, worauf Sie abzielen müssen. Verwenden Sie bevorzugt die Hooks unter [Zu verwendende Selektoren](#zu-verwendende-selektoren), Rollen wie `role="tab"` und CSS-Variablen statt langer Tailwind-Klassennamen. Wenn eine Regel nicht angewendet wird, prüfen Sie im Bereich **Styles**, ob eine Theme-Regel aufgrund ihrer Spezifität Vorrang hat oder `!important` verwendet.

## Einschränkungen

- CSS wird global angewendet. Verwenden Sie spezifische Selektoren, um Konflikte zu vermeiden.
- Einige Theme-Stile, darunter Schriftarten und der Hintergrund des Jam-Headers, verwenden `!important` oder sehr spezifische Selektoren. Möglicherweise benötigen Sie daher `!important`, um sie zu überschreiben.
- In der lokalen Vorschau (`jamdesk dev`) werden Änderungen an Ihren CSS-Dateien nach einer Aktualisierung des Browsers übernommen. Auf der veröffentlichten Website treten Änderungen mit dem nächsten Build in Kraft.
