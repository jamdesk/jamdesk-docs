Der Markenauftritt bestimmt den ersten visuellen Eindruck Ihrer Leser: Logos, Favicons und Navigationslinks. Alles unterstützt Varianten für den Hell- und Dunkelmodus.

## Logo

Fügen Sie Ihr Logo in den Navigationsheader ein:

```json
{
  "logo": {
    "light": "/images/logo-light.webp",
    "dark": "/images/logo-dark.webp",
    "href": "https://yourcompany.com"
  }
}
```

| Feld | Beschreibung |
|-------|-------------|
| `light` | Logo für den Hellmodus (dunkles Logo auf hellem Hintergrund) |
| `dark` | Logo für den Dunkelmodus (helles Logo auf dunklem Hintergrund) |
| `href` | Ziel, zu dem ein Klick auf das Logo führt |

<Tip>
Verwenden Sie SVG-Logos, damit sie bei jeder Größe scharf dargestellt werden. Wenn Sie nur ein Logo haben, verwenden Sie es sowohl für `light` als auch für `dark`.
</Tip>

### Abmessungen des Logos

Logos werden mit einer maximalen Breite von 120px angezeigt. Für optimale Ergebnisse:
- Breite: 120-240px
- Höhe: 30-40px
- Format: SVG empfohlen

## Favicon

Ein Bild für beide Modi:

```json
{
  "favicon": "/images/favicon.svg"
}
```

Oder eine eigene Variante für jeden Modus:

```json
{
  "favicon": {
    "light": "/images/favicon.svg",
    "dark": "/images/favicon-dark.svg"
  }
}
```

Das `light`-Favicon wird im Hellmodus angezeigt, `dark` im Dunkelmodus. `dark` ist optional. Wenn der Wert fehlt, wird `light` in beiden Modi verwendet. Jamdesk gibt für das primäre Favicon ein `<link rel="icon">` und für die dunkle Variante einen zweiten Link mit `media="(prefers-color-scheme: dark)"` aus.

Unterstützte Formate: SVG, PNG, ICO.

<Note>
Wenn Sie lieber ein einzelnes Asset verwenden, passt sich auch ein SVG, das `currentColor` für Konturen und Füllungen nutzt, automatisch an: Der Browser setzt die aktive Vordergrundfarbe ein.
</Note>

## Name der Website

Das Feld `name` wird in Browser-Tabs und Suchergebnissen angezeigt:

```json
{
  "name": "Acme Docs",
  "description": "Documentation for the Acme API"
}
```

Kombinieren Sie es mit einer [`description`](#beschreibung), damit Suchergebnisse und Linkvorschauen aussagekräftige Texte statt eines allgemeinen Standardtexts anzeigen.

## Beschreibung

Das Feld `description` ist die standardmäßige SEO-Zusammenfassung Ihrer Website. Suchmaschinen zeigen sie unter dem Titel Ihrer Website an, und soziale Plattformen verwenden sie für Linkvorschauen:

```json
{
  "description": "Build, ship, and scale documentation with the Acme platform."
}
```

Verfassen Sie einen Text mit 50 bis 160 Zeichen für Leser, die entscheiden, ob sie klicken. Seiten mit eigenem `description`-Frontmatter verwenden diesen Wert; die Website-Beschreibung gilt für alle übrigen Seiten.

## Navigationslinks

Fügen Sie Links zur Navigationsleiste hinzu:

```json
{
  "navbar": {
    "links": [
      { "label": "Blog", "href": "https://yourcompany.com/blog" },
      { "label": "Pricing", "href": "https://yourcompany.com/pricing" }
    ],
    "primary": {
      "type": "button",
      "label": "Get Started",
      "href": "https://app.yourcompany.com/signup"
    }
  }
}
```

### Linkoptionen

| Feld | Typ | Beschreibung |
|-------|------|-------------|
| `label` | string | Anzeigetext |
| `href` | string | URL (extern oder intern) |

### Primärer Button

Das Feld `primary` erstellt einen hervorgehobenen Call-to-Action-Button:

```json
{
  "primary": {
    "type": "button",
    "label": "Dashboard",
    "href": "https://app.yourcompany.com"
  }
}
```

Auf Tablets und Desktopgeräten befinden sich die Links und der primäre Button im Header. Auf Smartphones ist dort kein Platz, daher werden sie im Menü angezeigt; der primäre Button ist am unteren Rand fixiert. Pulsar zeigt weder Navigationslinks noch den primären Button an.

## Footer

Fügen Sie Ihrer Dokumentationsfußzeile Links zu sozialen Netzwerken und eigene Linkspalten hinzu.

### Social-Links

Zeigen Sie am Ende jeder Seite Symbole für soziale Netzwerke an:

```json
{
  "footer": {
    "socials": {
      "github": "https://github.com/yourcompany",
      "x": "https://x.com/yourcompany",
      "discord": "https://discord.gg/yourserver",
      "linkedin": "https://linkedin.com/company/yourcompany"
    }
  }
}
```

#### Unterstützte Plattformen

| Plattform | Schlüssel | Beschreibung |
|----------|-----|-------------|
| GitHub | `github` | Link zu Ihrer GitHub-Organisation oder Ihrem Repository |
| X (Twitter) | `x` oder `twitter` | Link zu Ihrem X-/Twitter-Profil |
| LinkedIn | `linkedin` | Link zu Ihrer LinkedIn-Unternehmensseite |
| Discord | `discord` | Link zu Ihrem Discord-Server |
| Slack | `slack` | Link zu Ihrer Slack-Community |
| YouTube | `youtube` | Link zu Ihrem YouTube-Kanal |
| Instagram | `instagram` | Link zu Ihrem Instagram-Profil |
| Facebook | `facebook` | Link zu Ihrer Facebook-Seite |
| Reddit | `reddit` | Link zu Ihrem Subreddit |
| Telegram | `telegram` | Link zu Ihrem Telegram-Kanal |
| Bluesky | `bluesky` | Link zu Ihrem Bluesky-Profil |
| Threads | `threads` | Link zu Ihrem Threads-Profil |
| Medium | `medium` | Link zu Ihrer Medium-Publikation |
| Hacker News | `hacker-news` | Link zu Ihrem Hacker-News-Profil |
| Website | `website` | Link zu Ihrer Hauptwebsite |

<Tip>
Die Symbole werden unabhängig davon, in welcher Reihenfolge Sie sie in Ihrer Konfiguration angeben, immer in derselben Reihenfolge angezeigt. GitHub und X/Twitter erscheinen zuerst, gefolgt von den anderen Plattformen.
</Tip>

### Linkspalten

Fügen Sie über den Symbolen für soziale Netzwerke übersichtlich angeordnete Linkgruppen hinzu:

```json
{
  "footer": {
    "links": [
      {
        "header": "Resources",
        "items": [
          { "label": "Blog", "href": "https://yourcompany.com/blog" },
          { "label": "Changelog", "href": "/changelog" }
        ]
      },
      {
        "header": "Company",
        "items": [
          { "label": "About", "href": "https://yourcompany.com/about" },
          { "label": "Careers", "href": "https://yourcompany.com/careers" }
        ]
      }
    ],
    "socials": {
      "github": "https://github.com/yourcompany",
      "x": "https://x.com/yourcompany"
    }
  }
}
```

| Feld | Typ | Beschreibung |
|-------|------|-------------|
| `links` | array | Array mit Linkspaltenobjekten |
| `links[].header` | string | Spaltenüberschrift (optional) |
| `links[].items` | array | Links in der Spalte |
| `links[].items[].label` | string | Anzeigetext für den Link |
| `links[].items[].href` | string | URL (interne Pfade oder externe URLs) |

<Note>
Externe Links (die mit `http` beginnen) werden automatisch in einem neuen Tab geöffnet. Interne Links führen innerhalb Ihrer Dokumentation zu einer anderen Seite.
</Note>

### Footer auf bestimmten Seiten ausblenden

Blenden Sie die Fußzeile auf einzelnen Seiten mithilfe des Frontmatters aus:

```yaml
---
title: Landing Page
hideFooter: true
---
```

Das ist nützlich für eigene Landingpages oder Seiten, auf denen die Fußzeile störend wäre.

## Jamdesk-Branding

Standardmäßig wird in der Fußzeile Ihrer Dokumentationsseiten ein Link „Powered by Jamdesk“ angezeigt. Über diesen Link können andere Teams Jamdesk entdecken. Bei Bedarf können Sie ihn entfernen.

### Branding ausblenden

So entfernen Sie den Jamdesk-Markenauftritt:

1. Öffnen Sie **Settings** in Ihrem Jamdesk-Dashboard.
2. Suchen Sie den Bereich **Build Settings**.
3. Deaktivieren Sie **Show Jamdesk Branding**.
4. Starten Sie einen neuen Build.

<Note>
Die Option zum Ausblenden des Markenauftritts ist in allen Tarifen verfügbar. Änderungen werden erst nach einem erneuten Build wirksam.
</Note>

```json
  }

```

## Benutzerdefinierte Domain

Fügen Sie Ihre Domain im Jamdesk-Dashboard hinzu:

1. Öffnen Sie **Settings** → **Domains**.
2. Fügen Sie Ihre Domain hinzu (z. B. `docs.yourcompany.com`).
3. Richten Sie DNS wie angezeigt ein.
4. Warten Sie auf die Verifizierung.

Ihre Dokumentation ist dann unter Ihrer eigenen Domain mit automatischem SSL verfügbar.
