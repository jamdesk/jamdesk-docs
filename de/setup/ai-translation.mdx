Jamdesk kann Ihre Dokumentation für Sie übersetzen. Wählen Sie die Sprachen in den Projekteinstellungen. Jamdesk übersetzt Ihre englischen Seiten nach jedem Build. Die Ergebnisse werden in sprachpräfixierten Verzeichnissen in Ihr GitHub-Repository committet. Die Übersetzungen gehören Ihnen. Sie liegen in Ihrem Repo und Ihrer Git-Historie. Bearbeiten Sie sie wie jede andere Datei.

Die Screenshots zeigen die Benutzeroberfläche auf Englisch.

Informationen zur sprachspezifischen Navigation und zum Sprachumschalter finden Sie unter [Mehrsprachige Unterstützung](/de/setup/languages). Diese Konfiguration gilt unabhängig davon, ob die Übersetzungen von Jamdesk, von Ihren eigenen Übersetzern oder von einem anderen Tool stammen.

## Voraussetzungen

- Ein [verbundenes GitHub-Repository](/de/setup/connecting-github) für das Projekt. Übersetzte Seiten werden zurück in Ihr Repo committet. Ein Projekt, das über die CLI oder ein Tarball bereitgestellt wurde, kann dies nicht nutzen.
- Schreibzugriff für die Jamdesk GitHub App, um diesen Commit durchzuführen. Das Übersetzungs-Panel weist auf fehlenden Zugriff hin und verlinkt einen GitHub-Administrator, der ihn gewähren kann. Dies ist ein einmaliger Schritt pro GitHub-Konto.

Jeder Tarif enthält automatische Übersetzung, einschließlich Testversionen. Es gibt keine Preise pro Wort und keine Credits zum Kauf.

## Aktivieren

<Steps>
  <Step title="Übersetzungs-Panel öffnen">
    Öffnen Sie Ihr Projekt im [Jamdesk-Dashboard](https://dashboard.jamdesk.com), öffnen Sie **Settings** und scrollen Sie zu **Translations**.
  </Step>

  <Step title="Sprachen auswählen">
    Aktivieren Sie **Translate my documentation** und markieren Sie die gewünschten Sprachen. Jede Sprache wird mit ihrem nativen Namen und daneben dem englischen Namen aufgelistet.

  </Step>

  <Step title="Build">
    Die Übersetzung läuft, nachdem ein Build abgeschlossen ist. Der erste Lauf übersetzt jede Seite und committet die Dateien in Ihr Repository. Prüfen Sie sie wie jeden anderen Commit.
  </Step>
</Steps>

## Einschränkungen

Limits gelten pro Projekt:

| Limit | Wert |
|-------|------|
| Sprachen pro Projekt | Bis zu 5 |
| Übersetzte Seiten pro Monat | 10.000 |

## Nur was sich geändert hat

Der erste Lauf übersetzt alles. Spätere Läufe übersetzen nur Seiten neu, deren englische Quelle sich geändert hat. Die Korrektur eines Tippfehlers auf einer Seite kostet eine Seite, nicht Ihre ganze Website. Eine stabile Website verbraucht nur einen kleinen Bruchteil des monatlichen Kontingents.

## Übersetzungen, die Jamdesk unverändert lässt

Jamdesk behandelt zwei Arten von Übersetzungen als von Ihnen verfasst. Sie werden nie automatisch ersetzt:

- **Übersetzungen, die Sie bereits hatten.** Jamdesk übernimmt übersetzte Seiten, die bereits in Ihrem Repository liegen, wenn Sie die Funktion aktivieren. Sie werden nicht überschrieben. Arbeiten, die Sie selbst geschrieben oder von einem Dienstleister bezahlt haben, bleiben unverändert.
- **Übersetzungen, die Sie bearbeiten.** Jamdesk erkennt eine übersetzte Seite, die Sie manuell ändern. Ihre Formulierungen bleiben bei jedem späteren Lauf erhalten.

Diese Seiten sind dauerhaft gesperrt. Sie werden auch dann nicht automatisch neu übersetzt, wenn sich ihre englische Quelle ändert. Sie erscheinen im Übersetzungs-Panel unter **Edited by hand**, wenn sich ihre englische Quelle ändert.

Jede dort aufgeführte Seite hat eine Schaltfläche **Replace with AI translation**. Sie übergibt die Seite wieder an die KI. Ihre Version wird verworfen. Die Seite wird bei Ihrem nächsten Build neu übersetzt, nicht im Moment des Klicks. Diese Schaltfläche ist der einzige Weg, die Sperre aufzuheben.

<Note>
  "Nur Geändertes" gilt nicht für diese Seiten. Eine von Jamdesk übersetzte Seite wird aktualisiert, wenn sich ihre englische Quelle ändert. Eine Seite, die Sie geschrieben oder bearbeitet haben, wartet, bis Sie es anfordern.
</Note>

## Links zwischen übersetzten Seiten

Übersetzte Überschriften erhalten eigene Anker, daher verwendet `/de/setup/languages#…` die deutsche Überschrift. Jamdesk hält diese Anker stabil:

- **Eine neu übersetzte Seite behält die Formulierungen der Überschriften bei, die Sie nicht geändert haben.** Fügen Sie eine englische Überschrift hinzu oder benennen Sie sie um, und nur diese Überschrift wird neu übersetzt. Links von anderen Seiten zu den übrigen Teilen der Seite landen weiterhin dort, wo sie zuvor landeten.
- **Seiten, die Sie geschrieben oder bearbeitet haben, erhalten korrigierte defekte Anker.** Wenn eine dieser Seiten auf eine Überschrift verlinkt, deren Anker sich geändert hat, aktualisiert Jamdesk den Teil des Links nach dem `#`. Sonst ändert sich auf Ihrer Seite nichts.

## Sprache deaktivieren

Entfernen Sie das Häkchen bei einer Sprache, um die Übersetzung in diese Sprache zu beenden. Nichts wird gelöscht. Bereits committete Seiten bleiben unverändert in Ihrem Repository.
