Jede Jamdesk-Website beginnt auf dieselbe Weise: mit einem Projekt im Dashboard, einem dahinterliegenden GitHub-Repository und einer `docs.json`-Datei, die Ihre Navigation beschreibt. Dieser Abschnitt behandelt diese anfängliche Einrichtung sowie strukturelle Entscheidungen, die Sie frühzeitig treffen sollten. URL-Struktur, Sprachen und Zugriffskontrolle lassen sich deutlich einfacher festlegen, bevor Sie fünfzig Seiten haben.

Sie migrieren von einer anderen Plattform? Springen Sie direkt zum [Migrationsleitfaden](/de/setup/migration). Jamdesk kann den Großteil der Konvertierung automatisieren.

## Vom Repository zur Live-Website

<Steps>
  <Step title="Projekt erstellen">
    Beginnen Sie mit einer Vorlage oder verbinden Sie ein vorhandenes GitHub-Repository. Ihre Website wird unter `yourproject.jamdesk.app` live geschaltet.
  </Step>
  <Step title="GitHub verbinden">
    Installieren Sie die GitHub-App, damit jeder Push automatisch bereitgestellt wird.
  </Step>
  <Step title="Repository organisieren">
    Eine `docs.json`-Datei und MDX-Seiten. Das ist der gesamte Vertrag.
  </Step>
</Steps>
