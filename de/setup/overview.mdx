Eine Jamdesk-Seite besteht aus einem Projekt im Dashboard, einem dahinterliegenden GitHub-Repo und einer `docs.json`-Datei, die deine Navigation beschreibt. Dieser Abschnitt behandelt dieses Setup. Lege URL-Struktur, Sprachen und Zugriffskontrolle früh fest. Sie lassen sich später nur schwer ändern, sobald du fünfzig Seiten hast.

Um von einer anderen Plattform zu wechseln, siehe den [Migrationsleitfaden](/de/setup/migration).

## Vom Repository zur Live-Website

<Steps>
  <Step title="Projekt anlegen">
    Starte mit einer Vorlage oder verbinde ein bestehendes GitHub-Repo. Deine Seite ist danach unter `yourproject.jamdesk.app` erreichbar.
  </Step>
  <Step title="GitHub verbinden">
    Installiere die GitHub-App, damit jeder Push automatisch bereitgestellt wird.
  </Step>
  <Step title="Repo organisieren">
    Füge eine `docs.json`-Datei und MDX-Seiten hinzu.
  </Step>
</Steps>
