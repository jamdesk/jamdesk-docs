Sehen Sie, wonach Leser suchen, welche Suchanfragen keine Ergebnisse liefern und auf welche Ergebnisse sie klicken.

<Info>
Suchen Sie Seitenaufrufe und Besucherdaten? Siehe [Projektanalyse](/de/setup/project-analytics).
</Info>

<Note>
Wenn Suchdaten fehlen oder verzögert angezeigt werden, siehe [Probleme mit der Analyse](/de/help/troubleshooting/analytics-issues).
</Note>

## Suchanalyse anzeigen

Greifen Sie über Ihr Projekt-Dashboard auf die Suchanalyse zu:

<Steps>
  <Step title="Projekt öffnen">
    Gehen Sie zu [dashboard.jamdesk.com](https://dashboard.jamdesk.com) und wählen Sie Ihr Projekt aus.
  </Step>

  <Step title="Search Analytics öffnen">
    Klicken Sie in der Seitenleiste unter **Analytics** auf **Search**, um Ihr Such-Dashboard anzuzeigen.
  </Step>

  <Step title="Datumsbereich auswählen">
    Verwenden Sie die Datumsauswahl, um Suchdaten für verschiedene Zeiträume anzuzeigen. Standardmäßig sind 30 Tage ausgewählt.
  </Step>
</Steps>

## Wichtige Kennzahlen

Das Suchanalyse-Dashboard zeigt vier zentrale Kennzahlen:

| Kennzahl | Beschreibung |
|--------|-------------|
| **Total Searches** | Anzahl der im ausgewählten Zeitraum durchgeführten Suchen |
| **Unique Queries** | Unterschiedliche verwendete Suchbegriffe |
| **Zero Results** | Suchen, die keine Treffer geliefert haben |
| **Click-through Rate** | Prozentsatz der Suchen, bei denen Nutzer auf ein Ergebnis geklickt haben |

Jede Kennzahl enthält einen Vergleich mit dem vorherigen Zeitraum, dargestellt als prozentuale Änderung.

Beispielauszug:

```json
{
  "period": "Last 30 days",
  "total_searches": 940,
  "unique_queries": 312,
  "zero_results": 42,
  "top_queries": [
    { "query": "authentication", "searches": 84, "ctr": 0.82 },
    { "query": "api keys", "searches": 63, "ctr": 0.71 }
  ]
}
```

## Suchvolumen

Das Diagramm zum Suchvolumen zeigt die tägliche Suchaktivität über den ausgewählten Zeitraum. Verwenden Sie es, um:

- Nutzungsmuster zu erkennen (Suchverkehr an Wochentagen im Vergleich zum Wochenende)
- Ungewöhnliche Spitzen zu erkennen, die auf externe Links oder Ankündigungen hindeuten können
- Das Wachstum der Dokumentationsnutzung im Zeitverlauf zu verfolgen

## Aufschlüsselung der Suchanfragen

### Häufigste Suchanfragen

Sehen Sie die häufigsten Suchbegriffe, die Nutzer eingeben. Daraus lassen sich folgende Erkenntnisse ableiten:

- **Beliebte Themen** – Was Nutzer am häufigsten benötigen
- **Navigationsprobleme** – Ob Nutzer nach Dingen suchen, die leicht in der Navigation zu finden sind
- **Lücken bei der Terminologie** – Ob Nutzer andere Begriffe als Ihre Dokumentation verwenden

Für jede Suchanfrage sehen Sie:
- Anzahl der Suchen
- Anzahl der Klicks auf Ergebnisse
- Click-through-Rate (CTR)

### Inhaltslücken

<Warning>
Inhaltslücken sind Suchanfragen, die keine Ergebnisse geliefert haben. Jede davon weist auf ein Thema hin, das Ihre Dokumentation noch nicht abdeckt.
</Warning>

Der Tab **Content Gaps** zeigt Suchanfragen, bei denen Nutzer gesucht, aber nichts gefunden haben. Häufige Ursachen:

| Ursache | Lösung |
|-------|----------|
| Fehlende Dokumentation | Erstellen Sie eine neue Seite, die das Thema behandelt |
| Andere Terminologie | Fügen Sie Synonyme hinzu oder aktualisieren Sie Überschriften |
| Tippfehler im Inhalt | Korrigieren Sie die Rechtschreibung in Ihrer Dokumentation |
| Funktion noch nicht dokumentiert | Nehmen Sie die Funktion in Ihre Dokumentations-Roadmap auf |

Überprüfen Sie Inhaltslücken regelmäßig. Der Abschnitt „Bewährte Vorgehensweisen“ weiter unten empfiehlt einen wöchentlichen Rhythmus.

## Erkenntnisse zur Suche

Das Analysefenster liefert schnelle Antworten:

| Erkenntnis | Bedeutung |
|---------|---------------|
| **Avg. Click Position** | Wie weit unten in den Ergebnissen Nutzer normalerweise klicken (niedriger ist besser) |
| **Searches per Day** | Durchschnittliches tägliches Suchvolumen |
| **Top Query** | Ihr häufigster Suchbegriff |
| **Most Missed** | Die häufigste Suchanfrage ohne Ergebnisse, die Sie bearbeiten sollten |

## Bewährte Vorgehensweisen

<Accordion title="Inhaltslücken wöchentlich überprüfen">
Legen Sie eine wiederkehrende Aufgabe zur Überprüfung von Suchen ohne Ergebnisse fest. Schon wenige Minuten pro Woche verhindern, dass sich Dokumentationsrückstände ansammeln.
</Accordion>

<Accordion title="Natürliche Sprache in Überschriften verwenden">
Nutzer suchen häufig mit natürlichen Formulierungen. Wenn Ihre Überschriften der Denkweise der Nutzer entsprechen, finden sie Inhalte schneller.
</Accordion>

<Accordion title="Wichtigen Seiten Synonyme hinzufügen">
Wenn Nutzer nach „setup“ suchen, Ihre Seite aber „installation“ heißt, sollten Sie beide Begriffe in Ihrem Inhalt erwähnen, damit die Suche die Seite findet.
</Accordion>

<Accordion title="CTR-Verbesserungen verfolgen">
Überwachen Sie nach der Behebung von Inhaltslücken, ob sich die Click-through-Raten verbessern. Eine niedrige CTR bei Suchanfragen mit hohem Volumen weist darauf hin, dass die Ergebnisse nicht zur Suchabsicht passen.
</Accordion>

## Suchqualität

Jamdesk berechnet einen Suchqualitätswert basierend auf der Click-through-Rate:

``` text
Score = (Searches with clicks / Total searches) × 100
```

| Wert | Bewertung |
|-------|--------|
| 90 %+ | Hervorragend |
| 70–89 % | Gut |
| 50–69 % | Verbesserungsbedarf |
| Unter 50 % | Schwach |

## Datenexport

Exportieren Sie Suchdaten für eine weitere Analyse:

1. Gehen Sie zu **Analytics** → **Search**
2. Klicken Sie auf **Export**
3. Wählen Sie das CSV- oder JSON-Format

## Datenverfügbarkeit

Daten zur Suchanalyse werden angezeigt, nachdem die tägliche Zusammenfassung um 2 Uhr UTC ausgeführt wurde. Suchen, die heute durchgeführt werden, erscheinen morgen im Dashboard.

<Note>
Wenn Sie Ihre Dokumentation gerade eingerichtet haben, warten Sie 24–48 Stunden, bis sich Suchdaten angesammelt haben und aussagekräftige Erkenntnisse verfügbar sind.
</Note>
