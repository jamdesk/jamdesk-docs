Sehen Sie, wonach Leser suchen, welche Suchanfragen keine Ergebnisse liefern und worauf sie klicken.

<Info>
Für Seitenaufrufe und Besucherdaten siehe [Projektanalysen](/de/setup/project-analytics).
</Info>

<Note>
Wenn Suchdaten fehlen oder verzögert sind, siehe [Probleme mit der Analyse](/de/help/troubleshooting/analytics-issues).
</Note>

## Suchanalyse anzeigen

<Steps>
  <Step title="Öffnen Sie Ihr Projekt">
    Rufen Sie [dashboard.jamdesk.com](https://dashboard.jamdesk.com) auf und wählen Sie Ihr Projekt aus.
  </Step>

  <Step title="Klicken Sie auf Search Analytics">
    Klicken Sie in der Seitenleiste unter **Analytics** auf **Search**.
  </Step>

  <Step title="Wählen Sie einen Zeitraum">
    Wählen Sie mit dem Datumsauswahlfeld einen Zeitraum. Der Standard ist 30 Tage.
  </Step>
</Steps>

## Wichtige Kennzahlen

| Kennzahl | Beschreibung |
|--------|-------------|
| **Total Searches** | Anzahl der Suchanfragen im ausgewählten Zeitraum |
| **Unique Queries** | Anzahl unterschiedlicher Suchbegriffe |
| **Zero Results** | Suchanfragen ohne Treffer |
| **Click-through Rate** | Prozentsatz der Suchanfragen, bei denen ein Ergebnis angeklickt wurde |

Jede Kennzahl zeigt die prozentuale Veränderung gegenüber dem vorherigen Zeitraum.

Beispiel-Snapshot:

```json
{
  "period": "Last 30 days",
  "total_searches": 940,
  "unique_queries": 312,
  "zero_results": 42,
  "top_queries": [
    { "query": "authentication", "searches": 84, "ctr": 0.82 },
    { "query": "api keys", "searches": 63, "ctr": 0.71 }
  ]
}
```

## Suchvolumen

Das Diagramm zum Suchvolumen zeigt die täglichen Suchanfragen im ausgewählten Zeitraum. Verwenden Sie es, um:

- Muster an Wochentagen und Wochenenden zu erkennen
- Spitzen durch externe Links oder Ankündigungen zu erkennen
- Wachstum über die Zeit zu verfolgen

## Aufschlüsselung der Suchanfragen

### Häufigste Suchanfragen

Die häufigsten Suchbegriffe zeigen:

- **Beliebte Themen:** was Leser am häufigsten brauchen
- **Navigationsprobleme:** Suchen nach Seiten, die bereits in der Navigation enthalten sind
- **Terminologielücken:** Begriffe, die von denen in Ihrer Dokumentation abweichen

Jede Abfrage zeigt:
- Anzahl der Suchanfragen
- Anzahl der Klicks auf Ergebnisse
- Click-through-Rate (CTR)

### Inhaltslücken

<Warning>
Inhaltslücken sind Suchanfragen ohne Treffer. Jede davon ist ein Thema, das Ihre Dokumentation noch nicht abdeckt.
</Warning>

Der Tab „Content Gaps“ listet Abfragen auf, die nichts gefunden haben. Häufige Ursachen:

| Ursache | Lösung |
|-------|----------|
| Fehlende Dokumentation | Eine neue Seite zum Thema erstellen |
| Abweichende Terminologie | Synonyme ergänzen oder Überschriften anpassen |
| Tippfehler im Inhalt | Rechtschreibung in Ihrer Dokumentation korrigieren |
| Funktion noch nicht dokumentiert | Zur Dokumentations-Roadmap hinzufügen |

## Erkenntnisse zur Suche

| Einblick | Bedeutung |
|---------|---------------|
| **Avg. Click Position** | Durchschnittliche Position des angeklickten Ergebnisses (niedriger ist besser) |
| **Searches per Day** | Durchschnittliches tägliches Suchvolumen |
| **Top Query** | Ihr häufigster Suchbegriff |
| **Most Missed** | Die wichtigste Suchanfrage ohne Treffer, die Sie angehen sollten |

## Bewährte Vorgehensweisen

<Accordion title="Inhaltslücken wöchentlich prüfen">
Richten Sie eine wiederkehrende Aufgabe ein, um Suchanfragen ohne Treffer zu prüfen.
</Accordion>

<Accordion title="Natürliche Sprache in Überschriften verwenden">
Leser suchen mit natürlichen Formulierungen. Schreiben Sie Überschriften, die dazu passen.
</Accordion>

<Accordion title="Synonyme auf wichtigen Seiten ergänzen">
Wenn Leser nach „setup“ suchen, Ihre Seite aber „installation“ heißt, erwähnen Sie „setup“ auf der Seite.
</Accordion>

<Accordion title="CTR-Verbesserungen verfolgen">
Beobachten Sie die Click-through-Raten nach der Behebung von Inhaltslücken. Eine niedrige CTR bei stark nachgefragten Suchbegriffen bedeutet, dass die Ergebnisse nicht dem entsprechen, was Leser wollen.
</Accordion>

## Suchqualität

Jamdesk berechnet einen Such-Qualitätswert auf Basis der Click-through-Rate:

``` text
Score = (Searches with clicks / Total searches) × 100
```

| Wert | Bewertung |
|-------|--------|
| 90%+ | Ausgezeichnet |
| 70-89% | Gut |
| 50-69% | Verbesserungsbedarf |
| Unter 50% | Schlecht |

## Datenexport

1. Gehen Sie zu **Analytics** → **Search**
2. Klicken Sie auf **Export**
3. Wählen Sie das Format CSV oder JSON

## Datenverfügbarkeit

Suchdaten erscheinen nach der täglichen Zusammenfassung um 2 Uhr UTC. Die heutigen Suchanfragen erscheinen morgen.

<Note>
Neue Websites benötigen 24–48 Stunden Suchdaten, bevor die Zahlen aussagekräftig sind.
</Note>
