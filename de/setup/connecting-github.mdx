## GitHub-App installieren

Wenn du dich zum ersten Mal bei Jamdesk anmeldest, wirst du aufgefordert, die Jamdesk GitHub App zu installieren. Diese App ermöglicht:

- **Repository-Zugriff** - Deine Dokumentationsinhalte lesen
- **Webhooks** - Builds bei Pushes auslösen
- **Commit-Status** - Build-Status für Commits anzeigen

### Berechtigungen

Die Jamdesk GitHub App fordert folgende Berechtigungen an:

| Berechtigung | Zweck |
|------------|---------|
| Repository-Inhalte (Lesen und Schreiben) | Deine Dokumentationsdateien klonen und lesen. Schreibvorgänge erfolgen nur, wenn du im Dashboard-Editor speicherst, Vorschläge von Fix with AI annimmst oder die Übersetzung aktivierst |
| Metadaten (Lesen) | Repositorys und Branches auflisten |
| Webhooks | Push-Benachrichtigungen empfangen |

<Note>
Jamdesk greift nur auf Repositorys zu, für die du ausdrücklich Zugriff gewährt hast. Du kannst den Zugriff jederzeit in deinen GitHub-Einstellungen ändern.
</Note>

## Repository verbinden

<Steps>
  <Step title="Repository auswählen">
    Klicke beim Erstellen oder Bearbeiten eines Projekts auf **Connect Repository**.

    Wähle eines der Repositorys aus, in denen die GitHub App installiert ist.
  </Step>

  <Step title="Branch auswählen">
    Wähle den Branch aus, der bereitgestellt werden soll:

    - **main** oder **master** - Am häufigsten für Produktionsdokumentation
    - **docs** - Wenn du die Dokumentation in einem separaten Branch verwaltest
    - Ein beliebiger Branch - Für Vorschau-Bereitstellungen
  </Step>

  <Step title="Dokumentationspfad angeben">
    Wenn sich deine `docs.json` nicht im Stammverzeichnis des Repositorys befindet, gib den Pfad an:

    ```bash
    docs/           # Docs in a subdirectory
    packages/docs/  # Monorepo with docs package
    ```

    Lass das Feld leer, wenn sich `docs.json` im Stammverzeichnis befindet.
  </Step>
</Steps>

Nach der Verbindung zeigt dein Projekt-Dashboard das verknüpfte Repository und den Branch an:

## Automatische Bereitstellungen

Nach der Verbindung löst jeder Push zu deinem konfigurierten Branch einen Build aus:

```bash
git add .
git commit -m "Update API documentation"
git push origin main
```

Builds sind in der Regel in 30–90 Sekunden abgeschlossen. Sieh dir den Status im Dashboard oder beim GitHub-Commit an.

## Repositories ändern

So verbindest du ein anderes Repository:

1. Gehe zu **Settings** → **Repository**
2. Klicke auf **Change Repository**
3. Wähle das neue Repository und den Branch aus

<Warning>
Ein Repository-Wechsel kann sich auf deine veröffentlichte Dokumentation auswirken. Das neue Repository muss eine gültige Jamdesk-Konfiguration enthalten.
</Warning>

## Zugriff auf die GitHub-App verwalten

Lege fest, auf welche Repositorys Jamdesk zugreifen kann:

1. Gehe zu [github.com/settings/installations](https://github.com/settings/installations)
2. Suche **Jamdesk** in der Liste
3. Klicke auf **Configure**
4. Wähle unter „Repository access“ bestimmte Repositorys oder alle aus

### Organisations-Repositories

Bei Organisations-Repositorys muss ein Organisationsadministrator die Installation der GitHub App genehmigen:

1. Fordere die Installation über dein Jamdesk-Dashboard an
2. Ein Administrator erhält eine Benachrichtigung in GitHub
3. Nach der Genehmigung werden Organisations-Repositorys in der Repository-Auswahl angezeigt

## Persönliches Konto verknüpfen

Für eine zuverlässige Build-Zuordnung verknüpfst du dein persönliches GitHub-Konto unter **User Settings**:

1. Klicke auf deinen Avatar → **User Settings**
2. Suche den Abschnitt **GitHub Account**
3. Klicke auf **Link GitHub Account**

Dies ist unabhängig von der GitHub App und stellt sicher, dass deine Commits korrekt dir zugeordnet werden. [Weitere Informationen](/de/integrations/github#persönliches-github-konto-benutzerebene).

## Fehlerbehebung

### Repository wird nicht angezeigt

- Prüfe, ob die GitHub App im Repository installiert ist
- Vergewissere dich bei Organisations-Repositorys, dass ein Administrator den Zugriff genehmigt hat
- Aktualisiere die Repository-Liste im Dashboard

### GitHub leitet dich immer wieder zur Jamdesk-App-Seite zurück

Wahrscheinlich verwaltet dein Unternehmen dein GitHub-Konto. GitHub erlaubt es solchen Konten nicht, Apps im eigenen Konto zu installieren. Unter [Unternehmensverwaltete GitHub-Konten](/de/help/troubleshooting/github-issues#von-unternehmen-verwaltete-github-konten) erfährst du, wie du das Problem behebst.

### Builds werden nicht ausgelöst

- Prüfe, ob der Webhook in den Repository-Einstellungen aktiv ist
- Vergewissere dich, dass du Änderungen zum konfigurierten Branch pushst
- Suche in GitHub nach Fehlern bei der Webhook-Zustellung

### Fehler wegen verweigerter Berechtigung

- Autorisiere die GitHub App in deinen GitHub-Einstellungen erneut
- Vergewissere dich, dass die Jamdesk App auf das Repository zugreifen kann

<Note>
  Ausführlichere Hinweise zur Fehlerbehebung findest du unter [GitHub-Integration verstehen](/de/integrations/github).
</Note>
