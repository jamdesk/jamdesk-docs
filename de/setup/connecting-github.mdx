## GitHub-App installieren

Jamdesk fordert dich bei deiner ersten Anmeldung auf, die Jamdesk GitHub App zu installieren. Die App erhält folgende Berechtigungen:

- **Repositoryzugriff**: Inhalte deiner Dokumentation lesen
- **Webhooks**: Builds bei Pushes auslösen
- **Commit-Status**: Build-Status für Commits anzeigen

### Berechtigungen

Die Jamdesk GitHub App fordert folgende Berechtigungen an:

| Berechtigung | Zweck |
|------------|---------|
| Repository-Inhalte (Lesen und Schreiben) | Dokumentationsdateien klonen und lesen. Schreibvorgänge erfolgen nur, wenn du im Dashboard-Editor speicherst, Vorschläge von Fix with AI annimmst oder die Übersetzung aktivierst |
| Metadaten (Lesen) | Repositories und Branches auflisten |
| Webhooks | Push-Benachrichtigungen empfangen |

<Note>
Jamdesk greift nur auf Repositories zu, für die du ausdrücklich Zugriff gewährst. Du kannst den Zugriff jederzeit in deinen GitHub-Einstellungen ändern.
</Note>

## Repository verbinden

<Steps>
  <Step title="Repository auswählen">
    Klicke beim Erstellen oder Bearbeiten eines Projekts auf **Connect Repository**.

    Wähle eines der Repositories aus, auf denen die GitHub App installiert ist.
  </Step>

  <Step title="Branch auswählen">
    Wähle den Branch aus, der bereitgestellt werden soll:

    - **main** oder **master**: am häufigsten für Produktionsdokumentation
    - **docs**: wenn du die Dokumentation in einem separaten Branch verwaltest
    - Beliebiger Branch: für Vorschau-Bereitstellungen
  </Step>

  <Step title="Dokumentationspfad angeben">
    Wenn sich deine `docs.json` nicht im Stammverzeichnis des Repositories befindet, gib den Pfad an:

    ```bash
    docs/           # Docs in a subdirectory
    packages/docs/  # Monorepo with docs package
    ```

    Lass das Feld leer, wenn sich `docs.json` im Stammverzeichnis befindet.
  </Step>
</Steps>

Im Projekt-Dashboard werden anschließend das verknüpfte Repository und der Branch angezeigt:

## Automatische Bereitstellungen

Jeder Push an deinen konfigurierten Branch löst einen Build aus:

```bash
git add .
git commit -m "Update API documentation"
git push origin main
```

Builds sind in der Regel in 30–90 Sekunden abgeschlossen. Den Status findest du im Dashboard oder beim GitHub-Commit.

## Repositories ändern

So verbindest du ein anderes Repository:

1. Gehe zu **Settings** → **Repository**
2. Klicke auf **Change Repository**
3. Wähle das neue Repository und den Branch aus

<Warning>
Ein Repositorywechsel kann sich auf deine Live-Dokumentation auswirken. Das neue Repository muss eine gültige Jamdesk-Konfiguration enthalten.
</Warning>

## Zugriff auf die GitHub-App verwalten

Lege fest, auf welche Repositories Jamdesk zugreifen kann:

1. Gehe zu [github.com/settings/installations](https://github.com/settings/installations)
2. Suche in der Liste nach **Jamdesk**
3. Klicke auf **Configure**
4. Wähle unter „Repository access“ bestimmte oder alle Repositories aus

### Organisations-Repositories

Ein Organisationsadministrator muss die Installation der GitHub App für Organisations-Repositories genehmigen:

1. Fordere die Installation über dein Jamdesk-Dashboard an
2. Ein Administrator erhält eine Benachrichtigung in GitHub
3. Nach der Genehmigung erscheinen die Organisations-Repositories in der Repository-Auswahl

## Persönliches Konto verknüpfen

Verknüpfe dein persönliches GitHub-Konto unter **User Settings**, damit Builds zuverlässig dir zugeordnet werden:

1. Klicke auf deinen Avatar → **User Settings**
2. Suche den Abschnitt **GitHub Account**
3. Klicke auf **Link GitHub Account**

Diese Verknüpfung ist unabhängig von der GitHub App. Sie ordnet deine Commits dir zu. [Weitere Informationen](/de/integrations/github#persönliches-github-konto-benutzerebene).

## Fehlerbehebung

### Repository wird nicht angezeigt

- Prüfe, ob die GitHub App im Repository installiert ist
- Vergewissere dich bei Organisations-Repositories, dass ein Administrator den Zugriff genehmigt hat
- Aktualisiere die Repository-Liste im Dashboard

### GitHub leitet dich immer wieder zur Jamdesk-App-Seite zurück

Wahrscheinlich verwaltet dein Unternehmen dein GitHub-Konto. GitHub erlaubt diesen Konten nicht, Apps für das eigene Konto zu installieren. Unter [Unternehmensverwaltete GitHub-Konten](/de/help/troubleshooting/github-issues#von-unternehmen-verwaltete-github-konten) erfährst du, wie du das Problem behebst.

### Builds werden nicht ausgelöst

- Prüfe, ob der Webhook in den Repository-Einstellungen aktiv ist
- Vergewissere dich, dass du an den konfigurierten Branch pushst
- Suche in GitHub nach Fehlern bei der Webhook-Zustellung

### Fehler wegen verweigerter Berechtigung

- Autorisiere die GitHub App in deinen GitHub-Einstellungen erneut
- Prüfe, ob die Jamdesk App auf das Repository zugreifen kann

<Note>
  Ausführlichere Hinweise zur Fehlerbehebung findest du unter [GitHub-Integration verstehen](/de/integrations/github).
</Note>
