## GitHub-App installieren

Wenn du dich zum ersten Mal bei Jamdesk anmeldest, wirst du aufgefordert, die Jamdesk-GitHub-App zu installieren. Diese App ermöglicht:

- **Repository-Zugriff** – Deine Dokumentationsinhalte lesen
- **Webhooks** – Builds bei Pushes auslösen
- **Commit-Status** – Build-Status für Commits anzeigen

### Berechtigungen

Die Jamdesk-GitHub-App fordert folgende Berechtigungen an:

| Berechtigung | Zweck |
|------------|---------|
| Repository-Inhalte (Lesen) | Deine Dokumentationsdateien klonen und lesen |
| Metadaten (Lesen) | Repositories und Branches auflisten |
| Webhooks | Push-Benachrichtigungen empfangen |

<Note>
Jamdesk greift nur auf Repositories zu, für die du ausdrücklich Zugriff gewährst. Du kannst den Zugriff jederzeit in deinen GitHub-Einstellungen ändern.
</Note>

## Repository verbinden

<Steps>
  <Step title="Repository auswählen">
    Klicke beim Erstellen oder Bearbeiten eines Projekts auf **Connect Repository**.

    Wähle ein Repository aus, in dem die GitHub-App installiert ist.
  </Step>

  <Step title="Branch auswählen">
    Wähle den bereitzustellenden Branch aus:

    - **main** oder **master** – Am häufigsten für Produktionsdokumentation
    - **docs** – Wenn du die Dokumentation in einem separaten Branch speicherst
    - Beliebiger Branch – Für Vorschau-Bereitstellungen
  </Step>

  <Step title="Dokumentationspfad angeben">
    Wenn sich deine `docs.json` nicht im Repository-Stammverzeichnis befindet, gib den Pfad an:

    ```bash
    docs/           # Docs in a subdirectory
    packages/docs/  # Monorepo with docs package
    ```

    Lass das Feld leer, wenn sich `docs.json` im Stammverzeichnis befindet.
  </Step>
</Steps>

Nach der Verbindung zeigt dein Projekt-Dashboard das verknüpfte Repository und den Branch an:

## Automatische Bereitstellungen

Nach der Verbindung löst jeder Push auf deinen konfigurierten Branch einen Build aus:

```bash
git add .
git commit -m "Update API documentation"
git push origin main
```

Builds sind normalerweise innerhalb von 30–90 Sekunden abgeschlossen. Du kannst den Status im Dashboard oder beim GitHub-Commit anzeigen.

## Repositories ändern

So verbindest du ein anderes Repository:

1. Gehe zu **Settings** → **Repository**
2. Klicke auf **Change Repository**
3. Wähle das neue Repository und den Branch aus

<Warning>
Das Ändern von Repositories kann sich auf deine live geschaltete Dokumentation auswirken. Das neue Repository muss eine gültige Jamdesk-Konfiguration enthalten.
</Warning>

## Zugriff auf die GitHub-App verwalten

Lege fest, auf welche Repositories Jamdesk zugreifen kann:

1. Gehe zu [github.com/settings/installations](https://github.com/settings/installations)
2. Suche **Jamdesk** in der Liste
3. Klicke auf **Configure**
4. Wähle unter „Repository access“ bestimmte Repositories oder alle Repositories aus

### Organisations-Repositories

Bei Organisations-Repositories muss ein Organisationsadministrator die Installation der GitHub-App genehmigen:

1. Fordere die Installation über dein Jamdesk-Dashboard an
2. Ein Administrator erhält eine Benachrichtigung in GitHub
3. Nach der Genehmigung werden Organisations-Repositories in der Repository-Auswahl angezeigt

## Persönliches Konto verknüpfen

Für eine zuverlässige Zuordnung von Builds verknüpfst du dein persönliches GitHub-Konto in den **User Settings**:

1. Klicke auf deinen Avatar → **User Settings**
2. Suche den Abschnitt **GitHub Account**
3. Klicke auf **Link GitHub Account**

Dies ist unabhängig von der GitHub-App und stellt sicher, dass deine Commits korrekt dir zugeordnet werden. [Mehr erfahren](/de/integrations/github#persönliches-github-konto-benutzerebene).

## Fehlerbehebung

### Repository wird nicht angezeigt

- Überprüfe, ob die GitHub-App im Repository installiert ist
- Stelle bei Organisations-Repositories sicher, dass ein Administrator den Zugriff genehmigt hat
- Aktualisiere die Repository-Liste im Dashboard

### GitHub leitet dich immer wieder zur Jamdesk-App-Seite zurück

Dein Unternehmen verwaltet wahrscheinlich dein GitHub-Konto, und GitHub erlaubt es solchen Konten nicht, Apps auf eigene Faust zu installieren. Siehe [unternehmensverwaltete GitHub-Konten](/de/help/troubleshooting/github-issues#von-unternehmen-verwaltete-github-konten), um das Problem zu beheben.

### Builds werden nicht ausgelöst

- Überprüfe, ob der Webhook in den Repository-Einstellungen aktiv ist
- Stelle sicher, dass du auf den konfigurierten Branch pushst
- Suche in GitHub nach Fehlern bei der Webhook-Zustellung

### Fehler wegen verweigerter Berechtigung

- Autorisiere die GitHub-App in deinen GitHub-Einstellungen erneut
- Stelle sicher, dass auf das Repository über die Jamdesk-App zugegriffen werden kann

<Note>
  Eine ausführlichere Fehlerbehebung findest du unter [GitHub-Integration verstehen](/de/integrations/github).
</Note>
