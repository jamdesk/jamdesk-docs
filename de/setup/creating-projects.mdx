Bevor Sie Dokumentation schreiben, benötigen Sie ein Projekt. Starten Sie mit einer Vorlage, damit Jamdesk das Repository auf GitHub oder Bitbucket Cloud erstellt. Alternativ verbinden Sie ein bestehendes Repository, das bereits eine `docs.json` enthält. Ihre Seite ist innerhalb weniger Minuten online.

## Ein neues Projekt erstellen

<Steps>
  <Step title="Bei Jamdesk anmelden">
    Rufen Sie [dashboard.jamdesk.com](https://dashboard.jamdesk.com) auf und melden Sie sich mit Ihrem GitHub-Konto an.

    Bei der ersten Anmeldung fordert Jamdesk Sie auf, die Jamdesk-GitHub-App zu autorisieren.
  </Step>

  <Step title="Auf New Project klicken">
    Klicken Sie im Dashboard oben rechts auf **New Project**.
  </Step>

  <Step title="Einen Ausgangspunkt wählen">
    <Tabs>
      <Tab title="From Template">
        Starten Sie mit einer vorgefertigten Vorlage. Jamdesk erstellt ein neues GitHub-Repository mit Beispielinhalten, Navigation und bereits konfigurierten Komponenten.

        Die Standardvorlage [Starter Template](https://github.com/jamdesk/starter-docs) enthält Beispielseiten, eine OpenAPI-Spezifikation und Beispiele für jede Komponente. Ersetzen Sie die Inhalte durch Ihre eigenen.
      </Tab>
      <Tab title="From Repository">
        Verbinden Sie ein bestehendes GitHub-Repository:

        1. Wählen Sie das Repository aus dem Dropdown-Menü
        2. Wählen Sie den Branch für das Deployment (meist `main`)
        3. Geben Sie den Pfad zu `docs.json` an, falls sie nicht im Stammverzeichnis liegt

        Repository auf Bitbucket Cloud? Geben Sie es stattdessen als `workspace/repository-slug` ein. Siehe [Bitbucket verbinden](/de/setup/connecting-bitbucket).
      </Tab>
    </Tabs>
  </Step>

  <Step title="Projekteinstellungen konfigurieren">
    Legen Sie die Grundinformationen Ihres Projekts fest:

    | Field | Description |
    |-------|-------------|
    | **Name** | Anzeigename im Dashboard |
    | **Slug** | URL-freundlicher Bezeichner (z. B. `my-docs`) |
    | **Domain** | Ihre `*.jamdesk.app`-Subdomain |
  </Step>
</Steps>

## Minimale Repository-Struktur

Ein Jamdesk-Projekt benötigt nur eine `docs.json` und mindestens eine Seite:

```bash
my-docs/
├── docs.json
└── introduction.mdx
```

Beispiel für `docs.json`:

```json docs.json
{
  "$schema": "https://jamdesk.com/docs.json",
  "name": "My Docs",
  "theme": "jam",
  "navigation": {
    "groups": [
      {
        "group": "Getting Started",
        "pages": ["introduction"]
      }
    ]
  }
}
```

## Projekteinstellungen

Konfigurieren Sie Ihr Projekt unter **Settings**:

### Allgemein

- **Name**: Anzeigenamen aktualisieren
- **Slug**: Projektbezeichner ändern
- **Delete Project**: Projekt dauerhaft entfernen

### Repository

- **Branch**: Branch, der Deployments auslöst
- **Docs Path**: Speicherort von `docs.json` für Monorepos

### Domain

- **Subdomain**: Ihre `*.jamdesk.app`-URL
- **Custom Domain**: Eigene Domain hinzufügen
- **Host at a subpath**: Dokumentation unter einem Pfad wie `/docs` oder `/help` statt im Stammverzeichnis bereitstellen

### Build

- **Show Jamdesk Branding**: Den Link „Powered by Jamdesk“ in Ihrer Fußzeile anzeigen (standardmäßig aktiviert)
- **Rebuild**: Einen neuen Build manuell auslösen

<Note>
Änderungen an den Build-Einstellungen werden erst mit einem neuen Build wirksam.
</Note>

## Projektlimits

Der Pro-Tarif umfasst ein Projekt. Weitere können Sie mit [Projekt-Add-ons](/de/help/billing/project-addons) für jeweils 15 $/Monat hinzufügen.
