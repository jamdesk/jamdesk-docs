Projekt-Add-ons erhöhen die Anzahl der Dokumentationsprojekte in Ihrem Tarif.

## Funktionsweise von Add-ons

Der Pro-Tarif umfasst ein Projekt. Jedes zusätzliche Projekt kostet 15 $/Monat bzw. 150 $/Jahr bei jährlicher Abrechnung.

## Projekte hinzufügen

<Steps>
  <Step title="Zur Abrechnung wechseln">
    Gehen Sie zu **Settings** → **Billing**.
  </Step>
  <Step title="Auf „Add Projects“ klicken">
    Wählen Sie **Add project slots** aus.
  </Step>
  <Step title="Anzahl auswählen">
    Wählen Sie aus, wie viele zusätzliche Projekte Sie benötigen.
  </Step>
  <Step title="Bestätigen">
    Prüfen Sie die aktualisierte Summe und bestätigen Sie.
  </Step>
</Steps>

Add-ons werden anteilig berechnet. Sie zahlen nur für die verbleibenden Tage Ihres Abrechnungszeitraums.

## Projekte entfernen

1. Löschen Sie Projekte, bis Sie die gewünschte Anzahl erreicht haben
2. Gehen Sie zu **Settings** → **Billing**
3. Klicken Sie auf **Manage add-ons**
4. Reduzieren Sie die Anzahl der zusätzlichen Slots
5. Bestätigen Sie die Änderung

<Warning>
Sie können die Anzahl nicht unter die Zahl der aktiven Projekte senken. Löschen Sie zuerst Projekte.
</Warning>

## Abrechnung von Add-ons

- Add-ons erscheinen als eigene Position auf den Rechnungen
- Bei einer Erweiterung mitten im Abrechnungszeitraum fallen anteilige Gebühren an
- Bei einer Reduzierung mitten im Abrechnungszeitraum werden Gutschriften angerechnet
