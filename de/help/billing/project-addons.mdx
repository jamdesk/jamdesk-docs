Mit Projekt-Add-ons können Sie die Anzahl der Dokumentationsprojekte in Ihrem Plan erweitern.

## Funktionsweise von Add-ons

Pro-Pläne umfassen 3 Projekte. Jedes zusätzliche Projekt kostet 15 $ pro Monat.

## Projekte hinzufügen

<Steps>
  <Step title="Zu Billing gehen">
    Navigieren Sie zu **Settings** → **Billing**.
  </Step>
  <Step title="Auf „Add Projects“ klicken">
    Wählen Sie **Add project slots** aus.
  </Step>
  <Step title="Menge auswählen">
    Wählen Sie aus, wie viele zusätzliche Projekte Sie benötigen.
  </Step>
  <Step title="Bestätigen">
    Überprüfen Sie die aktualisierte Gesamtsumme und bestätigen Sie.
  </Step>
</Steps>

Add-ons werden anteilig abgerechnet: Sie zahlen nur für die verbleibenden Tage Ihres Abrechnungszeitraums.

## Projekte entfernen

So reduzieren Sie die Anzahl Ihrer Projekte:

1. Löschen Sie Projekte, bis Sie die gewünschte Anzahl erreicht haben
2. Gehen Sie zu **Settings** → **Billing**
3. Klicken Sie auf **Manage add-ons**
4. Reduzieren Sie die Anzahl der zusätzlichen Slots
5. Bestätigen Sie die Änderung

<Warning>
Sie können die Anzahl nicht unter die Zahl der aktiven Projekte reduzieren. Löschen Sie zuerst Projekte.
</Warning>

## Abrechnung von Add-ons

- Add-ons erscheinen als separate Position auf Rechnungen
- Beim Hinzufügen innerhalb eines Abrechnungszeitraums fallen anteilige Kosten an
- Beim Entfernen innerhalb eines Abrechnungszeitraums werden Gutschriften angewendet
