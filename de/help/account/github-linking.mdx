Verknüpfen Sie Ihr GitHub-Konto, um Builds Ihnen zuzuordnen und auf private Repositories zuzugreifen.

## Warum GitHub verknüpfen?

- Verbinden Sie private Repositories mit Jamdesk
- Aktivieren Sie automatische Builds bei jedem Push
- Greifen Sie auf Repositories von Organisationen zu, denen Sie angehören

## Ihr Konto verknüpfen

<Steps>
  <Step title="Zu den Einstellungen wechseln">
    Klicken Sie auf Ihr Avatar-Bild und wählen Sie **Settings**.
  </Step>
  <Step title="Connections auswählen">
    Öffnen Sie den Tab **Connections**.
  </Step>
  <Step title="GitHub verbinden anklicken">
    Wählen Sie **Connect GitHub Account**.
  </Step>
  <Step title="Jamdesk autorisieren">
    Prüfen Sie die Berechtigungen und klicken Sie in GitHub auf **Authorize**.
  </Step>
</Steps>

## Angeforderte Berechtigungen

Jamdesk fordert diese Berechtigungen an:

| Berechtigung | Zweck |
|------------|---------|
| Read repository contents | Zugriff auf Ihre Dokumentationsdateien |
| Read repository metadata | Auflisten Ihrer Repositories |
| Webhooks | Empfang von Push-Benachrichtigungen für automatische Builds |

<Note>
Jamdesk schreibt niemals in Ihre Repositories. Der Zugriff ist nur lesend.
</Note>

## Verknüpfung Ihres Kontos aufheben

1. Wechseln Sie zu **Settings** → **Connections**
2. Klicken Sie neben GitHub auf **Disconnect**
3. Bestätigen Sie die Trennung

<Warning>
Das Trennen von GitHub deaktiviert automatische Builds für alle Ihre Projekte. Verbinden Sie erneut, um sie wieder zu aktivieren.
</Warning>

## Repositories von Organisationen

1. Öffnen Sie die Einstellungen der Organisation auf GitHub
2. Öffnen Sie **Third-party access** → **OAuth Apps**
3. Suchen Sie Jamdesk und klicken Sie auf **Grant**

Keine Option **Grant**? Bitten Sie einen Organisations-Admin, Jamdesk zu genehmigen.
