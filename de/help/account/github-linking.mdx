---

Durch die Verknüpfung Ihres GitHub-Kontos wird Ihre Identität für die Build-Zuordnung verknüpft und der Zugriff auf private Repositories ermöglicht.

## Warum GitHub verknüpfen?

Durch die Verknüpfung Ihres GitHub-Kontos können Sie:

- Private Repositories mit Jamdesk verbinden
- Automatische Builds bei Pushes aktivieren
- Auf Repositories von Organisationen zugreifen, denen Sie angehören

## Ihr Konto verknüpfen

<Steps>
  <Step title="Zu den Einstellungen gehen">
    Klicken Sie auf Ihren Avatar und wählen Sie **Settings**.
  </Step>
  <Step title="Verbindungen auswählen">
    Öffnen Sie den Tab **Connections**.
  </Step>
  <Step title="GitHub verbinden">
    Wählen Sie **Connect GitHub Account**.
  </Step>
  <Step title="Jamdesk autorisieren">
    Überprüfen Sie die Berechtigungen und klicken Sie in GitHub auf **Authorize**.
  </Step>
</Steps>

## Angeforderte Berechtigungen

Jamdesk fordert minimale Berechtigungen an:

| Berechtigung | Zweck |
|------------|---------|
| Repository-Inhalte lesen | Zugriff auf Ihre Dokumentationsdateien |
| Repository-Metadaten lesen | Ihre Repositories auflisten |
| Webhooks | Push-Benachrichtigungen für automatische Builds empfangen |

<Note>
Jamdesk schreibt niemals in Ihre Repositories. Der gesamte Zugriff ist schreibgeschützt.
</Note>

## Verknüpfung Ihres Kontos aufheben

So trennen Sie die Verbindung zu GitHub:

1. Gehen Sie zu **Settings** → **Connections**
2. Klicken Sie neben GitHub auf **Disconnect**
3. Bestätigen Sie die Trennung

<Warning>
Die Trennung von GitHub deaktiviert automatische Builds für alle Ihre Projekte. Sie müssen die Verbindung erneut herstellen, um sie wieder zu aktivieren.
</Warning>

## Repositories von Organisationen

So greifen Sie auf Repositories einer GitHub-Organisation zu:

1. Öffnen Sie die Einstellungen der Organisation auf GitHub
2. Gehen Sie zu **Third-party access** → **OAuth Apps**
3. Suchen Sie Jamdesk und klicken Sie auf **Grant**, um den Zugriff zu gewähren

Wenn diese Option nicht angezeigt wird, bitten Sie einen Organisationsadministrator, Jamdesk zu genehmigen.
