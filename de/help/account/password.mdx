Ändern Sie Ihr Jamdesk-Passwort oder setzen Sie es zurück, falls Sie es vergessen haben.

<Note>
  Diese Seite behandelt Ihr **Jamdesk-Kontopasswort** (die Anmeldung am Dashboard). Um Ihrer veröffentlichten Dokumentation ein Passwort zu geben, lesen Sie [Passwortschutz](/de/setup/password-protection). Eine Übersicht über öffentliche, Passwort- und SSO-Optionen finden Sie unter [Zugriffskontrolle](/de/setup/access-control).
</Note>

## Passwort ändern

Für diese Schritte benötigen Sie Ihr aktuelles Passwort.

<Steps>
  <Step title="Zu den Benutzereinstellungen wechseln">
    Klicken Sie in der Seitenleiste auf Ihr Profilbild und wählen Sie **User Settings**.
  </Step>
  <Step title="Auf Change Password klicken">
    Klicken Sie in der Karte **Account Information** auf **Change Password**.
  </Step>
  <Step title="Formular ausfüllen">
    Es öffnet sich ein Dialogfenster mit drei Feldern:

    1. **Current Password**
    2. **New Password**
    3. **Confirm New Password**

    Mit dem Augensymbol im jeweiligen Feld können Sie ein Passwort ein- oder ausblenden.
  </Step>
  <Step title="Absenden">
    Klicken Sie auf **Change Password**, um zu speichern. Eine Erfolgsmeldung erscheint und der Dialog schließt sich.
  </Step>
</Steps>

<Note>
Die Schaltfläche Change Password erscheint nur bei Konten, die mit E-Mail und Passwort erstellt wurden. Haben Sie sich mit Google oder GitHub registriert? Siehe unten [OAuth-Konten](#oauth-konten).
</Note>

## Vergessenes Passwort zurücksetzen

<Steps>
  <Step title="Zur Anmeldung wechseln">
    Öffnen Sie [dashboard.jamdesk.com](https://dashboard.jamdesk.com) und klicken Sie auf **Sign In**.
  </Step>
  <Step title="Auf Forgot Password klicken">
    Wählen Sie den Link **Forgot password?** unterhalb des Passwortfelds.
  </Step>
  <Step title="E-Mail-Adresse eingeben">
    Geben Sie die E-Mail-Adresse Ihres Kontos ein. Eine bereits im Anmeldeformular eingetragene Adresse wird automatisch übernommen.
  </Step>
  <Step title="Posteingang prüfen">
    Klicken Sie auf **Send reset email**. Öffnen Sie den Link zum Zurücksetzen des Passworts in Ihrem Posteingang und folgen Sie den Anweisungen.
  </Step>
</Steps>

<Note>
Links zum Zurücksetzen des Passworts laufen nach 1 Stunde ab. Fordern Sie einen neuen an, wenn Ihr Link abgelaufen ist.
</Note>

## Passwortanforderungen

Ihr Passwort muss mindestens **6 Zeichen** lang sein.

## OAuth-Konten

Konten, die ausschließlich mit Google oder GitHub erstellt wurden, haben kein Jamdesk-Passwort. Die Schaltfläche **Change Password** erscheint in ihren Kontoeinstellungen nicht.

Legen Sie ein Passwort für Ihre E-Mail-Adresse über den Ablauf **Forgot password?** auf der Anmeldeseite fest. Anschließend können Sie sich entweder mit Passwort oder über OAuth anmelden.
