Erstellen Sie Ihr Jamdesk-Konto per E-Mail, Google OAuth oder GitHub OAuth.

## Optionen zur Registrierung

Jamdesk unterstützt drei Authentifizierungsmethoden:

### E-Mail und Passwort

1. Besuchen Sie [dashboard.jamdesk.com](https://dashboard.jamdesk.com)
2. Klicken Sie auf **Sign Up**
3. Geben Sie Ihre E-Mail-Adresse ein
4. Erstellen Sie ein sicheres Passwort
5. Prüfen Sie Ihre E-Mails auf einen Bestätigungslink
6. Klicken Sie auf den Bestätigungslink, um Ihr Konto zu bestätigen

### Google OAuth

1. Besuchen Sie [dashboard.jamdesk.com](https://dashboard.jamdesk.com)
2. Klicken Sie auf **Sign Up**
3. Wählen Sie **Continue with Google**
4. Autorisieren Sie Jamdesk, auf Ihr Google-Konto zuzugreifen
5. Sie werden automatisch bestätigt und angemeldet

### GitHub OAuth

1. Besuchen Sie [dashboard.jamdesk.com](https://dashboard.jamdesk.com)
2. Klicken Sie auf **Sign Up**
3. Wählen Sie **Continue with GitHub**
4. Autorisieren Sie Jamdesk, auf Ihr GitHub-Konto zuzugreifen
5. Sie werden automatisch bestätigt und angemeldet

<Note>
Ihre GitHub-Anmeldung verknüpft Ihre Identität mit Jamdesk. Dies ist unabhängig von der Verbindung eines GitHub-Repositorys mit Ihrem Dokumentationsprojekt. Dies erledigen Sie während der Projekte Einrichtung.
</Note>

## Was nach der Registrierung geschieht

Nach der Kontoerstellung:
- Starten Sie eine 14-tägige kostenlose Testversion des Pro-Tarifs
- Werden Sie zur Erstellung Ihres ersten Dokumentationsprojekts weitergeleitet
- Erhalten Sie Zugriff auf die vollständige Onboarding-Anleitung

## E-Mail-Bestätigung

Wenn Sie keine Bestätigungs-E-Mail erhalten:
1. Prüfen Sie Ihren Spam-Ordner
2. Warten Sie einige Minuten und versuchen Sie erneut, sich zu registrieren
3. [Kontaktieren Sie den Support](/de/help/support/contact), wenn das Problem weiterhin besteht
