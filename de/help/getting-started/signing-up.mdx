Erstellen Sie Ihr Jamdesk-Konto per E-Mail, Google OAuth oder GitHub OAuth.

## Optionen zur Registrierung

### E-Mail und Passwort

1. Rufen Sie [dashboard.jamdesk.com](https://dashboard.jamdesk.com) auf
2. Klicken Sie auf **Sign Up**
3. Geben Sie Ihre E-Mail-Adresse ein
4. Erstellen Sie ein sicheres Passwort
5. Prüfen Sie Ihr E-Mail-Postfach auf einen Bestätigungslink
6. Klicken Sie auf den Bestätigungslink, um Ihr Konto zu bestätigen

### Google OAuth

1. Rufen Sie [dashboard.jamdesk.com](https://dashboard.jamdesk.com) auf
2. Klicken Sie auf **Sign Up**
3. Wählen Sie **Continue with Google**
4. Autorisieren Sie Jamdesk für den Zugriff auf Ihr Google-Konto
5. Jamdesk überprüft Ihr Konto und meldet Sie an

### GitHub OAuth

1. Rufen Sie [dashboard.jamdesk.com](https://dashboard.jamdesk.com) auf
2. Klicken Sie auf **Sign Up**
3. Wählen Sie **Continue with GitHub**
4. Autorisieren Sie Jamdesk für den Zugriff auf Ihr GitHub-Konto
5. Jamdesk überprüft Ihr Konto und meldet Sie an

<Note>
Die Anmeldung mit GitHub verknüpft Ihre Identität mit Jamdesk. Das Verbinden eines GitHub-Repositorys mit Ihrem Dokumentationsprojekt ist ein separater Schritt während der Projekteinrichtung.
</Note>

## Was nach der Registrierung geschieht

Ihr neues Konto:
- Startet eine 14-tägige kostenlose Testphase des Pro-Plans
- Leitet Sie zur Erstellung Ihres ersten Dokumentationsprojekts weiter
- Erhält die vollständige Einführungsanleitung

## E-Mail-Bestätigung

Falls Sie keine Bestätigungs-E-Mail erhalten:
1. Prüfen Sie Ihren Spam-Ordner
2. Warten Sie einige Minuten und versuchen Sie es erneut mit der Registrierung
3. [Kontaktieren Sie den Support](/de/help/support/contact), falls das Problem weiterhin besteht
