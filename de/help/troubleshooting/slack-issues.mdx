Slack-Benachrichtigungen erfordern einen gültigen eingehenden Webhook. Wenn keine Benachrichtigungen mehr eintreffen, prüfen Sie die folgende Webhook-Konfiguration.

## Benachrichtigungen werden nicht angezeigt

<Steps>
  <Step title="Webhook prüfen">
    1. Gehen Sie zu **Integrations**
    2. Prüfen Sie, ob Slack als verbunden angezeigt wird
    3. Klicken Sie auf **Send Test**, um die Verbindung zu testen
  </Step>
  <Step title="Kanal überprüfen">
    Der Slack-Kanal wurde möglicherweise gelöscht oder umbenannt. Erstellen Sie bei Bedarf einen neuen Webhook.
  </Step>
  <Step title="Benachrichtigungseinstellungen prüfen">
    Prüfen Sie, ob Sie die gewünschten Benachrichtigungstypen aktiviert haben (Build gestartet, erfolgreich, fehlgeschlagen).
  </Step>
</Steps>

## Webhook-Fehler

### „Ungültige Webhook-URL“

Das URL-Format ist falsch oder der Webhook wurde gelöscht.

**Behebung:**
1. Erstellen Sie einen neuen Webhook in Slack
2. Kopieren Sie die vollständige URL einschließlich `https://`
3. Aktualisieren Sie den Webhook in Jamdesk

### „Kanal nicht gefunden“

Der Zielkanal existiert nicht mehr.

**Behebung:**
1. Erstellen Sie einen neuen Webhook für einen vorhandenen Kanal
2. Aktualisieren Sie die Webhook-URL in Jamdesk

### „Veröffentlichung im Kanal fehlgeschlagen“

Der Webhook wurde möglicherweise widerrufen oder der Bot wurde entfernt.

**Behebung:**
1. Prüfen Sie die Slack-Workspace-Einstellungen für Jamdesk
2. Erstellen Sie den Webhook bei Bedarf neu

## Doppelte Benachrichtigungen

Möglicherweise sind mehrere Webhooks konfiguriert:

1. Gehen Sie zu **Integrations**
2. Entfernen Sie doppelte Slack-Verbindungen
3. Behalten Sie nur einen Webhook pro Kanal

## Verzögerte Benachrichtigungen

Benachrichtigungen treffen normalerweise innerhalb weniger Sekunden ein. Verzögerungen können folgende Ursachen haben:

- Probleme mit dem Slack-Dienst (prüfen Sie den [Slack-Status](https://status.slack.com))
- Netzwerküberlastung
- Große Build-Warteschlangen

## Slack erneut verbinden

So setzen Sie Ihre Slack-Integration zurück:

<Steps>
  <Step title="Trennen">
    Gehen Sie in Jamdesk zu **Integrations** → **Disconnect Slack**
  </Step>
  <Step title="Neuen Webhook erstellen">
    Erstellen Sie in Slack einen neuen eingehenden Webhook für Ihren Kanal
  </Step>
  <Step title="Erneut verbinden">
    Fügen Sie die neue Webhook-URL in Jamdesk hinzu
  </Step>
  <Step title="Testen">
    Klicken Sie auf **Send Test**, um die Funktion zu überprüfen
  </Step>
</Steps>

## Probleme mit dem Benachrichtigungsformat

Wenn Nachrichten fehlerhaft formatiert erscheinen:

- Stellen Sie sicher, dass Sie Incoming Webhooks verwenden (nicht die Slack API)
- Prüfen Sie, ob Ihr Slack-Workspace externe Webhooks zulässt
