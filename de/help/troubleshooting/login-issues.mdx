Sie können sich nicht beim Jamdesk-Dashboard anmelden? Finden Sie unten die passende Lösung.

## Passwort vergessen

<Steps>
  <Step title="Zur Anmeldeseite gehen">
    Besuchen Sie [dashboard.jamdesk.com](https://dashboard.jamdesk.com).
  </Step>
  <Step title="Auf „Forgot Password“ klicken">
    Wählen Sie den Link **Forgot password?** aus.
  </Step>
  <Step title="E-Mail-Adresse eingeben">
    Geben Sie die E-Mail-Adresse Ihres Kontos ein.
  </Step>
  <Step title="Posteingang prüfen">
    Klicken Sie auf den Link zum Zurücksetzen in der E-Mail, die wir Ihnen senden.
  </Step>
</Steps>

<Note>
Links zum Zurücksetzen laufen nach 1 Stunde ab. Fordern Sie einen neuen Link an, wenn Ihrer abgelaufen ist.
</Note>

## E-Mail-Adresse nicht erkannt

Wenn Sie „No account found“ sehen:

- Prüfen Sie Ihre E-Mail-Adresse auf Tippfehler.
- Probieren Sie andere E-Mail-Adressen aus, die Sie möglicherweise verwendet haben.
- Möglicherweise haben Sie sich stattdessen mit Google oder GitHub registriert.

## Probleme bei der OAuth-Anmeldung

### Google-Anmeldung funktioniert nicht

1. Löschen Sie die Cookies Ihres Browsers.
2. Probieren Sie einen anderen Browser aus.
3. Deaktivieren Sie Browser-Erweiterungen vorübergehend.
4. Prüfen Sie, ob Cookies von Drittanbietern zugelassen sind.

### GitHub-Anmeldung funktioniert nicht

1. Prüfen Sie, ob Sie bei GitHub angemeldet sind.
2. Prüfen Sie, ob Jamdesk in den GitHub-Einstellungen autorisiert ist.
3. Widerrufen Sie die Autorisierung und autorisieren Sie Jamdesk bei Bedarf erneut.

## Konto gesperrt

Nach mehreren fehlgeschlagenen Anmeldeversuchen werden Konten vorübergehend gesperrt.

- Warten Sie 15 Minuten, bevor Sie es erneut versuchen.
- Verwenden Sie die Option zum Zurücksetzen des Passworts.
- Wenden Sie sich an den Support, wenn das Problem weiterhin besteht.

## Zwei-Faktor-Authentifizierung

Wenn Sie 2FA aktiviert haben und nicht auf Ihre Authenticator-App zugreifen können:

1. Verwenden Sie Ihre Backup-Codes.
2. Wenden Sie sich mit einem Nachweis über den Kontobesitz an den Support.

## Browserprobleme

Führen Sie die folgenden Schritte aus:

1. **Löschen Sie Cache und Cookies** für jamdesk.com.
2. **Deaktivieren Sie Erweiterungen**, die möglicherweise stören.
3. **Verwenden Sie den Inkognito- bzw. privaten Modus.**
4. **Verwenden Sie einen anderen Browser.**
