Öffnen Sie den fehlgeschlagenen Build im Tab Deployments und ordnen Sie die Fehlermeldung einem der folgenden Abschnitte zu.

## Fehler finden

1. Gehen Sie zum Tab **Deployments** Ihres Projekts
2. Klicken Sie auf den fehlgeschlagenen Build
3. Prüfen Sie die Fehlermeldung und das Log

Das Log zeigt, was fehlgeschlagen ist und wo.

## Häufige Fehler

### Ungültige Konfiguration

**Fehler:** "Invalid docs.json"

Ihre `docs.json` enthält Syntax- oder Schemafehler.

**Lösung:**
1. Prüfen Sie auf fehlende Kommas, Klammern oder Anführungszeichen
2. Führen Sie `jamdesk validate` lokal aus
3. Vergleichen Sie mit der [Schema-Referenz](/de/config/docs-json-reference)

### Fehlende Seiten

**Fehler:** "Page 'path/to/page' not found"

Eine Seite in der Navigation existiert nicht.

**Lösung:**
- Prüfen Sie, ob die Datei vorhanden ist
- Stellen Sie sicher, dass der Pfad genau übereinstimmt (Groß-/Kleinschreibung beachten)
- Geben Sie die Endung `.mdx` nicht in `docs.json` an

### MDX-Syntaxfehler

**Fehler:** "MDX compilation failed"

Ungültige MDX- oder JSX-Syntax.

**Häufige Ursachen:**
- Nicht geschlossene Tags: `<Card>` ohne `</Card>`
- Nicht maskierte geschweifte Klammern: `{` statt `\{`
- Ungültige Props: `title=value` statt `title="value"`

### Fehlende Bilder

**Fehler:** "Asset not found"

Ein in MDX referenziertes Bild existiert nicht.

**Lösung:**
- Prüfen Sie, ob der Bildpfad korrekt ist
- Pfade sind relativ zu Ihrem Docs-Verzeichnis
- Stellen Sie sicher, dass die Datei in Git committet wurde

## Schritte zur Fehlerbehebung

<Steps>
  <Step title="Fehler lesen">
    Finden Sie im Log heraus, was fehlgeschlagen ist und wo.
  </Step>
  <Step title="Lokal testen">
    Führen Sie `jamdesk dev` aus, um den Fehler zu reproduzieren.
  </Step>
  <Step title="Konfiguration validieren">
    Führen Sie `jamdesk validate` aus, um Ihre Konfiguration zu prüfen.
  </Step>
  <Step title="Letzte Änderungen prüfen">
    Prüfen Sie Ihren letzten Commit auf das Problem.
  </Step>
</Steps>

## Noch keine Lösung?

Wenn Sie das Problem nicht lösen können:

1. Kopieren Sie das vollständige Build-Log
2. Notieren Sie Ihre Projekt-ID
3. [Kontaktieren Sie den Support](/de/help/support/contact)
