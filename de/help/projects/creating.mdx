Erstelle im Dashboard ein Projekt, um eine neue Dokumentationsseite einzurichten. Starte mit einer Vorlage oder verbinde ein bestehendes GitHub-Repository. Jamdesk installiert den Webhook und führt den ersten Build aus.

## Neues Projekt erstellen

<Steps>
  <Step title="Dashboard öffnen">
    Rufe [dashboard.jamdesk.com](https://dashboard.jamdesk.com) auf und melde dich an.
  </Step>
  <Step title="Auf New Project klicken">
    Wähle im Dashboard **New Project** aus.
  </Step>
  <Step title="Quelle auswählen">
    Lege fest, wie deine Dokumentation starten soll:

    <Tabs>
      <Tab title="Vorlage verwenden">
        Starte mit der [Starter Template](https://github.com/jamdesk/starter-docs). Jamdesk erstellt für dich ein GitHub-Repository mit Beispielinhalten, Komponenten und einer OpenAPI-Spezifikation.
      </Tab>
      <Tab title="Repository verbinden">
        Verbinde ein bestehendes GitHub-Repository, das deine Dokumentation enthält.
      </Tab>
    </Tabs>
  </Step>
  <Step title="Einstellungen konfigurieren">
    - **Project name**: wird im Dashboard angezeigt
    - **Subdomain**: deine Docs-URL (z. B. `my-docs.jamdesk.app`)
    - **Branch**: der Git-Branch, der bereitgestellt wird (normalerweise `main`)
  </Step>
  <Step title="Erstellen">
    Klicke auf **Create Project**, um die Einrichtung abzuschließen.
  </Step>
</Steps>

## Projektlimits

Dein Tarif bestimmt, wie viele Projekte du erstellen kannst:

| Tarif | Projekte |
|------|----------|
| Trial | 1 |
| Pro | 1 (erweiterbar) |

Zusätzliche Pro-Projektplätze kannst du auf der Seite **Subscription** hinzufügen.

## Was erstellt wird

Jamdesk führt anschließend Folgendes aus:

1. Verbindung zu deinem GitHub-Repository herstellen
2. Einen Webhook für automatische Builds installieren
3. Deinen ersten Build starten
4. Eine Subdomain `*.jamdesk.app` zuweisen
