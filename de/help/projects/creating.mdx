title: Projekte im Dashboard erstellen

---

Richten Sie eine neue Dokumentationswebsite ein, indem Sie ein Projekt im Dashboard erstellen. Sie können mit einer Vorlage beginnen oder ein vorhandenes GitHub-Repository verbinden. Jamdesk übernimmt die Webhook-Installation und den ersten Build automatisch.

## Neues Projekt erstellen

<Steps>
  <Step title="Dashboard öffnen">
    Rufen Sie [dashboard.jamdesk.com](https://dashboard.jamdesk.com) auf und melden Sie sich an.
  </Step>
  <Step title="Auf New Project klicken">
    Wählen Sie **New Project** im Dashboard aus.
  </Step>
  <Step title="Quelle auswählen">
    Wählen Sie aus, wie Sie mit Ihrer Dokumentation beginnen möchten:

    <Tabs>
      <Tab title="Use a Template">
        Beginnen Sie mit der [Starter Template](https://github.com/jamdesk/starter-docs). Jamdesk erstellt für Sie ein GitHub-Repository mit Beispielinhalten, Komponenten und einer OpenAPI-Spezifikation.
      </Tab>
      <Tab title="Connect Repository">
        Verbinden Sie ein vorhandenes GitHub-Repository, das Ihre Dokumentation enthält.
      </Tab>
    </Tabs>
  </Step>
  <Step title="Einstellungen konfigurieren">
    - **Project name** — Wird im Dashboard angezeigt
    - **Subdomain** — Ihre Dokumentations-URL (z. B. `my-docs.jamdesk.app`)
    - **Branch** — Der Git-Branch, der bereitgestellt werden soll (in der Regel `main`)
  </Step>
  <Step title="Erstellen">
    Klicken Sie auf **Create Project**, um die Einrichtung abzuschließen.
  </Step>
</Steps>

## Projektlimits

Ihr Tarif bestimmt, wie viele Projekte Sie erstellen können:

| Tarif | Projekte |
|------|----------|
| Trial | 1 |
| Pro | 1 (erweiterbar) |

Benötigen Sie mehr Projekte mit Pro? Fügen Sie auf der Seite **Subscription** zusätzliche Projektplätze hinzu.

## Was erstellt wird

Wenn Sie ein Projekt erstellen, führt Jamdesk folgende Schritte aus:

1. Verbindet Ihr GitHub-Repository
2. Installiert einen Webhook für automatische Builds
3. Löst Ihren ersten Build aus
4. Weist eine `*.jamdesk.app`-Subdomain zu
