Kontaktieren Sie den Jamdesk-Support bei Fragen zu Builds, zur Abrechnung oder zu Ihrem Konto.

## E-Mail-Support

Für alle Support-Anfragen:

**support@jamdesk.com**

### Antwortzeiten

| Plan | Antwortzeit |
|------|-------------|
| Trial | Innerhalb von 48 Stunden |
| Pro | Innerhalb von 24 Stunden |

Der Support ist Montag–Freitag von 9am–6pm EST verfügbar.

## Live-Chat

Sie können uns auch über das Chat-Widget unten rechts auf jeder Dokumentationsseite kontaktieren.

## Was Sie angeben sollten

Helfen Sie uns, Ihnen schneller zu helfen, indem Sie Folgendes angeben:

```text
Account email:
Project name or ID (found in URL):
Description of the issue:
Steps to reproduce (if applicable):
Error messages or screenshots:
What you've already tried:
```

## Funktionsanfragen

Haben Sie eine Idee für Jamdesk?

Schreiben Sie uns an **feedback@jamdesk.com** und teilen Sie uns Folgendes mit:

- Beschreibung der Funktion
- Warum sie Ihnen helfen würde
- Wie Sie sie einsetzen würden

Wir lesen jede Anfrage und priorisieren sie anhand der Nachfrage aus der Community.

## Fehlerberichte

Einen Fehler gefunden? Schreiben Sie an **support@jamdesk.com** und geben Sie Folgendes an:

- Was Ihrer Erwartung nach passieren sollte
- Was tatsächlich passiert ist
- Schritte zur Reproduktion
- Browser- und Betriebssystemversion
- Wenn möglich Screenshots

## Anfragen von Unternehmen

Für Enterprise-Pläne, individuelle Verträge oder Mengenpreise:

**enterprise@jamdesk.com**

## Sicherheitsprobleme

Melden Sie Sicherheitslücken an:

**security@jamdesk.com**

Auf unserer [Sicherheitsseite](/de/help/support/security) finden Sie unsere Richtlinie für verantwortungsvolle Offenlegung.
