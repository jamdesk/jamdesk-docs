Dieses Plugin gibt [Claude Code](https://claude.ai/code) das Jamdesk-Wissen, das Sie sonst in jedem Prompt erklären müssten: welche Komponenten es gibt, wie `docs.json` funktioniert und welche CLI-Befehle verfügbar sind.

<Note>
  Sie benötigen zuerst eine installierte Version von Claude Code. Erhältlich unter [claude.ai/code](https://claude.ai/code).
</Note>

## Installation

<Steps>
  <Step title="Marketplace hinzufügen">
    Führen Sie diesen Slash-Befehl in Claude Code aus:

    ```text
    /plugin marketplace add jamdesk/jamdesk-claude-plugin
    ```
  </Step>
  <Step title="Plugin installieren">
    ```text
    /plugin install jamdesk@jamdesk-marketplace
    ```
  </Step>
</Steps>

Sie können es auch finden, indem Sie `/plugin` ausführen und **Discover** auswählen.

<Accordion title="Manuelle Installation (für Entwicklung oder Tests)">
  ```bash
  git clone https://github.com/jamdesk/jamdesk-claude-plugin.git
  claude --plugin-dir ./jamdesk-claude-plugin
  ```
</Accordion>

## Enthaltene Inhalte

Das Plugin enthält einen Skill, `/jamdesk:jamdesk`. Er umfasst einen Schnellreferenz-Hub und drei Referenzdateien, die bei Bedarf geladen werden:

| Referenz | Was sie abdeckt |
|-----------|---------------|
| **Komponenten** | Über 25 MDX-Komponenten (Cards, Steps, Tabs, Callouts, Code Groups, Tables und mehr) mit vollständigen Props und Beispielen |
| **Konfiguration** | Vollständiges `docs.json`-Schema: Themes, Farben, Branding, Navbar, Footer, API-Konfiguration, über 20 Analyse-Integrationen |
| **Navigation** | 8 Navigationsmuster: flach, gruppiert, mit Tabs, Multi-Produkt, versioniert, mehrsprachig, Dropdowns, OpenAPI |

Der Hub listet außerdem die 19 CLI-Befehle, Frontmatter-Felder von Seiten, Syntax für Bildgrößen, Schreibstandards und häufige Fehler auf.

## Verwendung

Führen Sie `/jamdesk:jamdesk` aus, während Sie an Jamdesk-Dokumentation arbeiten.

Claude kann den Skill in einem Projekt mit einer `docs.json` automatisch aktivieren.

Claude beantwortet gängige Fragen, etwa zur Komponentensyntax und zu CLI-Befehlen, direkt aus dem Hub. Für vollständige Props-Tabellen, Konfigurationsoptionen oder Details zu Navigationsmustern lädt es eine Referenzdatei.

## Kombination mit CLAUDE.md und MCP

Das Plugin funktioniert am besten in einem Setup mit drei Ebenen:

1. Das Plugin vermittelt Claude die Jamdesk-Plattform: Komponenten, Konfiguration, Navigation, CLI.
2. [CLAUDE.md](/de/ai/claude-code) vermittelt Claude die Konventionen *Ihres Projekts*: Schreibstil, Terminologie, Seitenstruktur.
3. Der [MCP-Server](/de/ai/mcp-server) ermöglicht Claude, Ihre veröffentlichte Dokumentation zu durchsuchen und zu lesen.

Sie brauchen nicht alle drei. Das Plugin ist auch allein nützlich. Eine CLAUDE.md und eine MCP-Verbindung helfen Claude, sich an den Ton Ihrer Website anzupassen und auf bestehende Seiten zu verlinken.

## Aktualisierung und Quellcode
