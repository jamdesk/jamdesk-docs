Wenn du Claude bittest, eine Jamdesk-Seite zu schreiben, musst du immer wieder dieselben Dinge erklären: Welche Komponenten gibt es, wie funktioniert `docs.json`, und welche CLI-Befehle gibt es? Dieses Plug-in stellt [Claude Code](https://claude.ai/code) dieses Wissen direkt zur Verfügung. So kannst du die Einleitung überspringen und sofort mit dem Erstellen beginnen.

<Note>
  Claude Code muss zuerst installiert sein. Du erhältst es unter [claude.ai/code](https://claude.ai/code).
</Note>

## Installation

<Steps>
  <Step title="Marketplace hinzufügen">
    Führe diesen Slash-Befehl in Claude Code aus:

    ```text
    /plugin marketplace add jamdesk/jamdesk-claude-plugin
    ```
  </Step>
  <Step title="Plug-in installieren">
    ```text
    /plugin install jamdesk@jamdesk-marketplace
    ```
  </Step>
</Steps>

Du kannst es auch finden, indem du `/plugin` ausführst und **Discover** auswählst.

<Accordion title="Manuelle Installation (für Entwicklung oder Tests)">
  ```bash
  git clone https://github.com/jamdesk/jamdesk-claude-plugin.git
  claude --plugin-dir ./jamdesk-claude-plugin
  ```
</Accordion>

## Enthaltene Inhalte

Ein Skill (`/jamdesk:jamdesk`) mit einer Schnellreferenzübersicht und drei ausführlichen Referenzdateien, die bei Bedarf geladen werden:

| Referenz | Behandelte Inhalte |
|-----------|---------------|
| **Komponenten** | Mehr als 25 MDX-Komponenten (Cards, Steps, Tabs, Callouts, Code Groups, Tabellen und weitere) mit vollständigen Props und Beispielen |
| **Konfiguration** | Vollständiges `docs.json`-Schema: Themes, Farben, Branding, Navbar, Footer, API-Konfiguration und mehr als 20 Analytics-Integrationen |
| **Navigation** | 8 Navigationsmuster: flach, gruppiert, mit Tabs, für mehrere Produkte, versioniert, mehrsprachig, Dropdowns und OpenAPI |

Die Übersicht enthält außerdem alle 19 CLI-Befehle, Frontmatter-Felder für Seiten, die Syntax zur Bildgrößenanpassung, Schreibstandards und häufige Fehler.

## Verwendung

Wenn du an der Jamdesk-Dokumentation arbeitest, führe `/jamdesk:jamdesk` aus.

Wenn dein Projekt über eine `docs.json` verfügt, aktiviert Claude den Skill möglicherweise automatisch.

Häufige Fragen (Komponentensyntax, CLI-Befehle) werden direkt über die Übersicht beantwortet. Du benötigst vollständige Props-Tabellen, alle Konfigurationsoptionen oder Details zu Navigationsmustern? Claude lädt die entsprechende Referenzdatei.

## Kombination mit CLAUDE.md und MCP

Am besten funktioniert das Plug-in als Teil einer Konfiguration aus drei Ebenen:

1. Das Plug-in vermittelt Claude Kenntnisse über die Jamdesk-Plattform: Komponenten, Konfiguration, Navigation und CLI.
2. [CLAUDE.md](/de/ai/claude-code) vermittelt Claude die Konventionen *deines Projekts*: Schreibstil, Terminologie und Seitenstruktur.
3. Der [MCP-Server](/de/ai/mcp-server) ermöglicht Claude den Zugriff auf deine veröffentlichten Dokumente, damit Claude Inhalte suchen und lesen sowie vorhandene Seiten überprüfen kann.

Du benötigst nicht alle drei Komponenten. Das Plug-in ist allein bereits nützlich. In Kombination mit einer CLAUDE.md und einer MCP-Verbindung kann Claude jedoch Seiten schreiben, die zum Stil deiner Website passen und ohne Raten auf deine vorhandenen Inhalte verweisen.

## Aktualisierung und Quellcode

Suche nach Aktualisierungen, indem du `/plugin` in Claude Code ausführst. Du kannst auch den Installationsbefehl erneut ausführen, um die neueste Version abzurufen.

Das Plug-in ist Open Source (Apache 2.0). Sieh dir den Quellcode an, melde Probleme oder beteilige dich: [github.com/jamdesk/jamdesk-claude-plugin](https://github.com/jamdesk/jamdesk-claude-plugin). [Änderungsprotokoll](https://github.com/jamdesk/jamdesk-claude-plugin/blob/main/CHANGELOG.md).
