Link your GitHub account to attribute builds to you and reach private repositories.

## Why Link GitHub?

- Connect private repositories to Jamdesk
- Turn on automatic builds on push
- Reach repositories from organizations you belong to

## Linking Your Account

<Steps>
  <Step title="Go to Settings">
    Click your avatar and select **Settings**.
  </Step>
  <Step title="Select Connections">
    Open the **Connections** tab.
  </Step>
  <Step title="Click Connect GitHub">
    Select **Connect GitHub Account**.
  </Step>
  <Step title="Authorize Jamdesk">
    Review the permissions and click **Authorize** in GitHub.
  </Step>
</Steps>

## Permissions Requested

Jamdesk requests these permissions:

| Permission | Purpose |
|------------|---------|
| Read repository contents | Access your documentation files |
| Read repository metadata | List your repositories |
| Webhooks | Receive push notifications for automatic builds |

<Note>
Jamdesk never writes to your repositories. Access is read-only.
</Note>

## Unlinking Your Account

1. Go to **Settings** → **Connections**
2. Click **Disconnect** next to GitHub
3. Confirm the disconnection

<Warning>
Disconnecting GitHub turns off automatic builds for every project you have. Reconnect to turn them back on.
</Warning>

## Organization Repositories

1. Go to the organization's settings on GitHub
2. Open **Third-party access** → **OAuth Apps**
3. Find Jamdesk and click **Grant** access

No **Grant** option? Ask an organization admin to approve Jamdesk.
