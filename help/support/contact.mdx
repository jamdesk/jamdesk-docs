We're here to help. Choose the best way to reach us.

## Email Support

For all support inquiries:

**support@jamdesk.com**

### Response Times

| Plan | Response Time |
|------|---------------|
| Trial | Within 48 hours |
| Pro | Within 24 hours |

Support is available Monday–Friday, 9am–6pm EST.

## What to Include

Help us help you faster by including:

```text
Account email:
Project name or ID (found in URL):
Description of the issue:
Steps to reproduce (if applicable):
Error messages or screenshots:
What you've already tried:
```

## Feature Requests

Have an idea for Jamdesk?

Email us at **feedback@jamdesk.com** with:

- Description of the feature
- Why it would help you
- How you'd use it

We read every request and prioritize based on community demand.

## Bug Reports

Found a bug? Email **support@jamdesk.com** with:

- What you expected to happen
- What actually happened
- Steps to reproduce
- Browser and OS version
- Screenshots if possible

## Enterprise Inquiries

For enterprise plans, custom contracts, or volume pricing:

**enterprise@jamdesk.com**

## Security Issues

Report security vulnerabilities to:

**security@jamdesk.com**

See our [Security page](/help/support/security) for our responsible disclosure policy.
