title: Prompt
description: Prompt presenta instrucciones de IA reutilizables: copia, acciones de apertura integradas, destinos personalizados, iconos y visualización compacta.
---

El componente `<Prompt>` convierte un conjunto reutilizable de instrucciones en una tarjeta que los lectores pueden copiar o abrir en una herramienta de IA compatible. Las acciones Copy y de apertura usan exactamente el contenido redactado y visible para el humano entre las etiquetas.

## Uso básico

Cada Prompt incluye una acción Copy, por lo que la versión más simple no necesita ninguna prop:

<Prompt>
Explica cómo funciona la rotación de claves de API para un desarrollador que usa nuestra API REST por primera vez.
</Prompt>

```mdx
<Prompt>
Explain how API key rotation works for a developer using our REST API for the first time.
</Prompt>
```

## Título y descripción

Usa `title` para etiquetar la tarea. La prop `description`, compatible con Mintlify, reemplaza la vista previa visible por un resumen más breve, mientras que el contenido redactado y visible para el humano entre las etiquetas sigue siendo el prompt completo que usan las acciones Copy y de apertura.

<Prompt
  title="Redactar una nota de versión"
  description="Redacta una nota de versión concisa para un público de desarrolladores."
  actions={["copy", "claude"]}
>
Redacta una nota de versión para el nuevo endpoint de rotación de claves de API.

- Dirígete a los desarrolladores de backend.
- Comienza con el beneficio para el usuario.
- Incluye un ejemplo de solicitud.
</Prompt>

```mdx
<Prompt
  title="Draft a release note"
  description="Write a concise release note for a developer audience."
  actions={["copy", "claude"]}
>
Write a release note for the new API key rotation endpoint.

- Address backend developers.
- Lead with the user benefit.
- Include one request example.
</Prompt>
```

La acción `"copy"` explícita se acepta por compatibilidad, pero Copy siempre está presente y nunca es necesario incluirla en la lista.

<Note>
  Prompt copia exactamente el contenido redactado y visible para el humano. Cuando un prompt contiene [Visibility](/es/components/visibility), las etiquetas contenedoras exclusivas para humanos se omiten del texto copiado, pero su contenido se conserva. Los subárboles exclusivos para agentes quedan excluidos. Visibility con una prop `for` de valor de expresión, o cuya audiencia queda oculta por un atributo spread posterior, también queda excluido porque su audiencia no puede determinarse de forma estática. En cambio, Visibility sin prop `for`, con un `for` abreviado, o con una audiencia literal inválida permanece visible. Un Prompt oculto dentro de un Visibility exclusivo para agentes o cuya audiencia queda oculta por una expresión o spread no tiene fuente copiable.
</Note>

## Acciones de apertura

Agrega `claude`, `cursor`, `chatgpt`, `perplexity` o `gemini` para permitir que los lectores abran el prompt en esas herramientas, cada una con su icono de marca. La primera acción de apertura válida aparece junto a Copy; las acciones adicionales aparecen en el menú More.

<Prompt
  title="Comparar los flujos de autenticación"
  actions={["claude", "cursor", "chatgpt", "perplexity", "gemini"]}
>
Compara los flujos de autenticación por token de sesión y por clave de API en este repositorio. Enumera sus compensaciones de seguridad y recomienda qué flujo debe usar cada tipo de cliente.
</Prompt>

```mdx
<Prompt
  title="Compare authentication flows"
  actions={["claude", "cursor", "chatgpt", "perplexity", "gemini"]}
>
Compare the session-token and API-key authentication flows in this repository.
List their security tradeoffs and recommend which flow each client type should use.
</Prompt>
```

<Warning>
  Al hacer clic en una acción de apertura se envía el prompt copiable completo al tercero seleccionado. No incluyas secretos, datos personales ni contenido propietario, salvo que tengas la intención de compartirlos según la política de privacidad de ese proveedor. Copy no abre ningún servicio de terceros.
</Warning>

## Acciones de URL personalizadas

Las acciones personalizadas toman un `label`, una `url` en HTTPS o HTTP, y un icono opcional. Coloca `{prompt}` en un segmento de ruta, un valor de consulta o un fragmento para controlar a dónde va el prompt codificado en URL. Si omites el marcador de posición, Jamdesk agrega un parámetro de consulta `prompt`.

<Prompt
  title="Investigar esta migración"
  actions={[
    {
      label: "Buscar en la web",
      url: "https://www.google.com/search?q={prompt}",
      icon: "magnifying-glass",
    },
    "claude",
  ]}
>
Compara este plan de migración con el contrato de API pública actual. Identifica los cambios incompatibles, los pasos de reversión faltantes y las pruebas necesarias antes del lanzamiento.
</Prompt>

```mdx
<Prompt
  title="Research this migration"
  actions={[
    {
      label: "Search the web",
      url: "https://www.google.com/search?q={prompt}",
      icon: "magnifying-glass",
    },
    "claude",
  ]}
>
Compare this migration plan with the current public API contract. Identify
breaking changes, missing rollback steps, and tests needed before release.
</Prompt>
```

Las URL de acciones personalizadas deben usar URL `http:` o `https:` sin credenciales. Jamdesk rechaza otros esquemas, marcadores de posición en los orígenes o las claves de consulta, y las URL de acción finales de más de 8,000 caracteres. Copy sigue disponible cuando se rechaza una acción de apertura.

## Icono personalizado

Establece `icon` con un nombre de Font Awesome, una URL o ruta de imagen, o un SVG en línea. Usa `iconType` para seleccionar el estilo de un nombre de Font Awesome sin prefijo.

<Prompt title="Planificar un tutorial" icon="pen-nib" iconType="duotone">
Esboza un tutorial práctico que lleve a un nuevo usuario desde la instalación hasta una solicitud de API exitosa en menos de diez minutos.
</Prompt>

```mdx
<Prompt title="Plan a tutorial" icon="pen-nib" iconType="duotone">
  Outline a hands-on tutorial that gets a new user from installation to a
  successful API request in under ten minutes.
</Prompt>
```

Consulta [Iconos](/es/content/icons) para conocer los nombres y estilos disponibles.

## Vistas compactas

La vista previa muestra hasta tres líneas y se desplaza cuando un prompt es más largo; el control Expand abre el prompt completo. Establece `singleLine` para limitar la vista previa a una sola línea en su lugar. En cualquier caso, el prompt completo y visible para el humano se sigue copiando o enviando mediante una acción de apertura.

<Prompt title="Resumir la API">
Resume la API pública en cinco puntos:

- Autenticación y duración de los tokens.
- Convenciones de paginación.
- Límites de tasa y pautas de reintento.
- Formato de errores y códigos comunes.
- Política de versionado y obsolescencia.
</Prompt>

Usa `hidePrompt` con un título cuando la etiqueta por sí sola brinde suficiente contexto a los lectores:

<Prompt title="Generar una lista de verificación de migración" hidePrompt actions={["claude"]}>
Crea una lista de verificación de migración para pasar de la API v1 a v2. Incluye los prerrequisitos, los cambios de código, los pasos de validación, los criterios de reversión y la aprobación final del responsable.
</Prompt>

```mdx
<Prompt title="Summarize the API">
  Summarize the public API in five bullets:

  - Authentication and token lifetimes.
  - Pagination conventions.
  - Rate limits and retry guidance.
  - Error format and common codes.
  - Versioning and deprecation policy.
</Prompt>

<Prompt title="Generate a migration checklist" hidePrompt actions={["claude"]}>
  Create a migration checklist for moving from API v1 to v2. Include
  prerequisites, code changes, validation steps, and rollback criteria.
</Prompt>
```

`hidePrompt` solo oculta la vista previa cuando `title` está presente. Sin título, Jamdesk mantiene el prompt visible para que la tarjeta siga siendo comprensible.

## Props

<ParamField name="children" type="ReactNode">
  El contenido del prompt entre las etiquetas de apertura y cierre. Jamdesk conserva exactamente el Markdown redactado y visible para el humano para las acciones Copy y de apertura; también renderiza este contenido como vista previa, salvo que `description` reemplace la vista previa o `hidePrompt` la oculte. El filtrado de Visibility sigue las reglas descritas anteriormente.
</ParamField>

<ParamField name="title" type="string">
  Etiqueta mostrada en el encabezado de la tarjeta. No se muestra ningún título de forma predeterminada.
</ParamField>

<ParamField name="description" type="string">
  Vista previa compacta en Markdown en línea, aceptada por compatibilidad con Mintlify. Solo modifica la vista previa visible; el contenido redactado y visible para el humano sigue siendo el prompt que se copia o se envía.
</ParamField>

<ParamField name="icon" type="string | ReactElement" default="sparkles">
  Icono del encabezado. Acepta un nombre de Font Awesome, una URL o ruta de imagen, o un elemento SVG en línea.
</ParamField>

<ParamField name="iconType" type="regular | solid | light | thin | sharp-solid | duotone | brands">
  Estilo de Font Awesome aplicado a un icono de tipo cadena sin prefijo. No modifica las URL de imagen, las rutas, los nombres ya prefijados ni los elementos SVG en línea.
</ParamField>

<ParamField name="actions" type="('copy' | 'cursor' | 'claude' | 'chatgpt' | 'perplexity' | 'gemini' | CustomAction)[]" default="[]">
  Acciones de apertura en el orden de visualización. `CustomAction` es `{ label: string; url: string; icon?: string }`. Copy siempre se muestra; se acepta una entrada `copy` explícita y se elimina su duplicado. Las acciones de apertura no válidas, duplicadas o de tamaño excesivo se omiten.
</ParamField>

<ParamField name="singleLine" type="boolean | string" default="false">
  Recorta la vista previa visible a una línea cuando se establece en el booleano `true` o la cadena `"true"`. La cadena `"false"` permanece desactivada y el prompt completo sigue siendo utilizado por cada acción.
</ParamField>

<ParamField name="hidePrompt" type="boolean | string" default="false">
  Oculta la vista previa visible cuando hay un título presente y el valor es el booleano `true` o la cadena `"true"`. Sin título, la vista previa permanece visible. La cadena `"false"` permanece desactivada.
</ParamField>

<ParamField name="className" type="string">
  Nombres de clases CSS adicionales aplicados al elemento raíz de la tarjeta Prompt.
</ParamField>
