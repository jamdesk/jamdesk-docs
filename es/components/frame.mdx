Frame envuelve imágenes y demos en un contenedor con borde y subtítulos opcionales.

Las capturas de pantalla muestran la interfaz en inglés.

Usa Frame cuando quieras:
- Dar a las capturas de pantalla e imágenes de la interfaz un aspecto acabado
- Añadir subtítulos para explicar lo que ven los lectores
- Distinguir la salida de una demo del contenido habitual
- Crear consistencia visual en toda tu documentación

## Uso

```mdx
<Frame caption="Architecture diagram">
  ![Diagram](/images/city-skyline.jpg)
</Frame>
```

## Frame básico

<Frame>
  ![Horizonte de la ciudad](/images/city-skyline.webp)
</Frame>

```mdx
<Frame>
  ![City skyline](/images/city-skyline.webp)
</Frame>
```

## Con subtítulo

Añade un subtítulo debajo del marco:

<Frame caption="Nueva York al atardecer">
  ![Horizonte de la ciudad](/images/city-skyline.webp)
</Frame>

```mdx
<Frame caption="New York City at dusk">
  ![City skyline](/images/city-skyline.webp)
</Frame>
```

## Enmarcar otro contenido

Frame funciona con cualquier contenido, no solo imágenes:

<Frame caption="Ejemplo de salida de código">
```
✓ Build completed successfully
✓ 42 pages generated
✓ Deployed to production
```
</Frame>

## Cuándo NO usar Frame

- **Imágenes decorativas en línea** - las imágenes normales en markdown son adecuadas para ilustraciones
- **Iconos o gráficos pequeños** - Frame añade peso visual innecesario
- **Imágenes que fluyen con el texto** - Frame crea una ruptura visual; utilízalo para elementos visuales independientes

## Mejores prácticas

- **Mantén los subtítulos concisos** - una oración que explique lo que ve el lector
- **Úsalo de forma consistente** - si enmarcas una captura de pantalla, enmarca todas las capturas de pantalla para mantener la consistencia visual
- **No abuses del enmarcado** - reserva los marcos para elementos visuales importantes, no para cada imagen de la página

## Propiedades

<ParamField name="caption" type="string">
  Texto opcional debajo del marco.
</ParamField>
