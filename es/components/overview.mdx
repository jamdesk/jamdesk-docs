Jamdesk incluye componentes MDX que puedes usar en cualquier página. Este resumen te ayuda a elegir el componente adecuado para tu contenido.

## Uso

Inserta los componentes directamente en tu MDX:

```mdx
<Card title="Quickstart" icon="rocket" href="/quickstart">
  Launch your docs in minutes.
</Card>
```

## Diseño y navegación

<Columns cols={3}>
  <Card title="Accordion" icon="chevron-down" href="/es/components/accordion">
    Secciones de contenido plegables que permiten a los usuarios expandir solo lo que necesitan. Ideal para preguntas frecuentes, listas de funciones y opciones de configuración.
  </Card>
  <Card title="Card" icon="square" href="/es/components/card">
    Aprende a usar el componente Card para crear contenedores interactivos y con estilo, con iconos, imágenes, enlaces y CTA en diseños de cuadrícula.
  </Card>
  <Card title="Columns" icon="columns" href="/es/components/columns">
    Diseño de cuadrícula responsivo para mostrar Cards, Tiles y otro contenido en paralelo. Se adapta automáticamente al tamaño de la pantalla.
  </Card>
  <Card title="Frame" icon="image" href="/es/components/frame">
    Frame envuelve imágenes y demostraciones en un contenedor con borde y leyendas opcionales, manteniendo una presentación visual coherente en la documentación.
  </Card>
  <Card title="Panel" icon="sidebar" href="/es/components/panel">
    Usa Panel para fijar contenido personalizado, como avisos o referencias rápidas, en la barra lateral, manteniéndolo visible mientras los lectores se desplazan.
  </Card>
  <Card title="Steps" icon="list-ol" href="/es/components/steps">
    Guías numeradas paso a paso para flujos de configuración, tutoriales y solución de problemas. Admite iconos, bloques de código y contenido anidado.
  </Card>
  <Card title="Tabs" icon="folder" href="/es/components/tabs">
    Paneles intercambiables para contenido mutuamente excluyente, como gestores de paquetes o lenguajes. Los títulos de pestaña coincidentes se sincronizan en toda la página.
  </Card>
  <Card title="Tile" icon="grid-2" href="/es/components/tile">
    Los Tiles muestran vistas previas de contenido con un fondo de patrón estilizado y un área de imagen destacada. Úsalos para integraciones, plantillas o galerías visuales.
  </Card>
  <Card title="Tree" icon="folder-tree" href="/es/components/tree">
    Muestra jerarquías de archivos y carpetas con expansión/contracción interactiva y navegación por teclado. Ideal para documentar la estructura de un proyecto.
  </Card>
  <Card title="View" icon="window-maximize" href="/es/components/view">
    Crea documentación que se adapta al framework o lenguaje que elija el lector. Secciones completas cambian según la selección del usuario.
  </Card>
</Columns>

## Contenido y énfasis

<Columns cols={3}>
  <Card title="Badge" icon="tag" href="/es/components/badge">
    Etiquetas en línea para estados, categorías y metadatos: 11 variantes de color, 4 tamaños, iconos, formas de píldora/redondeadas y contornos.
  </Card>
  <Card title="Callouts" icon="circle-info" href="/es/components/callouts">
    Aprende a usar los componentes Note, Tip, Warning, Danger, Check y Callout personalizados para resaltar información clave en tu documentación.
  </Card>
  <Card title="Expandable" icon="expand" href="/es/components/expandable">
    Expandable crea un simple interruptor de mostrar/ocultar para contenido que los lectores pueden querer ver, pero que no es esencial para el flujo principal.
  </Card>
  <Card title="Tooltip" icon="message" href="/es/components/tooltip">
    Muestra definiciones y contexto al pasar el cursor. Define términos, explica siglas o enlaza a contenido relacionado sin saturar la página.
  </Card>
  <Card title="Update" icon="clock-rotate-left" href="/es/components/update">
    Entradas de registro de cambios estilo línea de tiempo, con fechas, descripciones y etiquetas de categoría. Se integra con tu tabla de contenido para la navegación.
  </Card>
  <Card title="Visibility" icon="eye" href="/es/components/visibility">
    Muestra contenido diferente a lectores humanos y a agentes de IA en la misma página. Contexto, instrucciones y definiciones exclusivos para agentes, que no aparecen en la documentación renderizada.
  </Card>
</Columns>

## Código y datos

<Columns cols={3}>
  <Card title="CodeGroup" icon="layer-group" href="/es/components/code-group">
    Muestra bloques de código en una interfaz con pestañas. Presenta la misma operación en varios lenguajes, como cURL, Python y JavaScript.
  </Card>
  <Card title="Examples" icon="code" href="/es/components/examples">
    Fija bloques de código en una barra lateral derecha fija en escritorio para que los lectores puedan consultarlos mientras se desplazan. Admite lenguajes en pestañas.
  </Card>
  <Card title="Fields" icon="list" href="/es/components/fields">
    Documenta los parámetros de la API y los campos de respuesta con los componentes ParamField y ResponseField. Admite tipos, valores predeterminados y objetos anidados.
  </Card>
  <Card title="Prompt" icon="wand-magic-sparkles" href="/es/components/prompt">
    Usa Prompt para presentar instrucciones de IA reutilizables con copia, acciones integradas de abrir en, destinos personalizados, iconos y opciones de visualización compacta.
  </Card>
  <Card title="Tables" icon="table" href="/es/components/tables">
    Organiza los datos en filas y columnas. Admite tablas en markdown y componentes Table con ordenación, resaltado y combinación de celdas.
  </Card>
</Columns>

## Diagramas y elementos visuales

<Columns cols={3}>
  <Card title="Color" icon="palette" href="/es/components/color">
    El componente Color muestra paletas de colores para documentar sistemas de diseño, guías de marca o cualquier especificación de color.
  </Card>
  <Card title="Mermaid Diagrams" icon="diagram-project" href="/es/components/mermaid">
    Genera diagramas de flujo, diagramas de secuencia, líneas de tiempo, gráficos circulares y más a partir de sintaxis Mermaid basada en texto. Los diagramas se generan como SVG en el momento del build.
  </Card>
  <Card title="D2 Diagrams" icon="diagram-project" href="/es/components/d2">
    Genera diagramas de arquitectura, diagramas de flujo, secuencias y modelos SQL a partir de sintaxis D2 basada en texto. Los diagramas se renderizan como SVG con temas claro y oscuro automáticos.
  </Card>
</Columns>
