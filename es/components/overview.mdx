title: Descripción general de componentes
description: >-
  Explora los componentes MDX de Jamdesk (tarjetas, pestañas, llamadas y
  bloques de código) para encontrar el más adecuado para tu documentación.
---

Jamdesk incluye componentes MDX que puedes usar en cualquier página. Esta descripción general te ayuda a elegir el componente adecuado para tu contenido.

## Uso

Agrega componentes directamente en tu MDX:

```mdx
<Card title="Quickstart" icon="rocket" href="/quickstart">
  Launch your docs in minutes.
</Card>
```

  <Card title="Card" icon="square" href="/es/components/card">

  </Card>
  <Card title="Columnas" icon="columns" href="/es/components/columns">

  </Card>
  <Card title="Frame" icon="image" href="/es/components/frame">
    Frame envuelve imágenes y demos en un contenedor con borde y leyendas opcionales, manteniendo la consistencia visual de la documentación.
  </Card>
  <Card title="Panel" icon="sidebar" href="/es/components/panel">
    Usa Panel para fijar contenido personalizado, como advertencias o referencias rápidas, en la barra lateral, visible mientras los lectores se desplazan.
  </Card>
  <Card title="Steps" icon="list-ol" href="/es/components/steps">
    Guías numeradas paso a paso para flujos de configuración, tutoriales y solución de problemas. Admite iconos, bloques de código y contenido anidado.
  </Card>
  <Card title="Pestañas" icon="folder" href="/es/components/tabs">
    Paneles alternables para contenido mutuamente excluyente como gestores de paquetes o lenguajes. Los títulos coincidentes se sincronizan en toda la página.
  </Card>
  <Card title="Tile" icon="grid-2" href="/es/components/tile">
    Los Tiles muestran vistas previas de contenido con fondo de patrón estilizado y área de imagen destacada. Úsalos para integraciones o galerías.
  </Card>
  <Card title="Tree" icon="folder-tree" href="/es/components/tree">
    Muestra jerarquías de archivos y carpetas con expansión/colapso interactivo y navegación por teclado. Ideal para documentar la estructura de proyectos.
  </Card>
  <Card title="View" icon="window-maximize" href="/es/components/view">
    Cree documentación que se adapta al framework o idioma que elija el lector. Secciones completas cambian según la selección.
  </Card>
</Columns>

## Contenido y énfasis

<Columns cols={3}>
  <Card title="Badge" icon="tag" href="/es/components/badge">

  </Card>
  <Card title="Callouts" icon="circle-info" href="/es/components/callouts">

  </Card>
  <Card title="Expandable" icon="expand" href="/es/components/expandable">
    Expandable crea un simple interruptor mostrar/ocultar para contenido que los lectores pueden querer ver pero que no es esencial para el flujo principal.
  </Card>
  <Card title="Tooltip" icon="message" href="/es/components/tooltip">
    Muestra definiciones y contexto al pasar el cursor. Define términos, explica acrónimos o enlaza a contenido relacionado sin sobrecargar la página.
  </Card>
  <Card title="Update" icon="clock-rotate-left" href="/es/components/update">
    Entradas de changelog estilo línea de tiempo con fechas, descripciones y etiquetas de categoría. Se integra con tu Tabla de contenidos para la navegación.
  </Card>
  <Card title="Visibilidad" icon="eye" href="/es/components/visibility">
    Muestra contenido distinto a lectores y agentes de IA. Contexto, instrucciones y definiciones para agentes, fuera de los docs renderizados.
  </Card>
</Columns>

## Código y datos

<Columns cols={3}>
  <Card title="CodeGroup" icon="layer-group" href="/es/components/code-group">
    Muestra bloques de código en una interfaz con pestañas. Presenta la misma operación en varios lenguajes como cURL, Python y JavaScript.
  </Card>
  <Card title="Ejemplos" icon="code" href="/es/components/examples">
    Ancla bloques de código en una barra lateral derecha fija en escritorio para consultarlos mientras haces scroll. Admite lenguajes en pestañas.
  </Card>
  <Card title="Campos" icon="list" href="/es/components/fields">
    Documenta parámetros de API y campos de respuesta con los componentes ParamField y ResponseField. Soporta tipos, valores por defecto y objetos anidados.
  </Card>
  <Card title="Prompt" icon="wand-magic-sparkles" href="/es/components/prompt">
    Usa Prompt para presentar instrucciones de IA reutilizables con copia, acciones de apertura integradas, destinos, iconos y opciones de vista compacta.
  </Card>
  <Card title="Tablas" icon="table" href="/es/components/tables">
    Organiza datos en filas y columnas. Admite tablas markdown y componentes Table con ordenación, resaltado y combinación de celdas.
  </Card>
</Columns>
