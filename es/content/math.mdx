---
title: Matemáticas y LaTeX
description: Renderiza expresiones matemáticas y ecuaciones con KaTeX y sintaxis LaTeX. Requiere que styling.latex esté configurado como true en docs.json.
---

Jamdesk admite LaTeX para renderizar expresiones matemáticas y ecuaciones usando [KaTeX](https://katex.org/).

<Note>
El soporte matemático requiere `styling.latex: true` en tu archivo `docs.json`.
</Note>

## Habilitar el soporte matemático

Añade a tu `docs.json`:

```json
{
  "styling": {
    "latex": true
  }
}
```

## Matemáticas en línea

Usa signos de dólar simples para ecuaciones en línea:

```md
The Pythagorean theorem states that $a^2 + b^2 = c^2$.
```

**Se renderiza como:** The Pythagorean theorem states that $a^2 + b^2 = c^2$.

## Ecuaciones en bloque

Usa signos de dólar dobles para ecuaciones centradas en modo de visualización:

```md
$$
E = mc^2
$$
```

**Se renderiza como:**

$$
E = mc^2
$$

## Ecuaciones complejas

KaTeX admite una amplia gama de notación LaTeX:

### Fracciones

```md
$$
\frac{n!}{k!(n-k)!} = \binom{n}{k}
$$
```

### Integrales

```md
$$
\int_0^\infty e^{-x^2} dx = \frac{\sqrt{\pi}}{2}
$$
```

### Sumatorias

```md
$$
\sum_{i=1}^{n} i = \frac{n(n+1)}{2}
$$
```

### Matrices

```md
$$
\begin{bmatrix}
a & b \\
c & d
\end{bmatrix}
$$
```

## Usar el componente Latex

Para mayor control, usa el componente `<Latex>` directamente:

```mdx
<Latex>E = mc^2</Latex>
```

Para el modo bloque/visualización:

```mdx
<Latex block>
\int_0^\infty e^{-x^2} dx = \frac{\sqrt{\pi}}{2}
</Latex>
```

## Los bloques de código están protegidos

Los signos de dólar dentro de bloques de código **no** se tratan como matemáticas:

```bash
echo $HOME
export PRICE=$100
```

Esto se renderiza como código normal, no como ecuaciones.

## Comandos admitidos

KaTeX admite la mayoría de los comandos matemáticos LaTeX comunes. Consulta la [documentación de KaTeX](https://katex.org/docs/supported.html) para obtener una lista completa de las funciones admitidas.

<Tip>
Para ecuaciones complejas, prueba tu LaTeX en la [página de demo de KaTeX](https://katex.org/) primero.
</Tip>
