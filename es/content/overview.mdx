Las páginas de Jamdesk son archivos MDX: Markdown estándar con componentes de React disponibles donde los necesites. Una página es solo frontmatter más contenido.

```mdx
---
title: Rate Limits
description: How rate limiting works across API tiers.
---

Requests are limited per API key.

<Note>Enterprise plans have custom limits.</Note>
```

La mayor parte de lo que escribirás es Markdown normal. Las páginas de esta sección cubren el resto: bloques de código con resaltado de sintaxis, imágenes y video, notación matemática, snippets reutilizables, y los campos de frontmatter que controlan títulos, iconos y metadatos SEO.
