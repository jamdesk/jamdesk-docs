Empieza aquí cuando algo no funcione. Cada sección ofrece una solución rápida y enlaza con la guía completa en el Centro de ayuda.

## Fallos de build

**Síntoma:** el estado del build aparece como "Failed" en el dashboard.

**Comprobaciones rápidas:**
1. Ejecuta `jamdesk dev` localmente para detectar errores de sintaxis MDX
2. Verifica que `docs.json` sea JSON válido (comas ausentes o comas finales)
3. Comprueba que todas las páginas listadas en la navegación existan como archivos `.mdx`

<Tip>
El log del build en tu dashboard muestra el archivo y la línea exactos donde se produjo el error. Empieza por ahí.
</Tip>

Consulta [Fallos de build](/es/help/troubleshooting/build-failures) y [Referencia de errores](/es/help/troubleshooting/error-reference) para códigos de error específicos.

## La verificación del dominio personalizado falla

**Síntoma:** el dominio se queda en "Pending" después de añadir los registros DNS.

**Comprobaciones rápidas:**
1. Confirma que añadiste un registro **CNAME** (no un registro A) para los subdominios
2. Si usas Cloudflare, configura el proxy como **DNS only** (nube gris)
3. Comprueba la propagación en [whatsmydns.net](https://www.whatsmydns.net/)

```bash
# Verify your CNAME is resolving
dig CNAME docs.yourdomain.com
```

Consulta [Resolución de problemas de DNS](/es/help/troubleshooting/dns-issues) para obtener indicaciones específicas según el proveedor.

## El repositorio de GitHub no aparece

**Síntoma:** tu repositorio no aparece al crear un proyecto.

**Comprobaciones rápidas:**
1. Verifica que la GitHub App de Jamdesk esté instalada en la organización del repositorio
2. Comprueba que el acceso al repositorio esté configurado como "All repositories" o que el repositorio concreto esté seleccionado
3. Vuelve a autorizar en [github.com/settings/installations](https://github.com/settings/installations)

Consulta [Problemas con GitHub](/es/help/troubleshooting/github-issues) para incidencias con webhooks y permisos.

## Faltan datos de analítica

**Síntoma:** el dashboard muestra cero visitantes o datos desactualizados.

**Comprobaciones rápidas:**
1. La analítica puede tardar hasta 24 horas en aparecer tras el primer despliegue
2. Los bloqueadores de anuncios y Do Not Track impiden que se contabilicen algunas visitas
3. Verifica que tu sitio esté desplegado y sea accesible públicamente

Consulta [Problemas de analítica](/es/help/troubleshooting/analytics-issues) para datos retrasados o ausentes.

## Problemas al iniciar sesión

**Síntoma:** no puedes iniciar sesión o se te redirige al login repetidamente.

**Comprobaciones rápidas:**
1. Borra la caché y las cookies del navegador para `dashboard.jamdesk.com`
2. Prueba en una ventana de incógnito o privada
3. Si usas SSO de GitHub, verifica que tu correo de GitHub coincida con el de tu cuenta de Jamdesk

Consulta [Problemas al iniciar sesión](/es/help/troubleshooting/login-issues) para conocer los pasos de recuperación de cuenta.
