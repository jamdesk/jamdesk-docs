Empieza aquí cuando algo no funcione. Cada sección ofrece una solución rápida y enlaces a la guía completa en el Centro de ayuda.

## Fallos de build

**Síntoma:** El estado del build muestra "Failed" en el dashboard.

**Comprobaciones rápidas:**
1. Ejecuta `jamdesk dev` localmente para detectar errores de sintaxis MDX
2. Verifica que `docs.json` sea JSON válido (comas faltantes, comas finales)
3. Comprueba que todas las páginas listadas en la navegación existen como archivos `.mdx`

<Tip>
El registro de build en tu dashboard muestra el archivo exacto y la línea donde ocurrió el error. Empieza por ahí.
</Tip>

Consulta [Fallos de build](/es/help/troubleshooting/build-failures) y [Referencia de errores](/es/help/troubleshooting/error-reference) para códigos de error específicos.

## Dominio personalizado sin verificar

**Síntoma:** El dominio se queda en "Pending" después de agregar los registros DNS.

**Comprobaciones rápidas:**
1. Confirma que agregaste un registro **CNAME** (no un registro A) para los subdominios
2. Si usas Cloudflare, configura el proxy en modo **DNS only** (nube gris)
3. Comprueba la propagación en [whatsmydns.net](https://www.whatsmydns.net/)

```bash
# Verify your CNAME is resolving
dig CNAME docs.yourdomain.com
```

Consulta [Solución de problemas de DNS](/es/help/troubleshooting/dns-issues) para orientación específica según el proveedor.

## Repositorio de GitHub no aparece

**Síntoma:** Tu repositorio no aparece al crear un proyecto.

**Comprobaciones rápidas:**
1. Verifica que la aplicación GitHub de Jamdesk esté instalada en la organización del repositorio
2. Comprueba que el acceso al repositorio esté configurado como "All repositories" o que el repositorio específico esté seleccionado
3. Vuelve a autorizar en [github.com/settings/installations](https://github.com/settings/installations)

Consulta [Problemas con GitHub](/es/help/troubleshooting/github-issues) para problemas de Webhook y permisos.

## Datos de analítica faltantes

**Síntoma:** El dashboard muestra cero visitantes o datos desactualizados.

**Comprobaciones rápidas:**
1. La analítica puede tardar hasta 24 horas en aparecer tras el primer despliegue
2. Los bloqueadores de anuncios y la opción "Do Not Track" impiden que algunos accesos se contabilicen
3. Verifica que tu sitio esté desplegado y sea accesible públicamente

Consulta [Problemas de analítica](/es/help/troubleshooting/analytics-issues) para datos retrasados o faltantes.

## Problemas de inicio de sesión

**Síntoma:** No puedes iniciar sesión o te redirige repetidamente a la página de login.

**Comprobaciones rápidas:**
1. Borra la caché del navegador y las cookies de `dashboard.jamdesk.com`
2. Prueba con una ventana de incógnito o privada
3. Si usas GitHub SSO, verifica que tu correo de GitHub coincida con tu cuenta de Jamdesk

Consulta [Problemas de inicio de sesión](/es/help/troubleshooting/login-issues) para los pasos de recuperación de cuenta.
