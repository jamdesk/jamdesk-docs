Antes de escribir cualquier documentación necesitas un proyecto. Puedes empezar desde una plantilla (Jamdesk crea el repositorio por ti, en GitHub o Bitbucket Cloud) o conectar un repositorio existente que ya tenga un `docs.json`. En cualquier caso, tendrás un sitio en línea en pocos minutos.

## Crear un nuevo proyecto

<Steps>
  <Step title="Iniciar sesión en Jamdesk">
    Ve a [dashboard.jamdesk.com](https://dashboard.jamdesk.com) e inicia sesión con tu cuenta de GitHub.

    A los usuarios nuevos se les pedirá que autoricen la aplicación de GitHub de Jamdesk.
  </Step>

  <Step title="Hacer clic en New Project">
    Desde el dashboard, haz clic en **New Project** en la esquina superior derecha.
  </Step>

  <Step title="Elegir un punto de partida">
    <Tabs>
      <Tab title="Desde una plantilla">
        Empieza con una plantilla prediseñada. Jamdesk crea un nuevo repositorio de GitHub para ti, con contenido de ejemplo, navegación y componentes ya configurados.

        La [plantilla inicial](https://github.com/jamdesk/starter-docs) predeterminada incluye páginas de ejemplo, una especificación OpenAPI y ejemplos de todos los componentes. Reemplaza el contenido con el tuyo y listo.
      </Tab>
      <Tab title="Desde un repositorio">
        Conecta un repositorio de GitHub existente:

        1. Selecciona el repositorio en el menú desplegable
        2. Elige la rama que se va a desplegar (normalmente `main`)
        3. Indica la ruta a `docs.json` si no está en la raíz

        ¿Repositorio en Bitbucket Cloud? Indícalo como `workspace/repository-slug` en su lugar. Consulta [Conectar Bitbucket](/es/setup/connecting-bitbucket).
      </Tab>
    </Tabs>
  </Step>

  <Step title="Configurar los ajustes del proyecto">
    Configura la información básica de tu proyecto:

    | Campo | Descripción |
    |-------|-------------|
    | **Name** | Nombre que se muestra en el dashboard |
    | **Slug** | Identificador apto para URL (p. ej., `my-docs`) |
    | **Domain** | Tu subdominio `*.jamdesk.app` |
  </Step>
</Steps>

## Estructura mínima del repositorio

Un proyecto de Jamdesk solo necesita un `docs.json` y al menos una página:

```bash
my-docs/
├── docs.json
└── introduction.mdx
```

Ejemplo de `docs.json`:

```json docs.json
{
  "$schema": "https://jamdesk.com/docs.json",
  "name": "My Docs",
  "theme": "jam",
  "navigation": {
    "groups": [
      {
        "group": "Getting Started",
        "pages": ["introduction"]
      }
    ]
  }
}
```

## Ajustes del proyecto

Después de crearlo, configura tu proyecto en **Settings**:

### General

- **Name** - Actualiza el nombre que se muestra
- **Slug** - Cambia el identificador del proyecto
- **Delete Project** - Elimina el proyecto de forma permanente

### Repositorio

- **Branch** - La rama que activa los despliegues
- **Docs Path** - Ubicación de `docs.json` para monorepos

### Dominio

- **Subdomain** - Tu URL `*.jamdesk.app`
- **Custom Domain** - Añade tu propio dominio
- **Host at a subpath** - Sirve la documentación en una ruta como `/docs` o `/help` en lugar de la raíz del sitio

### Build

- **Show Jamdesk Branding** - Muestra el enlace "Powered by Jamdesk" en tu pie de página (activado por defecto)
- **Rebuild** - Activa manualmente un nuevo build

<Note>
Los cambios en los ajustes de Build requieren un nuevo build para aplicarse.
</Note>
