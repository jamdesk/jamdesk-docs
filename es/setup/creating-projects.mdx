Antes de escribir cualquier documentación necesitas un proyecto. Puedes empezar desde una plantilla (Jamdesk crea el repositorio de GitHub por ti) o conectar un repositorio existente que ya tenga un `docs.json`. De cualquier forma, tendrás un sitio en vivo en pocos minutos.

## Crear un nuevo proyecto

<Steps>
  <Step title="Inicia sesión en Jamdesk">
    Ve a [dashboard.jamdesk.com](https://dashboard.jamdesk.com) e inicia sesión con tu cuenta de GitHub.

    A los usuarios nuevos se les pedirá que autoricen la Jamdesk GitHub App.
  </Step>

  <Step title="Haz clic en New Project">
    Desde el dashboard, haz clic en **New Project** en la esquina superior derecha.
  </Step>

  <Step title="Elige un punto de partida">
    <Tabs>
      <Tab title="From Template">
        Comienza con una plantilla preconstruida. Jamdesk crea un nuevo repositorio de GitHub para ti con contenido de muestra, navegación y componentes ya configurados.

        La [Starter Template](https://github.com/jamdesk/starter-docs) predeterminada incluye páginas de muestra, una especificación OpenAPI y ejemplos de cada componente. Reemplaza el contenido con el tuyo y listo.
      </Tab>
      <Tab title="From Repository">
        Conecta un repositorio de GitHub existente:

        1. Selecciona el repositorio en el menú desplegable
        2. Elige la rama a desplegar (normalmente `main`)
        3. Especifica la ruta a `docs.json` si no está en la raíz
      </Tab>
    </Tabs>
  </Step>

  <Step title="Configura los ajustes del proyecto">
    Define la información básica de tu proyecto:

    | Campo | Descripción |
    |-------|-------------|
    | **Name** | Nombre visible que se muestra en el dashboard |
    | **Slug** | Identificador amigable para URL (por ejemplo, `my-docs`) |
    | **Domain** | Tu subdominio `*.jamdesk.app` |
  </Step>
</Steps>

## Estructura mínima del repositorio

Un proyecto de Jamdesk solo necesita un `docs.json` y al menos una página:

```bash
my-docs/
├── docs.json
└── introduction.mdx
```

Ejemplo de `docs.json`:

```json docs.json
{
  "$schema": "https://jamdesk.com/docs.json",
  "name": "My Docs",
  "theme": "jam",
  "navigation": {
    "groups": [
      {
        "group": "Getting Started",
        "pages": ["introduction"]
      }
    ]
  }
}
```

## Ajustes del proyecto

Después de la creación, configura tu proyecto en **Settings**:

### General

- **Name** - Actualiza el nombre visible
- **Slug** - Cambia el identificador del proyecto
- **Delete Project** - Elimina el proyecto de forma permanente

### Repository

- **Branch** - Qué rama activa los despliegues
- **Docs Path** - Ubicación de `docs.json` para monorepos

### Domain

- **Subdomain** - Tu URL `*.jamdesk.app`
- **Custom Domain** - Agrega tu propio dominio
- **Host at /docs** - Sirve la documentación en la ruta `/docs` en lugar de la raíz

### Build

- **Show Jamdesk Branding** - Muestra el enlace "Powered by Jamdesk" en tu pie de página (activado por defecto)
- **Rebuild** - Activa manualmente un nuevo build

<Note>
Los cambios en los ajustes de build requieren un nuevo build para surtir efecto.
</Note>
