Jamdesk se integra con GitHub para desplegar automáticamente tu documentación con cada push.

Las capturas de pantalla muestran la interfaz en inglés.

<Note>

</Note>

<Tip>

</Tip>

## Instalación de la aplicación de GitHub

Cuando inicias sesión en Jamdesk por primera vez, se te pedirá que instales la aplicación de GitHub de Jamdesk. Esta aplicación permite:

- **Acceso al repositorio** - Leer el contenido de tu documentación
- **Webhooks** - Activar builds con cada push
- **Estado del commit** - Mostrar el estado del build en los commits

### Permisos

La aplicación de GitHub de Jamdesk solicita estos permisos:

| Permiso | Finalidad |
|------------|---------|
| Contenido del repositorio (lectura) | Clonar y leer los archivos de tu documentación |
| Metadatos (lectura) | Listar repositorios y ramas |
| Webhooks | Recibir notificaciones de push |

<Note>
Jamdesk solo accede a los repositorios a los que le concedes acceso explícitamente. Puedes modificar el acceso en cualquier momento desde la configuración de GitHub.
</Note>

## Conectar un repositorio

<Steps>
  <Step title="Seleccionar repositorio">
    Al crear o editar un proyecto, haz clic en **Connect Repository**.

    Elige entre los repositorios donde la aplicación de GitHub esté instalada.
  </Step>

  <Step title="Elegir rama">
    Selecciona la rama que quieres desplegar:

    - **main** o **master** - La más común para documentación en producción
    - **docs** - Si mantienes la documentación en una rama separada
    - Cualquier rama - Para despliegues de preview
  </Step>

  <Step title="Especificar la ruta de la documentación">
    Si tu `docs.json` no está en la raíz del repositorio, especifica la ruta:

    ```bash
    docs/           # Docs in a subdirectory
    packages/docs/  # Monorepo with docs package
    ```

    Déjalo en blanco si `docs.json` está en la raíz.
  </Step>
</Steps>

Una vez conectado, el dashboard de tu proyecto muestra el repositorio y la rama vinculados:

## Despliegues automáticos

Una vez conectado, cada push a tu rama configurada activa un build:

```bash
git add .
git commit -m "Update API documentation"
git push origin main
```

Los builds normalmente se completan en 30 a 90 segundos. Consulta el estado en el dashboard o en el commit de GitHub.

## Cambiar de repositorio

Para conectar un repositorio diferente:

1. Ve a **Settings** → **Repository**
2. Haz clic en **Change Repository**
3. Selecciona el nuevo repositorio y la rama

<Warning>
Cambiar de repositorio puede afectar tu documentación en producción. El nuevo repositorio debe contener una configuración de Jamdesk válida.
</Warning>

## Administrar el acceso de la aplicación de GitHub

Controla a qué repositorios puede acceder Jamdesk:

1. Ve a [github.com/settings/installations](https://github.com/settings/installations)
2. Busca **Jamdesk** en la lista
3. Haz clic en **Configure**
4. En «Repository access», selecciona repositorios específicos o todos

### Repositorios de organización

En el caso de los repositorios de organización, un administrador de la organización debe aprobar la instalación de la aplicación de GitHub:

1. Solicita la instalación desde tu dashboard de Jamdesk
2. Un administrador recibe una notificación en GitHub
3. Una vez aprobada, los repositorios de la organización aparecen en el selector de repositorios

## Vincular tu cuenta personal

Para una atribución de builds fiable, vincula tu cuenta personal de GitHub en **User Settings**:

1. Haz clic en tu avatar → **User Settings**
2. Busca la sección **GitHub Account**
3. Haz clic en **Link GitHub Account**

Esto es independiente de la aplicación de GitHub y garantiza que tus commits se te atribuyan correctamente. [Más información](/es/integrations/github#cuenta-personal-de-github-a-nivel-de-usuario).

## Solución de problemas

### El repositorio no aparece

- Verifica que la aplicación de GitHub esté instalada en el repositorio
- En repositorios de organización, confirma que un administrador haya aprobado el acceso
- Intenta actualizar la lista de repositorios en el dashboard

### GitHub te sigue redirigiendo a la página de la aplicación de Jamdesk

Es probable que tu empresa gestione tu cuenta de GitHub, y GitHub no permite que estas cuentas instalen aplicaciones en su propia cuenta. Consulta [cuentas de GitHub gestionadas por la empresa](/es/help/troubleshooting/github-issues#cuentas-de-github-gestionadas-por-la-empresa) para solucionarlo.

### Los builds no se activan

- Comprueba que el webhook esté activo en la configuración del repositorio
- Verifica que estás haciendo push a la rama configurada
- Busca errores de entrega del webhook en GitHub

### Errores de permiso denegado

- Vuelve a autorizar la aplicación de GitHub en la configuración de GitHub
- Asegúrate de que el repositorio sea accesible para la aplicación de Jamdesk
