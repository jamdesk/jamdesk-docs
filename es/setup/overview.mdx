Todos los sitios de Jamdesk empiezan de la misma manera: un proyecto en el dashboard, un repositorio de GitHub detrás y un archivo `docs.json` que describe tu navegación. Esta sección cubre esa configuración inicial, además de las decisiones estructurales que vale la pena tomar desde el principio. La estructura de las URL, los idiomas y el control de acceso son mucho más fáciles de definir antes de tener cincuenta páginas que después.

¿Migras desde otra plataforma? Ve directamente a la [Guía de migración](/es/setup/migration). Jamdesk puede automatizar la mayor parte de la conversión.

## Del repositorio al sitio en producción

<Steps>
  <Step title="Crea un proyecto">
    Empieza desde una plantilla o conecta un repositorio de GitHub existente. Tu sitio se publica en `yourproject.jamdesk.app`.
  </Step>
  <Step title="Conecta GitHub">
    Instala la GitHub App para que cada push se despliegue automáticamente.
  </Step>
  <Step title="Organiza el repositorio">
    Un archivo `docs.json` más páginas MDX. Eso es todo el contrato.
  </Step>
</Steps>
