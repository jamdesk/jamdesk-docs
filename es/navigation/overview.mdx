title: Navegación
description: La navegación en Jamdesk usa tabs, groups y pages para organizar tu documentación. Se pueden agregar enlaces externos con anchors.
---

Tu barra lateral y la barra superior se definen íntegramente en `docs.json`. La jerarquía de navegación tiene tres niveles: tabs para secciones de nivel superior, groups para carpetas colapsables y pages para entradas individuales. Los anchors agregan enlaces externos que aparecen en todas las páginas.

Las capturas de pantalla muestran la interfaz en inglés.

## Descripción general de la estructura

```json docs.json
{
  "navigation": {
    "tabs": [
      {
        "tab": "Documentation",
        "icon": "book-open",
        "groups": [
          {
            "group": "Getting Started",
            "pages": ["introduction", "quickstart"]
          }
        ]
      }
    ]
  }
}
```

## Conceptos

### Tabs

Secciones de navegación de nivel superior. Controla su posición con el ajuste `tabsPosition`:

| Valor    | Posición                        |
| -------- | -------------------------------- |
| `"top"`  | En la barra de tabs del encabezado |
| `"left"` | En la parte superior de la barra lateral |

La posición predeterminada depende de tu tema:

| Tema   | Predeterminado |
| ------ | -------- |
| jam    | `"left"` |
| nebula | `"left"` |
| pulsar | `"top"`  |

```json
{
  "tabsPosition": "left",
  "navigation": {
    "tabs": [
      { "tab": "Guides", "icon": "book", "groups": [...] },
      { "tab": "API", "icon": "code", "groups": [...] }
    ]
  }
}
```

<Note>
  Los íconos de la barra lateral se renderizan en la variante Font Awesome Solid de forma predeterminada. Sobrescribe el peso de cualquier
  ícono con un prefijo de estilo (`light/book`) o la
  [forma de objeto de ícono](/es/content/icons#forma-de-objeto-de-icono).
</Note>

### Enlaces externos (Anchors)

Agrega enlaces externos que aparecen en la parte superior de la barra lateral en todas las páginas:

```json
{
  "anchors": [
    { "name": "Blog", "href": "https://blog.example.com", "icon": "newspaper" },
    { "name": "Status", "href": "https://status.example.com", "icon": "signal" }
  ]
}
```

| Campo  | Tipo   | Requerido | Descripción                    |
| ------ | ------ | -------- | ------------------------------ |
| `name` | string | Sí       | Texto que se muestra del enlace |
| `href` | string | Sí       | URL (se abre en una pestaña nueva) |
| `icon` | string | No       | Nombre de ícono de Font Awesome |

### Groups

Un group es un conjunto etiquetado de entradas de la barra lateral dentro de un tab. Los groups agregan un segundo nivel de jerarquía a tu barra lateral y te permiten ocultar secciones más profundas detrás de carpetas estilo acordeón.

```json
{
  "group": "Authentication",
  "pages": ["auth/overview", "auth/tokens"]
}
```

#### Comportamiento de secciones y acordeón

Los groups de nivel superior son secciones permanentes: el título y sus pages siempre están visibles, y al hacer clic en el título se navega a la primera page del group. Los groups con nombre anidados son acordeones contraíbles. Un group anidado empieza cerrado a menos que contenga la page actual o establezca `expanded: true`. Al cargar por primera vez y en los cambios de ruta, toda la cadena de groups ancestros de la page actual se abre automáticamente para revelar el enlace activo; los visitantes aún pueden contraer manualmente el group anidado activo.

| Tipo de group | Comportamiento predeterminado |
| --- | --- |
| **Group de nivel superior** | Siempre abierto, sin chevron. Al hacer clic en el título se navega a la primera page del group. |
| **Group con nombre anidado** | Contraído hasta que esté activo, se abra manualmente o se configure con `expanded: true`. Al hacer clic en un group cerrado, se abre y navega a su primera page. Al hacer clic en un group abierto, se cierra. |
| **Contenedor sin nombre** | Siempre muestra sus pages porque no tiene etiqueta ni control para alternar. |

Usa groups de nivel superior para las secciones principales de tu barra lateral y groups anidados para mantener las secciones más largas fáciles de explorar. El estado de expansión persiste durante la navegación dentro de la app y se reinicia al recargar la página por completo.

#### Campos del group

| Campo | Tipo | Requerido | Descripción |
| --- | --- | --- | --- |
| `group` | string | Sí | Etiqueta que se muestra en la barra lateral. |
| `pages` | array | Sí | Lista de rutas de pages y/o objetos de group anidados (consulta [Groups anidados](#groups-anidados) para conocer la estructura anidada). |
| `icon` | string | No | Nombre de ícono de Font Awesome que se muestra junto a la etiqueta del group. |
| `tag` | string | No | Pequeña insignia junto a la etiqueta (por ejemplo, `"New"`, `"Beta"`). |
| `root` | string | No | Ruta de page a la que enlaza el group cuando se hace clic en la etiqueta (en lugar de saltar a la primera page hija). |
| `hidden` | boolean | No | Oculta el group de la barra lateral de forma predeterminada. Las pages siguen siendo accesibles mediante enlace directo. |
| `public` | boolean | No | Marca el group como de acceso público. Por defecto usa el ajuste del tab superior. |
| `expanded` | boolean | No | Abre un group con nombre anidado de forma predeterminada al cargar la página por primera vez. Los groups de nivel superior siempre están abiertos, así que la opción no tiene efecto visible en ellos. Los groups ancestros de la page actual se abren automáticamente al cargar por primera vez y en los cambios de ruta. |

### Pages

Páginas de documentación individuales, referenciadas por su ruta de archivo (sin `.mdx`):

```json
"pages": ["introduction", "guides/quickstart", "api/endpoints"]
```

De forma predeterminada, el título de la barra lateral se genera a partir del nombre del archivo: los guiones se convierten en espacios y cada palabra se pone en mayúscula inicial. Por ejemplo, `"api/getting-started"` se muestra como "Getting Started".

Para establecer un título personalizado de la barra lateral, usa un objeto en lugar de una cadena:

```json
"pages": [
  "guides/quickstart",
  { "page": "deploy/aws", "title": "AWS Route 53 & CloudFront" },
  { "page": "content/seo", "title": "SEO" },
  { "page": "api/users", "title": "List Users", "method": "GET" }
]
```

Esto es útil para siglas, nombres propios e insignias de endpoints de API.

| Campo | Tipo | Requerido | Descripción |
| --- | --- | --- | --- |
| `page` | string | Sí | Ruta de archivo sin `.mdx` |
| `title` | string | No | Título personalizado de la barra lateral |
| `icon` | string | No | Nombre de ícono de Font Awesome |
| `tag` | string | No | Pequeña insignia junto al título (por ejemplo, "New", "Beta") |
| `method` | string | No | Insignia de método HTTP: GET, POST, PUT, PATCH o DELETE |

## Múltiples tabs

Crea secciones separadas para diferentes audiencias:

```json
{
  "navigation": {
    "tabs": [
      {
        "tab": "Guides",
        "icon": "book",
        "groups": [
          { "group": "Getting Started", "pages": ["intro", "quickstart"] }
        ]
      },
      {
        "tab": "API Reference",
        "icon": "code",
        "groups": [{ "group": "Endpoints", "pages": ["api/auth", "api/users"] }]
      }
    ]
  }
}
```

## Enlaces externos de tabs

Enlaza a documentación o recursos externos directamente desde los tabs:

```json
{
  "navigation": {
    "tabs": [
      { "tab": "Docs", "icon": "book", "groups": [...] },
      { "tab": "GitHub", "icon": "github", "href": "https://github.com/example/repo" }
    ]
  }
}
```

Los tabs externos se abren en una nueva pestaña del navegador.

## Groups anidados

Organiza documentación compleja con estructuras anidadas:

```json
{
  "group": "SDKs",
  "pages": [
    "sdks/overview",
    {
      "group": "JavaScript",
      "pages": ["sdks/js/install", "sdks/js/usage"]
    },
    {
      "group": "Python",
      "pages": ["sdks/python/install", "sdks/python/usage"]
    }
  ]
}
```
