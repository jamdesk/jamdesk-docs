---

Cada build pasa por varias fases desde la cola hasta estar en vivo. Monitorea el progreso desde la pestaña Deployments.

## Fases del Build

<Steps>
  <Step title="En cola">
    El build está esperando para iniciar. La mayoría de los builds comienzan en segundos.
  </Step>
  <Step title="Clonando">
    Descargando el contenido de tu repositorio desde GitHub.
  </Step>
  <Step title="Validando">
    Verificando la configuración de `docs.json` y la sintaxis MDX.
  </Step>
  <Step title="Procesando">
    Analizando archivos MDX y resolviendo importaciones.
  </Step>
  <Step title="Compilando">
    Compilando MDX a HTML, aplicando resaltado de sintaxis.
  </Step>
  <Step title="Desplegando">
    Subiendo al CDN y purgando el caché.
  </Step>
  <Step title="En vivo">
    Build completo. Tu documentación ha sido actualizada.
  </Step>
</Steps>

## Ver el Estado del Build

### Resumen del Dashboard

La página principal de tu proyecto muestra:

- Estado actual del build
- Hora del último despliegue exitoso
- Historial reciente de builds

### Detalles del Build

Haz clic en cualquier build para ver:

- Hora de inicio y fin
- Duración
- Disparado por (push, manual, CLI)
- Hash y mensaje del commit
- Log completo del build

## Logs del Build

Los logs detallados ayudan a depurar problemas:

```text
[12:34:56] Starting build...
[12:34:57] Cloning repository...
[12:34:59] Found docs.json at root
[12:35:00] Validating configuration...
[12:35:01] Processing 45 pages...
[12:35:15] Building search index...
[12:35:18] Deploying to CDN...
[12:35:22] Build complete!
```

## Notificaciones de Build

Recibe notificaciones sobre el estado del build:

### Email

Habilita las alertas de fallos de build en **Configuración** → **Notificaciones**.

### Slack

Conecta Slack para recibir notificaciones de build en tu canal. Consulta [Integración con Slack](/es/integrations/slack).

## Historial de Builds

Ve tus últimos 30 builds en la pestaña **Deployments**:

- Estado del build (exitoso, fallido, cancelado)
- Duración
- Tipo de disparador
- Información del commit

## Cancelar Builds

Para cancelar un build en ejecución:

1. Ve a la pestaña **Deployments**
2. Encuentra el build en ejecución
3. Haz clic en **Cancelar**

El último build exitoso permanece activo.
