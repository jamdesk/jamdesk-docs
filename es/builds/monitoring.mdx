Cada build pasa por varias fases, desde la cola hasta estar en vivo. Supervisa el progreso desde la pestaña Deployments.

## Fases del Build

<Steps>
  <Step title="En cola">
    El build está esperando para iniciarse. La mayoría comienzan en segundos.
  </Step>
  <Step title="Clonando">
    Descargando el contenido de tu repositorio desde GitHub.
  </Step>
  <Step title="Validando">
    Comprobando la configuración de `docs.json` y la sintaxis MDX.
  </Step>
  <Step title="Procesando">
    Analizando los archivos MDX y resolviendo las importaciones.
  </Step>
  <Step title="Compilando">
    Compilando MDX a HTML y aplicando el resaltado de sintaxis.
  </Step>
  <Step title="Desplegando">
    Subiendo al CDN y purgando la caché.
  </Step>
  <Step title="En vivo">
    Build completado. Tu documentación está actualizada.
  </Step>
</Steps>

## Ver el Estado del Build

### Resumen del Dashboard

La página principal de tu proyecto muestra:

- Estado actual del build
- Hora del último despliegue exitoso
- Historial reciente de builds

### Detalles del Build

Haz clic en cualquier build para ver:

- Hora de inicio y fin
- Duración
- Disparado por (push, manual, CLI)
- Hash y mensaje del commit
- Log completo del build

### Advertencias y Sugerencias

Los builds completados pueden incluir dos niveles de retroalimentación:

- **Advertencias** (badge naranja) — problemas que vale la pena corregir, como enlaces rotos o recursos faltantes. Nunca detienen el build.
- **Sugerencias** (bombilla) — mejoras opcionales para el branding y SEO de tu sitio, como añadir un [favicon, descripción o logo](/es/customization/branding). Las sugerencias solo aparecen en tu último build completado, no cuentan para el badge de advertencias y nunca se envían por correo.

Muchas advertencias de enlace roto y de descripción faltante pueden corregirse automáticamente. Cuando tu último build tiene problemas corregibles, usa [Fix with AI](/es/builds/fix-with-ai) para revisar y aplicar los cambios sin editar el MDX a mano.

[12:35:15] Building search index...
[12:35:18] Deploying to CDN...

## Notificaciones de Build

Recibe notificaciones sobre el estado de los builds:

### Email

Activa las alertas de fallos de build en **Configuración** → **Notificaciones**.

### Slack

Conecta Slack para recibir notificaciones de builds en tu canal. Consulta [Integración con Slack](/es/integrations/slack).

## Historial de Builds

Consulta tus últimos 30 builds en la pestaña **Deployments**:

- Estado del build (exitoso, fallido, cancelado)
- Duración
- Tipo de disparador
- Información del commit

## Cancelar Builds

Para cancelar un build en ejecución:

1. Ve a la pestaña **Deployments**
2. Encuentra el build en ejecución
3. Haz clic en **Cancel**

El último build exitoso permanece en vivo.
