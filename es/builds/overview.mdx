Haces push a GitHub (o ejecutas `jamdesk deploy`), Jamdesk compila el sitio y los cambios se publican. Ese es el ciclo. Las páginas de esta sección cubren cada parte: el CLI que usarás a diario, qué ocurre durante un build, desde dónde se sirve tu sitio y las analíticas que Jamdesk recopila en cada página sin necesidad de scripts adicionales.

<Tip>
  **¿Falla el build?** [Solución de problemas de build](/es/builds/troubleshooting) asocia los mensajes de error comunes con sus causas y soluciones.
</Tip>
