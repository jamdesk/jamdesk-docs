Cada vez que le pides a Claude que escriba una página de Jamdesk, terminas explicando lo mismo: qué componentes existen, cómo funciona `docs.json`, cuáles son los comandos CLI. Este plugin le da a [Claude Code](https://claude.ai/code) ese conocimiento de antemano, para que puedas saltarte el preámbulo e ir directo a construir.

<Note>
  Necesitas tener Claude Code instalado primero. Consíguelo en [claude.ai/code](https://claude.ai/code).
</Note>

## Instalación

<Steps>
  <Step title="Agregar el marketplace">
    Ejecuta este comando de barra en Claude Code:

    ```text
    /plugin marketplace add jamdesk/jamdesk-claude-plugin
    ```
  </Step>
  <Step title="Instalar el plugin">
    ```text
    /plugin install jamdesk@jamdesk-marketplace
    ```
  </Step>
</Steps>

También puedes encontrarlo ejecutando `/plugin` y seleccionando **Discover**.

<Accordion title="Instalación manual (para desarrollo o pruebas)">
  ```bash
  git clone https://github.com/jamdesk/jamdesk-claude-plugin.git
  claude --plugin-dir ./jamdesk-claude-plugin
  ```
</Accordion>

## Qué incluye

Una skill (`/jamdesk:jamdesk`) con un centro de referencia rápida y tres archivos de referencia detallados que se cargan bajo demanda:

| Referencia | Qué cubre |
|-----------|---------------|
| **Componentes** | Más de 25 componentes MDX (Cards, Steps, Tabs, Callouts, Code Groups, Tables y más) con props completas y ejemplos |
| **Configuración** | Esquema completo de `docs.json`: temas, colores, branding, navbar, footer, configuración de API, más de 20 integraciones de analítica |
| **Navegación** | 8 patrones de navegación: plano, agrupado, con pestañas, multi-producto, versionado, multi-idioma, desplegables, OpenAPI |

El centro también incluye los 19 comandos CLI, los campos de frontmatter de página, la sintaxis de dimensionamiento de imágenes, los estándares de escritura y los errores comunes.

## Uso

Cuando estés trabajando en la documentación de Jamdesk, ejecuta `/jamdesk:jamdesk`.

Si tu proyecto tiene un `docs.json`, Claude puede activar la skill automáticamente.

Las preguntas comunes (sintaxis de componentes, comandos CLI) se responden directamente desde el centro. ¿Necesitas tablas de props completas, todas las opciones de configuración o detalles de patrones de navegación? Claude trae el archivo de referencia específico.

## Combinación con CLAUDE.md y MCP

Funciona mejor como parte de una configuración de tres capas:

1. El plugin le enseña a Claude sobre la plataforma de Jamdesk: componentes, configuración, navegación, CLI.
2. [CLAUDE.md](/es/ai/claude-code) le enseña a Claude sobre las convenciones de *tu proyecto*: estilo de escritura, terminología, estructura de página.
3. El [servidor MCP](/es/ai/mcp-server) le da a Claude acceso a tu documentación publicada, para que pueda buscar, leer contenido y revisar páginas existentes.

No necesitas las tres. El plugin por sí solo ya es útil. Pero combinado con un CLAUDE.md y una conexión MCP, Claude puede escribir páginas que coincidan con la voz de tu sitio y enlacen a tu contenido existente sin adivinar.

## Actualización y código fuente

Verifica si hay actualizaciones ejecutando `/plugin` en Claude Code. También puedes volver a ejecutar el comando de instalación para obtener la última versión.

El plugin es de código abierto (Apache 2.0). Explora el código fuente, reporta problemas o contribuye: [github.com/jamdesk/jamdesk-claude-plugin](https://github.com/jamdesk/jamdesk-claude-plugin). [Changelog](https://github.com/jamdesk/jamdesk-claude-plugin/blob/main/CHANGELOG.md).
