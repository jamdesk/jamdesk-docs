Añade tu ID de contenedor GTM a `docs.json` para cargar Google Tag Manager en cada página de tu sitio de documentación. Desde allí, tu equipo de marketing puede configurar analítica, píxeles de conversión y seguimiento de eventos completamente dentro de GTM.

<Info>
Los IDs de contenedor GTM comienzan con `GTM-`. Si solo necesitas Google Analytics, consulta la [Integración con Google Analytics](/es/integrations/google-analytics) para una configuración más sencilla.
</Info>

## Cuándo usar GTM

Usa Google Tag Manager cuando necesites:

- **Múltiples herramientas de seguimiento** - GA4, Facebook Pixel, LinkedIn, etc.
- **Control del equipo de marketing** - Permite a los marketers añadir etiquetas sin ayuda de desarrolladores
- **Disparadores avanzados** - Rastrea clics en botones, envíos de formularios, reproducciones de vídeo
- **Integración de pruebas A/B** - Conecta herramientas como Google Optimize

Para analítica básica únicamente, añadir GA4 directamente es más sencillo.

## Cómo obtener tu ID de contenedor

1. Ve a [Google Tag Manager](https://tagmanager.google.com/)
2. Selecciona tu cuenta y contenedor (o crea nuevos)
3. Copia el **ID de contenedor** de la parte superior de la página (comienza con `GTM-`)

## Añadir GTM a tu documentación

Añade el ID de contenedor a tu `docs.json`:

```json
{
  "name": "My Docs",
  "integrations": {
    "gtm": {
      "tagId": "GTM-XXXXXXX"
    }
  }
}
```

Reemplaza `GTM-XXXXXXX` con tu ID de contenedor real.

## Configurar GA4 a través de GTM

Si quieres usar GA4 a través de GTM en lugar de añadirlo directamente:

1. En GTM, ve a **Tags** → **New**
2. Elige **Google Analytics: GA4 Configuration**
3. Introduce tu ID de medición de GA4 (comienza con `G-`)
4. Establece el disparador en **All Pages**
5. **Publica** tu contenedor

<Warning>
Si configuras GA4 a través de GTM, no lo añadas también directamente en `docs.json`. Esto provoca un seguimiento duplicado.
</Warning>

## Verificar la instalación

### Usando el modo preview de GTM

1. En GTM, haz clic en **Preview** en la esquina superior derecha
2. Introduce la URL de tu sitio de documentación
3. Una ventana de depuración muestra qué etiquetas se activan en cada página

### Usando las herramientas de desarrollador del navegador

1. Abre tu sitio con las Herramientas de desarrollador (F12)
2. Ve a la pestaña **Network**
3. Filtra por `gtm.js` o `googletagmanager`
4. Deberías ver solicitudes siendo realizadas

## Etiquetas GTM comunes para documentación

### Rastrear enlaces salientes

Crea una etiqueta para rastrear cuando los usuarios hacen clic en enlaces externos:

1. **Tag**: Google Analytics: GA4 Event
2. **Event Name**: `click`
3. **Trigger**: Click - Just Links, donde Click URL no contiene tu dominio

### Rastrear uso de búsqueda

Rastrea cuando los usuarios interactúan con la función de búsqueda:

1. **Tag**: Google Analytics: GA4 Event
2. **Event Name**: `search`
3. **Trigger**: Evento personalizado que coincida con tu interacción de búsqueda

### Rastrear tiempo en página

Comprende cuánto tiempo pasan los usuarios leyendo:

1. **Tag**: Google Analytics: GA4 Event
2. **Event Name**: `timing`
3. **Trigger**: Disparador de temporizador (por ejemplo, cada 30 segundos)

## Solución de problemas

<Accordion title="Las etiquetas no se activan">
  1. **Verifica el ID de contenedor** - Debe comenzar con `GTM-`
  2. **Publica tu contenedor** - Los cambios sin publicar no aparecerán en tu sitio
  3. **Usa el modo preview** - El preview de GTM muestra qué etiquetas se activan en cada página
</Accordion>

<Accordion title="Datos duplicados en Google Analytics">
  Si tienes GA4 configurado tanto:
  - Directamente en `docs.json` (`integrations.ga4`)
  - A través de GTM como una etiqueta GA4

  Obtendrás vistas de página duplicadas. Elimina una de ellas.
</Accordion>
