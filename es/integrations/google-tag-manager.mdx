Agrega tu ID de contenedor GTM a `docs.json` para cargar Google Tag Manager en cada página de tu sitio de documentación. Desde allí, tu equipo de marketing puede configurar análisis, píxeles de conversión y seguimiento de eventos completamente dentro de GTM.

<Info>
Los IDs de contenedor GTM comienzan con `GTM-`. Si solo necesitas Google Analytics, consulta la [Integración con Google Analytics](/es/integrations/google-analytics) para una configuración más sencilla.
</Info>

## Cuándo usar GTM

Usa Google Tag Manager cuando necesites:

- **Múltiples herramientas de seguimiento** - GA4, Facebook Pixel, LinkedIn, etc.
- **Control del equipo de marketing** - Permite que los marketers agreguen etiquetas sin ayuda de desarrolladores
- **Disparadores avanzados** - Rastrear clics en botones, envíos de formularios, reproducciones de video
- **Integración de pruebas A/B** - Conectar herramientas como Google Optimize

Para análisis básicos únicamente, agregar GA4 directamente es más sencillo.

## Obtener tu Container ID

1. Ve a [Google Tag Manager](https://tagmanager.google.com/)
2. Selecciona tu cuenta y contenedor (o crea nuevos)
3. Copia el **Container ID** de la parte superior de la página (comienza con `GTM-`)

## Agregar GTM a tus docs

Agrega el ID de contenedor a tu `docs.json`:

```json docs.json
{
  "name": "My Docs",
  "integrations": {
    "gtm": {
      "tagId": "GTM-XXXXXXX"
    }
  }
}
```

Reemplaza `GTM-XXXXXXX` con tu ID de contenedor real.

## Configurar GA4 a través de GTM

Si quieres usar GA4 a través de GTM en lugar de agregarlo directamente:

1. En GTM, ve a **Tags** → **New**
2. Elige **Google Analytics: GA4 Configuration**
3. Ingresa tu GA4 Measurement ID (comienza con `G-`)
4. Establece el disparador en **All Pages**
5. **Publica** tu contenedor

<Warning>
Si configuras GA4 a través de GTM, no lo agregues también directamente en `docs.json`. Esto provoca seguimiento duplicado.
</Warning>

## Verificar la instalación

### Usar el modo preview de GTM

1. En GTM, haz clic en **Preview** en la parte superior derecha
2. Ingresa la URL de tu sitio de documentación
3. Una ventana de depuración muestra qué etiquetas se activan en cada página

### Usar las herramientas de desarrollador del navegador

1. Abre tu sitio con las Herramientas de desarrollador (F12)
2. Ve a la pestaña **Network**
3. Filtra por `gtm.js` o `googletagmanager`
4. Deberías ver solicitudes realizándose

## Etiquetas GTM comunes para docs

### Rastrear enlaces externos

Crea una etiqueta para rastrear cuando los usuarios hacen clic en enlaces externos:

1. **Tag**: Google Analytics: GA4 Event
2. **Event Name**: `click`
3. **Trigger**: Click - Just Links, donde Click URL no contiene tu dominio

### Rastrear el uso de la búsqueda

Rastrea cuando los usuarios interactúan con la función de búsqueda:

1. **Tag**: Google Analytics: GA4 Event
2. **Event Name**: `search`
3. **Trigger**: Evento personalizado que coincide con tu interacción de búsqueda

### Rastrear el tiempo en la página

Comprende cuánto tiempo pasan los usuarios leyendo:

1. **Tag**: Google Analytics: GA4 Event
2. **Event Name**: `timing`
3. **Trigger**: Disparador de temporizador (p. ej., cada 30 segundos)

## Solución de problemas

<Accordion title="Las etiquetas no se activan">
  1. **Verifica el ID de contenedor** - Debe comenzar con `GTM-`
  2. **Publica tu contenedor** - Los cambios no publicados no aparecerán en tu sitio
  3. **Usa el modo preview** - El preview de GTM muestra qué etiquetas se activan en cada página
</Accordion>

<Accordion title="Datos duplicados en Google Analytics">
  Si tienes GA4 configurado en ambos:
  - Directamente en `docs.json` (`integrations.ga4`)
  - A través de GTM como una etiqueta GA4

  Obtendrás vistas de página duplicadas. Elimina uno de ellos.
</Accordion>
