Jamdesk carga scripts de 13 proveedores adicionales de analítica, reproducción de sesión e identidad directamente desde `docs.json`. Añade el bloque del proveedor bajo `integrations`, y Jamdesk inyecta su script en cada página de tu sitio de documentación publicado.

<Info>
Cada valor se comprueba con un formato estricto antes de que Jamdesk cargue el script. Un valor con el formato incorrecto (caracteres de más, prefijo incorrecto, longitud incorrecta) se omite silenciosamente y nunca se renderiza — sin página de error, sin etiqueta de script rota. Si un proveedor no carga, vuelve a copiar el valor desde su dashboard y compáralo con el formato que aparece a continuación.
</Info>

## Configurar desde el Dashboard

La forma más rápida de configurar cualquiera de estos: **Dashboard → Integrations**. Elige la tarjeta de un proveedor, pega su clave, y Jamdesk confirma el bloque `docs.json` por ti y activa un rebuild (solo proyectos conectados a GitHub). Las secciones siguientes son para editar `docs.json` directamente, o para proyectos solo CLI.

## PostHog

Analítica de producto, reproducción de sesión y feature flags.

**Formato:** La clave de API del proyecto empieza por `phc_`, seguida de 8 a 64 letras o números. El host de API opcional debe ser una URL `https://`.

<Info>
Encuentra tu clave en **Settings → Project → Project API key** en PostHog.
</Info>

```json docs.json
{
  "integrations": {
    "posthog": {
      "apiKey": "phc_Kj8fPqZx92RmNbTeYcWs",
      "apiHost": "https://us.i.posthog.com"
    }
  }
}
```

`apiHost` es opcional y por defecto es `https://us.i.posthog.com`. Configúralo con tu host de la nube UE o tu URL de reverse-proxy si usas uno.

## Mixpanel

Analítica de eventos y funnels.

**Formato:** El token del proyecto tiene exactamente 32 caracteres hexadecimales en minúscula (`0-9`, `a-f`).

<Info>
Encuentra tu token en **Project Settings → Access Keys → Project Token** en Mixpanel.
</Info>

```json docs.json
{
  "integrations": {
    "mixpanel": {
      "projectToken": "a1b2c3d4e5f6a7b8c9d0e1f2a3b4c5d6"
    }
  }
}
```

## Amplitude

Analítica de producto y cohortes de comportamiento.

**Formato:** La clave de API tiene exactamente 32 caracteres hexadecimales en minúscula (`0-9`, `a-f`).

<Info>
Encuentra tu clave en **Settings → Projects → tu proyecto → API Key** en Amplitude.
</Info>

```json docs.json
{
  "integrations": {
    "amplitude": {
      "apiKey": "f6e5d4c3b2a1908877665544332211ff"
    }
  }
}
```

## Hotjar

Heatmaps y grabaciones de sesión.

**Formato:** El ID de sitio tiene de 1 a 12 dígitos. La versión del snippet tiene de 1 a 4 dígitos (normalmente `6`).

<Info>
Encuentra ambos en **Sites & Organizations → tu sitio** en Hotjar.
</Info>

```json docs.json
{
  "integrations": {
    "hotjar": {
      "hjid": "3482910",
      "hjsv": "6"
    }
  }
}
```

<Warning>
Hotjar graba las sesiones de los visitantes. Si el RGPD, la CCPA u otras normativas similares aplican a tus lectores, colócalo detrás de [Consentimiento de cookies](/es/integrations/cookie-consent).
</Warning>

## Microsoft Clarity

Heatmaps y grabaciones de sesión gratuitos.

**Formato:** El ID de proyecto tiene de 4 a 32 letras o números.

<Info>
Encuentra tu ID de proyecto en **Settings → Overview → Project ID** en Clarity.
</Info>

```json docs.json
{
  "integrations": {
    "clarity": {
      "projectId": "qbxk2paw9m"
    }
  }
}
```

<Warning>
Clarity graba las sesiones de los visitantes. Si el RGPD, la CCPA u otras normativas similares aplican a tus lectores, colócalo detrás de [Consentimiento de cookies](/es/integrations/cookie-consent).
</Warning>

## Fathom

Analítica centrada en la privacidad y sin cookies.

**Formato:** El ID de sitio tiene de 4 a 16 letras o números.

<Info>
Encuentra el ID de tu sitio en **Settings → Sites → tu sitio** en Fathom.
</Info>

```json docs.json
{
  "integrations": {
    "fathom": {
      "siteId": "ABCD1234"
    }
  }
}
```

## Pirsch

Analítica sin cookies y respetuosa con la privacidad.

**Formato:** El código de identificación tiene de 4 a 64 letras o números.

<Info>
Encuentra tu código en **Settings → Developer → Identification Code** en Pirsch.
</Info>

```json docs.json
{
  "integrations": {
    "pirsch": {
      "id": "Jd8fK2pQmZx9AeRt"
    }
  }
}
```

## Heap

Captura automática de eventos, sin instrumentación manual.

**Formato:** El ID de app tiene de 6 a 20 dígitos.

<Info>
Encuentra tu ID de app en **Account → Manage → Projects** en Heap.
</Info>

```json docs.json
{
  "integrations": {
    "heap": {
      "appId": "1234567890"
    }
  }
}
```

## LogRocket

Reproducción de sesión con logs de consola y red.

**Formato:** El ID de app consta de dos segmentos de slug separados por una barra — `org-slug/app-slug` — cada uno con 2 a 64 letras minúsculas, números o guiones.

<Info>
Encuentra tu ID de app en **Settings → Project Setup** en LogRocket.
</Info>

```json docs.json
{
  "integrations": {
    "logrocket": {
      "appId": "acme-inc/docs-site"
    }
  }
}
```

<Warning>
LogRocket graba las sesiones de los visitantes, incluida la actividad de consola y red. Si el RGPD, la CCPA u otras normativas similares aplican a tus lectores, colócalo detrás de [Consentimiento de cookies](/es/integrations/cookie-consent).
</Warning>

## Segment

Enruta los eventos de documentación a cada herramienta de destino desde una única fuente.

**Formato:** La clave de escritura tiene de 10 a 64 letras o números (sin guiones ni guiones bajos).

<Info>
Encuentra tu clave de escritura en **Connections → Sources → tu fuente JS → Settings → API Keys** en Segment.
</Info>

```json docs.json
{
  "integrations": {
    "segment": {
      "key": "hcQ8wK9pXeR2mNq7"
    }
  }
}
```

## Clearbit

Identifica y enriquece visitantes anónimos.

**Formato:** La clave de API pública empieza por `pk_`, seguida de 6 a 64 letras o números.

```json docs.json
{
  "integrations": {
    "clearbit": {
      "publicApiKey": "pk_4f8a2e1c9b6d"
    }
  }
}
```

## Hightouch

Envía los eventos de documentación directamente a tu data warehouse.

**Formato:** La clave de escritura tiene de 8 a 128 caracteres (letras, números, `:`, `.`, `_`, `-`). El host de API opcional tiene de 4 a 64 caracteres (letras, números, `.`, `-`).

```json docs.json
{
  "integrations": {
    "hightouch": {
      "writeKey": "wk_prod_4f8a2e1c9b6d",
      "apiHost": "us-east-1.hightouch-events.com"
    }
  }
}
```

`apiHost` es opcional — solo es necesario para un endpoint de eventos de Hightouch autoalojado o específico de una región.

## Koala

Identifica visitantes de alta intención para ventas y marketing.

**Formato:** La clave de API pública empieza por `pk_`, seguida de 6 a 64 letras o números.

```json docs.json
{
  "integrations": {
    "koala": {
      "publicApiKey": "pk_7e3a9c1f6b2d"
    }
  }
}
```

## Control de consentimiento

Los 13 proveedores anteriores respetan `integrations.cookies`. Cuando está definido, ninguno de sus scripts se carga hasta que tu banner de consentimiento registra la aprobación — consulta [Consentimiento de cookies](/es/integrations/cookie-consent) para la configuración completa. Sin él, cada script se carga para cada visitante al cargar la página.
