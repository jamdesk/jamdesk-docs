  Añade 13 proveedores de analítica, replay de sesiones e identidad a tu sitio de documentación con un bloque de docs.json.
---

Jamdesk carga directamente desde `docs.json` los scripts de 13 proveedores adicionales de analítica, replay de sesiones e identidad. Añade el bloque del proveedor bajo `integrations` y Jamdesk inyectará su script en cada página de tu sitio de documentación publicado.

<Info>
Cada valor se comprueba con un formato estricto antes de que Jamdesk cargue el script. Un valor con un formato incorrecto (caracteres adicionales, prefijo incorrecto o longitud incorrecta) se omite silenciosamente y nunca se renderiza: no aparece ninguna página de error ni ninguna etiqueta de script dañada. Si un proveedor no se carga, vuelve a copiar el valor desde su dashboard y compáralo con el formato indicado a continuación.
</Info>

## Configurar desde el dashboard

La forma más rápida de configurar cualquiera de estos proveedores es desde **Dashboard → Integrations**. Elige la tarjeta de un proveedor, pega su clave y Jamdesk confirmará el bloque de `docs.json` por ti y activará una nueva compilación (solo en proyectos conectados a GitHub). Las secciones siguientes sirven para editar `docs.json` directamente o para proyectos que solo usan la CLI.

## PostHog

Analítica de producto, replay de sesiones y flags de funcionalidades.

**Formato:** La clave de API del proyecto comienza por `phc_` y va seguida de entre 8 y 64 letras o números. El host de API opcional debe ser una URL `https://`.

<Info>
Encuentra tu clave en **Settings → Project → Project API key**, en PostHog.
</Info>

```json docs.json
{
  "integrations": {
    "posthog": {
      "apiKey": "phc_Kj8fPqZx92RmNbTeYcWs",
      "apiHost": "https://us.i.posthog.com"
    }
  }
}
```

`apiHost` es opcional y, de forma predeterminada, usa `https://us.i.posthog.com`. Establécelo en el host de nube de la UE o en la URL del proxy inverso si utilizas uno.

## Mixpanel

Analítica de eventos y embudos.

**Formato:** El token del proyecto tiene exactamente 32 caracteres hexadecimales en minúscula (`0-9`, `a-f`).

<Info>
Encuentra tu token en **Project Settings → Access Keys → Project Token**, en Mixpanel.
</Info>

```json docs.json
{
  "integrations": {
    "mixpanel": {
      "projectToken": "a1b2c3d4e5f6a7b8c9d0e1f2a3b4c5d6"
    }
  }
}
```

## Amplitude

Analítica de producto y cohortes de comportamiento.

**Formato:** La clave de API tiene exactamente 32 caracteres hexadecimales en minúscula (`0-9`, `a-f`).

<Info>
Encuentra tu clave en **Settings → Projects → your project → API Key**, en Amplitude.
</Info>

```json docs.json
{
  "integrations": {
    "amplitude": {
      "apiKey": "f6e5d4c3b2a1908877665544332211ff"
    }
  }
}
```

## Hotjar

Mapas de calor y grabaciones de sesiones.

**Formato:** El ID del sitio tiene entre 1 y 12 dígitos. La versión del snippet tiene entre 1 y 4 dígitos (normalmente `6`).

<Info>
Encuentra ambos valores en **Sites & Organizations → your site**, en Hotjar.
</Info>

```json docs.json
{
  "integrations": {
    "hotjar": {
      "hjid": "3482910",
      "hjsv": "6"
    }
  }
}
```

<Warning>
Hotjar graba las sesiones de los visitantes. Si el RGPD, la CCPA u otras normativas similares se aplican a tus lectores, protégelo mediante [Cookie Consent](/es/integrations/cookie-consent).
</Warning>

## Microsoft Clarity

Mapas de calor y grabaciones de sesiones gratuitas.

**Formato:** El ID del proyecto tiene entre 4 y 32 letras o números.

<Info>
Encuentra el ID de tu proyecto en **Settings → Overview → Project ID**, en Clarity.
</Info>

```json docs.json
{
  "integrations": {
    "clarity": {
      "projectId": "qbxk2paw9m"
    }
  }
}
```

<Warning>
Clarity graba las sesiones de los visitantes. Si el RGPD, la CCPA u otras normativas similares se aplican a tus lectores, protégelo mediante [Cookie Consent](/es/integrations/cookie-consent).
</Warning>

## Fathom

Analítica sin cookies y centrada en la privacidad.

**Formato:** El ID del sitio tiene entre 4 y 16 letras o números.

<Info>
Encuentra el ID de tu sitio en **Settings → Sites → your site**, en Fathom.
</Info>

```json docs.json
{
  "integrations": {
    "fathom": {
      "siteId": "ABCD1234"
    }
  }
}
```

## Pirsch

Analítica sin cookies y respetuosa con la privacidad.

**Formato:** El código de identificación tiene entre 4 y 64 letras o números.

<Info>
Encuentra tu código en **Settings → Developer → Identification Code**, en Pirsch.
</Info>

```json docs.json
{
  "integrations": {
    "pirsch": {
      "id": "Jd8fK2pQmZx9AeRt"
    }
  }
}
```

## Heap

Captura automática de eventos, sin instrumentación manual.

**Formato:** El ID de la aplicación tiene entre 6 y 20 dígitos.

<Info>
Encuentra el ID de tu aplicación en **Account → Manage → Projects**, en Heap.
</Info>

```json docs.json
{
  "integrations": {
    "heap": {
      "appId": "1234567890"
    }
  }
}
```

## LogRocket

Replay de sesiones con registros de consola y red.

**Formato:** El ID de la aplicación consta de dos segmentos separados por una barra: `org-slug/app-slug`. Cada segmento debe tener entre 2 y 64 letras minúsculas, números o guiones.

<Info>
Encuentra el ID de tu aplicación en **Settings → Project Setup**, en LogRocket.
</Info>

```json docs.json
{
  "integrations": {
    "logrocket": {
      "appId": "acme-inc/docs-site"
    }
  }
}
```

<Warning>
LogRocket graba las sesiones de los visitantes, incluida la actividad de la consola y de la red. Si el RGPD, la CCPA u otras normativas similares se aplican a tus lectores, protégelo mediante [Cookie Consent](/es/integrations/cookie-consent).
</Warning>

## Segment

Envía los eventos de documentación a todas las herramientas posteriores desde una única fuente.

**Formato:** La clave de escritura tiene entre 10 y 64 letras o números (sin guiones ni guiones bajos).

<Info>
Encuentra tu clave de escritura en **Connections → Sources → your JS source → Settings → API Keys**, en Segment.
</Info>

```json docs.json
{
  "integrations": {
    "segment": {
      "key": "hcQ8wK9pXeR2mNq7"
    }
  }
}
```

## Clearbit

Identifica y enriquece a los visitantes anónimos.

**Formato:** La clave de API pública comienza por `pk_` y va seguida de entre 6 y 64 letras o números.

```json docs.json
{
  "integrations": {
    "clearbit": {
      "publicApiKey": "pk_4f8a2e1c9b6d"
    }
  }
}
```

## Hightouch

Envía directamente los eventos de documentación a tu almacén de datos.

**Formato:** La clave de escritura tiene entre 8 y 128 caracteres (letras, números, `:`, `.`, `_`, `-`). El host de API opcional tiene entre 4 y 64 caracteres (letras, números, `.`, `-`).

```json docs.json
{
  "integrations": {
    "hightouch": {
      "writeKey": "wk_prod_4f8a2e1c9b6d",
      "apiHost": "us-east-1.hightouch-events.com"
    }
  }
}
```

`apiHost` es opcional y solo se necesita para un endpoint de eventos de Hightouch autoalojado o específico de una región.

## Koala

Identifica a los visitantes con alta intención de compra para los equipos de ventas y marketing.

**Formato:** La clave de API pública comienza por `pk_` y va seguida de entre 6 y 64 letras o números.

```json docs.json
{
  "integrations": {
    "koala": {
      "publicApiKey": "pk_7e3a9c1f6b2d"
    }
  }
}
```

## Control del consentimiento

Los 13 proveedores anteriores respetan `integrations.cookies`. Cuando está configurado, ninguno de sus scripts se carga hasta que el banner de consentimiento registra la aprobación. Consulta [Cookie Consent](/es/integrations/cookie-consent) para ver la configuración completa. Sin esta opción, todos los scripts se cargan para cada visitante al cargar la página.
