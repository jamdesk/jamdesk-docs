Conecta Slack para recibir notificaciones de build directamente en el canal de tu equipo.

<Note>
La integración con Slack está disponible en los planes Pro.
</Note>

## Configurar Slack

<Steps>
  <Step title="Crea un webhook de Slack">
    En Slack:
    1. Ve a la configuración de tu espacio de trabajo
    2. Ve a **Apps** → **Incoming Webhooks**
    3. Haz clic en **Add to Slack**
    4. Elige un canal
    5. Copia la URL del webhook
  </Step>
  <Step title="Agregar a Jamdesk">
    En tu proyecto de Jamdesk:
    1. Ve a **Integrations**
    2. Haz clic en **Connect Slack**
    3. Pega la URL de tu webhook
    4. Haz clic en **Save**
  </Step>
  <Step title="Probar la conexión">
    Haz clic en **Send Test** para verificar que la integración funciona.
  </Step>
</Steps>

## Preferencias de notificaciones

Elige qué resultados de build activan las notificaciones:

| Evento | Predeterminado | Descripción |
|-------|---------|-------------|
| Build correcto | Activado | Notifica cuando un build se completa correctamente |
| Build fallido | Activado | Notifica cuando un build falla |

Ambas opciones están activadas de forma predeterminada. Para cambiar las preferencias después de la configuración, activa o desactiva las casillas y haz clic en **Update**.

## Formato del mensaje

Las notificaciones incluyen:

- Nombre del proyecto
- Estado del build
- Mensaje de commit y autor
- Enlace a los detalles del build
- Duración (para builds completados)

Ejemplo:
``` text
✓ Docs build succeeded
Project: My Docs
Commit: "Add authentication guide" by @username
Duration: 45s
View build →
```

## Eliminar Slack

Para desconectar:

1. Ve a **Integrations**
2. Haz clic en **Disconnect** junto a Slack
3. Confirma la eliminación

## Solución de problemas

<Accordion title="Las notificaciones no aparecen">
  1. Verifica que la URL del webhook sea correcta
  2. Verifica que el canal siga existiendo
  3. Envía una notificación de prueba
  4. Revisa la configuración de webhooks entrantes de Slack
</Accordion>

<Accordion title="Las preferencias modificadas no se guardan">
  Después de activar o desactivar las casillas de notificación, haz clic en el botón **Update** que aparece. Los cambios no se guardan automáticamente.
</Accordion>
