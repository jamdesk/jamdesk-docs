Esta sección abarca tres tareas distintas, así que ayuda saber cuál de ellas buscas.

**Documentar tu API** significa convertir especificaciones de OpenAPI en páginas de endpoint que los lectores pueden probar desde el navegador. **La API de búsqueda de Jamdesk** va en la dirección contraria: tus docs se convierten en una fuente de datos que chatbots, herramientas de soporte y agentes de IA pueden consultar. Y las **integraciones** conectan tu sitio de docs con las herramientas que lo rodean, desde notificaciones de build en Slack hasta analítica y captura de emails.
