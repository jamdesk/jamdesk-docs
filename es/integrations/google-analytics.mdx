Añade Google Analytics 4 a tu sitio de documentación para entender cómo interactúan los usuarios con tu contenido.

<Info>
La integración con Google Analytics funciona con IDs de medición de GA4 (Google Analytics 4) que empiezan con `G-`.
</Info>

## Obtener tu ID de medición

1. Ve a [Google Analytics](https://analytics.google.com/)
2. Selecciona tu propiedad (o crea una)
3. Ve a **Admin** → **Data Streams**
4. Selecciona tu flujo web (o crea uno)
5. Copia el **Measurement ID** (empieza con `G-`)

## Añadir GA4 a tus docs

Añade el ID de medición a tu `docs.json`:

```json docs.json
{
  "name": "My Docs",
  "integrations": {
    "ga4": {
      "measurementId": "G-XXXXXXXXXX"
    }
  }
}
```

Reemplaza `G-XXXXXXXXXX` con tu ID de medición real.

## Ver tus datos

Después de añadir la integración:

1. Activa un rebuild de tus docs
2. Visita tu sitio de documentación en vivo
3. En Google Analytics, ve a **Reports** → **Real-time**
4. Deberías ver tu visita aparecer en menos de 30 segundos

<Note>
Puede tardar entre 24 y 48 horas en que los datos aparezcan en los informes estándar. Usa los informes en tiempo real para una verificación inmediata.
</Note>

## Uso con Google Tag Manager

Si ya usas Google Tag Manager, puedes configurar GA4 a través de GTM en lugar de añadirlo directamente. Consulta [Integración con Google Tag Manager](/es/integrations/google-tag-manager) para más detalles.

Eres responsable de configurar los banners de consentimiento de cookies para cualquier etiqueta que cargues a través de Google Tag Manager si los necesitas. Jamdesk carga tu contenedor de GTM para todos los visitantes sin una puerta de consentimiento. Consulta [Consentimiento de cookies](/es/integrations/cookie-consent) para restringir la analítica hasta que los visitantes acepten.

<Warning>
No añadas la misma propiedad de GA4 tanto directamente en `docs.json` como a través de Google Tag Manager, ya que esto causará un seguimiento duplicado.
</Warning>

## Consideraciones de privacidad

Google Analytics recopila datos de los visitantes. Considera:

- Añadir un banner de consentimiento de cookies si aplica el RGPD/CCPA. Jamdesk carga GA4 para todos los visitantes por defecto, así que usa [Consentimiento de cookies](/es/integrations/cookie-consent) para restringirlo hasta que acepten.
- Actualizar tu política de privacidad para mencionar la analítica
- Usar [anonimización de IP](https://support.google.com/analytics/answer/2763052) si es necesario

## Solución de problemas

<Accordion title="No se ven datos">
  1. **Verifica tu ID de medición** - Debe empezar con `G-`
  2. **Comprueba si hay bloqueadores de anuncios** - Pueden bloquear los scripts de analítica
  3. **Espera al rebuild** - Los cambios requieren un nuevo build para surtir efecto
  4. **Usa los informes en tiempo real** - Los informes estándar tienen un retraso de 24-48 horas
</Accordion>

<Accordion title="Aparece el error 'Invalid Measurement ID'">
  El ID debe:
  - Empezar con `G-`
  - Contener solo letras y números después de `G-`
  - Copiarse exactamente desde Google Analytics (sin espacios adicionales)
</Accordion>
