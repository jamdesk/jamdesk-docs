Añade Google Analytics 4 a tu sitio de documentación para entender cómo interactúan los usuarios con tu contenido.

<Info>
La integración con Google Analytics funciona con IDs de medición de GA4 (Google Analytics 4) que comienzan con `G-`.
</Info>

## Obtener tu ID de medición

1. Ve a [Google Analytics](https://analytics.google.com/)
2. Selecciona tu propiedad (o crea una)
3. Ve a **Administración** → **Flujos de datos**
4. Selecciona tu flujo web (o crea uno)
5. Copia el **ID de medición** (comienza con `G-`)

## Añadir GA4 a tu documentación

Añade el ID de medición a tu `docs.json`:

```json docs.json
{
  "name": "My Docs",
  "integrations": {
    "ga4": {
      "measurementId": "G-XXXXXXXXXX"
    }
  }
}
```

Reemplaza `G-XXXXXXXXXX` con tu ID de medición real.

## Ver tus datos

Después de añadir la integración:

1. Activa una reconstrucción de tu documentación
2. Visita tu sitio de documentación en producción
3. En Google Analytics, ve a **Informes** → **Tiempo real**
4. Deberías ver tu visita aparecer en menos de 30 segundos

<Note>
Los datos pueden tardar entre 24 y 48 horas en aparecer en los informes estándar. Usa los informes en tiempo real para una verificación inmediata.
</Note>

## Uso con Google Tag Manager

Si ya usas Google Tag Manager, puedes configurar GA4 a través de GTM en lugar de añadirlo directamente. Consulta [Integración de Google Tag Manager](/es/integrations/google-tag-manager) para más detalles.

Eres responsable de configurar banners de consentimiento de cookies para cualquier etiqueta que cargues a través de Google Tag Manager si las necesitas — Jamdesk carga tu contenedor de GTM para todos los visitantes sin verificación de consentimiento. Consulta [Consentimiento de cookies](/es/integrations/cookie-consent) para condicionar la analítica hasta que los visitantes den su consentimiento.

<Warning>
No añadas la misma propiedad de GA4 tanto directamente en `docs.json` como a través de Google Tag Manager — esto causará seguimiento duplicado.
</Warning>

## Consideraciones de privacidad

Google Analytics recopila datos de los visitantes. Ten en cuenta:

- Añadir un banner de consentimiento de cookies si aplica el RGPD/CCPA. Jamdesk carga GA4 para todos los visitantes de forma predeterminada, así que usa [Consentimiento de cookies](/es/integrations/cookie-consent) para condicionarlo hasta que den su consentimiento.
- Actualizar tu política de privacidad para mencionar la analítica
- Usar la [anonimización de IP](https://support.google.com/analytics/answer/2763052) si es necesario

## Solución de problemas

<Accordion title="No se ven datos">
  1. **Verifica tu ID de medición** - Debe comenzar con `G-`
  2. **Revisa los bloqueadores de anuncios** - Pueden bloquear los scripts de analítica
  3. **Espera a la reconstrucción** - Los cambios requieren un nuevo build para tener efecto
  4. **Usa los informes en tiempo real** - Los informes estándar tienen un retraso de 24 a 48 horas
</Accordion>

<Accordion title="Aparece el error 'Invalid Measurement ID'">
  El ID debe:
  - Comenzar con `G-`
  - Contener solo letras y números después de `G-`
  - Copiarse exactamente desde Google Analytics (sin espacios adicionales)
</Accordion>
