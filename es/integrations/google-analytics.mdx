Añade Google Analytics 4 a tu sitio de documentación para comprender cómo los usuarios interactúan con tu contenido.

<Info>
La integración de Google Analytics funciona con IDs de medición de GA4 (Google Analytics 4) que comienzan con `G-`.
</Info>

## Obtener tu ID de medición

1. Ve a [Google Analytics](https://analytics.google.com/)
2. Selecciona tu propiedad (o crea una)
3. Ve a **Administrar** → **Flujos de datos**
4. Selecciona tu flujo web (o crea uno)
5. Copia el **ID de medición** (comienza con `G-`)

## Añadir GA4 a tus Docs

Añade el ID de medición a tu `docs.json`:

```json
{
  "name": "My Docs",
  "integrations": {
    "ga4": {
      "measurementId": "G-XXXXXXXXXX"
    }
  }
}
```

Reemplaza `G-XXXXXXXXXX` con tu ID de medición real.

## Ver tus datos

Después de añadir la integración:

1. Activa un rebuild de tus docs
2. Visita tu sitio de documentación en producción
3. En Google Analytics, ve a **Informes** → **Tiempo real**
4. Deberías ver tu visita aparecer en menos de 30 segundos

<Note>
Los datos pueden tardar entre 24 y 48 horas en aparecer en los informes estándar. Usa los informes en tiempo real para verificación inmediata.
</Note>

## Uso con Google Tag Manager

Si ya estás usando Google Tag Manager, puedes configurar GA4 a través de GTM en lugar de añadirlo directamente. Consulta la [Integración de Google Tag Manager](/es/integrations/google-tag-manager) para más detalles.

<Warning>
No añadas la misma propiedad de GA4 directamente en `docs.json` y también a través de Google Tag Manager; esto causará un seguimiento duplicado.
</Warning>

## Consideraciones de privacidad

Google Analytics recopila datos de los visitantes. Ten en cuenta:

- Añadir un banner de consentimiento de cookies si así lo requiere el RGPD/CCPA
- Actualizar tu política de privacidad para mencionar el uso de analítica
- Usar la [anonimización de IP](https://support.google.com/analytics/answer/2763052) si es necesario

## Solución de problemas

<Accordion title="No veo ningún dato">
  1. **Verifica tu ID de medición** — debe comenzar con `G-`
  2. **Comprueba si hay bloqueadores de anuncios** — pueden bloquear los scripts de analítica
  3. **Espera el rebuild** — los cambios requieren un nuevo build para tener efecto
  4. **Usa los informes en tiempo real** — los informes estándar tienen un retraso de 24 a 48 horas
</Accordion>

<Accordion title="Aparece el error 'ID de medición no válido'">
  El ID debe:
  - Comenzar con `G-`
  - Contener solo letras y números después de `G-`
  - Ser copiado exactamente desde Google Analytics (sin espacios adicionales)
</Accordion>
