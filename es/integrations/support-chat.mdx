description: >-
  Añade Intercom o Front Chat a la documentación de Jamdesk configurando appId o
  snippetId en integrations de docs.json, con control de consentimiento opcional.
---

Jamdesk puede cargar un widget de chat en vivo en cada página de tu sitio de documentación. Añade el bloque del proveedor en `integrations` de `docs.json` y Jamdesk inyectará el script del widget por ti.

<Info>
Cada valor se comprueba con un formato estricto antes de que Jamdesk cargue el widget. Un valor con un formato incorrecto se omite silenciosamente y nunca se muestra: no se genera ninguna página de error ni una etiqueta de script dañada.
</Info>

## Configurar desde el dashboard

La forma más rápida de configurar cualquiera de estos servicios es: **Dashboard → Integrations**. Selecciona la tarjeta del proveedor, pega su ID y Jamdesk guardará el bloque de `docs.json` por ti y activará una nueva compilación (solo para proyectos conectados a GitHub). Las secciones siguientes sirven para editar `docs.json` directamente o para proyectos que solo usan la CLI.

## Intercom

**Formato:** El App ID debe tener entre 6 y 16 letras o números.

<Info>
Puedes encontrar tu App ID en **Settings → Installation → Web**, dentro de Intercom; es el ID de tu espacio de trabajo.
</Info>

```json docs.json
{
  "integrations": {
    "intercom": {
      "appId": "abc12345"
    }
  }
}
```

## Front Chat

**Formato:** El Chat ID debe tener entre 8 y 64 caracteres hexadecimales en minúsculas (`0-9`, `a-f`).

```json docs.json
{
  "integrations": {
    "frontchat": {
      "snippetId": "3f8a2e1c9b6d4a7f"
    }
  }
}
```

## Control del consentimiento

Ambos widgets respetan `integrations.cookies`. Cuando está configurado, el script de chat no se carga hasta que el banner de consentimiento registra la aprobación. Consulta [Consentimiento de cookies](/es/integrations/cookie-consent) para ver la configuración completa. Sin esta configuración, el widget se carga para cada visitante al cargar la página.
