Eliminar un proyecto lo elimina de tu dashboard de forma permanente -- el historial de builds, las analíticas y la configuración de dominio desaparecen. Tu repositorio de GitHub no se ve afectado.

## Eliminar un proyecto propio

<Warning>
Eliminar un proyecto elimina de forma permanente todos los datos, incluido el historial de builds, las analíticas y la configuración de dominio personalizado. Esta acción no se puede deshacer.
</Warning>

<Steps>
  <Step title="Abrir la configuración del proyecto">
    Ve a tu proyecto y haz clic en **Settings**.
  </Step>
  <Step title="Desplázate hasta la Zona de peligro">
    Encuentra la sección **Danger Zone** en la parte inferior.
  </Step>
  <Step title="Haz clic en Eliminar proyecto">
    Selecciona **Delete Project**.
  </Step>
  <Step title="Confirmar la eliminación">
    Escribe el nombre del proyecto para confirmar, luego haz clic en **Permanently Delete**.
  </Step>
</Steps>

## Qué se elimina

- Todo el historial de builds y los registros
- Datos de analíticas
- Configuración de dominio personalizado
- Asociaciones de miembros del equipo
- Integraciones de Webhook

## Qué NO se elimina

- Tu repositorio de GitHub (permanece sin cambios)
- Tu cuenta de Jamdesk
- Otros proyectos de tu propiedad

## Salir de un proyecto

Si eres miembro (no propietario) de un proyecto:

1. Ve a **Settings** → **Team**
2. Encuentra tu nombre en la lista de miembros
3. Haz clic en **Leave Project**
4. Confirma tu salida

Puedes ser invitado de nuevo más adelante si es necesario.

## Antes de eliminar

Considera estas alternativas:

- **Transferir la propiedad** si los miembros del equipo necesitan acceso continuo
- **Exportar las analíticas** si necesitas registros históricos
- **Anotar tu configuración** por si recrearás el proyecto

## Recuperar proyectos eliminados

Los proyectos eliminados no pueden recuperarse. Si eliminaste un proyecto por error:

1. Crea un nuevo proyecto
2. Conecta el mismo repositorio de GitHub
3. Reconfigura los ajustes manualmente

El contenido de tu documentación permanece en tu repositorio de GitHub.
