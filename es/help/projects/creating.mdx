---
title: Crear proyectos en el dashboard
description: Un proyecto en Jamdesk representa un único sitio de documentación. Cada proyecto se conecta a un repositorio de GitHub y se despliega en su propia URL.
---

Configura un nuevo sitio de documentación creando un proyecto en el dashboard. Puedes comenzar desde una plantilla o conectar un repositorio de GitHub existente, y Jamdesk gestiona la instalación del Webhook y el primer build automáticamente.

## Crear un nuevo proyecto

<Steps>
  <Step title="Abrir el dashboard">
    Ve a [dashboard.jamdesk.com](https://dashboard.jamdesk.com) e inicia sesión.
  </Step>
  <Step title="Hacer clic en Nuevo proyecto">
    Selecciona **Nuevo proyecto** en el dashboard.
  </Step>
  <Step title="Elegir el origen">
    Elige cómo comenzar tu documentación:

    <Tabs>
      <Tab title="Usar una plantilla">
        Comienza con la [Plantilla de inicio](https://github.com/jamdesk/starter-docs). Jamdesk crea un repositorio de GitHub para ti con contenido de muestra, componentes y una especificación OpenAPI.
      </Tab>
      <Tab title="Conectar repositorio">
        Conecta un repositorio de GitHub existente que contenga tu documentación.
      </Tab>
    </Tabs>
  </Step>
  <Step title="Configurar los ajustes">
    - **Nombre del proyecto** — Se muestra en el dashboard
    - **Subdominio** — La URL de tus docs (p. ej., `my-docs.jamdesk.app`)
    - **Rama** — La rama de Git a desplegar (normalmente `main`)
  </Step>
  <Step title="Crear">
    Haz clic en **Crear proyecto** para finalizar la configuración.
  </Step>
</Steps>

## Límites de proyectos

Tu plan determina cuántos proyectos puedes crear:

| Plan | Proyectos |
|------|-----------|
| Trial | 1 |
| Pro | 1 (ampliable) |

¿Necesitas más proyectos en Pro? Añade ranuras de proyecto adicionales en la página **Suscripción**.

## Qué se crea

Cuando creas un proyecto, Jamdesk:

1. Se conecta a tu repositorio de GitHub
2. Instala un Webhook para builds automáticos
3. Activa tu primer build
4. Asigna un subdominio `*.jamdesk.app`
