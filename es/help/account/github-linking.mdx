Vincular tu cuenta de GitHub conecta tu identidad para la atribución de builds y habilita el acceso a repositorios privados.

## ¿Por qué vincular GitHub?

Vincular tu cuenta de GitHub te permite:

- Conectar repositorios privados a Jamdesk
- Habilitar builds automáticos al hacer push
- Acceder a repositorios de organizaciones a las que perteneces

## Vinculación de tu cuenta

<Steps>
  <Step title="Ve a Configuración">
    Haz clic en tu avatar y selecciona **Configuración**.
  </Step>
  <Step title="Selecciona Conexiones">
    Navega a la pestaña **Conexiones**.
  </Step>
  <Step title="Haz clic en Conectar GitHub">
    Selecciona **Conectar cuenta de GitHub**.
  </Step>
  <Step title="Autoriza Jamdesk">
    Revisa los permisos y haz clic en **Autorizar** en GitHub.
  </Step>
</Steps>

## Permisos solicitados

Jamdesk solicita permisos mínimos:

| Permiso | Propósito |
|------------|---------|
| Leer contenido del repositorio | Acceder a tus archivos de documentación |
| Leer metadatos del repositorio | Listar tus repositorios |
| Webhooks | Recibir notificaciones de push para builds automáticos |

<Note>
Jamdesk nunca escribe en tus repositorios. Todo el acceso es de solo lectura.
</Note>

## Desvincular tu cuenta

Para desconectar GitHub:

1. Ve a **Configuración** → **Conexiones**
2. Haz clic en **Desconectar** junto a GitHub
3. Confirma la desconexión

<Warning>
Desconectar GitHub deshabilitará los builds automáticos para todos tus proyectos. Deberás volver a conectarte para habilitarlos de nuevo.
</Warning>

## Repositorios de organizaciones

Para acceder a repositorios de una organización de GitHub:

1. Ve a la configuración de la organización en GitHub
2. Navega a **Acceso de terceros** → **OAuth Apps**
3. Encuentra Jamdesk y haz clic en **Conceder** acceso

Si no ves esta opción, pide a un administrador de la organización que apruebe Jamdesk.
