Crea tu cuenta de Jamdesk usando correo electrónico, Google OAuth o GitHub OAuth.

## Opciones de registro

Jamdesk admite tres métodos de autenticación:

### Correo electrónico y contraseña

1. Visita [dashboard.jamdesk.com](https://dashboard.jamdesk.com)
2. Haz clic en **Sign Up**
3. Ingresa tu dirección de correo electrónico
4. Crea una contraseña segura
5. Revisa tu correo electrónico para encontrar un enlace de verificación
6. Haz clic en el enlace de verificación para confirmar tu cuenta

### Google OAuth

1. Visita [dashboard.jamdesk.com](https://dashboard.jamdesk.com)
2. Haz clic en **Sign Up**
3. Selecciona **Continue with Google**
4. Autoriza a Jamdesk a acceder a tu cuenta de Google
5. Serás verificado automáticamente e iniciará sesión

### GitHub OAuth

1. Visita [dashboard.jamdesk.com](https://dashboard.jamdesk.com)
2. Haz clic en **Sign Up**
3. Selecciona **Continue with GitHub**
4. Autoriza a Jamdesk a acceder a tu cuenta de GitHub
5. Serás verificado automáticamente e iniciará sesión

<Note>
Tu inicio de sesión con GitHub conecta tu identidad a Jamdesk. Esto es independiente de conectar un repositorio de GitHub a tu proyecto de documentación, lo cual harás durante la configuración del proyecto.
</Note>

## Qué ocurre después del registro

Después de crear tu cuenta:
- Comenzarás una prueba gratuita de 14 días del plan Pro
- Serás dirigido a crear tu primer proyecto de documentación
- Tendrás acceso al tutorial de incorporación completo

## Verificación de correo electrónico

Si no recibes un correo electrónico de verificación:
1. Revisa tu carpeta de spam
2. Espera unos minutos e intenta registrarte nuevamente
3. [Contacta con soporte](/es/help/support/contact) si el problema persiste
