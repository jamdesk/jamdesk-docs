## Los 5 pasos

<Steps>
  <Step title="Iniciar prueba">
    Cuando inicias sesión por primera vez, Jamdesk activa automáticamente tu **prueba gratuita de 14 días** del plan Pro.

    - Acceso completo a todas las funciones
    - La prueba termina 14 días después de la activación
  </Step>

  <Step title="Crear proyecto">
    Ponle un nombre a tu proyecto de documentación:

    - Usa un nombre claro y descriptivo (por ejemplo, "API Documentation", "User Guide")
    - Este pasa a formar parte de la URL de tu sitio de documentación
    - Puedes cambiar el nombre visible más adelante en la configuración del proyecto
  </Step>

  <Step title="Conectar GitHub y crear docs iniciales">
    Jamdesk crea un nuevo repositorio de GitHub a partir de la [plantilla inicial](https://github.com/jamdesk/starter-docs):

    - Páginas de ejemplo con contenido y componentes realistas
    - `docs.json` preconfigurado con navegación e identidad de marca
    - Ejemplo de spec de OpenAPI para páginas de referencia de la API
    - Listo para editar y hacer push de inmediato
  </Step>

  <Step title="Instalar la CLI">
    La CLI de Jamdesk permite el desarrollo local:

    ```bash
    npm install -g jamdesk
    ```

    <Note>
    Puedes omitir este paso durante la incorporación e instalar la CLI en cualquier momento. Si lo omites, igualmente puedes editar la documentación directamente en GitHub.
    </Note>
  </Step>

  <Step title="Empezar a editar">
    ¡Ya estás listo para hacer build! Edita tu documentación:

    - **Por CLI**: edita archivos localmente con `jamdesk dev`
    - **Por GitHub**: edita archivos `.mdx` directamente en tu repositorio
    - **En Jamdesk**: algunas funciones del dashboard están disponibles (según el plan)

    Los cambios activan automáticamente rebuilds de la documentación cuando haces push a GitHub.
  </Step>
</Steps>

## Solución de problemas

### Omití un paso, ¿puedo volver atrás?
Puedes completar la incorporación en cualquier momento desde el dashboard de tu proyecto. Busca la tarjeta de incorporación para continuar donde lo dejaste.

### Elegí el repositorio de GitHub incorrecto
Crea un nuevo proyecto con el repositorio correcto. Puedes eliminar el anterior cuando quieras.

### Necesito ayuda durante la incorporación
Contacta a [soporte](/es/help/support/contact) en cualquier momento del proceso.
