## Los 5 pasos

<Steps>
  <Step title="Iniciar prueba">
    Cuando inicias sesión por primera vez, Jamdesk activa automáticamente tu **prueba gratuita de 14 días** del plan Pro.

    - Acceso completo a todas las funciones
    - La prueba finaliza 14 días después de la activación
  </Step>

  <Step title="Crear proyecto">
    Ponle un nombre a tu proyecto de documentación:

    - Usa un nombre claro y descriptivo (por ejemplo, "Documentación de la API", "Guía del usuario")
    - Esto pasa a formar parte de la URL de tu sitio de documentación
    - Puedes cambiar el nombre visible más adelante en la configuración del proyecto
  </Step>

  <Step title="Conectar GitHub y crear documentación inicial">
    Jamdesk crea un nuevo repositorio de GitHub a partir de la [plantilla inicial](https://github.com/jamdesk/starter-docs):

    - Páginas de ejemplo con contenido y componentes realistas
    - `docs.json` preconfigurado con navegación y marca
    - Ejemplo de especificación OpenAPI para la documentación de referencia de la API
    - Listo para editar y hacer push de inmediato
  </Step>

  <Step title="Instalar la CLI">
    La CLI de Jamdesk permite el desarrollo local:

    ```bash
    npm install -g jamdesk
    ```

    <Note>
    Puedes omitir este paso durante la incorporación e instalar la CLI en cualquier momento. Si lo omites, igualmente podrás editar la documentación directamente en GitHub.
    </Note>
  </Step>

  <Step title="Empezar a editar">
    ¡Ya estás listo para empezar! Edita tu documentación:

    - **A través de la CLI**: edita archivos localmente con `jamdesk dev`
    - **A través de GitHub**: edita archivos `.mdx` directamente en tu repositorio
    - **En Jamdesk**: algunas funciones del dashboard están disponibles (según el plan)

    Los cambios activan automáticamente reconstrucciones de la documentación al hacer push a GitHub.
  </Step>
</Steps>

- [Invitar miembros del equipo](/es/help/projects/team-members)

## Solución de problemas

### Omití un paso, ¿puedo volver atrás?
Puedes completar la incorporación en cualquier momento desde el dashboard de tu proyecto. Busca la tarjeta de incorporación para continuar donde lo dejaste.

### Elegí el repositorio de GitHub incorrecto
Crea un nuevo proyecto con el repositorio correcto; puedes eliminar el anterior en cualquier momento.

### Necesito ayuda durante la incorporación
Ponte en contacto con [soporte](/es/help/support/contact) en cualquier momento durante el proceso.
