## Los 5 pasos

<Steps>
  <Step title="Iniciar prueba">
    Cuando inicias sesión por primera vez, Jamdesk inicia automáticamente tu **prueba gratuita de 14 días** del plan Pro.

    - No se requiere tarjeta de crédito
    - Acceso completo a todas las funciones
    - La prueba termina 14 días después de la activación
  </Step>

  <Step title="Crear proyecto">
    Asigna un nombre a tu proyecto de documentación:

    - Usa un nombre claro y descriptivo (p. ej., "Documentación de la API", "Guía del usuario")
    - Esto forma parte de la URL de tu sitio de documentación
    - Puedes cambiar el nombre visible más tarde en la configuración del proyecto
  </Step>

  <Step title="Conectar GitHub y crear documentación inicial">
    Jamdesk crea un nuevo repositorio de GitHub a partir de la [Plantilla inicial](https://github.com/jamdesk/starter-docs):

    - Páginas de ejemplo con contenido y componentes reales
    - `docs.json` preconfigurado con navegación y marca
    - Ejemplo de especificación OpenAPI para documentación de referencia de la API
    - Listo para editar y publicar de inmediato
  </Step>

  <Step title="Instalar CLI">
    El CLI de Jamdesk permite el desarrollo local:

    ```bash
    npm install -g jamdesk
    ```

    <Note>
    Puedes omitir este paso durante la incorporación e instalar el CLI en cualquier momento. Si lo omites, aún puedes editar la documentación directamente en GitHub.
    </Note>
  </Step>

  <Step title="Comenzar a editar">
    ¡Ya estás listo para construir! Edita tu documentación:

    - **Mediante CLI**: Edita archivos localmente con `jamdesk dev`
    - **Mediante GitHub**: Edita archivos `.mdx` directamente en tu repositorio
    - **En Jamdesk**: Algunas funciones del dashboard están disponibles (según el plan)

    Los cambios activan automáticamente rebuilds de la documentación cuando publicas en GitHub.
  </Step>
</Steps>

## Solución de problemas

### Omití un paso, ¿puedo volver atrás?
Puedes completar la incorporación en cualquier momento desde el dashboard de tu proyecto. Busca la tarjeta de incorporación para continuar donde lo dejaste.

### Elegí el repositorio de GitHub incorrecto
Crea un nuevo proyecto con el repositorio correcto — puedes eliminar el antiguo en cualquier momento.

### Necesito ayuda durante la incorporación
Contacta con el [soporte](/es/help/support/contact) en cualquier momento del proceso.
