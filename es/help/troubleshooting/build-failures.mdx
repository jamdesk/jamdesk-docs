Abre el build fallido en tu pestaña **Deployments** y relaciona el mensaje de error con una sección a continuación.

## Encontrar el error

1. Ve a la pestaña **Deployments** de tu proyecto
2. Haz clic en el build fallido
3. Revisa el mensaje de error y el log

El log muestra exactamente qué salió mal y dónde.

## Fallas comunes

### Configuración inválida

**Error:** "Invalid docs.json"

Tu `docs.json` tiene errores de sintaxis o de esquema.

**Solución:**
1. Revisa si faltan comas, corchetes o comillas
2. Ejecuta `jamdesk validate` localmente
3. Compara con la [referencia del esquema](/es/config/docs-json-reference)

### Páginas faltantes

**Error:** "Page 'path/to/page' not found"

Una página en la navegación no existe.

**Solución:**
- Verifica que el archivo exista
- Comprueba que la ruta coincida exactamente (distingue mayúsculas y minúsculas)
- No incluyas la extensión `.mdx` en `docs.json`

### Errores de sintaxis MDX

**Error:** "MDX compilation failed"

Sintaxis MDX o JSX inválida.

**Causas comunes:**
- Etiquetas sin cerrar: `<Card>` sin `</Card>`
- Llaves sin escapar: `{` en lugar de `\{`
- Props inválidas: `title=value` en lugar de `title="value"`

### Imágenes faltantes

**Error:** "Asset not found"

Una imagen referenciada en MDX no existe.

**Solución:**
- Verifica que la ruta de la imagen sea correcta
- Las rutas son relativas a tu directorio de docs
- Verifica que el archivo se haya subido a Git

## Pasos de depuración

<Steps>
  <Step title="Lee el error">
    El log te indica exactamente qué falló y dónde.
  </Step>
  <Step title="Prueba localmente">
    Ejecuta `jamdesk dev` para reproducir el error.
  </Step>
  <Step title="Valida la configuración">
    Ejecuta `jamdesk validate` para revisar tu configuración.
  </Step>
  <Step title="Revisa los cambios recientes">
    Revisa tu último commit en busca del problema.
  </Step>
</Steps>

## ¿Sigues atascado?

Si no puedes resolver el problema:

1. Copia el log completo del build
2. Anota el ID de tu proyecto
3. [Contacta con soporte](/es/help/support/contact)
