---
title: Descripción general del despliegue
description: "Opciones de alojamiento para tu documentación — subdominio de Jamdesk, dominio personalizado con SSL, o subpath /docs detrás de tu sitio existente usando un proxy inverso."
---

Jamdesk despliega tu documentación automáticamente en un subdominio `*.jamdesk.app`. Cuando estés listo para publicar en tu propio dominio, puedes elegir un subdominio personalizado (como `docs.example.com`) o alojarla en un subpath `/docs` en tu sitio principal.

## Opciones de despliegue

| Opción | Ideal para | Complejidad de configuración |
|--------|-----------|------------------------------|
| **Subdominio de Jamdesk** (`your-project.jamdesk.app`) | Lanzamiento rápido, sin trabajo de DNS | Baja |
| **Subdominio personalizado** (`docs.example.com`) | Documentación de producción con tu marca | Media |
| **Alojamiento en subpath** (`example.com/docs`) | Mantener la documentación en el dominio principal | Alta |

## Alojamiento predeterminado (sin configuración)

Cada proyecto se publica en un subdominio de Jamdesk en cuanto conectas un repositorio. Esta es la opción más sencilla para documentación interna, previews o lanzamientos tempranos.

## Dominio personalizado (subdominio)

Usa tu propio subdominio (por ejemplo, `docs.example.com`) para una URL pública con tu marca. Añadirás registros DNS y verificarás la propiedad en el dashboard de Jamdesk.

<Note>
La verificación DNS y el SSL se gestionan automáticamente una vez que los registros estén configurados. Consulta [Dominios personalizados](/es/deploy/custom-domains) para la configuración.
</Note>

## Alojamiento en subpath (/docs)

Aloja la documentación en `example.com/docs` redirigiendo el tráfico a Jamdesk. Es ideal cuando quieres que la documentación esté en tu dominio de marketing principal.

<Info>
El alojamiento en subpath requiere un proxy o una capa CDN para reenviar las solicitudes y establecer el encabezado `X-Jamdesk-Forwarded-Host`. Consulta [Alojamiento en subpath](/es/deploy/subpath-hosting).
</Info>

### Ejemplo de fragmento de proxy (nginx)

```nginx nginx.conf
location /docs {
    proxy_pass https://YOUR_SLUG.jamdesk.app;
    proxy_set_header X-Jamdesk-Forwarded-Host $host;
}
```

Para una configuración completa con SSL, encabezados y guías específicas por proveedor, consulta la guía de [Alojamiento en subpath](/es/deploy/subpath-hosting).
