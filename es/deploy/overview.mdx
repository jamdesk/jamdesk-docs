---
title: Resumen del despliegue
description: "Opciones de hosting para tu documentación: subdominio de Jamdesk, dominio personalizado con SSL o subruta /docs tras tu sitio vía proxy inverso."
---

Jamdesk despliega tu documentación automáticamente en un subdominio `*.jamdesk.app`. Cuando estés listo para desplegarla en tu propio dominio, puedes elegir un subdominio personalizado (como `docs.example.com`) o alojarla en una subruta `/docs` en tu sitio principal.

## Opciones de despliegue

| Opción | Ideal para | Complejidad de configuración |
|--------|----------|------------------|
| **Subdominio de Jamdesk** (`your-project.jamdesk.app`) | Lanzamiento más rápido, sin trabajo de DNS | Baja |
| **Subdominio personalizado** (`docs.example.com`) | Documentación de producción con tu marca | Media |
| **Hosting en subruta** (`example.com/docs`) | Mantener la documentación en el dominio principal | Alta |

## Hosting predeterminado (sin configuración)

Cada proyecto se despliega en vivo en un subdominio de Jamdesk en cuanto conectas un repo. Esta es la opción más simple para documentación interna, previews o lanzamientos tempranos.

## Dominio personalizado (subdominio)

Usa tu propio subdominio (por ejemplo, `docs.example.com`) para obtener una URL de marca y de cara al público. Añadirás registros DNS y verificarás la propiedad en el dashboard de Jamdesk.

<Note>
La verificación DNS y el SSL se gestionan automáticamente una vez que los registros están en su lugar. Consulta [Dominios personalizados](/es/deploy/custom-domains) para la configuración.
</Note>

## Hosting en subruta (/docs)

Aloja la documentación en `example.com/docs` mediante un proxy del tráfico hacia Jamdesk. Esto es ideal cuando quieres que la documentación viva bajo tu dominio de marketing principal.

<Info>
El hosting en subruta requiere una capa de proxy o CDN para reenviar las solicitudes y establecer el encabezado `X-Jamdesk-Forwarded-Host`. Consulta [Hosting en subruta](/es/deploy/subpath-hosting).
</Info>

### Ejemplo de fragmento de proxy (nginx)

```nginx nginx.conf
location /docs {
    proxy_pass https://YOUR_SLUG.jamdesk.app;
    proxy_set_header X-Jamdesk-Forwarded-Host $host;
}

location /_next/ {
    proxy_pass https://YOUR_SLUG.jamdesk.app;
}

location /_jd/ {
    proxy_pass https://YOUR_SLUG.jamdesk.app;
}
```

Para una configuración completa con SSL, encabezados y guías específicas de cada proveedor, consulta la guía de [Hosting en subruta](/es/deploy/subpath-hosting).
