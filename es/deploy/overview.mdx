---
title: Resumen del despliegue
description: "Aloja tu documentación: subdominio de Jamdesk, dominio personalizado con SSL, o subruta /docs detrás de tu sitio con un proxy inverso."
---

Jamdesk despliega tu documentación automáticamente en un subdominio `*.jamdesk.app`. Cuando estés listo para salir a producción con tu propio dominio, puedes elegir un subdominio personalizado (como `docs.example.com`) o alojar la documentación en una subruta de tu sitio principal: `/docs` de forma predeterminada, o cualquier segmento personalizado que elijas.

## Opciones de despliegue

| Opción | Ideal para | Complejidad de configuración |
|--------|----------|------------------|
| **Subdominio Jamdesk** (`your-project.jamdesk.app`) | Lanzamiento más rápido, sin configuración DNS | Baja |
| **Subdominio personalizado** (`docs.example.com`) | Documentación de producción con tu marca | Media |
| **Alojamiento en subruta** (`example.com/docs`, personalizable) | Mantener la documentación en el dominio principal | Alta |

## Alojamiento predeterminado (sin configuración)

Cada proyecto se publica en un subdominio de Jamdesk en cuanto conectas un repositorio. Es la opción más simple para documentación interna, preview, o lanzamientos tempranos.

## Dominio personalizado (subdominio)

Usa tu propio subdominio (por ejemplo, `docs.example.com`) para una URL pública con tu marca. Añadirás registros DNS y verificarás la propiedad desde el dashboard de Jamdesk.

<Note>
La verificación de DNS y el SSL se gestionan automáticamente una vez que los registros están configurados. Consulta [Dominios personalizados](/es/deploy/custom-domains) para la configuración.
</Note>

## Alojamiento en subruta

Aloja la documentación en una subruta de tu dominio redirigiendo el tráfico hacia Jamdesk mediante un proxy: `example.com/docs` de forma predeterminada, o un segmento personalizado como `example.com/help`. Usa esta opción cuando quieras que la documentación esté bajo tu dominio de marketing principal.

<Info>
El alojamiento en subruta requiere una capa de proxy o CDN para reenviar las solicitudes y definir el encabezado `X-Jamdesk-Forwarded-Host`. Consulta [Alojamiento en subruta](/es/deploy/subpath-hosting).
</Info>

### Ejemplo de fragmento de proxy (nginx)

```nginx nginx.conf
location /docs {
    proxy_pass https://YOUR_SLUG.jamdesk.app;
    proxy_set_header X-Jamdesk-Forwarded-Host $host;
}

location /_next/ {
    proxy_pass https://YOUR_SLUG.jamdesk.app;
}

location /_jd/ {
    proxy_pass https://YOUR_SLUG.jamdesk.app;
}
```

Para obtener una configuración completa con SSL, encabezados y orientación específica del proveedor, consulta la guía [Alojamiento en subruta](/es/deploy/subpath-hosting).
