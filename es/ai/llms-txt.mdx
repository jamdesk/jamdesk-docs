Si quieres que herramientas de IA como ChatGPT, Claude o Copilot den respuestas precisas sobre tu producto, necesitan acceso estructurado a tus docs, no solo lo que quedó en sus datos de entrenamiento.

Cada sitio de Jamdesk genera `llms.txt` y `llms-full.txt` siguiendo la especificación de [llmstxt.org](https://llmstxt.org). Las herramientas de IA leen estos archivos en lugar de rastrear páginas individuales.

<Note>
  Google ahora audita `llms.txt` como parte de las [comprobaciones de navegación agéntica de Lighthouse](https://developer.chrome.com/docs/lighthouse/agentic-browsing/llms-txt). Los sitios que publican un `llms.txt` válido son más descubribles para los agentes de IA — y, cada vez más, para el propio Google al clasificar contenido para respuestas basadas en IA. Jamdesk te ofrece esto de forma gratuita.
</Note>

<Tip>
  **Comprueba tu puntuación.** Mira qué tan preparado para los agentes de IA está cualquier sitio de documentación con la herramienta gratuita [AI Score](https://www.jamdesk.com/ai-score): publicar un `llms.txt` válido es una de las primeras cosas que comprueba. También hay una [extensión de Chrome de AI Score](https://chromewebstore.google.com/detail/jamdesk-ai-score/mhihkkgpcbmapmojnakhjfhjmiagkhlj) para evaluar sitios mientras navegas.
</Tip>

## Qué genera Jamdesk

| Archivo | Contenido |
|---------|-----------|
| `llms.txt` | Títulos de páginas, descripciones y URLs (una tabla de contenidos estructurada) |
| `llms-full.txt` | Contenido completo de la documentación en un único archivo |

Jamdesk genera ambos en tiempo de build y los sirve desde el mismo CDN que tus docs.

## Verifica tus archivos

Comprueba que tus archivos existen después de tu primer build:

<Tabs>
  <Tab title="Dominio raíz">
    Si tus docs están en la raíz de tu dominio (p. ej., `docs.acme.com` o `acme.jamdesk.app`):

    ```bash
    curl https://docs.acme.com/llms.txt
    curl https://docs.acme.com/llms-full.txt
    ```
  </Tab>
  <Tab title="Subruta /docs">
    Si tus docs están bajo `/docs` en tu sitio principal (como este sitio en `jamdesk.com/docs`):

    ```bash
    curl https://jamdesk.com/docs/llms.txt
    curl https://jamdesk.com/docs/llms-full.txt
    ```
  </Tab>
</Tabs>

## Formato del archivo

El archivo `llms.txt` lista cada página con su título, descripción y URL, agrupadas en secciones que reflejan tu navegación:

```text
# Your Project Documentation

> Documentation for Your Project

## Get Started

- [Getting Started](https://your-project.jamdesk.app/getting-started): Set up your first project in 5 minutes
- [Configuration](https://your-project.jamdesk.app/configuration): Configure your project settings

## API Reference

- [Authentication](https://your-project.jamdesk.app/authentication): How to authenticate API requests
```

El archivo `llms-full.txt` contiene el contenido Markdown completo de cada página, concatenado con límites de página marcados por encabezados.

## Estructura

`llms.txt` sigue la propuesta de [llmstxt.org](https://llmstxt.org/): un título H1,
un resumen en bloque de cita, y las pestañas y grupos de tu navegación como secciones `##` de
enlaces Markdown.

Los sitios multilingües obtienen un índice por idioma. El `llms.txt` raíz lista tu
idioma predeterminado y enlaza cada índice traducido al final — por ejemplo
`/es/llms.txt` para español. Cada archivo de idioma enlaza de vuelta a sus equivalentes.

## Directiva de agente en cada página

Cada página también lleva una nota invisible y silenciosa para lectores de pantalla destinada a los agentes de IA
que apunta a `llms.txt`, y cada exportación Markdown comienza con un bloque de cita
que enlaza el índice. Los agentes que llegan a tu HTML encuentran la ruta Markdown
sin necesidad de rastrear.

## Cómo se construye

- Generado en tiempo de build junto con tu HTML
- Servido desde CDN con la misma política de caché que tus docs
- Se actualiza automáticamente en cada build
- No se necesita configuración; todas las páginas se incluyen por defecto

## Rastreadores de IA

El `robots.txt` predeterminado de Jamdesk permite todos los rastreadores de IA principales (Claude, ChatGPT, Copilot, Gemini). Tu documentación es accesible para herramientas de IA desde el primer momento.

<Accordion title="En qué se diferencia llms.txt de sitemap.xml">
  `sitemap.xml` lista URLs para que los motores de búsqueda las rastreen e indexen. No incluye ningún contenido, solo enlaces y metadatos como fechas de última modificación.

  `llms.txt` está diseñado para modelos de IA. Incluye títulos de páginas, descripciones y (en `llms-full.txt`) el contenido real. Las herramientas de IA pueden leer el archivo completo para entender tu documentación sin realizar múltiples solicitudes HTTP.
</Accordion>
