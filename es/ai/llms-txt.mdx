Si quieres que herramientas de IA como ChatGPT, Claude o Copilot den respuestas precisas sobre tu producto, necesitan acceso estructurado a tu documentación, no solo lo que haya llegado a sus datos de entrenamiento.

Cada sitio de Jamdesk genera `llms.txt` y `llms-full.txt` siguiendo la especificación de [llmstxt.org](https://llmstxt.org). Las herramientas de IA leen estos archivos en lugar de rastrear páginas individuales.

<Note>
  Google ahora audita `llms.txt` como parte de las [comprobaciones de navegación agéntica de Lighthouse](https://developer.chrome.com/docs/lighthouse/agentic-browsing/llms-txt). Los sitios que publican un `llms.txt` válido son más descubribles por los agentes de IA — y, cada vez más, por el propio Google al clasificar contenido para respuestas basadas en IA. Jamdesk te lo ofrece de forma gratuita.
</Note>

## Qué genera Jamdesk

| Archivo | Contenido |
|---------|-----------|
| `llms.txt` | Títulos de páginas, descripciones y URLs (una tabla de contenidos estructurada) |
| `llms-full.txt` | Contenido completo de la documentación en un solo archivo |

Jamdesk genera ambos en el momento del build y los sirve desde el mismo CDN que tu documentación.

## Verifica tus archivos

Comprueba que tus archivos existen después de tu primer build:

<Tabs>
  <Tab title="Dominio raíz">
    Si tu documentación está en la raíz de tu dominio (p. ej., `docs.acme.com` o `acme.jamdesk.app`):

    ```bash
    curl https://docs.acme.com/llms.txt
    curl https://docs.acme.com/llms-full.txt
    ```
  </Tab>
  <Tab title="Subruta /docs">
    Si tu documentación está bajo `/docs` en tu sitio principal (como este sitio en `jamdesk.com/docs`):

    ```bash
    curl https://jamdesk.com/docs/llms.txt
    curl https://jamdesk.com/docs/llms-full.txt
    ```
  </Tab>
</Tabs>

## Formato de los archivos

El archivo `llms.txt` lista cada página con su título, descripción y URL:

```text
# Your Project Documentation

> Documentation for Your Project

## Pages

- [Getting Started](https://your-project.jamdesk.app/getting-started): Set up your first project in 5 minutes
- [Authentication](https://your-project.jamdesk.app/authentication): How to authenticate API requests
- [Configuration](https://your-project.jamdesk.app/configuration): Configure your project settings
```

El archivo `llms-full.txt` contiene el contenido Markdown completo de cada página, concatenado con límites de página marcados mediante encabezados.

## Cómo se genera

- Se genera en el momento del build junto con tu HTML
- Se sirve desde CDN con la misma política de caché que tu documentación
- Se actualiza automáticamente en cada build
- No requiere configuración; todas las páginas se incluyen por defecto

## Rastreadores de IA

El `robots.txt` predeterminado de Jamdesk permite todos los rastreadores de IA principales (Claude, ChatGPT, Copilot, Gemini). Tu documentación es accesible para herramientas de IA de forma inmediata.

<Accordion title="En qué se diferencia llms.txt de sitemap.xml">
  `sitemap.xml` lista URLs para que los motores de búsqueda las rastreen e indexen. No incluye ningún contenido, solo enlaces y metadatos como fechas de última modificación.

  `llms.txt` está diseñado para modelos de IA. Incluye títulos de páginas, descripciones y (en `llms-full.txt`) el contenido real. Las herramientas de IA pueden leer el archivo completo para entender tu documentación sin realizar múltiples solicitudes HTTP.
</Accordion>
