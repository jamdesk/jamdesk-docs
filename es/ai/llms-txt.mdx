Si quieres que herramientas de IA como ChatGPT, Claude o Copilot den respuestas precisas sobre tu producto, necesitan acceso estructurado a tu documentación, no solo lo que haya llegado a sus datos de entrenamiento.

Todos los sitios de Jamdesk generan `llms.txt` y `llms-full.txt` siguiendo la especificación [llmstxt.org](https://llmstxt.org). Las herramientas de IA leen estos archivos en lugar de rastrear cada página por separado.

<Note>
  Google ahora audita `llms.txt` como parte de las [comprobaciones de navegación agéntica de Lighthouse](https://developer.chrome.com/docs/lighthouse/agentic-browsing/llms-txt). Los sitios que publican un `llms.txt` válido son más fáciles de descubrir para los agentes de IA, y cada vez más para el propio Google al clasificar contenido para respuestas basadas en IA. Jamdesk te ofrece esto de forma gratuita.
</Note>

<Tip>
  **Comprueba tu puntuación.** Descubre qué tan preparado está cualquier sitio de documentación para los agentes con la herramienta gratuita [AI Score](https://jamdesk.com/ai-score). Publicar un `llms.txt` válido es una de las primeras cosas que comprueba. También hay una [extensión de Chrome AI Score](https://chromewebstore.google.com/detail/jamdesk-ai-score/mhihkkgpcbmapmojnakhjfhjmiagkhlj) para calificar sitios mientras navegas.
</Tip>

## Qué genera Jamdesk

| Archivo | Contenido |
|------|---------|
| `llms.txt` | Títulos de página, descripciones y URL (una tabla de contenidos estructurada) |
| `llms-full.txt` | Contenido completo de la documentación en un solo archivo |

Jamdesk genera ambos en el momento del build y los sirve desde el mismo CDN que tu documentación.

## Verifica tus archivos

Comprueba que tus archivos existen después de tu primer build:

<Tabs>
  <Tab title="Dominio raíz">
    Si tu documentación está en la raíz de tu dominio (por ejemplo, `docs.acme.com` o `acme.jamdesk.app`):

    ```bash
    curl https://docs.acme.com/llms.txt
    curl https://docs.acme.com/llms-full.txt
    ```
  </Tab>
  <Tab title="Subruta /docs">
    Si tu documentación está bajo `/docs` en tu sitio principal (como este sitio en `jamdesk.com/docs`):

    ```bash
    curl https://jamdesk.com/docs/llms.txt
    curl https://jamdesk.com/docs/llms-full.txt
    ```
  </Tab>
</Tabs>

## Formato de archivo

El archivo `llms.txt` enumera cada página con su título, descripción y URL, agrupadas en secciones que reflejan tu navegación:

```text
# Your Project Documentation

> Documentation for Your Project

## Get Started

- [Getting Started](https://your-project.jamdesk.app/getting-started): Set up your first project in 5 minutes
- [Configuration](https://your-project.jamdesk.app/configuration): Configure your project settings

## API Reference

- [Authentication](https://your-project.jamdesk.app/authentication): How to authenticate API requests
```

El archivo `llms-full.txt` contiene el contenido Markdown completo de cada página, concatenado con los límites de página marcados por encabezados.

## Estructura

`llms.txt` sigue la propuesta de [llmstxt.org](https://llmstxt.org/): un título H1,
un resumen en cita, y tus pestañas y grupos de navegación como secciones `##`
de enlaces Markdown.

## Sitios multilingües

Los sitios con más de un idioma obtienen un conjunto de archivos independiente para cada
idioma, de modo que una herramienta de IA pueda obtener solo el idioma que necesita. Para un sitio en
inglés (el predeterminado) y francés:

| URL | Contenido |
|-----|---------|
| `/llms.txt` | Índice en inglés, con enlaces al índice de cada otro idioma al final |
| `/en/llms.txt` | Igual que el archivo `/llms.txt` |
| `/fr/llms.txt` | Índice en francés, con enlaces de vuelta a los demás idiomas |
| `/llms-full.txt` | Contenido completo de todos los idiomas, uno tras otro |
| `/en/llms-full.txt` | Contenido completo solo de las páginas en inglés |
| `/fr/llms-full.txt` | Contenido completo solo de las páginas en francés |

El `llms-full.txt` raíz conserva todos los idiomas, así que las herramientas que ya lo leen
no notan ningún cambio. Dirige un agente al archivo propio de un idioma cuando solo necesite ese
idioma:

```bash
curl https://jamdesk.com/docs/fr/llms-full.txt
```

Un idioma obtiene sus propios archivos en cuanto tiene al menos una página. Los sitios con
un solo idioma conservan únicamente los archivos raíz.

## Directiva de agente en cada página

Cada página también incluye una nota invisible y silenciosa para lectores de pantalla, dirigida a los agentes de IA,
que apunta a `llms.txt`, y cada exportación en Markdown comienza con una cita
que enlaza al índice. Los agentes que llegan a tu HTML encuentran la ruta de Markdown
sin necesidad de rastrear el sitio.

## Cómo se genera

- Se genera en el momento del build junto con tu HTML
- Se sirve desde el CDN con la misma política de caché que tu documentación
- Se actualiza automáticamente en cada build
- No requiere configuración; todas las páginas se incluyen de forma predeterminada

## Desactivar llms.txt

`llms.txt` y `llms-full.txt` se publican de forma predeterminada. Para dejar de generarlos (por ejemplo, si no quieres que las herramientas de IA usen tu contenido), define `seo.ai.llmsTxt` como `false` en tu `docs.json`:

```json docs.json
{
  "seo": {
    "ai": {
      "llmsTxt": false
    }
  }
}
```

En tu próximo build, Jamdesk omite ambos archivos, incluida cada copia por idioma, y las URL activas `/llms.txt` y `/llms-full.txt` devuelven `404`.

<Note>
  **La ingesta de IA y la indexación en buscadores son controles independientes.** `seo.ai.llmsTxt` rige únicamente los archivos `llms.txt`/`llms-full.txt` que leen las herramientas de IA. No cambia la forma en que los motores de búsqueda indexan tu sitio; eso lo controlan los [metadatos `robots` y el `noindex` por página](/es/content/seo#control-de-la-indexación). Una página puede estar indexada por Google y a la vez excluida de la ingesta de IA, o viceversa.
</Note>

## Rastreadores de IA

El `robots.txt` predeterminado de Jamdesk permite todos los principales rastreadores de IA (Claude, ChatGPT, Copilot, Gemini). Tu documentación es accesible para las herramientas de IA desde el primer momento.

<Accordion title="En qué se diferencia llms.txt de sitemap.xml">
  `sitemap.xml` enumera las URL que los motores de búsqueda deben rastrear e indexar. No incluye contenido alguno, solo enlaces y metadatos como las fechas de última modificación.

  `llms.txt` está diseñado para modelos de IA. Incluye títulos de página, descripciones y (en `llms-full.txt`) el contenido real. Las herramientas de IA pueden leer el archivo completo para entender tu documentación sin hacer múltiples solicitudes HTTP.
</Accordion>
