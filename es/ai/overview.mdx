Cuando los desarrolladores le preguntan a la IA sobre tu producto, esta suele trabajar con datos de entrenamiento desactualizados o directamente no puede acceder a tus docs. Cada build de Jamdesk genera tres endpoints de IA (`llms.txt`, un servidor MCP y URLs de Markdown sin procesar) para que las herramientas de IA puedan leer tus docs actuales directamente, sin hacer scraping de HTML. Tus visitantes también obtienen un asistente de chat integrado que responde preguntas directamente desde tus docs.

Esta sección cubre esos endpoints, el chat de IA integrado y cómo configurar herramientas de IA para escribir y mantener tu documentación.

<Tip>
  **Descubre cómo se califica tu documentación.** Jamdesk califica tus propias docs en cada build. Abre [AI Score](/es/ai/ai-score) en el dashboard para ver tu calificación y los problemas por corregir. También puedes evaluar cualquier sitio de documentación con la herramienta gratuita [AI Score tool](https://jamdesk.com/ai-score), calificada según el estándar abierto [AFDocs](https://afdocs.dev), o calificar sitios mientras navegas con la [extensión AI Score para Chrome](https://chromewebstore.google.com/detail/jamdesk-ai-score/mhihkkgpcbmapmojnakhjfhjmiagkhlj).
</Tip>

## Cómo funciona

<Steps>
  <Step title="Escribe MDX">
    Crea páginas de documentación en Markdown con componentes de React opcionales.
  </Step>
  <Step title="Push y build">
    Jamdesk hace el build de tu sitio y genera los endpoints de IA junto con tu HTML.
  </Step>
  <Step title="Las herramientas de IA se conectan">
    Claude, Cursor, ChatGPT y otras herramientas pueden acceder a tus docs mediante llms.txt, MCP o URLs de Markdown sin procesar.
  </Step>
</Steps>
