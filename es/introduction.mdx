Jamdesk es una [herramienta de documentación de software](https://www.jamdesk.com) que genera sitios de documentación a partir de tus archivos Markdown. Conecta un repositorio de GitHub, escribe en MDX y despliega globalmente en segundos. No necesitas configurar un pipeline de build ni gestionar DevOps por tu cuenta. Cada sitio genera un archivo `llms.txt` para que las herramientas de AI puedan indexar tu contenido.

<Info>
**Escribe con AI.** Usa Cursor, Claude o cualquier asistente de AI para generar y editar tus docs. MDX es un formato de texto que las herramientas de AI comprenden de forma nativa, por lo que no se necesitan prompts especiales.
</Info>

## Un Proyecto Mínimo de Jamdesk

```text
my-docs/
├── docs.json
└── introduction.mdx
```

Eso es todo lo que necesitas. Consulta el [Inicio rápido](/es/quickstart) para crear el tuyo.

<Tip>
Explora el [código fuente de esta documentación](https://github.com/jamdesk/jamdesk-docs) en GitHub. Es un proyecto Jamdesk funcional que puedes usar como referencia.
</Tip>

## Cómo Funciona

<Steps>
  <Step title="Escribe en MDX">
    Crea documentación usando Markdown con componentes React opcionales. Usa tu editor favorito: VS Code, Cursor o cualquier editor de texto. Herramientas de AI como Claude pueden generar y editar MDX de forma nativa.
  </Step>
  <Step title="Haz Push a GitHub">
    Confirma tus cambios y haz push. No necesitas ejecutar un comando de build ni mantener un script de despliegue.
  </Step>
  <Step title="En Vivo en Segundos">
    Jamdesk detecta tu push, hace el build de tu sitio y lo despliega en un CDN global. Tu documentación estará disponible en `your-project.jamdesk.app`.
  </Step>
</Steps>
