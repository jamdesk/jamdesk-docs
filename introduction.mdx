Jamdesk is a documentation platform that transforms your Markdown files into beautiful, AI-ready docs sites.
Connect your GitHub repo, write in MDX, and deploy globally in seconds—no build pipelines, and no DevOps.

<Info>
**Works with your AI tools.** Write docs using Cursor, Claude, or any AI assistant. Jamdesk's MDX format is LLM-friendly—AI tools understand it natively, making doc generation and editing effortless.
</Info>

## A Minimal Jamdesk Project

```text
my-docs/
├── docs.json
└── introduction.mdx
```

## How It Works

<Steps>
  <Step title="Write in MDX">
    Create docs using Markdown with optional React components. Use your favorite editor—VS Code, Cursor, or any text editor. AI tools like Claude can generate and edit MDX natively.
  </Step>
  <Step title="Push to GitHub">
    Commit your changes and push. That's it—no build commands, no deploy scripts.
  </Step>
  <Step title="Live in Seconds">
    Jamdesk detects your push, builds your site, and deploys to a global CDN. Your docs are live at `your-project.jamdesk.app`.
  </Step>
</Steps>
