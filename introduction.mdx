## The Jamdesk Workflow

<Steps>
  <Step title="Write">
    Create MDX files with your documentation. Use components like Cards, Tabs, and Steps to make content scannable.
  </Step>
  <Step title="Preview">
    Run `jamdesk dev` to preview locally with hot reload. See changes instantly as you type.
  </Step>
  <Step title="Deploy">
    Push to GitHub. Jamdesk builds and deploys automatically. Your changes are live in under a minute.
  </Step>
</Steps>

## Core Features

| Feature | Description |
|---------|-------------|
| **MDX Components** | Cards, Tabs, Accordions, Steps, Code Groups, and more |
| **Syntax Highlighting** | Shiki-powered code blocks with 100+ language support |
| **Automatic Search** | Full-text search indexed on every deploy |
| **Dark Mode** | Automatic theme switching based on system preference |
| **SEO Optimized** | Meta tags, Open Graph, and structured data built in |
| **Custom Domains** | Your docs at `docs.yourcompany.com` with free SSL |
