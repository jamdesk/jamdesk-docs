title: Problemas de analytics
description: Diagnostique dados de analytics ausentes ou atrasados, causados por bloqueadores de anúncios, atrasos de propagação e limites de retenção.
---

A maioria dos dados de analytics ausentes ou inesperados é causada por bloqueadores de anúncios, atrasos de propagação ou limites de retenção de dados.

## Nenhum dado é exibido

### Implantação recente

Os analytics levam algumas horas para serem preenchidos após sua primeira implantação. Verifique novamente mais tarde.

### Bloqueadores de anúncios

Alguns bloqueadores de anúncios impedem o carregamento dos analytics. Faça um teste com os bloqueadores desativados.

### Do Not Track

Usuários com o Do Not Track ativado não serão rastreados. Isso é intencional.

## Os dados parecem incorretos

### Visualizações de página muito baixas

Possíveis causas:
- Bloqueadores de anúncios nos navegadores dos visitantes
- Páginas armazenadas em cache que não acionam os analytics
- Implantação recente (os dados ainda estão sendo preenchidos)

### Visualizações de página muito altas

Possíveis causas:
- Tráfego de bots (filtramos a maioria, mas parte consegue passar)
- Suas próprias visitas durante os testes
- Atualização das páginas durante o desenvolvimento

<Tip>
Use o modo de navegação anônima durante os testes para evitar distorções nos seus analytics.
</Tip>

## Analytics de pesquisa vazios

### A pesquisa não está sendo usada

Verifique se os visitantes estão realmente usando a pesquisa. A caixa de pesquisa precisa estar visível e funcionar corretamente.

### Implantação recente

Os analytics de pesquisa levam tempo para serem preenchidos. Aguarde de 24 a 48 horas após a implantação.

### Problemas de indexação

Se a pesquisa retornar resultados ruins, os visitantes poderão desistir. Verifique se o conteúdo está sendo indexado corretamente testando algumas pesquisas.

## Páginas ausentes nos relatórios

### Página não implantada

Verifique se a página existe na sua documentação publicada.

### Sem tráfego

Páginas com zero visualizações não aparecem nos relatórios.

### Retenção de dados

| Plano | Retenção |
|------|-----------|
| Avaliação | 7 dias |
| Pro | 90 dias |

Os dados mais antigos são removidos automaticamente.

## Problemas com dados geográficos

### A localização mostra "Unknown"

Alguns visitantes usam VPNs ou desativaram o compartilhamento de localização. Isso é normal.

### Localizações incorretas

Usamos geolocalização por IP, que ocasionalmente é imprecisa. Grandes discrepâncias podem indicar o uso de uma VPN.

## Exportação de dados

Para exportar analytics:

1. Acesse **Analytics**
2. Selecione o intervalo de datas
3. Clique em **Export**
4. Escolha o formato CSV ou JSON

## Analytics em tempo real

O Jamdesk não fornece analytics em tempo real. Os dados são atualizados a cada poucas horas.

Para necessidades em tempo real, considere integrar uma ferramenta de analytics de terceiros junto ao Jamdesk.
