title: Problemas com análises
description: Diagnostique dados de análise ausentes ou atrasados. Causas comuns incluem bloqueadores de anúncios, atrasos de propagação após o primeiro deploy e limites de retenção de dados.
---

A maioria dos dados de análise ausentes ou inesperados vem de bloqueadores de anúncios, atrasos de propagação ou limites de retenção de dados.

## Nenhum dado é exibido

### Implantação recente

As análises levam algumas horas para serem preenchidas após o seu primeiro deploy.

### Bloqueadores de anúncios

Alguns bloqueadores de anúncios impedem o carregamento das análises. Teste com os bloqueadores desativados.

### Do Not Track

A Jamdesk não rastreia visitantes com Do Not Track ativado.

## Os dados parecem incorretos

### Visualizações de página muito baixas

Possíveis causas:
- Bloqueadores de anúncios nos navegadores dos visitantes
- Páginas em cache que não disparam as análises
- Deploy recente (dados ainda sendo preenchidos)

### Visualizações de página muito altas

Possíveis causas:
- Tráfego de bots (filtramos a maioria, mas parte passa)
- Suas próprias visitas durante os testes
- Atualizações de página durante o desenvolvimento

<Tip>
Teste no modo anônimo para evitar que suas próprias visitas entrem nas análises.
</Tip>

## Analytics de pesquisa vazios

### A pesquisa não está sendo usada

Verifique se os visitantes usam a pesquisa. Confirme que a caixa de pesquisa é fácil de encontrar e está funcionando.

### Implantação recente

As análises de pesquisa levam de 24 a 48 horas para serem preenchidas após o deploy.

### Problemas de indexação

Resultados de pesquisa ruins fazem os visitantes desistirem. Faça pesquisas de teste para confirmar que seu conteúdo está indexado.

## Páginas ausentes nos relatórios

### Página não implantada

Verifique se a página existe na sua documentação publicada.

### Sem tráfego

Páginas com zero visualizações não aparecem nos relatórios.

### Retenção de dados

| Plano | Retenção |
|------|-----------|
| Trial | 7 dias |
| Pro | 90 dias |

Dados mais antigos são removidos automaticamente.

## Problemas com dados geográficos

### A localização mostra "Unknown"

Alguns visitantes usam VPNs ou têm a localização desativada.

### Localizações incorretas

A geolocalização por IP é ocasionalmente imprecisa. Discrepâncias grandes podem indicar uma VPN.

## Exportação de dados

Para exportar as análises:

1. Acesse **Analytics**
2. Selecione o intervalo de datas
3. Clique em **Export**
4. Escolha o formato CSV ou JSON

## Analytics em tempo real

A Jamdesk não oferece análises em tempo real. Os dados são atualizados a cada poucas horas.

Adicione uma ferramenta de análise de terceiros junto com a Jamdesk para obter dados em tempo real.
