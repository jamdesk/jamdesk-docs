Crie um projeto no dashboard para configurar um novo site de documentação. Comece a partir de um template ou conecte um repositório GitHub existente. O Jamdesk instala o webhook e executa o primeiro build.

## Criar um novo projeto

<Steps>
  <Step title="Abra o dashboard">
    Acesse [dashboard.jamdesk.com](https://dashboard.jamdesk.com) e faça login.
  </Step>
  <Step title="Clique em New Project">
    Selecione **New Project** no dashboard.
  </Step>
  <Step title="Escolha sua origem">
    Escolha como começar sua documentação:

    <Tabs>
      <Tab title="Usar um template">
        Comece com o [Starter Template](https://github.com/jamdesk/starter-docs). O Jamdesk cria um repositório GitHub para você com conteúdo de exemplo, componentes e uma especificação OpenAPI.
      </Tab>
      <Tab title="Conectar repositório">
        Conecte um repositório GitHub existente que contenha sua documentação.
      </Tab>
    </Tabs>
  </Step>
  <Step title="Configure as definições">
    - **Project name**: exibido no dashboard
    - **Subdomain**: a URL da sua documentação (por exemplo, `my-docs.jamdesk.app`)
    - **Branch**: o branch Git a ser implantado (geralmente `main`)
  </Step>
  <Step title="Criar">
    Clique em **Create Project** para concluir a configuração.
  </Step>
</Steps>

## Limites de projetos

Seu plano determina quantos projetos você pode criar:

| Plano | Projetos |
|------|----------|
| Trial | 1 |
| Pro | 1 (expansível) |

Adicione vagas extras de projeto Pro na página **Subscription**.

## O que é criado

Em seguida, o Jamdesk:

1. Conecta-se ao seu repositório GitHub
2. Instala um webhook para builds automáticos
3. Dispara o seu primeiro build
4. Atribui um subdomínio `*.jamdesk.app`
