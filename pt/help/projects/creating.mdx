---
title: Criar projetos no dashboard
description: Um projeto no Jamdesk representa um único site de documentação. Cada projeto conecta-se a um repositório GitHub e é publicado em sua própria URL.
---

Configure um novo site de documentação criando um projeto no dashboard. Você pode começar com um modelo ou conectar um repositório GitHub existente; o Jamdesk gerencia automaticamente a instalação do Webhook e o primeiro build.

## Criar um novo projeto

<Steps>
  <Step title="Abrir o dashboard">
    Acesse [dashboard.jamdesk.com](https://dashboard.jamdesk.com) e faça login.
  </Step>
  <Step title="Clique em New Project">
    Selecione **New Project** no dashboard.
  </Step>
  <Step title="Escolher sua fonte">
    Escolha como iniciar sua documentação:

    <Tabs>
      <Tab title="Use a Template">
        Comece com o [Starter Template](https://github.com/jamdesk/starter-docs). O Jamdesk cria um repositório GitHub para você, com conteúdo de exemplo, componentes e uma especificação OpenAPI.
      </Tab>
      <Tab title="Connect Repository">
        Conecte um repositório GitHub existente que contenha sua documentação.
      </Tab>
    </Tabs>
  </Step>
  <Step title="Configurar as definições">
    - **Project name** — Exibido no dashboard
    - **Subdomain** — A URL da sua documentação (por exemplo, `my-docs.jamdesk.app`)
    - **Branch** — A branch Git a ser publicada (geralmente `main`)
  </Step>
  <Step title="Criar">
    Clique em **Create Project** para concluir a configuração.
  </Step>
</Steps>

## Limites de projetos

Seu plano determina quantos projetos você pode criar:

| Plano | Projetos |
|------|----------|
| Trial | 1 |
| Pro | 1 (expansível) |

Precisa de mais projetos no Pro? Adicione slots de projeto extras na página **Subscription**.

## O que é criado

Quando você cria um projeto, o Jamdesk:

1. Conecta-se ao seu repositório GitHub
2. Instala um Webhook para builds automáticos
3. Aciona seu primeiro build
4. Atribui um subdomínio `*.jamdesk.app`
