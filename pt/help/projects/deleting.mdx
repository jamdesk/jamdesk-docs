---
title: Exclusão de projetos
description: Remova permanentemente um projeto do dashboard: histórico de builds, análises e domínio são excluídos, mas o repositório GitHub permanece intacto.
---

Excluir um projeto o remove permanentemente do dashboard: todo o histórico de builds, as análises e a configuração de domínio são excluídos. Seu repositório GitHub não é afetado.

## Excluir um projeto seu

<Warning>
Excluir um projeto remove permanentemente todos os dados, incluindo o histórico de builds, as análises e a configuração de domínio personalizado. Essa ação não pode ser desfeita.
</Warning>

<Steps>
  <Step title="Abrir as configurações do projeto">
    Acesse seu projeto e clique em **Settings**.
  </Step>
  <Step title="Rolar até Danger Zone">
    Encontre a seção **Danger Zone** na parte inferior.
  </Step>
  <Step title="Clicar em Delete Project">
    Selecione **Delete Project**.
  </Step>
  <Step title="Confirmar a exclusão">
    Digite o nome do projeto para confirmar e clique em **Permanently Delete**.
  </Step>
</Steps>

## O que é excluído

- Todo o histórico e os logs de builds
- Dados de análises
- Configuração de domínio personalizado
- Associações de membros da equipe
- Integrações de Webhook

## O que NÃO é excluído

- Seu repositório GitHub, que permanece inalterado
- Sua conta Jamdesk
- Outros projetos seus

## Sair de um projeto

Se você for membro, mas não proprietário, de um projeto:

1. Acesse **Settings** → **Members**
2. Encontre seu nome na lista de membros
3. Clique em **Leave Project**
4. Confirme sua saída

Você poderá ser convidado novamente mais tarde, se necessário.

## Antes de excluir

Considere estas alternativas:

- **Transferir a propriedade** se os membros da equipe precisarem continuar com acesso
- **Exportar os dados de análises** se precisar de registros históricos
- **Anotar sua configuração** caso possa recriar o projeto

## Recuperar projetos excluídos

Não é possível recuperar projetos excluídos. Se você excluiu um projeto acidentalmente:

1. Crie um novo projeto
2. Conecte o mesmo repositório GitHub
3. Reconfigure as definições manualmente

O conteúdo da sua documentação permanece no repositório GitHub.
