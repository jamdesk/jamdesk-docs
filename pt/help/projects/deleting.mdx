title: Excluindo projetos

---

Excluir um projeto também exclui seu histórico de builds, análises e configuração de domínio. Seu repositório do GitHub não é afetado.

## Excluir um projeto seu

<Warning>
Excluir um projeto remove permanentemente todos os dados, incluindo histórico de builds, análises e configuração de domínio personalizado. Isso não pode ser desfeito.
</Warning>

<Steps>
  <Step title="Abra as configurações do projeto">
    Acesse seu projeto e clique em **Settings**.
  </Step>
  <Step title="Role até Danger Zone">
    Encontre a seção **Danger Zone** na parte inferior.
  </Step>
  <Step title="Clique em Delete Project">
    Selecione **Delete Project**.
  </Step>
  <Step title="Confirme a exclusão">
    Digite o nome do projeto para confirmar e clique em **Permanently Delete**.
  </Step>
</Steps>

## O que é excluído

- Todo o histórico de builds e logs
- Dados de análises
- Configuração de domínio personalizado
- Associações de membros da equipe
- Integrações de Webhook

## O que NÃO é excluído

- Seu repositório do GitHub (permanece inalterado)
- Sua conta Jamdesk
- Outros projetos que você possui

## Sair de um projeto

Se você é membro (não proprietário) de um projeto:

1. Acesse **Settings** → **Members**
2. Encontre seu nome na lista de membros
3. Clique em **Leave Project**
4. Confirme

Você pode ser convidado novamente mais tarde.

## Antes de excluir

Considere estas alternativas:

- **Transfira a propriedade** se membros da equipe precisarem de acesso contínuo
- **Exporte os dados de análise** se precisar de registros históricos
- **Anote sua configuração** caso possa recriar o projeto

## Recuperar projetos excluídos

Projetos excluídos não podem ser recuperados. Recrie um do zero:

1. Crie um novo projeto
2. Conecte o mesmo repositório do GitHub
3. Reconfigure as definições manualmente

Seu conteúdo de documentação permanece no seu repositório do GitHub.
