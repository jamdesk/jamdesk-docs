Configure o nome exibido do projeto, o repositório conectado, a branch, as variáveis de ambiente, o domínio personalizado e as opções da zona de risco na página **Settings**.

As capturas de tela mostram a interface em inglês.

## Acessar as configurações

1. Selecione seu projeto no dashboard
2. Clique em **Settings** na barra lateral

A página de configurações é dividida em seções de exibição, repositório, equipe, configuração e notificações.

## Configurações gerais

### Nome do projeto

O nome exibido no dashboard. Isso não afeta sua documentação publicada.

### Subdomínio

Sua URL padrão em `*.jamdesk.app`. Para alterá-la:

1. Insira um novo subdomínio
2. Clique em **Save**
3. Aguarde a propagação do DNS (geralmente instantânea)

<Note>
As alterações de subdomínio não quebram os links existentes. A URL antiga redireciona para a nova.
</Note>

## Configurações do repositório

### Repositório conectado

Mostra seu repositório do GitHub vinculado. Para alterar os repositórios, será necessário excluir o projeto e criar um novo.

### Branch

A branch do Git que aciona os builds. Normalmente, `main` ou `master`.

### Caminho dos docs

Em configurações de monorepo, especifique o caminho para seu `docs.json` (por exemplo, `packages/docs`).

Deixe vazio se `docs.json` estiver na raiz do repositório.

## Configurações de build

### Variáveis de ambiente

Defina variáveis usadas durante o build da sua documentação:

1. Clique em **Add Variable**
2. Insira a chave e o valor
3. Clique em **Save**

As variáveis ficam disponíveis durante o build e podem ser referenciadas nos seus docs.

### Rebuild

Clique em **Rebuild** para acionar um novo build sem fazer push para o GitHub. Útil após alterar as configurações.

## Domínio personalizado

Adicione seu próprio domínio na seção **Domains**. Consulte [Domínios personalizados](/pt/deploy/custom-domains) para obter instruções de configuração.

## Zona de risco

### Excluir projeto

Exclui permanentemente o projeto e todos os dados associados:

- Histórico de builds
- Dados de analytics
- Configuração do domínio personalizado

<Warning>
Essa ação não pode ser desfeita. Considere transferir a propriedade se os membros da equipe precisarem continuar tendo acesso.
</Warning>
