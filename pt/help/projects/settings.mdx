Configure o nome de exibição do projeto, o repositório conectado, o branch, as variáveis de ambiente, o domínio personalizado e as opções da zona de perigo na página Settings.

As capturas de tela mostram a interface em inglês.

## Acessar as configurações

1. Selecione seu projeto no painel
2. Clique em **Settings** na barra lateral

A página de configurações está dividida em seções de exibição, repositório, equipe, configuração e notificações.

## Configurações gerais

### Nome do projeto

O nome de exibição mostrado no seu painel. Isso não afeta sua documentação publicada.

### Subdomínio

Sua URL padrão em `*.jamdesk.app`. Para alterá-la:

1. Digite um novo subdomínio
2. Clique em **Save**
3. Aguarde a propagação do DNS (geralmente instantânea)

<Note>
Alterações de subdomínio não quebram links existentes. A URL antiga redireciona para a nova.
</Note>

## Configurações do repositório

### Repositório conectado

O repositório GitHub vinculado. Para trocar de repositório, é preciso excluir o projeto e criar um novo.

### Branch

O branch Git que dispara os builds. Normalmente `main` ou `master`.

### Caminho dos docs

Caminho até o seu `docs.json` em um monorepo (por exemplo, `packages/docs`).

Deixe vazio se o `docs.json` estiver na raiz do repositório.

## Configurações de build

### Variáveis de ambiente

Defina variáveis de tempo de build para a sua documentação:

1. Clique em **Add Variable**
2. Digite a chave e o valor
3. Clique em **Save**

As variáveis ficam disponíveis durante o build. Referencie-as na sua documentação.

### Rebuild

Clique em **Rebuild** para iniciar um build novo sem enviar nada ao GitHub. Use-o depois de alterar configurações.

## Domínio personalizado

Adicione seu próprio domínio na seção **Domains**. Consulte [Domínios personalizados](/pt/deploy/custom-domains) para as instruções de configuração.

## Zona de risco

### Excluir projeto

Exclui permanentemente o projeto e todos os dados associados:

- Histórico de builds
- Dados de análise
- Configuração de domínio personalizado

<Warning>
Esta ação não pode ser desfeita. Considere transferir a propriedade se membros da equipe precisarem continuar com acesso.
</Warning>
