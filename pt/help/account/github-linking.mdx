Vincule sua conta do GitHub para atribuir builds a você e acessar repositórios privados.

## Por que vincular o GitHub?

- Conecte repositórios privados ao Jamdesk
- Ative builds automáticos a cada push
- Acesse repositórios de organizações às quais você pertence

## Como vincular sua conta

<Steps>
  <Step title="Acesse Settings">
    Clique no seu avatar e selecione **Settings**.
  </Step>
  <Step title="Selecione Connections">
    Abra a aba **Connections**.
  </Step>
  <Step title="Clique em Connect GitHub">
    Selecione **Connect GitHub Account**.
  </Step>
  <Step title="Autorize o Jamdesk">
    Revise as permissões e clique em **Authorize** no GitHub.
  </Step>
</Steps>

## Permissões solicitadas

O Jamdesk solicita estas permissões:

| Permissão | Finalidade |
|------------|---------|
| Read repository contents | Acessar seus arquivos de documentação |
| Read repository metadata | Listar seus repositórios |
| Webhooks | Receber notificações de push para builds automáticos |

<Note>
O Jamdesk nunca grava nos seus repositórios. O acesso é somente leitura.
</Note>

## Como desvincular sua conta

1. Acesse **Settings** → **Connections**
2. Clique em **Disconnect** ao lado do GitHub
3. Confirme a desconexão

<Warning>
Desconectar o GitHub desativa os builds automáticos de todos os seus projetos. Conecte novamente para reativá-los.
</Warning>

## Repositórios de organizações

1. Acesse as configurações da organização no GitHub
2. Abra **Third-party access** → **OAuth Apps**
3. Encontre o Jamdesk e clique em **Grant** para conceder acesso

Não aparece a opção **Grant**? Peça a um administrador da organização para aprovar o Jamdesk.
