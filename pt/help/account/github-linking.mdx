Vincular sua conta do GitHub conecta sua identidade para atribuição de builds e permite acessar repositórios privados.

## Por que vincular o GitHub?

Vincular sua conta do GitHub permite:

- Conectar repositórios privados ao Jamdesk
- Habilitar builds automáticos após um push
- Acessar repositórios de organizações às quais você pertence

## Como vincular sua conta

<Steps>
  <Step title="Acesse Settings">
    Clique no seu avatar e selecione **Settings**.
  </Step>
  <Step title="Selecione Connections">
    Acesse a aba **Connections**.
  </Step>
  <Step title="Clique em Connect GitHub">
    Selecione **Connect GitHub Account**.
  </Step>
  <Step title="Autorize o Jamdesk">
    Revise as permissões e clique em **Authorize** no GitHub.
  </Step>
</Steps>

## Permissões solicitadas

O Jamdesk solicita permissões mínimas:

| Permissão | Finalidade |
|------------|---------|
| Ler conteúdo dos repositórios | Acessar seus arquivos de documentação |
| Ler metadados dos repositórios | Listar seus repositórios |
| Webhooks | Receber notificações de push para builds automáticos |

<Note>
O Jamdesk nunca grava nos seus repositórios. Todo o acesso é somente leitura.
</Note>

## Como desvincular sua conta

Para desconectar o GitHub:

1. Acesse **Settings** → **Connections**
2. Clique em **Disconnect** ao lado do GitHub
3. Confirme a desconexão

<Warning>
Desconectar o GitHub desabilitará os builds automáticos de todos os seus projetos. Você precisará reconectar para reabilitá-los.
</Warning>

## Repositórios de organizações

Para acessar repositórios de uma organização do GitHub:

1. Acesse as configurações da organização no GitHub
2. Acesse **Third-party access** → **OAuth Apps**
3. Encontre o Jamdesk e clique em **Grant** para conceder acesso

Se essa opção não estiver disponível, peça a um administrador da organização para aprovar o Jamdesk.
