## As 5 etapas

<Steps>
  <Step title="Iniciar avaliação">
    O Jamdesk inicia seu **teste gratuito de 14 dias** do plano Pro no primeiro login.

    - Todos os recursos estão ativados
    - O teste termina 14 dias após a ativação
  </Step>

  <Step title="Criar projeto">
    Dê um nome ao seu projeto de documentação:

    - Use um nome claro e descritivo (por exemplo, "Documentação da API", "Guia do usuário")
    - O nome se torna parte da URL do seu site de documentação
    - Você pode alterar o nome de exibição depois nas configurações do projeto
  </Step>

  <Step title="Conectar GitHub e criar documentação inicial">
    O Jamdesk cria um novo repositório no GitHub a partir do [Starter Template](https://github.com/jamdesk/starter-docs):

    - Páginas de exemplo com conteúdo e componentes realistas
    - `docs.json` pré-configurado com navegação e identidade visual
    - Exemplo de especificação OpenAPI para documentação de referência de API
    - Pronto para editar e enviar
  </Step>

  <Step title="Instalar a CLI">
    Instale a CLI do Jamdesk para desenvolvimento local:

    ```bash
    npm install -g jamdesk
    ```

    <Note>
    Esta etapa é opcional. Instale a CLI a qualquer momento ou edite a documentação diretamente no GitHub.
    </Note>
  </Step>

  <Step title="Começar a editar">
    Edite sua documentação:

    - **Via CLI**: edite os arquivos localmente com `jamdesk dev`
    - **Via GitHub**: edite os arquivos `.mdx` diretamente no seu repositório
    - **No Jamdesk**: alguns recursos do painel estão disponíveis (dependendo do plano)

    Cada envio para o GitHub dispara um novo build.
  </Step>
</Steps>

## Solução de problemas

### Ignorei uma etapa. Posso voltar?
Sim. Você pode concluir a integração a qualquer momento pelo cartão de integração no painel do seu projeto.

### Escolhi o repositório do GitHub errado
Crie um novo projeto com o repositório correto. Você pode excluir o antigo a qualquer momento.

### Preciso de ajuda durante o onboarding
Entre em contato com o [suporte](/pt/help/support/contact).
