Crie sua conta Jamdesk usando e-mail, Google OAuth ou GitHub OAuth.

## Opções de cadastro

O Jamdesk é compatível com três métodos de autenticação:

### E-mail e senha

1. Acesse [dashboard.jamdesk.com](https://dashboard.jamdesk.com)
2. Clique em **Sign Up**
3. Insira seu endereço de e-mail
4. Crie uma senha segura
5. Verifique seu e-mail para encontrar um link de confirmação
6. Clique no link de confirmação para confirmar sua conta

### Google OAuth

1. Acesse [dashboard.jamdesk.com](https://dashboard.jamdesk.com)
2. Clique em **Sign Up**
3. Selecione **Continue with Google**
4. Autorize o Jamdesk a acessar sua conta do Google
5. Você será verificado e conectado automaticamente

### GitHub OAuth

1. Acesse [dashboard.jamdesk.com](https://dashboard.jamdesk.com)
2. Clique em **Sign Up**
3. Selecione **Continue with GitHub**
4. Autorize o Jamdesk a acessar sua conta do GitHub
5. Você será verificado e conectado automaticamente

<Note>
Seu login do GitHub conecta sua identidade ao Jamdesk. Isso é separado da conexão de um repositório do GitHub ao seu projeto de documentação. Você fará isso durante a configuração do projeto.
</Note>

## O que acontece após o cadastro

Após criar sua conta, você:

- Iniciará um teste gratuito de 14 dias do plano Pro
- Será direcionado a criar seu primeiro projeto de documentação
- Terá acesso ao passo a passo completo de integração inicial

## Verificação de e-mail

Se você não receber um e-mail de confirmação:

1. Verifique sua pasta de spam
2. Aguarde alguns minutos e tente se cadastrar novamente
3. [Entre em contato com o suporte](/pt/help/support/contact) se o problema persistir
