## Layout principal

### Barra lateral (esquerda)

A barra lateral à esquerda dá acesso às páginas do projeto atual:

- **Project Home** - Visão geral e status do build
- **Analytics** - Visualizações de página, visitantes, dados geográficos e métricas de busca
- **Settings** - Configuração do projeto, membros da equipe e integrações
- **User Settings** - Preferências da conta e perfil

No topo da barra lateral:
- **Project Selector** - Alterne entre seus projetos
- **Theme Toggle** - Alterne o tema de cores

### Navegação superior

A área superior mostra o projeto selecionado:
- O **nome do projeto ativo** com um indicador
- Links rápidos para seções importantes

### Área de conteúdo principal

A área principal mostra a página selecionada na barra lateral:
- Visão geral do projeto e atividade recente
- Painéis de análise
- Painéis de configurações
- Membros da equipe

## Project Home

A página Project Home é aberta quando você faz login pela primeira vez:

- **Recent Builds** - Mostra o status da implantação mais recente
- **Project Status** - Status da conexão e última atualização
- **Onboarding Card** - Continue a configuração se ela estiver incompleta (somente na primeira vez)
- **Quick Actions** - Links para tarefas comuns

## Encontrar sua documentação

O URL da documentação publicada aparece em **Project Settings** > **Display Settings**:

- Os projetos usam o formato: `https://<project-id>.jamdesk.app`
- [Domínios personalizados](/pt/deploy/custom-domains) podem substituir o URL padrão
- Cada build implanta sua documentação

## Membros da equipe

Em **Settings** > **Members**, você pode:
- Ver os membros da equipe que têm acesso a este projeto
- Convidar novos colaboradores
- Alterar as permissões dos membros
- Remover membros

## Configurações do projeto

Principais configurações em **Settings** > **Project**:

- **Display Name** - O nome exibido no site da documentação
- **Project ID** - Identificador usado no URL da documentação
- **Connected Repository** - Repositório do GitHub que contém sua documentação
- **Powered by Jamdesk Badge** - Mostrar ou ocultar a marca (obrigatório nos planos gratuitos)

## Acessar a Central de ajuda

1. Clique no avatar do usuário na barra lateral
2. Procure um link **Help** ou **Documentation**
3. Ou acesse esta página diretamente

## Atalhos de teclado

- **`k`** - Abra o seletor de projetos (ou use o seletor no topo da barra lateral)
- **`?`** - Veja todos os atalhos de teclado
- **`cmd/ctrl + m`** - Alterne o tema (claro/escuro)

## Solução de problemas

### Não encontro um projeto

O projeto não aparece no seletor de projetos? Faça estas verificações:
- Confirme se você foi convidado como membro da equipe
- Verifique se o projeto não foi excluído
- [Entre em contato com o suporte](/pt/help/support/contact) se você acredita que deveria ter acesso

### As configurações parecem diferentes

Os layouts do dashboard variam de acordo com o plano de assinatura. Consulte [Planos e preços](/pt/help/billing/plans) para ver os recursos específicos de cada plano.
