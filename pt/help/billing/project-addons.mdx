Os complementos de projetos permitem expandir o número de projetos de documentação incluídos no seu plano.

## Como funcionam os complementos

Os planos Pro incluem 3 projetos. Cada projeto adicional custa US$ 15/mês.

## Adicionar projetos

<Steps>
  <Step title="Ir para Billing">
    Navegue até **Settings** → **Billing**.
  </Step>
  <Step title="Clicar em Add Projects">
    Selecione **Add project slots**.
  </Step>
  <Step title="Escolher a quantidade">
    Selecione quantos projetos adicionais você precisa.
  </Step>
  <Step title="Confirm">
    Revise o total atualizado e confirme.
  </Step>
</Steps>

Os complementos têm cobrança proporcional: você paga apenas pelos dias restantes do seu ciclo de cobrança.

## Remover projetos

Para reduzir o número de projetos:

1. Exclua projetos até atingir a quantidade desejada
2. Acesse **Settings** → **Billing**
3. Clique em **Manage add-ons**
4. Reduza o número de vagas adicionais
5. Confirme a alteração

<Warning>
Você não pode reduzir para menos do que o número de projetos ativos. Exclua os projetos primeiro.
</Warning>

## Cobrança dos complementos

- Os complementos aparecem como um item separado nas faturas
- Aplicam-se cobranças proporcionais ao adicionar projetos no meio do ciclo
- Aplicam-se créditos ao remover projetos no meio do ciclo

## Descontos por volume

Para 10 ou mais projetos, entre em contato conosco para obter preços por volume.
