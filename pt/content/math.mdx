O Jamdesk oferece suporte a LaTeX para renderizar expressões e equações matemáticas usando [KaTeX](https://katex.org/).

<Note>
O suporte a matemática requer `styling.latex: true` no arquivo `docs.json`.
</Note>

## Ativar suporte a matemática

Adicione ao seu `docs.json`:

```json docs.json
{
  "styling": {
    "latex": true
  }
}
```

## Matemática inline

Use cifrões simples para equações inline:

```md
The Pythagorean theorem states that $a^2 + b^2 = c^2$.
```

**Renderiza como:** O teorema de Pitágoras afirma que $a^2 + b^2 = c^2$.

## Equações em bloco

Use cifrões duplos para equações centralizadas em estilo de exibição:

```md
$$
E = mc^2
$$
```

**Renderiza como:**

$$
E = mc^2
$$

## Equações complexas

O KaTeX oferece suporte a uma ampla variedade de notações LaTeX:

### Frações

```md
$$
\frac{n!}{k!(n-k)!} = \binom{n}{k}
$$
```

### Integrais

```md
$$
\int_0^\infty e^{-x^2} dx = \frac{\sqrt{\pi}}{2}
$$
```

### Somatórios

```md
$$
\sum_{i=1}^{n} i = \frac{n(n+1)}{2}
$$
```

### Matrizes

```md
$$
\begin{bmatrix}
a & b \\
c & d
\end{bmatrix}
$$
```

## Usar o componente Latex

Para ter mais controle, use o componente `<Latex>` diretamente:

```mdx
<Latex>E = mc^2</Latex>
```

Para o modo bloco/exibição:

```mdx
<Latex block>
\int_0^\infty e^{-x^2} dx = \frac{\sqrt{\pi}}{2}
</Latex>
```

## Blocos de código são protegidos

Os cifrões dentro de blocos de código **não** são tratados como matemática:

```bash
echo $HOME
export PRICE=$100
```

Isso é renderizado como código normal, não como equações.

## Comandos compatíveis

O KaTeX oferece suporte à maioria dos comandos matemáticos comuns do LaTeX. Consulte a [documentação do KaTeX](https://katex.org/docs/supported.html) para ver uma lista completa das funções compatíveis.

<Tip>
Para equações complexas, teste seu LaTeX primeiro na [página de demonstração do KaTeX](https://katex.org/).
</Tip>
