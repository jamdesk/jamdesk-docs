O Jamdesk renderiza fórmulas LaTeX com o [KaTeX](https://katex.org/).

<Note>
O suporte a matemática requer `styling.latex: true` no seu arquivo `docs.json`.
</Note>

## Ativar suporte a matemática

Adicione ao seu `docs.json`:

```json docs.json
{
  "styling": {
    "latex": true
  }
}
```

## Matemática inline

Use cifrões simples para equações em linha:

```md
The Pythagorean theorem states that $a^2 + b^2 = c^2$.
```

**Renderiza como:** The Pythagorean theorem states that $a^2 + b^2 = c^2$.

## Equações em bloco

Use cifrões duplos para equações centralizadas, em estilo de exibição:

```md
$$
E = mc^2
$$
```

**Renderiza como:**

$$
E = mc^2
$$

## Equações complexas

O KaTeX renderiza uma ampla gama de notações LaTeX:

### Frações

```md
$$
\frac{n!}{k!(n-k)!} = \binom{n}{k}
$$
```

### Integrais

```md
$$
\int_0^\infty e^{-x^2} dx = \frac{\sqrt{\pi}}{2}
$$
```

### Somatórios

```md
$$
\sum_{i=1}^{n} i = \frac{n(n+1)}{2}
$$
```

### Matrizes

```md
$$
\begin{bmatrix}
a & b \\
c & d
\end{bmatrix}
$$
```

## Usar o componente Latex

Use o componente `<Latex>` diretamente para mais controle:

```mdx
<Latex>E = mc^2</Latex>
```

Para o modo de bloco/exibição:

```mdx
<Latex block>
\int_0^\infty e^{-x^2} dx = \frac{\sqrt{\pi}}{2}
</Latex>
```

## Blocos de código são protegidos

Cifrões dentro de blocos de código **não** são tratados como matemática:

```bash
echo $HOME
export PRICE=$100
```

## Comandos compatíveis

O KaTeX cobre a maioria dos comandos matemáticos comuns do LaTeX. A [documentação do KaTeX](https://katex.org/docs/supported.html) lista todas as funções suportadas.

<Tip>
Teste equações complexas na [página de demonstração do KaTeX](https://katex.org/) primeiro.
</Tip>
