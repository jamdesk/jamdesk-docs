Cada página do Jamdesk é um arquivo `.mdx`: Markdown padrão com componentes JSX como `<Card>`, `<Tabs>` e `<Accordion>`.

## O que é MDX?

O MDX permite escrever Markdown padrão e incorporar componentes JSX no mesmo arquivo. Escreva títulos, listas e blocos de código em Markdown e, onde precisar de interatividade, insira componentes como `<Card>` ou `<Tabs>`.

MDX é texto simples que ferramentas de IA conseguem ler e escrever nativamente. Pode ser versionado no Git. Comporta componentes sem um formato proprietário.

```mdx
# Welcome to My Docs

This is regular **Markdown** with a component below:

<Card title="Quickstart" icon="rocket" href="/quickstart">
  Jump right in with our quickstart guide.
</Card>
```

<Tip>
  O [Validador MDX](https://jamdesk.com/utilities/mdx-validator) gratuito detecta erros de sintaxe antes de um build.
  O [Formatador MDX](https://jamdesk.com/utilities/mdx-formatter) gratuito corrige espaçamento e indentação.
  Cole uma página para verificá-la ou organizá-la sem executar a CLI.
</Tip>

## Estrutura da página

Toda página MDX começa com o frontmatter, os metadados entre triplos traços:

```mdx
---
title: My Page Title
description: A brief description for search and previews
---

Your content starts here...
```

<Note>
O `title` e a `description` aparecem nos resultados de busca, nas abas do navegador e nas prévias em redes sociais.
</Note>

## Fundamentos do Markdown

### Títulos

Use `##` para seções principais e `###` para subseções. O Jamdesk cria o sumário a partir dos seus títulos.

```markdown
## Main Section
Content under the main section.

### Subsection
More detailed content here.
```

<Tip>
Comece com `##` (h2) para o seu primeiro título. O título da página definido no frontmatter é o h1.
</Tip>

### Formatação de texto

| Sintaxe | Resultado |
|--------|--------|
| `**bold**` | **bold** |
| `*italic*` | *italic* |
| `~~strikethrough~~` | ~~strikethrough~~ |
| `` `inline code` `` | `inline code` |

### Listas

```markdown
Unordered list:
- First item
- Second item
  - Nested item

Ordered list:
1. First step
2. Second step
3. Third step
```

### Citações em bloco

```markdown
> This is a blockquote. Use it for callouts or
> highlighting important information.
```

> This is a blockquote. Use it for callouts or highlighting important information.

## Adicionando componentes

Componentes são elementos JSX que você pode usar em qualquer lugar do seu MDX. Eles podem ser autofechados ou envolver conteúdo:

```mdx
{/* Self-closing component */}
<Card title="Example" icon="star" href="/introduction" />

{/* Component wrapping content */}
<Accordion title="Click to expand">
  This content is inside the accordion.
</Accordion>
```

## Tabelas

Tabelas Markdown padrão funcionam sem configuração:

```markdown
| Feature | Starter | Team |
|---------|------|-----|
| Pages | 10 | Unlimited |
| Custom domain | No | Yes |
```

| Feature | Starter | Team |
|---------|------|-----|
| Pages | 10 | Unlimited |
| Custom domain | No | Yes |

Use o componente Table para destacar linhas, alinhar células e mesclar colunas:

<Table striped>
  <Row header>
    <Cell>Feature</Cell>
    <Cell align="center">Starter</Cell>
    <Cell align="center">Team</Cell>
  </Row>
  <Row>
    <Cell>Pages</Cell>
    <Cell align="center">10</Cell>
    <Cell align="center" highlight highlightColor="success">Unlimited</Cell>
  </Row>
  <Row>
    <Cell>Custom domain</Cell>
    <Cell align="center">No</Cell>
    <Cell align="center" highlight highlightColor="success">Yes</Cell>
  </Row>
</Table>

<Note>
Consulte [Tabelas](/pt/components/tables) para a documentação completa do componente, incluindo destaque de linhas e células, mesclagem de colunas e opções de estilo.
</Note>

## Comentários

Adicione comentários que não aparecerão na saída renderizada:

```mdx
{/* This is a comment - it won't be visible to readers */}
```
