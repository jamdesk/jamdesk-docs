Toda página do Jamdesk é um arquivo `.mdx`: Markdown padrão com componentes JSX como `<Card>`, `<Tabs>` e `<Accordion>`.

## O que é MDX?

O MDX permite escrever Markdown padrão e incorporar componentes JSX no mesmo arquivo. Escreva títulos, listas e blocos de código em Markdown e, em seguida, adicione componentes como `<Card>` ou `<Tabs>` onde precisar de interatividade.

O MDX também funciona bem para documentações que ferramentas de IA precisam ler: é texto simples (para que elas possam ler e escrever nele nativamente), pode ser versionado no Git e tem estrutura suficiente para componentes, sem exigir um formato proprietário.

```mdx
# Welcome to My Docs

This is regular **Markdown** with a component below:

<Card title="Quickstart" icon="rocket" href="/quickstart">
  Jump right in with our quickstart guide.
</Card>
```

<Tip>
  Duas ferramentas gratuitas para navegador ajudam durante a escrita: o [MDX Validator](https://jamdesk.com/utilities/mdx-validator)
  detecta erros de sintaxe antes do build, e o [MDX Formatter](https://jamdesk.com/utilities/mdx-formatter)
  ajusta espaçamento e recuo. Cole uma página para verificá-la ou organizá-la sem executar a CLI.
</Tip>

## Estrutura da página

Toda página MDX começa com frontmatter: metadados entre três traços:

```mdx
---
title: My Page Title
description: A brief description for search and previews
---

Your content starts here...
```

<Note>
O `title` e a `description` aparecem nos resultados de busca, nas abas do navegador e nas prévias de redes sociais. Escreva-os com cuidado.
</Note>

## Fundamentos do Markdown

### Títulos

Use `##` para seções principais e `###` para subseções. O Jamdesk gera automaticamente um sumário com base nos seus títulos.

```markdown
## Main Section
Content under the main section.

### Subsection
More detailed content here.
```

<Tip>
Comece com `##` (h2) no primeiro título. O título da página definido no frontmatter funciona como h1.
</Tip>

### Formatação de texto

| Sintaxe | Resultado |
|--------|--------|
| `**bold**` | **negrito** |
| `*italic*` | *itálico* |
| `~~strikethrough~~` | ~~tachado~~ |
| `` `inline code` `` | `código em linha` |

### Listas

```markdown
Unordered list:
- First item
- Second item
  - Nested item

Ordered list:
1. First step
2. Second step
3. Third step
```

### Citações em bloco

```markdown
> This is a blockquote. Use it for callouts or
> highlighting important information.
```

> Isto é uma citação em bloco. Use-a para destaques ou para realçar informações importantes.

## Adicionando componentes

Os componentes são elementos JSX que você pode usar em qualquer parte do MDX. Eles podem ser autônomos ou envolver conteúdo:

```mdx
{/* Self-closing component */}
<Card title="Example" icon="star" href="/introduction" />

{/* Component wrapping content */}
<Accordion title="Click to expand">
  This content is inside the accordion.
</Accordion>
```

## Tabelas

As tabelas padrão do Markdown funcionam diretamente:

```markdown
| Feature | Starter | Team |
|---------|------|-----|
| Pages | 10 | Unlimited |
| Custom domain | No | Yes |
```

| Recurso | Starter | Team |
|---------|------|-----|
| Páginas | 10 | Ilimitado |
| Domínio personalizado | Não | Sim |

Para recursos avançados, como destaque de linhas, alinhamento de células e mesclagem, use o componente Table:

<Table striped>
  <Row header>
    <Cell>Recurso</Cell>
    <Cell align="center">Starter</Cell>
    <Cell align="center">Team</Cell>
  </Row>
  <Row>
    <Cell>Páginas</Cell>
    <Cell align="center">10</Cell>
    <Cell align="center" highlight highlightColor="success">Ilimitado</Cell>
  </Row>
  <Row>
    <Cell>Domínio personalizado</Cell>
    <Cell align="center">Não</Cell>
    <Cell align="center" highlight highlightColor="success">Sim</Cell>
  </Row>
</Table>

<Note>
Consulte [Tabelas](/pt/components/tables) para ver a documentação completa do componente, incluindo opções de destaque de linhas e células, mesclagem de colunas e estilos.
</Note>

## Comentários

Adicione comentários que não aparecerão no conteúdo renderizado:

```mdx
{/* This is a comment - it won't be visible to readers */}
```
