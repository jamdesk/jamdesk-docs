Cada `<iframe>` na sua documentação recebe cantos arredondados, uma borda de moldura e um espaçamento que combina com o restante da página. Você não precisa de divs de encapsulamento nem de classes utilitárias.

## Estilização automática

O Jamdesk aplica esta moldura a todo iframe no momento da renderização:

| Propriedade | Valor | Descrição |
|----------|-------|-------------|
| Raio da borda | `0.5rem` | Cantos arredondados no conteúdo |
| Largura da moldura | `8px` | Espaçamento visual ao redor do conteúdo |
| Borda | `1px` | Borda discreta na cor do tema |
| Espaçamento | `1rem + 9px` | Margem acima e abaixo |

A cor da moldura vem de `--color-bg-secondary`. A linha da borda usa `--color-border`. Essas propriedades personalizadas de CSS seguem o seu tema, incluindo o modo escuro.

## Incorporando conteúdo externo

Uma incorporação básica usa uma tag iframe HTML padrão:

```html
<iframe
  src="https://example.com/embed"
  width="100%"
  height="400"
  title="Description of embedded content"
/>
```

Inclua sempre um atributo `title`. Leitores de tela o anunciam. Ele também informa a qualquer pessoa que leia o código-fonte da página o que a incorporação contém.

## Dimensionamento responsivo

A maioria dos provedores de incorporação retorna conteúdo com proporção fixa. O utilitário `aspect-video` do Tailwind mantém o iframe em 16:9, independentemente da largura da janela. `w-full` o estica para preencher o contêiner pai:

```html
<iframe
  className="w-full aspect-video"
  src="https://example.com/embed"
  title="16:9 responsive embed"
/>
```

`w-full` define `width: 100%` via Tailwind. Sem ele, o iframe assume a largura padrão do navegador (geralmente 300px). Isso fica com aparência quebrada em telas largas.

Use a sintaxe de proporção arbitrária do Tailwind para conteúdos que não sejam 16:9, como um protótipo do Figma ou um painel:

```html
<iframe
  className="w-full aspect-[4/3]"
  src="https://example.com/embed"
  title="4:3 responsive embed"
/>
```

Substitua `4/3` pela proporção que melhor se adapta ao conteúdo. `aspect-[1/1]` para incorporações quadradas, `aspect-[21/9]` para ultrawide, e assim por diante.

## Vimeo

Incorpore um vídeo do Vimeo com um iframe padrão apontando para a URL do player:

```html
<iframe
  className="w-full aspect-video rounded-xl"
  src="https://player.vimeo.com/video/VIDEO_ID"
  title="Vimeo video player"
  allow="autoplay; fullscreen; picture-in-picture"
  allowFullScreen
/>
```

Troque `VIDEO_ID` pelo ID numérico de qualquer URL do Vimeo (o número após `vimeo.com/`). O atributo `allow` concede ao player incorporado as permissões de tela cheia e picture-in-picture.

<Tip>
Use o [componente `<YouTube>`](/pt/content/youtube) dedicado para vídeos do YouTube, em vez de um iframe bruto. Ele faz carregamento lento do player e remove as sugestões de vídeos relacionados.
</Tip>

## Incorporações comuns

<AccordionGroup>
  <Accordion title="CodePen" icon="codepen">
    Copie a URL de incorporação no botão "Embed" do CodePen. O parâmetro `default-tab` controla qual painel aparece primeiro (`result`, `html`, `css` ou `js`).

    ```html
    <iframe
      height="400"
      style={{width: '100%'}}
      src="https://codepen.io/USERNAME/embed/PEN_ID?default-tab=result"
      title="CodePen Embed"
      allowFullScreen
    />
    ```
  </Accordion>

  <Accordion title="CodeSandbox" icon="cube">
    As incorporações do CodeSandbox aceitam parâmetros de consulta para tamanho da fonte, tema e qual arquivo exibir. O atributo `sandbox` controla o que o iframe pode fazer. O CodeSandbox precisa de várias permissões para executar código no navegador.

    ```html
    <iframe
      src="https://codesandbox.io/embed/SANDBOX_ID?fontsize=14&theme=dark"
      style={{width: '100%', height: '500px', border: 0, borderRadius: '4px', overflow: 'hidden'}}
      title="CodeSandbox"
      allow="accelerometer; ambient-light-sensor; camera; encrypted-media; geolocation; gyroscope; hid; microphone; midi; payment; usb; vr; xr-spatial-tracking"
      sandbox="allow-forms allow-modals allow-popups allow-presentation allow-same-origin allow-scripts"
    />
    ```
  </Accordion>

  <Accordion title="Figma" icon="figma">
    Abra um arquivo do Figma, clique em **Share** e depois em **Get embed code**. A URL vai no atributo `src`. Faça as incorporações do Figma com `450px` de altura ou mais. Alturas menores cortam a barra de ferramentas.

    ```html
    <iframe
      style={{border: '1px solid rgba(0, 0, 0, 0.1)'}}
      width="100%"
      height="450"
      src="https://www.figma.com/embed?embed_host=share&url=FIGMA_URL"
      allowFullScreen
    />
    ```
  </Accordion>

  <Accordion title="Loom" icon="video">
    Copie o ID do vídeo de qualquer link de compartilhamento do Loom (a string após `loom.com/share/`). As incorporações do Loom iniciam automaticamente ao passar o cursor por padrão.

    ```html
    <iframe
      src="https://www.loom.com/embed/VIDEO_ID"
      width="100%"
      height="400"
      allowFullScreen
    />
    ```
  </Accordion>
</AccordionGroup>
