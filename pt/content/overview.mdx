As páginas do Jamdesk são arquivos MDX: Markdown padrão com componentes React disponíveis sempre que você precisar deles. Uma página é apenas frontmatter e conteúdo.

```mdx
---
title: Rate Limits
description: How rate limiting works across API tiers.
---

Requests are limited per API key.

<Note>Enterprise plans have custom limits.</Note>
```

A maior parte do que você escreverá será Markdown simples. As páginas desta seção abordam o restante: blocos de código com destaque de sintaxe, imagens e vídeos, notação matemática, snippets reutilizáveis e os campos de frontmatter que controlam títulos, ícones e metadados de SEO.
