Todo site Jamdesk inclui um assistente de chat que responde às perguntas dos visitantes com base na sua documentação. Ele localiza seções relevantes, envia-as ao Claude e transmite uma resposta com links para as páginas de origem. O chat vem ativado por padrão em todos os planos, sem custo adicional.

## Casos de uso

<Tabs>
  <Tab title="Integração de API">
    Um desenvolvedor que está integrando sua API pergunta *"Como autentico as solicitações?"* e recebe as etapas exatas com um exemplo de código, além de um link para a página de origem.
  </Tab>
  <Tab title="Solução de problemas">
    *"Meu build está falhando com um erro de timeout"*

    Em vez de consultar várias páginas, o visitante encontra em segundos a solução relevante no seu guia de solução de problemas.
  </Tab>
  <Tab title="Referência rápida">
    Usuários que retornam fazem perguntas como *"Quais parâmetros o endpoint /users aceita?"* e o chat busca a documentação do endpoint e retorna diretamente a tabela de parâmetros.
  </Tab>
</Tabs>

## Como funciona

<Steps>
  <Step title="O build indexa sua documentação">
    Durante cada build, o Jamdesk divide suas páginas em seções e as armazena como embeddings pesquisáveis.
  </Step>
  <Step title="O visitante faz uma pergunta">
    O botão "Ask AI" (ou Cmd+I / Ctrl+I) abre um painel de chat em qualquer página.
  </Step>
  <Step title="A IA responde com base na sua documentação">
    As seções relevantes são localizadas, enviadas ao Claude como contexto, e a resposta é transmitida com links de citação para as páginas de origem.
  </Step>
</Steps>

## Recursos

| Recurso | Detalhe |
|---------|--------|
| Respostas em streaming | As respostas chegam em tempo real |
| Links de citação | Cada resposta inclui links para as páginas da documentação usadas como fonte |
| Desambiguação | Quando uma pergunta corresponde a vários tópicos, a IA pergunta a qual deles o visitante se refere |
| Contexto da conversa | Histórico de 10 mensagens, mantido por aba do navegador |
| Perguntas sugeridas | Geradas automaticamente a partir da sua documentação ou definidas por você em docs.json |
| Atalhos de teclado | Cmd+I / Ctrl+I para alternar, Escape para fechar |
| Renderização de Markdown | Blocos de código, tabelas e listas são renderizados nas respostas |

## Configuração

O chat funciona sem precisar de configuração. Adicione um bloco `chat` ao seu `docs.json` somente se quiser personalizar as perguntas sugeridas, renomear o botão, alterar o ícone ou desativar o chat. O campo `chat` é opcional, e todas as configurações têm um valor padrão.

```json docs.json
{
  "chat": {
    "enabled": true,
    "starterQuestions": [
      "How do I get started?",
      "What API endpoints are available?"
    ]
  }
}
```

| Campo | Tipo | Padrão | Descrição |
|-------|------|---------|-------------|
| `enabled` | boolean | `true` | Defina como `false` para remover do seu site o botão Ask AI, o painel de chat e o atalho de teclado |
| `starterQuestions` | string[] | auto-generated | Até 4 perguntas exibidas quando o painel é aberto (de 5 a 200 caracteres cada). Geradas automaticamente a partir da sua documentação quando omitidas; defina como `[]` para não exibir nenhuma |
| `label` | string | "Ask AI" no idioma da página | Substitui "Ask AI" no botão de chat, no cabeçalho do painel e no atalho de busca. Até 40 caracteres. Aplica-se a todos os idiomas. |
| `icon` | string | `sparkles` | Um nome de ícone do Font Awesome, uma URL de imagem ou um caminho para uma imagem no seu projeto. Um ícone do Font Awesome segue a cor de destaque; uma imagem é exibida como está, então escolha uma que funcione em fundos claros e escuros. |

### Perguntas sugeridas

Perguntas sugeridas são prompts recomendados exibidos no painel de chat antes de o visitante digitar qualquer coisa: exemplos acessíveis com um clique que dão ideias do que perguntar. Quando você não inclui `starterQuestions` no seu `docs.json`, o Jamdesk as gera automaticamente a partir da sua documentação a cada build, para que continuem relevantes à medida que ela cresce.

Para definir suas próprias perguntas, liste-as no array `starterQuestions`. Isso é útil quando sua equipe de suporte recebe as mesmas perguntas repetidamente e você quer destacá-las primeiro:

```json docs.json
{
  "chat": {
    "starterQuestions": [
      "How do notifications work?",
      "Tell me more about analytics"
    ]
  }
}
```

Você pode definir até 4 perguntas sugeridas, cada uma com 5 a 200 caracteres. Para não exibir nenhuma pergunta sugerida, defina `starterQuestions` como um array vazio (`[]`).

### Nome e ícone personalizados

Por padrão, o botão de chat, o cabeçalho do painel e o atalho de busca exibem "Ask AI" e usam um ícone de brilhos. Defina `label` e `icon` para combinar com seu produto:

```json docs.json
{
  "chat": {
    "label": "Acme Assistant",
    "icon": "/images/assistant.svg"
  }
}
```

O rótulo é o mesmo em todos os idiomas do seu site. Um valor de `icon` como `robot` é um nome do Font Awesome. Um valor que começa com `http://`, `https://` ou `/`, ou termina com uma extensão de imagem, é tratado como imagem.

### Desativar o chat

O chat vem ativado por padrão em todos os planos. Para desativá-lo, defina `enabled` como `false`. Isso remove o botão Ask AI, o painel de chat e o atalho `Cmd+I` / `Ctrl+I`:

```json docs.json
{
  "chat": {
    "enabled": false
  }
}
```

<Note>
Desativar o chat não afeta a busca. O chat com IA e a busca são recursos separados, então sua documentação continua totalmente pesquisável mesmo com o chat desativado.
</Note>

## Limites

| Limite | Valor |
|-------|-------|
| Tamanho máximo da mensagem | 2,000 caracteres |
| Tamanho máximo da resposta | 2,048 tokens |
| Limite de solicitações | 10 solicitações / 60 segundos por visitante e por site |
| Histórico da conversa | 10 mensagens por aba |
| Perguntas sugeridas | Máximo de 4 |

O chat funciona em [domínios personalizados](/pt/deploy/custom-domains). O endpoint `/_chat` é da mesma origem, então funciona em qualquer domínio que disponibilize sua documentação.

<Accordion title="Como funciona o pipeline de recuperação">
  Durante cada build, o Jamdesk divide suas páginas em seções e armazena embeddings vetoriais para cada uma. Quando um visitante faz uma pergunta, o sistema executa uma busca híbrida (combinação de correspondência por palavra-chave e similaridade semântica) para localizar as seções mais relevantes na sua documentação. Essas seções são enviadas ao Claude como contexto, com instruções para responder somente com base na documentação fornecida. As citações são extraídas comparando as referências a páginas na resposta do Claude com as seções recuperadas.
</Accordion>
