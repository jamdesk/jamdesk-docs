Se você quer que ferramentas de IA como ChatGPT, Claude ou Copilot forneçam respostas precisas sobre seu produto, elas precisam de acesso estruturado à sua documentação, não apenas do conteúdo incluído nos dados de treinamento.

Todos os sites Jamdesk geram `llms.txt` e `llms-full.txt` de acordo com a especificação [llmstxt.org](https://llmstxt.org). As ferramentas de IA leem esses arquivos em vez de rastrear páginas individuais.

<Note>
  O Google agora audita `llms.txt` como parte das [verificações de navegação agentic do Lighthouse](https://developer.chrome.com/docs/lighthouse/agentic-browsing/llms-txt). Sites que publicam um `llms.txt` válido são mais facilmente descobertos por agentes de IA e, cada vez mais, pelo próprio Google ao classificar conteúdo para respostas baseadas em IA. O Jamdesk oferece isso gratuitamente.
</Note>

<Tip>
  **Verifique sua pontuação.** Veja o quanto qualquer site de documentação está pronto para agentes com a ferramenta gratuita [AI Score](https://jamdesk.com/ai-score). A publicação de um `llms.txt` válido é uma das primeiras verificações realizadas. Também há uma [extensão AI Score para Chrome](https://chromewebstore.google.com/detail/jamdesk-ai-score/mhihkkgpcbmapmojnakhjfhjmiagkhlj) para avaliar sites enquanto você navega.
</Tip>

## O que o Jamdesk gera

| Arquivo | Conteúdo |
|------|---------|
| `llms.txt` | Títulos, descrições e URLs das páginas (um índice estruturado) |
| `llms-full.txt` | Conteúdo completo da documentação em um único arquivo |

O Jamdesk gera ambos durante o build e os disponibiliza pelo mesmo CDN da sua documentação.

## Verifique seus arquivos

Confira se os arquivos existem após o primeiro build:

<Tabs>
  <Tab title="Domínio raiz">
    Se sua documentação estiver na raiz do domínio (por exemplo, `docs.acme.com` ou `acme.jamdesk.app`):

    ```bash
    curl https://docs.acme.com/llms.txt
    curl https://docs.acme.com/llms-full.txt
    ```
  </Tab>
  <Tab title="Subcaminho /docs">
    Se sua documentação estiver em `/docs` no site principal (como neste site, em `jamdesk.com/docs`):

    ```bash
    curl https://jamdesk.com/docs/llms.txt
    curl https://jamdesk.com/docs/llms-full.txt
    ```
  </Tab>
</Tabs>

## Formato do arquivo

O arquivo `llms.txt` lista cada página com seu título, descrição e URL, agrupados em seções que refletem sua navegação:

```text
# Your Project Documentation

> Documentation for Your Project

## Get Started

- [Getting Started](https://your-project.jamdesk.app/getting-started): Set up your first project in 5 minutes
- [Configuration](https://your-project.jamdesk.app/configuration): Configure your project settings

## API Reference

- [Authentication](https://your-project.jamdesk.app/authentication): How to authenticate API requests
```

O arquivo `llms-full.txt` contém o conteúdo Markdown completo de cada página, concatenado com limites entre páginas marcados por títulos.

## Estrutura

`llms.txt` segue a proposta do [llmstxt.org](https://llmstxt.org/): um título H1,
um resumo em blockquote e suas abas e grupos de navegação como seções `##` de
links Markdown.

## Sites multilíngues

Sites com mais de um idioma recebem um conjunto separado de arquivos para cada
idioma, para que uma ferramenta de IA possa buscar apenas o idioma necessário. Para um site em inglês (o padrão) e francês:

| URL | Conteúdo |
|-----|---------|
| `/llms.txt` | Índice em inglês, com links para o índice de cada outro idioma ao final |
| `/fr/llms.txt` | Índice em francês, com links de volta para os outros idiomas |
| `/llms-full.txt` | Conteúdo completo de todos os idiomas, um após o outro |
| `/en/llms-full.txt` | Apenas o conteúdo das páginas em inglês |
| `/fr/llms-full.txt` | Apenas o conteúdo das páginas em francês |

O `llms-full.txt` raiz mantém todos os idiomas, portanto as ferramentas que já o
leem não percebem nenhuma mudança. Aponte um agente para o arquivo do próprio
idioma quando ele precisar apenas desse idioma:

```bash
curl https://jamdesk.com/docs/fr/llms-full.txt
```

Um idioma recebe seus próprios arquivos assim que tiver pelo menos uma página. Sites com um único idioma mantêm apenas os arquivos raiz.

## Diretiva para agentes em cada página

Cada página também contém uma observação invisível e silenciosa para leitores de tela, direcionada aos agentes de IA e apontando para `llms.txt`, e toda exportação Markdown começa com um link em blockquote para o índice. Os agentes que acessarem seu HTML encontrarão o caminho Markdown sem rastrear o site.

## Como isso é criado

- Gerado durante o build junto com seu HTML
- Disponibilizado por CDN com a mesma política de cache da sua documentação
- Atualizado automaticamente a cada build
- Nenhuma configuração necessária; todas as páginas são incluídas por padrão

## Desativar o llms.txt

`llms.txt` e `llms-full.txt` são publicados por padrão. Para interromper a geração (por exemplo, se você não quiser que ferramentas de IA processem seu conteúdo), defina `seo.ai.llmsTxt` como `false` em seu `docs.json`:

```json docs.json
{
  "seo": {
    "ai": {
      "llmsTxt": false
    }
  }
}
```

No próximo build, o Jamdesk ignora os dois arquivos, incluindo todas as cópias por idioma, e as URLs ativas `/llms.txt` e `/llms-full.txt` retornam `404`.

<Note>
  **A ingestão por IA e a indexação de busca são controles separados.** `seo.ai.llmsTxt` controla apenas os arquivos `llms.txt`/`llms-full.txt` lidos pelas ferramentas de IA. Isso não altera a forma como os mecanismos de busca indexam seu site; esse comportamento é controlado pelos [`robots` metadados e pelo `noindex` por página](/pt/content/seo#controlando-a-indexação). Uma página pode ser indexada pelo Google enquanto é excluída da ingestão por IA, ou vice-versa.
</Note>

## Rastreadores de IA

O `robots.txt` padrão do Jamdesk permite todos os principais rastreadores de IA (Claude, ChatGPT, Copilot, Gemini). Sua documentação fica acessível às ferramentas de IA desde o início.

<Accordion title="Como llms.txt difere de sitemap.xml">
  `sitemap.xml` lista URLs para que os mecanismos de busca rastreiem e indexem. Ele não inclui conteúdo, apenas links e metadados, como datas da última modificação.

  `llms.txt` foi projetado para modelos de IA. Ele inclui títulos e descrições das páginas e, no `llms-full.txt`, o conteúdo propriamente dito. As ferramentas de IA podem ler o arquivo completo para entender sua documentação sem fazer várias solicitações HTTP.
</Accordion>
