title: Atualizações automáticas da documentação
description: >-
  Saiba como a skill /update-jamdesk do Claude Code transforma mudanças de código voltadas ao usuário em atualizações correspondentes na sua documentação Jamdesk.
---

A skill `/update-jamdesk` do Claude Code acompanha as mudanças no seu código e gera atualizações correspondentes na documentação. Execute-a depois de lançar um recurso voltado ao usuário. Ela identifica as páginas de documentação a criar ou editar.

<Note>
**Procurando dicas gerais de escrita com IA?** Veja [Claude Code](/pt/ai/claude-code) para a configuração da ferramenta. Veja [Escrever com IA](/pt/ai/writing-with-ai) para orientações mais amplas sobre como escrever documentação com ferramentas de IA.
</Note>

## Quando usar

**Use quando:** você fez mudanças voltadas ao usuário em APIs, comandos da CLI, interface, opções de configuração ou comportamento de componentes.

**Ignore quando:** refatorações internas, mudanças apenas em testes, configuração de build/CI ou trabalho de desempenho sem mudança de comportamento.

## Pré-requisitos

- [Claude Code](https://claude.ai/code) instalado e configurado
- Um projeto de documentação Jamdesk com `docs.json`
- Opcional: [CLI do Jamdesk](/pt/cli/overview) para verificação (`npm install -g jamdesk`)

## Início rápido

<Steps>
  <Step title="Criar arquivo de configuração">
    Crie um arquivo `.jamdesk-docs-path` no repositório do seu código apontando para a sua documentação:

    ```yaml .jamdesk-docs-path
    docs_path: ../my-docs
    ```

    O caminho pode ser relativo (a partir do arquivo de configuração) ou absoluto.
  </Step>
  <Step title="Executar a skill">
    Execute depois de implementar um recurso:

    ```text
    /update-jamdesk
    ```

    O Claude analisa suas mudanças e faz perguntas de esclarecimento antes de escrever a documentação.
  </Step>
  <Step title="Revisar e fazer commit">
    Revise a documentação gerada. O Claude a verifica com `jamdesk validate` e `jamdesk broken-links` antes do commit.
  </Step>
</Steps>

## Formato do arquivo de configuração

O arquivo `.jamdesk-docs-path` informa ao Claude onde está a sua documentação.

**Formato simples**, apenas com o caminho:

```text
../my-docs
```

**Formato completo**, com opções:

```yaml .jamdesk-docs-path
# Path to documentation repository
docs_path: ../my-docs

# Optional: Branch for doc updates (default: main)
docs_branch: main
```

<Note>
  A skill localiza o arquivo de configuração subindo a partir do diretório atual até a raiz do git. Coloque-o na raiz do seu repositório.
</Note>

## Como funciona

O Claude executa estas etapas para `/update-jamdesk`:

1. **Localiza sua documentação:** encontra o arquivo de configuração `.jamdesk-docs-path`
2. **Faz perguntas:** esclarece a estratégia de branch, o escopo e o conteúdo
3. **Analisa a documentação existente:** procura conteúdo relacionado para atualizar ou ampliar
4. **Escreve a documentação:** cria ou atualiza páginas seguindo os padrões do Jamdesk, com exemplos simples primeiro
5. **Revisa o tom:** verifique a saída em busca de enchimento típico de IA. O Claude escreve melhor com um CLAUDE.md que define a voz (veja [Claude Code](/pt/ai/claude-code))
6. **Verifica:** executa `jamdesk validate` e `jamdesk broken-links`
7. **Faz commit:** prepara as mudanças e oferece commit/push/PR

<Tip>
  Execute `git checkout .` antes do commit para reverter todas as edições.
</Tip>

<Accordion title="Como o Claude decide o que criar ou atualizar">
  | Cenário | Ação |
  |----------|--------|
  | Novo recurso | Criar nova página |
  | Mudança de comportamento | Atualizar página existente |
  | Pequena adição | Adicionar seção a uma página existente |
  | Capacidade principal | Nova página independente |
  | Descontinuação/remoção | Atualizar a existente e adicionar notas de migração |
</Accordion>

## Exemplo de sessão

```text
User: I just added a webhook feature. Can you document it?

Claude: I'm using the update-jamdesk skill to update your documentation.

Found .jamdesk-docs-path: ../customer-docs

How should I handle changes to the docs repository?
1. Create a new feature branch (recommended)
2. Update directly on main
3. Use current branch

User: 1

Claude: Based on the webhook implementation, I plan to:
- Create: webhooks/overview.mdx
- Update: getting-started.mdx (add link)

Any changes to this plan?

User: Looks good

Claude: [Creates documentation...]

✓ jamdesk validate passed
✓ jamdesk broken-links passed

Commit these changes?
```

## Modo de visualização prévia

Execute com `--preview` para ver o que mudaria sem fazer edições:

```text
/update-jamdesk --preview
```

O modo de pré-visualização permite:
- Verificar que documentação precisa ser atualizada
- Revisar as mudanças propostas antes do commit
- Ver a análise da skill sem efeitos colaterais

## Sugestões proativas

O Claude pode sugerir isto depois que você fizer commit de mudanças de código voltadas ao usuário:

```text
Tip: These changes affect user-facing features.
Run /update-jamdesk to update your documentation.
```

Isto aparece quando:
- Você tem um arquivo de configuração `.jamdesk-docs-path`, E
- Seu commit inclui arquivos que correspondem a padrões voltados ao usuário (API, CLI, componentes)

## Instalar a skill

Instale a skill `/update-jamdesk` usando a CLI de skills:

```bash
npx skills add jamdesk/skills --skill update-jamdesk
```

Isto instala a skill em `.claude/skills/update-jamdesk/` no seu projeto.

<Tabs>
  <Tab title="Instalação no projeto (padrão)">
    Instala no diretório do projeto atual:

    ```bash
    npx skills add jamdesk/skills --skill update-jamdesk
    ```

    A skill fica disponível ao trabalhar neste projeto.
  </Tab>
  <Tab title="Instalação global">
    Instala no seu diretório pessoal para uso em qualquer projeto:

    ```bash
    npx skills add jamdesk/skills --skill update-jamdesk -g
    ```

    A skill fica disponível em qualquer projeto.
  </Tab>
  <Tab title="Outros agentes">
    Instale no Cursor, Codex, Windsurf ou outros agentes suportados:

    ```bash
    # Install to Cursor
    npx skills add jamdesk/skills --skill update-jamdesk -a cursor

    # Install to multiple agents
    npx skills add jamdesk/skills --skill update-jamdesk -a claude-code -a cursor
    ```

    Execute `npx skills add --help` para ver todos os agentes suportados.
  </Tab>
</Tabs>

### Listar skills disponíveis

Veja todas as skills do Jamdesk:

```bash
npx skills add jamdesk/skills --list
```

### Atualizar

Execute o comando de instalação novamente para obter a versão mais recente:

```bash
npx skills add jamdesk/skills --skill update-jamdesk
```

<Note>
  Reinicie o Claude Code ou inicie uma nova sessão depois de instalar ou atualizar.
</Note>

## Solução de problemas

<Accordion title="Skill não reconhecida">
  Verifique se o arquivo da skill está em `.claude/skills/update-jamdesk/SKILL.md`. Depois, reinicie sua sessão do Claude Code.
</Accordion>

<Accordion title="Arquivo de configuração não encontrado">
  Crie `.jamdesk-docs-path` na raiz do seu repositório com o caminho para o diretório da documentação. A skill procura a partir do diretório atual até a raiz do git.
</Accordion>

<Accordion title="CLI do jamdesk não instalada">
  Instale com `npm install -g jamdesk`. A skill funciona sem ela, mas pula a validação automatizada.
</Accordion>
