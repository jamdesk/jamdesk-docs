Toda página do seu site Jamdesk tem um menu de Ações de IA, um pequeno menu suspenso acima do título. Os leitores podem copiar a página em Markdown, abri-la no ChatGPT ou instalar seu servidor MCP no Cursor. Nenhuma configuração é necessária.

## Opções integradas

O menu vem com oito opções, todas ativadas por padrão:

| Opção | Chave | O que faz |
|--------|-----|-------------|
| **Copy page** | `copy` | Busca o Markdown bruto e o copia para a área de transferência |
| **View as Markdown** | `view` | Abre o arquivo `.md` em uma nova aba |
| **Open in ChatGPT** | `chatgpt` | Abre o ChatGPT com um prompt para ler a página atual |
| **Open in Claude** | `claude` | Abre o Claude com o mesmo prompt |
| **Open in Perplexity** | `perplexity` | Abre o Perplexity com o mesmo prompt |
| **Copy MCP config** | `mcp` | Copia a configuração JSON do seu [servidor MCP](/pt/ai/mcp-server) do site |
| **Add to Cursor** | `cursor` | Cria um link direto para instalar o servidor MCP no Cursor |
| **Add to VS Code** | `vscode` | Cria um link direto para instalar o servidor MCP no VS Code |

O Gemini também está disponível como `gemini`. Ele não faz parte dos padrões porque não preenche prompts de forma confiável a partir de uma URL. Adicione-o explicitamente se seus leitores o utilizarem.

`copy` se torna o botão principal quando está na lista de opções. As demais aparecem em um menu suspenso atrás de um chevron. Sem `copy`, o menu se recolhe em um único menu suspenso "AI Actions".

### Baixar especificação da API

As páginas de referência de API recebem mais um item: **Download API spec**. Ele agrupa todas as especificações OpenAPI que seu site referencia em um único `api-specs.zip`, incluindo URLs de especificações remotas. Entregue o zip ao Postman, a um gerador de clientes ou às suas próprias ferramentas. Especificações com múltiplos arquivos mantêm a estrutura de pastas dentro do zip. Os links `$ref` entre arquivos continuam sendo resolvidos.

Não há nada a configurar. O item aparece apenas em páginas baseadas em uma especificação OpenAPI. A Jamdesk gera o zip novamente a cada download, por isso ele sempre corresponde às suas especificações atuais.

## Configuração

Edite o `docs.json` somente para alterar quais opções aparecem ou para desativar o menu.

### Mostrar um subconjunto de opções

```json docs.json
{
  "contextual": {
    "options": ["copy", "claude", "mcp"]
  }
}
```

### Desativar o menu

```json docs.json
{
  "contextual": {
    "enabled": false
  }
}
```

### Adicionar opções personalizadas

Combine opções integradas com as suas próprias. Uma opção personalizada abre sua URL em uma nova aba.

```json docs.json
{
  "contextual": {
    "options": [
      "copy",
      "claude",
      {
        "title": "Ask on Discord",
        "description": "Get help from the community",
        "icon": "discord",
        "href": "https://discord.gg/your-server"
      }
    ]
  }
}
```

As opções personalizadas aceitam um campo `icon` opcional. Qualquer [nome de ícone do Font Awesome](/pt/content/icons) funciona, incluindo ícones de marcas como `discord` ou `slack`. Opções sem ícone exibem um ícone de link.

As opções personalizadas também aceitam parâmetros de consulta:

```json docs.json
{
  "contextual": {
    "options": [
      "copy",
      {
        "title": "Search in Notion",
        "description": "Find related internal docs",
        "href": {
          "base": "https://notion.so/search",
          "query": [
            { "key": "q", "value": "docs" }
          ]
        }
      }
    ]
  }
}
```

## Como funciona

O menu é executado no lado do cliente. Suas URLs são atualizadas a cada navegação entre páginas, incluindo a navegação pela barra lateral, sem recarregar a página inteira. O link "Open in Claude" sempre aponta para a página atual.

Os links dos serviços de IA colocam a URL `.md` da página no prompt. ChatGPT, Claude e Perplexity buscam a página a partir desse link.

As opções MCP usam o endpoint `/_mcp` em todo site Jamdesk. "Copy MCP config" copia o JSON para qualquer cliente MCP. "Add to Cursor" e "Add to VS Code" são links diretos que abrem o fluxo de instalação do editor. Veja [Servidor MCP](/pt/ai/mcp-server) para saber o que as ferramentas de IA podem fazer com ele.
