O Jamdesk é uma [ferramenta de documentação de software](https://jamdesk.com) que cria sites de documentação a partir dos seus arquivos Markdown. Conecte um repositório do GitHub, escreva em MDX e publique globalmente em segundos. Você não precisa configurar um pipeline de build nem executar tarefas de DevOps. Cada site gera um arquivo `llms.txt` para que ferramentas de IA possam indexar seu conteúdo.

<Info>
**Escreva com IA.** Use Cursor, Claude ou qualquer assistente de IA para gerar e editar sua documentação. MDX é um formato de texto que as ferramentas de IA entendem nativamente, portanto não são necessários prompts especiais.
</Info>

## Um projeto Jamdesk mínimo

```text
my-docs/
├── docs.json
└── introduction.mdx
```

Isso é tudo de que você precisa. Consulte o [Guia de início rápido](/pt/quickstart) para criar o seu.

<Tip>
Consulte no GitHub o [código-fonte desta documentação](https://github.com/jamdesk/jamdesk-docs). É um projeto Jamdesk funcional que você pode usar como referência.
</Tip>

## Como funciona

<Steps>
  <Step title="Escreva em MDX">
    Crie documentação usando Markdown com componentes React opcionais. Use seu editor favorito: VS Code, Cursor ou qualquer editor de texto simples. Ferramentas de IA, como Claude, podem gerar e editar MDX nativamente.
  </Step>
  <Step title="Envie para o GitHub">
    Faça commit das suas alterações e envie-as. Você não precisa executar um comando de build nem manter um script de publicação.
  </Step>
  <Step title="Online em segundos">
    O Jamdesk detecta seu envio, cria seu site e o publica em uma CDN global. Sua documentação estará disponível em `your-project.jamdesk.app`.
  </Step>
</Steps>
