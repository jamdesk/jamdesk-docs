Cada projeto do Jamdesk recebe um subdomínio gratuito em `yourproject.jamdesk.app`. Este é o URL padrão da sua documentação e funciona imediatamente após a primeira implantação.

## Como funcionam os subdomínios

Ao criar um projeto, o Jamdesk atribui automaticamente um subdomínio com base no slug do projeto:

| Slug do projeto | Subdomínio |
|----------------|------------|
| `my-docs` | `my-docs.jamdesk.app` |
| `acme-api` | `acme-api.jamdesk.app` |
| `company-help` | `company-help.jamdesk.app` |

Seu subdomínio fica ativo assim que o primeiro build é concluído.

## Regras de nomenclatura de subdomínios

Os subdomínios devem seguir estas regras:
- Somente letras minúsculas, números e hífens
- Devem começar com uma letra
- Não podem começar ou terminar com um hífen
- Devem ter de 3 a 63 caracteres
- Devem ser exclusivos em todos os projetos do Jamdesk

## Alterar seu subdomínio

Para alterar seu subdomínio:

1. Acesse seu projeto no [Dashboard](https://dashboard.jamdesk.com)
2. Abra **Settings** → **General**
3. Atualize o campo **Project Slug**
4. Clique em **Save**

<Warning>
Alterar seu subdomínio quebra os links existentes. Mecanismos de pesquisa e sites externos que apontarem para o subdomínio antigo receberão erros 404. Se precisar manter a estabilidade do URL, considere configurar um domínio personalizado.
</Warning>

Após a alteração:
- Seu novo subdomínio fica ativo imediatamente
- O subdomínio antigo retorna 404
- Favoritos e links externos deixam de funcionar
- As classificações nos mecanismos de pesquisa são redefinidas

## Certificados SSL

Os certificados SSL são provisionados automaticamente para todos os subdomínios `*.jamdesk.app`. HTTPS é obrigatório; as solicitações HTTP são redirecionadas para HTTPS.

## Limites de uso

Os subdomínios do Jamdesk compartilham a infraestrutura com outros projetos. Para documentações com alto tráfego:
- Considere um domínio personalizado para obter recursos dedicados
- Entre em contato com o suporte se esperar um tráfego alto e contínuo

## Quando usar um domínio personalizado

Use um domínio personalizado quando:
- Precisar de estabilidade do URL (alterações no subdomínio quebram links)
- Quiser disponibilizar sua documentação em `docs.yourcompany.com`
- Precisar corresponder ao domínio da sua empresa
- Sua documentação for voltada para clientes

Consulte [Domínios personalizados](/pt/deploy/custom-domains) para obter instruções de configuração.

## Subdomínio ou domínio personalizado

| Recurso | Subdomínio | Domínio personalizado |
|---------|------------|-----------------------|
| Tempo de configuração | Instantâneo | 10–30 minutos |
| Custo | Gratuito | Gratuito (você fornece o domínio) |
| Formato do URL | `project.jamdesk.app` | `docs.yourdomain.com` |
| SSL | Automático | Automático |
| Marca | Com a marca Jamdesk | Sua marca |
| Estabilidade do URL | Vinculada ao slug do projeto | Permanente |
