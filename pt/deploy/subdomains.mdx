Todo projeto Jamdesk recebe um subdomínio gratuito em `yourproject.jamdesk.app`. Ele é a sua URL padrão de documentação.

## Como funcionam os subdomínios

O Jamdesk atribui um subdomínio a partir do slug do seu projeto quando você cria o projeto:

| Slug do projeto | Subdomínio |
|--------------|-----------|
| `my-docs` | `my-docs.jamdesk.app` |
| `acme-api` | `acme-api.jamdesk.app` |
| `company-help` | `company-help.jamdesk.app` |

Seu subdomínio fica ativo assim que o primeiro build for concluído.

## Regras de nomenclatura de subdomínios

- Apenas letras minúsculas, números e hífens
- Deve começar com uma letra
- Não pode começar nem terminar com hífen
- Entre 3 e 63 caracteres
- Deve ser único em todos os projetos Jamdesk

## Alterar seu subdomínio

1. Acesse seu projeto no [Dashboard](https://dashboard.jamdesk.com)
2. Abra **Settings** → **General**
3. Atualize o campo **Project Slug**
4. Clique em **Save**

<Warning>
Alterar seu subdomínio quebra os links existentes. Mecanismos de busca e sites externos que apontam para o seu antigo subdomínio receberão erros 404. Configure um domínio personalizado se precisar de URLs estáveis.
</Warning>

O que muda:
- Seu novo subdomínio fica ativo imediatamente
- O antigo subdomínio retorna 404
- Favoritos e links externos deixam de funcionar
- O ranqueamento nos mecanismos de busca é reiniciado

## Certificados SSL

O Jamdesk provisiona certificados SSL para todo subdomínio `*.jamdesk.app`. Requisições HTTP são redirecionadas para HTTPS.

## Limites de uso

Os subdomínios do Jamdesk compartilham infraestrutura com outros projetos. Para documentação com alto tráfego:
- Use um domínio personalizado para recursos dedicados
- Entre em contato com o suporte se você espera tráfego alto e sustentado

## Quando usar um domínio personalizado

Escolha um domínio personalizado se:
- Você precisa de estabilidade de URL (mudanças de subdomínio quebram links)
- Você quer sua documentação em `docs.yourcompany.com`
- Você precisa combinar com o domínio da sua empresa
- Sua documentação é voltada para clientes

Consulte [Domínios personalizados](/pt/deploy/custom-domains) para as instruções de configuração.

## Subdomínio ou domínio personalizado

| Recurso | Subdomínio | Domínio personalizado |
|---------|-----------|---------------|
| Tempo de configuração | Instantâneo | 10-30 minutos |
| Custo | Gratuito | Gratuito (você fornece o domínio) |
| Formato da URL | `project.jamdesk.app` | `docs.yourdomain.com` |
| SSL | Automático | Automático |
| Marca | Marca Jamdesk | Sua marca |
| Estabilidade da URL | Vinculada ao slug do projeto | Permanente |
