Use Callouts para destacar contexto importante, como avisos, dicas ou requisitos, sem interromper o fluxo de leitura.

## Avisos disponíveis

<Note>
**Note**: Contexto útil ou informações adicionais.
</Note>

<Info>
**Info**: Informações neutras ou fatos. Use para detalhes complementares.
</Info>

<Tip>
**Tip**: Abordagens recomendadas ou otimizações.
</Tip>

<Warning>
**Warning**: Ressalvas ou requisitos importantes. Use quando ignorar algo puder causar problemas.
</Warning>

<Danger>
**Danger**: Avisos críticos. Use para ações que possam causar perda de dados ou problemas de segurança.
</Danger>

<Check>
**Check**: Confirmações de sucesso. Use para confirmar comportamento correto ou conclusão bem-sucedida.
</Check>

## Uso

```mdx
<Note>
This is helpful context for the reader.
</Note>

<Warning>
This could cause issues if you skip this step.
</Warning>

<Danger>
This action cannot be undone. Proceed with caution.
</Danger>
```

## Com títulos

Adicione um título personalizado a qualquer callout:

```mdx
<Note title="Did you know?">
You can use **Markdown** inside callouts, including `code` and [links](/introduction).
</Note>
```

<Note title="Did you know?">
Você pode usar **Markdown** dentro de callouts, incluindo `code` e [links](/pt/components/card).
</Note>

## Com blocos de código

Callouts podem conter código:

<Warning title="Breaking Change in v2.0">
A assinatura da função `getData()` mudou:

```javascript
// Before (v1.x)
getData(id)

// After (v2.0)
getData({ id, options })
```
</Warning>

## Práticas recomendadas

<AccordionGroup>
  <Accordion title="Use com moderação" icon="hand" defaultOpen>
    Callouts em excesso diluem seu impacto. Procure usar no máximo 1 a 2 por página.

    Reserve os callouts para informações que o leitor não pode deixar passar.
  </Accordion>

  <Accordion title="Escolha o tipo certo" icon="list-check">
    | Cenário | Callout |
    |----------|---------|
    | Dica útil | `<Tip>` |
    | Contexto extra | `<Note>` ou `<Info>` |
    | Possível armadilha | `<Warning>` |
    | Ação irreversível | `<Danger>` |
    | Confirmação | `<Check>` |
    | Identidade visual personalizada | `<Callout>` |
  </Accordion>

  <Accordion title="Seja conciso" icon="text-width">
    Mantenha os callouts fáceis de escanear. Use um Accordion para vários parágrafos.

    **Bom:** Uma ou duas frases
    **Evite:** Vários parágrafos de texto
  </Accordion>

  <Accordion title="Posicione estrategicamente" icon="arrows-up-down">
    Coloque os callouts:
    - **Antes** de código que tenha requisitos
    - **Depois** de instruções com ressalvas importantes
    - **Perto** do conteúdo a que se referem
  </Accordion>
</AccordionGroup>

## Propriedades

Todo callout aceita estas props:

<ParamField name="title" type="string">
  Título personalizado (substitui o padrão).
</ParamField>

## Acessibilidade

Os callouts usam HTML semântico e roles ARIA:
- Leitores de tela anunciam o tipo do callout
- A cor não é o único indicador (ícones estão incluídos)
- Contraste de cor suficiente no modo escuro

## Aviso personalizado

Defina um ícone e uma cor personalizados com o componente `Callout`:

<Callout icon="key" color="#FFC107">
**Custom**: Use qualquer ícone e cor para combinar com seu conteúdo.
</Callout>

<Callout icon="rocket" color="#9333EA">
Publique suas alterações com confiança usando nosso pipeline de CI/CD.
</Callout>

<Callout icon="regular/star" color="#EC4899">
Use prefixos de estilo de ícone como `regular/`, `light/` ou `duotone/` para diferentes espessuras.
</Callout>

### Uso de avisos personalizados

```mdx
<Callout icon="key" color="#FFC107">
  This callout uses a key icon with amber color.
</Callout>

<Callout icon="rocket" color="#9333EA">
  This callout uses a rocket icon with purple color.
</Callout>

<Callout icon="regular/star" color="#EC4899">
  Use style prefixes for different icon weights.
</Callout>
```

### Propriedades de avisos personalizados

<ParamField name="icon" type="string" default="circle-info">
  Nome do ícone (veja [Ícones](/pt/content/icons)).
</ParamField>

<ParamField name="color" type="string">
  Código de cor hexadecimal (ex.: `#FFC107`). O padrão é a cor de destaque.
</ParamField>

**Prefixos de estilo de ícone:** Adicione um prefixo para mudar a espessura do ícone:
- `solid/` - Ícones preenchidos (padrão)
- `regular/` - Ícones com contorno
- `light/` - Ícones com contorno fino
- `duotone/` - Ícones de dois tons
