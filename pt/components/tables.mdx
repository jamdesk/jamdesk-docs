Tabelas organizam dados em linhas e colunas. Use **tabelas markdown** para tabelas rápidas e simples. Use **componentes Table** para destaque, alinhamento e outras opções.

## Uso

```mdx
<Table>
  <Row header>
    <Cell>Name</Cell>
    <Cell>Type</Cell>
  </Row>
  <Row>
    <Cell>id</Cell>
    <Cell>string</Cell>
  </Row>
</Table>
```

## Tabelas Markdown

A forma mais rápida de criar uma tabela. Use barras verticais (`|`) para separar colunas e hífens (`-`) para a linha de cabeçalho:

```markdown
| Name | Type | Description |
|------|------|-------------|
| id | string | Unique identifier |
| email | string | User email address |
```

| Name | Type | Description |
|------|------|-------------|
| id | string | Unique identifier |
| email | string | User email address |

<Tip>
Use tabelas markdown para dados de referência simples. Mude para o componente Table para destaque, alinhamento ou ênfase visual.
</Tip>

## Componente Table

Para mais controle, use os componentes `<Table>`, `<Row>` e `<Cell>`:

```mdx
<Table>
  <Row header>
    <Cell>Name</Cell>
    <Cell>Type</Cell>
    <Cell>Description</Cell>
  </Row>
  <Row>
    <Cell>id</Cell>
    <Cell>string</Cell>
    <Cell>Unique identifier</Cell>
  </Row>
  <Row>
    <Cell>email</Cell>
    <Cell>string</Cell>
    <Cell>User email address</Cell>
  </Row>
</Table>
```

## Linhas listradas

Adicione fundos de linha alternados para melhor legibilidade:

```mdx
<Table striped>
  <Row header>
    <Cell>Parameter</Cell>
    <Cell>Value</Cell>
  </Row>
  <Row><Cell>timeout</Cell><Cell>30s</Cell></Row>
  <Row><Cell>retries</Cell><Cell>3</Cell></Row>
  <Row><Cell>backoff</Cell><Cell>exponential</Cell></Row>
  <Row><Cell>maxDelay</Cell><Cell>60s</Cell></Row>
</Table>
```

## Com bordas e compacto

Adicione bordas entre células e reduza o espaçamento:

```mdx
    <Cell>1</Cell>
```

## Realce de linhas

Destaque linhas inteiras para chamar a atenção:

```mdx
<Table>
  <Row header>
    <Cell>Field</Cell>
    <Cell>Required</Cell>
    <Cell>Description</Cell>
  </Row>
  <Row highlight highlightColor="warning">
    <Cell>api_key</Cell>
    <Cell>Yes</Cell>
    <Cell>Your API authentication key</Cell>
  </Row>
  <Row>
    <Cell>limit</Cell>
    <Cell>No</Cell>
    <Cell>Maximum results (default: 100)</Cell>
  </Row>
</Table>
```

## Alinhamento de células

Controle o alinhamento do texto por célula:

```mdx
<Table>
  <Row header>
    <Cell align="left">Left</Cell>

    <Cell align="right">Right</Cell>
  </Row>
  <Row>
    <Cell align="left">Text</Cell>
    <Cell align="center">Text</Cell>
    <Cell align="right">$99.99</Cell>
```

## Mesclagem de colunas e linhas

Mescle células entre colunas ou linhas:

```mdx
<Table bordered>
  <Row header>
    <Cell>Category</Cell>
    <Cell>Item</Cell>
    <Cell>Price</Cell>
  </Row>
  <Row>
    <Cell rowSpan={2}>Fruits</Cell>
    <Cell>Apple</Cell>
    <Cell>$1.00</Cell>
  </Row>
  <Row>
    <Cell>Banana</Cell>
    <Cell>$0.50</Cell>
  </Row>
  <Row>
    <Cell colSpan={2}>Subtotal</Cell>
    <Cell>$1.50</Cell>
  </Row>
</Table>
```

## Colunas classificáveis

Ative a ordenação de colunas com a propriedade `sortable`. Clique em um cabeçalho de coluna para ordenar:

```mdx
<Table sortable>
  <Row header>
    <Cell>Name</Cell>
    <Cell>Price</Cell>
    <Cell>Stock</Cell>
  </Row>
  <Row><Cell>Widget A</Cell><Cell>$29.99</Cell><Cell>150</Cell></Row>
  <Row><Cell>Gadget B</Cell><Cell>$49.99</Cell><Cell>75</Cell></Row>
  <Row><Cell>Tool C</Cell><Cell>$19.99</Cell><Cell>200</Cell></Row>
  <Row><Cell>Device D</Cell><Cell>$99.99</Cell><Cell>25</Cell></Row>
</Table>
```

<Table sortable>
  <Row header>
    <Cell>Name</Cell>
    <Cell>Price</Cell>
    <Cell>Stock</Cell>
  </Row>
  <Row><Cell>Widget A</Cell><Cell>$29.99</Cell><Cell>150</Cell></Row>
  <Row><Cell>Gadget B</Cell><Cell>$49.99</Cell><Cell>75</Cell></Row>
  <Row><Cell>Tool C</Cell><Cell>$19.99</Cell><Cell>200</Cell></Row>
  <Row><Cell>Device D</Cell><Cell>$99.99</Cell><Cell>25</Cell></Row>
</Table>

<Tip>
Clique em um cabeçalho de coluna uma vez para ordenar em ordem crescente, de novo para decrescente, e uma terceira vez para redefinir. Números são ordenados numericamente, texto em ordem alfabética.
</Tip>

Combine `sortable` com outras propriedades como `striped`:

```mdx
<Table sortable striped>
  <Row header>
    <Cell>Team</Cell>
    <Cell>Wins</Cell>
    <Cell>Losses</Cell>
  </Row>
  <Row><Cell>Eagles</Cell><Cell>12</Cell><Cell>4</Cell></Row>
  <Row><Cell>Bears</Cell><Cell>8</Cell><Cell>8</Cell></Row>
  <Row><Cell>Lions</Cell><Cell>10</Cell><Cell>6</Cell></Row>
</Table>
```

## Props

### Table

| Prop | Type | Default | Description |
|------|------|---------|-------------|
| `striped` | boolean | false | Fundos de linha alternados |
| `bordered` | boolean | false | Bordas entre todas as células |
| `compact` | boolean | false | Espaçamento de célula reduzido |
| `fullWidth` | boolean | true | Tabela ocupa a largura total |
| `caption` | string | - | Texto da legenda da tabela |
| `captionVisible` | boolean | false | Mostra a legenda visualmente (padrão: apenas leitor de tela) |
| `stickyHeader` | boolean | false | Mantém o cabeçalho visível ao rolar |
| `sortable` | boolean | false | Ativa a ordenação por clique nos cabeçalhos de coluna |

### Row

| Prop | Type | Default | Description |
|------|------|---------|-------------|
| `header` | boolean | false | Renderiza como linha de cabeçalho |
| `highlight` | boolean | false | Destaca a linha |
| `highlightColor` | string | primary | Cor: primary, success, warning, error, info |

### Cell

| Prop | Type | Default | Description |
|------|------|---------|-------------|
| `align` | string | left | Alinhamento do texto: left, center, right |
| `colSpan` | number | - | Colunas a mesclar |
| `rowSpan` | number | - | Linhas a mesclar |
| `highlight` | boolean | false | Destaca a célula |
| `highlightColor` | string | primary | Cor: primary, success, warning, error, info |
| `header` | boolean | false | Força estilo de cabeçalho |
