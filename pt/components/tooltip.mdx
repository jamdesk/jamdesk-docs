Adicione texto ao passar o mouse para definir termos, explicar siglas ou linkar para páginas relacionadas sem poluir o conteúdo principal.

Use Tooltips quando:
- **Definir termos** inline sem interromper a leitura
- **Explicar siglas** que alguns leitores podem não conhecer
- **Fornecer contexto** útil, mas não essencial
- **Linkar para conteúdo relacionado** com uma chamada para ação

## Tooltip básico

Passe o mouse sobre <Tooltip tip="Um conjunto de protocolos para que aplicações de software se comuniquem.">API</Tooltip> para ver a definição.

```jsx
<Tooltip tip="A set of protocols for software applications to communicate.">
  API
</Tooltip>
```

## Com título

Adicione um título acima do texto da dica:

Passe o mouse sobre <Tooltip headline="API" tip="Application Programming Interface: um conjunto de protocolos para que aplicações de software se comuniquem.">API</Tooltip> para ver a definição com um título.

```jsx
<Tooltip
  headline="API"
  tip="Application Programming Interface: a set of protocols for software applications to communicate."
>
  API
</Tooltip>
```

## Com link de chamada para ação

Adicione um link para mais detalhes:

Saiba mais sobre <Tooltip headline="API" tip="Application Programming Interface: um conjunto de protocolos para que aplicações de software se comuniquem." cta="Saiba mais" href="/pt/components/overview">APIs</Tooltip> em nossa documentação.

```jsx
<Tooltip
  headline="API"
  tip="Application Programming Interface: a set of protocols..."
  cta="Learn more"
  href="/components/overview"
>
  API
</Tooltip>
```

## Uso em linha

Tooltips funcionam inline com o texto. Você pode explicar termos como <Tooltip tip="HyperText Markup Language">HTML</Tooltip>, <Tooltip tip="Cascading Style Sheets">CSS</Tooltip> ou <Tooltip tip="JavaScript">JS</Tooltip> diretamente no texto.

```jsx
Explain <Tooltip tip="HyperText Markup Language">HTML</Tooltip>,
<Tooltip tip="Cascading Style Sheets">CSS</Tooltip>, or
<Tooltip tip="JavaScript">JS</Tooltip> terms inline.
```

## Tooltips versus outros componentes

| Necessidade | Componente |
|------|-----------|
| Definir um termo inline | **Tooltip** |
| Explicar um conceito em detalhes | Expandable ou seção separada |
| Alertar sobre algo importante | Callout (Note, Warning) |
| Mostrar código contextual | CodeGroup ou código inline |

**Regra prática:** Tooltips são para definições rápidas (1-2 frases). Explicações mais longas pertencem ao conteúdo principal ou a um Expandable.

## Props

<ParamField name="tip" type="string" required>
  O texto do tooltip exibido ao passar o mouse.
</ParamField>

<ParamField name="headline" type="string">
  Texto exibido acima da dica.
</ParamField>

<ParamField name="cta" type="string">
  Texto do link de chamada para ação.
</ParamField>

<ParamField name="href" type="string">
  URL para a chamada para ação (obrigatório com `cta`).
</ParamField>

<ParamField name="children" type="ReactNode">
  O texto que aciona o tooltip.
</ParamField>

## Acessibilidade

- Tooltips são acessíveis por teclado (Tab para focar, exibe ao focar)
- Usa `role="tooltip"` para leitores de tela
- O texto de acionamento tem um sublinhado tracejado para indicar interatividade
