  Aprenda a usar o componente Card para criar contêineres clicáveis e estilizados com ícones, imagens, links e CTAs em layouts de grade.
---

O componente `<Card>` é um contêiner clicável e estilizado. Use-o para criar links para outras páginas ou agrupar conteúdos relacionados. Combine cards com `<Columns>` para criar layouts em grade.

## Uso

```mdx
<Card title="Quickstart" icon="rocket" href="/quickstart">
  Launch your docs in minutes.
</Card>
```

## Cartão básico

Um card com título:

<Card title="Começando">
  Configure seu primeiro projeto em menos de cinco minutos.
</Card>

```mdx
<Card title="Getting Started">
  Set up your first project in under five minutes.
</Card>
```

## Cartão com ícone

Adicione um ícone:

<Card title="Documentação" icon="book">
  Explore nossa documentação completa para conhecer todos os recursos.
</Card>

```mdx
<Card title="Documentation" icon="book">
  Explore our complete documentation to learn all features.
</Card>
```

## Cartão com link

Cards podem apontar para outras páginas:

<Card title="Referência da API" icon="code" href="/pt/introduction">
  Veja a documentação completa da API.
</Card>

```mdx
<Card title="API Reference" icon="code" href="/introduction">
  View the complete API documentation.
</Card>
```

## Cartão com seta

Adicione uma seta para indicar que o card é um link. Links externos recebem a seta automaticamente. Ative-a em links internos com `arrow={true}`:

<Card title="Quickstart" icon="github" href="/pt/quickstart" arrow={true}>
  Confira o código-fonte e contribua.
</Card>

```mdx
<Card title="Quickstart" icon="github" href="/quickstart" arrow={true}>
  Check out the source code and contribute.
</Card>
```

Links externos mostram a seta automaticamente:

<Card title="External Resource" href="https://example.com">
  Este card aponta para um site externo.
</Card>

```mdx
<Card title="External Resource" href="https://example.com">
  This card links to an external site.
</Card>
```

## Cartão com CTA

Adicione um texto de chamada à ação abaixo do conteúdo do card:

<Card title="Quickstart" icon="star" href="/pt/quickstart" cta="Upgrade now">
  Desbloqueie recursos avançados e suporte prioritário.
</Card>

```mdx
<Card title="Quickstart" icon="star" href="/quickstart" cta="Upgrade now">
  Unlock advanced features and priority support.
</Card>
```

Combine seta e CTA:

<Card title="Quickstart" icon="rocket" href="/pt/quickstart" arrow={true} cta="Start building">
  Tudo o que você precisa para lançar seu primeiro projeto.
</Card>

```mdx
<Card title="Quickstart" icon="rocket" href="/quickstart" arrow={true} cta="Start building">
  Everything you need to launch your first project.
</Card>
```

## Cartão com imagem

Exiba uma imagem no topo do card:

<Card title="Guia visual" img="/images/card-example-1.webp">
  Um card com imagem no cabeçalho.
</Card>

```mdx
<Card title="Visual Guide" img="/images/card-example.webp">
  A card featuring an image header.
</Card>
```

## Grade de cartões com Columns

Organize cards em uma grade responsiva com `Columns`:

<Columns cols={2}>
  <Card title="Quickstart" icon="rocket" href="/pt/quickstart">
    Comece a usar em minutos.
  </Card>
  <Card title="Tutoriais" icon="graduation-cap" href="/pt/content/mdx-basics">
    Trilhas de aprendizado passo a passo.
  </Card>
  <Card title="Exemplos" icon="flask" href="/pt/components/overview">
    Exemplos de código do mundo real.
  </Card>
</Columns>

```mdx
<Columns cols={2}>
  <Card title="Quickstart" icon="rocket" href="/quickstart">
    Get up and running in minutes.
  </Card>
  <Card title="Tutorials" icon="graduation-cap" href="/content/mdx-basics">
    Step-by-step learning paths.
  </Card>
  <Card title="Examples" icon="flask" href="/components/overview">
    Real-world code examples.
  </Card>

</Columns>
```

### Layout de três colunas

<Columns cols={3}>
  <Card title="Docs" icon="book">
    Documentação
  </Card>
  <Card title="API" icon="code">
    Referência da API
  </Card>
  <Card title="Blog" icon="newspaper">
    Últimas atualizações
  </Card>
</Columns>

```mdx
<Columns cols={3}>
  <Card title="Docs" icon="book">
    Documentation
  </Card>
  <Card title="API" icon="code">
    API Reference
  </Card>
  <Card title="Blog" icon="newspaper">
    Latest updates
  </Card>
</Columns>
```

## Propriedades

<ParamField name="title" type="string" required>
  O título exibido no topo do card.
</ParamField>

<ParamField name="icon" type="string">
  Nome do ícone Font Awesome (por exemplo, "book", "code", "rocket"). É renderizado na variante Solid por padrão. Adicione um prefixo de estilo como `light/book` para alterar o peso. Veja [Ícones](/pt/content/icons).
</ParamField>

<ParamField name="href" type="string">
  URL para a qual o card aponta. Pode ser interna (`/docs/intro`) ou externa (`https://example.com`).
</ParamField>

<ParamField name="img" type="string">
  Caminho para uma imagem exibida no topo do card.
</ParamField>

<ParamField name="arrow" type="boolean">
  Exibe um indicador de seta (↗) no canto superior direito. Ativado automaticamente para links externos (URLs que começam com `http://` ou `https://`). Defina como `true` para exibir em links internos, ou `false` para ocultar em links externos.
</ParamField>

<ParamField name="cta" type="string">
  Texto personalizado de chamada à ação exibido abaixo do conteúdo do card. Aparece somente quando `href` está definido.
</ParamField>

## Propriedades de Columns

<ParamField name="cols" type="number" default="2">
  Número de colunas na grade. Aceita 1, 2, 3 ou 4.
</ParamField>
