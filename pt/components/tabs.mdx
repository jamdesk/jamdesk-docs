title: Abas

---

Use Tabs para alternativas paralelas: gerenciadores de pacotes, linguagens de programação ou instruções específicas de sistema operacional. O leitor escolhe uma vez e permanece no contexto. Títulos de abas iguais são sincronizados na página. Selecione "yarn" em um grupo e todos os outros grupos npm/yarn/pnpm mudam para o mesmo.

Use Tabs quando:
- **Existirem múltiplas implementações** do mesmo conceito (npm/yarn/pnpm, JavaScript/Python)
- **As opções paralelas forem mutuamente exclusivas** (o leitor escolhe uma)
- **A consistência importar**: a escolha do leitor deve persistir ao longo da página

## Uso

```mdx
<Tabs>
  <Tab title="npm">npm install jamdesk</Tab>
  <Tab title="pnpm">pnpm add jamdesk</Tab>
</Tabs>
```

## Abas vs CodeGroup vs Accordion

| Component | Best For | Synchronizes |
|-----------|----------|--------------|
| **Tabs** | Mutually exclusive content choices | Yes (across page) |
| **CodeGroup** | Code blocks in multiple languages | No |
| **Accordion** | Collapsible sections, FAQs | No |

**Regra prática:** Use Tabs quando a escolha do leitor (como o gerenciador de pacotes preferido) deve persistir ao longo da página. Use CodeGroup para comparações apenas de código. Use Accordion para conteúdos que podem ser todos relevantes.

## Abas sincronizadas

Abas com títulos iguais são sincronizadas na página. Clique em "yarn" em um grupo e todos os grupos npm/yarn/pnpm da página mudam junto:

**Instalar:**

<Tabs>
  <Tab title="npm">
    ```bash
    npm install my-package
    ```
  </Tab>
  <Tab title="yarn">
    ```bash
    yarn add my-package
    ```
  </Tab>
</Tabs>

**Executar:**

<Tabs>
  <Tab title="npm">
    ```bash
    npm run dev
    ```
  </Tab>
  <Tab title="yarn">
    ```bash
    yarn dev
    ```
  </Tab>
</Tabs>

A sincronização acontece quando os títulos das abas são iguais (sem diferenciar maiúsculas de minúsculas).

## Propriedades

### Tabs

<ParamField name="borderBottom" type="boolean" default="false">
  Adds a bottom border and padding to the tab content container. Use it to separate tabbed content from the rest of the page.
</ParamField>

### Tab

<ParamField name="title" type="string" required>
  The label displayed in the tab bar. Tabs with matching titles sync their selection across the page.
</ParamField>

<ParamField name="icon" type="string">
  Font Awesome icon name to display before the title (e.g., "react", "code", "terminal").
</ParamField>

<ParamField name="iconType" type="string" default="solid">
  Font Awesome icon style. Options: `regular`, `solid`, `light`, `thin`, `sharp-solid`, `duotone`, `brands`.
</ParamField>
