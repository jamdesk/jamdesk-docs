Visualizações alternam seções inteiras de uma página para corresponder ao framework ou idioma do leitor. Abas mostram as opções lado a lado. Visualizações ocultam completamente o conteúdo não selecionado. Use-as quando seções inteiras diferirem entre frameworks.

Use Visualizações quando:
- **Seções inteiras da página** diferirem por framework (e não apenas trechos de código)
- **Tutoriais** tiverem etapas diferentes para tecnologias diferentes
- **Guias de primeiros passos** diferirem por plataforma

<Tip>
Para exemplos de código que diferem por linguagem, use [CodeGroup](/pt/components/code-group). Para procedimentos com diferenças pequenas, use [Tabs](/pt/components/tabs). Use Visualizações quando **seções inteiras** do conteúdo forem específicas de um framework.
</Tip>

## Uso básico

Crie visualizações para diferentes linguagens:

## Como funciona

Uma página com componentes View funciona assim:

1. Um seletor suspenso aparece no topo do conteúdo
2. Os leitores alternam entre as visualizações pelo seletor suspenso
3. Apenas o conteúdo da visualização selecionada fica visível

## View vs Tabs vs CodeGroup

| Componente | Melhor para | Escopo |
|-----------|----------|-------|
| **View** | Seções inteiras que diferem por framework | Alternância de conteúdo em toda a página |
| **Tabs** | Comparações rápidas, gerenciadores de pacotes | Alternância de conteúdo em linha |
| **CodeGroup** | A mesma operação em múltiplas linguagens | Apenas blocos de código |

**Exemplos de cenários:**
- "Instalar com npm vs yarn" → **Tabs** (pequena diferença)
- "fetch em JavaScript vs requests em Python" → **CodeGroup** (comparação de código)
- "Tutorial React vs tutorial Vue" → **View** (seção inteira diferente)

## Props

<ParamField name="title" type="string" required>
  O título exibido no seletor suspenso. Deve ser único dentro da página.
</ParamField>

<ParamField name="icon" type="string">
  Um ícone do Font Awesome, URL para um ícone ou caminho relativo para um ícone.
</ParamField>

<ParamField name="iconType" type="string" default="solid">
  Apenas para ícones do Font Awesome. Opções: `regular`, `solid`, `light`, `thin`, `sharp-solid`, `duotone`, `brands`.
</ParamField>
