As visualizações permitem criar documentação que se adapta à escolha de framework ou linguagem do leitor. Diferentemente de Tabs, que mostram várias opções lado a lado, as visualizações ocultam completamente o conteúdo não selecionado. Isso mantém a página mais organizada quando seções inteiras variam entre frameworks.

Use visualizações quando:
- **Seções inteiras da página** forem diferentes conforme o framework, e não apenas os trechos de código
- **Tutoriais** tiverem etapas diferentes para tecnologias distintas
- **Guias de primeiros passos** variarem bastante conforme a plataforma

<Tip>
Para exemplos de código que variam conforme a linguagem, use [CodeGroup](/pt/components/code-group). Para procedimentos com pequenas diferenças, use [Tabs](/pt/components/tabs). Use visualizações quando **seções inteiras** do conteúdo forem específicas de cada framework.
</Tip>

## Uso básico

Crie visualizações para diferentes linguagens:

  ```javascript
  console.log("Hello from JavaScript!");
  ```
</View>

<View title="Python" icon="python">

  ```python
  print("Hello from Python!")
  ```

</View>

## Como funciona

Ao adicionar componentes View a uma página:

1. Um seletor suspenso aparece no topo do conteúdo
2. Os usuários podem alternar entre as visualizações usando o seletor
3. Apenas o conteúdo da visualização selecionada fica visível

## View vs Tabs vs CodeGroup

| Componente | Ideal para | Escopo |
|-----------|----------|-------|
| **View** | Seções inteiras que variam conforme o framework | Alternância do conteúdo em toda a página |
| **Tabs** | Comparações rápidas, gerenciadores de pacotes | Alternância de conteúdo em linha |
| **CodeGroup** | A mesma operação em várias linguagens | Apenas blocos de código |

**Exemplos de cenários:**
- “Instalar com npm ou yarn” → **Tabs** (pequena diferença)
- “JavaScript fetch ou Python requests” → **CodeGroup** (comparação de código)
- “Tutorial de React ou tutorial de Vue” → **View** (a seção inteira é diferente)

## Props

<ParamField name="title" type="string" required>
  O título exibido no seletor suspenso. Deve ser exclusivo na página.
</ParamField>

<ParamField name="icon" type="string">
  Um ícone do Font Awesome, uma URL para um ícone ou um caminho relativo para um ícone.
</ParamField>

<ParamField name="iconType" type="string" default="solid">
  Apenas para ícones do Font Awesome. Opções: `regular`, `solid`, `light`, `thin`, `sharp-solid`, `duotone`, `brands`.
</ParamField>
