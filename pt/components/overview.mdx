description: >-
  Conheça os componentes MDX do Jamdesk, incluindo cards, abas, avisos e blocos

---

O Jamdesk inclui componentes MDX que você pode usar em qualquer página.

## Uso

Adicione componentes ao seu MDX:

```mdx
<Card title="Quickstart" icon="rocket" href="/quickstart">
  Launch your docs in minutes.
</Card>
```

  </Card>
  <Card title="Panel" icon="sidebar" href="/pt/components/panel">
    Fixe conteúdo personalizado, como avisos ou referências rápidas, na barra lateral, onde ele permanece visível enquanto o leitor rola a página.
  </Card>
  <Card title="Steps" icon="list-ol" href="/pt/components/steps">

  </Card>
  <Card title="Tabs" icon="folder" href="/pt/components/tabs">

  </Card>
  <Card title="Tile" icon="grid-2" href="/pt/components/tile">

  </Card>
  <Card title="Tree" icon="folder-tree" href="/pt/components/tree">
    Exiba hierarquias de arquivos e pastas com expansão/recolhimento interativos e navegação por teclado. Use-o para documentar a estrutura do projeto.
  </Card>
  <Card title="View" icon="window-maximize" href="/pt/components/view">
    Mostre conteúdo para o framework ou a linguagem escolhida pelo leitor. Seções inteiras mudam conforme a seleção.
  </Card>
</Columns>

## Conteúdo e destaque

<Columns cols={3}>
  <Card title="Badge" icon="tag" href="/pt/components/badge">
    Rótulos inline para status, categorias e metadados, com 11 variantes de cor, 4 tamanhos, ícones, formatos pill/arredondado e contornos de traço.
  </Card>
  <Card title="Callouts" icon="circle-info" href="/pt/components/callouts">
    Componentes Note, Tip, Warning, Danger, Check e Callout personalizados que destacam informações importantes.
  </Card>
  <Card title="Expandable" icon="expand" href="/pt/components/expandable">
    O Expandable cria um alternador de mostrar/ocultar para conteúdo opcional fora do fluxo principal.
  </Card>
  <Card title="Tooltip" icon="message" href="/pt/components/tooltip">
    Exiba definições e contexto ao passar o mouse. Defina termos, explique siglas ou crie links para conteúdos relacionados sem sobrecarregar a página.
  </Card>
  <Card title="Update" icon="clock-rotate-left" href="/pt/components/update">
    Entradas de changelog em formato de linha do tempo, com datas, descrições e tags de categoria. As entradas aparecem no Sumário.
  </Card>
  <Card title="Visibility" icon="eye" href="/pt/components/visibility">
    Mostre conteúdos diferentes para leitores humanos e agentes de IA na mesma página. Contexto, instruções e definições exclusivos para agentes que não aparecem na documentação renderizada.
  </Card>
</Columns>

## Código e dados

<Columns cols={3}>
  <Card title="CodeGroup" icon="layer-group" href="/pt/components/code-group">
    Exiba blocos de código em uma interface com abas. Mostre a mesma operação em várias linguagens, como cURL, Python e JavaScript.
  </Card>
  <Card title="Examples" icon="code" href="/pt/components/examples">
    Fixe blocos de código, com abas de linguagem opcionais, em uma barra lateral direita fixa que permanece visível enquanto o leitor rola a página no desktop.
  </Card>
  <Card title="Fields" icon="list" href="/pt/components/fields">
    Documente parâmetros de API e campos de resposta com os componentes ParamField e ResponseField, incluindo tipos, valores padrão e objetos aninhados.
  </Card>
  <Card title="Prompt" icon="wand-magic-sparkles" href="/pt/components/prompt">
    Use o Prompt para apresentar instruções de IA reutilizáveis, com copiar, ações de abrir em outro aplicativo integradas, destinos personalizados, ícones e opções de exibição compactas.
  </Card>
  <Card title="Tables" icon="table" href="/pt/components/tables">
    Organize dados em linhas e colunas. Use tabelas Markdown ou componentes Table com ordenação, destaque e mesclagem de células.
  </Card>
</Columns>

## Diagramas e recursos visuais

<Columns cols={3}>
  <Card title="Color" icon="palette" href="/pt/components/color">
    O componente Color exibe paletas de cores para sistemas de design, diretrizes de marca ou qualquer especificação de cor.
  </Card>
  <Card title="Mermaid Diagrams" icon="diagram-project" href="/pt/components/mermaid">
    Renderize fluxogramas, diagramas de sequência, linhas do tempo, gráficos de pizza e mais a partir da sintaxe de texto do Mermaid. Os diagramas são gerados como SVG no momento do build.
  </Card>
  <Card title="D2 Diagrams" icon="diagram-project" href="/pt/components/d2">
    Renderize diagramas de arquitetura, fluxogramas, sequências e modelos SQL a partir da sintaxe de texto do D2. Os diagramas são renderizados como SVG que segue o tema do site.
  </Card>
</Columns>
