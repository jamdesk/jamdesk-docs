title: Expandable
description: >-
  Expandable oculta detalhes complementares, respostas longas de API e etapas de solução de problemas em um único bloco recolhível, alternativa mais leve que Accordion
---

Use Expandable para ocultar respostas longas de API, etapas de solução de problemas ou detalhes extras que quebrariam a leitura. Ele é exibido como um único bloco clicável. É mais leve que Accordion, que serve para seções agrupadas e navegáveis.

Use Expandable quando:
- **Detalhes complementares** interromperiam a narrativa principal
- **Informações opcionais** interessam a alguns leitores, mas não a todos
- **Conteúdo extenso** (como respostas completas de API) deve ficar recolhido por padrão

## Uso básico

<Expandable title="Mostrar mais detalhes">
  Estes detalhes ficam ocultos por padrão e são revelados ao clicar.
</Expandable>

```mdx
<Expandable title="Show more details">
  These details are hidden by default and revealed when clicked.
</Expandable>
```

## Aberto por padrão

Comece expandido:

<Expandable title="Expandido por padrão" defaultOpen>
  Esta seção começa visível.
</Expandable>

```mdx
<Expandable title="Expanded by default" defaultOpen>
  This section starts visible.
</Expandable>
```

## Casos de uso comuns

### Detalhes da resposta da API

Recolha respostas longas:

<Expandable title="Ver resposta completa">
```json
{
  "id": "123",
  "name": "Example",
  "metadata": {
    "created": "2024-01-01",
    "updated": "2024-01-15"
  }
}
```
</Expandable>

### Etapas de solução de problemas

<Expandable title="Com problemas de conexão?">
  1. Verifique sua conexão de rede
  2. Confirme que o endpoint da API está correto
  3. Garanta que sua chave de API é válida
</Expandable>

## Props

<ParamField name="title" type="string" required>
  Texto do cabeçalho da seção.
</ParamField>

<ParamField name="defaultOpen" type="boolean" default="false">
  Começar expandido.
</ParamField>

## Expandable vs Accordion

| Recurso | Expandable | Accordion |
|---------|------------|-----------|
| Finalidade | Ocultar conteúdo complementar | Organizar seções de igual importância |
| Ícones | Não | Sim |
| Descrições | Não | Sim (suporte a subtítulo) |
| Agrupamento | Independente | Pode ser agrupado com AccordionGroup |
| Ideal para | Detalhes opcionais, exemplos longos | FAQs, listas de recursos, navegação |

**Regra prática:** se o conteúdo é "bom saber", use Expandable. Se o leitor escolhe entre seções, use Accordion.
