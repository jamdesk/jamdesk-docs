Este plugin dá ao [Claude Code](https://claude.ai/code) o conhecimento sobre Jamdesk que você precisaria explicar em cada prompt: quais componentes existem, como funciona o `docs.json` e quais são os comandos da CLI.

<Note>
  Você precisa ter o Claude Code instalado primeiro. Obtenha em [claude.ai/code](https://claude.ai/code).
</Note>

## Instalação

<Steps>
  <Step title="Adicione o marketplace">
    Execute este comando de barra no Claude Code:

    ```text
    /plugin marketplace add jamdesk/jamdesk-claude-plugin
    ```
  </Step>
  <Step title="Instale o plugin">
    ```text
    /plugin install jamdesk@jamdesk-marketplace
    ```
  </Step>
</Steps>

Você também pode encontrá-lo executando `/plugin` e selecionando **Discover**.

<Accordion title="Instalação manual (para desenvolvimento ou testes)">
  ```bash
  git clone https://github.com/jamdesk/jamdesk-claude-plugin.git
  claude --plugin-dir ./jamdesk-claude-plugin
  ```
</Accordion>

## O que está incluído

O plugin tem uma skill, `/jamdesk:jamdesk`. Ela contém um hub de referência rápida e três arquivos de referência carregados sob demanda:

| Referência | O que cobre |
|-----------|---------------|
| **Componentes** | Mais de 25 componentes MDX (Cards, Steps, Tabs, Callouts, Code Groups, Tables e outros) com props completas e exemplos |
| **Configuração** | Esquema completo do `docs.json`: temas, cores, identidade visual, navbar, footer, configuração de API, mais de 20 integrações de análise |
| **Navegação** | 8 padrões de navegação: plana, agrupada, com abas, multiprodutos, versionada, multilíngue, dropdowns, OpenAPI |

O hub também lista os 19 comandos da CLI, os campos de frontmatter das páginas, a sintaxe de dimensionamento de imagens, os padrões de escrita e erros comuns.

## Uso

Execute `/jamdesk:jamdesk` enquanto trabalha na documentação Jamdesk.

O Claude pode ativar a skill automaticamente em um projeto com um `docs.json`.

O Claude responde perguntas comuns, como sintaxe de componentes e comandos da CLI, a partir do hub. Ele carrega um arquivo de referência para tabelas completas de props, opções de configuração ou detalhes de padrões de navegação.

## Uso com CLAUDE.md e MCP

O plugin funciona melhor em uma configuração de três camadas:

1. O plugin ensina ao Claude sobre a plataforma Jamdesk: componentes, configuração, navegação, CLI.
2. [CLAUDE.md](/pt/ai/claude-code) ensina ao Claude sobre as convenções *do seu projeto*: estilo de escrita, terminologia, estrutura de páginas.
3. O [servidor MCP](/pt/ai/mcp-server) permite que o Claude pesquise e leia sua documentação publicada.

Você não precisa das três. O plugin é útil por conta própria. Um CLAUDE.md e uma conexão MCP permitem que o Claude corresponda ao tom do seu site e crie links para páginas existentes.
