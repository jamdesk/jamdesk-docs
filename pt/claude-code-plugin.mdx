Sempre que você pede ao Claude para escrever uma página do Jamdesk, acaba explicando as mesmas coisas: quais componentes existem, como o `docs.json` funciona e quais são os comandos da CLI. Este plugin fornece esse conhecimento ao [Claude Code](https://claude.ai/code) antecipadamente, para que você possa ignorar a introdução e começar diretamente a criar.

<Note>
  Você precisa instalar o Claude Code primeiro. Faça o download em [claude.ai/code](https://claude.ai/code).
</Note>

## Instalação

<Steps>
  <Step title="Adicionar o marketplace">
    Execute este comando slash no Claude Code:

    ```text
    /plugin marketplace add jamdesk/jamdesk-claude-plugin
    ```
  </Step>
  <Step title="Instalar o plugin">
    ```text
    /plugin install jamdesk@jamdesk-marketplace
    ```
  </Step>
</Steps>

Você também pode encontrá-lo executando `/plugin` e selecionando **Discover**.

<Accordion title="Instalação manual (para desenvolvimento ou testes)">
  ```bash
  git clone https://github.com/jamdesk/jamdesk-claude-plugin.git
  claude --plugin-dir ./jamdesk-claude-plugin
  ```
</Accordion>

## O que está incluído

Uma skill (`/jamdesk:jamdesk`) com um hub de referência rápida e três arquivos de referência detalhados carregados sob demanda:

| Referência | Conteúdo |
|-----------|----------|
| **Componentes** | Mais de 25 componentes MDX (Cards, Steps, Tabs, Callouts, Code Groups, Tables e outros), com todas as props e exemplos |
| **Configuração** | Schema completo do `docs.json`: temas, cores, identidade visual, barra de navegação, rodapé, configuração de API e mais de 20 integrações de analytics |
| **Navegação** | 8 padrões de navegação: simples, agrupada, com abas, para vários produtos, com versões, multilíngue, menus suspensos e OpenAPI |

O hub também inclui todos os 19 comandos da CLI, campos de frontmatter das páginas, sintaxe para dimensionamento de imagens, padrões de escrita e erros comuns.

## Uso

Ao trabalhar na documentação do Jamdesk, execute `/jamdesk:jamdesk`.

Se o projeto tiver um `docs.json`, o Claude poderá ativar a skill automaticamente.

Perguntas comuns (sintaxe de componentes e comandos da CLI) são respondidas diretamente pelo hub. Precisa de tabelas completas de props, todas as opções de configuração ou detalhes sobre padrões de navegação? O Claude carrega o arquivo de referência específico.

## Uso com CLAUDE.md e MCP

Funciona melhor como parte de uma configuração em três camadas:

1. O plugin ensina ao Claude sobre a plataforma do Jamdesk: componentes, configuração, navegação e CLI.
2. [CLAUDE.md](/pt/ai/claude-code) ensina ao Claude as convenções *do seu projeto*: estilo de escrita, terminologia e estrutura das páginas.
3. O [servidor MCP](/pt/ai/mcp-server) dá ao Claude acesso à sua documentação publicada, permitindo pesquisar, ler conteúdo e verificar páginas existentes.

Você não precisa das três camadas. O plugin é útil por si só. No entanto, combinado com um CLAUDE.md e uma conexão MCP, o Claude pode escrever páginas que correspondem à voz do seu site e criar links para o conteúdo existente sem fazer suposições.

## Atualização e código-fonte

Verifique se há atualizações executando `/plugin` no Claude Code. Você também pode executar novamente o comando de instalação para obter a versão mais recente.

O plugin é de código aberto (Apache 2.0). Consulte o código-fonte, registre problemas ou contribua: [github.com/jamdesk/jamdesk-claude-plugin](https://github.com/jamdesk/jamdesk-claude-plugin). [Registro de alterações](https://github.com/jamdesk/jamdesk-claude-plugin/blob/main/CHANGELOG.md).
