Você faz push para o GitHub (ou executa `jamdesk deploy`), o Jamdesk faz o build do site e as alterações entram no ar. Esse é o ciclo. As páginas desta seção abordam cada parte dele: a CLI que você usará diariamente, o que acontece durante um build, de onde seu site é servido e os analytics que o Jamdesk coleta em cada página sem scripts adicionais.

<Tip>
  **Build falhando?** [Solução de problemas de build](/pt/builds/troubleshooting) associa mensagens de erro comuns às respectivas causas e soluções.
</Tip>
