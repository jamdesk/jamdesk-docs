Faça push para o GitHub (ou execute `jamdesk deploy`). O Jamdesk gera o build do site. As alterações entram no ar. Esta seção aborda a CLI, o que acontece durante um build, de onde o seu site é servido e as análises que o Jamdesk coleta em cada página sem scripts extras.

<Tip>
  **Build falhando?** [Solução de problemas de build](/pt/builds/troubleshooting) relaciona as mensagens de erro mais comuns às causas e correções.
</Tip>
