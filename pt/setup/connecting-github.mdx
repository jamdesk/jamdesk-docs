O Jamdesk implanta sua documentação automaticamente quando você envia alterações para o GitHub.

As capturas de tela mostram a interface em inglês.

<Note>
Para entender como o GitHub App e a vinculação da conta pessoal funcionam em conjunto, consulte [Entenda a integração com o GitHub](/pt/integrations/github).
</Note>

<Tip>
Sua documentação está no Bitbucket Cloud? Consulte [Conectar Bitbucket](/pt/setup/connecting-bitbucket). Cada projeto se conecta a um único provedor.
</Tip>

## Instalação do GitHub App

O Jamdesk solicita que você instale o Jamdesk GitHub App na primeira vez que entrar. O app permite:

- **Acesso ao repositório**: ler o conteúdo da sua documentação
- **Webhooks**: iniciar builds quando houver um push
- **Status do commit**: mostrar o status do build nos commits

### Permissões

O Jamdesk GitHub App solicita as seguintes permissões:

| Permissão | Finalidade |
|------------|---------|
| Conteúdo do repositório (leitura e gravação) | Clonar e ler seus arquivos de documentação. A gravação ocorre somente quando você salva no editor do dashboard, aceita sugestões de Fix with AI ou ativa a tradução |
| Metadados (leitura) | Listar repositórios e branches |
| Webhooks | Receber notificações de push |

<Note>
O Jamdesk acessa apenas os repositórios aos quais você concede acesso explicitamente. Altere o acesso a qualquer momento nas configurações do GitHub.
</Note>

## Conectar um repositório

<Steps>
  <Step title="Selecionar repositório">
    Clique em **Connect Repository** ao criar ou editar um projeto.

    Escolha entre os repositórios nos quais o GitHub App está instalado.
  </Step>

  <Step title="Escolher branch">
    Selecione a branch para implantação:

    - **main** ou **master**: as opções mais comuns para documentação de produção
    - **docs**: se você mantém a documentação em uma branch separada
    - Qualquer branch: para implantações de prévia
  </Step>

  <Step title="Especificar o caminho da documentação">
    Se o arquivo `docs.json` não estiver na raiz do repositório, especifique o caminho:

    ```bash
    docs/           # Docs in a subdirectory
    packages/docs/  # Monorepo with docs package
    ```

    Deixe em branco se `docs.json` estiver na raiz.
  </Step>
</Steps>

O dashboard do projeto mostra o repositório e a branch vinculados:

## Deploys automáticos

Cada push para a branch configurada inicia um build:

```bash
git add .
git commit -m "Update API documentation"
git push origin main
```

Os builds geralmente são concluídos em 30 a 90 segundos. Consulte o status no dashboard ou no commit do GitHub.

## Alterar repositórios

Para conectar outro repositório:

1. Acesse **Settings** → **Repository**
2. Clique em **Change Repository**
3. Selecione o novo repositório e a branch

<Warning>
Alterar repositórios pode afetar sua documentação publicada. O novo repositório precisa conter uma configuração válida do Jamdesk.
</Warning>

## Gerenciar o acesso do GitHub App

Controle quais repositórios o Jamdesk pode acessar:

1. Acesse [github.com/settings/installations](https://github.com/settings/installations)
2. Encontre **Jamdesk** na lista
3. Clique em **Configure**
4. Em "Repository access", selecione repositórios específicos ou todos

### Repositórios de organizações

Um administrador da organização precisa aprovar a instalação do GitHub App para os repositórios da organização:

1. Solicite a instalação pelo dashboard do Jamdesk
2. Um administrador recebe uma notificação no GitHub
3. Os repositórios da organização aparecem no seletor de repositórios após a aprovação

## Vincular sua conta pessoal

Vincule sua conta pessoal do GitHub em **User Settings** para atribuir os builds corretamente:

1. Clique no seu avatar → **User Settings**
2. Encontre a seção **GitHub Account**
3. Clique em **Link GitHub Account**

Esse vínculo é separado do GitHub App. Ele atribui seus commits a você. [Saiba mais](/pt/integrations/github#conta-pessoal-do-github-nível-do-usuário).

## Solução de problemas

### Repositório não aparece

- Verifique se o GitHub App está instalado no repositório
- Para repositórios de uma organização, confirme se um administrador aprovou o acesso
- Atualize a lista de repositórios no dashboard

### O GitHub continua redirecionando você para a página do app do Jamdesk

Provavelmente, sua empresa gerencia sua conta do GitHub. O GitHub não permite que essas contas instalem apps na própria conta. Consulte [contas do GitHub gerenciadas pela empresa](/pt/help/troubleshooting/github-issues#contas-github-gerenciadas-pela-empresa) para resolver o problema.

### Os builds não são acionados

- Verifique se o webhook está ativo nas configurações do repositório
- Confirme se você está enviando alterações para a branch configurada
- Procure erros de entrega do webhook no GitHub

### Erros de permissão negada

- Autorize novamente o GitHub App nas configurações do GitHub
- Confirme se o Jamdesk App pode acessar o repositório
