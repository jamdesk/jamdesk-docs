O Jamdesk integra-se ao GitHub para fazer o deploy automático da sua documentação quando você envia alterações.

As capturas de tela mostram a interface em inglês.

<Note>
Para entender como o GitHub App e a vinculação da conta pessoal funcionam juntos, consulte [Entendendo a integração com o GitHub](/pt/integrations/github).
</Note>

<Tip>
A documentação está no Bitbucket Cloud? Consulte [Conectar Bitbucket](/pt/setup/connecting-bitbucket). Cada projeto se conecta a um único provedor.
</Tip>

## Instalação do GitHub App

Quando você entrar no Jamdesk pela primeira vez, será solicitado que instale o Jamdesk GitHub App. Esse app permite:

- **Acesso ao repositório** - Ler o conteúdo da sua documentação
- **Webhooks** - Acionar builds a cada push
- **Status do commit** - Mostrar o status do build nos commits

### Permissões

O Jamdesk GitHub App solicita estas permissões:

| Permissão | Finalidade |
|------------|---------|
| Conteúdo do repositório (leitura) | Clonar e ler os arquivos da sua documentação |
| Metadados (leitura) | Listar repositórios e branches |
| Webhooks | Receber notificações de push |

<Note>
O Jamdesk acessa apenas os repositórios aos quais você concedeu acesso explicitamente. Você pode modificar o acesso a qualquer momento nas configurações do GitHub.
</Note>

## Conectar um repositório

<Steps>
  <Step title="Selecionar o repositório">
    Ao criar ou editar um projeto, clique em **Connect Repository**.

    Escolha entre os repositórios nos quais o GitHub App está instalado.
  </Step>

  <Step title="Escolher a branch">
    Selecione a branch para o deploy:

    - **main** ou **master** - As mais comuns para documentação em produção
    - **docs** - Se você mantém a documentação em uma branch separada
    - Qualquer branch - Para deploys de preview
  </Step>

  <Step title="Especificar o caminho da documentação">
    Se o seu `docs.json` não estiver na raiz do repositório, especifique o caminho:

    ```bash
    docs/           # Docs in a subdirectory
    packages/docs/  # Monorepo with docs package
    ```

    Deixe em branco se o `docs.json` estiver na raiz.
  </Step>
</Steps>

Depois de conectado, o dashboard do projeto mostra o repositório e a branch vinculados:

## Implantações automáticas

Depois de conectado, cada push para a branch configurada aciona um build:

```bash
git add .
git commit -m "Update API documentation"
git push origin main
```

Os builds geralmente são concluídos em 30–90 segundos. Consulte o status no dashboard ou no commit do GitHub.

## Alterar repositórios

Para conectar um repositório diferente:

1. Acesse **Settings** → **Repository**
2. Clique em **Change Repository**
3. Selecione o novo repositório e a branch

<Warning>
Alterar os repositórios pode afetar sua documentação publicada. O novo repositório deve conter uma configuração válida do Jamdesk.
</Warning>

## Gerenciar o acesso do GitHub App

Controle quais repositórios o Jamdesk pode acessar:

1. Acesse [github.com/settings/installations](https://github.com/settings/installations)
2. Encontre **Jamdesk** na lista
3. Clique em **Configure**
4. Em "Repository access", selecione repositórios específicos ou todos

### Repositórios da organização

Para repositórios de organizações, um administrador da organização deve aprovar a instalação do GitHub App:

1. Solicite a instalação no dashboard do Jamdesk
2. Um administrador receberá uma notificação no GitHub
3. Depois da aprovação, os repositórios da organização aparecerão no seletor de repositórios

## Vincular sua conta pessoal

Para atribuir os builds de forma confiável, vincule sua conta pessoal do GitHub em **User Settings**:

1. Clique no seu avatar → **User Settings**
2. Encontre a seção **GitHub Account**
3. Clique em **Link GitHub Account**

Isso é separado do GitHub App e garante que seus commits sejam atribuídos corretamente a você. [Saiba mais](/pt/integrations/github#conta-pessoal-do-github-nível-do-usuário).

## Solução de problemas

### Repositório não aparece

- Verifique se o GitHub App está instalado no repositório
- Para repositórios de organizações, confirme se um administrador aprovou o acesso
- Tente atualizar a lista de repositórios no dashboard

### Builds não são acionados

- Verifique se o webhook está ativo nas configurações do repositório
- Confirme se você está enviando alterações para a branch configurada
- Procure erros de entrega do webhook no GitHub

### Erros de permissão negada

- Autorize novamente o GitHub App nas configurações do GitHub
- Verifique se o repositório está acessível ao Jamdesk App
