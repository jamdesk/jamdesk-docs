O Jamdesk se integra ao GitHub para implantar automaticamente sua documentação quando você envia alterações.

As capturas de tela mostram a interface em inglês.

<Note>
Para entender como o GitHub App e a vinculação da conta pessoal funcionam em conjunto, consulte [Entenda a integração com o GitHub](/pt/integrations/github).
</Note>

<Tip>
Sua documentação está no Bitbucket Cloud? Consulte [Conectar Bitbucket](/pt/setup/connecting-bitbucket). Cada projeto se conecta a um único provedor.
</Tip>

## Instalação do GitHub App

Ao entrar no Jamdesk pela primeira vez, você receberá uma solicitação para instalar o GitHub App do Jamdesk. Esse app permite:

- **Repository access** - Ler o conteúdo da sua documentação
- **Webhooks** - Iniciar builds quando houver um push
- **Commit status** - Mostrar o status do build nos commits

### Permissões

O GitHub App do Jamdesk solicita estas permissões:

| Permissão | Finalidade |
|------------|---------|
| Repository contents (read and write) | Clonar e ler os arquivos da sua documentação. A gravação ocorre somente quando você salva no editor do dashboard, aceita sugestões de Fix with AI ou ativa a tradução |
| Metadata (read) | Listar repositórios e branches |
| Webhooks | Receber notificações de push |

<Note>
O Jamdesk só acessa os repositórios aos quais você concede acesso explicitamente. Você pode alterar o acesso a qualquer momento nas configurações do GitHub.
</Note>

## Conectar um repositório

<Steps>
  <Step title="Selecionar repositório">
    Ao criar ou editar um projeto, clique em **Connect Repository**.

    Escolha entre os repositórios nos quais o GitHub App está instalado.
  </Step>

  <Step title="Escolher branch">
    Selecione a branch para implantação:

    - **main** ou **master** - As opções mais comuns para documentação de produção
    - **docs** - Se você mantém a documentação em uma branch separada
    - Qualquer branch - Para implantações de pré-visualização
  </Step>

  <Step title="Especificar o caminho da documentação">
    Se o arquivo `docs.json` não estiver na raiz do repositório, especifique o caminho:

    ```bash
    docs/           # Docs in a subdirectory
    packages/docs/  # Monorepo with docs package
    ```

    Deixe em branco se `docs.json` estiver na raiz.
  </Step>
</Steps>

Depois da conexão, o dashboard do projeto mostra o repositório e a branch vinculados:

## Deploys automáticos

Depois da conexão, cada push para a branch configurada inicia um build:

```bash
git add .
git commit -m "Update API documentation"
git push origin main
```

Os builds geralmente são concluídos em 30 a 90 segundos. Consulte o status no dashboard ou no commit do GitHub.

## Alterar repositórios

Para conectar outro repositório:

1. Acesse **Settings** → **Repository**
2. Clique em **Change Repository**
3. Selecione o novo repositório e a branch

<Warning>
A alteração de repositórios pode afetar sua documentação publicada. O novo repositório precisa conter uma configuração válida do Jamdesk.
</Warning>

## Gerenciar o acesso do GitHub App

Controle quais repositórios o Jamdesk pode acessar:

1. Acesse [github.com/settings/installations](https://github.com/settings/installations)
2. Encontre **Jamdesk** na lista
3. Clique em **Configure**
4. Em "Repository access", selecione repositórios específicos ou todos

### Repositórios de organizações

Para repositórios de organizações, um administrador da organização precisa aprovar a instalação do GitHub App:

1. Solicite a instalação pelo dashboard do Jamdesk
2. Um administrador receberá uma notificação no GitHub
3. Após a aprovação, os repositórios da organização aparecerão no seletor de repositórios

## Vincular sua conta pessoal

Para atribuir os builds corretamente, vincule sua conta pessoal do GitHub em **User Settings**:

1. Clique no seu avatar → **User Settings**
2. Encontre a seção **GitHub Account**
3. Clique em **Link GitHub Account**

Essa vinculação é separada do GitHub App e garante que seus commits sejam atribuídos corretamente a você. [Saiba mais](/pt/integrations/github#conta-pessoal-do-github-nível-do-usuário).

## Solução de problemas

### Repositório não aparece

- Verifique se o GitHub App está instalado no repositório
- Para repositórios de organizações, confirme se um administrador aprovou o acesso
- Tente atualizar a lista de repositórios no dashboard

### O GitHub continua redirecionando você para a página do app do Jamdesk

Provavelmente, sua empresa gerencia sua conta do GitHub, e o GitHub não permite que essas contas instalem apps na própria conta. Consulte [contas do GitHub gerenciadas pela empresa](/pt/help/troubleshooting/github-issues#contas-github-gerenciadas-pela-empresa) para resolver o problema.

### Os builds não são acionados

- Verifique se o webhook está ativo nas configurações do repositório
- Confirme se você está enviando alterações para a branch configurada
- Verifique se há erros de entrega de webhook no GitHub

### Erros de permissão negada

- Autorize novamente o GitHub App nas configurações do GitHub
- Verifique se o repositório está acessível ao Jamdesk App
