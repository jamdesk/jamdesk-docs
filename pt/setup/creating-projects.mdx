Você precisa de um projeto antes de escrever qualquer documentação. Comece a partir de um modelo para que o Jamdesk crie o repositório no GitHub ou no Bitbucket Cloud. Ou conecte um repositório existente que já tenha um `docs.json`. Seu site fica online em alguns minutos. Para começar sem uma conta no GitHub, veja [Documentação sem GitHub](/pt/setup/without-github).

## Criar um novo projeto

<Steps>
  <Step title="Entre no Jamdesk">
    Acesse [dashboard.jamdesk.com](https://dashboard.jamdesk.com) e entre com sua conta do GitHub.

    O Jamdesk pede que você autorize o GitHub App do Jamdesk no primeiro login.
  </Step>

  <Step title="Clique em New Project">
    No painel, clique em **New Project** no canto superior direito.
  </Step>

  <Step title="Escolha um ponto de partida">
    <Tabs>
      <Tab title="A partir de um modelo">
        Comece com um modelo pré-criado. O Jamdesk cria um novo repositório no GitHub com conteúdo de exemplo, navegação e componentes já configurados.

        O [Starter Template](https://github.com/jamdesk/starter-docs) padrão inclui páginas de exemplo, uma especificação OpenAPI e exemplos de todos os componentes. Substitua o conteúdo pelo seu.
      </Tab>
      <Tab title="A partir de um repositório">
        Conecte um repositório GitHub existente:

        1. Selecione o repositório no menu suspenso
        2. Escolha a branch para deploy (normalmente `main`)
        3. Especifique o caminho para `docs.json`, se ele não estiver na raiz

        Repositório no Bitbucket Cloud? Informe-o no formato `workspace/repository-slug`. Veja [Conectar Bitbucket](/pt/setup/connecting-bitbucket).
      </Tab>
    </Tabs>
  </Step>

  <Step title="Configure as definições do projeto">
    Defina as informações básicas do seu projeto:

    | Campo | Descrição |
    |-------|-------------|
    | **Name** | Nome de exibição mostrado no painel |
    | **Slug** | Identificador amigável para URL (ex.: `my-docs`) |
    | **Domain** | Seu subdomínio `*.jamdesk.app` |
  </Step>
</Steps>

## Estrutura mínima do repositório

Um projeto Jamdesk precisa apenas de um `docs.json` e de pelo menos uma página:

```bash
my-docs/
├── docs.json
└── introduction.mdx
```

Exemplo de `docs.json`:

```json docs.json
{
  "$schema": "https://jamdesk.com/docs.json",
  "name": "My Docs",
  "theme": "jam",
  "navigation": {
    "groups": [
      {
        "group": "Getting Started",
        "pages": ["introduction"]
      }
    ]
  }
}
```

## Configurações do projeto

Configure seu projeto em **Settings**:

### General

- **Name**: atualize o nome de exibição
- **Slug**: altere o identificador do projeto
- **Delete Project**: remove o projeto permanentemente

### Repository

- **Branch**: qual branch dispara os deploys
- **Docs Path**: localização do `docs.json` para monorepos

### Domain

- **Subdomain**: sua URL `*.jamdesk.app`
- **Custom Domain**: adicione seu próprio domínio
- **Host at a subpath**: sirva a documentação em um caminho como `/docs` ou `/help` em vez da raiz do site

### Build

- **Show Jamdesk Branding**: exibe o link "Powered by Jamdesk" no rodapé (ativado por padrão)
- **Rebuild**: dispara manualmente um novo build

<Note>
As alterações nas configurações de build exigem um novo build para terem efeito.
</Note>

## Limites do projeto

O plano Pro inclui um projeto. Adicione mais com [complementos de projeto](/pt/help/billing/project-addons) por US$ 15/mês cada.
