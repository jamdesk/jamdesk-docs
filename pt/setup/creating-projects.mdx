Antes de escrever qualquer documentação, você precisa de um projeto. Você pode começar com um template (o Jamdesk cria o repositório para você no GitHub ou no Bitbucket Cloud) ou conectar um repositório existente que já tenha um `docs.json`. De qualquer forma, seu site estará online em poucos minutos.

## Criar um novo projeto

<Steps>
  <Step title="Iniciar sessão no Jamdesk">
    Acesse [dashboard.jamdesk.com](https://dashboard.jamdesk.com) e inicie sessão com sua conta do GitHub.

    Usuários de primeira viagem receberão uma solicitação para autorizar o aplicativo do GitHub do Jamdesk.
  </Step>

  <Step title="Clique em New Project">
    No dashboard, clique em **New Project** no canto superior direito.
  </Step>

  <Step title="Escolha um ponto de partida">
    <Tabs>
      <Tab title="From Template">
        Comece com um template pré-configurado. O Jamdesk cria um novo repositório do GitHub para você, com conteúdo de exemplo, navegação e componentes já configurados.

        O [Starter Template](https://github.com/jamdesk/starter-docs) padrão inclui páginas de exemplo, uma especificação OpenAPI e exemplos de todos os componentes. Substitua o conteúdo pelo seu e pronto.
      </Tab>
      <Tab title="From Repository">
        Conecte um repositório existente do GitHub:

        1. Selecione o repositório no menu suspenso
        2. Escolha a branch para fazer deploy (geralmente `main`)
        3. Especifique o caminho para `docs.json` caso ele não esteja na raiz

        O repositório está no Bitbucket Cloud? Insira-o como `workspace/repository-slug`. Consulte [Conectar Bitbucket](/pt/setup/connecting-bitbucket).
      </Tab>
    </Tabs>
  </Step>

  <Step title="Configure as configurações do projeto">
    Defina as informações básicas do seu projeto:

    | Campo | Descrição |
    |-------|-------------|
    | **Name** | Nome exibido no dashboard |
    | **Slug** | Identificador compatível com URL (por exemplo, `my-docs`) |
    | **Domain** | Seu subdomínio `*.jamdesk.app` |
  </Step>
</Steps>

## Estrutura mínima do repositório

Um projeto Jamdesk precisa apenas de um `docs.json` e pelo menos uma página:

```bash
my-docs/
├── docs.json
└── introduction.mdx
```

Exemplo de `docs.json`:

```json docs.json
{
  "$schema": "https://jamdesk.com/docs.json",
  "name": "My Docs",
  "theme": "jam",
  "navigation": {
    "groups": [
      {
        "group": "Getting Started",
        "pages": ["introduction"]
      }
    ]
  }
}
```

## Configurações do projeto

Após a criação, configure seu projeto em **Settings**:

### General

- **Name** - Atualize o nome exibido
- **Slug** - Altere o identificador do projeto
- **Delete Project** - Remova o projeto permanentemente

### Repository

- **Branch** - A branch que aciona os deploys
- **Docs Path** - Localização de `docs.json` em monorepos

### Domain

- **Subdomain** - Sua URL `*.jamdesk.app`
- **Custom Domain** - Adicione seu próprio domínio
- **Host at a subpath** - Disponibilize a documentação em um caminho como `/docs` ou `/help`, em vez da raiz do site

### Build

- **Show Jamdesk Branding** - Exiba o link “Powered by Jamdesk” no rodapé (ativado por padrão)
- **Rebuild** - Acione manualmente um novo build

<Note>
Alterações nas configurações de build exigem um novo build para entrarem em vigor.
</Note>
