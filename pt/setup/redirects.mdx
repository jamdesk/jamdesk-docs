Redirecionamentos levam os leitores de URLs antigas para novas. Use-os quando você reorganizar a documentação, renomear páginas ou quiser manter funcionando os links de versões anteriores da documentação.

## Configuração

Adicione redirecionamentos ao seu `docs.json`:

```json docs.json
{
  "redirects": [
    {
      "source": "/old-page",
      "destination": "/new-page"
    },
    {
      "source": "/guides/setup",
      "destination": "/getting-started"
    }
  ]
}
```

## Tipos de redirecionamento

### Correspondência exata

Redireciona uma URL específica:

```json
{
  "source": "/api/v1/users",
  "destination": "/api/v2/users"
}
```

`/api/v1/users` → `/api/v2/users`

### Correspondência curinga

Use `*` para corresponder a segmentos de caminho:

```json
{
  "source": "/blog/*",
  "destination": "/articles/*"
}
```

`/blog/hello-world` → `/articles/hello-world`

### Correspondência por prefixo

Redirecione todos os caminhos sob um prefixo:

```json
{
  "source": "/v1/*",
  "destination": "/v2/*"
}
```

`/v1/api/users` → `/v2/api/users`

## Códigos de status HTTP

Os redirecionamentos retornam `308` (redirecionamento permanente) por padrão. Defina outro status:

```json
{
  "source": "/old-page",
  "destination": "/new-page",
  "statusCode": 307
}
```

| Status | Tipo | Caso de uso |
|--------|------|----------|
| `301` | Permanente (GET) | Movido permanentemente, altera POST para GET |
| `302` | Temporário (GET) | Movimentação temporária, altera POST para GET |
| `307` | Temporário | Movimentação temporária, preserva o método HTTP |
| `308` | Permanente | Movido permanentemente, preserva o método HTTP |

Use `308` para a maioria dos redirecionamentos de documentação. Use `307` para movimentações temporárias durante migrações.

## Padrões comuns

### Reorganizar a documentação

```json
{
  "redirects": [
    { "source": "/setup", "destination": "/getting-started" },
    { "source": "/setup/install", "destination": "/getting-started/installation" },
    { "source": "/setup/config", "destination": "/getting-started/configuration" }
  ]
}
```

### Migração de versão da API

```json
{
  "redirects": [
    { "source": "/api/v1/*", "destination": "/api/v2/*" }
  ]
}
```

### Redirecionamentos externos

```json
{
  "source": "/community",
  "destination": "https://discord.gg/your-server"
}
```

### Preservar o SEO

Mantenha o ranqueamento em buscas de páginas movidas com um redirecionamento permanente:

```json
{
  "redirects": [
    {
      "source": "/tutorials/getting-started-with-api",
      "destination": "/quickstart",
      "statusCode": 301
    }
  ]
}
```

## Ordem dos redirecionamentos

Os redirecionamentos são avaliados em ordem. Coloque as regras específicas antes dos curingas:

```json
{
  "redirects": [
    { "source": "/api/v1/special-endpoint", "destination": "/api/special" },
    { "source": "/api/v1/*", "destination": "/api/v2/*" }
  ]
}
```

A primeira regra correspondente prevalece.

## Limitações

- Os redirecionamentos se aplicam apenas a caminhos da documentação
- Parâmetros de consulta são preservados automaticamente
- Fragmentos de hash são preservados automaticamente
- Máximo de 1000 redirecionamentos por projeto

## Testar redirecionamentos

1. Faça o deploy das suas alterações
2. Acesse a URL antiga diretamente
3. Verifique se você chega ao novo destino
4. Confira o código de status HTTP nas ferramentas de desenvolvedor do navegador

```bash
# Check redirect with curl
curl -I https://docs.example.com/old-page
```
