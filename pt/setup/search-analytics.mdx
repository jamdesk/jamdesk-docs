Veja o que os leitores pesquisam, quais consultas não retornam resultados e em quais resultados eles clicam.

<Info>
Procurando dados de visualizações de páginas e visitantes? Consulte [Análises do projeto](/pt/setup/project-analytics).
</Info>

<Note>
Se os dados de pesquisa estiverem ausentes ou atrasados, consulte [Problemas de análise](/pt/help/troubleshooting/analytics-issues).
</Note>

## Visualizar análises de pesquisa

Acesse as análises de pesquisa no dashboard do seu projeto:

<Steps>
  <Step title="Abra seu projeto">
    Acesse [dashboard.jamdesk.com](https://dashboard.jamdesk.com) e selecione seu projeto.
  </Step>

  <Step title="Clique em Search Analytics">
    Na barra lateral, em **Analytics**, clique em **Search** para visualizar seu dashboard de pesquisa.
  </Step>

  <Step title="Selecione um período">
    Use o seletor de datas para visualizar os dados de pesquisa de diferentes períodos. O padrão é 30 dias.
  </Step>
</Steps>

## Principais métricas

O dashboard de análises de pesquisa mostra quatro métricas principais:

| Métrica | Descrição |
|--------|-------------|
| **Total Searches** | Número de pesquisas realizadas no período selecionado |
| **Unique Queries** | Termos de pesquisa distintos usados |
| **Zero Results** | Pesquisas que não retornaram correspondências |
| **Click-through Rate** | Porcentagem de pesquisas em que os usuários clicaram em um resultado |

Cada métrica inclui uma comparação com o período anterior, exibida como uma variação percentual.

Exemplo de snapshot:

```json
{
  "period": "Last 30 days",
  "total_searches": 940,
  "unique_queries": 312,
  "zero_results": 42,
  "top_queries": [
    { "query": "authentication", "searches": 84, "ctr": 0.82 },
    { "query": "api keys", "searches": 63, "ctr": 0.71 }
  ]
}
```

## Volume de pesquisa

O gráfico de volume de pesquisa mostra a atividade diária de pesquisas no período selecionado. Use-o para:

- Identificar padrões de uso (tráfego em dias úteis versus fins de semana)
- Detectar picos incomuns que podem indicar links externos ou anúncios
- Acompanhar o crescimento do uso da documentação ao longo do tempo

## Detalhamento das consultas

### Principais pesquisas

Veja os termos de pesquisa mais comuns inseridos pelos usuários. Isso revela:

- **Tópicos populares** - O que os usuários mais precisam
- **Problemas de navegação** - Se os usuários pesquisam itens facilmente encontrados na navegação
- **Lacunas de terminologia** - Se os usuários usam termos diferentes dos seus docs

Para cada consulta, você verá:
- Número de pesquisas
- Número de cliques nos resultados
- Taxa de cliques (CTR)

### Lacunas de conteúdo

<Warning>
Lacunas de conteúdo são pesquisas que não retornaram resultados. Cada uma representa um tópico que seus docs ainda não abordam.
</Warning>

A aba Content Gaps mostra consultas em que os usuários pesquisaram, mas não encontraram nada. Causas comuns:

| Causa | Solução |
|-------|----------|
| Documentação ausente | Crie uma nova página que aborde o tópico |
| Terminologia diferente | Adicione sinônimos ou atualize os títulos |
| Erros de digitação no conteúdo | Corrija a ortografia nos seus docs |
| Recurso ainda não documentado | Adicione-o ao roadmap da documentação |

Revise as lacunas de conteúdo regularmente. A seção Práticas recomendadas abaixo sugere uma frequência semanal.

## Insights de pesquisa

O painel de insights fornece respostas rápidas:

| Insight | O que significa |
|---------|---------------|
| **Avg. Click Position** | Até que ponto os usuários costumam clicar nos resultados (quanto menor, melhor) |
| **Searches per Day** | Volume médio diário de pesquisas |
| **Top Query** | Seu termo de pesquisa mais comum |
| **Most Missed** | A principal consulta sem resultados a ser abordada |

## Práticas recomendadas

<Accordion title="Revise as lacunas de conteúdo semanalmente">
Defina uma tarefa recorrente para revisar as pesquisas sem resultados. Mesmo alguns minutos por semana evitam o acúmulo de dívida de documentação.
</Accordion>

<Accordion title="Use linguagem natural nos títulos">
Os usuários costumam pesquisar usando frases naturais. Se seus títulos corresponderem à forma como os usuários pensam, eles encontrarão o conteúdo mais rapidamente.
</Accordion>

<Accordion title="Adicione sinônimos a páginas importantes">
Se os usuários pesquisarem por "setup", mas sua página se chamar "installation", mencione os dois termos no conteúdo para que a pesquisa o encontre.
</Accordion>

<Accordion title="Acompanhe as melhorias de CTR">
Depois de resolver as lacunas de conteúdo, monitore se as taxas de cliques melhoram. CTR baixo em consultas de alto volume indica que os resultados não correspondem à intenção dos usuários.
</Accordion>

## Pontuação de qualidade da pesquisa

O Jamdesk calcula uma pontuação de qualidade da pesquisa com base na taxa de cliques:

``` text
Score = (Searches with clicks / Total searches) × 100
```

| Pontuação | Classificação |
|-------|--------|
| 90%+ | Excelente |
| 70-89% | Boa |
| 50-69% | Precisa melhorar |
| Abaixo de 50% | Ruim |

## Exportação de dados

Exporte os dados de pesquisa para análises adicionais:

1. Acesse **Analytics** → **Search**
2. Clique em **Export**
3. Escolha o formato CSV ou JSON

## Disponibilidade dos dados

Os dados de análises de pesquisa aparecem depois que o processamento diário é executado às 2h UTC. As pesquisas realizadas hoje aparecerão no dashboard amanhã.

<Note>
Se você acabou de configurar sua documentação, aguarde de 24 a 48 horas para que os dados de pesquisa se acumulem antes de esperar insights relevantes.
</Note>
