Todo site Jamdesk começa da mesma forma: um projeto no dashboard, um repositório do GitHub por trás dele e um arquivo `docs.json` que descreve sua navegação. Esta seção aborda essa configuração inicial, além das decisões estruturais que vale a pena tomar desde o início. É muito mais fácil definir o layout das URLs, os idiomas e o controle de acesso antes de ter cinquenta páginas do que depois.

Migrando de outra plataforma? Vá direto para o [Guia de migração](/pt/setup/migration). O Jamdesk pode automatizar a maior parte da conversão.

## Do repositório ao site publicado

<Steps>
  <Step title="Crie um projeto">
    Comece com um modelo ou conecte um repositório existente do GitHub. Seu site ficará disponível em `yourproject.jamdesk.app`.
  </Step>
  <Step title="Conecte o GitHub">
    Instale o aplicativo do GitHub para que cada push faça o deploy automaticamente.
  </Step>
  <Step title="Organize o repositório">
    Um arquivo `docs.json` e páginas MDX. Esse é todo o contrato.
  </Step>
</Steps>
