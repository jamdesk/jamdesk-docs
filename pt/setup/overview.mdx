Um site Jamdesk é um projeto no dashboard, um repositório GitHub por trás dele e um arquivo `docs.json` que descreve sua navegação. Esta seção cobre essa configuração. Defina cedo a estrutura das URLs, os idiomas e o controle de acesso. Essas decisões são mais difíceis de mudar quando você já tem cinquenta páginas.

Para migrar de outra plataforma, consulte o [Guia de migração](/pt/setup/migration).

## Do repositório ao site publicado

<Steps>
  <Step title="Criar um projeto">
    Comece a partir de um template ou conecte um repositório GitHub existente. Seu site entra no ar em `yourproject.jamdesk.app`.
  </Step>
  <Step title="Conectar o GitHub">
    Instale o GitHub App para que cada push seja implantado automaticamente.
  </Step>
  <Step title="Organizar o repositório">
    Adicione um arquivo `docs.json` e páginas MDX.
  </Step>
</Steps>
