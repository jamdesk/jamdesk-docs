## Entrar

Use as mesmas credenciais do [painel web](https://dashboard.jamdesk.com):

- E-mail e senha
- Login com o Google

Face ID ou Touch ID desbloqueiam o aplicativo após o primeiro login.

## Notificações push

Ative ou desative em **Settings** no aplicativo:

- **Build success**: um deploy é concluído.
- **Build failure**: um build falha. A notificação inclui a mensagem de erro.

As preferências de notificação são definidas por dispositivo. Os alertas podem ir para o seu celular e não para o tablet.

## Somente leitura por design

O aplicativo móvel não dispara rebuilds. Os builds começam quando você faz push para o seu provedor Git. Inicie um rebuild manual pelo [painel web](https://dashboard.jamdesk.com). O aplicativo é um monitor, não um painel de controle.

Use o painel web para alterar configurações do projeto, convidar membros, rotacionar chaves de API ou disparar um rebuild manual.

## Privacidade

O aplicativo se comunica diretamente com o mesmo backend Firebase do painel web. Não há uma camada de API separada nem um relé de análises coletando sua atividade. Os dados do seu projeto nunca saem da infraestrutura da Jamdesk.
