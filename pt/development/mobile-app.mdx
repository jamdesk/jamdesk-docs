## Entrar

Use as mesmas credenciais do [dashboard web](https://dashboard.jamdesk.com):

- Email and password
- Google Sign-In

Após o primeiro login, o Face ID ou Touch ID desbloqueia o app nas próximas inicializações.

## Notificações push

Acesse **Settings** no app para ativar ou desativar:

- **Build success** — receba uma notificação quando um deploy for concluído.
- **Build failure** — receba uma notificação assim que um build falhar, junto com a mensagem de erro.

As preferências de notificação são específicas de cada dispositivo. Assim, você pode receber alertas no celular sem que eles cheguem ao tablet.

## Somente leitura por design

O app móvel não inicia rebuilds. Os builds são iniciados automaticamente quando você envia alterações para seu provedor Git, e qualquer rebuild manual é feito no [dashboard web](https://dashboard.jamdesk.com). O app é um monitor, não um painel de controle — o objetivo é permitir que você verifique sua documentação sem precisar mudar de contexto.

Se precisar gerenciar configurações do projeto, convidar membros, alternar chaves de API ou iniciar um rebuild manual, acesse o dashboard web.

## Privacidade

O app se comunica diretamente com o mesmo back-end Firebase usado pelo dashboard web. Portanto, não há uma camada de API separada entre eles nem um serviço de análise coletando sua atividade. Os dados do seu projeto nunca deixam a infraestrutura do Jamdesk.
