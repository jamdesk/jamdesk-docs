title: Visualização local
description: Visualize sua documentação na sua máquina com a CLI do Jamdesk antes de publicar em produção. As alterações aparecem conforme você edita os arquivos.
---

Execute `jamdesk dev` (ou `npx jamdesk dev`) a partir de um diretório que contenha um `docs.json`. Ele inicia um servidor local com recarregamento automático e busca. Os componentes são renderizados como são em produção.

## Pré-requisitos

- **Node.js 20+** - Verifique com `node --version`
- **Um projeto de documentação** - Com um arquivo de configuração `docs.json`

## Iniciando o servidor de desenvolvimento

<Tabs>
  <Tab title="npm (instalação global)">
    Instale a CLI globalmente e depois execute a partir do diretório da sua documentação:

    ```bash
    npm install -g jamdesk
    cd your-docs
    jamdesk dev
    ```
  </Tab>
  <Tab title="npx (sem instalação)">
    Execute diretamente sem instalar:

    ```bash
    cd your-docs
    npx jamdesk dev
    ```
  </Tab>
</Tabs>

Sua documentação estará disponível em **http://localhost:3000**

## Porta personalizada

A porta padrão é 3000. Passe outra com `--port`:

```bash
jamdesk dev --port 3001
```

Ou defina um padrão permanente em `~/.jamdeskrc`:

```json
{
  "defaultPort": 3001
}
```

## Modo detalhado

Mostre os detalhes do build com a flag `--verbose`:

```bash
jamdesk dev --verbose
```

Isso mostra:
- Detecção de alterações em arquivos
- Tempo de build
- Análise da navegação
- Quaisquer avisos ou erros

## Desempenho na primeira execução

<Note>
A primeira execução de `jamdesk dev` instala as dependências em `~/.jamdesk`. Isso leva de 30 a 60 segundos. As execuções seguintes começam em menos de 5 segundos.
</Note>

Limpe o cache e force uma nova instalação:

```bash
jamdesk clean
jamdesk dev
```

## Solução de problemas

<AccordionGroup>
  <Accordion title="Porta já em uso">
    Outro processo está usando a porta 3000.

    **Opção 1:** Use uma porta diferente
    ```bash
    jamdesk dev --port 3001
    ```

    **Opção 2:** Encontre e encerre o processo
    ```bash
    lsof -i :3000
    kill -9 <PID>
    ```
  </Accordion>

  <Accordion title="docs.json não encontrado">
    Execute o comando a partir do diretório que contém o seu arquivo `docs.json`:

    ```bash
    ls docs.json  # Should show the file
    jamdesk dev
    ```
  </Accordion>

  <Accordion title="Alterações não aparecem">
    1. Verifique o terminal em busca de erros
    2. Force a atualização do navegador (Cmd+Shift+R)
    3. Reinicie o servidor de desenvolvimento
    4. Execute `jamdesk clean` e tente novamente
  </Accordion>

  <Accordion title="Inicialização lenta">
    Execute o diagnóstico:
    ```bash
    jamdesk doctor
    ```

    Ele verifica o seu ambiente e informa os problemas encontrados.
  </Accordion>
</AccordionGroup>
