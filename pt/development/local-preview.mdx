---
title: Visualização local
description: A CLI do Jamdesk permite visualizar a documentação na sua máquina antes de enviá-la para produção. As alterações aparecem instantaneamente durante a edição.
---

Execute `jamdesk dev` (ou `npx jamdesk dev`) em qualquer diretório que contenha um `docs.json` para iniciar um servidor local com atualização automática, pesquisa completa e todos os componentes funcionando exatamente como em produção.

## Pré-requisitos

Antes de começar, verifique se você tem:

- **Node.js 20 ou superior** — verifique com `node --version`
- **Um projeto de documentação** — com um arquivo de configuração `docs.json`

## Iniciando o servidor de desenvolvimento

<Tabs>
  <Tab title="npm (Instalação global)">
    Instale a CLI globalmente e execute-a no diretório da documentação:

    ```bash
    npm install -g jamdesk
    cd your-docs
    jamdesk dev
    ```
  </Tab>
  <Tab title="npx (Sem instalação)">
    Execute diretamente, sem instalar:

    ```bash
    cd your-docs
    npx jamdesk dev
    ```
  </Tab>
</Tabs>

Sua documentação estará disponível em **http://localhost:3000**

## Porta personalizada

A porta padrão é 3000. Se ela estiver em uso, especifique outra:

```bash
jamdesk dev --port 3001
```

Ou defina um padrão permanente em `~/.jamdeskrc`:

```json
{
  "defaultPort": 3001
}
```

## Modo detalhado

Veja informações detalhadas do build com a flag `--verbose`:

```bash
jamdesk dev --verbose
```

Isso mostra:
- Detecção de alterações nos arquivos
- Duração do build
- Análise da navegação
- Avisos ou erros

## Desempenho na primeira execução

<Note>
Na primeira vez que você executar `jamdesk dev`, as dependências serão instaladas em `~/.jamdesk`. Isso leva de 30 a 60 segundos. As execuções seguintes começam em menos de 5 segundos.
</Note>

Para limpar o cache e forçar uma nova instalação:

```bash
jamdesk clean
jamdesk dev
```

## Solução de problemas

<AccordionGroup>
  <Accordion title="Porta já em uso">
    Outro processo está usando a porta 3000.

    **Opção 1:** Use outra porta
    ```bash
    jamdesk dev --port 3001
    ```

    **Opção 2:** Encontre e interrompa o processo
    ```bash
    lsof -i :3000
    kill -9 <PID>
    ```
  </Accordion>

  <Accordion title="docs.json não encontrado">
    Verifique se você está no diretório que contém seu arquivo `docs.json`:

    ```bash
    ls docs.json  # Should show the file
    jamdesk dev
    ```
  </Accordion>

  <Accordion title="As alterações não aparecem">
    Tente estas etapas:
    1. Verifique se há erros no terminal
    2. Atualize o navegador forçadamente (Cmd+Shift+R)
    3. Reinicie o servidor de desenvolvimento
    4. Execute `jamdesk clean` e tente novamente
  </Accordion>

  <Accordion title="Inicialização lenta">
    Execute o diagnóstico:
    ```bash
    jamdesk doctor
    ```

    Isso verifica seu ambiente e identifica problemas.
  </Accordion>
</AccordionGroup>
