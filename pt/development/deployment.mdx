O Jamdesk gerencia a implantação automaticamente. Faça push para sua branch conectada do GitHub e sua documentação ficará disponível em minutos.

## Implantação via CLI

Você também pode fazer a implantação diretamente pelo terminal, sem enviar alterações para o GitHub. Isso é útil para iterações rápidas, testar alterações ou trabalhar em projetos que não estão conectados a um repositório.

```bash
jamdesk login     # First time only
jamdesk deploy
```

A CLI empacota seus arquivos, faz o upload e mostra o progresso do build em tempo real. Use `--detach` para colocar o build na fila e sair imediatamente.

## O fluxo

<Steps>
  <Step title="Faça alterações localmente">
    Edite seus arquivos MDX e visualize o resultado com `jamdesk dev`.
  </Step>
  <Step title="Faça push para o GitHub">
    Faça commit e push para sua branch conectada:

    ```bash
    git add .
    git commit -m "Update authentication docs"
    git push
    ```
  </Step>
  <Step title="Implantação automática">
    O Jamdesk detecta seu push, cria o build da sua documentação e faz a implantação na CDN. A maioria dos sites conclui o build em 30 a 90 segundos.
  </Step>
</Steps>

## Status da implantação

Verifique o status no dashboard, em **Deployments**:

| Status | Significado |
|--------|---------|
| **Building** | Build em andamento |
| **Deployed** | Disponível no seu domínio |
| **Failed** | Erro no build — verifique os logs |
| **Queued** | Aguardando o build anterior |

## Rebuild manual

Inicie um rebuild sem fazer push:

1. Acesse **Settings** no seu projeto
2. Clique em **Rebuild**

Use esta opção ao atualizar variáveis de ambiente ou corrigir builds travados.

## Logs de build

Quando os builds falharem, acesse **Deployments** → clique em uma implantação → visualize os logs. Problemas comuns:
- Sintaxe MDX inválida
- Imagens ausentes
- Links internos quebrados
- Erros de configuração

## Rollbacks

Reverta para uma versão anterior:

1. Acesse **Deployments**
2. Encontre a implantação que deseja restaurar
3. Clique em **Rollback**

A versão anterior ficará disponível imediatamente.
