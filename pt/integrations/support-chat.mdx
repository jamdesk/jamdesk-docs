O Jamdesk pode carregar um widget de chat ao vivo em todas as páginas do seu site de documentação. Adicione o bloco do provedor em `integrations` no `docs.json`, e o Jamdesk injeta o script do widget para você.

<Info>
Cada valor é verificado quanto a um formato rigoroso antes que o Jamdesk carregue o widget. Um valor no formato incorreto é ignorado silenciosamente e nunca renderizado — sem página de erro nem tag de script inválida.
</Info>

## Configurar pelo Dashboard

A maneira mais rápida de configurar qualquer um deles é: **Dashboard → Integrations**. Selecione o cartão do provedor, cole o ID, e o Jamdesk grava o bloco `docs.json` para você e aciona um rebuild (somente projetos conectados ao GitHub). As seções abaixo são para editar `docs.json` diretamente ou para projetos somente com CLI.

## Intercom

**Formato:** o ID do app contém de 6 a 16 letras ou números.

<Info>
Encontre o ID do app em **Settings → Installation → Web**, no Intercom — ele é o ID do seu workspace.
</Info>

```json docs.json
{
  "integrations": {
    "intercom": {
      "appId": "abc12345"
    }
  }
}
```

## Front Chat

**Formato:** o ID do chat contém de 8 a 64 caracteres hexadecimais minúsculos (`0-9`, `a-f`).

```json docs.json
{
  "integrations": {
    "frontchat": {
      "snippetId": "3f8a2e1c9b6d4a7f"
    }
  }
}
```

## Consentimento obrigatório

Ambos os widgets respeitam `integrations.cookies`. Quando definido, o script de chat não é carregado até que o banner de consentimento registre a aprovação — consulte [Consentimento de cookies](/pt/integrations/cookie-consent) para ver a configuração completa. Sem essa opção, o widget é carregado para todos os visitantes ao carregar a página.
