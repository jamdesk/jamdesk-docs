O Jamdesk pode carregar um widget de chat ao vivo em todas as páginas do seu site de documentação. Adicione o bloco do provedor em `integrations` no `docs.json`. O Jamdesk injeta o script do widget.

<Info>
O Jamdesk verifica cada valor contra um formato rigoroso antes de carregar o widget. Um valor no formato errado é ignorado silenciosamente. Você não recebe nenhuma página de erro nem uma tag de script quebrada.
</Info>

## Configurar pelo Dashboard

Abra **Dashboard → Integrations**, escolha o cartão do provedor e cole o ID. O Jamdesk grava o bloco no `docs.json` e dispara um novo build (apenas para projetos conectados ao GitHub). Use as seções abaixo para editar o `docs.json` diretamente, ou para projetos que usam apenas a CLI.

## Intercom

**Formato:** o App ID tem de 6 a 16 letras ou números.

<Info>
Encontre seu App ID em **Settings → Installation → Web** no Intercom. Ele é o ID do seu workspace.
</Info>

```json docs.json
{
  "integrations": {
    "intercom": {
      "appId": "abc12345"
    }
  }
}
```

## Front Chat

**Formato:** o Chat ID tem de 8 a 64 caracteres hexadecimais minúsculos (`0-9`, `a-f`).

```json docs.json
{
  "integrations": {
    "frontchat": {
      "snippetId": "3f8a2e1c9b6d4a7f"
    }
  }
}
```

## Consentimento obrigatório

Os widgets do Intercom e do Front Chat respeitam `integrations.cookies`. Com essa opção definida, o script do chat aguarda o seu banner de consentimento registrar a aprovação. Veja [Cookie Consent](/pt/integrations/cookie-consent) para a configuração. Sem ela, o widget é carregado para todos os visitantes no carregamento da página.
