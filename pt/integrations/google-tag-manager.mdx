Adicione o ID do seu contêiner GTM ao `docs.json` para carregar o Google Tag Manager em todas as páginas do seu site de documentação. Depois, sua equipe de marketing configura análises, pixels de conversão e rastreamento de eventos no GTM.

<Info>
IDs de contêiner GTM começam com `GTM-`. Para usar apenas o Google Analytics, veja [Integração com Google Analytics](/pt/integrations/google-analytics) para uma configuração mais simples.
</Info>

## Quando usar o GTM

Use o Google Tag Manager quando precisar de:

- **Múltiplas ferramentas de rastreamento**: GA4, Facebook Pixel, LinkedIn, etc.
- **Controle pela equipe de marketing**: profissionais de marketing adicionam tags sem ajuda de desenvolvedores
- **Gatilhos avançados**: rastrear cliques em botões, envios de formulários, visualizações de vídeos
- **Integração de testes A/B**: conectar ferramentas como o Google Optimize

Para análises básicas, adicionar o GA4 diretamente é mais simples.

## Como obter o ID do contêiner

1. Acesse o [Google Tag Manager](https://tagmanager.google.com/)
2. Selecione sua conta e contêiner (ou crie novos)
3. Copie o **ID do contêiner** no topo da página (começa com `GTM-`)

## Como adicionar o GTM à documentação

Adicione o ID do contêiner ao seu `docs.json`:

```json docs.json
{
  "name": "My Docs",
  "integrations": {
    "gtm": {
      "tagId": "GTM-XXXXXXX"
    }
  }
}
```

Substitua `GTM-XXXXXXX` pelo ID do seu contêiner.

## Consentimento de cookies

Configure você mesmo os banners de consentimento de cookies, caso precise deles. A Jamdesk carrega o seu contêiner GTM em todas as páginas. Cada tag que você configurar é disparada para todos os visitantes. Se a GDPR, a CCPA ou regulamentações semelhantes se aplicarem aos seus leitores, configure o [modo de consentimento](https://support.google.com/tagmanager/answer/10718549) no GTM ou use uma plataforma de gerenciamento de consentimento. A Jamdesk também pode condicionar o próprio GTM ao consentimento. Veja [Consentimento de cookies](/pt/integrations/cookie-consent).

## Como configurar o GA4 pelo GTM

Carregue o GA4 pelo GTM em vez de adicioná-lo diretamente:

1. No GTM, acesse **Tags** → **Nova**
2. Escolha **Google Analytics: Configuração do GA4**
3. Insira seu ID de medição do GA4 (começa com `G-`)
4. Defina o gatilho como **Todas as páginas**
5. **Publique** seu contêiner

<Warning>
Se você configurar o GA4 pelo GTM, não o adicione também diretamente no `docs.json`. Isso causa rastreamento duplicado.
</Warning>

## Como verificar a instalação

### Usando o modo de visualização do GTM

1. No GTM, clique em **Visualizar** no canto superior direito
2. Insira a URL do seu site de documentação
3. Uma janela de depuração mostra quais tags são disparadas em cada página

### Usando as ferramentas de desenvolvedor do navegador

1. Abra seu site com as Ferramentas de Desenvolvedor (F12)
2. Acesse a aba **Network** (Rede)
3. Filtre por `gtm.js` ou `googletagmanager`
4. Confirme que as requisições aparecem

## Tags comuns do GTM para documentação

### Rastrear links externos

Rastreie cliques em links externos com esta tag:

1. **Tag**: Google Analytics: Evento do GA4
2. **Nome do evento**: `click`
3. **Gatilho**: Clique - Apenas links, em que a URL do clique não contém o seu domínio

### Rastrear o uso da pesquisa

Rastreie o uso da busca:

1. **Tag**: Google Analytics: Evento do GA4
2. **Nome do evento**: `search`
3. **Gatilho**: Evento personalizado correspondente à sua interação de busca

### Rastrear o tempo na página

Meça por quanto tempo os leitores permanecem em uma página:

1. **Tag**: Google Analytics: Evento do GA4
2. **Nome do evento**: `timing`
3. **Gatilho**: Gatilho de temporizador (por exemplo, a cada 30 segundos)

## Solução de problemas

<Accordion title="Tags não disparam">
  1. **Verifique o ID do contêiner**: ele deve começar com `GTM-`
  2. **Publique seu contêiner**: alterações não publicadas não aparecem no seu site
  3. **Use o modo de visualização**: a visualização do GTM mostra quais tags são disparadas em cada página
</Accordion>

<Accordion title="Dados duplicados no Google Analytics">
  O GA4 configurado em dois lugares conta cada visualização de página duas vezes:
  - Diretamente no `docs.json` (`integrations.ga4`)
  - Pelo GTM como uma tag do GA4

  Remova um deles.
</Accordion>
