Conecte o Slack para receber notificações de build no canal da sua equipe.

<Note>
A integração com Slack está disponível nos planos Pro.
</Note>

Captura de tela: a interface do Jamdesk aparece em inglês.

## Configurar o Slack

<Steps>
  <Step title="Crie um webhook no Slack">
    No Slack:
    1. Acesse as configurações do seu workspace
    2. Navegue até **Apps** → **Incoming Webhooks**
    3. Clique em **Add to Slack**
    4. Escolha um canal
    5. Copie a URL do webhook
  </Step>
  <Step title="Adicione ao Jamdesk">
    No seu projeto Jamdesk:
    1. Acesse **Integrations**
    2. Clique em **Connect Slack**
    3. Cole a URL do seu webhook
    4. Clique em **Save**
  </Step>
  <Step title="Teste a conexão">
    Clique em **Send Test** para verificar se a integração funciona.
  </Step>
</Steps>

## Preferências de notificações

Escolha quais resultados de build disparam notificações:

| Evento | Padrão | Descrição |
|-------|---------|-------------|
| Build succeeded | Ativado | Notifica quando um build é concluído com sucesso |
| Build failed | Ativado | Notifica quando um build falha |

Marque ou desmarque as caixas e clique em **Update** para alterar as preferências após a configuração.

## Formato das mensagens

As notificações incluem:

- Nome do projeto
- Status do build
- Mensagem do commit e autor
- Link para os detalhes do build
- Duração (para builds concluídos)

Exemplo:
``` text
✓ Docs build succeeded
Project: My Docs
Commit: "Add authentication guide" by @username
Duration: 45s
View build →
```

## Remover o Slack

Para desconectar:

1. Acesse **Integrations**
2. Clique em **Disconnect** ao lado do Slack
3. Confirme a remoção

## Solução de problemas

<Accordion title="Notificações não aparecem">
  1. Verifique se a URL do webhook está correta
  2. Confirme se o canal ainda existe
  3. Envie uma notificação de teste
  4. Verifique as configurações de incoming webhook do Slack
</Accordion>

<Accordion title="Preferências alteradas não são salvas">
  Clique no botão **Update** que aparece depois que você marca uma caixa. As alterações não são salvas automaticamente.
</Accordion>
