Conecte o Slack para receber notificações de build diretamente no canal da sua equipe.

<Note>
A integração com o Slack está disponível nos planos Pro.
</Note>

## Configurar o Slack

<Steps>
  <Step title="Criar um webhook do Slack">
    No Slack:
    1. Acesse as configurações do seu workspace
    2. Navegue até **Apps** → **Incoming Webhooks**
    3. Clique em **Add to Slack**
    4. Escolha um canal
    5. Copie a URL do webhook
  </Step>
  <Step title="Adicionar ao Jamdesk">
    No seu projeto do Jamdesk:
    1. Acesse **Integrations**
    2. Clique em **Connect Slack**
    3. Cole a URL do webhook
    4. Clique em **Save**
  </Step>
  <Step title="Testar a conexão">
    Clique em **Send Test** para verificar se a integração funciona.
  </Step>
</Steps>

## Preferências de notificações

Escolha quais resultados de build acionam notificações:

| Evento | Padrão | Descrição |
|-------|---------|-------------|
| Build concluído | On | Notifica quando um build é concluído com sucesso |
| Build com falha | On | Notifica quando um build falha |

Ambos são ativados por padrão. Para alterar as preferências após a configuração, alterne as caixas de seleção e clique em **Update**.

## Formato das mensagens

As notificações incluem:

- Nome do projeto
- Status do build
- Mensagem e autor do commit
- Link para os detalhes do build
- Duração (para builds concluídos)

Exemplo:
``` text
✓ Docs build succeeded
Project: My Docs
Commit: "Add authentication guide" by @username
Duration: 45s
View build →
```

## Remover o Slack

Para desconectar:

1. Acesse **Integrations**
2. Clique em **Disconnect** ao lado de Slack
3. Confirme a remoção

## Solução de problemas

<Accordion title="As notificações não aparecem">
  1. Verifique se a URL do webhook está correta
  2. Confirme se o canal ainda existe
  3. Envie uma notificação de teste
  4. Verifique as configurações de webhook recebido do Slack
</Accordion>

<Accordion title="As preferências alteradas não são salvas">
  Após alternar as caixas de seleção de notificações, clique no botão **Update** exibido. As alterações não são salvas automaticamente.
</Accordion>
