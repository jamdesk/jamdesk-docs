Adicione o Google Analytics 4 ao seu site de documentação para entender como os usuários interagem com seu conteúdo.

<Info>
A integração com o Google Analytics funciona com IDs de medição do GA4 (Google Analytics 4) que começam com `G-`.
</Info>

## Obtendo seu ID de medição

1. Acesse o [Google Analytics](https://analytics.google.com/)
2. Selecione sua propriedade (ou crie uma)
3. Acesse **Admin** → **Data Streams**
4. Selecione seu fluxo da Web (ou crie um)
5. Copie o **Measurement ID** (começa com `G-`)

## Adicionando o GA4 à documentação

Adicione o ID de medição ao seu `docs.json`:

```json docs.json
{
  "name": "My Docs",
  "integrations": {
    "ga4": {
      "measurementId": "G-XXXXXXXXXX"
    }
  }
}
```

Substitua `G-XXXXXXXXXX` pelo seu ID de medição real.

## Visualizando seus dados

Depois de adicionar a integração:

1. Inicie um novo build da sua documentação
2. Acesse seu site de documentação publicado
3. No Google Analytics, acesse **Reports** → **Real-time**
4. Sua visita deverá aparecer em até 30 segundos

<Note>
Pode levar de 24 a 48 horas para os dados aparecerem nos relatórios padrão. Use os relatórios em tempo real para uma verificação imediata.
</Note>

## Usando com o Google Tag Manager

Se você já usa o Google Tag Manager, pode configurar o GA4 pelo GTM em vez de adicioná-lo diretamente. Consulte [Integração com o Google Tag Manager](/pt/integrations/google-tag-manager) para obter mais detalhes.

Você é responsável por configurar banners de consentimento de cookies para quaisquer tags carregadas pelo Google Tag Manager, se necessário. O Jamdesk carrega seu contêiner do GTM para todos os visitantes sem uma etapa de consentimento. Consulte [Consentimento de cookies](/pt/integrations/cookie-consent) para bloquear as análises até que os visitantes optem por aceitá-las.

<Warning>
Não adicione a mesma propriedade do GA4 diretamente no `docs.json` e também pelo Google Tag Manager, pois isso causará rastreamento duplicado.
</Warning>

## Considerações sobre privacidade

O Google Analytics coleta dados dos visitantes. Considere:

- Adicionar um banner de consentimento de cookies se o GDPR/CCPA se aplicar. O Jamdesk carrega o GA4 para todos os visitantes por padrão; use [Consentimento de cookies](/pt/integrations/cookie-consent) para bloqueá-lo até que eles optem por aceitá-lo.
- Atualizar sua política de privacidade para mencionar as análises
- Usar [anonimização de IP](https://support.google.com/analytics/answer/2763052), se necessário

## Solução de problemas

<Accordion title="Nenhum dado é exibido">
  1. **Verifique seu ID de medição** - Ele deve começar com `G-`
  2. **Verifique os bloqueadores de anúncios** - Eles podem bloquear os scripts de análise
  3. **Aguarde o build** - As alterações exigem um novo build para entrar em vigor
  4. **Use os relatórios em tempo real** - Os relatórios padrão têm um atraso de 24 a 48 horas
</Accordion>

<Accordion title="Erro 'Invalid Measurement ID'">
  O ID deve:
  - Começar com `G-`
  - Conter apenas letras e números depois de `G-`
  - Ser copiado exatamente do Google Analytics (sem espaços extras)
</Accordion>
