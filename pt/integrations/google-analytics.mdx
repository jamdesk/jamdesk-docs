Adicione o Google Analytics 4 ao seu site de documentação para ver como os leitores usam seu conteúdo.

<Info>
A integração aceita IDs de medição do GA4 (Google Analytics 4) que começam com `G-`.
</Info>

## Obtendo seu ID de medição

1. Acesse o [Google Analytics](https://analytics.google.com/)
2. Selecione sua propriedade (ou crie uma)
3. Acesse **Admin** → **Fluxos de dados**
4. Selecione seu fluxo da Web (ou crie um)
5. Copie o **ID de medição** (começa com `G-`)

## Adicionando o GA4 à documentação

Adicione o ID de medição ao seu `docs.json`:

```json docs.json
{
  "name": "My Docs",
  "integrations": {
    "ga4": {
      "measurementId": "G-XXXXXXXXXX"
    }
  }
}
```

Substitua `G-XXXXXXXXXX` pelo seu ID de medição.

## Visualizando seus dados

Verifique se os dados estão chegando:

1. Dispare um novo build da sua documentação
2. Acesse seu site de documentação publicado
3. No Google Analytics, acesse **Relatórios** → **Tempo real**
4. Sua visita aparece em até 30 segundos

<Note>
Pode levar de 24 a 48 horas para os dados aparecerem nos relatórios padrão. Use os relatórios em tempo real para verificação imediata.
</Note>

## Usando com o Google Tag Manager

Se você já usa o Google Tag Manager, configure o GA4 pelo GTM em vez de adicioná-lo diretamente. Consulte [Integração com o Google Tag Manager](/pt/integrations/google-tag-manager) para mais detalhes.

Configure você mesmo os banners de consentimento de cookies para quaisquer tags que você carregue pelo Google Tag Manager. A Jamdesk carrega seu contêiner do GTM para todos os visitantes sem uma barreira de consentimento. Consulte [Consentimento de cookies](/pt/integrations/cookie-consent) para bloquear a análise até que os visitantes optem por ela.

<Warning>
Não adicione a mesma propriedade do GA4 diretamente no `docs.json` e também pelo Google Tag Manager. Isso causa rastreamento duplicado.
</Warning>

## Considerações sobre privacidade

O Google Analytics coleta dados dos visitantes. Considere:

- Adicionar um banner de consentimento de cookies se a GDPR/CCPA for aplicável. Por padrão, a Jamdesk carrega o GA4 para todos os visitantes. O [Consentimento de cookies](/pt/integrations/cookie-consent) o bloqueia até que eles optem por ele.
- Atualizar sua política de privacidade para mencionar a análise de dados
- Usar a [anonimização de IP](https://support.google.com/analytics/answer/2763052), se necessário

## Solução de problemas

<Accordion title="Não vejo nenhum dado">
  1. **Verifique seu ID de medição**: ele deve começar com `G-`
  2. **Verifique bloqueadores de anúncios**: eles podem bloquear os scripts de análise
  3. **Aguarde o novo build**: as alterações exigem um novo build para ter efeito
  4. **Use os relatórios em tempo real**: os relatórios padrão têm atraso de 24 a 48 horas
</Accordion>

<Accordion title="Vejo o erro 'ID de medição inválido'">
  O ID deve:
  - Começar com `G-`
  - Conter apenas letras e números depois de `G-`
  - Ser copiado exatamente do Google Analytics (sem espaços extras)
</Accordion>
