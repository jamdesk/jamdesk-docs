O Jamdesk carrega scripts de 13 provedores adicionais de analytics, replay de sessões e identidade diretamente do `docs.json`. Adicione o bloco do provedor em `integrations`, e o Jamdesk injeta o script em todas as páginas do seu site de documentação publicado.

<Info>
Cada valor é verificado em relação a um formato rigoroso antes que o Jamdesk carregue o script. Um valor no formato incorreto (caracteres extras, prefixo errado ou comprimento incorreto) é silenciosamente ignorado e nunca renderizado — sem página de erro nem tag de script corrompida. Se um provedor não estiver carregando, copie novamente o valor do dashboard dele e compare-o com o formato abaixo.
</Info>

## Configurar pelo Dashboard

A maneira mais rápida de configurar qualquer um deles: **Dashboard → Integrations**. Escolha o cartão de um provedor, cole sua chave, e o Jamdesk confirma o bloco `docs.json` por você e aciona uma nova build (somente projetos conectados ao GitHub). As seções abaixo servem para editar o `docs.json` diretamente ou para projetos somente de CLI.

## PostHog

Analytics de produto, replay de sessões e sinalizadores de recursos.

**Formato:** A chave de API do projeto começa com `phc_`, seguida por 8 a 64 letras ou números. O host de API opcional deve ser uma URL `https://`.

<Info>
Encontre sua chave em **Settings → Project → Project API key** no PostHog.
</Info>

```json docs.json
{
  "integrations": {
    "posthog": {
      "apiKey": "phc_Kj8fPqZx92RmNbTeYcWs",
      "apiHost": "https://us.i.posthog.com"
    }
  }
}
```

`apiHost` é opcional e usa `https://us.i.posthog.com` por padrão. Defina-o como o host da sua nuvem na UE ou como a URL do proxy reverso, se usar um.

## Mixpanel

Analytics de eventos e funis.

**Formato:** O token do projeto tem exatamente 32 caracteres hexadecimais minúsculos (`0-9`, `a-f`).

<Info>
Encontre seu token em **Project Settings → Access Keys → Project Token** no Mixpanel.
</Info>

```json docs.json
{
  "integrations": {
    "mixpanel": {
      "projectToken": "a1b2c3d4e5f6a7b8c9d0e1f2a3b4c5d6"
    }
  }
}
```

## Amplitude

Analytics de produto e coortes comportamentais.

**Formato:** A chave de API tem exatamente 32 caracteres hexadecimais minúsculos (`0-9`, `a-f`).

<Info>
Encontre sua chave em **Settings → Projects → your project → API Key** no Amplitude.
</Info>

```json docs.json
{
  "integrations": {
    "amplitude": {
      "apiKey": "f6e5d4c3b2a1908877665544332211ff"
    }
  }
}
```

## Hotjar

Mapas de calor e gravações de sessões.

**Formato:** O ID do site tem de 1 a 12 dígitos. A versão do snippet tem de 1 a 4 dígitos (geralmente `6`).

<Info>
Encontre ambos em **Sites & Organizations → your site** no Hotjar.
</Info>

```json docs.json
{
  "integrations": {
    "hotjar": {
      "hjid": "3482910",
      "hjsv": "6"
    }
  }
}
```

<Warning>
O Hotjar grava as sessões dos visitantes. Se o GDPR, o CCPA ou regulamentações semelhantes se aplicarem aos seus leitores, coloque-o atrás de [Cookie Consent](/pt/integrations/cookie-consent).
</Warning>

## Microsoft Clarity

Mapas de calor e gravações de sessões gratuitos.

**Formato:** O ID do projeto tem de 4 a 32 letras ou números.

<Info>
Encontre o ID do projeto em **Settings → Overview → Project ID** no Clarity.
</Info>

```json docs.json
{
  "integrations": {
    "clarity": {
      "projectId": "qbxk2paw9m"
    }
  }
}
```

<Warning>
O Clarity grava as sessões dos visitantes. Se o GDPR, o CCPA ou regulamentações semelhantes se aplicarem aos seus leitores, coloque-o atrás de [Cookie Consent](/pt/integrations/cookie-consent).
</Warning>

## Fathom

Analytics com foco em privacidade e sem cookies.

**Formato:** O ID do site tem de 4 a 16 letras ou números.

<Info>
Encontre o ID do site em **Settings → Sites → your site** no Fathom.
</Info>

```json docs.json
{
  "integrations": {
    "fathom": {
      "siteId": "ABCD1234"
    }
  }
}
```

## Pirsch

Analytics sem cookies e com foco em privacidade.

**Formato:** O código de identificação tem de 4 a 64 letras ou números.

<Info>
Encontre seu código em **Settings → Developer → Identification Code** no Pirsch.
</Info>

```json docs.json
{
  "integrations": {
    "pirsch": {
      "id": "Jd8fK2pQmZx9AeRt"
    }
  }
}
```

## Heap

Captura automática de eventos, sem instrumentação manual.

**Formato:** O ID do app tem de 6 a 20 dígitos.

<Info>
Encontre o ID do app em **Account → Manage → Projects** no Heap.
</Info>

```json docs.json
{
  "integrations": {
    "heap": {
      "appId": "1234567890"
    }
  }
}
```

## LogRocket

Replay de sessões com logs do console e da rede.

**Formato:** O ID do app consiste em dois segmentos de slug separados por uma barra — `org-slug/app-slug` — cada um com 2 a 64 letras minúsculas, números ou hífens.

<Info>
Encontre o ID do app em **Settings → Project Setup** no LogRocket.
</Info>

```json docs.json
{
  "integrations": {
    "logrocket": {
      "appId": "acme-inc/docs-site"
    }
  }
}
```

<Warning>
O LogRocket grava as sessões dos visitantes, incluindo a atividade do console e da rede. Se o GDPR, o CCPA ou regulamentações semelhantes se aplicarem aos seus leitores, coloque-o atrás de [Cookie Consent](/pt/integrations/cookie-consent).
</Warning>

## Segment

Envie eventos da documentação para todas as ferramentas downstream a partir de uma única fonte.

**Formato:** A chave de gravação tem de 10 a 64 letras ou números (sem hífens ou sublinhados).

<Info>
Encontre sua chave de gravação em **Connections → Sources → your JS source → Settings → API Keys** no Segment.
</Info>

```json docs.json
{
  "integrations": {
    "segment": {
      "key": "hcQ8wK9pXeR2mNq7"
    }
  }
}
```

## Clearbit

Identifique e enriqueça visitantes anônimos.

**Formato:** A chave de API pública começa com `pk_`, seguida por 6 a 64 letras ou números.

```json docs.json
{
  "integrations": {
    "clearbit": {
      "publicApiKey": "pk_4f8a2e1c9b6d"
    }
  }
}
```

## Hightouch

Envie eventos da documentação diretamente para o seu data warehouse.

**Formato:** A chave de gravação tem de ter de 8 a 128 caracteres (letras, números, `:`, `.`, `_`, `-`). O host de API opcional tem de ter de 4 a 64 caracteres (letras, números, `.`, `-`).

```json docs.json
{
  "integrations": {
    "hightouch": {
      "writeKey": "wk_prod_4f8a2e1c9b6d",
      "apiHost": "us-east-1.hightouch-events.com"
    }
  }
}
```

`apiHost` é opcional — necessário somente para um endpoint de eventos Hightouch auto-hospedado ou específico de uma região.

## Koala

Identifique visitantes com alta intenção para vendas e marketing.

**Formato:** A chave de API pública começa com `pk_`, seguida por 6 a 64 letras ou números.

```json docs.json
{
  "integrations": {
    "koala": {
      "publicApiKey": "pk_7e3a9c1f6b2d"
    }
  }
}
```

## Controle de consentimento

Todos os 13 provedores acima respeitam `integrations.cookies`. Quando essa opção está definida, nenhum dos scripts é carregado até que o banner de consentimento registre a aprovação — consulte [Cookie Consent](/pt/integrations/cookie-consent) para ver a configuração completa. Sem essa opção, todos os scripts são carregados para todos os visitantes no carregamento da página.
