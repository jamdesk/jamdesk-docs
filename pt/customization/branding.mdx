A identidade visual controla os elementos que os leitores veem primeiro: logotipos, favicons e links de navegação. Tudo oferece variantes para temas claro e escuro.

## Logotipo

Adicione seu logotipo ao cabeçalho de navegação:

```json
{
  "logo": {
    "light": "/images/logo-light.webp",
    "dark": "/images/logo-dark.webp",
    "href": "https://yourcompany.com"
  }
}
```

| Campo | Descrição |
|-------|-------------|
| `light` | Logotipo para o tema claro (logotipo escuro em fundo claro) |
| `dark` | Logotipo para o tema escuro (logotipo claro em fundo escuro) |
| `href` | Destino ao clicar no logotipo |

<Tip>
Use logotipos SVG para obter uma renderização nítida em qualquer tamanho. Se você tiver apenas um logotipo, use-o tanto em `light` quanto em `dark`. As prévias de links não conseguem exibir o texto dentro de um logotipo SVG, então converta qualquer texto em contornos (paths). Consulte [Personalizar o cartão social](/pt/content/seo#personalizar-o-cartão-social).
</Tip>

### Dimensões do logotipo

Os logotipos são exibidos com largura máxima de 120px. Para melhores resultados:
- Largura: 120-240px
- Altura: 30-40px
- Formato: SVG recomendado

## Favicon

Uma imagem para os dois temas:

```json
{
  "favicon": "/images/favicon.svg"
}
```

Ou uma variante separada para cada tema:

```json
{
  "favicon": {
    "light": "/images/favicon.svg",
    "dark": "/images/favicon-dark.svg"
  }
}
```

O favicon `light` é exibido no tema claro; `dark`, no tema escuro. `dark` é opcional. Se omitido, `light` será usado nos dois temas. O Jamdesk gera um `<link rel="icon">` para o favicon principal e um segundo link com `media="(prefers-color-scheme: dark)"` para a variante escura.

Formatos compatíveis: SVG, PNG, ICO.

<Note>
Se preferir um único recurso, um SVG que use `currentColor` nos traços e preenchimentos também se adapta automaticamente: o navegador substitui a cor pelo tom de primeiro plano ativo.
</Note>

## Nome do site

O campo `name` aparece nas abas do navegador e nos resultados de busca:

```json
{
  "name": "Acme Docs",
  "description": "Documentation for the Acme API"
}
```

Para alterar o formato do título ou excluí-lo, use [`seo.titleTemplate`](/pt/content/seo#títulos-de-página).

Combine-o com uma [`description`](#descrição) para que os resultados de busca e as prévias de links mostrem um texto adequado, em vez de um conteúdo genérico.

## Descrição

O campo `description` é o resumo de SEO padrão do seu site. Os mecanismos de busca o exibem abaixo do título do site, e as plataformas sociais o usam nas prévias de links:

```json
{
  "description": "Build, ship, and scale documentation with the Acme platform."
}
```

Procure usar de 50 a 160 caracteres, pensando em leitores que estão decidindo se devem clicar. As páginas que definem sua própria `description` no frontmatter usam esse valor; a descrição do site se aplica a todas as outras.

## Links de navegação

Adicione links à barra de navegação:

```json
{
  "navbar": {
    "links": [
      { "label": "Blog", "href": "https://yourcompany.com/blog" },
      { "label": "Pricing", "href": "https://yourcompany.com/pricing" }
    ],
    "primary": {
      "type": "button",
      "label": "Get Started",
      "href": "https://app.yourcompany.com/signup"
    }
  }
}
```

### Opções de link

| Campo | Tipo | Descrição |
|-------|------|-------------|
| `label` | string | Texto exibido |
| `href` | string | URL (externo ou interno) |

### Botão principal

O campo `primary` cria um botão de chamada para ação em destaque:

```json
{
  "primary": {
    "type": "button",
    "label": "Dashboard",
    "href": "https://app.yourcompany.com"
  }
}
```

Em tablets e computadores, os links e o botão principal ficam no cabeçalho. Em celulares, não há espaço para eles no cabeçalho, então aparecem no menu, com o botão principal fixado na parte inferior. O Pulsar não exibe links de navegação nem o botão principal.

## Rodapé

Adicione links para redes sociais e colunas de links personalizados ao rodapé da documentação.

### Links sociais

Exiba ícones de redes sociais na parte inferior de cada página:

```json
{
  "footer": {
    "socials": {
      "github": "https://github.com/yourcompany",
      "x": "https://x.com/yourcompany",
      "discord": "https://discord.gg/yourserver",
      "linkedin": "https://linkedin.com/company/yourcompany"
    }
  }
}
```

#### Plataformas compatíveis

| Plataforma | Chave | Descrição |
|----------|-----|-------------|
| GitHub | `github` | Link para sua organização ou seu repositório no GitHub |
| X (Twitter) | `x` ou `twitter` | Link para seu perfil no X/Twitter |
| LinkedIn | `linkedin` | Link para a página da sua empresa no LinkedIn |
| Discord | `discord` | Link para seu servidor do Discord |
| Slack | `slack` | Link para sua comunidade no Slack |
| YouTube | `youtube` | Link para seu canal do YouTube |
| Instagram | `instagram` | Link para seu perfil no Instagram |
| Facebook | `facebook` | Link para sua página no Facebook |
| Reddit | `reddit` | Link para seu subreddit |
| Telegram | `telegram` | Link para seu canal no Telegram |
| Bluesky | `bluesky` | Link para seu perfil no Bluesky |
| Threads | `threads` | Link para seu perfil no Threads |
| Medium | `medium` | Link para sua publicação no Medium |
| Hacker News | `hacker-news` | Link para seu perfil no Hacker News |
| Site | `website` | Link para seu site principal |

<Tip>
Os ícones são exibidos em uma ordem consistente, independentemente de como você os definir na configuração. GitHub e X/Twitter aparecem primeiro, seguidos pelas outras plataformas.
</Tip>

### Colunas de links

Adicione grupos de links organizados acima dos ícones sociais:

```json
{
  "footer": {
    "links": [
      {
        "header": "Resources",
        "items": [
          { "label": "Blog", "href": "https://yourcompany.com/blog" },
          { "label": "Changelog", "href": "/changelog" }
        ]
      },
      {
        "header": "Company",
        "items": [
          { "label": "About", "href": "https://yourcompany.com/about" },
          { "label": "Careers", "href": "https://yourcompany.com/careers" }
        ]
      }
    ],
    "socials": {
      "github": "https://github.com/yourcompany",
      "x": "https://x.com/yourcompany"
    }
  }
}
```

| Campo | Tipo | Descrição |
|-------|------|-------------|
| `links` | array | Lista de objetos de coluna de links |
| `links[].header` | string | Título da coluna (opcional) |
| `links[].items` | array | Links da coluna |
| `links[].items[].label` | string | Texto exibido para o link |
| `links[].items[].href` | string | URL (caminho interno ou URL externa) |

<Note>
Links externos (que começam com `http`) são abertos automaticamente em uma nova aba. Links internos levam a outras páginas da sua documentação.
</Note>

### Ocultar o rodapé em páginas específicas

Use o frontmatter para ocultar o rodapé em páginas individuais:

```yaml
---
title: Landing Page
hideFooter: true
---
```

Isso é útil para páginas de destino personalizadas ou páginas em que o rodapé possa distrair.

## Identidade visual do Jamdesk

Por padrão, um link “Powered by Jamdesk” aparece no rodapé das páginas da sua documentação. Esse link ajuda outras equipes a conhecer o Jamdesk. Você pode removê-lo se preferir.

### Ocultar a identidade visual

Para remover a identidade visual do Jamdesk:

1. Acesse **Settings** no seu dashboard do Jamdesk
2. Encontre a seção **Build Settings**
3. Desative **Show Jamdesk Branding**
4. Inicie um novo build

<Note>
A opção de identidade visual está disponível em todos os planos. É necessário fazer um novo build para aplicar as alterações.
</Note>

```json
  }

```

## Domínio personalizado

Adicione seu domínio no dashboard do Jamdesk:

1. Acesse **Settings** → **Domains**
2. Adicione seu domínio (por exemplo, `docs.yourcompany.com`)
3. Configure o DNS conforme indicado
4. Aguarde a verificação

Sua documentação ficará disponível no domínio personalizado com SSL automático.
