Defina `theme` em `docs.json` para controlar o layout, a tipografia, o espaçamento e o comportamento do modo escuro. Há quatro temas disponíveis: `jam` (padrão), `nebula`, `pulsar` e `halo`.

```json docs.json
{
  "theme": "jam"
}
```

As capturas de tela mostram a interface em inglês.

<Tip>
Experimente cada tema nesta documentação antes de escolher. Selecione um em **Preview a theme**, na parte superior da barra lateral. No celular, abra o menu de navegação. A visualização permanece até você fechar o navegador.
</Tip>

## Tipografia

Cada tema inclui fontes carregadas do Google Fonts:

| Tema | Títulos | Corpo | Código |
|-------|----------|------|------|
| [Jam](https://jamdesk.com/docs/introduction) | Inter | Inter | JetBrains Mono |
| [Nebula](https://nebula.jamdesk.com) | IBM Plex Mono | IBM Plex Mono | IBM Plex Mono |
| [Pulsar](https://pulsar.jamdesk.com) | Inter | Inter | JetBrains Mono |
| [Halo](https://halo.jamdesk.com) | Figtree | Figtree | JetBrains Mono |

Recomendamos os padrões; eles são ajustados para cada tema. Se precisar de uma aparência diferente, defina `fonts` em `docs.json` para trocar todo o site por uma fonte do Google:

```json
{
  "fonts": {
    "family": "Lora"
  }
}
```

Use fontes separadas para títulos e corpo:

```json
{
  "fonts": {
    "heading": { "family": "Space Grotesk" },
    "body": { "family": "Inter" }
  }
}
```

Qualquer fonte do Google funciona. Defina apenas `family` e o build fará o download automaticamente. Para hospedar uma fonte personalizada por conta própria, adicione `source` (URL ou caminho relativo a `/`) e `format`:

```json
{
  "fonts": {
    "family": "AcmeSans",
    "source": "/fonts/acme-sans.woff2",
    "format": "woff2"
  }
}
```

Defina `weight` para um corpo mais leve (ou mais pesado). Isso é útil para fontes geométricas delicadas, como Geist:

```json
{
  "fonts": {
    "family": "Geist",
    "weight": 200
  }
}
```

`weight` define apenas o peso do texto do **corpo**; os títulos mantêm os pesos mais fortes de cada tema, preservando a hierarquia tipográfica. Também funciona no formato `body`: `"body": { "family": "Geist", "weight": 200 }`.

Para qualquer configuração além do campo `fonts` (substituir fontes de código, ajustar pesos por nível de título ou carregar fontes da web que não sejam do Google), consulte [CSS personalizado](/pt/customization/custom-css#fontes-externas).

## Cores personalizadas

Substitua a paleta padrão para corresponder à identidade da sua marca:

```json
{
  "theme": "jam",
  "colors": {
    "primary": "#635BFF",
    "light": "#7C75FF",
    "dark": "#4F46E5"
  }
}
```

| Cor | Uso |
|-------|-------|
| `primary` | Links, botões e destaques |
| `light` | Estados de foco e realces |
| `dark` | Estados ativos e destaques do modo escuro |

<Note>
As cores entram em vigor após o próximo build. No desenvolvimento local, reinicie o servidor de desenvolvimento para ver as alterações.
</Note>

<Tip>
Use uma ferramenta de cores, como [Coolors](https://coolors.co) ou [Realtime Colors](https://realtimecolors.com), para gerar uma paleta harmoniosa.
</Tip>

<Tip>
**Precisa de mais do que cores?** O [CSS personalizado](/pt/customization/custom-css) permite substituir fontes, espaçamento, largura do conteúdo, raios de borda, estilos de avisos e detalhes no nível dos componentes. Os temas definem os padrões; o CSS personalizado é a alternativa para tudo o que o CSS pode alterar.
</Tip>

## Modo escuro

Todos os temas incluem modo escuro. Por padrão, o Jamdesk segue a preferência do sistema do usuário e oferece um alternador na barra de navegação. Sua paleta de cores se adapta automaticamente.

Fixe o site em um modo específico usando `appearance` em `docs.json`:

```json
{
  "appearance": {
    "default": "dark",
    "strict": true
  }
}
```

| Campo | Valores | Padrão | Descrição |
|-------|--------|---------|-------------|
| `default` | `"system"` \| `"light"` \| `"dark"` | `"system"` | Modo inicial para visitantes na primeira visita |
| `strict` | boolean | `false` | Quando `true`, oculta o alternador da barra de navegação para que os visitantes permaneçam em `default` |

Defina apenas `default` para sugerir um modo inicial e ainda permitir que os usuários troquem de modo. Adicione `strict: true` para remover completamente o alternador e bloquear o site nesse modo.

Para testar o modo escuro durante o desenvolvimento, use o alternador da barra de navegação ou simule-o no DevTools:

1. Abra o DevTools
2. Pressione Cmd+Shift+P (Mac) ou Ctrl+Shift+P (Windows)
3. Pesquise por "Emulate CSS prefers-color-scheme: dark"

Para um controle detalhado dos estilos do modo escuro, use [CSS personalizado](/pt/customization/custom-css).
