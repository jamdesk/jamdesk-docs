title: Plano de fundo
description: "Escolha uma decoração (gradiente, grade de pontos, manchas translúcidas ou plana), defina a cor de fundo da página por modo ou ajuste a cor e o tamanho do gradiente Jam."
---

O bloco `background` em `docs.json` controla o plano de fundo da página. Escolha um de quatro tratamentos de decoração, substitua a cor base por modo ou ajuste o gradiente padrão.

```json docs.json
{
  "theme": "jam",
  "background": {
    "decoration": "none",
    "color": {
      "light": "#faf7f2",
      "dark": "#0a0a0d"
    }
  }
}
```

Todos os campos são opcionais. Omita o bloco `background` inteiro para usar os padrões do tema.

## decoration

Escolha o tratamento de plano de fundo para o modo claro do tema Jam. Cada valor renderiza um padrão distinto sobre a cor base `--color-bg-primary`. O modo escuro sempre renderiza sólido.

```json docs.json
{
  "background": {
    "decoration": "grid"
  }
}
```

| Valor | Comportamento |
|-------|---------------|
| `gradient` (padrão) | Gradiente radial ancorado no topo. Ajustável pelo bloco `gradient` abaixo |
| `grid` | Padrão sutil de grade de pontos: pontos de 1,5px em `--color-primary` com 8% de opacidade, espaçamento de 24px |
| `windows` | Duas manchas radiais suaves nos cantos superiores (visual translúcido estilo Windows 11) |
| `none` | Preenchimento plano `--color-bg-primary`, sem decoração |

<Note>
`decoration` afeta apenas o modo claro do tema Jam. Nebula e Pulsar renderizam fundos sólidos independentemente. O modo escuro do Jam sempre renderiza sólido.
</Note>

## color

Substitua a cor de fundo da página por modo. Aceita qualquer cor CSS: hex, `rgb(...)`, `rgba(...)` ou `hsl(...)`.

```json docs.json
{
  "background": {
    "color": {
      "light": "#faf7f2",
      "dark": "#0a0a0d"
    }
  }
}
```

| Campo | Aplica-se a |
|-------|-------------|
| `color.light` | Fundo do corpo no modo claro |
| `color.dark` | Fundo do corpo no modo escuro |

Defina apenas `light` para substituir o modo claro e manter o padrão escuro do tema. Defina apenas `dark` para o inverso. Isso funciona em todos os temas: Jam, Nebula, Pulsar, Halo e Dusk.

<Tip>
Combine `decoration: "none"` com uma substituição de `color` para um fundo plano e com a identidade da marca. Isso é comum em documentações de estilo editorial ou de marketing.
</Tip>

## gradient

Ajuste o gradiente radial do modo claro do tema Jam. Todos os campos são opcionais e se aplicam de forma independente. Defina apenas `color` para mudar a cor, ou apenas `size` para reduzir ou ampliar.

```json docs.json
{
  "background": {
    "gradient": {
      "color": "#a855f7",
      "size": "800px",
      "position": "top center",
      "opacity": 0.25
    }
  }
}
```

| Campo | Padrão | Descrição |
|-------|--------|-----------|
| `color` | Herda `colors.primary` | Cor do gradiente (qualquer cor CSS) |
| `size` | `500px` | Raio. Qualquer comprimento CSS (`px`, `rem`, `%`, `vh`) |
| `position` | `top center` | Ponto central. Palavras-chave `top`/`bottom`/`center`/`left`/`right`, porcentagens ou coordenadas em pixels |
| `opacity` | `0.12` | Opacidade máxima no centro. Número entre `0` e `1` |

<Note>
`gradient` só se aplica quando `decoration` é `gradient` (ou não definido). As decorações `grid`, `windows` e `none` ignoram este bloco. `grid` e `windows` usam a cor do padrão a partir de `--color-primary`. Altere-a no bloco `colors`.
</Note>

### Suporte dos navegadores

O gradiente paramétrico (consumo de variáveis CSS) usa `color-mix()`, que requer:

- Chrome / Edge 111+
- Firefox 113+
- Safari 16.2+

Navegadores mais antigos voltam ao gradiente original do Jam e ignoram as substituições de `gradient`.

## Receitas comuns

<AccordionGroup>
  <Accordion title="Fundo creme plano, sem gradiente">
    ```json docs.json
    {
      "background": {
        "decoration": "none",
        "color": {
          "light": "#faf7f2",
          "dark": "#0a0a0d"
        }
      }
    }
    ```
    Comum em documentações de estilo editorial. Funciona em qualquer tema.
  </Accordion>

  <Accordion title="Gradiente roxo sutil">
    ```json docs.json
    {
      "background": {
        "gradient": {
          "color": "#a855f7",
          "opacity": 0.15
        }
      }
    }
    ```
    Recolore o gradiente Jam sem alterar seu tamanho ou posição.
  </Accordion>

  <Accordion title="Gradiente maior, descentralizado">
    ```json docs.json
    {
      "background": {
        "gradient": {
          "size": "1200px",
          "position": "top left",
          "opacity": 0.2
        }
      }
    }
    ```
    Gradiente mais largo e difuso, ancorado no canto superior esquerdo.
  </Accordion>

  <Accordion title="Grade de pontos sutil">
    ```json docs.json
    {
      "background": {
        "decoration": "grid"
      }
    }
    ```
    Pinta uma grade de pontos de 24px discreta na cor primária do seu tema. Altere a cor dos pontos com `colors.primary` em `docs.json`.
  </Accordion>

  <Accordion title="Visual translúcido estilo Windows 11">
    ```json docs.json
    {
      "background": {
        "decoration": "windows"
      }
    }
    ```
    Duas manchas radiais suaves nos cantos superiores, ancoradas à janela de visualização. Usa `--color-primary` para a cor das manchas.
  </Accordion>

  <Accordion title="Substituição apenas no modo escuro">
    ```json docs.json
    {
      "background": {
        "color": {
          "dark": "#0d0d12"
        }
      }
    }
    ```
    Mantém os padrões do tema no modo claro e define um fundo personalizado para o modo escuro.
  </Accordion>
