title: 触发构建

---

推送到 GitHub 后，Jamdesk 会自动构建。你也可以从仪表板触发构建。

## 自动构建

每次推送到已连接的分支都会自动触发构建：

1. 你将更改推送到 GitHub
2. GitHub 向 Jamdesk 发送 Webhook
3. Jamdesk 将你的构建加入队列并启动
4. 构建后的文档会部署到 CDN

<Tip>
构建采用防抖机制。如果你在短时间内推送多个提交，Jamdesk 会等待 10 秒，待操作稳定后再开始构建。
</Tip>

## 手动构建

无需推送更改即可触发构建：

<Steps>
  <Step title="打开项目">
    在仪表板中打开你的项目。
  </Step>
  <Step title="前往设置">
    在侧边栏中点击 **Settings**。
  </Step>
  <Step title="点击重新构建">
    选择 **Rebuild** 以开始新的构建。
  </Step>
</Steps>

### 何时使用手动构建

- 更改环境变量后
- 构建失败后刷新
- Jamdesk 平台更新后
- 清除缓存内容

## 构建队列

流量较高时，构建可能会短暂排队。队列位置会显示在仪表板中。构建会按照接收顺序处理。

## 并发构建

每个项目一次只能运行一个构建。构建运行期间触发的新构建会进入队列。

| 方案 | 并发项目数 |
|------|------------|
| Trial | 1 |
| Pro | 3 |
