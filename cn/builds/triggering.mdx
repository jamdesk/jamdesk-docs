---
title: 触发构建
description: 构建会在 git push 时自动触发，也可从仪表板手动触发，包含防抖与队列行为。
---

Jamdesk 会在每次推送到 GitHub 时构建您的文档。您也可以从仪表板触发构建。

## 自动构建

每次推送到您已连接的分支都会触发构建：

1. 您将更改推送到 GitHub
2. GitHub 向 Jamdesk 发送 webhook
3. Jamdesk 将您的构建加入队列并开始构建
4. 构建完成的文档部署到 CDN

<Tip>
构建会进行防抖处理。Jamdesk 会等待 10 秒内没有新推送后再开始构建。
</Tip>

## 手动构建

无需推送更改即可触发构建：

<Steps>
  <Step title="打开您的项目">
    在仪表板中进入您的项目。
  </Step>
  <Step title="进入设置">
    点击侧边栏中的 **Settings**。
  </Step>
  <Step title="点击 Rebuild">
    选择 **Rebuild**。新的构建将开始。
  </Step>
</Steps>

### 何时使用手动构建

- 修改环境变量之后
- 构建失败后刷新
- Jamdesk 平台更新之后
- 清除缓存内容

## 构建队列

在流量高峰期间，构建可能会短暂排队。仪表板会显示队列位置。构建按接收顺序运行。

## 并发构建

每个项目一次只运行一个构建。在构建运行期间到达的触发请求会在队列中等待。

| 套餐 | 并发项目数 |
|------|---------------------|
| 试用版 | 1 |
| Pro | 3 |
