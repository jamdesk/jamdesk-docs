无法登录 Jamdesk 仪表板？请在下方查找适合你的情况。

## 忘记密码

<Steps>
  <Step title="前往登录页面">
    访问 [dashboard.jamdesk.com](https://dashboard.jamdesk.com)。
  </Step>
  <Step title="点击 Forgot Password">
    选择 **Forgot password?** 链接。
  </Step>
  <Step title="输入邮箱">
    输入账号所用的邮箱地址。
  </Step>
  <Step title="检查收件箱">
    点击我们发送的邮件中的重置链接。
  </Step>
</Steps>

<Note>
重置链接将在 1 小时后失效。如果链接已失效，请重新申请。
</Note>

## 无法识别邮箱

如果看到“No account found”：

- 检查邮箱地址是否有拼写错误
- 尝试其他可能使用过的邮箱地址
- 你可能使用 Google 或 GitHub 注册了账号

## OAuth 登录问题

### Google 登录无效

1. 清除浏览器 Cookie
2. 尝试使用其他浏览器
3. 暂时停用浏览器扩展
4. 检查是否允许第三方 Cookie

### GitHub 登录无效

1. 确认已登录 GitHub
2. 在 GitHub 设置中检查是否已授权 Jamdesk
3. 如有需要，撤销授权后重新授权

## 账号锁定

多次登录失败后，账号会暂时锁定。

- 等待 15 分钟后再试
- 使用密码重置选项
- 如果问题仍然存在，请联系支持团队

## 双重身份验证

如果已启用 2FA，但无法访问身份验证器：

1. 尝试使用备份代码
2. 提供账号所有权证明并联系支持团队

## 浏览器问题

尝试以下步骤：

1. 清除 jamdesk.com 的**缓存和 Cookie**
2. **停用扩展**，避免其造成干扰
3. **尝试无痕/隐私模式**
4. **使用其他浏览器**
