使用邮箱、Google OAuth 或 GitHub OAuth 创建您的 Jamdesk 账户。

## 注册选项

Jamdesk 支持三种身份验证方式：

### 邮箱和密码

1. 访问 [dashboard.jamdesk.com](https://dashboard.jamdesk.com)
2. 点击 **Sign Up**
3. 输入您的邮箱地址
4. 创建安全密码
5. 检查邮箱中的验证链接
6. 点击验证链接确认您的账户

### Google OAuth

1. 访问 [dashboard.jamdesk.com](https://dashboard.jamdesk.com)
2. 点击 **Sign Up**
3. 选择 **Continue with Google**
4. 授权 Jamdesk 访问您的 Google 账户
5. 系统会自动完成验证并登录

### GitHub OAuth

1. 访问 [dashboard.jamdesk.com](https://dashboard.jamdesk.com)
2. 点击 **Sign Up**
3. 选择 **Continue with GitHub**
4. 授权 Jamdesk 访问您的 GitHub 账户
5. 系统会自动完成验证并登录

<Note>
您的 GitHub 登录会将您的身份关联到 Jamdesk。这与将 GitHub 仓库连接到文档项目不同。您将在项目设置期间完成该操作。
</Note>

## 注册后会发生什么

创建账户后，您将：
- 开始为期 14 天的 Pro 计划免费试用
- 进入创建首个文档项目的流程
- 使用完整的入门引导

## 邮箱验证

如果您没有收到验证邮件：
1. 检查垃圾邮件文件夹
2. 等待几分钟，然后再次尝试注册
3. 如果问题仍然存在，请[联系支持团队](/cn/help/support/contact)
