使用邮箱、Google OAuth 或 GitHub OAuth 创建您的 Jamdesk 账户。

## 注册选项

### 邮箱和密码

1. 访问 [dashboard.jamdesk.com](https://dashboard.jamdesk.com)
2. 点击 **Sign Up**
3. 输入您的邮箱地址
4. 设置安全密码
5. 查收邮件中的验证链接
6. 点击验证链接以确认您的账户

### Google OAuth

1. 访问 [dashboard.jamdesk.com](https://dashboard.jamdesk.com)
2. 点击 **Sign Up**
3. 选择 **Continue with Google**
4. 授权 Jamdesk 访问您的 Google 账户
5. Jamdesk 会验证您的账户并让您登录

### GitHub OAuth

1. 访问 [dashboard.jamdesk.com](https://dashboard.jamdesk.com)
2. 点击 **Sign Up**
3. 选择 **Continue with GitHub**
4. 授权 Jamdesk 访问您的 GitHub 账户
5. Jamdesk 会验证您的账户并让您登录

<Note>
GitHub 登录会将您的身份与 Jamdesk 关联。将 GitHub 仓库连接到您的文档项目是项目设置期间的另一个独立步骤。
</Note>

## 注册后会发生什么

您的新账户将：
- 开启 Pro 方案的 14 天免费试用
- 引导您创建第一个文档项目
- 获得完整的入门引导

## 邮箱验证

如果您没有收到验证邮件：
1. 检查垃圾邮件文件夹
2. 等待几分钟后重新尝试注册
3. 如果问题仍然存在，请[联系支持](/cn/help/support/contact)
