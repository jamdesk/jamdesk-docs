## 主布局

### 侧边栏（左侧）

左侧边栏链接到当前项目的页面：

- **Project Home** - 概览和构建状态
- **Analytics** - 页面浏览量、访客、地理位置和搜索指标
- **Settings** - 项目配置、团队成员、集成
- **User Settings** - 账户偏好和个人资料

侧边栏最顶部：
- **Project Selector** - 在您的项目之间切换
- **Theme Toggle** - 切换颜色主题

### 顶部导航

顶部区域显示所选项目：
- 带有指示器的**当前项目名称**
- 指向关键部分的快速链接

### 主内容区域

主区域显示您在侧边栏中选择的页面：
- 项目概览和近期活动
- 分析仪表板
- 设置面板
- 团队成员

## Project Home

首次登录时会打开 Project Home：

- **Recent Builds** - 显示最新的部署状态
- **Project Status** - 连接状况、最后更新时间
- **Onboarding Card** - 如果设置未完成，可继续设置（仅首次显示）
- **Quick Actions** - 指向常见任务的链接

## 查找文档

您的在线文档 URL 显示在 **Project Settings** > **Display Settings** 中：

- 项目使用以下格式：`https://<project-id>.jamdesk.app`
- [自定义域名](/cn/deploy/custom-domains)可以替换默认 URL
- 每次构建都会部署您的文档

## 团队成员

在 **Settings** > **Members** 中，您可以：
- 查看有权访问此项目的团队成员
- 邀请新的协作者
- 更改成员权限
- 移除成员

## 项目设置

**Settings** > **Project** 下的关键设置：

- **Display Name** - 文档站点中显示的名称
- **Project ID** - 用于文档 URL 的标识符
- **Connected Repository** - 包含您文档的 GitHub 仓库
- **Powered by Jamdesk Badge** - 显示/隐藏品牌标识（免费套餐必须显示）

## 访问帮助中心

1. 点击侧边栏中的用户头像
2. 查找 **Help** 或 **Documentation** 链接
3. 或直接访问此页面

## 键盘快捷键

- **`k`** - 打开项目切换器（或使用顶部侧边栏选择器）
- **`?`** - 查看所有键盘快捷键
- **`cmd/ctrl + m`** - 切换主题（浅色/深色）

## 故障排除

### 找不到项目

项目未出现在项目选择器中？请按以下步骤检查：
- 确认您已被邀请为团队成员
- 检查该项目是否未被删除
- 如果您认为自己应有访问权限，请[联系支持](/cn/help/support/contact)

### 设置显示不同

仪表板布局因订阅套餐而异。有关特定套餐的功能，请参阅[套餐与定价](/cn/help/billing/plans)。
