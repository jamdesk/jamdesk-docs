关联 GitHub 账户后，Jamdesk 可将您的身份与构建归属相关联，并允许访问私有仓库。

## 为什么要关联 GitHub？

关联 GitHub 账户后，您可以：

- 将私有仓库连接到 Jamdesk
- 启用推送时自动构建
- 访问您所属组织中的仓库

## 关联账户

<Steps>
  <Step title="前往 Settings">
    点击您的头像，然后选择 **Settings**。
  </Step>
  <Step title="选择 Connections">
    转到 **Connections** 选项卡。
  </Step>
  <Step title="点击 Connect GitHub">
    选择 **Connect GitHub Account**。
  </Step>
  <Step title="授权 Jamdesk">
    查看权限，然后在 GitHub 中点击 **Authorize**。
  </Step>
</Steps>

## 请求的权限

Jamdesk 仅请求最低限度的权限：

| 权限 | 用途 |
|------------|---------|
| 读取仓库内容 | 访问您的文档文件 |
| 读取仓库元数据 | 列出您的仓库 |
| Webhooks | 接收推送通知以执行自动构建 |

<Note>
Jamdesk 不会写入您的仓库。所有访问均为只读。
</Note>

## 取消关联账户

如需断开 GitHub：

1. 前往 **Settings** → **Connections**
2. 点击 GitHub 旁边的 **Disconnect**
3. 确认断开关联

<Warning>
断开 GitHub 将会为您的所有项目停用自动构建。您需要重新关联才能重新启用自动构建。
</Warning>

## 组织仓库

如需访问 GitHub 组织中的仓库：

1. 前往该组织在 GitHub 上的设置
2. 转到 **Third-party access** → **OAuth Apps**
3. 找到 Jamdesk，然后点击 **Grant** 授权

如果看不到此选项，请让组织管理员批准 Jamdesk。
