关联你的 GitHub 账户，以将构建归属到你名下并访问私有仓库。

## 为什么要关联 GitHub？

- 将私有仓库连接到 Jamdesk
- 开启推送时自动构建
- 访问你所属组织中的仓库

## 关联账户

<Steps>
  <Step title="进入设置">
    点击你的头像，然后选择 **Settings**。
  </Step>
  <Step title="选择 Connections">
    打开 **Connections** 标签页。
  </Step>
  <Step title="点击 Connect GitHub">
    选择 **Connect GitHub Account**。
  </Step>
  <Step title="授权 Jamdesk">
    查看权限请求，然后在 GitHub 中点击 **Authorize**。
  </Step>
</Steps>

## 请求的权限

Jamdesk 请求以下权限：

| 权限 | 用途 |
|------------|---------|
| 读取仓库内容 | 访问你的文档文件 |
| 读取仓库元数据 | 列出你的仓库 |
| Webhooks | 接收推送通知以进行自动构建 |

<Note>
Jamdesk 从不写入你的仓库。访问权限为只读。
</Note>

## 取消关联账户

1. 进入 **Settings** → **Connections**
2. 点击 GitHub 旁边的 **Disconnect**
3. 确认断开连接

<Warning>
断开 GitHub 会关闭你所有项目的自动构建。重新连接即可再次开启。
</Warning>

## 组织仓库

1. 在 GitHub 上进入该组织的设置
2. 打开 **Third-party access** → **OAuth Apps**
3. 找到 Jamdesk 并点击 **Grant** 授予访问权限

如果没有 **Grant** 选项？请让组织管理员批准 Jamdesk。
