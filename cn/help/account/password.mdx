管理 Jamdesk 密码，包括更改密码或忘记密码时重置密码。

<Note>
  本页介绍的是你的 **Jamdesk 账户密码**（用于登录仪表板的密码）。如果你想为已发布的文档站点设置密码，请参阅[密码保护](/cn/setup/password-protection)；如需了解公开访问、密码保护和 SSO 选项，请参阅[访问控制](/cn/setup/access-control)。
</Note>

## 更改密码

如果你知道当前密码：

<Steps>
  <Step title="前往用户设置">
    点击侧边栏中的头像，然后选择 **User Settings**。
  </Step>
  <Step title="点击更改密码">
    在 **Account Information** 卡片中，点击 **Change Password**。
  </Step>
  <Step title="填写表单">
    系统会打开一个包含三个字段的模态窗口：

    1. **Current Password**
    2. **New Password**
    3. **Confirm New Password**

    点击每个字段中的眼睛图标可以切换密码可见性。
  </Step>
  <Step title="提交">
    点击 **Change Password** 保存。你会看到成功消息，模态窗口也会自动关闭。
  </Step>
</Steps>

<Note>
只有通过电子邮件和密码注册时，才会显示 Change Password 按钮。如果你是通过 Google 或 GitHub 注册的，请参阅下面的 [OAuth 账户](#oauth-账户)。
</Note>

## 重置忘记的密码

如果你不记得密码：

<Steps>
  <Step title="前往登录页面">
    访问 [dashboard.jamdesk.com](https://dashboard.jamdesk.com)，然后点击 **Sign In**。
  </Step>
  <Step title="点击忘记密码">
    点击密码字段下方的 **Forgot password?** 链接。
  </Step>
  <Step title="输入电子邮件地址">
    输入与你的账户关联的电子邮件地址。如果你已在登录表单中输入该地址，系统会自动填充。
  </Step>
  <Step title="检查收件箱">
    点击 **Send reset email**。在收件箱中找到密码重置链接，然后按照说明操作。
  </Step>
</Steps>

<Note>
密码重置链接将在 1 小时后过期。如果链接已过期，请重新请求链接。
</Note>

## 密码要求

你的密码长度必须至少为 **6 个字符**。

## OAuth 账户

如果你仅通过 Google 或 GitHub 注册，则不会拥有 Jamdesk 密码，并且账户设置中不会显示 **Change Password** 按钮。

如需在 OAuth 之外使用密码登录，请在登录页面使用 **Forgot password?** 流程，为你的电子邮件地址设置密码。
