更改您的 Jamdesk 密码；如果忘记密码，可以重置。

<Note>
  本页介绍您的 **Jamdesk 账户密码**（即登录仪表板时使用的密码）。若要为已发布的文档站点设置密码，请参阅 [密码保护](/cn/setup/password-protection)。有关公开、密码和 SSO 选项的概览，请参阅 [访问控制](/cn/setup/access-control)。
</Note>

## 更改密码

以下步骤需要您的当前密码。

<Steps>
  <Step title="进入用户设置">
    点击侧边栏中的头像，然后选择 **User Settings**。
  </Step>
  <Step title="点击 Change Password">
    在 **Account Information** 卡片中，点击 **Change Password**。
  </Step>
  <Step title="填写表单">
    会打开一个包含三个字段的弹窗：

    1. **Current Password**
    2. **New Password**
    3. **Confirm New Password**

    点击字段上的眼睛图标可显示或隐藏密码。
  </Step>
  <Step title="提交">
    点击 **Change Password** 保存。随后会出现成功提示，弹窗关闭。
  </Step>
</Steps>

<Note>
只有使用邮箱和密码创建的账户才会显示 Change Password 按钮。如果您是通过 Google 或 GitHub 注册的，请参阅下方的 [OAuth 账户](#oauth-账户)。
</Note>

## 重置忘记的密码

<Steps>
  <Step title="进入登录页">
    访问 [dashboard.jamdesk.com](https://dashboard.jamdesk.com)，然后点击 **Sign In**。
  </Step>
  <Step title="点击 Forgot Password">
    选择密码字段下方的 **Forgot password?** 链接。
  </Step>
  <Step title="输入您的邮箱">
    输入您账户的邮箱地址。如果您已在登录表单中输入过该地址，它会自动填充。
  </Step>
  <Step title="检查收件箱">
    点击 **Send reset email**。打开收件箱中的密码重置链接，并按照说明操作。
  </Step>
</Steps>

<Note>
密码重置链接 1 小时后失效。如果链接已过期，请重新请求。
</Note>

## 密码要求

您的密码长度必须至少为 **6 个字符**。

## OAuth 账户

仅通过 Google 或 GitHub 创建的账户没有 Jamdesk 密码。其账户设置中不会显示 **Change Password** 按钮。

您可以在登录页使用 **Forgot password?** 流程为邮箱设置密码。之后，您既可以使用密码登录，也可以继续使用 OAuth 登录。
