了解 Jamdesk 如何保护您的文档和账户数据。

## 基础设施安全

### 托管

Jamdesk 运行在符合 SOC 2 标准的云服务提供商上。构建、应用数据和编译后的文档分别存储在这些提供商托管并强化安全的服务中；所有流量均通过内置 DDoS 防护的全球 CDN 提供。

### 加密

| 数据状态 | 防护措施 |
|------------|------------|
| 传输中 | 您、我们的边缘节点和源站之间使用 TLS 1.3 |
| 静态存储 | 所有持久化数据均使用 AES-256 加密，包括数据库记录、对象存储和日志 |
| 备份 | 使用相同的密钥加密，并复制到多个区域 |

## 访问控制

### 登录

您可以使用电子邮件和密码登录仪表板，也可以通过 Google 或 GitHub 单点登录。密码绝不会以明文形式存储；我们的身份验证提供商只保留单向哈希值。

如果您通过 Google 或 GitHub 登录，该账户上配置的任何 MFA（TOTP、安全密钥、通行密钥）也适用于 Jamdesk 登录。为获得最强保护，我们建议在 Google 或 GitHub 账户上启用 MFA，并使用 SSO。

### 团队访问

基于角色的访问控制（Owner、Admin、Member）由数据库安全规则和每次后端调用共同执行。会话在一段时间无活动后自动过期；账单、成员、自定义域名或 API 密钥的变更都会记录到项目级审计日志中。

### GitHub 集成

Jamdesk 通过 GitHub App 连接到您的代码仓库，并仅请求所需权限：

- 对代码仓库内容的读取和写入权限
- 用于触发构建的 Webhook 投递

只有在您要求时，Jamdesk 才会写入您的代码仓库：例如，您在仪表板编辑器中保存更改、接受 Fix with AI 建议，或启用翻译（这会提交已翻译的页面）。构建过程只会读取内容。您可以随时在 GitHub 的 [Applications settings](https://github.com/settings/installations) 中撤销 Jamdesk 的访问权限。

### 令牌和密钥

您交由我们保管的所有密钥都会加密存储，包括：

- GitHub App 连接信息：我们只保存数字形式的安装 ID。短期安装令牌（有效期为一小时）会按需生成，绝不持久化。
- 在入门代码库流程中使用的 GitHub OAuth 令牌：令牌只交换一次，用于克隆模板，随后即被丢弃。
- 第三方集成凭据，例如 Slack 入站 Webhook URL、自定义域名验证令牌和分析 API 密钥。

保存后，仪表板不会再向浏览器返回这些值；只有服务器端构建流水线可以读取它们。

程序化 API 密钥以单向哈希形式存储。明文密钥仅在创建时向您显示一次。如果丢失，请轮换密钥。

## 数据处理

### 我们存储的内容

- 您的 `docs.json` 配置和上传的品牌素材
- 编译后的文档（HTML、CSS、JS）
- 保留 30 天的构建日志
- 您的文档网站的页面浏览事件（路径、引荐来源、国家/地区、浏览器、设备类型、每个标签页的会话 ID 和访客 IP 地址），90 天后删除
- AI 聊天问题（前 200 个字符，不含回答），30 天后删除
- 您配置的任何第三方集成的加密密钥

### 我们不存储的内容

- 您的源代码。我们在构建时克隆代码仓库，并在构建容器销毁时丢弃工作目录。
- 长期有效的 GitHub 凭据。请参阅上文的**令牌与密钥**。
- 任何可逆形式的用户密码。
- 支付卡号。所有卡数据均由 Stripe 处理；我们只保留客户 ID 和订阅元数据。

### 内部访问

只有少数需要运营服务或响应支持请求的员工可以访问生产数据。所有访问都会记录。

## 构建隔离

每次文档构建都在专用容器中运行：

- 无法访问其他客户的数据
- 每次构建都使用全新环境，并在需要时即时注入密钥
- 构建完成或失败后，容器都会销毁

## 合规

### GDPR

Jamdesk 符合 GDPR 要求：

- 自动适用《数据处理附录》([Data Processing Addendum](https://jamdesk.com/dpa))；如有需要，可通过 `privacy@jamdesk.com` 索取双方签署的副本
- 在 [jamdesk.com/subprocessors](https://jamdesk.com/subprocessors) 上公布分处理者名单
- 在 30 天内履行删除权请求
- 支持通过导出实现数据可携带性

### 隐私

我们的内置分析功能：

- 不使用 Cookie。随机会话 ID 保存在浏览器的会话存储中，并在标签页关闭时清除
- 不与广告网络共享数据
- 将访客 IP 地址与页面浏览事件一同存储，并在 90 天后删除

详情请参阅我们的[隐私政策](https://jamdesk.com/privacy)。

## 事件响应

如果安全事件影响到您的账户或数据，我们会采取以下三项措施：

1. 调查并控制问题。
2. 根据 GDPR 义务，在 72 小时内通知受影响的客户。
3. 确认原因后提供书面事件报告。

## 报告漏洞

发现安全问题？请负责任地报告：

- 发送电子邮件至 `security@jamdesk.com`
- 请附上问题描述、复现步骤和影响评估
- 我们会在 48 小时内确认收到

我们目前没有提供付费漏洞赏金计划，但很乐意向善意报告问题的研究人员致谢。
