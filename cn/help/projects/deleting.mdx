---
title: 删除项目
description: 永久删除项目及其构建历史、分析数据和域名配置（GitHub 仓库保持不变）。
---

删除项目也会同时删除其构建历史、分析数据和域名配置。您的 GitHub 仓库不会受到影响。

## 删除您拥有的项目

<Warning>
删除项目将永久移除所有数据，包括构建历史、分析数据和自定义域名配置。此操作无法撤销。
</Warning>

<Steps>
  <Step title="打开项目设置">
    进入您的项目，点击 **Settings**。
  </Step>
  <Step title="滚动到 Danger Zone">
    在页面底部找到 **Danger Zone** 部分。
  </Step>
  <Step title="点击 Delete Project">
    选择 **Delete Project**。
  </Step>
  <Step title="确认删除">
    输入项目名称以确认，然后点击 **Permanently Delete**。
  </Step>
</Steps>

## 将被删除的内容

- 所有构建历史和日志
- 分析数据
- 自定义域名配置
- 团队成员关联
- Webhook 集成

## 未删除的内容

- 您的 GitHub 仓库（保持不变）
- 您的 Jamdesk 账户
- 您拥有的其他项目

## 离开项目

如果您是某项目的成员（而非所有者）：

1. 进入 **Settings** → **Members**
2. 在成员列表中找到您的名字
3. 点击 **Leave Project**
4. 确认

您之后可以被重新邀请。

## 删除前须知

可以考虑以下替代方案：

- 如果团队成员需要继续访问，请**转移所有权**
- 如果需要保留历史记录，请**导出分析**数据
- 如果您之后可能重新创建项目，请**记录您的配置**

## 恢复已删除的项目

已删除的项目无法恢复。如需重建，请从头开始：

1. 创建新项目
2. 连接相同的 GitHub 仓库
3. 手动重新配置设置

您的文档内容仍保留在 GitHub 仓库中。
