description: >-
  将账户的完整控制权交给信任的人，包括账单与所有项目。了解如何添加、接受、离开及移除账户管理员。

将联合创始人、您的代理机构或负责发票的人设为账户管理员，他们即可处理账单和项目，无需借用您的登录信息。账单仍归属您的账户和您的银行卡。

<Warning>
账户管理员对账户拥有与您相同的控制权，仅少数仅限所有者的操作除外。请只添加您信任的人。
</Warning>

## 账户管理员可以做什么

账户管理员可以：

- 更改、取消或重新开启您的订阅，并更新银行卡
- 创建由您付费的项目
- 管理并删除您的任何项目
- 添加或移除其他管理员

管理员自动成为您拥有的每个项目的管理员，包括您之后创建的项目。您仍是所有这些项目的所有者。

任何人都无法将您（所有者）从您自己的账户中移除，且只有您可以[转让项目所有权](/cn/help/projects/ownership-transfer)。

当管理员在您的账户上执行重要操作（例如创建或删除项目、更改套餐）时，您会收到电子邮件通知。Jamdesk 还会在账户的审计日志中记录每一项管理员操作。

## 添加账户管理员

账户所有者和现有管理员均可添加管理员。

<Steps>
  <Step title="打开账户管理员">
    在侧边栏中进入**用户设置**，找到**账户管理员**卡片。
  </Step>
  <Step title="点击添加管理员">
    输入对方的电子邮件地址。
  </Step>
  <Step title="确认您信任对方">
    对话框会列出对方将拥有的权限。勾选**我信任此人管理我的账户**。
  </Step>
  <Step title="发送邀请">
    点击**发送邀请**。对方会收到电子邮件，卡片中会显示**已发送邀请**。
  </Step>
</Steps>

邀请在 14 天后过期。再次添加同一邮箱会重新发送现有邀请。若要撤回邀请，请点击其旁边的**取消邀请**。

## 接受邀请

如果有人将您添加为管理员：

1. 使用收到邀请的电子邮件地址登录 Jamdesk。
2. 如尚未验证邮箱，请先完成验证。**用户设置**中的横幅可以重新发送验证邮件。
3. 在**用户设置**中，点击邀请横幅上的**接受**。点击**不，谢谢**即可拒绝。

接受后，所有者的项目将显示在您的项目列表中。

## 离开或移除管理员

**若要离开您担任管理员的账户**，进入**用户设置** → **账户管理员**，选择该账户，然后点击您自己那一行的**离开**。您将失去对该所有者的项目和账单的访问权限。

**若要移除管理员**，点击其所在行的移除按钮并确认。所有者或其他任何管理员均可执行此操作。

移除管理员将收回其通过管理员角色获得的项目访问权限及账单访问权限。如果您此前曾直接将其邀请加入某个项目，该项目成员身份将保留。

<Note>
您无法从单个项目中移除账户管理员。在项目的**成员**列表中，他们会显示一个**账户管理员**标签，且没有移除选项。请改在**账户管理员**下将其移除。
</Note>

## 管理员的账单

账单始终归属所有者的账户和所有者的银行卡。管理员从不为所有者的项目付费。

要管理所有者的订阅，请打开**订阅**，并从顶部的切换器中选择所有者的账户。提示框会确认您正在更改的是谁的订阅："此处的更改将应用于其账户和银行卡。"在此您可以更改套餐、取消或重新开启订阅，或更新银行卡。

**管理订阅**按钮会打开所有者账户的 Stripe 账单页面。管理员还可以在该页面更改接收发票的账单邮箱，因此只添加您同样信任的人。

当您创建项目且管理着其他账户时，Jamdesk 会询问**谁为此项目付费？**选择所有者的账户后，该项目即归其所有、向其计费，并占用其一个项目名额。

## 账户管理员与项目成员

| | 项目成员 | 账户管理员 |
|---|---|---|
| 范围 | 单个项目 | 所有者现在及以后拥有的全部项目 |
| 账单 | 无权限 | 完全控制所有者的订阅和银行卡 |
| 创建项目 | 否 | 是，费用计入所有者账户 |
| 删除项目 | 否 | 是 |
| 添加位置 | 项目的**设置** → **成员** | **用户设置** → **账户管理员** |

如果某人只需查看单个项目的构建和分析数据，请将其邀请为[项目成员](/cn/help/projects/team-members)。
