在 Settings 页面配置项目的显示名称、已连接仓库、分支、环境变量、自定义域名和危险区域选项。

屏幕截图显示的是英文界面。

## 访问设置

1. 从仪表板中选择项目
2. 点击侧边栏中的 **Settings**

设置页面分为显示、仓库、团队、配置和通知几个部分。

## 常规设置

### 项目名称

仪表板中显示的名称。这不会影响在线文档。

### 子域名

默认 URL 为 `*.jamdesk.app`。如需更改：

1. 输入新的子域名
2. 点击 **Save**
3. 等待 DNS 传播（通常会立即完成）

<Note>
更改子域名不会导致现有链接失效。旧 URL 会重定向到新 URL。
</Note>

## 仓库设置

### 已连接仓库

显示已链接的 GitHub 仓库。如需更换仓库，必须删除项目并创建新项目。

### 分支

触发构建的 Git 分支。通常为 `main` 或 `master`。

### 文档路径

对于单体仓库设置，指定 `docs.json` 的路径（例如 `packages/docs`）。

如果 `docs.json` 位于仓库根目录，请留空。

## 构建设置

### 环境变量

为文档设置构建时变量：

1. 点击 **Add Variable**
2. 输入键和值
3. 点击 **Save**

变量在构建期间可用，也可以在文档中引用。

### 重新构建

点击 **Rebuild**，无需推送到 GitHub 即可触发新的构建。更改设置后此功能非常有用。

## 自定义域名

在 **Domains** 部分添加自己的域名。请参阅[自定义域名](/cn/deploy/custom-domains)了解设置说明。

## 危险区域

### 删除项目

永久删除项目及其所有关联数据：

- 构建历史
- 分析数据
- 自定义域名配置

<Warning>
此操作无法撤销。如果团队成员需要继续访问，请考虑转移所有权。
</Warning>
