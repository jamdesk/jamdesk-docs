---
title: 在仪表板中创建项目
description: Jamdesk 中的项目代表一个独立的文档站点。每个项目连接一个 GitHub 仓库，并部署到专属 URL。
---

在仪表板中创建项目，即可设置新的文档站点。你可以从模板开始，也可以连接现有的 GitHub 仓库，Jamdesk 会自动安装 Webhook 并执行首次构建。

## 创建新项目

<Steps>
  <Step title="打开仪表板">
    前往 [dashboard.jamdesk.com](https://dashboard.jamdesk.com) 并登录。
  </Step>
  <Step title="点击 New Project">
    在仪表板中选择 **New Project**。
  </Step>
  <Step title="选择来源">
    选择开始文档项目的方式：

    <Tabs>
      <Tab title="Use a Template">
        使用 [Starter Template](https://github.com/jamdesk/starter-docs) 开始。Jamdesk 会为你创建一个 GitHub 仓库，其中包含示例内容、组件和 OpenAPI 规范。
      </Tab>
      <Tab title="Connect Repository">
        连接包含文档的现有 GitHub 仓库。
      </Tab>
    </Tabs>
  </Step>
  <Step title="配置设置">
    - **项目名称** — 显示在仪表板中
    - **子域名** — 文档 URL（例如 `my-docs.jamdesk.app`）
    - **分支** — 要部署的 Git 分支（通常为 `main`）
  </Step>
  <Step title="创建">
    点击 **Create Project** 完成设置。
  </Step>
</Steps>

## 项目限制

你的套餐决定了可以创建的项目数量：

| 套餐 | 项目数 |
|------|--------|
| Trial | 1 |
| Pro | 1（可扩展） |

在 Pro 套餐中需要更多项目？前往 **Subscription** 页面添加额外的项目名额。

## 创建的内容

创建项目时，Jamdesk 会：

1. 连接到你的 GitHub 仓库
2. 安装用于自动构建的 Webhook
3. 触发首次构建
4. 分配一个 `*.jamdesk.app` 子域名
