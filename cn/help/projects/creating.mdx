---
title: 在仪表板中创建项目
description: 从模板或现有 GitHub 仓库创建 Jamdesk 项目，Jamdesk 自动处理 webhook 和首次构建。
---

在仪表板中创建项目，以搭建新的文档站点。可以从模板开始，也可以连接现有的 GitHub 仓库。Jamdesk 会安装 webhook 并运行首次构建。

## 创建新项目

<Steps>
  <Step title="打开仪表板">
    前往 [dashboard.jamdesk.com](https://dashboard.jamdesk.com) 并登录。
  </Step>
  <Step title="点击新建项目">
    在仪表板中选择 **New Project**。
  </Step>
  <Step title="选择来源">
    选择文档的起始方式：

    <Tabs>
      <Tab title="使用模板">
        从 [Starter Template](https://github.com/jamdesk/starter-docs) 开始。Jamdesk 会为你创建一个包含示例内容、组件和 OpenAPI 规范的 GitHub 仓库。
      </Tab>
      <Tab title="连接仓库">
        连接包含你文档的现有 GitHub 仓库。
      </Tab>
    </Tabs>
  </Step>
  <Step title="配置设置">
    - **Project name**：在仪表板中显示的名称
    - **Subdomain**：你的文档 URL（例如 `my-docs.jamdesk.app`）
    - **Branch**：要部署的 Git 分支（通常为 `main`）
  </Step>
  <Step title="创建">
    点击 **Create Project** 完成设置。
  </Step>
</Steps>

## 项目限制

你的套餐决定可以创建的项目数量：

| 套餐 | 项目数 |
|------|----------|
| Trial | 1 |
| Pro | 1（可扩展） |

在 **Subscription** 页面可以添加额外的 Pro 项目名额。

## 创建的内容

随后，Jamdesk 会：

1. 连接到你的 GitHub 仓库
2. 安装用于自动构建的 webhook
3. 触发首次构建
4. 分配一个 `*.jamdesk.app` 子域名
