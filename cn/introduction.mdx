Jamdesk 是一款[软件文档工具](https://jamdesk.com)，可根据 Markdown 文件构建文档站点。连接 GitHub 代码库，使用 MDX 编写内容，并在数秒内将站点部署到全球。你无需设置构建流水线，也无需自行运行任何 DevOps。每个站点都会生成 `llms.txt` 文件，以便 AI 工具为你的内容建立索引。

<Info>
**使用 AI 编写。** 使用 Cursor、Claude 或任何 AI 助手生成和编辑文档。MDX 是一种 AI 工具原生理解的文本格式，因此无需特殊提示词。
</Info>

## 一个最小化的 Jamdesk 项目

```text
my-docs/
├── docs.json
└── introduction.mdx
```

这就是全部所需内容。请参阅 [快速入门](/cn/quickstart) 创建自己的项目。

<Tip>
在 GitHub 上浏览[本文档的源代码](https://github.com/jamdesk/jamdesk-docs)。这是一个可供参考的可运行 Jamdesk 项目。
</Tip>

## 工作原理

<Steps>
  <Step title="使用 MDX 编写">
    使用带有可选 React 组件的 Markdown 创建文档。使用你喜欢的编辑器：VS Code、Cursor 或任何纯文本编辑器。Claude 等 AI 工具可以原生生成和编辑 MDX。
  </Step>
  <Step title="推送到 GitHub">
    提交更改并推送。你无需运行构建命令或维护部署脚本。
  </Step>
  <Step title="数秒内上线">
    Jamdesk 会检测你的推送，构建站点，并将其部署到全球 CDN。你的文档将通过 `your-project.jamdesk.app` 上线。
  </Step>
</Steps>
