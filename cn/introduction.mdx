Jamdesk est un [outil de documentation logicielle](https://jamdesk.com) qui génère des sites de documentation à partir de vos fichiers Markdown. Connectez un dépôt GitHub, rédigez en MDX et déployez mondialement en quelques secondes. Vous n'avez pas besoin de configurer un pipeline de build ni de gérer le DevOps vous-même. Chaque site génère un fichier `llms.txt` que les outils d'IA utilisent pour indexer votre contenu.

<Info>
**Rédigez avec l'IA.** Utilisez Cursor, Claude ou tout assistant IA pour générer et modifier votre documentation. Les outils d'IA lisent le MDX nativement. Aucun prompt spécial n'est nécessaire.
</Info>

## 一个最小化的 Jamdesk 项目

```text
my-docs/
├── docs.json
└── introduction.mdx
```

C'est tout ce dont vous avez besoin. Consultez le [Démarrage rapide](/cn/quickstart) pour créer le vôtre.

<Tip>
Parcourez le [code source de cette documentation](https://github.com/jamdesk/jamdesk-docs) sur GitHub. C'est un projet Jamdesk fonctionnel que vous pouvez utiliser comme référence.
</Tip>

## 工作原理

<Steps>
  <Step title="Rédigez en MDX">
    Créez votre documentation en Markdown avec des composants React optionnels. Utilisez l'éditeur de votre choix : VS Code, Cursor ou tout éditeur de texte brut. Des outils d'IA comme Claude peuvent générer et modifier le MDX nativement.
  </Step>
  <Step title="Poussez vers GitHub">
    Validez vos modifications et poussez-les. Vous n'avez pas besoin d'exécuter une commande de build ni de maintenir un script de déploiement.
  </Step>
  <Step title="En ligne en quelques secondes">
    Jamdesk détecte votre push, génère votre site et le déploie sur un CDN mondial. Votre documentation est en ligne sur `your-project.jamdesk.app`.
  </Step>
</Steps>
