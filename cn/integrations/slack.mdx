连接 Slack，在团队频道中接收构建通知。

<Note>
Slack 集成适用于 Pro 套餐。
</Note>

## 设置 Slack

<Steps>
  <Step title="创建 Slack webhook">
    在 Slack 中：
    1. 进入工作区设置
    2. 导航到 **Apps** → **Incoming Webhooks**
    3. 点击 **Add to Slack**
    4. 选择一个频道
    5. 复制 webhook URL
  </Step>
  <Step title="添加到 Jamdesk">
    在你的 Jamdesk 项目中：
    1. 进入 **Integrations**
    2. 点击 **Connect Slack**
    3. 粘贴你的 webhook URL
    4. 点击 **Save**
  </Step>
  <Step title="测试连接">
    点击 **Send Test** 以验证集成是否正常工作。
  </Step>
</Steps>

## 通知偏好

选择哪些构建结果会触发通知：

| 事件 | 默认 | 说明 |
|-------|---------|-------------|
| Build succeeded | 开启 | 构建成功完成时通知 |
| Build failed | 开启 | 构建失败时通知 |

设置完成后，切换复选框并点击 **Update** 以更改偏好设置。

## 消息格式

通知包含：

- 项目名称
- 构建状态
- 提交信息和作者
- 构建详情链接
- 持续时间（针对已完成的构建）

示例：
``` text
✓ Docs build succeeded
Project: My Docs
Commit: "Add authentication guide" by @username
Duration: 45s
View build →
```

## 移除 Slack

要断开连接：

1. 进入 **Integrations**
2. 点击 Slack 旁边的 **Disconnect**
3. 确认移除

## 故障排除

<Accordion title="通知未显示">
  1. 检查 webhook URL 是否正确
  2. 验证频道是否仍然存在
  3. 发送测试通知
  4. 检查 Slack 的 incoming webhook 设置
</Accordion>

<Accordion title="更改的偏好设置未保存">
  切换复选框后，点击出现的 **Update** 按钮。更改不会自动保存。
</Accordion>
