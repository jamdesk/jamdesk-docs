在 `docs.json` 中添加你的 GTM 容器 ID，即可在文档站点的每个页面加载 Google Tag Manager。随后，你的营销团队就可以在 GTM 中设置分析、转化像素和事件跟踪。

<Info>
GTM 容器 ID 以 `GTM-` 开头。如果只需要 Google Analytics，请参阅 [Google Analytics 集成](/cn/integrations/google-analytics)，设置更简单。
</Info>

## 何时使用 GTM

在以下情况下使用 Google Tag Manager：

- **多种跟踪工具**：GA4、Facebook Pixel、LinkedIn 等
- **营销团队自主控制**：营销人员无需开发人员协助即可添加标签
- **高级触发器**：跟踪按钮点击、表单提交、视频观看
- **A/B 测试集成**：连接 Google Optimize 等工具

如果只需要基础分析，直接添加 GA4 会更简单。

## 获取容器 ID

1. 前往 [Google Tag Manager](https://tagmanager.google.com/)
2. 选择你的账户和容器（或创建新容器）
3. 从页面顶部复制 **Container ID**（以 `GTM-` 开头）

## 将 GTM 添加到文档

将容器 ID 添加到 `docs.json`：

```json docs.json
{
  "name": "My Docs",
  "integrations": {
    "gtm": {
      "tagId": "GTM-XXXXXXX"
    }
  }
}
```

将 `GTM-XXXXXXX` 替换为你的容器 ID。

## Cookie 同意

如果需要 Cookie 同意横幅，请自行设置。Jamdesk 会在每个页面加载你的 GTM 容器，你配置的每个标签都会对每位访客触发。如果你的读者受 GDPR、CCPA 或类似法规约束，请在 GTM 中配置[同意模式](https://support.google.com/tagmanager/answer/10718549)，或使用同意管理平台。Jamdesk 还可以将 GTM 本身置于同意之后加载。参见 [Cookie 同意](/cn/integrations/cookie-consent)。

## 通过 GTM 设置 GA4

通过 GTM 加载 GA4，而不是直接添加：

1. 在 GTM 中，前往 **Tags** → **New**
2. 选择 **Google Analytics: GA4 Configuration**
3. 输入你的 GA4 衡量 ID（以 `G-` 开头）
4. 将触发器设置为 **All Pages**
5. **Publish** 你的容器

<Warning>
如果你通过 GTM 配置了 GA4，请不要同时在 `docs.json` 中直接添加它。这会导致重复跟踪。
</Warning>

## 验证安装

### 使用 GTM 预览模式

1. 在 GTM 中，点击右上角的 **Preview**
2. 输入你的文档站点 URL
3. 调试窗口会显示每个页面上触发了哪些标签

### 使用浏览器开发者工具

1. 打开开发者工具（F12）访问你的站点
2. 前往 **Network** 选项卡
3. 筛选 `gtm.js` 或 `googletagmanager`
4. 确认请求已出现

## 文档常用 GTM 标签

### 跟踪出站链接

使用此标签跟踪外部链接的点击：

1. **Tag**：Google Analytics: GA4 Event
2. **Event Name**：`click`
3. **Trigger**：Click - Just Links，且 Click URL 不包含你的域名

### 跟踪搜索使用情况

跟踪搜索使用：

1. **Tag**：Google Analytics: GA4 Event
2. **Event Name**：`search`
3. **Trigger**：与你的搜索交互相匹配的自定义事件

### 跟踪页面停留时间

衡量读者在页面上停留的时长：

1. **Tag**：Google Analytics: GA4 Event
2. **Event Name**：`timing`
3. **Trigger**：Timer 触发器（例如每 30 秒）

## 排查常见 GTM 问题

<Accordion title="标签未触发">
  1. **检查容器 ID**：必须以 `GTM-` 开头
  2. **发布你的容器**：未发布的更改不会出现在你的站点上
  3. **使用预览模式**：GTM 的预览会显示每个页面上触发了哪些标签
</Accordion>

<Accordion title="Google Analytics 数据重复">
  在两个地方设置 GA4 会使每次页面浏览被计算两次：
  - 直接在 `docs.json`（`integrations.ga4`）中设置
  - 通过 GTM 以 GA4 标签的形式设置

  请删除其中一个。
</Accordion>
