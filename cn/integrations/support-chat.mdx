Jamdesk 可以在文档站点的每个页面加载实时聊天小部件。在 `docs.json` 的 `integrations` 下添加服务商的配置块，Jamdesk 会注入小部件脚本。

<Info>
Jamdesk 在加载小部件前会按严格格式校验每个值。格式错误的值会被静默跳过，既不会显示错误页面，也不会产生损坏的脚本标签。
</Info>

## 从仪表板配置

打开 **Dashboard → Integrations**，选择服务商的卡片，粘贴其 ID。Jamdesk 会提交 `docs.json` 配置块并触发重新构建（仅限已连接 GitHub 的项目）。如果您要直接编辑 `docs.json`，或项目仅使用 CLI，请参阅以下各节。

## Intercom

**格式：** App ID 为 6–16 个字母或数字。

<Info>
在 Intercom 中，您可以在 **Settings → Installation → Web** 找到 App ID。它就是您的工作区 ID。
</Info>

```json docs.json
{
  "integrations": {
    "intercom": {
      "appId": "abc12345"
    }
  }
}
```

## Front Chat

**格式：** Chat ID 为 8–64 个小写十六进制字符（`0-9`、`a-f`）。

```json docs.json
{
  "integrations": {
    "frontchat": {
      "snippetId": "3f8a2e1c9b6d4a7f"
    }
  }
}
```

## 同意控制

Intercom 和 Front Chat 小部件遵循 `integrations.cookies` 的设置。设置后，聊天脚本会等待您的同意横幅记录用户的同意。配置方法请参阅 [Cookie 同意](/cn/integrations/cookie-consent#)。若未设置，小部件会在页面加载时对所有访问者加载。
