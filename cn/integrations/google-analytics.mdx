在您的文档站点中添加 Google Analytics 4，了解读者如何使用您的内容。

<Info>
该集成接受以 `G-` 开头的 GA4（Google Analytics 4）测量 ID。
</Info>

## 获取衡量 ID

1. 访问 [Google Analytics](https://analytics.google.com/)
2. 选择您的资源（或创建一个）
3. 前往 **Admin** → **Data Streams**
4. 选择您的网站数据流（或创建一个）
5. 复制 **Measurement ID**（以 `G-` 开头）

## 将 GA4 添加到文档

将测量 ID 添加到您的 `docs.json` 中：

```json docs.json
{
  "name": "My Docs",
  "integrations": {
    "ga4": {
      "measurementId": "G-XXXXXXXXXX"
    }
  }
}
```

将 `G-XXXXXXXXXX` 替换为您的测量 ID。

## 查看数据

检查数据是否正常到达：

1. 触发文档的重新构建
2. 访问您的线上文档站点
3. 在 Google Analytics 中，前往 **Reports** → **Real-time**
4. 您的访问记录会在 30 秒内出现

<Note>
数据可能需要 24-48 小时才会出现在标准报告中。如需即时验证，请使用实时报告。
</Note>

## 与 Google Tag Manager 搭配使用

如果您已在使用 Google Tag Manager，请通过 GTM 配置 GA4，而不是直接添加。详情请参阅 [Google Tag Manager 集成](/cn/integrations/google-tag-manager)。

对于通过 Google Tag Manager 加载的任何标签，请自行设置 Cookie 同意横幅。Jamdesk 会为所有访客加载您的 GTM 容器，不设同意门槛。如需让分析功能在访客选择同意后才生效，请参阅 [Cookie 同意](/cn/integrations/cookie-consent)。

<Warning>
请勿同时在 `docs.json` 和 Google Tag Manager 中添加同一个 GA4 资源，否则会导致重复跟踪。
</Warning>

## 隐私注意事项

Google Analytics 会收集访客数据。请考虑以下事项：

- 如果适用 GDPR/CCPA，请添加 Cookie 同意横幅。Jamdesk 默认会为每位访客加载 GA4。[Cookie 同意](/cn/integrations/cookie-consent) 可将其设置为访客选择同意后才加载。
- 更新您的隐私政策，提及分析工具
- 如有需要，使用 [IP 匿名化](https://support.google.com/analytics/answer/2763052)

## 故障排除

<Accordion title="看不到任何数据">
  1. **验证您的测量 ID**：它必须以 `G-` 开头
  2. **检查广告拦截器**：它们可能会拦截分析脚本
  3. **等待重新构建**：更改需要新的构建才能生效
  4. **使用实时报告**：标准报告有 24-48 小时的延迟
</Accordion>

<Accordion title="出现“Invalid Measurement ID”错误">
  该 ID 必须：
  - 以 `G-` 开头
  - 在 `G-` 之后仅包含字母和数字
  - 从 Google Analytics 中准确复制（不含多余空格）
</Accordion>
