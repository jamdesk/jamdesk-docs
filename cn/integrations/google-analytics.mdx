将 Google Analytics 4 添加到文档站点，了解用户如何与您的内容互动。

<Info>
Google Analytics 集成适用于以 `G-` 开头的 GA4（Google Analytics 4）衡量 ID。
</Info>

## 获取衡量 ID

1. 前往 [Google Analytics](https://analytics.google.com/)
2. 选择您的媒体资源（或创建一个）
3. 前往 **Admin** → **Data Streams**
4. 选择您的网站数据流（或创建一个）
5. 复制 **Measurement ID**（以 `G-` 开头）

## 将 GA4 添加到文档

将衡量 ID 添加到您的 `docs.json`：

```json docs.json
{
  "name": "My Docs",
  "integrations": {
    "ga4": {
      "measurementId": "G-XXXXXXXXXX"
    }
  }
}
```

将 `G-XXXXXXXXXX` 替换为您的实际衡量 ID。

## 查看数据

添加集成后：

1. 触发文档重新构建
2. 访问您的线上文档站点
3. 在 Google Analytics 中，前往 **Reports** → **Real-time**
4. 您应该能在 30 秒内看到访问数据

<Note>
数据可能需要 24–48 小时才会显示在标准报告中。要立即验证，请使用 Real-time 报告。
</Note>

## 与 Google Tag Manager 搭配使用

如果您已经在使用 Google Tag Manager，可以通过 GTM 配置 GA4，而不是直接添加 GA4。详情请参阅 [Google Tag Manager 集成](/cn/integrations/google-tag-manager)。

如果需要，您需要负责为通过 Google Tag Manager 加载的任何标签设置 Cookie 同意横幅。Jamdesk 会为所有访客加载您的 GTM 容器，不会设置同意门槛。请参阅 [Cookie 同意](/cn/integrations/cookie-consent)，在访客选择同意前阻止分析功能。

<Warning>
不要同时在 `docs.json` 中直接添加 GA4 媒体资源，并通过 Google Tag Manager 添加同一媒体资源，否则会导致重复跟踪。
</Warning>

## 隐私注意事项

Google Analytics 会收集访客数据。请考虑：

- 如果 GDPR/CCPA 适用，请添加 Cookie 同意横幅。Jamdesk 默认会为每位访客加载 GA4，因此请使用 [Cookie 同意](/cn/integrations/cookie-consent)，在访客选择同意前阻止 GA4。
- 更新隐私政策，说明分析功能
- 如有需要，使用 [IP 匿名化](https://support.google.com/analytics/answer/2763052)

## 故障排除

<Accordion title="看不到任何数据">
  1. **验证衡量 ID** - 必须以 `G-` 开头
  2. **检查广告拦截器** - 它们可能会阻止分析脚本
  3. **等待重新构建** - 更改需要在新的构建后才能生效
  4. **使用 Real-time 报告** - 标准报告会延迟 24–48 小时
</Accordion>

<Accordion title="出现“Invalid Measurement ID”错误">
  ID 必须：
  - 以 `G-` 开头
  - 在 `G-` 后仅包含字母和数字
  - 从 Google Analytics 中准确复制（不能包含额外空格）
</Accordion>
