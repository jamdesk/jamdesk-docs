每个 Jamdesk 项目都会获得一个免费的 `yourproject.jamdesk.app` 子域名。这是您的默认文档 URL，在首次部署后即可立即使用。

## 子域名的工作方式

创建项目时，Jamdesk 会根据项目 slug 自动分配子域名：

| Project Slug | Subdomain |
|--------------|-----------|
| `my-docs` | `my-docs.jamdesk.app` |
| `acme-api` | `acme-api.jamdesk.app` |
| `company-help` | `company-help.jamdesk.app` |

首次构建完成后，您的子域名即会激活。

## 子域名命名规则

子域名必须遵循以下规则：
- 只能包含小写字母、数字和连字符
- 必须以字母开头
- 不能以连字符开头或结尾
- 长度为 3–63 个字符
- 必须在所有 Jamdesk 项目中保持唯一

## 更改子域名

要更改子域名：

1. 在 [Dashboard](https://dashboard.jamdesk.com) 中打开项目
2. 打开 **Settings** → **General**
3. 更新 **Project Slug** 字段
4. 点击 **Save**

<Warning>
更改子域名会导致现有链接失效。指向旧子域名的搜索引擎链接和外部网站链接将返回 404 错误。如果需要保持 URL 稳定，请考虑改用自定义域名。
</Warning>

更改后：
- 新子域名会立即激活
- 旧子域名返回 404
- 书签和外部链接会失效
- 搜索引擎排名会重置

## SSL 证书

所有 `*.jamdesk.app` 子域名都会自动配置 SSL 证书。必须使用 HTTPS；HTTP 请求会重定向到 HTTPS。

## 速率限制

Jamdesk 子域名与其他项目共享基础设施。对于高流量文档：
- 考虑使用自定义域名以获得专用资源
- 如果预计会持续产生高流量，请联系支持团队

## 何时使用自定义域名

以下情况适合使用自定义域名：
- 需要保持 URL 稳定（子域名更改会导致链接失效）
- 希望将文档放在 `docs.yourcompany.com`
- 需要匹配公司域名
- 文档面向客户

请参阅[自定义域名](/cn/deploy/custom-domains)了解设置说明。

## 子域名与自定义域名

| 功能 | 子域名 | 自定义域名 |
|---------|-----------|---------------|
| 设置时间 | 即时 | 10–30 分钟 |
| 费用 | 免费 | 免费（需提供域名） |
| URL 格式 | `project.jamdesk.app` | `docs.yourdomain.com` |
| SSL | 自动 | 自动 |
| 品牌 | Jamdesk 品牌 | 您的品牌 |
| URL 稳定性 | 与项目 slug 关联 | 永久 |
