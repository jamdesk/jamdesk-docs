Chaque projet Jamdesk reçoit gratuitement un sous-domaine `yourproject.jamdesk.app`. Il s'agit de votre URL de documentation par défaut.

## 子域名的工作方式

Jamdesk attribue un sous-domaine à partir du slug de votre projet lors de sa création :

| Slug du projet | Sous-domaine |
|----------------|--------------|
| `my-docs` | `my-docs.jamdesk.app` |
| `acme-api` | `acme-api.jamdesk.app` |
| `company-help` | `company-help.jamdesk.app` |

Votre sous-domaine est actif dès la fin de votre premier build.

## 子域名命名规则

- Lettres minuscules, chiffres et tirets uniquement
- Doit commencer par une lettre
- Ne peut ni commencer ni se terminer par un tiret
- Entre 3 et 63 caractères
- Doit être unique parmi tous les projets Jamdesk

## 更改子域名

1. Accédez à votre projet dans le [Dashboard](https://dashboard.jamdesk.com)
2. Ouvrez **Settings** → **General**
3. Mettez à jour le champ **Project Slug**
4. Cliquez sur **Save**

<Warning>
Modifier votre sous-domaine casse les liens existants. Les moteurs de recherche et les sites externes pointant vers l'ancien sous-domaine recevront des erreurs 404. Configurez plutôt un domaine personnalisé si vous avez besoin d'URL stables.
</Warning>

Ce qui change :
- Le nouveau sous-domaine est actif immédiatement
- L'ancien sous-domaine renvoie une erreur 404
- Les favoris et les liens externes sont rompus
- Le classement dans les moteurs de recherche est réinitialisé

## SSL 证书

Jamdesk fournit des certificats SSL pour chaque sous-domaine `*.jamdesk.app`. Les requêtes HTTP sont redirigées vers HTTPS.

## 速率限制

Les sous-domaines Jamdesk partagent l'infrastructure avec d'autres projets. Pour une documentation à fort trafic :
- Utilisez un domaine personnalisé pour disposer de ressources dédiées
- Contactez le support si vous prévoyez un trafic élevé et soutenu

## 何时使用自定义域名

Choisissez un domaine personnalisé si :
- Vous avez besoin de stabilité des URL (un changement de sous-domaine casse les liens)
- Vous souhaitez que votre documentation soit accessible sur `docs.yourcompany.com`
- Vous devez correspondre au domaine de votre entreprise
- Votre documentation est destinée aux clients

Consultez [Domaines personnalisés](/cn/deploy/custom-domains) pour les instructions de configuration.

## 子域名与自定义域名

| Caractéristique | Sous-domaine | Domaine personnalisé |
|-----------------|--------------|----------------------|
| Temps de configuration | Immédiat | 10 à 30 minutes |
| Coût | Gratuit | Gratuit (vous fournissez le domaine) |
| Format d'URL | `project.jamdesk.app` | `docs.yourdomain.com` |
| SSL | Automatique | Automatique |
| Image de marque | Marque Jamdesk | Votre marque |
| Stabilité de l'URL | Liée au slug du projet | Permanente |
