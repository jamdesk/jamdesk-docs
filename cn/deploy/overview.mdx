title: 部署概览
description: "文档的托管选项：Jamdesk 子域名、带 SSL 的自定义域名，或通过反向代理置于现有网站下的 /docs 子路径。"
---

Jamdesk 会将你的文档部署到 `*.jamdesk.app` 子域名。要在自己的域名上上线，可以选择自定义子域名（如 `docs.example.com`）或主站上的子路径。子路径默认为 `/docs`，也可以选择任何自定义路径段。

## 部署选项

| 选项 | 适用场景 | 设置复杂度 |
|--------|----------|------------------|
| **Jamdesk 子域名**（`your-project.jamdesk.app`） | 最快上线，无需 DNS 操作 | 低 |
| **自定义子域名**（`docs.example.com`） | 使用品牌的生产文档 | 中 |
| **子路径托管**（`example.com/docs`，可自定义） | 将文档保留在主域名下 | 高 |

## 默认托管（无需设置）

连接代码仓库后，每个项目都会立即在 Jamdesk 子域名上线。适用于内部文档、预览或早期发布。

## 自定义域名（子域名）

使用你自己的子域名（例如 `docs.example.com`）获得带品牌的公开 URL。在 Jamdesk 控制台中添加 DNS 记录并验证所有权。

<Note>
DNS 记录生效后，Jamdesk 会验证 DNS 并签发 SSL。设置方法请参阅[自定义域名](/cn/deploy/custom-domains)。
</Note>

## 子路径托管

将流量代理到 Jamdesk，即可在你的域名下的子路径托管文档。默认为 `example.com/docs`，也可以选择自定义路径段，如 `example.com/help`。若希望文档保留在主营销域名之下，请使用此选项。

<Info>
子路径托管需要代理或 CDN 层来转发请求并设置 `X-Jamdesk-Forwarded-Host` 请求头。请参阅[子路径托管](/cn/deploy/subpath-hosting)。
</Info>

### 代理示例代码片段（nginx）

```nginx nginx.conf
location /docs {
    proxy_pass https://YOUR_SLUG.jamdesk.app;
    proxy_set_header X-Jamdesk-Forwarded-Host $host;
}

location /_next/ {
    proxy_pass https://YOUR_SLUG.jamdesk.app;
}

location /_jd/ {
    proxy_pass https://YOUR_SLUG.jamdesk.app;
}
```

如需包含 SSL、请求头及各服务商具体步骤的完整配置，请参阅[子路径托管](/cn/deploy/subpath-hosting)指南。
