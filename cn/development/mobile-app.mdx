用手机查看您的文档站点。Jamdesk iOS 应用可显示实时分析数据和构建状态。构建成功或失败时，它会发送推送通知。

<Card title="在 App Store 下载" icon="apple" href="https://apps.apple.com/us/app/jamdesk/id6762151258">
  现已支持 iPhone 和 iPad。Android 版即将推出。
</Card>

## 登录

请使用与 [网页仪表板](https://dashboard.jamdesk.com) 相同的凭据：

- 电子邮件和密码
- Google 登录

首次登录后，可使用 Face ID 或 Touch ID 解锁应用。

## 推送通知

在应用中的 **Settings** 下选择开启或关闭：

- **Build success**：部署完成。
- **Build failure**：构建失败。通知中包含错误信息。

通知偏好按设备单独设置。提醒可以发送到手机，而跳过平板。

## 设计为只读

移动应用不会触发重新构建。构建会在您推送到 Git 提供商时开始。如需手动重新构建，请从 [网页仪表板](https://dashboard.jamdesk.com) 发起。该应用是监控工具，而非控制面板。

如需更改项目设置、邀请成员、轮换 API 密钥或触发手动重新构建，请使用网页仪表板。

## 隐私

该应用直接与网页仪表板使用的同一 Firebase 后端通信。没有单独的 API 层，也没有收集您活动数据的分析中继。您的项目数据始终保留在 Jamdesk 基础设施内。
