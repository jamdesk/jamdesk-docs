## 登录

使用与[网页仪表板](https://dashboard.jamdesk.com)相同的凭据：

- Email and password
- Google Sign-In

首次登录后，Face ID 或 Touch ID 可在后续启动应用时解锁应用。

## 推送通知

在应用内前往 **Settings**，选择开启或关闭以下通知：

- **构建成功** — 部署完成后接收通知。
- **构建失败** — 构建失败时立即接收通知，并查看错误消息。

通知偏好设置按设备生效，因此您可以在手机上接收提醒，而不会在平板电脑上收到这些提醒。

## 设计为只读

移动应用不会触发重新构建。当您推送到 Git 提供商时，构建会自动启动；任何手动重新构建都需从[网页仪表板](https://dashboard.jamdesk.com)执行。该应用用于监控，而不是控制；其目标是让您无需切换环境即可查看文档状态。

如果您需要管理项目设置、邀请成员、轮换 API 密钥或触发手动重新构建，请前往网页仪表板。

## 隐私

该应用直接连接到与网页仪表板相同的 Firebase 后端，中间没有单独的 API 层，也没有收集您活动数据的分析中继服务。您的项目数据始终不会离开 Jamdesk 基础设施。
