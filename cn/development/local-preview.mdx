在包含 `docs.json` 的目录中运行 `jamdesk dev`（或 `npx jamdesk dev`）。它会启动一个带热重载和搜索功能的本地服务器。组件的渲染效果与生产环境一致。

## 前置条件

- **Node.js 20+** - 使用 `node --version` 检查
- **一个文档项目** - 包含 `docs.json` 配置文件

## 启动开发服务器

<Tabs>
  <Tab title="npm（全局安装）">
    全局安装 CLI，然后在文档目录中运行：

    ```bash
    npm install -g jamdesk
    cd your-docs
    jamdesk dev
    ```
  </Tab>
  <Tab title="npx（无需安装）">
    无需安装，直接运行：

    ```bash
    cd your-docs
    npx jamdesk dev
    ```
  </Tab>
</Tabs>

你的文档将在 **http://localhost:3000** 上可用。

## 自定义端口

默认端口为 3000。使用 `--port` 指定其他端口：

```bash
jamdesk dev --port 3001
```

或者在 `~/.jamdeskrc` 中设置永久默认值：

```json
{
  "defaultPort": 3001
}
```

## 详细模式

使用 `--verbose` 标志显示构建详情：

```bash
jamdesk dev --verbose
```

这将显示：
- 文件变更检测
- 构建耗时
- 导航解析
- 任何警告或错误

## 首次运行性能

<Note>
首次运行 `jamdesk dev` 时会将依赖安装到 `~/.jamdesk`。这需要 30-60 秒。之后的运行将在 5 秒内启动。
</Note>

清除缓存并强制重新安装：

```bash
jamdesk clean
jamdesk dev
```

## 故障排除

<AccordionGroup>
  <Accordion title="端口已被占用">
    另一个进程正在使用端口 3000。

    **方案一：** 使用其他端口
    ```bash
    jamdesk dev --port 3001
    ```

    **方案二：** 查找并停止该进程
    ```bash
    lsof -i :3000
    kill -9 <PID>
    ```
  </Accordion>

  <Accordion title="找不到 docs.json">
    请在包含 `docs.json` 文件的目录中运行该命令：

    ```bash
    ls docs.json  # Should show the file
    jamdesk dev
    ```
  </Accordion>

  <Accordion title="更改未生效">
    1. 检查终端是否有错误
    2. 强制刷新浏览器（Cmd+Shift+R）
    3. 重启开发服务器
    4. 运行 `jamdesk clean` 后重试
  </Accordion>

  <Accordion title="启动缓慢">
    运行诊断：
    ```bash
    jamdesk doctor
    ```

    它会检查你的环境并报告问题。
  </Accordion>
</AccordionGroup>
