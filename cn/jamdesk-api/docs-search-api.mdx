description: 通过语义搜索以编程方式检索 Jamdesk 文档，为聊天机器人、Slack 机器人和 AI 智能体提供最新答案。

Docs Search API 通过语义搜索，让你以编程方式访问文档内容。一个端点（`POST /_api/search`）接收自然语言查询，并按相关性排序，返回文档中最相关的段落。

## 使用场景

<Columns cols={2}>
  <Card title="客服聊天机器人" icon="comment-dots">

  </Card>
  <Card title="Slack 机器人" icon="slack">

## 快速开始

<Steps>
  <Step title="生成 API 密钥">
    前往 [Jamdesk 仪表板](https://dashboard.jamdesk.com)中的 **Project Settings → API Keys**。点击 **Generate Key**，为密钥命名并复制。密钥以 `jd_live_` 开头，后接 32 个十六进制字符（总计 40 个字符），且仅显示一次。
  </Step>
  <Step title="发送第一个搜索请求">
    向文档子域名上的 `/_api/search` 发送 `POST` 请求：

    ```bash
    curl -X POST https://your-project.jamdesk.app/_api/search \
      -H "Authorization: Bearer jd_live_c83003a54ae0a83123454c3f7ec82f0a" \
      -H "Content-Type: application/json" \
      -d '{"query": "How do I set up a custom domain?", "limit": 5, "language": "en"}'
    ```
  </Step>
  <Step title="使用搜索结果">
    响应会返回一个匹配段落数组，其中包含相关性评分和页面元数据：

    ```json
    {
      "query": "How do I set up a custom domain?",
      "language": "en",
      "results": [
        {
          "title": "Custom Domains",
          "section": "Step 4: Deploy",
          "slug": "deploy/custom-domains",
          "content": "To add a custom domain, go to Project Settings and enter your domain. You'll need to add a CNAME record pointing to your Jamdesk subdomain.",
          "url": "https://your-project.jamdesk.app/deploy/custom-domains",
          "score": 0.94
        }
      ],
      "total": 1,
      "durationMs": 85
    }
    ```
  </Step>
</Steps>

## 身份验证

所有请求都必须在 `Authorization` 标头中提供 Bearer 令牌。

```http
Authorization: Bearer jd_live_c83003a54ae0a83123454c3f7ec82f0a
```

<Info>
  Search API 可用于启用了密码或 JWT 身份验证的网站。它会验证你的 API 密钥，而不是访客的登录状态，因此无需将 `/_api/search` 添加到 `auth.jwt.public`。搜索结果可能包含需要登录才能访问的页面，因此请从服务器调用 API，切勿将密钥放入浏览器代码中。搜索结果遵循与站内搜索相同的规则：不会返回受群组限制的页面；除非你已将隐藏页面或设置了 `search: false` 的页面设为可搜索，否则这些页面也不会出现在结果中。
</Info>

### 生成 API 密钥

<Steps>
  <Step title="打开项目设置">
    在 Jamdesk 仪表板中，进入你的项目并点击 **Settings**。
  </Step>
  <Step title="前往 API Keys">
    选择 **API Keys** 标签页。
  </Step>
  <Step title="创建密钥">
    点击 **Generate Key**，输入描述性名称（例如“Intercom 聊天机器人”），然后点击 **Create**。
  </Step>
  <Step title="复制密钥">
    立即复制密钥。它以 `jd_live_` 开头，后接 32 个十六进制字符，并且**仅显示一次**。请将其存储在密钥管理器或环境变量中。
  </Step>
</Steps>

### 密钥管理

<Info>
API 密钥仅适用于单个项目。为 `acme.jamdesk.app` 创建的密钥无法查询其他项目的文档。
</Info>

| 规则 | 详情 |
|------|--------|
| **格式** | `jd_live_<32 hex chars>`（总计 40 个字符，永不过期） |
| **适用范围** | 每个项目一个密钥（无法访问其他项目） |
| **轮换** | 可随时在 Project Settings 中撤销并重新生成 |
| **存储** | 存储在环境变量或密钥管理器中；切勿提交到源代码管理系统 |

### 撤销密钥

要撤销密钥，请前往 **Project Settings → API Keys**，按名称找到密钥，然后点击 **Revoke**。密钥撤销后会立即失效。生成新密钥即可替换它。

## 速率限制

请求按 API 密钥进行速率限制。

| 套餐 | 限制 |
|------|-------|
| **Pro** | 每分钟 60 个请求 |
| **Enterprise** | 自定义；请联系[支持团队](mailto:support@jamdesk.com) |

超过限制时，API 会返回 `429 Too Many Requests`，并在标头中提供 `Retry-After: 60`，在响应正文中提供 `{"error": "Rate limit exceeded"}`。

<Warning>
如果生产环境集成需要更高的速率限制，请[联系我们](mailto:support@jamdesk.com)，了解 Enterprise 方案。
</Warning>

## 查询限制

每个请求都可以通过 `limit` 参数控制返回结果数量。最大值为 **20**，默认值为 **5**，最小值为 **1**。不支持分页；所有匹配结果都会在单个响应中返回。如果需要更多上下文，请尝试使用更具体的查询，而不是增大限制。

查询没有匹配项时，API 会返回 HTTP 200 和一个空结果数组：

```json
{"query": "quantum entanglement", "results": [], "total": 0, "durationMs": 48}
```

## 按语言筛选

如果文档站点支持多种语言，API 会将每个请求的结果筛选为单一语言。在请求正文中传入 `language`，并使用 BCP-47 代码（例如 `en`、`es`、`fr`、`pt-BR`、`zh-Hans`）。

```bash
curl -X POST https://your-project.jamdesk.app/_api/search \
  -H "Authorization: Bearer jd_live_c83003a54ae0a83123454c3f7ec82f0a" \
  -H "Content-Type: application/json" \
  -d '{"query": "¿Cómo configuro un dominio personalizado?", "language": "es"}'
```

| 规则 | 详情 |
|------|--------|
| **默认值** | `en`（英语）。省略此字段或传入 `null` 即使用默认值。 |
| **格式** | BCP-47（`^[a-zA-Z]{2,3}([-_][a-zA-Z]{2,4})?$`）。示例：`en`、`es`、`fr`、`pt-BR`、`zh-Hans`。 |
| **验证** | 格式错误的值会返回 `400` 和 `{"error": "Invalid language code"}`。 |
| **3 段式标签** | 目前不支持。`zh-Hant-HK` 和 `sr-Latn-RS` 等代码会返回 `400`。如有需要，请[联系支持团队](mailto:support@jamdesk.com)。 |
| **多语言项目** | 筛选条件严格生效：只返回标记为所请求语言的内容块。对于仅包含英语和法语内容的项目，使用 `de` 请求会返回空结果集，而不是 `400`。 |
| **单语言项目** | 忽略筛选条件；始终返回完整结果集。传入 `language` 不会造成影响，也不会报错。 |
| **响应中回显** | 每个成功响应都包含 `language` 字段，其值为服务器解析出的语言（请求中的值或默认值 `en`）。 |

<Info>
当项目的 `docs.json` 中包含一个有两个或更多条目的 `navigation.languages` 数组时，该项目即为多语言项目。要检查站点是否为多语言站点，请打开仪表板中的 **Settings → Languages** 标签页，或直接打开 `docs.json`。
</Info>

<Warning>
默认值 `en` 同样适用于没有英语版本的项目。如果你的多语言项目仅包含法语和西班牙语等语言，不传入 `language` 字段调用端点时，API 会按 `en` 筛选并返回空结果集。对于不包含英语的站点，请务必显式传入 `language`。
</Warning>

## 错误处理

所有错误响应都包含一个可供程序分支判断的机器可读 `error` 字段。

| 状态 | `error` 值 | 含义 | 处理方式 |
|--------|---------------|---------|--------|
| **400** | `Missing or empty "query" field` | 请求正文缺少 `query`，或该字段为空 | 添加非空的 `query` 字符串 |
| **400** | `Invalid language code` | `language` 字段不是字符串，或不符合 BCP-47 格式（`null` 有效；空字符串、仅含空白字符的字符串和 3 段式标签无效） | 使用有效的 1 段或 2 段代码，例如 `en`、`es`、`fr` 或 `pt-BR` |
| **401** | `invalid_key_format` | 缺少 `Authorization` 标头，或密钥不符合 `jd_live_<32 hex>` 格式 | 检查标头格式；必须使用 `Bearer jd_live_...` |
| **401** | `invalid_key` | 密钥无法识别或已被撤销 | 在仪表板中生成新密钥 |
| **403** | `wrong_project` | 密钥有效，但它是为其他项目生成的 | 使用与 URL 中项目 slug 对应的密钥 |
| **429** | `Rate limit exceeded` | 每分钟请求数超过 60 | 等待 `Retry-After` 标头中指定的秒数 |
| **502** | `Search temporarily unavailable` | 向量搜索后端不可用 | 短暂退避后重试 |
| **503** | `lookup_failed` 或 `redis_unavailable` | 密钥验证后端无法访问 | 短暂退避后重试 |

<Info>
401 和 403 是永久性故障，使用同一密钥重试无济于事。429、502 和 503 是暂时性故障，请采用指数退避策略重试。
</Info>

## CORS

所有端点均已启用 CORS。基于浏览器的客户端（单页应用、浏览器扩展、静态站点）无需后端代理，即可直接调用 `/_api/search`。所有来源均获准访问。

## SDK

目前没有官方的编程语言 SDK。请使用 `fetch`、`requests`、`curl` 或任何 HTTP 客户端直接调用 REST API。下方的 [Postman 集合](#postman-集合)提供了可直接复用的示例。

## 版本控制

API 当前版本为 **v1.0.0**。破坏性变更（字段重命名、移除端点、更改身份验证）会通过 [Jamdesk 博客](https://jamdesk.com/blog)和 `X-Deprecation` 响应标头中的弃用通知提前至少 90 天公布。
