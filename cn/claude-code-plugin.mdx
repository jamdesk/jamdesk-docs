本插件为 [Claude Code](https://claude.ai/code) 提供 Jamdesk 相关知识，省去你在每次提问时都要重新解释的内容：有哪些组件、`docs.json` 如何工作、CLI 命令是什么。

<Note>
  你需要先安装 Claude Code。可在 [claude.ai/code](https://claude.ai/code) 获取。
</Note>

## 安装

<Steps>
  <Step title="添加插件市场">
    在 Claude Code 中运行以下斜杠命令：

    ```text
    /plugin marketplace add jamdesk/jamdesk-claude-plugin
    ```
  </Step>
  <Step title="安装插件">
    ```text
    /plugin install jamdesk@jamdesk-marketplace
    ```
  </Step>
</Steps>

你也可以运行 `/plugin` 并选择 **Discover** 来找到它。

<Accordion title="手动安装（用于开发或测试）">
  ```bash
  git clone https://github.com/jamdesk/jamdesk-claude-plugin.git
  claude --plugin-dir ./jamdesk-claude-plugin
  ```
</Accordion>

## 包含内容

该插件提供一个技能 `/jamdesk:jamdesk`。它包含一个快速参考中心，以及三个按需加载的参考文件：

| 参考 | 涵盖内容 |
|-----------|---------------|
| **Components** | 25+ 个 MDX 组件（Cards、Steps、Tabs、Callouts、Code Groups、Tables 等），含完整属性和示例 |
| **Configuration** | 完整的 `docs.json` 结构：主题、颜色、品牌、导航栏、页脚、API 配置，以及 20+ 个分析集成 |
| **Navigation** | 8 种导航模式：扁平、分组、标签页、多产品、版本化、多语言、下拉菜单、OpenAPI |

中心还列出 19 个 CLI 命令、页面 frontmatter 字段、图片尺寸语法、编写规范以及常见错误。

## 使用方法

在编写 Jamdesk 文档时运行 `/jamdesk:jamdesk`。

在包含 `docs.json` 的项目中，Claude 可能会自动激活该技能。

对于组件语法和 CLI 命令等常见问题，Claude 会直接从参考中心作答。如需完整的属性表、配置选项或导航模式细节，它会加载对应的参考文件。

## 与 CLAUDE.md 和 MCP 配合使用

该插件在三层架构下效果最佳：

1. 插件让 Claude 了解 Jamdesk 平台：组件、配置、导航、CLI。
2. [CLAUDE.md](/cn/ai/claude-code) 让 Claude 了解*你项目*的约定：写作风格、术语、页面结构。
3. [MCP 服务器](/cn/ai/mcp-server) 让 Claude 能够搜索并读取你已发布的文档。

三者并非都必需。插件本身已经有用。配合 CLAUDE.md 和 MCP 连接，Claude 还能匹配你站点的文风，并链接到现有页面。
