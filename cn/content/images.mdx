Jamdesk 会为图片添加圆角并保持间距一致。将文件放入 `/images` 目录，然后使用标准 Markdown 引用图片。

屏幕截图显示的是英文界面。

## 标准 Markdown

使用常见的 `![alt](path)` 语法：

```markdown
![API response showing user data in JSON format](/images/tabs-preview.webp)
```

![显示 JSON 格式用户数据的 API 响应](/images/tabs-preview.webp)

路径以项目根目录为起点。`your-docs/images/screenshot.webp` 中的图片应引用为 `/images/screenshot.webp`。

## 图片尺寸

在图片 URL 后（以空格分隔）追加 `=WIDTHxHEIGHT`，即可控制尺寸：

```markdown
![Dashboard overview](/images/tabs-preview.webp =400x300)
```

只设置一个尺寸，另一个尺寸会按比例缩放：

```markdown
![Wide banner](/images/tabs-preview.webp =800x)
![Tall graphic](/images/tabs-preview.webp =x200)
```

如果需要让一列截图保持相同宽度，或将高分辨率图片缩小到合适的显示尺寸，这种方式会很有用。

## 说明文字

将图片放在 `<Frame>` 组件中，可添加边框和图片下方的说明文字：

```mdx
<Frame caption="Dashboard overview showing project statistics">
  ![Dashboard](/images/tabs-preview.webp)
</Frame>
```

<Frame caption="带说明文字的边框图片示例">
  ![Jamdesk](/images/jd-blueprint-transparent.webp)

</Frame>

`Frame` 会在图片周围绘制浅色边框，并在下方显示说明文字。它适用于其中的任何内容，不限于图片。

## 点击缩放

在宽度为 768px 或更大的屏幕上，点击图片即可全屏查看。按 Escape 键或点击任意位置即可关闭放大后的图片。

若要禁止图片缩放，请在 `<img>` 标签中添加 `noZoom`：

```mdx
<img src="/images/diagram.png" alt="Architecture diagram" noZoom />
```

Markdown 图片（`![alt](src)`）没有属性语法，因此无法选择禁用缩放。需要使用 `noZoom` 时，请改用 `<img>` 标签。

## 明暗模式

文档网站通常需要为不同配色方案提供不同的图片变体：白色背景上的 logo 在暗色模式下可能显得不协调。

### `srcDark` 属性

这是最简单的方式。Jamdesk 会根据当前主题切换图片来源：

```mdx
<img
  src="/images/logo-light.webp"
  srcDark="/images/logo-dark.webp"
  alt="Company logo"
/>
```

浏览器只会加载与当前配色方案匹配的图片。

### HTML `<picture>` 元素

如果需要使用 Jamdesk 之外也能正常工作的标准 HTML，可配合媒体查询使用 `<picture>`：

```mdx
<picture>
  <source srcset="/images/logo-dark.webp" media="(prefers-color-scheme: dark)" />
  <img src="/images/logo-light.webp" alt="Company logo" />
</picture>
```

`<picture>` 方式遵循操作系统的配色方案设置。`srcDark` 属性则响应 Jamdesk 的主题切换按钮，这通常更适合文档网站。

## 支持的格式

| 格式 | 适用场景 | 说明 |
|--------|----------|-------|
| PNG | 屏幕截图、界面截图 | 无损质量，支持透明背景。文件较大。 |
| JPEG | 照片 | 压缩效果好，不支持透明背景。 |
| SVG | 图标、图表、logo | 矢量格式，可缩放到任意尺寸且不会损失画质。文件极小。 |
| GIF | 简单动画 | 文件可能迅速变大。帧数超过几帧时，可考虑使用较短的 `.mp4` 循环视频。 |
| WebP | 通用 | 在画质相近时，文件比 PNG 和 JPEG 更小。所有现代浏览器均支持。 |

<Tip>
对于大多数文档图片，WebP 能提供最佳的文件大小与画质平衡。如果需要透明背景，WebP 也支持，因此无需使用 PNG。
</Tip>

## 最佳实践

<AccordionGroup>
  <Accordion title="编写有意义的替代文本" icon="universal-access">
    替代文本有两个用途：屏幕阅读器会使用它来提供无障碍支持；图片加载失败时，它会作为占位内容显示。请描述图片实际展示的内容。

    ```markdown
    {/* Good -- says what's in the image */}
    ![API response showing user data in JSON format](/images/tabs-preview.webp)

    {/* Bad -- tells you nothing */}
    ![Screenshot](/images/tabs-preview.webp)
    ```

    对于不提供信息的装饰性图片（如背景图案、分隔线），请使用空替代文本：`![](/images/decoration.webp)`。
  </Accordion>

  <Accordion title="控制文件大小" icon="gauge-high">
    图片文件过大会拖慢页面加载速度，尤其是在移动网络下。建议控制在以下大小：

    - **屏幕截图/界面截图：** PNG 或 WebP，小于 500KB
    - **照片：** JPEG 或 WebP，小于 200KB
    - **图标和图表：** 尽可能使用 SVG

    [Squoosh](https://squoosh.app) 和 [TinyPNG](https://tinypng.com) 可以在不造成明显画质损失的情况下压缩图片。提交前，请用其中一种工具处理屏幕截图。

    也可以让 Jamdesk 在构建时处理图片。在 `docs.json` 中启用[自动转换为 WebP](/cn/builds/image-optimization)，提交的 PNG 或 JPG 图片便会在每次构建时自动优化。
  </Accordion>

  <Accordion title="保持尺寸一致" icon="ruler-combined">
    宽度不一的屏幕截图排列起来会显得杂乱。请选择统一的截图宽度（1200px 通常效果不错），并在文档中保持一致。Jamdesk 会自动缩放图片以适应内容区域，因此统一的源图片尺寸能带来一致的渲染效果。
  </Accordion>

  <Accordion title="检查社交分享图片" icon="share-nodes">
    Jamdesk 会为每个页面自动生成带品牌标识的 1200×630 社交卡片；你也可以通过 frontmatter 中的 `og:image` 为单个页面设置自定义图片。构建完成后，将页面 URL 输入免费的 [OpenGraph Preview](https://jamdesk.com/utilities/opengraph-preview) 工具，查看卡片在 X、Facebook、LinkedIn、Slack、Discord 等平台上的显示效果。完整设置方法请参阅 [SEO 优化](/cn/content/seo)。
  </Accordion>
</AccordionGroup>

## 文件组织

按照内容结构将图片归类到子目录中。这样随着文档增多，图片也更容易查找：

```bash
your-docs/
├── images/
│   ├── getting-started/
│   │   ├── step-1.png
│   │   └── step-2.png
│   ├── api/
│   │   └── response.png
│   └── logo.svg
└── docs.json
```

使用从项目根目录开始的完整路径引用图片：

```markdown
![GitHub repository access](/images/getting-started/step-1.png)
```

<Warning>
图片文件名中不要使用空格，请改用连字符：`api-response.webp`，不要写成 `api response.webp`。
</Warning>
