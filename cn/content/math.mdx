Jamdesk 使用 [KaTeX](https://katex.org/) 渲染 LaTeX 数学公式。

<Note>
数学公式支持需要在你的 `docs.json` 文件中设置 `styling.latex: true`。
</Note>

## 启用数学支持

在你的 `docs.json` 中添加：

```json docs.json
{
  "styling": {
    "latex": true
  }
}
```

## 行内数学

使用单个美元符号书写行内公式：

```md
The Pythagorean theorem states that $a^2 + b^2 = c^2$.
```

**渲染效果：** The Pythagorean theorem states that $a^2 + b^2 = c^2$.

## 块级公式

使用双美元符号书写居中的展示型公式：

```md
$$
E = mc^2
$$
```

**渲染效果：**

$$
E = mc^2
$$

## 复杂公式

KaTeX 支持多种 LaTeX 记号：

### 分数

```md
$$
\frac{n!}{k!(n-k)!} = \binom{n}{k}
$$
```

### 积分

```md
$$
\int_0^\infty e^{-x^2} dx = \frac{\sqrt{\pi}}{2}
$$
```

### 求和

```md
$$
\sum_{i=1}^{n} i = \frac{n(n+1)}{2}
$$
```

### 矩阵

```md
$$
\begin{bmatrix}
a & b \\
c & d
\end{bmatrix}
$$
```

## 使用 Latex 组件

如需更多控制，可直接使用 `<Latex>` 组件：

```mdx
<Latex>E = mc^2</Latex>
```

块级/展示模式：

```mdx
<Latex block>
\int_0^\infty e^{-x^2} dx = \frac{\sqrt{\pi}}{2}
</Latex>
```

## 代码块受保护

代码块中的美元符号**不会**被当作数学公式处理：

```bash
echo $HOME
export PRICE=$100
```

## 支持的命令

KaTeX 涵盖了大多数常用的 LaTeX 数学命令。[KaTeX 文档](https://katex.org/docs/supported.html)列出了所有支持的函数。

<Tip>
请先在 [KaTeX 的演示页面](https://katex.org/)上测试复杂公式。
</Tip>
