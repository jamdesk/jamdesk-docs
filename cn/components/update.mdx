title: 更新
description: 时间线式更新日志条目，包含日期、描述和分类标签。与目录集成，便于导航。
---

Update 组件用于创建时间线式的更新日志条目。条目会显示在目录中。每个条目可以包含日期标签、描述和分类标签。可用于"新功能"页面、API 更新日志和发布说明。

在以下情况使用 Update：
- **记录发布版本**，包含版本号或日期
- **构建更新日志**，让读者可通过目录导航
- **宣布功能**，并使用分类标签（新增、修复、破坏性变更）

<Tip>
在产品内部展示更新日志，配合"有什么新变化？"按钮和未读提示点。参见 [嵌入更新日志](/cn/development/embed-page)。
</Tip>

## 基本用法

<Update label="January 10, 2025">
Added support for dark mode across all themes.
</Update>

```mdx
<Update label="January 10, 2025">
Added support for dark mode across all themes.
</Update>
```

## 添加描述

在日期下方添加上下文说明：

<Update label="January 5, 2025" description="Breaking change">
The `getData()` function now requires an options object.
</Update>

```mdx
<Update label="January 5, 2025" description="Breaking change">
The `getData()` function now requires an options object.
</Update>
```

## 添加标签

使用标签对条目进行分类：

<Update label="December 20, 2024" tags={["breaking", "api"]}>
- Removed deprecated `legacyMode` option
- Updated authentication flow
</Update>

```mdx
<Update label="December 20, 2024" tags={["breaking", "api"]}>
- Removed deprecated `legacyMode` option
- Updated authentication flow
</Update>
```

## 多个条目

堆叠多个 Update 组件即可构成完整的更新日志：

<Update label="December 15, 2024" tags={["feature"]}>
New export functionality for PDF and CSV formats.
</Update>

<Update label="December 10, 2024" tags={["fix"]}>
Fixed timezone handling in scheduled posts.
</Update>

<Update label="December 1, 2024" tags={["deprecation"]}>
The `v1` API endpoints are now deprecated. Migrate to `v2` by March 2025.
</Update>

## 锚点链接和目录

每个 Update 会根据其 label 生成锚点 ID（`label="January 10, 2025"` 会生成 `#january-10-2025`）。label 也会显示在目录中，便于快速导航。

## 属性

<ParamField name="label" type="string">
  日期或版本标签（用于生成锚点 ID）。
</ParamField>

<ParamField name="description" type="string">
  标签下方的辅助文本。
</ParamField>

<ParamField name="tags" type="string[]">
  以徽章形式显示的分类标签。
</ParamField>

<ParamField name="date" type="string">
  ISO 日期字符串（例如 `"2025-03-15"`），用于 RSS 订阅源的 `pubDate`。不会在页面上显示；`label` 仍是你展示给读者的文本。
</ParamField>

## RSS Feed

在包含 Update 组件的任意页面上添加 `rss: true`。Jamdesk 会在构建时生成 `feed.xml`。读者可订阅它以获取更新日志。

```yaml
---
title: Changelog
rss: true
---
```

启用后：
- 页面标题旁会出现 RSS 图标，链接到订阅源
- `<head>` 中会添加 `<link rel="alternate">` 标签，供 RSS 阅读器和浏览器自动发现
- 每个 `<Update>` 会成为一个 RSS 条目，以其 label 作为标题，并附带指向该条目的锚点链接

### 设置发布日期

使用 `date` 属性为订阅源中的每个条目设置 `<pubDate>`。若不设置 `date`，条目仍会出现在订阅源中，但没有时间戳。

```mdx
<Update label="March 2025" date="2025-03-15" tags={["feature"]}>
Added dark mode support across all themes.
</Update>
```

### Feed 内容

RSS 订阅源仅包含纯文本。Markdown 格式、MDX 组件、代码块和 HTML 都会从订阅源描述中剥离。请将第一句写成无需格式也能读懂的摘要。

### Feed URL

订阅源位于 `/cn/feed.xml`（如果你的站点使用 [hostAtDocs](/cn/deploy/custom-domains)，则为 `/cn/docs/feed.xml`）。

生成的订阅源如下所示：

```xml
<?xml version="1.0" encoding="UTF-8"?>
<rss version="2.0" xmlns:atom="http://www.w3.org/2005/Atom">
  <channel>
    <title>Acme Docs Changelog</title>
    <link>https://docs.acme.com</link>
    <description>Updates and changelog for Acme Docs</description>
    <item>
      <title>March 2025 — New dashboard</title>
      <link>https://docs.acme.com/changelog#march-2025</link>
      <pubDate>Sat, 15 Mar 2025 00:00:00 GMT</pubDate>
      <description>Added dark mode support across all themes.</description>
    </item>
  </channel>
</rss>
```

### 与其他工具集成

将订阅源 URL 添加到任何兼容 RSS 的服务中：

- Slack：将 `/feed` [RSS 应用](https://slack.com/apps/A0F81R7U7-rss) 添加到频道。
- Discord：使用 [MonitoRSS](https://monitorss.xyz/) 或类似机器人自动发布更新。
- 邮件：将订阅源连接到 [Zapier](https://zapier.com/) 或 [IFTTT](https://ifttt.com/)，在有新条目时向订阅者发送邮件。
- 浏览器：Safari、Vivaldi 以及 Firefox（通过扩展）原生支持 RSS。

<Tip>
  如有需要，可在多个页面上添加 `rss: true`。Jamdesk 会将所有启用 RSS 的页面中的 Update 条目合并到一个全站 `feed.xml` 中。
</Tip>

## 最佳实践

<AccordionGroup>
  <Accordion title="使用唯一的 label" icon="fingerprint" defaultOpen>
    每个 label 都会生成一个锚点 ID。保持 label 唯一，以确保深层链接可以正常解析：
    - 使用具体日期：`January 10, 2025`（而不仅是 `January 2025`）
    - 包含版本号：`v2.1.0` 与 `v2.0.0`
    - 重复的 label 会产生重复的 ID，并导致锚点链接失效
  </Accordion>

  <Accordion title="使用一致的日期格式" icon="calendar">
    选择一种格式并始终保持一致：
    - `January 10, 2025`（推荐）
    - `2025-01-10`（ISO 格式）
    - `v2.0.0`（适用于基于版本的更新日志）
  </Accordion>

  <Accordion title="使用有意义的标签" icon="tags">
    常用标签会自动配色：

    | 标签 | 颜色 | 用途 |
    |-----|-------|---------|
    | `breaking` | 红色 | 破坏性变更 |
    | `feature` / `new` | 绿色 | 新功能 |
    | `deprecation` / `deprecated` | 琥珀色 | 已弃用的功能 |
    | 其他标签 | 灰色 | 通用分类，如 `api`、`fix` |
  </Accordion>

  <Accordion title="保持条目易于浏览" icon="eye">
    - 将最重要的变化放在最前面
    - 多项变化使用项目符号列出
    - 复杂变化可链接到详细文档
  </Accordion>
</AccordionGroup>
