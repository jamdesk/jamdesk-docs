title: Card
description: >-
  了解如何使用 Card 组件构建可点击、带样式的容器，包含图标、图片、链接和 CTA，适用于网格布局。
---

`<Card>` 组件是一个可点击的带样式容器。使用它链接到其他页面，或对相关内容进行分组。将卡片与 `<Columns>` 搭配使用，可以构建网格布局。

## 用法

```mdx
<Card title="Quickstart" icon="rocket" href="/quickstart">
  Launch your docs in minutes.
</Card>
```

## 基础卡片

带标题的卡片：

<Card title="开始使用">
  在五分钟内完成第一个项目的设置。
</Card>

```mdx
<Card title="Getting Started">
  Set up your first project in under five minutes.
</Card>
```

## 带图标的卡片

添加图标：

<Card title="文档" icon="book">
  浏览完整文档，了解所有功能。
</Card>

```mdx
<Card title="Documentation" icon="book">
  Explore our complete documentation to learn all features.
</Card>
```

## 带链接的卡片

卡片可以链接到其他页面：

<Card title="API 参考" icon="code" href="/cn/introduction">
  查看完整的 API 文档。
</Card>

```mdx
<Card title="API Reference" icon="code" href="/introduction">
  View the complete API documentation.
</Card>
```

## 带箭头的卡片

添加箭头以表明卡片是链接。外部链接会自动显示箭头。对于内部链接，可通过 `arrow={true}` 启用：

<Card title="Quickstart" icon="github" href="/cn/quickstart" arrow={true}>
  查看源代码并参与贡献。
</Card>

```mdx
<Card title="Quickstart" icon="github" href="/quickstart" arrow={true}>
  Check out the source code and contribute.
</Card>
```

外部链接会自动显示箭头：

<Card title="外部资源" href="https://example.com">
  此卡片链接到外部网站。
</Card>

```mdx
<Card title="External Resource" href="https://example.com">
  This card links to an external site.
</Card>
```

## 带 CTA 的卡片

在卡片内容下方添加行动号召文字：

<Card title="Quickstart" icon="star" href="/cn/quickstart" cta="立即升级">
  解锁高级功能和优先支持。
</Card>

```mdx
<Card title="Quickstart" icon="star" href="/quickstart" cta="Upgrade now">
  Unlock advanced features and priority support.
</Card>
```

组合箭头与 CTA：

<Card title="Quickstart" icon="rocket" href="/cn/quickstart" arrow={true} cta="开始构建">
  启动第一个项目所需的一切。
</Card>

```mdx
<Card title="Quickstart" icon="rocket" href="/quickstart" arrow={true} cta="Start building">
  Everything you need to launch your first project.
</Card>
```

## 带图片的卡片

在卡片顶部显示图片：

<Card title="视觉指南" img="/images/card-example-1.webp">
  带有图片标题的卡片。
</Card>

```mdx
<Card title="Visual Guide" img="/images/card-example.webp">
  A card featuring an image header.
</Card>
```

## 使用 Columns 构建卡片网格

使用 `Columns` 将卡片排列为响应式网格：

<Columns cols={2}>
  <Card title="Quickstart" icon="rocket" href="/cn/quickstart">
    几分钟内即可上手运行。
  </Card>
  <Card title="教程" icon="graduation-cap" href="/cn/content/mdx-basics">
    循序渐进的学习路径。
  </Card>
  <Card title="示例" icon="flask" href="/cn/components/overview">
    真实场景的代码示例。
  </Card>
</Columns>

```mdx
<Columns cols={2}>
  <Card title="Quickstart" icon="rocket" href="/quickstart">
    Get up and running in minutes.
  </Card>
  <Card title="Tutorials" icon="graduation-cap" href="/content/mdx-basics">
    Step-by-step learning paths.
  </Card>
  <Card title="Examples" icon="flask" href="/components/overview">
    Real-world code examples.
  </Card>

</Columns>
```

### 三列布局

<Columns cols={3}>
  <Card title="文档" icon="book">
    文档
  </Card>
  <Card title="API" icon="code">
    API 参考
  </Card>
  <Card title="博客" icon="newspaper">
    最新动态
  </Card>
</Columns>

```mdx
<Columns cols={3}>
  <Card title="Docs" icon="book">
    Documentation
  </Card>
  <Card title="API" icon="code">
    API Reference
  </Card>
  <Card title="Blog" icon="newspaper">
    Latest updates
  </Card>
</Columns>
```

## Props

<ParamField name="title" type="string" required>
  显示在卡片顶部的标题。
</ParamField>

<ParamField name="icon" type="string">
  Font Awesome 图标名称（例如 "book"、"code"、"rocket"）。默认以 Solid 样式渲染。添加样式前缀（如 `light/book`）可更改字重。参见 [图标](/cn/content/icons)。
</ParamField>

<ParamField name="href" type="string">
  卡片链接的 URL。可以是内部链接（`/docs/intro`）或外部链接（`https://example.com`）。
</ParamField>

<ParamField name="img" type="string">
  显示在卡片顶部的图片路径。
</ParamField>

<ParamField name="arrow" type="boolean">
  在右上角显示箭头指示器（↗）。外部链接（以 `http://` 或 `https://` 开头的 URL）自动启用。设为 `true` 可在内部链接上显示，设为 `false` 可在外部链接上隐藏。
</ParamField>

<ParamField name="cta" type="string">
  显示在卡片内容下方的自定义行动号召文字。仅在设置了 `href` 时显示。
</ParamField>

## Columns Props

<ParamField name="cols" type="number" default="2">
  网格中的列数。可选值为 1、2、3 或 4。
</ParamField>
