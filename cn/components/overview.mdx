Jamdesk 提供可在任何页面中使用的 MDX 组件。

## 用法

将组件添加到您的 MDX 中：

```mdx
<Card title="Quickstart" icon="rocket" href="/quickstart">
  Launch your docs in minutes.
</Card>
```

## 布局与导航

<Columns cols={3}>
  <Card title="Accordion" icon="chevron-down" href="/cn/components/accordion">
    可折叠的内容区块，读者可展开查看详细信息。适用于常见问题、功能列表和配置选项。
  </Card>
  <Card title="Card" icon="square" href="/cn/components/card">
    可点击的样式化容器，支持图标、图片、链接和行动号召，可排列成网格布局。
  </Card>
  <Card title="Columns" icon="columns" href="/cn/components/columns">
    响应式网格布局，可将卡片、磁贴和其他内容并排放置。会根据屏幕尺寸自动调整。
  </Card>
  <Card title="Frame" icon="image" href="/cn/components/frame">
    Frame 将图片和演示内容包裹在带边框的容器中，并可选择添加说明文字。
  </Card>
  <Card title="Panel" icon="sidebar" href="/cn/components/panel">
    将警告或快速参考等自定义内容固定在侧边栏中，读者滚动页面时内容始终可见。
  </Card>
  <Card title="Steps" icon="list-ol" href="/cn/components/steps">
    用于设置流程、教程和故障排除的编号分步指南，支持图标、代码块和嵌套内容。
  </Card>
  <Card title="Tabs" icon="folder" href="/cn/components/tabs">
    用于互斥内容（如包管理器或编程语言）的可切换面板。相同的标签页标题会在整个页面中同步。
  </Card>
  <Card title="Tile" icon="grid-2" href="/cn/components/tile">
    磁贴以带样式的图案背景和突出的图片区域展示内容预览。适用于集成、模板或视觉图库。
  </Card>
  <Card title="Tree" icon="folder-tree" href="/cn/components/tree">
    以可交互的展开/折叠和键盘导航展示文件和文件夹层级结构。适用于记录项目结构。
  </Card>
  <Card title="View" icon="window-maximize" href="/cn/components/view">
    为读者所选的框架或语言显示内容。整个区块会随所选项切换。
  </Card>
</Columns>

## 内容与强调

<Columns cols={3}>
  <Card title="Badge" icon="tag" href="/cn/components/badge">
    用于状态、分类和元数据的行内标签，提供 11 种颜色变体、4 种尺寸、图标、药丸形/圆角形状和描边轮廓。
  </Card>
  <Card title="Callouts" icon="circle-info" href="/cn/components/callouts">
    Note、Tip、Warning、Danger、Check 以及自定义 Callout 组件，用于突出关键信息。
  </Card>
  <Card title="Expandable" icon="expand" href="/cn/components/expandable">
    Expandable 为主内容流之外的可选内容创建显示/隐藏切换。
  </Card>
  <Card title="Tooltip" icon="message" href="/cn/components/tooltip">
    悬停时显示定义和上下文。定义术语、解释缩写，或链接到相关内容，同时不会让页面显得杂乱。
  </Card>
  <Card title="Update" icon="clock-rotate-left" href="/cn/components/update">
    时间线式的更新日志条目，包含日期、描述和分类标签。条目会显示在目录中。
  </Card>
  <Card title="Visibility" icon="eye" href="/cn/components/visibility">
    在同一页面上为人类读者和 AI 代理显示不同内容。仅供代理使用的上下文、说明和定义不会出现在渲染后的文档中。
  </Card>
</Columns>

## 代码与数据

<Columns cols={3}>
  <Card title="CodeGroup" icon="layer-group" href="/cn/components/code-group">
    以标签页界面显示代码块。以多种语言（如 cURL、Python 和 JavaScript）展示同一操作。
  </Card>
  <Card title="Examples" icon="code" href="/cn/components/examples">
    在桌面端将代码块（可选语言标签页）固定在粘性右侧边栏中，读者滚动时始终保持可见。
  </Card>
  <Card title="Fields" icon="list" href="/cn/components/fields">
    使用 ParamField 和 ResponseField 组件记录 API 参数和响应字段，包括类型、默认值和嵌套对象。
  </Card>
  <Card title="Prompt" icon="wand-magic-sparkles" href="/cn/components/prompt">
    使用 Prompt 呈现可复用的 AI 指令，支持复制、内置的打开操作、自定义目标位置、图标和紧凑显示选项。
  </Card>
  <Card title="Tables" icon="table" href="/cn/components/tables">
    将数据组织为行和列。可使用 Markdown 表格或 Table 组件，支持排序、高亮和跨行跨列。
  </Card>
</Columns>

  </Card>
</Columns>
