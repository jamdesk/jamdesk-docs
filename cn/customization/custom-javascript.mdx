title: 自定义 JavaScript
description: 为文档站点添加自定义 JavaScript，用于聊天组件、分析、第三方集成及其他客户端功能。
---

Jamdesk 支持添加自定义 JavaScript，并在文档站点的每个页面运行。你可以用它添加聊天组件、分析功能或所需的其他客户端脚本。

## 添加自定义 JavaScript

在文档目录中创建 JavaScript 文件，并在 `docs.json` 中引用：

```json docs.json
{
  "styling": {
    "js": "/script.js"
  }
}
```

```javascript script.js
// Your custom JavaScript runs on every page
console.log('Hello from custom JS!');
```

脚本会直接内联到页面 HTML 中，因此页面加载时就会执行。

## 自动检测

如果未配置 `styling.js`，Jamdesk 会自动检测项目根目录中的 `.js` 文件。只需将 `script.js` 放在 `docs.json` 旁边，系统就会将其包含在内。

```bash
my-docs/
├── docs.json
├── script.js      ← auto-detected
├── introduction.mdx
└── getting-started.mdx
```

在 `docs.json` 中配置 `styling.js` 后，自动检测将会停用，系统只会使用指定的文件。

<Note>自动检测会包含项目根目录中的**所有** `.js` 文件。如果文档目录中还有 `eslint.config.js` 或 `postcss.config.js` 之类的实用脚本，请在 `docs.json` 中使用 `styling.js`，明确指定要包含的文件。</Note>

## 多个文件

传入数组即可包含多个脚本：

```json docs.json
{
  "styling": {
    "js": ["/chat.js", "/analytics.js"]
  }
}
```

使用自动检测时，根目录中的所有 `.js` 文件都会按字母顺序包含。如果有 `analytics.js` 和 `chat.js`，它们会按此顺序加载。

## 示例

如需查看将脚本与 CSS 配合使用的详细演示，请参阅 [CSS 和 JS 示例](/cn/customization/custom-code-examples)。该示例会添加一个悬浮的 Ask AI 按钮和一个品牌色标题栏。

### 聊天小组件（Crisp）

```javascript script.js
window.$crisp = [];
window.CRISP_WEBSITE_ID = "your-website-id";
(function () {
  var d = document;
  var s = d.createElement("script");
  s.src = "https://client.crisp.chat/l.js";
  s.async = 1;
  d.getElementsByTagName("head")[0].appendChild(s);
})();
```

### 自定义分析

```javascript script.js
// Track outbound link clicks
document.addEventListener('click', function (e) {
  var link = e.target.closest('a[href^="http"]');
  if (link && !link.href.includes(window.location.hostname)) {
    console.log('Outbound click:', link.href);
    // Send to your analytics service
  }
});
```

### 反馈小组件

```javascript script.js
// Load a feedback widget after the page is ready
window.addEventListener('load', function () {
  var s = document.createElement('script');
  s.src = 'https://your-feedback-tool.com/widget.js';
  s.setAttribute('data-project', 'your-project-id');
  document.body.appendChild(s);
});
```

## 工作原理

构建过程中会读取 JavaScript 文件，并将其直接嵌入每个页面的 HTML 中。脚本标签会放在 `<body>` 末尾，因此代码运行时 DOM 已可用。

在 `jamdesk dev`（CLI 1.1.222 及更高版本）中也会运行自定义 JavaScript，因此你可以在推送前测试脚本。脚本抛出的错误会显示在浏览器控制台中。在 `jamdesk dev` 中，`window.__JAMDESK_DEV__` 的值为 `true`，因此你可以跳过分析等仅用于生产环境的代码：

```javascript
if (!window.__JAMDESK_DEV__) {
  // analytics, chat widgets and other production-only code
}
```

如果使用 `integrations.cookies` 配置了 Cookie 同意功能，脚本只会在已发布的网站上运行，并且只有在访客同意后才会运行。

访客首次加载网站时，脚本会运行一次。点击文档中的链接会切换页面内容，但不会完整重新加载页面，因此脚本不会再次运行。如果代码需要处理页面内容，请[监听页面变更](/cn/customization/custom-code-examples#每次页面更改后运行代码)。

## 限制

- 脚本会在**每个页面**上运行，无法指定特定页面
- 更改会在下一次**构建**时生效
- 脚本会**内联**到 HTML 中，而不会作为独立文件提供
- 对于分析功能，可以考虑改用内置的[集成](/cn/integrations/google-analytics)，它们会自动处理同意管理和性能优化
