Jamdesk 支持添加自定义 JavaScript，使其在文档站点的每个页面上运行。可将其用于聊天组件、分析或所需的其他客户端脚本。

## 添加自定义 JavaScript

在文档目录中创建 JavaScript 文件，并在 `docs.json` 中引用它：

```json docs.json
{
  "styling": {
    "js": "/script.js"
  }
}
```

```javascript script.js
// Your custom JavaScript runs on every page
console.log('Hello from custom JS!');
```

脚本会直接内嵌到页面 HTML 中，因此会在页面加载时执行。

## 自动检测

如果未配置 `styling.js`，Jamdesk 会自动检测项目根目录中的 `.js` 文件。只需将 `script.js` 放在 `docs.json` 旁边，系统便会将其包含在内。

```bash
my-docs/
├── docs.json
├── script.js      ← auto-detected
├── introduction.mdx
└── getting-started.mdx
```

在 `docs.json` 中配置 `styling.js` 后，自动检测会停用，系统只会使用指定的文件。

<Note>自动检测会包含项目根目录中的**所有** `.js` 文件。如果文档目录中还有 `eslint.config.js` 或 `postcss.config.js` 等实用脚本，请在 `docs.json` 中使用 `styling.js` 明确指定要包含的文件。</Note>

## 多个文件

传入数组即可包含多个脚本：

```json docs.json
{
  "styling": {
    "js": ["/chat.js", "/analytics.js"]
  }
}
```

使用自动检测时，根目录中的所有 `.js` 文件都会按字母顺序包含。如果有 `analytics.js` 和 `chat.js`，它们会按此顺序加载。

## 示例

如需查看将脚本与 CSS 配合使用的详细演示，请参阅 [CSS 与 JS 示例](/cn/customization/custom-code-examples)。示例会添加一个悬浮的 Ask AI 按钮和一个品牌色标题栏。

### 聊天小组件（Crisp）

```javascript script.js
window.$crisp = [];
window.CRISP_WEBSITE_ID = "your-website-id";
(function () {
  var d = document;
  var s = d.createElement("script");
  s.src = "https://client.crisp.chat/l.js";
  s.async = 1;
  d.getElementsByTagName("head")[0].appendChild(s);
})();
```

### 自定义分析

```javascript script.js
// Track outbound link clicks
document.addEventListener('click', function (e) {
  var link = e.target.closest('a[href^="http"]');
  if (link && !link.href.includes(window.location.hostname)) {
    console.log('Outbound click:', link.href);
    // Send to your analytics service
  }
});
```

### 反馈小组件

```javascript script.js
// Load a feedback widget after the page is ready
window.addEventListener('load', function () {
  var s = document.createElement('script');
  s.src = 'https://your-feedback-tool.com/widget.js';
  s.setAttribute('data-project', 'your-project-id');
  document.body.appendChild(s);
});
```

## 工作原理

构建过程中会读取 JavaScript 文件，并将其直接嵌入每个页面的 HTML 中。脚本标签位于 `<body>` 末尾，因此代码运行时 DOM 已就绪。

自定义 JavaScript 只会在已发布的网站上运行。`jamdesk dev` 不会加载这些脚本；如需在本地测试脚本，请将其粘贴到预览页面的浏览器控制台中。

访客首次加载网站时，脚本会运行一次。在文档中点击链接只会替换页面内容，不会完整重新加载页面，因此脚本不会再次运行。如果代码需要与页面内容交互，请[监听页面变化](/cn/customization/custom-code-examples#每次页面更改后运行代码)。

## 限制

- 脚本会在**每个页面**上运行，无法针对特定页面
- 更改会在下一次**构建**时生效；`jamdesk dev` 不会运行自定义脚本
- 脚本会**内嵌**到 HTML 中，而不会作为单独的文件提供
- 对于分析功能，可以考虑改用内置的[集成](/cn/integrations/google-analytics)，它会自动处理用户同意和性能问题
