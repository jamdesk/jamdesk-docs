品牌设置决定读者首先看到的视觉元素：标志、网站图标和导航链接。所有元素均支持浅色与深色模式变体。

## 徽标

将标志添加到导航栏标题中：

```json
{
  "logo": {
    "light": "/images/logo-light.webp",
    "dark": "/images/logo-dark.webp",
    "href": "https://yourcompany.com"
  }
}
```

| 字段 | 说明 |
|-------|-------------|
| `light` | 浅色模式下使用的标志（浅色背景上的深色标志） |
| `dark` | 深色模式下使用的标志（深色背景上的浅色标志） |
| `href` | 点击标志后跳转到的位置 |

<Tip>
使用 SVG 标志可确保在任何尺寸下都清晰显示。如果只有一个标志，可同时用于 `light` 和 `dark`。
</Tip>

### 徽标尺寸

标志的显示宽度最大为 120px。为获得最佳效果：
- 宽度：120-240px
- 高度：30-40px
- 格式：优先使用 SVG

## 网站图标

两种模式使用同一张图片：

```json
{
  "favicon": "/images/favicon.svg"
}
```

也可以为每种模式分别设置：

```json
{
  "favicon": {
    "light": "/images/favicon.svg",
    "dark": "/images/favicon-dark.svg"
  }
}
```

浅色模式下显示 `light` 网站图标，深色模式下显示 `dark`。`dark` 为可选项。省略时，两种模式都会使用 `light`。Jamdesk 会为主网站图标生成一个 `<link rel="icon">`，并为深色变体生成第二个带有 `media="(prefers-color-scheme: dark)"` 的链接。

支持的格式：SVG、PNG、ICO。

<Note>
如果希望只使用一个资源，可以使用描边和填充采用 `currentColor` 的 SVG，它也会自动适配：浏览器会替换为当前的前景色。
</Note>

## 网站名称

`name` 字段会显示在浏览器标签页和搜索结果中：

```json
{
  "name": "Acme Docs",
  "description": "Documentation for the Acme API"
}
```

可搭配 [`description`](#描述)，让搜索结果和链接预览显示实际文案，而不是通用的默认内容。

## 描述

`description` 字段是网站默认的 SEO 摘要。搜索引擎会在网站标题下方显示该摘要，社交平台则会将其用于链接预览：

```json
{
  "description": "Build, ship, and scale documentation with the Acme platform."
}
```

建议撰写 50-160 个字符，帮助读者判断是否要点击。自行设置了 `description` 前置元数据的页面会使用该值；其他页面则使用网站描述。

## 导航链接

在导航栏中添加链接：

```json
{
  "navbar": {
    "links": [
      { "label": "Blog", "href": "https://yourcompany.com/blog" },
      { "label": "Pricing", "href": "https://yourcompany.com/pricing" }
    ],
    "primary": {
      "type": "button",
      "label": "Get Started",
      "href": "https://app.yourcompany.com/signup"
    }
  }
}
```

### 链接选项

| 字段 | 类型 | 说明 |
|-------|------|-------------|
| `label` | string | 显示文本 |
| `href` | string | URL（外部或内部） |

### 主要按钮

`primary` 字段会创建一个突出显示的行动号召按钮：

```json
{
  "primary": {
    "type": "button",
    "label": "Dashboard",
    "href": "https://app.yourcompany.com"
  }
}
```

在平板电脑和桌面设备上，链接和主按钮会显示在页眉中。手机屏幕的页眉没有足够空间，因此这些内容会显示在菜单中，主按钮则固定在底部。Pulsar 不会显示导航栏链接或主按钮。

## 页脚

在文档页脚中添加社交链接和自定义链接列。

### 社交链接

在每个页面底部显示社交媒体图标：

```json
{
  "footer": {
    "socials": {
      "github": "https://github.com/yourcompany",
      "x": "https://x.com/yourcompany",
      "discord": "https://discord.gg/yourserver",
      "linkedin": "https://linkedin.com/company/yourcompany"
    }
  }
}
```

#### 支持的平台

| 平台 | 键 | 说明 |
|----------|-----|-------------|
| GitHub | `github` | 链接到 GitHub 组织或代码库 |
| X (Twitter) | `x` 或 `twitter` | 链接到 X/Twitter 个人资料 |
| LinkedIn | `linkedin` | 链接到公司 LinkedIn 页面 |
| Discord | `discord` | 链接到 Discord 服务器 |
| Slack | `slack` | 链接到 Slack 社区 |
| YouTube | `youtube` | 链接到 YouTube 频道 |
| Instagram | `instagram` | 链接到 Instagram 个人资料 |
| Facebook | `facebook` | 链接到 Facebook 页面 |
| Reddit | `reddit` | 链接到 subreddit |
| Telegram | `telegram` | 链接到 Telegram 频道 |
| Bluesky | `bluesky` | 链接到 Bluesky 个人资料 |
| Threads | `threads` | 链接到 Threads 个人资料 |
| Medium | `medium` | 链接到 Medium 出版物 |
| Hacker News | `hacker-news` | 链接到 Hacker News 个人资料 |
| 网站 | `website` | 链接到主网站 |

<Tip>
无论如何在配置中定义图标，图标都会按固定顺序显示。GitHub 和 X/Twitter 排在前面，其他平台随后显示。
</Tip>

### 链接列

在社交图标上方添加分类整理的链接组：

```json
{
  "footer": {
    "links": [
      {
        "header": "Resources",
        "items": [
          { "label": "Blog", "href": "https://yourcompany.com/blog" },
          { "label": "Changelog", "href": "/changelog" }
        ]
      },
      {
        "header": "Company",
        "items": [
          { "label": "About", "href": "https://yourcompany.com/about" },
          { "label": "Careers", "href": "https://yourcompany.com/careers" }
        ]
      }
    ],
    "socials": {
      "github": "https://github.com/yourcompany",
      "x": "https://x.com/yourcompany"
    }
  }
}
```

| 字段 | 类型 | 说明 |
|-------|------|-------------|
| `links` | array | 链接列对象数组 |
| `links[].header` | string | 列标题（可选） |
| `links[].items` | array | 列中的链接 |
| `links[].items[].label` | string | 链接的显示文本 |
| `links[].items[].href` | string | URL（内部路径或外部 URL） |

<Note>
外部链接（以 `http` 开头）会自动在新标签页中打开。内部链接会在文档站点内跳转。
</Note>

### 在特定页面隐藏页脚

使用前置元数据，在个别页面隐藏页脚：

```yaml
---
title: Landing Page
hideFooter: true
---
```

适用于自定义着陆页，或页脚会分散读者注意力的页面。

## Jamdesk 品牌

默认情况下，文档页面的页脚中会显示“Powered by Jamdesk”链接，帮助其他团队了解 Jamdesk。如果需要，也可以将其移除。

### 隐藏品牌标识

移除 Jamdesk 品牌标识：

1. 在 Jamdesk 仪表板中前往 **Settings**
2. 找到 **Build Settings** 部分
3. 关闭 **Show Jamdesk Branding**
4. 触发一次新构建

<Note>
所有套餐均可使用品牌标识开关。更改需要重新构建才能生效。
</Note>

## 完整品牌配置示例

以下是完整的品牌配置：

```json
{
  "name": "Acme Documentation",
  "description": "Build amazing products with Acme",
  "theme": "jam",
  "colors": {
    "primary": "#6366F1",
    "light": "#818CF8",
    "dark": "#4F46E5"
  },
  "favicon": "/images/favicon.svg",
  "logo": {
    "light": "/images/logo-dark.webp",
    "dark": "/images/logo-light.webp",
    "href": "https://acme.com"
  },
  "navbar": {
    "links": [
      { "label": "API", "href": "/api/overview" },
      { "label": "Blog", "href": "https://acme.com/blog" }
    ],
    "primary": {
      "type": "button",
      "label": "Sign Up",
      "href": "https://app.acme.com/signup"
    }
  },
  "footer": {
    "socials": {
      "github": "https://github.com/acme",
      "x": "https://x.com/acme",
      "discord": "https://discord.gg/acme"
    },
    "links": [
      {
        "header": "Resources",
        "items": [
          { "label": "Blog", "href": "https://acme.com/blog" },
          { "label": "Status", "href": "https://status.acme.com" }
        ]
      }
    ]
  }
}
```

## 自定义域名

在 Jamdesk 仪表板中添加域名：

1. 前往 **Settings** → **Domains**
2. 添加域名（例如 `docs.yourcompany.com`）
3. 按照说明配置 DNS
4. 等待验证完成

配置后，读者即可通过自定义域名访问文档，SSL 也会自动启用。
