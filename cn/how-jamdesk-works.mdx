Jamdesk 从 GitHub 仓库中的 MDX 文件构建文档站点。你可以使用 React 组件编写 Markdown，推送到 GitHub，网站便会在 60 秒内通过全球 CDN 上线。内容以纯 MDX 文件的形式保留在你的仓库中，因此你随时可以将其迁移到其他工具。

## 架构概览

你的仓库是内容的唯一可信来源。Jamdesk 连接到仓库、构建站点，并将其部署到全球边缘网络。你无需管理任何基础设施。

## 构建流程

从开始到完成通常需要 30–60 秒。构建速度很快，因为 Jamdesk 不会预渲染页面。原始内容会传送到边缘网络，访客请求页面时再按需渲染。

<Steps>
  <Step title="获取源文件">
    推送到已连接的 GitHub 分支（或在仪表板中点击 Rebuild）。Jamdesk 会克隆你的仓库并查找文档目录。
  </Step>
  <Step title="验证">
    系统会根据架构验证你的 `docs.json` 配置，并检查内部链接是否指向不存在的页面或无效锚点。
  </Step>
  <Step title="处理内容">
    Jamdesk 会根据你的内容生成搜索索引、[AI 聊天](/cn/ai/chat)嵌入、站点地图、[`llms.txt`](/cn/ai/llms-txt) 和重定向规则。
  </Step>
  <Step title="部署到边缘网络">
    内容会上传到 CDN，并分发到 300 多个边缘节点。传输时只包含变更文件，因此重新部署速度很快。
  </Step>
</Steps>

## 每个站点内置的功能

每个站点默认都包含以下功能，无需配置。

<Columns cols={2}>
  <Card title="AI 搜索" icon="magnifying-glass" href="/cn/ai/chat">
    支持自然语言搜索，能够理解用户意图，而不只是匹配关键词。构建时根据你的内容生成向量嵌入，为搜索提供支持。
  </Card>
  <Card title="llms.txt" icon="robot" href="/cn/ai/llms-txt">
    遵循 llmstxt.org 规范的 AI 可读索引。编码助手和 AI 代理可以直接读取你的文档。
  </Card>
  <Card title="SEO 基础功能" icon="chart-line">
    包含站点地图、robots.txt、Open Graph 图片和元标记。首次部署后，你的文档即可被编入索引。
  </Card>
  <Card title="内置分析" icon="chart-bar" href="/cn/setup/analytics-overview">
    注重隐私的分析仪表板，无需使用 Cookie。你也可以接入自己的分析工具：Jamdesk 支持 Google Analytics、Plausible、PostHog 等。
  </Card>
</Columns>

## 什么会触发构建

推送到已连接的分支、点击仪表板中的 Rebuild 按钮，或通过 CLI 运行 [`jamdesk deploy`](/cn/cli/deploy)，都会触发构建。如果你在短时间内推送多个提交，Jamdesk 会对它们进行防抖处理，合并为一次构建，避免浪费资源。

如需了解运行细节（状态监控、回滚、分支部署），请参阅[构建与部署生命周期](/cn/deploy/lifecycle)。

## 安全性与基础设施

你无需操心这些细节；如果安全团队有疑问，可以告知他们：构建在隔离容器中运行，且 GitHub App 连接为只读。

<Columns cols={2}>
  <Card title="最小权限" icon="shield-check">
    GitHub App 仅请求读取你所选仓库的权限。该应用没有写入权限，也不会请求组织范围的权限。
  </Card>
  <Card title="隔离构建" icon="box">
    每次构建都会使用独立容器，该容器会在部署后销毁。不同构建或客户之间不会保留任何数据。
  </Card>
  <Card title="全程使用 HTTPS" icon="lock">
    为自定义域名和子域名自动配置 SSL 证书。证书会自动签发和续期。
  </Card>
  <Card title="全球 CDN" icon="globe">
    内容通过 Cloudflare 网络提供，该网络拥有 300 多个边缘节点，正常运行时间达 99.9%。
  </Card>
</Columns>

## 性能

文档能否被找到，部分取决于加载速度。Google 将 [Core Web Vitals](https://jamdesk.com/blog/why-google-pagespeed-matters) 作为排名信号；GPTBot 和 ClaudeBot 等 AI 爬虫通常只会为每个页面留出 1–5 秒。如果文档未能在这段时间内加载，就不会被引用。

每个 Jamdesk 站点都从边缘网络提供内容，首字节时间低于 50 毫秒。这一速度足以满足 Google 的排名阈值，也能让 AI 爬虫及时抓取并引用内容。

| 指标 | 典型值 |
|--------|---------------|
| 构建时间 | 30–60 秒 |
| 部署传播时间 | < 30 秒 |
| 首字节时间（边缘网络） | < 50ms |
| 完整页面加载时间 | < 500ms |
