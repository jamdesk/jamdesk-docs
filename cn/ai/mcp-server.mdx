每个 Jamdesk 站点都内置 MCP（Model Context Protocol）服务器。`llms.txt` 为 AI 工具提供文档的静态快照，而 MCP 可让它们以交互方式搜索和查询文档，适用于 AI 代理需要查找具体答案、而不是阅读全部内容的场景。

## 什么是 MCP？

[Model Context Protocol](https://modelcontextprotocol.io) 是一项开放标准，可让 AI 工具访问外部数据源。你的 Jamdesk 文档通过 MCP 提供两种工具：

| 工具 | 用途 |
|------|---------|
| `searchDocs` | 按关键词搜索文档，并返回排序后的结果 |
| `getPage` | 获取指定页面的完整内容 |

## 端点 URL

你的 MCP 端点是在文档 URL 后追加 `/_mcp`。如果你已启用[自定义域名](/cn/deploy/custom-domains)，请使用该域名：

| 设置 | 端点 |
|-------|----------|
| 使用自定义域名 `docs.acme.com` | `https://docs.acme.com/_mcp` |
| 未设置自定义域名 | `https://my-project.jamdesk.app/_mcp` |

<Note>
  只要已连接自定义域名，就优先使用该域名对应的端点。这样 AI 工具看到的每个 URL 都会保留你的品牌；即使之后通过[仅使用自定义域名](/cn/deploy/custom-domain-only)隐藏 `.jamdesk.app` 子域名，该端点仍可正常使用。
</Note>

## 快速设置

<Tabs>
  <Tab title="Claude Code">
    将文档添加为 MCP 服务器：

    ```bash
    claude mcp add --transport http my-docs https://docs.acme.com/_mcp
    ```

    将 `docs.acme.com` 替换为你的文档域名；如果尚未连接自定义域名，则替换为 `my-project.jamdesk.app`。

    之后，当你向 Claude 询问项目相关问题时，它就能直接搜索和阅读你的文档。
  </Tab>
  <Tab title="Cursor">
    将以下内容添加到项目的 `.cursor/mcp.json`：

    ```json
    {
      "mcpServers": {
        "my-docs": {
          "url": "https://docs.acme.com/_mcp"
        }
      }
    }
    ```

    打开项目时，Cursor 会自动连接到你的文档。
  </Tab>
</Tabs>

## 可用工具

### searchDocs

搜索文档并获取排序后的结果。

**参数：**

| 参数 | 类型 | 必填 | 说明 |
|-----------|------|----------|-------------|
| `query` | string | 是 | 搜索词（例如："authentication"、"getting started"） |
| `limit` | number | 否 | 结果数量上限（默认值：10，最大值：50） |
| `type` | string | 否 | 按内容类型筛选：`all`、`api`、`guide`、`quickstart`、`help`、`component` |

**请求示例：**

```json
{
  "jsonrpc": "2.0",
  "id": 1,
  "method": "tools/call",
  "params": {
    "name": "searchDocs",
    "arguments": {
      "query": "authentication",
      "limit": 5
    }
  }
}
```

**响应示例：**

```json
{
  "jsonrpc": "2.0",
  "id": 1,
  "result": {
    "content": [{
      "type": "text",
      "text": "{\"query\":\"authentication\",\"total\":1,\"results\":[{\"title\":\"Authentication\",\"description\":\"How to authenticate API requests\",\"url\":\"/docs/api/authentication\",\"type\":\"api\",\"score\":0.95}]}"
    }]
  }
}
```

### getPage

获取指定文档页面的完整内容。

**参数：**

| 参数 | 类型 | 必填 | 说明 |
|-----------|------|----------|-------------|
| `slug` | string | 是 | 不含 `/docs` 前缀的页面路径（例如：`api/authentication`） |

**请求示例：**

```json
{
  "jsonrpc": "2.0",
  "id": 2,
  "method": "tools/call",
  "params": {
    "name": "getPage",
    "arguments": {
      "slug": "api/authentication"
    }
  }
}
```

**响应示例：**

```json
{
  "jsonrpc": "2.0",
  "id": 2,
  "result": {
    "content": [{
      "type": "text",
      "text": "{\"title\":\"Authentication\",\"description\":\"How to authenticate\",\"content\":\"## Overview\\n\\nUse API keys to authenticate...\",\"url\":\"/docs/api/authentication\"}"
    }]
  }
}
```

## 测试端点

你可以使用 curl 直接测试 MCP 端点：

```bash
# List available tools
curl -X POST https://docs.acme.com/_mcp \
  -H "Content-Type: application/json" \
  -d '{"jsonrpc":"2.0","id":1,"method":"tools/list","params":{}}'

# Search for content
curl -X POST https://docs.acme.com/_mcp \
  -H "Content-Type: application/json" \
  -d '{"jsonrpc":"2.0","id":2,"method":"tools/call","params":{"name":"searchDocs","arguments":{"query":"getting started"}}}'
```

## 受登录保护的网站

如果你的网站使用密码或 JWT 身份验证，MCP 服务器需要项目 API 密钥。请在 **Project Settings > API Keys** 中创建密钥，并将其作为请求头发送：

```bash
claude mcp add --transport http my-docs https://docs.example.com/_mcp \
  --header "Authorization: Bearer jd_live_..."
```

使用密钥后，MCP 客户端可以搜索和阅读网站上可搜索的页面，也就是网站搜索涵盖的同一批页面。无论是否提供密钥，MCP 都不会提供受分组限制的页面。隐藏页面和设置了 `search: false` 的页面也不会包含在结果中，除非你已将它们设为可搜索。请像保护密码一样保护密钥；如果密钥泄露，请在仪表板中撤销。

未提供密钥时，服务器会返回 `401`，并在 JSON 响应正文中说明如何添加密钥。其他项目的密钥会被拒绝。错误代码如下：

| 状态 | `error` | 含义 |
|--------|---------|---------|
| 401 | `auth_required` | 未发送密钥。 |
| 401 | `invalid_api_key` | 此密钥对该站点无效。 |
| 503 | `auth_unavailable` | 无法验证该密钥。请等待 `Retry-After` 请求头中指定的秒数后重试。 |

## 工作原理

MCP 端点使用与文档一同构建的搜索索引：

- **BM25 排序** - 按相关性对结果排序
- **模糊匹配** - 处理拼写错误（容许 1 个字符的差异）
- **字段加权** - 标题和章节标题的权重高于正文内容
- **类型筛选** - 按内容类型筛选结果（API、指南等）

每次部署时都会重新构建索引。

## 速率限制

MCP 端点对每个 IP 地址的速率限制为每分钟 **60 个请求**。这足以满足 AI 助手的常规使用需求。超出限制时，你会收到 429 响应。

## 故障排除

<Accordion title="MCP 服务器无法连接">
  请确认端点 URL 正确且可访问：

  ```bash
  curl https://docs.acme.com/_mcp
  ```

  你应该会看到包含服务器信息的 JSON 响应。如果没有，请确认你的文档至少已构建过一次。
</Accordion>

<Accordion title="搜索未返回结果">
  搜索索引会在构建时生成。如果你最近添加了内容，请在 Jamdesk 仪表板中触发重新构建，以更新索引。
</Accordion>

<Accordion title="getPage 返回 null">
  请确认 slug 与页面路径完全一致（不含 `.mdx` 扩展名）。例如，如果页面路径为 `api/authentication.mdx`，slug 应使用 `api/authentication`。
</Accordion>

<Accordion title="受保护的网站返回 401 auth_required">
  该网站使用密码或 JWT 身份验证，因此请求需要项目 API 密钥。请添加 `Authorization: Bearer` 请求头，并使用在 **Project Settings > API Keys** 中创建的密钥。请参阅[受登录保护的网站](#受登录保护的网站)。
</Accordion>
