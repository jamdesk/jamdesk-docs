每个 Jamdesk 站点都内置聊天助手，可根据文档回答访客的问题。助手会检索相关章节，将其发送给 Claude，并实时返回附有源页面链接的回答。所有套餐默认启用聊天，无需额外付费。

## 使用场景

<Tabs>
  <Tab title="API 接入">
    开发者在集成你的 API 时询问 *"如何对请求进行身份验证？"*，即可获得准确的操作步骤和代码示例，以及指向源页面的链接。
  </Tab>
  <Tab title="故障排除">
    *"我的构建因超时错误而失败了"*

    访客无需逐页查找，就能在几秒内从故障排除指南中找到相关解决方法。
  </Tab>
  <Tab title="快速参考">
    回访用户可能会问 *"/users 端点接受哪些参数？"*，聊天助手会调取端点文档，并直接返回参数表。
  </Tab>
</Tabs>

## 工作原理

<Steps>
  <Step title="构建时为文档建立索引">
    每次构建时，Jamdesk 都会将页面拆分为多个章节，并将其保存为可搜索的嵌入向量。
  </Step>
  <Step title="访客提出问题">
    点击“Ask AI”按钮（或按 Cmd+I / Ctrl+I）即可在任意页面打开聊天面板。
  </Step>
  <Step title="AI 根据文档回答">
    系统会检索相关章节，将其作为上下文发送给 Claude，并实时返回附有源页面引用链接的回答。
  </Step>
</Steps>

## 功能

| 功能 | 详情 |
|---------|--------|
| 流式响应 | 实时收到回答 |
| 引用链接 | 每条回答都会链接到其引用的文档页面 |
| 消歧 | 如果问题匹配多个主题，AI 会询问访客具体指的是哪一个 |
| 对话上下文 | 保存 10 条消息的历史记录，按浏览器标签页分别存储 |
| 推荐问题 | 根据文档自动生成，也可以在 docs.json 中自行设置 |
| 键盘快捷键 | 按 Cmd+I / Ctrl+I 切换，按 Escape 关闭 |
| Markdown 渲染 | 在回答中渲染代码块、表格和列表 |

## 配置

聊天开箱即用，无需配置。只有在需要自定义推荐问题、重命名按钮、更改图标或关闭聊天时，才需要在 `docs.json` 中添加 `chat` 块。`chat` 字段为可选项，每项设置都有默认值。

```json docs.json
{
  "chat": {
    "enabled": true,
    "starterQuestions": [
      "How do I get started?",
      "What API endpoints are available?"
    ]
  }
}
```

| 字段 | 类型 | 默认值 | 说明 |
|-------|------|---------|-------------|
| `enabled` | boolean | `true` | 设置为 `false`，即可从站点中移除 Ask AI 按钮、聊天面板和键盘快捷键 |
| `starterQuestions` | string[] | auto-generated | 面板打开时显示的最多 4 个问题（每个问题 5–200 个字符）。省略时会根据文档自动生成；设置为 `[]` 则不显示问题 |
| `label` | string | "Ask AI" in the page's language | 替换聊天按钮、面板标题和搜索快捷键上的 "Ask AI"。最多 40 个字符。适用于所有语言。 |
| `icon` | string | `sparkles` | Font Awesome 图标名称、图片 URL 或项目中的图片路径。Font Awesome 图标会采用强调色；图片则按原样显示，因此请使用在浅色和深色背景上都清晰可见的图片。 |

### 推荐问题

推荐问题是访客在聊天面板中输入内容前看到的提示问题，点击即可提问，帮助访客了解可以询问哪些内容。如果不在 `docs.json` 中设置 `starterQuestions`，Jamdesk 会在每次构建时根据文档自动生成推荐问题，让问题随着文档内容扩展而保持相关。

如需自行设置，请将问题列在 `starterQuestions` 数组中。如果支持团队经常收到相同的问题，这种方式很实用，可以优先展示这些问题：

```json docs.json
{
  "chat": {
    "starterQuestions": [
      "How do notifications work?",
      "Tell me more about analytics"
    ]
  }
}
```

最多可设置 4 个推荐问题，每个问题长度为 5 到 200 个字符。如需完全不显示推荐问题，请将 `starterQuestions` 设置为空数组（`[]`）。

### 自定义名称和图标

默认情况下，聊天按钮、面板标题和搜索快捷键会显示“Ask AI”，并使用闪光图标。设置 `label` 和 `icon`，即可让它们符合你的产品风格：

```json docs.json
{
  "chat": {
    "label": "Acme Assistant",
    "icon": "/images/assistant.svg"
  }
}
```

网站的所有语言都会使用相同的标签。`robot` 这样的 `icon` 值是 Font Awesome 图标名称。以 `http://`、`https://` 或 `/` 开头，或以图片扩展名结尾的值会被视为图片。

### 关闭聊天

所有套餐默认启用聊天。如需关闭，请将 `enabled` 设置为 `false`。这会移除 Ask AI 按钮、聊天面板以及 `Cmd+I` / `Ctrl+I` 快捷键：

```json docs.json
{
  "chat": {
    "enabled": false
  }
}
```

<Note>
关闭聊天不会影响搜索。AI 聊天和搜索是独立功能，因此即使关闭聊天，访客仍然可以完整搜索你的文档。
</Note>

## 限制

| 限制 | 数值 |
|-------|-------|
| 消息长度上限 | 2,000 个字符 |
| 响应长度上限 | 2,048 个 token |
| 速率限制 | 每位访客在每个站点每 60 秒 10 个请求 |
| 对话历史 | 每个标签页 10 条消息 |
| 推荐问题 | 最多 4 个 |

聊天支持[自定义域名](/cn/deploy/custom-domains)。`/_chat` 端点与页面同源，因此在任何托管文档的域名上都能正常工作。

<Accordion title="检索流程的工作原理">
  每次构建时，Jamdesk 都会将页面拆分为多个章节，并为每个章节保存向量嵌入。访客提出问题时，系统会运行混合搜索（结合关键词匹配和语义相似度），从文档中找出最相关的章节。系统会将这些章节作为上下文发送给 Claude，并指示它仅根据提供的文档作答。系统会将 Claude 回答中的页面引用与检索到的章节进行匹配，从而提取引用。
</Accordion>
