当用户向 AI 工具询问你的产品时，这些工具往往依赖过时的训练数据，或者根本无法访问你的文档。每次 Jamdesk 构建都会生成三个 AI 端点（`llms.txt`、MCP 服务器和原始 Markdown URL）。AI 工具可以直接从这些端点读取最新文档，无需抓取 HTML。访客还可以使用内置的聊天助手，获得基于你的文档的回答。

<Tip>
  **查看你的文档评分。** Jamdesk 在每次构建时为你的文档评分。在仪表板中打开 [AI 评分](/cn/ai/ai-score)，即可查看你的等级以及需要修复的问题。免费的 [AI 评分工具](https://jamdesk.com/ai-score) 可基于开放的 [AFDocs](https://afdocs.dev) 标准为任何文档站点评分。使用 [AI 评分 Chrome 扩展](https://chromewebstore.google.com/detail/jamdesk-ai-score/mhihkkgpcbmapmojnakhjfhjmiagkhlj)，在浏览时即可为网站评分。
</Tip>

## 工作原理

<Steps>
  <Step title="编写 MDX">
    使用 Markdown 创建文档页面，并可选择使用 React 组件。
  </Step>
  <Step title="推送并构建">
    Jamdesk 构建你的站点，并在生成 HTML 的同时生成 AI 端点。
  </Step>
  <Step title="AI 工具连接">
    Claude、Cursor、ChatGPT 等工具通过 llms.txt、MCP 或原始 Markdown URL 读取你的文档。
  </Step>
</Steps>
