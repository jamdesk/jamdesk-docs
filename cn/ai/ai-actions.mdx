您的 Jamdesk 网站每个页面的标题上方都有一个 AI 操作菜单，这是一个小型下拉菜单。读者可以将页面复制为 Markdown、在 ChatGPT 中打开，或在 Cursor 中安装您的 MCP 服务器。无需任何配置。

## 内置选项

菜单默认包含八个选项，均已启用：

| 选项 | 键 | 功能 |
|--------|-----|-------------|
| **Copy page** | `copy` | 获取原始 Markdown 并复制到剪贴板 |
| **View as Markdown** | `view` | 在新标签页中打开 `.md` 文件 |
| **Open in ChatGPT** | `chatgpt` | 打开 ChatGPT，并附带一个用于阅读当前页面的提示 |
| **Open in Claude** | `claude` | 使用相同的提示打开 Claude |
| **Open in Perplexity** | `perplexity` | 使用相同的提示打开 Perplexity |
| **Copy MCP config** | `mcp` | 复制您网站的 [MCP 服务器](/cn/ai/mcp-server) 的 JSON 配置 |
| **Add to Cursor** | `cursor` | 通过深度链接在 Cursor 中安装 MCP 服务器 |
| **Add to VS Code** | `vscode` | 通过深度链接在 VS Code 中安装 MCP 服务器 |

Gemini 也可以通过 `gemini` 使用。它不在默认选项中，因为它无法可靠地从 URL 预填充提示。如果您的读者使用它，请显式添加。

当 `copy` 位于选项列表中时，它会成为主按钮。其余选项显示在带有下拉箭头的下拉菜单中。如果没有 `copy`，菜单会折叠为一个"AI Actions"下拉菜单。

### Download API spec

API 参考页面还会多一个选项：**Download API spec**。它会将您网站引用的所有 OpenAPI 规范（包括远程规范 URL）打包成一个 `api-specs.zip` 文件。您可以将该 zip 文件交给 Postman、客户端生成器或您自己的工具使用。多文件规范在 zip 中保留其文件夹结构，文件之间的 `$ref` 链接仍然有效。

无需任何配置。该选项仅显示在由 OpenAPI 规范支持的页面上。Jamdesk 会在每次下载时重新构建 zip 文件，因此它始终与您当前的规范保持一致。

## 配置

仅当您需要更改显示哪些选项或关闭菜单时，才需编辑 `docs.json`。

### 显示部分选项

```json docs.json
{
  "contextual": {
    "options": ["copy", "claude", "mcp"]
  }
}
```

### 禁用菜单

```json docs.json
{
  "contextual": {
    "enabled": false
  }
}
```

### 添加自定义选项

您可以将内置选项与自己的选项混合使用。自定义选项会在新标签页中打开其 URL。

```json docs.json
{
  "contextual": {
    "options": [
      "copy",
      "claude",
      {
        "title": "Ask on Discord",
        "description": "Get help from the community",
        "icon": "discord",
        "href": "https://discord.gg/your-server"
      }
    ]
  }
}
```

自定义选项可以选填 `icon` 字段。任何 [Font Awesome 图标名称](/cn/content/icons) 均可使用，包括 `discord` 或 `slack` 等品牌图标。未设置图标的选项会显示链接图标。

自定义选项还可以接受查询参数：

```json docs.json
{
  "contextual": {
    "options": [
      "copy",
      {
        "title": "Search in Notion",
        "description": "Find related internal docs",
        "href": {
          "base": "https://notion.so/search",
          "query": [
            { "key": "q", "value": "docs" }
          ]
        }
      }
    ]
  }
}
```

## 工作原理

该菜单在客户端运行。每次页面导航（包括无需完整刷新页面的侧边栏导航）时，其 URL 都会更新。"Open in Claude" 链接始终指向当前页面。

AI 服务链接会将页面的 `.md` URL 放入提示中，ChatGPT、Claude 和 Perplexity 会从该链接获取页面内容。

MCP 选项使用每个 Jamdesk 网站上的 `/_mcp` 端点。"Copy MCP config" 会复制适用于任何 MCP 客户端的 JSON。"Add to Cursor" 和 "Add to VS Code" 是打开编辑器安装流程的深度链接。有关 AI 工具可以通过它做什么，请参阅 [MCP 服务器](/cn/ai/mcp-server)。
