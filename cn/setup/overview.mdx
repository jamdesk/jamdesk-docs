每个 Jamdesk 网站的起点都相同：仪表板中的一个项目、与之关联的 GitHub 仓库，以及描述导航结构的 `docs.json` 文件。本节介绍初始设置，以及适合尽早确定的结构决策。在拥有五十个页面之前确定 URL 结构、语言和访问控制，远比之后再处理容易。

要从其他平台迁移？请直接前往[迁移指南](/cn/setup/migration)。Jamdesk 可以自动完成大部分转换工作。

## 从仓库到上线网站

<Steps>
  <Step title="创建项目">
    从模板开始，或连接现有的 GitHub 仓库。网站会在 `yourproject.jamdesk.app` 上线。
  </Step>
  <Step title="连接 GitHub">
    安装 GitHub App，让每次推送都自动部署。
  </Step>
  <Step title="整理仓库">
    一个 `docs.json` 文件加上 MDX 页面。这就是全部约定。
  </Step>
</Steps>
