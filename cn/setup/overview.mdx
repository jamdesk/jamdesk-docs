Jamdesk 站点由仪表板中的一个项目、背后的一个 GitHub 仓库，以及一个描述导航结构的 `docs.json` 文件组成。本节介绍这些设置。尽早确定 URL 结构、语言和访问控制，因为一旦页面数量达到五十个，这些内容就很难更改。

如果要从其他平台迁移，请参阅[迁移指南](/cn/setup/migration)。

## 从仓库到上线网站

<Steps>
  <Step title="创建项目">
    从模板开始，或连接现有的 GitHub 仓库。你的站点将上线于 `yourproject.jamdesk.app`。
  </Step>
  <Step title="连接 GitHub">
    安装 GitHub App，使每次推送都自动部署。
  </Step>
  <Step title="整理仓库">
    添加 `docs.json` 文件和 MDX 页面。
  </Step>
</Steps>
