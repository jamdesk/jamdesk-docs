使用内置分析功能跟踪页面浏览量、流量来源和热门内容。无需 Cookie。

屏幕截图显示的是英文界面。

<Note>
分析功能注重隐私：不使用 Cookie，数据经过匿名化处理。如果指标显示为空，请参阅[分析问题](/cn/help/troubleshooting/analytics-issues)。
</Note>

## 查看分析数据

<Steps>
  <Step title="打开项目">
    前往 [dashboard.jamdesk.com](https://dashboard.jamdesk.com) 并选择你的项目。
  </Step>

  <Step title="点击 Analytics">
    在侧边栏中，点击 **Analytics**。
  </Step>

  <Step title="选择日期范围">
    使用日期选择器选择时间段：

    - **Last 7 days**（默认）
    - **Last 30 days**
    - **Last 90 days**
    - **Custom range**
  </Step>
</Steps>

![项目分析仪表板](/images/project-analytics.webp)

## 跟踪的数据

### 概览指标

| 指标 | 说明 |
|--------|-------------|
| **访客数** | 所选时间段内的独立会话数 |
| **浏览量** | 页面浏览总数 |

每项指标都会显示与上一时间段相比的百分比变化。

示例数据：

```json
{
  "period": "Last 30 days",
  "visitors": 4120,
  "views": 12890,
  "top_referrers": ["google.com", "github.com", "direct"],
  "top_pages": ["/introduction", "/quickstart", "/content/mdx-basics"]
}
```

### 热门页面

查看流量最高的页面。你可以借此：

- 找出需要保持更新的高流量内容
- 找出互动率较低的页面
- 了解读者如何浏览文档

### 流量来源

查看访客来自哪里：

| 来源类型 | 示例 |
|-------------|----------|
| **搜索引擎** | Google、Bing、DuckDuckGo |
| **社交媒体** | Twitter、LinkedIn、Reddit |
| **直接访问** | 输入 URL 或使用书签 |
| **引荐流量** | 来自其他网站的链接 |

### 地理数据

在交互式世界地图上查看访客位置：

- **国家分布：** 按国家查看访客
- **热力图：** 颜色越深表示流量越高

根据国家分布决定本地化时应优先支持哪些语言。

### 技术分布

查看访客使用的设备和浏览器：

<Tabs>
  <Tab title="Browsers">
    - Chrome、Safari、Firefox、Edge
    - 发现特定浏览器的问题
  </Tab>
  <Tab title="Operating Systems">
    - Windows、macOS、Linux、iOS、Android
    - 比较桌面端和移动端受众
  </Tab>
  <Tab title="Devices">
    - 桌面设备、手机、平板电脑
    - 确定响应式设计的优先事项
  </Tab>
</Tabs>

### 进入页面与退出页面

| 指标 | 说明 |
|--------|---------------|
| **入口页** | 访客进入网站后访问的第一个页面 |
| **退出页** | 访客离开前访问的最后一个页面 |

利用这些数据：
- 改进落地页（入口页面）
- 找出读者离开的页面（退出页面）

## 隐私功能

<Columns cols={2}>
  <Card title="不使用 Cookie" icon="cookie-bite">
    会话使用随机 ID，并将其保存在浏览器标签页的会话存储中，而非 Cookie 中。在部分欧盟国家/地区，即使是此 ID，也可能需要获得用户同意；使用 `analytics.enabled` 关闭页面浏览分析。

  </Card>
  <Card title="符合 GDPR 要求" icon="shield-check">

  </Card>

## SPA 导航跟踪

Jamdesk 会将每次客户端导航都计为一次单独的页面浏览，即使页面没有完全重新加载。跟踪范围包括：
- 文档中的内部链接
- 浏览器的前进和后退导航
- 程序化导航

## 数据保留

原始事件会保留 90 天。每天的事件会汇总为每日总数。删除原始事件后，这些总数仍会保留。

## 比较时间段

仪表板会将所选时间段与长度相同的上一时间段进行比较：

- **Last 7 days** 与此前 7 天进行比较
- **Last 30 days** 与此前 30 天进行比较

百分比变化标记：
- 增长时显示**绿色**标记
- 下降时显示**红色**标记

通过比较数据，了解更改文档后的趋势。

## 最佳实践

<Accordion title="定期检查热门页面">
确保浏览量最高的页面内容准确且易于浏览。
</Accordion>

<Accordion title="监控入口页">
为来自搜索流量的页面提供足够的背景信息和明确的后续步骤。
</Accordion>

<Accordion title="检查设备分布">
如果大量流量来自移动设备，请在移动设备上测试文档。
</Accordion>

<Accordion title="跟踪引荐来源">
查看引荐数据，了解哪些渠道带来的流量最多。
</Accordion>
