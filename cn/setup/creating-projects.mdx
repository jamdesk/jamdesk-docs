title: 创建项目

---

编写文档前，你需要先创建一个项目。你可以从模板开始（Jamdesk 会在 GitHub 或 Bitbucket Cloud 上为你创建仓库），也可以连接已有的、包含 `docs.json` 的仓库。无论选择哪种方式，你都能在几分钟内上线网站。

## 创建新项目

<Steps>
  <Step title="登录 Jamdesk">
    前往 [dashboard.jamdesk.com](https://dashboard.jamdesk.com)，使用 GitHub 账户登录。

    首次使用的用户会收到授权 Jamdesk GitHub App 的提示。
  </Step>

  <Step title="点击 New Project">
    在仪表板右上角点击 **New Project**。
  </Step>

  <Step title="选择起始方式">
    <Tabs>
      <Tab title="使用模板">
        从预先构建的模板开始。Jamdesk 会为你创建一个新的 GitHub 仓库，其中已配置示例内容、导航和组件。

        默认的 [Starter Template](https://github.com/jamdesk/starter-docs) 包含示例页面、OpenAPI 规范以及每个组件的示例。替换为你自己的内容即可。
      </Tab>
      <Tab title="使用仓库">
        连接现有 GitHub 仓库：

        1. 从下拉菜单中选择仓库
        2. 选择要部署的分支（通常是 `main`）
        3. 如果 `docs.json` 不在根目录中，请指定其路径

        如果仓库位于 Bitbucket Cloud，请按 `workspace/repository-slug` 的格式输入。请参阅[连接 Bitbucket](/cn/setup/connecting-bitbucket)。
      </Tab>
    </Tabs>
  </Step>

  <Step title="配置项目设置">
    设置项目的基本信息：

    | 字段 | 说明 |
    |-------|-------------|
    | **Name** | 在仪表板中显示的名称 |
    | **Slug** | 适合用作 URL 的标识符（例如 `my-docs`） |
    | **Domain** | 你的 `*.jamdesk.app` 子域名 |
  </Step>
</Steps>

## 最小仓库结构

Jamdesk 项目只需要一个 `docs.json` 和至少一个页面：

```bash
my-docs/
├── docs.json
└── introduction.mdx
```

`docs.json` 示例：

```json docs.json
{
  "$schema": "https://jamdesk.com/docs.json",
  "name": "My Docs",
  "theme": "jam",
  "navigation": {
    "groups": [
      {
        "group": "Getting Started",
        "pages": ["introduction"]
      }
    ]
  }
}
```

## 项目设置

创建项目后，可在 **Settings** 中进行配置：

### General

- **Name** - 更新显示名称
- **Slug** - 更改项目标识符
- **Delete Project** - 永久删除项目

### Repository

- **Branch** - 触发部署的分支
- **Docs Path** - 单体仓库中 `docs.json` 的位置

### Domain

- **Subdomain** - 你的 `*.jamdesk.app` URL
- **Custom Domain** - 添加自己的域名
- **Host at a subpath** - 将文档托管在 `/docs` 或 `/help` 等路径下，而不是网站根目录

### Build

- **Show Jamdesk Branding** - 在页脚显示“Powered by Jamdesk”链接（默认启用）
- **Rebuild** - 手动触发新构建

<Note>
构建设置更改后，需要重新构建才能生效。
</Note>

## 项目限制

Pro 计划包含一个项目。你可以通过[项目附加项](/cn/help/billing/project-addons)添加更多项目，每个项目每月 $15。
