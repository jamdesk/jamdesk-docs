在编写任何文档之前，您需要先创建一个项目。您可以从模板开始，由 Jamdesk 在 GitHub 或 Bitbucket Cloud 上创建仓库；也可以连接一个已包含 `docs.json` 的现有仓库。您的网站将在几分钟内上线。如需在没有 GitHub 账户的情况下开始，请参阅 [无 GitHub 使用文档](/cn/setup/without-github)。

## 创建新项目

<Steps>
  <Step title="登录 Jamdesk">
    前往 [dashboard.jamdesk.com](https://dashboard.jamdesk.com)，并使用您的 GitHub 账户登录。

    首次登录时，Jamdesk 会提示您授权 Jamdesk GitHub App。
  </Step>

  <Step title="点击 New Project">
    在仪表板中，点击右上角的 **New Project**。
  </Step>

  <Step title="选择起始方式">
    <Tabs>
      <Tab title="从模板创建">
        从预置模板开始。Jamdesk 会创建一个新的 GitHub 仓库，其中已包含示例内容、导航和组件配置。

        默认的 [Starter Template](https://github.com/jamdesk/starter-docs) 包含示例页面、一个 OpenAPI 规范，以及每个组件的示例。您可以将内容替换为您自己的。
      </Tab>
      <Tab title="从仓库创建">
        连接一个现有的 GitHub 仓库：

        1. 从下拉列表中选择仓库
        2. 选择要部署的分支（通常为 `main`）
        3. 如果 `docs.json` 不在根目录，请指定其路径

        仓库位于 Bitbucket Cloud 上？请改为以 `workspace/repository-slug` 的形式输入。参阅 [连接 Bitbucket](/cn/setup/connecting-bitbucket)。
      </Tab>
    </Tabs>
  </Step>

  <Step title="配置项目设置">
    设置项目的基本信息：

    | 字段 | 说明 |
    |-------|-------------|
    | **Name** | 仪表板中显示的名称 |
    | **Slug** | 适用于 URL 的标识符（例如 `my-docs`） |
    | **Domain** | 您的 `*.jamdesk.app` 子域名 |
  </Step>
</Steps>

## 最小仓库结构

Jamdesk 项目只需要一个 `docs.json` 和至少一个页面：

```bash
my-docs/
├── docs.json
└── introduction.mdx
```

`docs.json` 示例：

```json docs.json
{
  "$schema": "https://jamdesk.com/docs.json",
  "name": "My Docs",
  "theme": "jam",
  "navigation": {
    "groups": [
      {
        "group": "Getting Started",
        "pages": ["introduction"]
      }
    ]
  }
}
```

## 项目设置

在 **Settings** 中配置您的项目：

### General

- **Name**：更新显示名称
- **Slug**：更改项目标识符
- **Delete Project**：永久删除项目

### Repository

- **Branch**：哪个分支会触发部署
- **Docs Path**：单体仓库（monorepo）中 `docs.json` 的位置

### Domain

- **Subdomain**：您的 `*.jamdesk.app` 网址
- **Custom Domain**：添加您自己的域名
- **Host at a subpath**：将文档托管在 `/docs` 或 `/help` 等子路径下，而不是站点根目录

### Build

- **Show Jamdesk Branding**：在页脚显示 "Powered by Jamdesk" 链接（默认启用）
- **Rebuild**：手动触发新的构建

<Note>
构建设置的更改需要新的构建才能生效。
</Note>

## 项目限制

Pro 套餐包含一个项目。如需更多项目，可通过[项目附加服务](/cn/help/billing/project-addons)添加，每个每月 15 美元。
