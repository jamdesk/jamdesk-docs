Jamdesk 可以为您翻译文档。在项目设置中选择语言。每次构建后，Jamdesk 会翻译您的英文页面，并将结果提交到您的 GitHub 仓库中带语言前缀的目录里。这些译文归您所有，保存在您的仓库和 Git 历史中。您可以像编辑其他文件一样编辑它们。

屏幕截图显示的是英文界面。

关于各语言的导航和语言切换器，请参阅[多语言支持](/cn/setup/languages)。无论译文来自 Jamdesk、您自己的译者还是其他工具，该配置均适用。

## 前提条件

- 项目的[已连接 GitHub 仓库](/cn/setup/connecting-github)。译后页面会提交回您的仓库。通过 CLI 或压缩包部署的项目无法使用此功能。
- Jamdesk GitHub App 需要具有写入权限才能完成该提交。翻译面板会标记缺失的权限，并提供链接，以便 GitHub 管理员授予权限。每个 GitHub 账户只需进行一次此操作。

所有套餐（包括试用版）均包含自动翻译。没有按字数计费，也无需购买积分。

## 开启翻译

<Steps>
  <Step title="打开翻译面板">
    前往 [Jamdesk 控制台](https://dashboard.jamdesk.com)中的项目，打开**设置**，然后滚动到**翻译**。
  </Step>

  <Step title="选择语言">
    打开**翻译我的文档**开关，并勾选您需要的语言。每种语言以其母语名称列出，旁边附有英文名称。

    <Frame>
      <img src="/images/translations/translations-settings.webp" alt="项目设置中的翻译面板。上方的“翻译我的文档”开关已打开，下方是带复选框的双列语言列表。已选中简体中文、葡萄牙语、德语和意大利语。每种语言以其母语名称列出，旁边附有英文名称。" />
    </Frame>
  </Step>

  <Step title="构建">
    构建完成后会运行翻译。首次运行会翻译所有页面，并将文件提交到您的仓库。像审查其他提交一样审查它们。
  </Step>
</Steps>

## 限制

限制以项目为单位：

| 限制 | 数值 |
|-------|-------|
| 每个项目的语言数 | 最多 5 种 |
| 每月翻译页面数 | 10,000 页 |

## 仅翻译发生变化的内容

首次运行会翻译全部内容。之后的运行只会重新翻译英文源文件发生变化的页面。修正一个页面的错别字只消耗一个页面的额度，而不是整个站点。稳定运行的站点只会占用每月额度的一小部分。

## Jamdesk 不会修改的翻译

Jamdesk 将两类译文视为您的作品，不会自动替换：

- **您已有的译文。** 开启该功能时，Jamdesk 会采用您仓库中已有的译后页面。它不会覆盖这些内容。您自己撰写或付费委托供应商完成的工作将保持不变。
- **您编辑过的译文。** Jamdesk 会检测您手动修改过的译后页面。您的措辞在之后的每次运行中都会保留。

这些页面处于永久保留状态。即使英文源文件发生变化，也不会被自动重新翻译。当其英文源文件变化时，它们会在翻译面板的**手动编辑**下列出。

列表中的每个页面都有**用 AI 译文替换**按钮。点击后，该页面会交回 AI 处理。您的版本将被丢弃。页面会在您的下一次构建时重新翻译，而不是在您点击按钮的那一刻。该按钮是解除保留状态的唯一方式。

<Note>
  “仅处理变更内容”不适用于这些页面。Jamdesk 翻译的页面会在其英文源文件变化时刷新。您撰写或编辑过的页面则需等待您主动请求。
</Note>

## 译后页面之间的链接

译后的标题会拥有各自的锚点，因此 `/de/setup/languages#…` 使用的是德语标题。Jamdesk 会保持这些锚点稳定：

- **重新翻译的页面会保留您未修改标题的措辞。** 添加或重命名一个英文标题时，只有该标题会重新翻译。其他页面指向该页面其余部分的链接仍会指向原来的位置。
- **您撰写或编辑过的页面，其失效的锚点会被修复。** 如果这些页面链接到锚点已变化的标题，Jamdesk 会更新链接中 `#` 之后的部分。页面的其他内容保持不变。

## 关闭语言

取消勾选某种语言即可停止向其翻译。不会删除任何内容。已提交的页面将保留在您的仓库中，内容不变。
