Jamdesk 可以为您翻译文档。在项目设置中选择语言。每次构建后，Jamdesk 会翻译您的英文页面，并将结果提交到您 GitHub 仓库中以语言前缀命名的目录中。译文归您所有，保存在您的仓库和 Git 历史中。您可以像编辑其他文件一样编辑它们。

屏幕截图显示的是英文界面。

关于各语言的导航和语言切换器，请参阅[多语言支持](/cn/setup/languages)。无论译文来自 Jamdesk、您自己的译者还是其他工具，该配置都同样适用。

## 前提条件

- 项目的[已连接 GitHub 仓库](/cn/setup/connecting-github)。译文页面会提交回您的仓库。通过 CLI 或压缩包部署的项目无法使用此功能。
- Jamdesk GitHub App 需要具备写入权限才能完成该提交。翻译面板会标记缺失的权限，并链接到 GitHub 管理员以授予权限。每个 GitHub 账户只需进行一次此操作。

所有套餐（包括试用版）都包含自动翻译。没有按字数计费，也无需购买额度。

## 开启翻译

<Steps>
  <Step title="打开翻译面板">
    进入您在 [Jamdesk 控制台](https://dashboard.jamdesk.com)中的项目，打开**设置**，然后滚动到**翻译**。
  </Step>

  <Step title="选择语言">
    打开**翻译我的文档**开关，并勾选您需要的语言。每种语言都以其母语名称列出，旁边标注英文名称。

    <Frame>
      <img src="/images/translations/translations-settings.webp" alt="项目设置中的翻译面板。上方的“翻译我的文档”开关已打开，下方是带复选框的两列语言列表。已选中简体中文、葡萄牙语、德语和意大利语。每种语言都以其母语名称列出，旁边标注英文名称。" />
    </Frame>
  </Step>

  <Step title="构建">
    构建完成后会运行翻译。首次运行会翻译所有页面，并将文件提交到您的仓库。请像审查其他提交一样审查它们。
  </Step>
</Steps>

## 限制

限制以项目为单位：

| 限制 | 数值 |
|-------|-------|
| 每个项目的语言数 | 最多 5 种 |
| 每月翻译的页面数 | 10,000 页 |

## 仅翻译发生变化的内容

首次运行会翻译全部内容。之后的运行只会重新翻译英文原文发生变化的页面。修正某一页的错别字只消耗一页的额度，而不是整个网站的额度。稳定运行的网站只占用每月额度的一小部分。

重新翻译的页面会保留您未改动的标题的译文。如果您新增或重命名某个英文标题，只有该标题会被重新翻译。其他页面指向本页其余部分的链接仍然有效。

## Jamdesk 不会修改的翻译

Jamdesk 将以下两类译文视为您自己编写的内容，不会自动替换：

- **您已有的译文。** 开启该功能时，Jamdesk 会采用您仓库中已有的译文页面，且不会覆盖。您自己编写或付费请供应商翻译的内容将保持不变。
- **您编辑过的译文。** Jamdesk 能检测到您手动修改过的译文页面。您的措辞在之后的每次运行中都会保留。

这些页面会被永久锁定。即使英文原文发生变化，它们也不会被自动重新翻译。当其英文原文变化时，它们会在翻译面板的**手动编辑**下列出。

有一项例外可以保证您的链接正常工作。如果其中某个页面链接到另一个已翻译页面中的某个标题，而该标题的锚点发生了变化，Jamdesk 会更新链接中 `#` 之后的部分。页面的其他内容不会改变。

列表中的每个页面都有一个**使用 AI 翻译替换**按钮，点击后将该页面交回 AI 处理。您的版本将被丢弃。该页面会在您的下一次构建时重新翻译，而不是在您点击按钮的那一刻。这个按钮是解除锁定的唯一方式。

<Note>
  “仅翻译有变化的内容”不适用于这些页面。Jamdesk 翻译过的页面会在其英文原文变化时自动刷新。您编写或编辑过的页面则需要您主动请求才会更新。
</Note>

## 关闭语言

取消勾选某种语言即可停止向其翻译。不会删除任何内容。已提交的页面将保留在您的仓库中，内容不变。
