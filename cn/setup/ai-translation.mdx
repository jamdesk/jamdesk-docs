> 屏幕截图显示的是英文界面。

Jamdesk 可以为您翻译文档。在项目设置中选择语言。Jamdesk 会在每次构建后翻译您的英文页面，并将结果以语言前缀目录的形式提交到您的 GitHub 仓库。译文归您所有，保存在您的仓库和 Git 历史中。您可以像编辑其他文件一样编辑它们。

有关各语言的导航和语言切换器，请参阅 [多语言支持](/cn/setup/languages)。无论译文来自 Jamdesk、您自己的译员还是其他工具，该配置都适用。

## 前提条件

- 项目的[已连接 GitHub 仓库](/cn/setup/connecting-github)。译文页面会提交回您的仓库。通过 CLI 或压缩包部署的项目无法使用此功能。
- Jamdesk GitHub App 需要具备提交该内容的写入权限。翻译面板会标记缺失的权限，并链接到 GitHub 管理员以便授予权限。每个 GitHub 账户只需进行一次。

所有套餐（包括试用版）都包含自动翻译功能。没有按字数计费，也无需购买额度。

## 开启翻译

<Steps>
  <Step title="打开翻译面板">
    进入您在 [Jamdesk 控制台](https://dashboard.jamdesk.com) 中的项目，打开 **Settings**，然后滚动到 **Translations**。
  </Step>

  <Step title="选择语言">
    开启 **Translate my documentation** 并勾选所需语言。每种语言均以其母语名称列出，旁边附有英文名称。

    <Frame>
      <img src="/images/translations/translations-settings.webp" alt="项目设置中的翻译面板。上方的 Translate my documentation 开关已打开，下方是带复选框的双列语言列表。已选中简体中文、葡萄牙语、德语和意大利语。每种语言均以其母语名称列出，旁边附有英文名称。" />
    </Frame>
  </Step>

  <Step title="构建">
    构建完成后开始翻译。首次运行会翻译所有页面，并将文件提交到您的仓库。像审查其他提交一样审查它们。
  </Step>
</Steps>

## 限制

限制以项目为单位：

| 限制 | 数值 |
|-------|-------|
| 每个项目的语言数 | 最多 5 种 |
| 每月翻译页面数 | 10,000 |

## 仅翻译发生变化的内容

首次运行会翻译全部内容。之后的运行只会重新翻译英文源内容发生变化的页面。修正某一页的错别字只消耗一页的额度，而不是整个站点。稳定运行的站点只会使用月度额度中的一小部分。

## Jamdesk 不会修改的翻译

Jamdesk 将以下两类译文视为您自己编写的内容，不会自动替换：

- **您已有的译文。** 启用该功能时，Jamdesk 会采用您仓库中已有的译文页面，不会覆盖。您自己编写或向供应商付费获得的内容将保持不变。
- **您编辑过的译文。** Jamdesk 能识别您手动修改过的译文页面。您的措辞在之后的每次运行中都会保留。

这些页面处于永久保留状态。即使其英文源内容发生变化，也不会被自动重新翻译。当英文源内容变化时，它们会在翻译面板的 **Edited by hand** 下列出。

列表中的每个页面都有一个 **Replace with AI translation** 按钮，点击后会将该页面交还给 AI。您的版本将被丢弃，页面会在您的下一次构建时重新翻译，而不是在您点击时立即翻译。该按钮是解除保留状态的唯一方式。

<Note>
  "仅翻译有变更的内容"不适用于这些页面。Jamdesk 翻译的页面会在英文源内容变化时刷新；您编写或编辑过的页面则会等待您主动请求。
</Note>

## 关闭语言

取消勾选某种语言即可停止向其翻译。不会删除任何内容，已提交的页面将保留在您的仓库中，保持不变。
