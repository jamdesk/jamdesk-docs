## 安装 GitHub App

首次登录 Jamdesk 时，系统会提示你安装 Jamdesk GitHub App。此应用支持以下功能：

- **仓库访问权限** - 读取文档内容
- **Webhook** - 在推送时触发构建
- **提交状态** - 在提交上显示构建状态

### 权限

Jamdesk GitHub App 会请求以下权限：

| 权限 | 用途 |
|------------|---------|
| 仓库内容（读取和写入） | 克隆并读取文档文件。仅当你在仪表板编辑器中保存、接受 Fix with AI 建议或开启翻译时，才会写入内容 |
| 元数据（读取） | 列出仓库和分支 |
| Webhook | 接收推送通知 |

<Note>
Jamdesk 只会访问你明确授权的仓库。你可以随时在 GitHub 设置中修改访问权限。
</Note>

## 连接仓库

<Steps>
  <Step title="选择仓库">
    创建或编辑项目时，点击 **Connect Repository**。

    从已安装 GitHub App 的仓库中选择。
  </Step>

  <Step title="选择分支">
    选择要部署的分支：

    - **main** 或 **master** - 最常用于生产环境文档
    - **docs** - 如果你将文档放在单独的分支中
    - 任意分支 - 用于预览部署
  </Step>

  <Step title="指定文档路径">
    如果 `docs.json` 不在仓库根目录中，请指定路径：

    ```bash
    docs/           # Docs in a subdirectory
    packages/docs/  # Monorepo with docs package
    ```

    如果 `docs.json` 位于根目录，请留空。
  </Step>
</Steps>

连接后，项目仪表板会显示已关联的仓库和分支：

## 自动部署

连接后，每次向已配置的分支推送都会触发构建：

```bash
git add .
git commit -m "Update API documentation"
git push origin main
```

构建通常会在 30-90 秒内完成。你可以在仪表板或 GitHub 提交页面查看状态。

## 更换仓库

要连接其他仓库：

1. 前往 **Settings** → **Repository**
2. 点击 **Change Repository**
3. 选择新的仓库和分支

<Warning>
更换仓库可能会影响线上文档。新仓库必须包含有效的 Jamdesk 配置。
</Warning>

## 管理 GitHub App 访问权限

控制 Jamdesk 可以访问哪些仓库：

1. 前往 [github.com/settings/installations](https://github.com/settings/installations)
2. 在列表中找到 **Jamdesk**
3. 点击 **Configure**
4. 在“Repository access”下，选择特定仓库或所有仓库

### 组织仓库

对于组织仓库，组织管理员必须批准 GitHub App 安装：

1. 在 Jamdesk 仪表板中请求安装
2. 管理员会收到 GitHub 通知
3. 批准后，组织仓库会显示在仓库选择器中

## 关联个人账户

为确保构建归属信息准确，请在 **User Settings** 中关联你的个人 GitHub 账户：

1. 点击头像 → **User Settings**
2. 找到 **GitHub Account** 部分
3. 点击 **Link GitHub Account**

此操作与 GitHub App 安装相互独立，可确保正确将提交归属到你的账户。[了解详情](/cn/integrations/github#个人-github-账户用户级)。

## 故障排除

### 找不到仓库

- 确认仓库已安装 GitHub App
- 对于组织仓库，请确认管理员已批准访问
- 尝试在仪表板中刷新仓库列表

### GitHub 不断将你带回 Jamdesk 应用页面

你的公司可能在管理你的 GitHub 账户，而 GitHub 不允许这类账户在自己的账户下安装应用。请参阅[公司管理的 GitHub 账户](/cn/help/troubleshooting/github-issues#公司托管的-github-账户)了解解决方法。

### 未触发构建

- 检查仓库设置中的 Webhook 是否处于启用状态
- 确认你推送到了已配置的分支
- 在 GitHub 中查看 Webhook 投递错误

### 权限被拒绝错误

- 在 GitHub 设置中重新授权 GitHub App
- 确保 Jamdesk App 可以访问该仓库

<Note>
  如需更详细的故障排除信息，请参阅[了解 GitHub 集成](/cn/integrations/github)。
</Note>
