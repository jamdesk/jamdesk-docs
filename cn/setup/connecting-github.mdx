Jamdesk 集成 GitHub，可在您推送更改时自动部署文档。

</Tip>

## 安装 GitHub App

首次登录 Jamdesk 时，系统会提示您安装 Jamdesk GitHub App。此应用支持：

- **仓库访问权限** - 读取您的文档内容
- **Webhooks** - 在推送时触发构建
- **提交状态** - 显示提交的构建状态

### 权限

Jamdesk GitHub App 请求以下权限：

| 权限 | 用途 |
|------------|---------|
| 仓库内容（读取） | 克隆并读取您的文档文件 |
| 元数据（读取） | 列出仓库和分支 |
| Webhooks | 接收推送通知 |

<Note>
Jamdesk 只会访问您明确授权的仓库。您可以随时在 GitHub 设置中修改访问权限。
</Note>

## 连接仓库

<Steps>
  <Step title="选择仓库">
    创建或编辑项目时，点击 **Connect Repository**。

    从已安装 GitHub App 的仓库中进行选择。
  </Step>

  <Step title="选择分支">
    选择要部署的分支：

    - **main** 或 **master** - 生产文档最常用的分支
    - **docs** - 如果您将文档保存在单独的分支中
    - 任意分支 - 用于预览部署
  </Step>

  <Step title="指定文档路径">
    如果 `docs.json` 不在仓库根目录中，请指定路径：

    ```bash
    docs/           # Docs in a subdirectory
    packages/docs/  # Monorepo with docs package
    ```

    如果 `docs.json` 位于根目录中，请留空。
  </Step>
</Steps>

连接后，项目仪表板会显示关联的仓库和分支：

## 自动部署

连接后，每次向已配置分支推送都会触发构建：

```bash
git add .
git commit -m "Update API documentation"
git push origin main
```

构建通常会在 30–90 秒内完成。您可以在仪表板或 GitHub 提交中查看状态。

## 更换仓库

要连接其他仓库：

1. 前往 **Settings** → **Repository**
2. 点击 **Change Repository**
3. 选择新的仓库和分支

<Warning>
更换仓库可能会影响您的在线文档。新仓库必须包含有效的 Jamdesk 配置。
</Warning>

## 管理 GitHub App 访问权限

控制 Jamdesk 可以访问哪些仓库：

1. 前往 [github.com/settings/installations](https://github.com/settings/installations)
2. 在列表中找到 **Jamdesk**
3. 点击 **Configure**
4. 在“Repository access”下，选择特定仓库或全部仓库

### 组织仓库

对于组织仓库，组织管理员必须批准 GitHub App 安装：

1. 从 Jamdesk 仪表板请求安装
2. 管理员会在 GitHub 中收到通知
3. 批准后，组织仓库会出现在仓库选择器中

## 关联个人账户

为了可靠地标记构建归属，请在 **User Settings** 中关联您的个人 GitHub 账户：

1. 点击您的头像 → **User Settings**
2. 找到 **GitHub Account** 部分
3. 点击 **Link GitHub Account**

此设置独立于 GitHub App，可确保正确将您的提交归属到您本人。[了解更多](/cn/integrations/github#个人-github-账户用户级别)。

## 故障排除

### 未显示仓库

- 确认 GitHub App 已安装在该仓库中
- 对于组织仓库，确认管理员已批准访问权限
- 尝试在仪表板中刷新仓库列表

### 未触发构建

- 检查仓库设置中的 webhook 是否处于启用状态
- 确认您推送到了已配置的分支
- 在 GitHub 中查看 webhook 传送错误

### 权限被拒绝错误

- 在 GitHub 设置中重新授权 GitHub App
- 确保 Jamdesk App 可以访问该仓库

<Note>
  如需更详细的故障排除信息，请参阅[了解 GitHub 集成](/cn/integrations/github)。
</Note>
