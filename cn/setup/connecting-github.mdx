Jamdesk 在你推送到 GitHub 时自动部署你的文档。

<Note>
如需了解 GitHub 应用与个人账户关联如何协同工作，请参阅 [了解 GitHub 集成](/cn/integrations/github)。
</Note>

<Tip>
文档托管在 Bitbucket Cloud 上？请参阅 [连接 Bitbucket](/cn/setup/connecting-bitbucket)。每个项目只能连接一个提供商。
</Tip>

## 安装 GitHub App

你首次登录时，Jamdesk 会提示你安装 Jamdesk GitHub 应用。该应用授予以下权限：

- **仓库访问**：读取你的文档内容
- **Webhooks**：推送时触发构建
- **提交状态**：在提交上显示构建状态

### 权限

Jamdesk GitHub 应用请求以下权限：

| 权限 | 用途 |
|------------|---------|
| 仓库内容（读写） | 克隆并读取你的文档文件。仅在你于仪表板编辑器中保存、接受 Fix with AI 建议或开启翻译时才会写入 |
| 元数据（只读） | 列出仓库和分支 |
| Webhooks | 接收推送通知 |

<Note>
Jamdesk 仅访问你明确授权的仓库。你可随时在 GitHub 设置中更改访问权限。
</Note>

## 连接仓库

<Steps>
  <Step title="选择仓库">
    在创建或编辑项目时，点击 **Connect Repository**。

    从已安装 GitHub 应用的仓库中进行选择。
  </Step>

  <Step title="选择分支">
    选择要部署的分支：

    - **main** 或 **master**：生产文档最常用
    - **docs**：如果你将文档放在单独的分支中
    - 任意分支：用于预览部署
  </Step>

  <Step title="指定文档路径">
    如果你的 `docs.json` 不在仓库根目录，请指定路径：

    ```bash
    docs/           # Docs in a subdirectory
    packages/docs/  # Monorepo with docs package
    ```

    如果 `docs.json` 位于根目录，请留空。
  </Step>
</Steps>

项目仪表板随后会显示已关联的仓库和分支：

## 自动部署

每次推送到你配置的分支都会触发一次构建：

```bash
git add .
git commit -m "Update API documentation"
git push origin main
```

构建通常需要 30–90 秒完成。你可以在仪表板或 GitHub 提交页面查看状态。

## 更换仓库

要连接其他仓库：

1. 前往 **Settings** → **Repository**
2. 点击 **Change Repository**
3. 选择新的仓库和分支

<Warning>
更换仓库可能会影响你的线上文档。新仓库必须包含有效的 Jamdesk 配置。
</Warning>

## 管理 GitHub App 访问权限

控制 Jamdesk 可以访问哪些仓库：

1. 前往 [github.com/settings/installations](https://github.com/settings/installations)
2. 在列表中找到 **Jamdesk**
3. 点击 **Configure**
4. 在 "Repository access" 下，选择特定仓库或全部仓库

### 组织仓库

对于组织仓库，组织管理员必须批准 GitHub 应用的安装：

1. 从你的 Jamdesk 仪表板发起安装请求
2. 管理员会在 GitHub 中收到通知
3. 获批后，组织仓库会出现在仓库选择器中

## 关联个人账户

在 **User Settings** 中关联你的个人 GitHub 账户，以确保构建归属准确：

1. 点击你的头像 → **User Settings**
2. 找到 **GitHub Account** 部分
3. 点击 **Link GitHub Account**

此关联独立于 GitHub 应用，用于将你的提交归属到你的账户。[了解更多](/cn/integrations/github#个人-github-账户用户级)。

## 故障排除

### 找不到仓库

- 确认 GitHub 应用已安装在该仓库上
- 对于组织仓库，确认管理员已批准访问权限
- 在仪表板中刷新仓库列表

### GitHub 不断将你带回 Jamdesk 应用页面

你的公司很可能管理着你的 GitHub 账户。GitHub 不允许这类账户自行在其账户上安装应用。请参阅 [公司托管的 GitHub 账户](/cn/help/troubleshooting/github-issues#公司托管的-github-账户) 进行修复。

### 未触发构建

- 检查仓库设置中的 webhook 是否处于活动状态
- 确认你推送到的是已配置的分支
- 在 GitHub 中查看 webhook 投递错误

### 权限被拒绝错误

- 在你的 GitHub 设置中重新授权 GitHub 应用
- 确认 Jamdesk 应用可以访问该仓库

<Note>
  如需更详细的故障排除，请参阅 [了解 GitHub 集成](/cn/integrations/github)。
</Note>
