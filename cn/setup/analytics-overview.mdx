两个仪表板：用于流量的 **Project Analytics**，以及用于搜索查询的 **Search Analytics**。

## 可获取的数据

<Columns cols={2}>
  <Card title="Project Analytics" icon="chart-line" href="/cn/setup/project-analytics">
    访客、页面浏览量、来源站点和设备细分
  </Card>
  <Card title="Search Analytics" icon="magnifying-glass" href="/cn/setup/search-analytics">
    搜索查询、零结果缺口和点击率
  </Card>
</Columns>

## 访问方式

<Steps>
  <Step title="打开您的项目">
    前往 [dashboard.jamdesk.com](https://dashboard.jamdesk.com) 并选择您的项目。
  </Step>
  <Step title="打开 Analytics">
    点击侧边栏中的 **Analytics**，即可打开 Project Analytics 和 Search Analytics。
  </Step>
  <Step title="选择日期范围">
    使用日期选择器比较不同时间段，并发现随时间变化的趋势。
  </Step>
</Steps>

## 示例快照

Project Analytics 和 Search Analytics 数据的示例汇总：

```json
{
  "period": "Last 30 days",
  "project_analytics": {
    "visitors": 4120,
    "views": 12890,
    "top_pages": ["/quickstart", "/content/mdx-basics", "/deploy/overview"]
  },
  "search_analytics": {
    "total_searches": 940,
    "zero_results": 42,
    "top_queries": ["authentication", "api keys", "custom domains"]
  }
}
```

## 常见工作流

- **识别热门入口页面**，并确保它们能快速说明产品功能。
- **发现搜索缺口**：找出返回零结果的搜索，并补充缺失的内容。
- **监控发布影响**：比较发布前后的流量变化。
