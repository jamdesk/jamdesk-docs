了解读者搜索的内容、无结果的查询以及他们点击的结果。

<Info>
如果你要查看页面浏览量和访客数据，请参阅[项目分析](/cn/setup/project-analytics)。
</Info>

<Note>
如果搜索数据缺失或延迟，请参阅[分析问题](/cn/help/troubleshooting/analytics-issues)。
</Note>

## 查看搜索分析

从项目仪表板访问搜索分析：

<Steps>
  <Step title="打开项目">
    前往 [dashboard.jamdesk.com](https://dashboard.jamdesk.com) 并选择项目。
  </Step>

  <Step title="点击 Search Analytics">
    在侧边栏的 **Analytics** 下，点击 **Search** 以查看搜索仪表板。
  </Step>

  <Step title="选择日期范围">
    使用日期选择器查看不同时间段的搜索数据。默认范围为 30 天。
  </Step>
</Steps>

## 关键指标

搜索分析仪表板显示四项主要指标：

| 指标 | 描述 |
|--------|-------------|
| **搜索总数** | 所选时间段内执行的搜索次数 |
| **唯一查询** | 使用过的不同搜索词 |
| **无结果** | 未返回匹配项的搜索 |
| **点击率** | 用户点击结果的搜索所占百分比 |

每项指标都会与上一时间段进行比较，并以百分比变化显示。

示例快照：

```json
{
  "period": "Last 30 days",
  "total_searches": 940,
  "unique_queries": 312,
  "zero_results": 42,
  "top_queries": [
    { "query": "authentication", "searches": 84, "ctr": 0.82 },
    { "query": "api keys", "searches": 63, "ctr": 0.71 }
  ]
}
```

## 搜索量

搜索量图表显示所选时间范围内的每日搜索活动。你可以使用它来：

- 识别使用模式（工作日与周末流量）
- 发现可能表示外部链接或公告的异常峰值
- 跟踪文档使用量随时间的增长

## 查询明细

### 热门搜索

查看用户输入的最常见搜索词。这可以揭示：

- **热门主题** - 用户最常需要的内容
- **导航问题** - 用户搜索那些在导航中很容易找到的内容
- **术语空白** - 用户是否使用了不同于文档的术语

对于每个查询，你会看到：
- 搜索次数
- 结果点击次数
- 点击率（CTR）

### 内容空白

<Warning>
内容空白是指返回零结果的搜索。每一项都代表文档尚未涵盖的主题。
</Warning>

Content Gaps 选项卡显示用户搜索但未找到任何内容的查询。常见原因包括：

| 原因 | 解决方案 |
|-------|----------|
| 缺少文档 | 创建涵盖该主题的新页面 |
| 术语不同 | 添加同义词或更新标题 |
| 内容中存在拼写错误 | 修正文档中的拼写 |
| 功能尚未记录 | 将其添加到文档路线图 |

定期检查内容空白。下方的最佳实践部分建议每周进行一次检查。

## 搜索洞察

洞察面板提供快速答案：

| 洞察 | 含义 |
|---------|---------------|
| **平均点击位置** | 用户通常点击结果列表中的位置（越低越好） |
| **每日搜索次数** | 每日平均搜索量 |
| **热门查询** | 最常见的搜索词 |
| **最常遗漏** | 需要处理的首要零结果查询 |

## 最佳实践

<Accordion title="每周检查内容空白">
设置定期任务，检查零结果搜索。每周即使只花几分钟，也能防止文档债务不断累积。
</Accordion>

<Accordion title="在标题中使用自然语言">
用户经常使用自然短语进行搜索。如果标题符合用户的思考方式，他们就能更快找到内容。
</Accordion>

<Accordion title="为重要页面添加同义词">
如果用户搜索的是 "setup"，而你的页面名为 "installation"，请在内容中同时提及这两个术语，以便搜索找到该页面。
</Accordion>

<Accordion title="跟踪 CTR 改进">
处理内容空白后，监控点击率是否有所提升。高搜索量查询的点击率较低，说明结果与用户意图不匹配。
</Accordion>

## 搜索质量评分

Jamdesk 根据点击率计算搜索质量评分：

``` text
Score = (Searches with clicks / Total searches) × 100
```

| 评分 | 等级 |
|-------|--------|
| 90%+ | 优秀 |
| 70-89% | 良好 |
| 50-69% | 需要改进 |
| 低于 50% | 较差 |

## 数据导出

导出搜索数据以供进一步分析：

1. 前往 **Analytics** → **Search**
2. 点击 **Export**
3. 选择 CSV 或 JSON 格式

## 数据可用性

搜索分析数据会在每日汇总任务于 UTC 时间凌晨 2 点运行后显示。今天执行的搜索将在明天显示于仪表板中。

<Note>
如果你刚设置好文档，请等待 24-48 小时，让搜索数据积累后再查看有意义的洞察。
</Note>
