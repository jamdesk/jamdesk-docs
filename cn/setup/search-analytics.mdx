查看读者搜索了什么、哪些查询没有返回结果，以及他们点击了什么。

<Info>
有关页面浏览量和访客数据，请参阅 [项目分析](/cn/setup/project-analytics)。
</Info>

<Note>
如果搜索数据缺失或延迟，请参阅 [分析问题](/cn/help/troubleshooting/analytics-issues)。
</Note>

## 查看搜索分析

<Steps>
  <Step title="打开你的项目">
    前往 [dashboard.jamdesk.com](https://dashboard.jamdesk.com)，然后选择你的项目。
  </Step>

  <Step title="点击搜索分析">
    在侧边栏的 **Analytics** 下，点击 **Search**。
  </Step>

  <Step title="选择日期范围">
    使用日期选择器选择一个时间段。默认为 30 天。
  </Step>
</Steps>

## 关键指标

| Metric | Description |
|--------|-------------|
| **Total Searches** | 所选时间段内执行的搜索次数 |
| **Unique Queries** | 使用过的不重复搜索词数量 |
| **Zero Results** | 未返回任何匹配结果的搜索次数 |
| **Click-through Rate** | 有点击结果的搜索所占的百分比 |

每项指标都会显示与上一时间段相比的百分比变化。

示例快照：

```json
{
  "period": "Last 30 days",
  "total_searches": 940,
  "unique_queries": 312,
  "zero_results": 42,
  "top_queries": [
    { "query": "authentication", "searches": 84, "ctr": 0.82 },
    { "query": "api keys", "searches": 63, "ctr": 0.71 }
  ]
}
```

## 搜索量

搜索量图表显示所选时间段内每日的搜索次数。可用于：

- 发现工作日与周末的规律
- 发现来自外部链接或公告的搜索高峰
- 追踪随时间变化的增长情况

## 查询明细

### 热门搜索

最常见的搜索词会显示：

- **热门主题：** 读者最常需要的内容
- **导航问题：** 搜索已在导航中的页面
- **术语缺口：** 与你文档中用词不同的术语

每个查询会显示：
- 搜索次数
- 结果点击次数
- 点击率（CTR）

### 内容空白

<Warning>
内容缺口指没有返回任何结果的搜索。每一条都代表你的文档尚未涵盖的主题。
</Warning>

“Content Gaps”标签页列出了没有找到任何结果的查询。常见原因：

| Cause | Solution |
|-------|----------|
| 缺少文档 | 新建一个页面来介绍该主题 |
| 术语不同 | 添加同义词或更新标题 |
| 内容中的拼写错误 | 修正文档中的拼写 |
| 功能尚未编写文档 | 加入你的文档路线图 |

## 搜索洞察

| Insight | What It Means |
|---------|---------------|
| **Avg. Click Position** | 被点击结果的平均位置（越低越好） |
| **Searches per Day** | 日均搜索量 |
| **Top Query** | 最常见的搜索词 |
| **Most Missed** | 需要处理的零结果查询中排名最靠前的一条 |

## 最佳实践

<Accordion title="每周审查内容缺口">
设置一个定期任务，检查零结果搜索。
</Accordion>

<Accordion title="在标题中使用自然语言">
读者通常使用自然的短语进行搜索。请编写与之匹配的标题。
</Accordion>

<Accordion title="为重要页面添加同义词">
如果读者搜索“setup”，而你的页面叫“installation”，请在页面中提到“setup”。
</Accordion>

<Accordion title="追踪点击率的改善">
修复内容缺口后，关注点击率的变化。高搜索量查询的点击率偏低，说明结果与读者的需求不匹配。
</Accordion>

## 搜索质量评分

Jamdesk 根据点击率计算搜索质量评分：

``` text
Score = (Searches with clicks / Total searches) × 100
```

| Score | Rating |
|-------|--------|
| 90%+ | Excellent |
| 70-89% | Good |
| 50-69% | Needs improvement |
| Below 50% | Poor |

## 数据导出

1. 前往 **Analytics** → **Search**
2. 点击 **Export**
3. 选择 CSV 或 JSON 格式

## 数据可用性

搜索数据会在每天 UTC 时间凌晨 2 点的每日汇总后出现。当天的搜索数据将于次日显示。

<Note>
新站点需要 24-48 小时的搜索数据，数字才有参考意义。
</Note>
