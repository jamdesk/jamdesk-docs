Follow these steps to create and deploy your first Jamdesk documentation site.

<Steps>
  <Step title="Create a Project">
    Go to [app.jamdesk.com](https://app.jamdesk.com) and click **New Project**.

    Give your project a name and select a plan.
  </Step>

  <Step title="Connect GitHub">
    Connect your GitHub account and select the repository containing your documentation.

    Jamdesk will automatically detect your `docs.json` configuration file.
  </Step>

  <Step title="Configure Your Domain">
    Add a custom domain in project settings, or use the provided `*.jamdesk.dev` subdomain.

    For custom domains, add the DNS records shown in the dashboard.
  </Step>

  <Step title="Push and Deploy">
    Push changes to your connected branch. Jamdesk automatically builds and deploys your site.

    ```bash
    git add . && git commit -m "Update docs" && git push
    ```
  </Step>
</Steps>
