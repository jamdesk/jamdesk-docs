Jamdesk styles images, video embeds, and iFrames automatically with rounded corners and consistent framing.

## Images

### Standard Markdown

```markdown
![Alt text describing the image](/images/tabs-preview.png)
```

Place images in your `/images` directory and reference them with absolute paths.

### Image Dimensions

Control image size by appending `=WIDTHxHEIGHT` after the URL (with a space before `=`):

```markdown
![Screenshot](/images/screenshot.png =400x300)
```

You can also specify just one dimension and let the other auto-scale:

```markdown
![Wide banner](/images/banner.png =800x)
![Tall graphic](/images/sidebar.png =x200)
```

### With Captions

The `Frame` component adds a border and optional caption:

```mdx
<Frame caption="Dashboard overview showing project statistics">
  ![Dashboard](/images/tabs-preview.png)
</Frame>
```

<Frame caption="Example of a framed image with caption">
  ![Jamdesk](/images/jd-blueprint-transparent.webp)

</Frame>

### Light/Dark Mode Images

Show different images based on the user's color scheme:

```mdx
<img
  src="/images/logo-light.webp"
  srcDark="/images/logo-dark.webp"
  alt="Company logo"
/>
```

Or use the HTML picture element:

```mdx
<picture>
  <source srcset="/images/logo-dark.webp" media="(prefers-color-scheme: dark)" />
  <img src="/images/logo-light.webp" alt="Company logo" />
</picture>
```

## Video Embeds

Videos get the same rounded-corner styling as images.

### YouTube

Embed YouTube videos with the `<YouTube>` component:

```mdx
<YouTube id="dQw4w9WgXcQ" />
```

<YouTube id="dQw4w9WgXcQ" />

Pass the video ID from the YouTube URL (the part after `v=`). The component lazy-loads the player, disables related videos, and applies consistent rounded styling.

#### Props

| Prop | Type | Description |
|------|------|-------------|
| `id` | string | YouTube video ID (required) |
| `title` | string | Accessibility label for the play button |
| `start` | number | Start time in seconds |

#### Start at a specific time

```mdx
<YouTube id="dQw4w9WgXcQ" start={60} />
```

<YouTube id="dQw4w9WgXcQ" start={60} />

Starts playback at 1 minute (60 seconds).

<Tip>
To find the video ID, look at the YouTube URL: `youtube.com/watch?v=VIDEO_ID` or `youtu.be/VIDEO_ID`
</Tip>

#### Using iFrames directly

For more control, embed YouTube videos with a raw iFrame:

```html
<iframe
  className="w-full aspect-video rounded-xl"
  src="https://www.youtube.com/embed/VIDEO_ID"
  title="YouTube video player"
  allow="accelerometer; autoplay; clipboard-write; encrypted-media; gyroscope; picture-in-picture"
  allowFullScreen
/>
```

<Note>
Prefer the `<YouTube>` component over raw iFrames. It lazy-loads the player, so your page doesn't download a full video embed until someone clicks play.
</Note>

### Video Files

You can embed `.mp4` and `.webm` files directly from your project. Place them in a `/videos` directory and reference them in markdown or with the `<Video>` component.

#### Markdown syntax

Works just like images. Jamdesk detects the video extension and renders an HTML5 player with controls:

```markdown
![Never Gonna Give You Up](/videos/never-gonna-give-you-up.mp4)
```

![Never Gonna Give You Up](/videos/never-gonna-give-you-up.mp4)

#### Video component

The `<Video>` component gives you control over playback props:

```mdx
<Video src="/videos/never-gonna-give-you-up.mp4" title="Rick Astley" />
```

<Video src="/videos/never-gonna-give-you-up.mp4" title="Rick Astley" />

#### Props

| Prop | Type | Default | Description |
|------|------|---------|-------------|
| `src` | string | — | Video file path (required) |
| `title` | string | — | Accessibility label |
| `controls` | boolean | `true` | Show player controls |
| `autoPlay` | boolean | `false` | Start playing automatically |
| `muted` | boolean | `false` | Mute audio |
| `loop` | boolean | `false` | Loop playback |
| `width` | string | — | Video width |
| `height` | string | — | Video height |

#### GIF replacement

For short looping clips (UI demos, animations), combine `autoPlay`, `muted`, and `loop` with `controls={false}`:

```mdx
<Video src="/videos/never-gonna-give-you-up.mp4" autoPlay muted loop controls={false} />
```

<Video src="/videos/never-gonna-give-you-up.mp4" autoPlay muted loop controls={false} />

<Note>
Browsers require `muted` when using `autoPlay`. Unmuted autoplay is blocked on most browsers.
</Note>

#### Supported formats

| Format | Extension | Browser Support |
|--------|-----------|----------------|
| MP4 (H.264) | `.mp4` | All browsers including Safari/iOS |
| WebM (VP9) | `.webm` | Chrome, Firefox, Edge (smaller files) |

Use `.mp4` for maximum compatibility. Files can be up to 100MB.

### Vimeo

Embed Vimeo videos with an iFrame:

```html
<iframe
  className="w-full aspect-video rounded-xl"
  src="https://player.vimeo.com/video/VIDEO_ID"
  title="Vimeo video player"
  allow="autoplay; fullscreen; picture-in-picture"
  allowFullScreen
/>
```

### Responsive Videos

The `aspect-video` utility class handles responsive sizing for all video iFrames:

```html
<iframe
  className="w-full aspect-video rounded-xl"
  src="https://www.youtube.com/embed/VIDEO_ID"
  title="YouTube video player"
  allow="accelerometer; autoplay; clipboard-write; encrypted-media; gyroscope; picture-in-picture"
  allowFullScreen
/>
```

This maintains a 16:9 ratio at any width. If you need 4:3, use `aspect-[4/3]` instead.

## iFrames

Any iFrame content gets automatic styling:

- Rounded corners on both the frame and content
- A subtle border that adapts to light/dark mode
- Consistent spacing above and below

### Embedding External Content

```html
<iframe
  src="https://example.com/embed"
  width="100%"
  height="400"
  title="Description of embedded content"
/>
```

## Styling Details

All iFrames receive automatic styling:

| Property | Value | Description |
|----------|-------|-------------|
| Border radius | `0.5rem` | Rounded corners on content |
| Frame width | `8px` | Visual padding around content |
| Border | `1px` | Subtle border in theme color |
| Spacing | `1rem + 9px` | Margin above and below |

The styling adapts to your theme's color scheme, using `--color-bg-secondary` for the frame and `--color-border` for the border line.

## Image Best Practices

<AccordionGroup>
  <Accordion title="Use descriptive alt text" icon="universal-access">
    Alt text helps screen readers and appears when images fail to load. Describe what the image shows, not just "screenshot" or "image".

    ```markdown
    {/* Good */}
    ![API response showing user data in JSON format](/images/tabs-preview.png)

    {/* Avoid */}
    ![Screenshot](/images/tabs-preview.png)
    ```
  </Accordion>

  <Accordion title="Optimize file sizes" icon="gauge-high">
    Large images slow down page loads. Aim for:
    - Screenshots: PNG, under 500KB
    - Photos: JPEG, under 200KB
    - Icons/diagrams: SVG when possible

    Tools like [Squoosh](https://squoosh.app) or [TinyPNG](https://tinypng.com) can compress images without visible quality loss.
  </Accordion>

  <Accordion title="Use consistent dimensions" icon="ruler-combined">
    Keep screenshots at consistent widths (e.g., 1200px). Jamdesk scales images to fit the content width automatically.
  </Accordion>
</AccordionGroup>

## Supported Image Formats

| Format | Best For | Notes |
|--------|----------|-------|
| PNG | Screenshots, UI | Lossless, supports transparency |
| JPEG | Photos | Smaller files, no transparency |
| SVG | Icons, diagrams | Scales perfectly, tiny file size |
| GIF | Simple animations | Use sparingly, can be large |
| WebP | Modern alternative | Smaller than PNG/JPEG |

## File Organization

Keep your media organized:

```
your-docs/
├── images/
│   ├── getting-started/
│   │   ├── step-1.png
│   │   └── step-2.png
│   ├── api/
│   │   └── response.png
│   └── logo.svg
├── videos/
│   └── product-demo.mp4
└── docs.json
```

Reference them with the full path:

```markdown
![Step 1](/images/help-center/dashboard/github-repository-access.webp)
```
