Store `.mp4` or `.webm` files in a `/videos` directory inside your project and reference them directly. Jamdesk renders an HTML5 player with controls, rounded corners, and consistent spacing.

## Markdown Syntax

The same `![alt](path)` pattern you use for images works for video files. Jamdesk checks the file extension and renders a video player instead of an `<img>` tag:

```markdown
![Never Gonna Give You Up](/videos/never-gonna-give-you-up.mp4)
```

![Never Gonna Give You Up](/videos/never-gonna-give-you-up.mp4)

You get a standard player with play/pause, volume, progress bar, and fullscreen. Use the `<Video>` component to control playback (autoplay, looping, muting).

## Video Component

The `<Video>` component exposes HTML5 video attributes as props:

```mdx
<Video src="/videos/never-gonna-give-you-up.mp4" title="Rick Astley" />
```

<Video src="/videos/never-gonna-give-you-up.mp4" title="Rick Astley" />

The `title` prop sets the `aria-label` on the video element. Screen readers announce this label. Always include one.

## Props

| Prop | Type | Default | Description |
|------|------|---------|-------------|
| `src` | `string` | none | **Required.** Path to the video file. |
| `title` | `string` | none | Accessibility label for screen readers. |
| `controls` | `boolean` | `true` | Show the browser's built-in player controls. |
| `autoPlay` | `boolean` | `false` | Begin playing as soon as the video is visible. |
| `muted` | `boolean` | `false` | Start with audio muted. |
| `loop` | `boolean` | `false` | Restart from the beginning when the video ends. |
| `width` | `string` | none | CSS width value (e.g., `"400px"`, `"100%"`). |
| `height` | `string` | none | CSS height value. |

## GIF Replacement

A 5-second UI recording can hit 10MB as a GIF and stay under 500KB as an MP4. Replace GIFs with a silent, looping video and hide the player chrome:

```mdx
<Video src="/videos/ui-demo.mp4" autoPlay muted loop controls={false} />
```

The result behaves like a GIF (plays inline, loops forever, no controls). It loads faster and stays sharp at any resolution.

<Note>
Browsers block unmuted autoplay. A video with `autoPlay` and no `muted` won't play. It sits on the first frame with no error. Always set `muted` with `autoPlay`.
</Note>

## Supported Formats

| Format | Extension | Browser Support |
|--------|-----------|-----------------|
| MP4 (H.264) | `.mp4` | All browsers, including Safari and iOS |
| WebM (VP9) | `.webm` | Chrome, Firefox, Edge. Smaller files at comparable quality |

MP4 is the safe default. Every browser and device plays it. WebM produces smaller files. Safari and iOS don't play WebM. Readers on Apple devices see nothing.

Video files can be up to **100MB**. Host anything longer than a few minutes on YouTube and use the [`<YouTube>` component](/content/youtube) instead. A CDN built for video streams it faster than your docs can serve a large file.

<Tip>
Compress videos before committing them. Tools like [FFmpeg](https://ffmpeg.org/) and [Handbrake](https://handbrake.fr/) cut file sizes without visible quality loss: `ffmpeg -i input.mp4 -crf 28 -preset slow output.mp4`
</Tip>
