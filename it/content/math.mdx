Jamdesk visualizza formule LaTeX tramite [KaTeX](https://katex.org/).

<Note>
Il supporto alla matematica richiede `styling.latex: true` nel file `docs.json`.
</Note>

## Abilitare il supporto matematico

Aggiungi a `docs.json`:

```json docs.json
{
  "styling": {
    "latex": true
  }
}
```

## Matematica in linea

Usa un singolo simbolo di dollaro per le equazioni in linea:

```md
The Pythagorean theorem states that $a^2 + b^2 = c^2$.
```

**Risultato:** The Pythagorean theorem states that $a^2 + b^2 = c^2$.

## Equazioni a blocco

Usa doppi simboli di dollaro per equazioni centrate, in stile display:

```md
$$
E = mc^2
$$
```

**Risultato:**

$$
E = mc^2
$$

## Equazioni complesse

KaTeX visualizza un'ampia gamma di notazioni LaTeX:

### Frazioni

```md
$$
\frac{n!}{k!(n-k)!} = \binom{n}{k}
$$
```

### Integrali

```md
$$
\int_0^\infty e^{-x^2} dx = \frac{\sqrt{\pi}}{2}
$$
```

### Sommatorie

```md
$$
\sum_{i=1}^{n} i = \frac{n(n+1)}{2}
$$
```

### Matrici

```md
$$
\begin{bmatrix}
a & b \\
c & d
\end{bmatrix}
$$
```

## Usare il componente Latex

Usa direttamente il componente `<Latex>` per un maggiore controllo:

```mdx
<Latex>E = mc^2</Latex>
```

Per la modalità a blocco/display:

```mdx
<Latex block>
\int_0^\infty e^{-x^2} dx = \frac{\sqrt{\pi}}{2}
</Latex>
```

## I blocchi di codice sono protetti

I simboli di dollaro all'interno dei blocchi di codice **non** vengono trattati come matematica:

```bash
echo $HOME
export PRICE=$100
```

## Comandi supportati

KaTeX copre la maggior parte dei comandi matematici LaTeX più comuni. La [documentazione di KaTeX](https://katex.org/docs/supported.html) elenca ogni funzione supportata.

<Tip>
Prova prima le equazioni complesse nella [pagina demo di KaTeX](https://katex.org/).
</Tip>
