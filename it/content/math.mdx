---

Jamdesk supporta LaTeX per il rendering di espressioni ed equazioni matematiche usando [KaTeX](https://katex.org/).

<Note>
Il supporto matematico richiede `styling.latex: true` nel file `docs.json`.
</Note>

## Abilitare il supporto matematico

Aggiungi quanto segue al tuo `docs.json`:

```json docs.json
{
  "styling": {
    "latex": true
  }
}
```

## Matematica in linea

Usa un singolo simbolo del dollaro per le equazioni in linea:

```md
The Pythagorean theorem states that $a^2 + b^2 = c^2$.
```

**Viene visualizzato come:** The Pythagorean theorem states that $a^2 + b^2 = c^2$.

## Equazioni a blocco

Usa due simboli del dollaro per le equazioni centrate in modalità visualizzazione:

```md
$$
E = mc^2
$$
```

**Viene visualizzato come:**

$$
E = mc^2
$$

## Equazioni complesse

KaTeX supporta un'ampia gamma di notazioni LaTeX:

### Frazioni

```md
$$
\frac{n!}{k!(n-k)!} = \binom{n}{k}
$$
```

### Integrali

```md
$$
\int_0^\infty e^{-x^2} dx = \frac{\sqrt{\pi}}{2}
$$
```

### Sommatorie

```md
$$
\sum_{i=1}^{n} i = \frac{n(n+1)}{2}
$$
```

### Matrici

```md
$$
\begin{bmatrix}
a & b \\
c & d
\end{bmatrix}
$$
```

## Usare il componente Latex

Per un maggiore controllo, usa direttamente il componente `<Latex>`:

```mdx
<Latex>E = mc^2</Latex>
```

Per la modalità a blocco/visualizzazione:

```mdx
<Latex block>
\int_0^\infty e^{-x^2} dx = \frac{\sqrt{\pi}}{2}
</Latex>
```

## I blocchi di codice sono protetti

I simboli del dollaro all'interno dei blocchi di codice **non** vengono trattati come espressioni matematiche:

```bash
echo $HOME
export PRICE=$100
```

Il risultato è un normale blocco di codice, non un'equazione.

## Comandi supportati

KaTeX supporta la maggior parte dei comandi matematici LaTeX comuni. Consulta la [documentazione di KaTeX](https://katex.org/docs/supported.html) per un elenco completo delle funzioni supportate.

<Tip>
Per le equazioni complesse, prova prima il tuo LaTeX sulla [pagina demo di KaTeX](https://katex.org/).
</Tip>
