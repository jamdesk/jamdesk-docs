Archivia i file `.mp4` o `.webm` in una directory `/videos` all'interno del progetto e fai riferimento direttamente a essi. Jamdesk mostra un player HTML5 con controlli, angoli arrotondati e spaziatura uniforme.

Gli screenshot mostrano l'interfaccia in inglese.

## Sintassi Markdown

Lo stesso schema `![alt](path)` usato per le immagini funziona anche con i file video. Jamdesk controlla l'estensione del file e mostra un player video anziché un tag `<img>`:

```markdown
![Never Gonna Give You Up](/videos/never-gonna-give-you-up.mp4)
```

![Non smettere mai di darmi la tua fiducia](/videos/never-gonna-give-you-up.mp4)

Il player standard include riproduzione/pausa, volume, barra di avanzamento e schermo intero. Usa il componente `<Video>` per controllare la riproduzione (autoplay, ripetizione e disattivazione dell'audio).

## Componente Video

Il componente `<Video>` espone gli attributi video HTML5 come props:

```mdx
<Video src="/videos/never-gonna-give-you-up.mp4" title="Rick Astley" />
```

<Video src="/videos/never-gonna-give-you-up.mp4" title="Rick Astley" />

La prop `title` imposta l'`aria-label` sull'elemento video. Gli screen reader annunciano questa etichetta. Includila sempre.

## Proprietà

| Prop | Tipo | Predefinito | Descrizione |
|------|------|---------|-------------|
| `src` | `string` | none | **Obbligatorio.** Percorso del file video. |
| `title` | `string` | none | Etichetta di accessibilità per gli screen reader. |
| `controls` | `boolean` | `true` | Mostra i controlli integrati del player del browser. |
| `autoPlay` | `boolean` | `false` | Avvia la riproduzione non appena il video è visibile. |
| `muted` | `boolean` | `false` | Avvia il video con l'audio disattivato. |
| `loop` | `boolean` | `false` | Riavvia il video dall'inizio quando termina. |
| `width` | `string` | none | Valore CSS per la larghezza (ad es. `"400px"`, `"100%"`). |
| `height` | `string` | none | Valore CSS per l'altezza. |

## Sostituire le GIF

Una registrazione dell'interfaccia di 5 secondi può raggiungere i 10 MB come GIF e restare sotto i 500 KB come MP4. Sostituisci le GIF con un video senza audio e in ripetizione, nascondendo i controlli del player:

```mdx
<Video src="/videos/ui-demo.mp4" autoPlay muted loop controls={false} />
```

Il risultato si comporta come una GIF (si riproduce in linea, si ripete all'infinito e non mostra controlli). Si carica più velocemente e rimane nitido a qualsiasi risoluzione.

<Note>
I browser bloccano la riproduzione automatica con audio attivo. Un video con `autoPlay` ma senza `muted` non viene riprodotto: resta sul primo fotogramma senza mostrare errori. Imposta sempre `muted` insieme a `autoPlay`.
</Note>

## Formati supportati

| Formato | Estensione | Supporto dei browser |
|--------|-----------|-----------------|
| MP4 (H.264) | `.mp4` | Tutti i browser, inclusi Safari e iOS |
| WebM (VP9) | `.webm` | Chrome, Firefox, Edge. File più piccoli a qualità comparabile |

MP4 è la scelta predefinita più sicura: viene riprodotto da tutti i browser e dispositivi. WebM genera file più piccoli, ma Safari e iOS non lo supportano. Chi usa dispositivi Apple non vedrà nulla.

I file video possono essere grandi fino a **100MB**. Per i video più lunghi di qualche minuto, ospitali su YouTube e usa invece il componente [`<YouTube>`](/it/content/youtube). Una CDN progettata per i flussi video li trasmette più velocemente di quanto la tua documentazione possa servire un file di grandi dimensioni.

<Tip>
Comprimi i video prima di inserirli nel repository. Strumenti come [FFmpeg](https://ffmpeg.org/) e [Handbrake](https://handbrake.fr/) riducono le dimensioni dei file senza perdite di qualità visibili: `ffmpeg -i input.mp4 -crf 28 -preset slow output.mp4`
</Tip>
