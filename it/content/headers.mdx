Le intestazioni Markdown (`##`, `###`) suddividono la pagina in sezioni. Jamdesk aggiunge le intestazioni H2 e H3 all'indice a destra. Genera inoltre un link di ancoraggio condivisibile per ogni intestazione.

## Uso di base

Usa le intestazioni Markdown standard per strutturare i contenuti:

```markdown
## Section Title

Content goes here...

### Subsection

More detailed content...
```

L'**Indice** sul lato destro elenca le intestazioni H2 e H3. I lettori lo usano per spostarsi tra le sezioni delle pagine lunghe.

## Link di ancoraggio

Ogni intestazione genera un ID di ancoraggio dal proprio testo:

| Intestazione              | Ancoraggio generato    |
| ------------------------- | ---------------------- |
| `## Getting Started`      | `#getting-started`     |
| `## API Reference`        | `#api-reference`       |
| `### User Authentication` | `#user-authentication` |

### Condivisione dei link alle intestazioni

Passa il mouse su qualsiasi intestazione H2 o H3 per visualizzare un'**icona di collegamento**:

- **Fai clic sull'icona di collegamento** per copiare l'URL negli appunti
- **Fai clic sul testo dell'intestazione** per copiare l'URL e passare a quella sezione

L'icona di collegamento compare in un piccolo riquadro a sinistra dell'intestazione. Per un attimo cambia colore per confermare la copia.

<Note>
  I dispositivi mobili non supportano lo stato di hover. L'icona di collegamento
  è nascosta. Le intestazioni funzionano comunque per la navigazione.
</Note>

### Collegamento alle intestazioni

Fai riferimento a sezioni specifiche da altre pagine usando l'ancoraggio:

```markdown
See the [headings section](/content/mdx-basics#headings) for details.
```

## Procedure consigliate

<AccordionGroup>
  <Accordion title="Usa una gerarchia chiara" icon="sitemap" defaultOpen>
    Inizia con H2 per le sezioni principali e H3 per le sottosezioni:

    ```markdown
    ## Installation

    ### Prerequisites

    ### Quick Install

    ## Configuration

    ### Basic Options

    ### Advanced Options
    ```

    Evita di saltare i livelli (ad esempio passando da H2 a H4).

  </Accordion>

  <Accordion title="Mantieni le intestazioni concise" icon="text-width">
    Le intestazioni brevi sono più facili da scorrere:

    ```markdown
    {/* Good */}
    ## Authentication

    {/* Avoid */}
    ## How to Set Up Authentication in Your Application
    ```

  </Accordion>

  <Accordion title="Usa il maiuscolo solo iniziale" icon="font">
    Scrivi in maiuscolo solo la prima parola e i nomi propri:

    ```markdown
    {/* Good */}
    ## Getting started with the API

    {/* Avoid */}
    ## Getting Started With The API
    ```

  </Accordion>
</AccordionGroup>
