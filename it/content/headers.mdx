Le intestazioni Markdown (`##`, `###`) dividono la pagina in sezioni che i lettori possono esaminare rapidamente. Jamdesk rileva le intestazioni H2 e H3 per il sommario sul lato destro e genera link di ancoraggio che puoi condividere direttamente.

## Uso di base

Usa le intestazioni Markdown standard per strutturare i tuoi contenuti:

```markdown
## Section Title

Content goes here...

### Subsection

More detailed content...
```

Le intestazioni H2 e H3 vengono visualizzate nel **Table of Contents** sul lato destro, così i lettori possono passare tra le sezioni delle pagine lunghe.

## Link di ancoraggio

Ogni intestazione genera automaticamente un ID di ancoraggio dal proprio testo:

| Intestazione              | Ancora generata         |
| ------------------------- | ---------------------- |
| `## Getting Started`      | `#getting-started`     |
| `## API Reference`        | `#api-reference`       |
| `### User Authentication` | `#user-authentication` |

### Condivisione dei link alle intestazioni

Passa il puntatore su qualsiasi intestazione H2 o H3 per visualizzare un'**icona di collegamento**. In questo modo è facile condividere link diretti a sezioni specifiche:

- **Fai clic sull'icona di collegamento** per copiare l'URL negli appunti
- **Fai clic sul testo dell'intestazione** per copiare l'URL e passare a quella sezione

L'icona di collegamento appare in un piccolo riquadro con bordo a sinistra dell'intestazione. Quando copi un link, l'icona cambia brevemente colore per confermare l'azione.

<Note>
  Sui dispositivi mobili, l'icona di collegamento è nascosta poiché non è disponibile lo stato hover.
  Le intestazioni continuano a funzionare normalmente per la navigazione.
</Note>

### Collegamento alle intestazioni

Fai riferimento a sezioni specifiche di altre pagine usando l'ancoraggio:

```markdown
See the [headings section](/content/mdx-basics#headings) for details.
```

## Procedure consigliate

<AccordionGroup>
  <Accordion title="Usa una gerarchia chiara" icon="sitemap" defaultOpen>
    Inizia con H2 per le sezioni principali e H3 per le sottosezioni:

    ```markdown
    ## Installation

    ### Prerequisites

    ### Quick Install

    ## Configuration

    ### Basic Options

    ### Advanced Options
    ```

    Evita di saltare livelli, ad esempio passando da H2 a H4.

  </Accordion>

  <Accordion title="Mantieni concise le intestazioni" icon="text-width">
    Le intestazioni brevi sono più facili da esaminare:

    ```markdown
    {/* Good */}
    ## Authentication

    {/* Avoid */}
    ## How to Set Up Authentication in Your Application
    ```

  </Accordion>

  <Accordion title="Usa le maiuscole in stile frase" icon="font">
    Usa la maiuscola solo per la prima parola e i nomi propri:

    ```markdown
    {/* Good */}
    ## Getting started with the API

    {/* Avoid */}
    ## Getting Started With The API
    ```

  </Accordion>
</AccordionGroup>
