Ogni pagina Jamdesk è un file `.mdx`: Markdown standard con componenti JSX come `<Card>`, `<Tabs>` e `<Accordion>`.

## Che cos'è MDX?

MDX ti permette di scrivere Markdown standard e inserire componenti JSX nello stesso file. Scrivi intestazioni, elenchi e blocchi di codice in Markdown, poi inserisci componenti come `<Card>` o `<Tabs>` dove ti servono per l'interattività.

MDX è testo semplice che gli strumenti di AI possono leggere e scrivere in modo nativo. È gestibile con il controllo di versione in Git. Contiene componenti senza un formato proprietario.

```mdx
# Welcome to My Docs

This is regular **Markdown** with a component below:

<Card title="Quickstart" icon="rocket" href="/quickstart">
  Jump right in with our quickstart guide.
</Card>
```

<Tip>
  Il [Validatore MDX](https://jamdesk.com/utilities/mdx-validator) gratuito individua gli errori di sintassi prima di una build.
  Il [Formattatore MDX](https://jamdesk.com/utilities/mdx-formatter) gratuito sistema spaziatura e indentazione.
  Incolla una pagina per verificarla o sistemarla senza eseguire la CLI.
</Tip>

## Struttura della pagina

Ogni pagina MDX inizia con il frontmatter, i metadati compresi tra tre trattini:

```mdx
---
title: My Page Title
description: A brief description for search and previews
---

Your content starts here...
```

<Note>
`title` e `description` compaiono nei risultati di ricerca, nelle schede del browser e nelle anteprime sui social media.
</Note>

## Elementi essenziali di Markdown

### Titoli

Usa `##` per le sezioni principali e `###` per le sottosezioni. Jamdesk crea l'indice a partire dalle tue intestazioni.

```markdown
## Main Section
Content under the main section.

### Subsection
More detailed content here.
```

<Tip>
Inizia con `##` (h2) per la prima intestazione. Il titolo della pagina nel frontmatter è l'h1.
</Tip>

### Formattazione del testo

| Sintassi | Risultato |
|--------|--------|
| `**bold**` | **grassetto** |
| `*italic*` | *corsivo* |
| `~~strikethrough~~` | ~~barrato~~ |
| `` `inline code` `` | `codice inline` |

### Elenchi

```markdown
Unordered list:
- First item
- Second item
  - Nested item

Ordered list:
1. First step
2. Second step
3. Third step
```

### Citazioni

```markdown
> This is a blockquote. Use it for callouts or
> highlighting important information.
```

## Aggiunta di componenti

I componenti sono elementi JSX che puoi usare ovunque nel tuo MDX. Possono essere auto-chiudenti oppure racchiudere contenuto:

```mdx
{/* Self-closing component */}
<Card title="Example" icon="star" href="/introduction" />

{/* Component wrapping content */}
<Accordion title="Click to expand">
  This content is inside the accordion.
</Accordion>
```

## Tabelle

Le tabelle Markdown standard funzionano subito:

```markdown
| Feature | Starter | Team |
|---------|------|-----|
| Pages | 10 | Unlimited |
| Custom domain | No | Yes |
```

| Feature | Starter | Team |
|---------|------|-----|
| Pages | 10 | Unlimited |
| Custom domain | No | Yes |

Usa il componente Table per evidenziare le righe, allineare le celle e unire celle:

<Table striped>
  <Row header>
    <Cell>Feature</Cell>
    <Cell align="center">Starter</Cell>
    <Cell align="center">Team</Cell>
  </Row>
  <Row>
    <Cell>Pages</Cell>
    <Cell align="center">10</Cell>
    <Cell align="center" highlight highlightColor="success">Unlimited</Cell>
  </Row>
  <Row>
    <Cell>Custom domain</Cell>
    <Cell align="center">No</Cell>
    <Cell align="center" highlight highlightColor="success">Yes</Cell>
  </Row>
</Table>

<Note>
Consulta [Tabelle](/it/components/tables) per la documentazione completa del componente, inclusa l'evidenziazione di righe e celle, l'unione di colonne e le opzioni di stile.
</Note>

## Commenti

Aggiungi commenti che non compariranno nell'output renderizzato:

```mdx
{/* This is a comment - it won't be visible to readers */}
```
