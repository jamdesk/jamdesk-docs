Ogni pagina Jamdesk è un file `.mdx`: Markdown standard con componenti JSX come `<Card>`, `<Tabs>` e `<Accordion>`.

## Che cos'è MDX?

MDX permette di scrivere Markdown standard e incorporare componenti JSX nello stesso file. Scrivi titoli, elenchi e blocchi di codice in Markdown, poi aggiungi componenti come `<Card>` o `<Tabs>` dove serve interattività.

MDX è adatto anche alla documentazione che gli strumenti AI devono leggere: è testo semplice (quindi possono leggerlo e scriverlo in modo nativo), è versionabile in Git e ha una struttura sufficiente per usare i componenti, senza richiedere un formato proprietario.

```mdx
# Welcome to My Docs

This is regular **Markdown** with a component below:

<Card title="Quickstart" icon="rocket" href="/quickstart">
  Jump right in with our quickstart guide.
</Card>
```

<Tip>
  Due strumenti gratuiti per browser ti aiutano mentre scrivi: il [MDX Validator](https://jamdesk.com/utilities/mdx-validator)
  rileva gli errori di sintassi prima del build, mentre il [MDX Formatter](https://jamdesk.com/utilities/mdx-formatter)
  sistema spaziatura e indentazione. Incolla una pagina per controllarla o riordinarla senza eseguire la CLI.
</Tip>

## Struttura della pagina

Ogni pagina MDX inizia con il frontmatter: metadati racchiusi tra tre trattini:

```mdx
---
title: My Page Title
description: A brief description for search and previews
---

Your content starts here...
```

<Note>
Il `title` e la `description` appaiono nei risultati di ricerca, nelle schede del browser e nelle anteprime dei social media. Sceglili con cura.
</Note>

## Elementi essenziali di Markdown

### Titoli

Usa `##` per le sezioni principali e `###` per le sottosezioni. Jamdesk genera automaticamente un indice dai titoli.

```markdown
## Main Section
Content under the main section.

### Subsection
More detailed content here.
```

<Tip>
Inizia con `##` (h2) per il primo titolo. Il titolo della pagina definito nel frontmatter funge da h1.
</Tip>

### Formattazione del testo

| Sintassi | Risultato |
|--------|--------|
| `**bold**` | **grassetto** |
| `*italic*` | *corsivo* |
| `~~strikethrough~~` | ~~barrato~~ |
| `` `inline code` `` | `inline code` |

### Elenchi

```markdown
Unordered list:
- First item
- Second item
  - Nested item

Ordered list:
1. First step
2. Second step
3. Third step
```

### Citazioni

```markdown
> This is a blockquote. Use it for callouts or
> highlighting important information.
```

> Questa è una citazione. Usala per evidenziare avvisi o informazioni importanti.

## Aggiunta di componenti

I componenti sono elementi JSX utilizzabili ovunque nel file MDX. Possono essere autonomi oppure racchiudere contenuti:

```mdx
{/* Self-closing component */}
<Card title="Example" icon="star" href="/introduction" />

{/* Component wrapping content */}
<Accordion title="Click to expand">
  This content is inside the accordion.
</Accordion>
```

## Tabelle

Le tabelle Markdown standard funzionano subito:

```markdown
| Feature | Starter | Team |
|---------|------|-----|
| Pages | 10 | Unlimited |
| Custom domain | No | Yes |
```

| Funzionalità | Starter | Team |
|---------|------|-----|
| Pagine | 10 | Illimitate |
| Dominio personalizzato | No | Sì |

Per funzioni avanzate come l'evidenziazione delle righe, l'allineamento delle celle e l'unione di celle, usa il componente Table:

<Table striped>
  <Row header>
    <Cell>Funzionalità</Cell>
    <Cell align="center">Starter</Cell>
    <Cell align="center">Team</Cell>
  </Row>
  <Row>
    <Cell>Pagine</Cell>
    <Cell align="center">10</Cell>
    <Cell align="center" highlight highlightColor="success">Illimitate</Cell>
  </Row>
  <Row>
    <Cell>Dominio personalizzato</Cell>
    <Cell align="center">No</Cell>
    <Cell align="center" highlight highlightColor="success">Sì</Cell>
  </Row>
</Table>

<Note>
Consulta [Tabelle](/it/components/tables) per la documentazione completa del componente, comprese le opzioni per evidenziare righe e celle, unire colonne e applicare stili.
</Note>

## Commenti

Aggiungi commenti che non compariranno nel contenuto visualizzato:

```mdx
{/* This is a comment - it won't be visible to readers */}
```
