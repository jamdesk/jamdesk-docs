I snippet sono blocchi di contenuto riutilizzabili memorizzati in una directory `/snippets`. Importali in qualsiasi pagina MDX per evitare di duplicare il contenuto.

## Creazione dei frammenti

Crea una directory `/snippets` nella radice della documentazione:

```bash
my-docs/
├── docs.json
├── introduction.mdx
└── snippets/
    ├── prerequisites.mdx
    ├── installation.mdx
    └── support-cta.mdx
```

Scrivi il contenuto dello snippet come qualsiasi file MDX, ma senza frontmatter:

```mdx snippets/prerequisites.mdx
Before you begin, make sure you have:

- Node.js 20 or higher
- A GitHub account
- A text editor (VS Code recommended)
```

## Utilizzo dei frammenti

Importa e usa gli snippet nelle tue pagine:

```mdx getting-started.mdx
---
title: Getting Started
---

## Prerequisites

import Prerequisites from '/snippets/prerequisites.mdx';

<Prerequisites />

## Installation

Continue with your page content...
```

## Componenti dei frammenti

Gli snippet possono contenere componenti Jamdesk:

```mdx snippets/support-cta.mdx
<Columns cols={2}>
  <Card title="Documentation" icon="book" href="/docs">
    Browse our guides
  </Card>
  <Card title="Contact Support" icon="headset" href="/support">
    Get help from our team
  </Card>
</Columns>
```

Usalo in qualsiasi pagina:

```mdx
import SupportCTA from '/snippets/support-cta.mdx';

## Need Help?

<SupportCTA />
```

## Frammenti interattivi

Usa file `.tsx` con la direttiva `'use client'` per gli snippet che richiedono hook di React (`useState`, `useEffect`, ecc.):

```tsx snippets/counter.tsx
'use client';

import { useState } from 'react';

export function Counter() {
  const [count, setCount] = useState(0);
  return (
    <button onClick={() => setCount(c => c + 1)}>
      Count: {count}
    </button>
  );
}
```

Importa in MDX:

```mdx
import { Counter } from '/snippets/counter';

<Counter />
```

<Note>
La direttiva `'use client'` è obbligatoria per qualsiasi componente che usa hook di React. Se la ometti, si verificano errori "useState is not defined".
</Note>

## Frammenti parametrizzati

Passa props per rendere dinamici gli snippet:

```mdx snippets/api-key-warning.mdx
export const ApiKeyWarning = ({ service }) => (
  <Warning>
    Never commit your {service} API key to version control. Use environment variables instead.
  </Warning>
);
```

Usalo con props:

```mdx
import { ApiKeyWarning } from '/snippets/api-key-warning.mdx';

<ApiKeyWarning service="Stripe" />
```

## Organizzazione dei frammenti

Nei progetti più grandi, organizza gli snippet in sottodirectory:

```bash
snippets/
├── components/
│   ├── cta-cards.mdx
│   └── feature-table.mdx
├── warnings/
│   ├── api-key.mdx
│   └── deprecation.mdx
└── shared/
    ├── prerequisites.mdx
    └── support-links.mdx
```

Importa con il percorso completo:

```mdx
import CtaCards from '/snippets/components/cta-cards.mdx';
import ApiKeyWarning from '/snippets/warnings/api-key.mdx';
```

## Casi d'uso comuni

| Caso d'uso | Esempio |
|----------|---------|
| Prerequisiti | Requisiti di sistema, configurazione account |
| Passaggi di installazione | Comandi di installazione CLI per piattaforma |
| Autenticazione API | Configurazione auth ripetuta in più endpoint |
| CTA di supporto | Link di contatto alla fine delle pagine di risoluzione problemi |
| Avvisi di deprecazione | Avvisi per funzionalità obsolete |
| Esempi di codice | Pattern di codice riutilizzabili |

## Frammento o componente inline

| Funzionalità | Snippet | Componente inline |
|---------|---------|------------------|
| Riutilizzabile tra pagine | Sì | No (specifico della pagina) |
| Può usare hook di React | Sì (con `'use client'`) | No |
| Può importare pacchetti esterni | Sì (file `.tsx`) | No |
| Sintassi | Istruzione import | `export const` in MDX |

Usa gli **snippet** per contenuti che appaiono in più pagine. Usa i **componenti inline** per componenti di presentazione una tantum su una singola pagina.
