Jamdesk include **Font Awesome Pro**: migliaia di icone gratuite e pro.

## Utilizzo delle icone nei componenti

La maggior parte dei componenti accetta una prop `icon` con il nome di un'icona Font Awesome:

```mdx
<Card title="Quickstart" icon="rocket" href="/quickstart">
  Learn how to set up your documentation site.
</Card>
```

<Card title="Quickstart" icon="rocket" href="/it/quickstart">
  Scopri come configurare il tuo sito di documentazione.
</Card>

Le icone funzionano in Card, Accordion, Tab e nelle voci di navigazione.

## Il componente Icon

Usa il componente `<Icon>` per mostrare icone inline con il testo:

```mdx
<Icon icon="check" color="green" /> Task completed
```

<Icon icon="check" color="green" /> Attività completata

### Props di Icon

| Prop | Tipo | Predefinito | Descrizione |
|------|------|-------------|-------------|
| `icon` | string | obbligatorio | Nome dell'icona Font Awesome |
| `color` | string | - | Colore con nome (red, blue, green) o hex (#FF5733) |
| `size` | number | 16 | Dimensione in pixel |

### Esempi

```mdx
<Icon icon="star" color="yellow" size={24} />
<Icon icon="circle-check" color="green" />
<Icon icon="triangle-exclamation" color="orange" />
<Icon icon="heart" color="#E91E63" size={20} />
```

<Icon icon="star" color="yellow" size={24} /> <Icon icon="circle-check" color="green" /> <Icon icon="triangle-exclamation" color="orange" /> <Icon icon="heart" color="#E91E63" size={20} />

## Trovare le icone

Sfoglia la libreria completa di icone su [fontawesome.com/icons](https://fontawesome.com/icons). Cerca ciò che ti serve, poi usa il nome dell'icona nella tua documentazione.

<Tip>
Sul sito di Font Awesome, trova il nome mostrato sotto l'icona (ad esempio "circle-check", "arrow-right"). Usa esattamente quel nome nella tua documentazione.
</Tip>

## Varianti delle icone

Le icone Font Awesome esistono in più varianti di stile che controllano il peso visivo. Aggiungi un prefisso al nome dell'icona per scegliere una variante.

### Varianti disponibili

| Variante | Prefisso | Esempio | Descrizione |
|----------|----------|---------|-------------|
| Solid | `solid/` | `solid/star` | Icone piene, peso maggiore |
| Regular | `regular/` | `regular/star` | Icone con contorno, peso medio |
| Light | `light/` | `light/star` | Icone con contorno più sottile |
| Thin | `thin/` | `thin/star` | Icone con contorno sottilissimo |
| Duotone | `duotone/` | `duotone/star` | Icone a due toni con colori sovrapposti |

È disponibile anche la famiglia **Sharp** di Font Awesome, con angoli squadrati: `sharp-solid/`, `sharp-regular/`, `sharp-light/`, `sharp-thin/` e `sharp-duotone-solid/` (ad esempio `sharp-duotone-solid/star`).

### Esempi

```mdx
<Icon icon="solid/bell" size={24} />
<Icon icon="regular/bell" size={24} />
<Icon icon="light/bell" size={24} />
<Icon icon="thin/bell" size={24} />
<Icon icon="duotone/bell" size={24} />
```

<Icon icon="solid/bell" size={24} /> <Icon icon="regular/bell" size={24} /> <Icon icon="light/bell" size={24} /> <Icon icon="thin/bell" size={24} /> <Icon icon="duotone/bell" size={24} />

### Utilizzo delle varianti nei componenti

Le varianti funzionano ovunque si usano le icone: componenti, navigazione e frontmatter.

```mdx
<Card title="Callouts" icon="light/bell" href="/components/callouts">
  Add important notices to your documentation.
</Card>
```

```yaml page.mdx
---
title: Settings
icon: light/gear
---
```

```json docs.json
{
  "group": "Account",
  "icon": "regular/user",
  "pages": ["profile", "settings"]
}
```

### Forma a oggetto delle icone

Ovunque `docs.json` accetta un'icona (gruppi di navigazione, tab, anchor, icone di pagina e `popularPages` della ricerca), puoi scriverla come oggetto invece che come stringa. Il selettore di icone della dashboard produce questa forma:

```json docs.json
{
  "group": "Security",
  "icon": { "name": "shield", "style": "duotone" }
}
```

| Campo | Tipo | Descrizione |
|-------|------|-------------|
| `name` | string | Nome dell'icona Font Awesome (obbligatorio) |
| `style` | string | Una delle varianti sopra: `solid`, `regular`, `light`, `thin`, `duotone`, oppure una variante `sharp-*` |
| `library` | string | `fontawesome` o `lucide`, accettati per compatibilità; le icone vengono renderizzate tramite Font Awesome |

`{ "name": "shield", "style": "duotone" }` è equivalente alla stringa `"duotone/shield"`. Usa quella che preferisci. Il campo `icon` nel frontmatter (icone di pagina) accetta solo la forma a stringa.

### Variante predefinita

Le icone vengono renderizzate nella variante **Solid** per impostazione predefinita. Puoi sostituirla per singola icona con un prefisso di stile (`light/gear`) o, in `docs.json`, con il campo `style` della forma a oggetto.

### Confronto tra le varianti

La stessa icona in ogni variante:

| Variante | Icona | Ideale per |
|----------|-------|------------|
| Solid | <Icon icon="solid/folder" size={20} /> | Azioni principali, enfasi |
| Regular | <Icon icon="regular/folder" size={20} /> | Elementi secondari dell'interfaccia |
| Light | <Icon icon="light/folder" size={20} /> | Design minimali, navigazione |
| Thin | <Icon icon="thin/folder" size={20} /> | Estetiche ultra-minimali |
| Duotone | <Icon icon="duotone/folder" size={20} /> | Interesse visivo, branding |

<Note>
Le icone duotone usano due colori: una tonalità primaria e una secondaria. Il livello secondario viene impostato automaticamente con un'opacità più chiara del colore primario.
</Note>

## Icone di navigazione

Le icone possono apparire nella navigazione della barra laterale a tre livelli: anchor, gruppi e singole pagine.

### Icone delle pagine

Aggiungi un'icona a qualsiasi pagina usando il frontmatter:

```yaml authentication.mdx
---
title: Authentication
icon: lock
---
```

L'icona appare nella barra laterale accanto al titolo della pagina.

### Icone dei gruppi

Aggiungi icone ai gruppi di navigazione in `docs.json`:

```json docs.json
{
  "group": "Security",
  "icon": "shield",
  "pages": ["authentication", "api-keys"]
}
```

### Icone degli ancoraggi

Aggiungi icone agli anchor di primo livello in `docs.json`:

```json docs.json
{
  "navigation": {
    "anchors": [
      {
        "anchor": "Docs",
        "icon": "book-open",
        "groups": [...]
      },
      {
        "anchor": "API",
        "icon": "code",
        "groups": [...]
      }
    ]
  }
}
```

## Icone gratuite e Pro

Jamdesk include Font Awesome Pro, il che significa:

- **7.000+ icone** disponibili (contro circa 2.000 nella versione free)
- Tutte le icone free funzionano senza modifiche
- Sono incluse anche le icone esclusive Pro, come le varianti duotone
- Disponibili anche icone con peso light e thin

Le icone di una piattaforma di documentazione che usava Font Awesome Free continuano a funzionare dopo la migrazione.
