Le pagine Jamdesk sono file MDX: Markdown standard con componenti React disponibili ovunque servano. Una pagina contiene semplicemente frontmatter e contenuto.

```mdx
---
title: Rate Limits
description: How rate limiting works across API tiers.
---

Requests are limited per API key.

<Note>Enterprise plans have custom limits.</Note>
```

La maggior parte dei contenuti che scriverai sarà in Markdown semplice. Le pagine di questa sezione trattano il resto: blocchi di codice con evidenziazione della sintassi, immagini e video, notazione matematica, snippet riutilizzabili e campi frontmatter che controllano titoli, icone e metadati SEO.
