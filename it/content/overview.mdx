Le pagine Jamdesk sono file MDX: Markdown standard con componenti React disponibili dove servono. Una pagina è composta da frontmatter e contenuto.

```mdx
---
title: Rate Limits
description: How rate limiting works across API tiers.
---

Requests are limited per API key.

<Note>Enterprise plans have custom limits.</Note>
```

Gran parte di quello che scriverai è Markdown semplice. Le pagine di questa sezione coprono il resto: blocchi di codice con evidenziazione della sintassi, immagini e video, notazione matematica, snippet riutilizzabili e i campi frontmatter che controllano titoli, icone e metadati SEO.
