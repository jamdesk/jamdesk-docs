## Accesso

Usa le stesse credenziali del [dashboard web](https://dashboard.jamdesk.com):

- Email e password
- Google Sign-In

Dopo il primo accesso, Face ID o Touch ID sblocca l'app agli avvii successivi.

## Notifiche push

Vai su **Settings** nell'app per attivare o disattivare:

- **Build success** — ricevi una notifica quando un deploy viene completato.
- **Build failure** — ricevi una notifica nel momento in cui una build non va a buon fine, insieme al messaggio di errore.

Le preferenze per le notifiche sono specifiche per dispositivo, quindi puoi ricevere gli avvisi sul telefono senza inviarli anche al tablet.

## Sola lettura per scelta

L'app mobile non avvia nuove build. Le build vengono avviate automaticamente quando esegui un push sul tuo provider Git; eventuali ricostruzioni manuali vengono eseguite dal [dashboard web](https://dashboard.jamdesk.com). L'app serve per monitorare, non per controllare: puoi verificare la documentazione senza dover cambiare contesto.

Se devi gestire le impostazioni del progetto, invitare membri, ruotare le chiavi API o avviare una ricostruzione manuale, apri il dashboard web.

## Privacy

L'app comunica direttamente con lo stesso backend Firebase del dashboard web, quindi non esiste un livello API separato tra i due e nessun relay di analisi raccoglie la tua attività. I dati del tuo progetto non lasciano mai l'infrastruttura Jamdesk.
