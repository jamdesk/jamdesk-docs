## Accesso

Usa le stesse credenziali della [dashboard web](https://dashboard.jamdesk.com):

- Email e password
- Accesso con Google

Face ID o Touch ID sbloccano l'app dopo il primo accesso.

## Notifiche push

Attiva o disattiva le notifiche in **Settings** nell'app:

- **Build riuscita**: un deploy viene completato.
- **Build fallita**: una build si interrompe. La notifica include il messaggio di errore.

Le preferenze di notifica sono per dispositivo. Gli avvisi possono arrivare sul telefono ed evitare il tablet.

## Sola lettura per scelta

L'app mobile non avvia nuove build. Le build partono quando esegui un push verso il tuo provider Git. Avvia una ricostruzione manuale dalla [dashboard web](https://dashboard.jamdesk.com). L'app è un monitor, non un pannello di controllo.

Usa la dashboard web per modificare le impostazioni del progetto, invitare membri, ruotare le chiavi API o avviare manualmente una build.

## Privacy

L'app comunica direttamente con lo stesso backend Firebase della dashboard web. Non esiste un livello API separato né un relay di analisi che raccolga la tua attività. I dati del tuo progetto non lasciano mai l'infrastruttura Jamdesk.
