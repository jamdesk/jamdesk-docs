Esegui `jamdesk dev` (o `npx jamdesk dev`) da qualsiasi directory che contenga un `docs.json` per avviare un server locale con ricaricamento automatico, ricerca completa e tutti i componenti funzionanti esattamente come in produzione.

## Prerequisiti

Prima di iniziare, assicurati di avere:

- **Node.js 20+** - Verifica con `node --version`
- **Un progetto docs** - Con un file di configurazione `docs.json`

## Avvio del server di sviluppo

<Tabs>
  <Tab title="npm (Global Install)">
    Installa la CLI globalmente, quindi eseguila dalla directory della documentazione:

    ```bash
    npm install -g jamdesk
    cd your-docs
    jamdesk dev
    ```
  </Tab>
  <Tab title="npx (No Install)">
    Eseguila direttamente senza installarla:

    ```bash
    cd your-docs
    npx jamdesk dev
    ```
  </Tab>
</Tabs>

La documentazione sarà disponibile all'indirizzo **http://localhost:3000**

## Porta personalizzata

La porta predefinita è 3000. Se è in uso, specificane un'altra:

```bash
jamdesk dev --port 3001
```

Oppure imposta un valore predefinito permanente in `~/.jamdeskrc`:

```json
{
  "defaultPort": 3001
}
```

## Modalità dettagliata

Visualizza informazioni dettagliate sul build con il flag `--verbose`:

```bash
jamdesk dev --verbose
```

Vengono mostrati:
- Rilevamento delle modifiche ai file
- Durata del build
- Analisi della navigazione
- Eventuali avvisi o errori

## Prestazioni al primo avvio

<Note>
La prima volta che esegui `jamdesk dev`, le dipendenze vengono installate in `~/.jamdesk`. L'operazione richiede 30-60 secondi. Gli avvii successivi richiedono meno di 5 secondi.
</Note>

Per svuotare la cache e forzare una nuova installazione:

```bash
jamdesk clean
jamdesk dev
```

## Risoluzione dei problemi

<AccordionGroup>
  <Accordion title="Port already in use">
    Un altro processo sta usando la porta 3000.

    **Opzione 1:** Usa una porta diversa
    ```bash
    jamdesk dev --port 3001
    ```

    **Opzione 2:** Individua e arresta il processo
    ```bash
    lsof -i :3000
    kill -9 <PID>
    ```
  </Accordion>

  <Accordion title="docs.json not found">
    Assicurati di trovarti nella directory che contiene il file `docs.json`:

    ```bash
    ls docs.json  # Should show the file
    jamdesk dev
    ```
  </Accordion>

  <Accordion title="Changes not appearing">
    Prova questi passaggi:
    1. Controlla la presenza di errori nel terminale
    2. Esegui un aggiornamento forzato del browser (Cmd+Shift+R)
    3. Riavvia il server di sviluppo
    4. Esegui `jamdesk clean` e riprova
  </Accordion>

  <Accordion title="Slow startup">
    Esegui la diagnostica:
    ```bash
    jamdesk doctor
    ```

    Questo comando controlla il tuo ambiente e identifica eventuali problemi.
  </Accordion>
</AccordionGroup>
