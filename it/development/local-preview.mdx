---

Esegui `jamdesk dev` (oppure `npx jamdesk dev`) da una directory che contiene un `docs.json`. Avvia un server locale con hot reload e ricerca. I componenti vengono visualizzati come in produzione.

## Prerequisiti

- **Node.js 20+** - Verifica con `node --version`
- **Un progetto di documentazione** - Con un file di configurazione `docs.json`

## Avvio del server di sviluppo

<Tabs>
  <Tab title="npm (installazione globale)">
    Installa la CLI globalmente, poi esegui il comando dalla directory della documentazione:

    ```bash
    npm install -g jamdesk
    cd your-docs
    jamdesk dev
    ```
  </Tab>
  <Tab title="npx (senza installazione)">
    Esegui direttamente senza installare:

    ```bash
    cd your-docs
    npx jamdesk dev
    ```
  </Tab>
</Tabs>

La tua documentazione sarà disponibile all'indirizzo **http://localhost:3000**

## Porta personalizzata

La porta predefinita è 3000. Passane una diversa con `--port`:

```bash
jamdesk dev --port 3001
```

Oppure imposta un valore predefinito permanente in `~/.jamdeskrc`:

```json
{
  "defaultPort": 3001
}
```

## Modalità dettagliata

Mostra i dettagli della build con il flag `--verbose`:

```bash
jamdesk dev --verbose
```

Questo mostra:
- Rilevamento delle modifiche ai file
- Tempi di build
- Analisi della navigazione
- Eventuali avvisi o errori

## Prestazioni al primo avvio

<Note>
Il primo avvio di `jamdesk dev` installa le dipendenze in `~/.jamdesk`. Questo richiede 30-60 secondi. Gli avvii successivi partono in meno di 5 secondi.
</Note>

Pulisci la cache e forza una nuova installazione:

```bash
jamdesk clean
jamdesk dev
```

## Risoluzione dei problemi

<AccordionGroup>
  <Accordion title="Porta già in uso">
    Un altro processo sta usando la porta 3000.

    **Opzione 1:** Usa una porta diversa
    ```bash
    jamdesk dev --port 3001
    ```

    **Opzione 2:** Trova e interrompi il processo
    ```bash
    lsof -i :3000
    kill -9 <PID>
    ```
  </Accordion>

  <Accordion title="docs.json non trovato">
    Esegui il comando dalla directory che contiene il tuo file `docs.json`:

    ```bash
    ls docs.json  # Should show the file
    jamdesk dev
    ```
  </Accordion>

  <Accordion title="Modifiche non visibili">
    1. Controlla il terminale per eventuali errori
    2. Esegui un refresh forzato del browser (Cmd+Shift+R)
    3. Riavvia il server di sviluppo
    4. Esegui `jamdesk clean` e riprova
  </Accordion>

  <Accordion title="Avvio lento">
    Esegui la diagnostica:
    ```bash
    jamdesk doctor
    ```

    Controlla il tuo ambiente e segnala eventuali problemi.
  </Accordion>
</AccordionGroup>
