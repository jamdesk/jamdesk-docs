---

Visualizza in anteprima la documentazione senza uscire da Visual Studio Code. L'estensione Jamdesk aggiunge un pulsante alla barra di stato che avvia `jamdesk dev`, monitora il server e apre il browser quando è pronto. Non serve alcun terminale.

## Prerequisiti

- [Jamdesk CLI](/it/cli/overview) installato (`npm install -g jamdesk`)
- Un workspace contenente un file `docs.json`

## Installare l'estensione

Cerca **Jamdesk** nel pannello Extensions di VS Code (`Cmd+Shift+X` su macOS, `Ctrl+Shift+X` su Windows/Linux) e fai clic su **Install**. In alternativa, installala direttamente dal [VS Code Marketplace](https://marketplace.visualstudio.com/items?itemName=Jamdesk.jamdesk).

L'estensione si attiva automaticamente quando il workspace contiene un file `docs.json`. Nella barra di stato viene visualizzato un pulsante di riproduzione.

## Avviare il server di sviluppo

Fai clic sul pulsante di riproduzione nella barra di stato per avviare il server di sviluppo. L'estensione:

1. Avvia `jamdesk dev` come processo figlio
2. Monitora l'output per rilevare quando il server è pronto
3. Apre il browser sull'anteprima locale, se l'apertura automatica è abilitata

La barra di stato mostra lo stato attuale del server: in avvio, in esecuzione o arrestato.

## Comandi

Apri la Command Palette (`Cmd+Shift+P` / `Ctrl+Shift+P`) e digita "Jamdesk" per accedere a:

| Comando | Descrizione |
|---------|-------------|
| **Jamdesk: Start Dev Server** | Avvia il server di sviluppo |
| **Jamdesk: Stop Dev Server** | Arresta il server in esecuzione |
| **Jamdesk: Restart Dev Server** | Riavvia il server |
| **Jamdesk: Show Output** | Mostra il canale di output della CLI |

## Impostazioni

Configura l'estensione nelle impostazioni di VS Code (`Cmd+,` / `Ctrl+,`), nella sezione **Jamdesk**:

| Impostazione | Predefinito | Descrizione |
|-------------|-------------|-------------|
| `jamdesk.port` | `3000` | Porta preferita del server di sviluppo |
| `jamdesk.verbose` | `false` | Abilita l'output dettagliato della CLI |
| `jamdesk.clean` | `false` | Cancella la cache della build al prossimo avvio |
| `jamdesk.browserMode` | `external` | Dove aprire l'anteprima: `external` (browser di sistema) o `embedded` (pannello laterale di VS Code) |
| `jamdesk.autoOpenBrowser` | `true` | Apre il browser quando il server è pronto |

<Tip>
Imposta `browserMode` su `embedded` per aprire l'anteprima della documentazione in un pannello laterale di VS Code. Puoi così modificare e visualizzare l'anteprima affiancate senza cambiare finestra.
</Tip>

## Gestione intelligente delle porte

Se la porta preferita è già in uso, la CLI passa automaticamente alla porta disponibile successiva. L'estensione rileva la porta effettiva dall'output della CLI, così il browser viene sempre aperto sull'URL corretto.

## Canale di output

L'estensione trasmette tutto l'output della CLI a un canale di output **Jamdesk** dedicato. Aprilo con il comando **Jamdesk: Show Output** o dal menu a discesa del pannello Output.

Usalo per:

- Monitorare l'avanzamento della build
- Eseguire il debug dei problemi del server
- Visualizzare i log dettagliati, quando `jamdesk.verbose` è abilitato
