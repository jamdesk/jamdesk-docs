---

Visualizza in anteprima la tua documentazione senza uscire da Visual Studio Code. L'estensione Jamdesk aggiunge un pulsante nella barra di stato che avvia `jamdesk dev`. Monitora il server e apre il browser quando il server è pronto.

## Prerequisiti

- [CLI Jamdesk](/it/cli/overview) installata (`npm install -g jamdesk`)
- Un workspace contenente un file `docs.json`

## Installare l'estensione

Cerca **Jamdesk** nel pannello Estensioni di VS Code (`Cmd+Shift+X` su macOS, `Ctrl+Shift+X` su Windows/Linux) e fai clic su **Install**. Oppure installala dal [VS Code Marketplace](https://marketplace.visualstudio.com/items?itemName=Jamdesk.jamdesk).

L'estensione si attiva in un workspace che contiene un file `docs.json`. Nella barra di stato compare un pulsante di riproduzione.

## Avviare il server di sviluppo

Fai clic sul pulsante di riproduzione nella barra di stato. L'estensione:

1. Avvia `jamdesk dev` come processo figlio
2. Monitora l'output per rilevare quando il server è pronto
3. Apre il browser sull'anteprima locale (se l'apertura automatica è abilitata)

La barra di stato mostra lo stato corrente del server: in avvio, in esecuzione o arrestato.

## Comandi

Apri la Command Palette (`Cmd+Shift+P` / `Ctrl+Shift+P`) e digita "Jamdesk":

| Comando | Descrizione |
|---------|-------------|
| **Jamdesk: Start Dev Server** | Avvia il server di sviluppo |
| **Jamdesk: Stop Dev Server** | Arresta il server in esecuzione |
| **Jamdesk: Restart Dev Server** | Riavvia il server |
| **Jamdesk: Show Output** | Mostra il canale di output della CLI |

## Impostazioni

Configura l'estensione nelle impostazioni di VS Code (`Cmd+,` / `Ctrl+,`) in **Jamdesk**:

| Impostazione | Predefinito | Descrizione |
|--------------|-------------|-------------|
| `jamdesk.port` | `3000` | Porta preferita del server di sviluppo |
| `jamdesk.verbose` | `false` | Abilita l'output dettagliato della CLI |
| `jamdesk.clean` | `false` | Cancella la cache di build al prossimo avvio |
| `jamdesk.browserMode` | `external` | Dove aprire l'anteprima: `external` (browser di sistema) o `embedded` (pannello laterale di VS Code) |
| `jamdesk.autoOpenBrowser` | `true` | Apri il browser quando il server è pronto |

<Tip>
Imposta `browserMode` su `embedded` per aprire l'anteprima della documentazione in un pannello laterale di VS Code. Modifica e visualizza in anteprima affiancati.
</Tip>

## Gestione intelligente delle porte

La CLI passa alla porta libera successiva quando quella preferita è occupata. L'estensione legge la porta dall'output della CLI. Il browser si apre sull'URL corretto.

## Canale di output

L'estensione invia l'output della CLI a un canale di output **Jamdesk**. Aprilo con il comando **Jamdesk: Show Output** oppure dal menu a discesa del pannello Output.

Usalo per:
- Monitorare l'avanzamento della build
- Eseguire il debug dei problemi del server
- Visualizzare i log dettagliati (quando `jamdesk.verbose` è abilitato)
