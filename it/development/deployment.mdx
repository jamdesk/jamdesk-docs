Jamdesk gestisce automaticamente il deployment. Esegui il push sul branch GitHub collegato e la documentazione sarà online entro pochi minuti.

## Deployment tramite CLI

Puoi anche eseguire il deployment direttamente dal terminale senza effettuare il push su GitHub. È utile per iterazioni rapide, per testare le modifiche o per progetti non collegati a un repository.

```bash
jamdesk login     # First time only
jamdesk deploy
```

La CLI crea il pacchetto dei tuoi file, lo carica e mostra in tempo reale l'avanzamento della build. Usa `--detach` per accodare la build e uscire immediatamente.

## Il flusso di lavoro

<Steps>
  <Step title="Apporta modifiche localmente">
    Modifica i file MDX e visualizza l'anteprima con `jamdesk dev`.
  </Step>
  <Step title="Esegui il push su GitHub">
    Esegui il commit e il push sul branch collegato:

    ```bash
    git add .
    git commit -m "Update authentication docs"
    git push
    ```
  </Step>
  <Step title="Deployment automatico">
    Jamdesk rileva il push, crea la build della documentazione ed esegue il deployment sul CDN. La maggior parte dei siti viene compilata in 30-90 secondi.
  </Step>
</Steps>

## Stato del deployment

Controlla lo stato nel dashboard, alla voce **Deployments**:

| Stato | Significato |
|--------|---------|
| **Building** | Build in corso |
| **Deployed** | Online sul tuo dominio |
| **Failed** | Errore di build: controlla i log |
| **Queued** | In attesa della build precedente |

## Ricostruzione manuale

Avvia una nuova build senza effettuare il push:

1. Vai a **Settings** nel tuo progetto
2. Fai clic su **Rebuild**

Usa questa opzione quando aggiorni le variabili d'ambiente o risolvi build bloccate.

## Log di build

Quando le build non riescono, controlla **Deployments** → fai clic su un deployment → visualizza i log. Problemi comuni:
- Sintassi MDX non valida
- Immagini mancanti
- Link interni non funzionanti
- Errori di configurazione

## Rollback

Ripristina una versione precedente:

1. Vai a **Deployments**
2. Trova il deployment da ripristinare
3. Fai clic su **Rollback**

La versione precedente sarà online immediatamente.
