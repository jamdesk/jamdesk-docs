---
title: Correggere i link non funzionanti
description: >-
  Scopri come jamdesk fix ripara i link interni non funzionanti e le ancore con errori di battitura, con anteprima prima di scrivere le modifiche.
---

`jamdesk fix` ripara ciò che `jamdesk broken-links` segnala. Legge gli stessi avvisi e riscrive un link quando trova un unico destinatario corretto e chiaro. Lascia intatti i casi ambigui per la revisione manuale.

<Tip>
  [Correggi con AI](/it/builds/fix-with-ai) esegue la stessa riparazione su una build dalla dashboard. Inoltre compila le descrizioni mancanti delle pagine. Esegue il commit delle modifiche su GitHub.
</Tip>

Corregge due tipi di link interni non funzionanti:

- **Ancore con errori di battitura**: un frammento che è un chiaro errore di ortografia di un titolo reale nella pagina di destinazione (ad esempio `#instalation` → `#installation`)
- **Disallineamento delle ancore tra lingue**: una pagina tradotta ha rinominato i propri titoli, ma i link in quella lingua puntano ancora al vecchio frammento inglese (ad esempio `/fr/ai/selectors#ai-strategies` → `/fr/ai/selectors#stratégies-ia`)

## Passaggio 1: trovare i link interrotti

Esegui `jamdesk broken-links` per vedere cosa va corretto:

```bash
jamdesk broken-links
```

Controlla l'output. `jamdesk fix` agisce sugli avvisi in cui riesce a far corrispondere un'ancora probabile a un titolo reale.

## Passaggio 2: visualizzare l'anteprima delle correzioni

Esegui con `--dry-run` per vedere cosa cambierebbe senza scrivere file:

```bash
jamdesk fix --dry-run
```

**Output di esempio:**

```text
Planned fixes:

  fr/ai/overview.mdx:9
    /fr/ai/selectors#ai-strategies  →  /fr/ai/selectors#stratégies-ia

(dry run — no files written)
```

Verifica ogni correzione prevista. Se una modifica sembra errata, correggi quel link a mano.

## Passaggio 3: applicare le correzioni

Esegui senza `--dry-run` per applicare. La CLI chiede conferma:

```bash
jamdesk fix
```

```text
Apply 1 fix(es) to local files? (y/N)
```

Premi `y` per scrivere le modifiche. Salta il prompt in CI o negli script con `-y`:

```bash
jamdesk fix -y
```

Il comando poi stampa:

```text
Fixed 1 file(s); 0 warning(s) left for manual review.
```

`jamdesk fix` lascia un avviso con destinazione ambigua perché tu lo corregga a mano.

## Passaggio 4: esaminare il diff ed eseguire il commit

Verifica le modifiche prima del commit:

```bash
git diff
```

Assicurati che ogni link riscritto punti dove ti aspetti. Poi effettua il commit:

```bash
git add -A
git commit -m "fix(docs): auto-fix broken internal links"
```

## Opzioni

| Flag | Descrizione |
|------|-------------|
| `--dry-run` | Visualizza in anteprima le correzioni previste senza scrivere file |
| `-y, --yes` | Applica le correzioni senza prompt di conferma |
| `--types <list>` | Tipi di avviso da correggere, separati da virgole (predefinito: tutti quelli supportati) |
