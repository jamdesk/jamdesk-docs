Questo plugin fornisce a [Claude Code](https://claude.ai/code) le conoscenze su Jamdesk che altrimenti dovresti spiegare in ogni prompt: quali componenti esistono, come funziona `docs.json`, quali sono i comandi CLI.

<Note>
  Devi prima installare Claude Code. Scaricalo da [claude.ai/code](https://claude.ai/code).
</Note>

## Installazione

<Steps>
  <Step title="Aggiungi il marketplace">
    Esegui questo comando slash in Claude Code:

    ```text
    /plugin marketplace add jamdesk/jamdesk-claude-plugin
    ```
  </Step>
  <Step title="Installa il plugin">
    ```text
    /plugin install jamdesk@jamdesk-marketplace
    ```
  </Step>
</Steps>

Puoi anche trovarlo eseguendo `/plugin` e selezionando **Discover**.

<Accordion title="Installazione manuale (per sviluppo o test)">
  ```bash
  git clone https://github.com/jamdesk/jamdesk-claude-plugin.git
  claude --plugin-dir ./jamdesk-claude-plugin
  ```
</Accordion>

## Contenuti inclusi

Il plugin ha una skill, `/jamdesk:jamdesk`. Contiene un hub di riferimento rapido e tre file di riferimento caricati on demand:

| Riferimento | Cosa copre |
|-----------|---------------|
| **Components** | Oltre 25 componenti MDX (Cards, Steps, Tabs, Callouts, Code Groups, Tables e altri) con props complete ed esempi |
| **Configuration** | Schema completo di `docs.json`: temi, colori, branding, navbar, footer, configurazione API, oltre 20 integrazioni analytics |
| **Navigation** | 8 pattern di navigazione: flat, grouped, tabbed, multi-product, versioned, multi-language, dropdowns, OpenAPI |

L'hub elenca anche i 19 comandi CLI, i campi frontmatter delle pagine, la sintassi per il dimensionamento delle immagini, gli standard di scrittura e gli errori comuni.

## Utilizzo

Esegui `/jamdesk:jamdesk` mentre lavori sulla documentazione Jamdesk.

Claude può attivare la skill automaticamente in un progetto con un `docs.json`.

Claude risponde alle domande più comuni, come la sintassi dei componenti e i comandi CLI, dall'hub. Carica un file di riferimento per tabelle complete delle props, opzioni di configurazione o dettagli sui pattern di navigazione.

## Insieme a CLAUDE.md e MCP

Il plugin funziona al meglio in una configurazione a tre livelli:

1. Il plugin insegna a Claude la piattaforma Jamdesk: componenti, configurazione, navigazione, CLI.
2. [CLAUDE.md](/it/ai/claude-code) insegna a Claude le convenzioni *del tuo progetto*: stile di scrittura, terminologia, struttura delle pagine.
3. Il [server MCP](/it/ai/mcp-server) permette a Claude di cercare e leggere la tua documentazione pubblicata.

Non ti servono tutti e tre. Il plugin è utile anche da solo. Un CLAUDE.md e una connessione MCP permettono a Claude di adattarsi al tono del tuo sito e di collegarsi alle pagine esistenti.
