Ogni volta che chiedi a Claude di scrivere una pagina Jamdesk, finisci per dover spiegare sempre le stesse cose: quali componenti esistono, come funziona `docs.json` e quali sono i comandi CLI. Questo plugin fornisce in anticipo a [Claude Code](https://claude.ai/code) queste informazioni, così puoi saltare il preambolo e iniziare subito a creare.

<Note>
  Devi prima installare Claude Code. Scaricalo da [claude.ai/code](https://claude.ai/code).
</Note>

## Installazione

<Steps>
  <Step title="Aggiungi il marketplace">
    Esegui questo comando slash in Claude Code:

    ```text
    /plugin marketplace add jamdesk/jamdesk-claude-plugin
    ```
  </Step>
  <Step title="Installa il plugin">
    ```text
    /plugin install jamdesk@jamdesk-marketplace
    ```
  </Step>
</Steps>

Puoi trovarlo anche eseguendo `/plugin` e selezionando **Discover**.

<Accordion title="Installazione manuale (per sviluppo o test)">
  ```bash
  git clone https://github.com/jamdesk/jamdesk-claude-plugin.git
  claude --plugin-dir ./jamdesk-claude-plugin
  ```
</Accordion>

## Contenuti inclusi

Una skill (`/jamdesk:jamdesk`) con un hub di riferimento rapido e tre file di riferimento dettagliati caricati su richiesta:

| Riferimento | Contenuto |
|-----------|---------------|
| **Componenti** | Oltre 25 componenti MDX (Card, Steps, Tabs, Callout, gruppi di codice, tabelle e altro) con tutte le proprietà e gli esempi |
| **Configurazione** | Schema completo di `docs.json`: temi, colori, branding, navbar, footer, configurazione API e oltre 20 integrazioni di analytics |
| **Navigazione** | 8 pattern di navigazione: piatta, raggruppata, a schede, multi-prodotto, con versioni, multilingue, menu a discesa e OpenAPI |

L'hub include anche tutti i 19 comandi CLI, i campi del frontmatter delle pagine, la sintassi per il dimensionamento delle immagini, gli standard di scrittura e gli errori comuni.

## Utilizzo

Quando lavori sulla documentazione Jamdesk, esegui `/jamdesk:jamdesk`.

Se il tuo progetto contiene un file `docs.json`, Claude potrebbe attivare automaticamente la skill.

Le domande comuni, come quelle sulla sintassi dei componenti e sui comandi CLI, ricevono risposta direttamente dall'hub. Hai bisogno delle tabelle complete delle proprietà, di tutte le opzioni di configurazione o dei dettagli sui pattern di navigazione? Claude carica il file di riferimento specifico.

## Insieme a CLAUDE.md e MCP

Funziona al meglio come parte di una configurazione a tre livelli:

1. Il plugin insegna a Claude come funziona la piattaforma Jamdesk: componenti, configurazione, navigazione e CLI.
2. [CLAUDE.md](/it/ai/claude-code) insegna a Claude le convenzioni del *tuo progetto*: stile di scrittura, terminologia e struttura delle pagine.
3. Il [server MCP](/it/ai/mcp-server) consente a Claude di accedere alla documentazione pubblicata, per cercare e leggere contenuti e controllare le pagine esistenti.

Non ti servono tutti e tre. Il solo plugin è utile. Tuttavia, insieme a un file CLAUDE.md e a una connessione MCP, Claude può scrivere pagine coerenti con lo stile del tuo sito e collegarle ai contenuti esistenti senza procedere per tentativi.

## Aggiornamenti e codice sorgente

Controlla la disponibilità di aggiornamenti eseguendo `/plugin` in Claude Code. Puoi anche eseguire nuovamente il comando di installazione per scaricare la versione più recente.

Il plugin è open source (Apache 2.0). Esamina il codice sorgente, segnala problemi o contribuisci: [github.com/jamdesk/jamdesk-claude-plugin](https://github.com/jamdesk/jamdesk-claude-plugin). [Changelog](https://github.com/jamdesk/jamdesk-claude-plugin/blob/main/CHANGELOG.md).
