Jamdesk pubblica la documentazione su un sottodominio `*.jamdesk.app`. Per andare online sul tuo dominio, scegli un sottodominio personalizzato (come `docs.example.com`) oppure un sottopercorso del sito principale. Il sottopercorso predefinito è `/docs`, ma puoi scegliere qualsiasi altro segmento personalizzato.

## Opzioni di deploy

| Opzione | Ideale per | Complessità di configurazione |
|---------|------------|-------------------------------|
| **Sottodominio Jamdesk** (`your-project.jamdesk.app`) | Avvio più rapido, nessun lavoro sui DNS | Bassa |
| **Sottodominio personalizzato** (`docs.example.com`) | Documentazione di produzione con il tuo brand | Media |
| **Hosting su sottopercorso** (`example.com/docs`, personalizzabile) | Mantenere la documentazione sul dominio principale | Alta |

## Hosting predefinito (nessuna configurazione)

Ogni progetto va online su un sottodominio Jamdesk non appena colleghi un repository. Puoi usarlo per documentazione interna, anteprime o lanci iniziali.

## Dominio personalizzato (sottodominio)

Usa un tuo sottodominio (ad esempio `docs.example.com`) per avere un URL pubblico con il tuo brand. Aggiungi i record DNS e verifica la proprietà nella dashboard di Jamdesk.

<Note>
Jamdesk verifica i DNS ed emette il certificato SSL una volta inseriti i record. Consulta [Domini personalizzati](/it/deploy/custom-domains) per la configurazione.
</Note>

## Hosting in un sottopercorso

Instrada il traffico verso Jamdesk per ospitare la documentazione su un sottopercorso del tuo dominio. Il valore predefinito è `example.com/docs`, oppure puoi scegliere un segmento personalizzato come `example.com/help`. Usa questa opzione per mantenere la documentazione sotto il dominio marketing principale.

<Info>
L'hosting su sottopercorso richiede un livello di proxy o CDN che inoltri le richieste e imposti l'header `X-Jamdesk-Forwarded-Host`. Consulta [Hosting su sottopercorso](/it/deploy/subpath-hosting).
</Info>

### Esempio di configurazione proxy (nginx)

```nginx nginx.conf
location /docs {
    proxy_pass https://YOUR_SLUG.jamdesk.app;
    proxy_set_header X-Jamdesk-Forwarded-Host $host;
}

location /_next/ {
    proxy_pass https://YOUR_SLUG.jamdesk.app;
}

location /_jd/ {
    proxy_pass https://YOUR_SLUG.jamdesk.app;
}
```

Consulta la guida [Hosting su sottopercorso](/it/deploy/subpath-hosting) per una configurazione completa con SSL, header e passaggi specifici per ogni provider.
