Jamdesk è uno [strumento per la documentazione software](https://jamdesk.com) che crea siti di documentazione dai tuoi file Markdown. Collega un repository GitHub, scrivi in MDX e pubblica globalmente in pochi secondi. Non devi configurare una pipeline di build né occuparti personalmente di DevOps. Ogni sito genera un file `llms.txt` che consente agli strumenti di IA di indicizzare i tuoi contenuti.

<Info>
**Scrivi con l'IA.** Usa Cursor, Claude o qualsiasi assistente IA per generare e modificare la tua documentazione. MDX è un formato di testo che gli strumenti di IA comprendono nativamente, quindi non servono prompt speciali.
</Info>

## Un progetto Jamdesk minimo

```text
my-docs/
├── docs.json
└── introduction.mdx
```

Tutto qui. Consulta il [Quickstart](/it/quickstart) per crearne uno.

<Tip>
Consulta su GitHub il [sorgente di questa documentazione](https://github.com/jamdesk/jamdesk-docs). È un progetto Jamdesk funzionante che puoi usare come riferimento.
</Tip>

## Come funziona

<Steps>
  <Step title="Scrivi in MDX">
    Crea la documentazione usando Markdown con componenti React opzionali. Usa il tuo editor preferito: VS Code, Cursor o qualsiasi editor di testo semplice. Gli strumenti di IA come Claude possono generare e modificare MDX in modo nativo.
  </Step>
  <Step title="Esegui il push su GitHub">
    Esegui il commit delle modifiche e il push. Non devi eseguire un comando di build né gestire uno script di deploy.
  </Step>
  <Step title="Online in pochi secondi">
    Jamdesk rileva il tuo push, crea il sito e lo pubblica su una CDN globale. La tua documentazione è disponibile all'indirizzo `your-project.jamdesk.app`.
  </Step>
</Steps>
