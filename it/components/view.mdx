Le viste cambiano intere sezioni di una pagina per adattarsi al framework o alla lingua scelti dal lettore. Le schede mostrano le opzioni affiancate. Le viste nascondono completamente il contenuto non selezionato. Usale quando intere sezioni differiscono tra i vari framework.

Usa le Viste quando:
- **Intere sezioni della pagina** differiscono per framework (non solo frammenti di codice)
- I **tutorial** hanno passaggi diversi per tecnologie diverse
- Le **guide introduttive** differiscono per piattaforma

<Tip>
Per esempi di codice che differiscono per linguaggio, usa [CodeGroup](/it/components/code-group). Per procedure con differenze minime, usa [Tabs](/it/components/tabs). Usa le Viste quando **intere sezioni** di contenuto sono specifiche per framework.
</Tip>

## Come funziona

Una pagina con componenti View funziona così:

1. Un selettore a tendina appare in cima al contenuto
2. I lettori passano da una vista all'altra con la tendina
3. È visibile solo il contenuto della vista selezionata

## View, Tabs e CodeGroup a confronto

| Componente | Ideale per | Ambito |
|-----------|----------|-------|
| **View** | Intere sezioni che differiscono per framework | Cambio di contenuto a livello di pagina |
| **Tabs** | Confronti rapidi, gestori di pacchetti | Cambio di contenuto in linea |
| **CodeGroup** | Stessa operazione in più linguaggi | Solo blocchi di codice |

**Scenari di esempio:**
- "Installa con npm vs yarn" → **Tabs** (differenza minima)
- "JavaScript fetch vs Python requests" → **CodeGroup** (confronto di codice)
- "Tutorial React vs tutorial Vue" → **View** (intera sezione diversa)

## Props

<ParamField name="title" type="string" required>
  Il titolo visualizzato nel selettore a tendina. Deve essere univoco all'interno della pagina.
</ParamField>

<ParamField name="icon" type="string">
  Un'icona Font Awesome, un URL di un'icona o un percorso relativo a un'icona.
</ParamField>

<ParamField name="iconType" type="string" default="solid">
  Solo per le icone Font Awesome. Opzioni: `regular`, `solid`, `light`, `thin`, `sharp-solid`, `duotone`, `brands`.
</ParamField>
