Le viste consentono di creare documentazione che si adatta al framework o alla lingua scelti dal lettore. A differenza delle Tabs, che mostrano più opzioni affiancate, le viste nascondono del tutto i contenuti non selezionati. In questo modo la pagina resta più ordinata quando intere sezioni variano in base al framework.

Usa le viste quando:
- **Intere sezioni della pagina** variano in base al framework, non solo gli snippet di codice
- I **tutorial** prevedono passaggi diversi per tecnologie diverse
- Le **guide introduttive** cambiano significativamente in base alla piattaforma

<Tip>
Per gli esempi di codice che variano in base al linguaggio, usa [CodeGroup](/it/components/code-group). Per le procedure con differenze minime, usa [Tabs](/it/components/tabs). Usa le viste quando **intere sezioni** dei contenuti dipendono dal framework.
</Tip>

## Utilizzo di base

Crea viste per linguaggi diversi:

  console.log("Hello from JavaScript!");

## Come funziona

Quando aggiungi componenti View a una pagina:

1. Nella parte superiore dei contenuti compare un selettore a discesa
2. Gli utenti possono passare da una vista all'altra usando il menu a discesa
3. È visibile solo il contenuto della vista selezionata

## View, Tabs e CodeGroup a confronto

| Componente | Ideale per | Ambito |
|-----------|----------|-------|
| **View** | Intere sezioni che variano in base al framework | Cambio dei contenuti nell'intera pagina |
| **Tabs** | Confronti rapidi, gestori di pacchetti | Cambio dei contenuti in linea |
| **CodeGroup** | La stessa operazione in più linguaggi | Solo blocchi di codice |

**Esempi:**
- «Installa con npm o yarn» → **Tabs** (differenza minima)
- «JavaScript fetch o Python requests» → **CodeGroup** (confronto tra blocchi di codice)
- «Tutorial React o tutorial Vue» → **View** (l'intera sezione è diversa)

## Props

<ParamField name="title" type="string" required>
  Il titolo mostrato nel selettore a discesa. Deve essere univoco all'interno della pagina.
</ParamField>

<ParamField name="icon" type="string">
  Un'icona Font Awesome, l'URL di un'icona o il percorso relativo a un'icona.
</ParamField>

<ParamField name="iconType" type="string" default="solid">
  Solo per le icone Font Awesome. Opzioni: `regular`, `solid`, `light`, `thin`, `sharp-solid`, `duotone`, `brands`.
</ParamField>
