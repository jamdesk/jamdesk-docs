title: Prompt
description: Usa Prompt per presentare istruzioni AI riutilizzabili con copia, azioni di apertura integrate, destinazioni personalizzate, icone e opzioni di visualizzazione compatte.
---

Il componente `<Prompt>` trasforma un insieme riutilizzabile di istruzioni in una scheda che i lettori possono copiare o aprire in uno strumento AI supportato. Le azioni di copia e apertura usano esattamente il contenuto visibile all'utente, scritto tra i tag.

## Utilizzo di base

Ogni Prompt ha un'azione Copia. La versione più semplice non richiede props:

<Prompt>
Spiega come funziona la rotazione delle chiavi API per uno sviluppatore che usa la nostra REST API per la prima volta.
</Prompt>

```mdx
<Prompt>
Explain how API key rotation works for a developer using our REST API for the first time.
</Prompt>
```

## Titolo e descrizione

Usa `title` per dare un'etichetta all'attività. La prop `description`, compatibile con Mintlify, sostituisce l'anteprima visibile con un riepilogo più breve. Le azioni di copia e apertura usano comunque il contenuto completo visibile tra i tag.

<Prompt
  title="Redigi una nota di rilascio"
  description="Scrivi una nota di rilascio concisa per un pubblico di sviluppatori."
  actions={["copy", "claude"]}
>
Scrivi una nota di rilascio per il nuovo endpoint di rotazione delle chiavi API.

- Rivolgiti agli sviluppatori backend.
- Parti dal beneficio per l'utente.
- Includi un esempio di richiesta.
</Prompt>

```mdx
<Prompt
  title="Draft a release note"
  description="Write a concise release note for a developer audience."
  actions={["copy", "claude"]}
>
Write a release note for the new API key rotation endpoint.

- Address backend developers.
- Lead with the user benefit.
- Include one request example.
</Prompt>
```

Copia è sempre presente. Un'azione `"copy"` esplicita è accettata per compatibilità ma non è mai necessaria.

<Note>
  Prompt copia esattamente il contenuto visibile all'utente. In un prompt che contiene [Visibility](/it/components/visibility), Jamdesk rimuove dal testo copiato i tag wrapper riservati agli utenti e mantiene il loro contenuto. I sottoalberi riservati agli agenti sono esclusi. Jamdesk esclude anche Visibility con una prop `for` espressa come valore dinamico o con un pubblico nascosto da un attributo spread successivo, perché il pubblico non può essere determinato staticamente. Visibility senza prop `for`, con `for` in forma abbreviata o con un pubblico letterale non valido resta visibile. Un Prompt nascosto all'interno di Visibility riservato agli agenti o con espressioni/spread che ne oscurano il pubblico non ha una sorgente copiabile.
</Note>

## Azioni di apertura

Aggiungi `claude`, `cursor`, `chatgpt`, `perplexity` o `gemini` per permettere ai lettori di aprire il prompt in questi strumenti. Ogni azione mostra la relativa icona del marchio. La prima azione di apertura valida compare accanto a Copia. Le altre compaiono nel menu Altro.

<Prompt
  title="Confronta i flussi di autenticazione"
  actions={["claude", "cursor", "chatgpt", "perplexity", "gemini"]}
>
Confronta i flussi di autenticazione con token di sessione e con chiave API in questo repository. Elenca i loro compromessi di sicurezza e consiglia quale flusso usare per ciascun tipo di client.
</Prompt>

```mdx
<Prompt
  title="Compare authentication flows"
  actions={["claude", "cursor", "chatgpt", "perplexity", "gemini"]}
>
Compare the session-token and API-key authentication flows in this repository.
List their security tradeoffs and recommend which flow each client type should use.
</Prompt>
```

<Warning>
  Cliccare un'azione di apertura invia l'intero prompt copiabile al terzo fornitore selezionato. Non includere segreti, dati personali o contenuti proprietari, a meno che tu non intenda condividerli secondo la privacy policy di quel fornitore. Copia non apre alcun servizio di terze parti.
</Warning>

## Azioni URL personalizzate

Le azioni personalizzate accettano un `label`, un `url` HTTPS o HTTP e un'icona opzionale. Inserisci `{prompt}` in un segmento di percorso, in un valore di query o in un frammento per controllare dove va il prompt codificato in URL. Se ometti il segnaposto, Jamdesk aggiunge un parametro di query `prompt`.

<Prompt
  title="Ricerca questa migrazione"
  actions={[
    {
      label: "Cerca sul web",
      url: "https://www.google.com/search?q={prompt}",
      icon: "magnifying-glass",
    },
    "claude",
  ]}
>
Confronta questo piano di migrazione con l'attuale contratto pubblico dell'API. Individua le modifiche che rompono la compatibilità, i passaggi di rollback mancanti e i test necessari prima del rilascio.
</Prompt>

```mdx
<Prompt
  title="Research this migration"
  actions={[
    {
      label: "Search the web",
      url: "https://www.google.com/search?q={prompt}",
      icon: "magnifying-glass",
    },
    "claude",
  ]}
>
Compare this migration plan with the current public API contract. Identify
breaking changes, missing rollback steps, and tests needed before release.
</Prompt>
```

Gli URL delle azioni personalizzate devono essere URL `http:` o `https:` senza credenziali. Jamdesk rifiuta altri schemi, segnaposto nell'origine o nelle chiavi di query, e URL finali di azione più lunghi di 8.000 caratteri. Copia resta disponibile anche quando un'azione di apertura viene rifiutata.

## Icona personalizzata

Imposta `icon` su un nome Font Awesome, un URL o percorso di immagine, oppure un SVG inline. Usa `iconType` per scegliere lo stile di un nome Font Awesome senza prefisso.

<Prompt title="Pianifica un tutorial" icon="pen-nib" iconType="duotone">
Delinea un tutorial pratico che porti un nuovo utente dall'installazione a una richiesta API riuscita in meno di dieci minuti.
</Prompt>

```mdx
<Prompt title="Plan a tutorial" icon="pen-nib" iconType="duotone">
  Outline a hands-on tutorial that gets a new user from installation to a
  successful API request in under ten minutes.
</Prompt>
```

Vedi [Icone](/it/content/icons) per i nomi e gli stili disponibili.

## Visualizzazioni compatte

L'anteprima mostra fino a tre righe e scorre per un prompt più lungo. Il controllo Espandi apre il prompt completo. Imposta `singleLine` per ridurre l'anteprima a una sola riga. Le azioni di copia e apertura usano comunque il prompt completo visibile all'utente.

<Prompt title="Riassumi l'API">
Riassumi l'API pubblica in cinque punti:

- Autenticazione e durata dei token.
- Convenzioni di paginazione.
- Limiti di frequenza e indicazioni per i nuovi tentativi.
- Formato degli errori e codici comuni.
- Politica di versionamento e deprecazione.
</Prompt>

Usa `hidePrompt` insieme a un titolo quando l'etichetta da sola basta a dare contesto ai lettori:

<Prompt title="Genera una checklist di migrazione" hidePrompt actions={["claude"]}>
Crea una checklist di migrazione per passare dall'API v1 alla v2. Includi prerequisiti, modifiche al codice, passaggi di validazione, criteri di rollback e approvazione del responsabile.
</Prompt>

```mdx
<Prompt title="Summarize the API">
  Summarize the public API in five bullets:

  - Authentication and token lifetimes.
  - Pagination conventions.
  - Rate limits and retry guidance.
  - Error format and common codes.
  - Versioning and deprecation policy.
</Prompt>

<Prompt title="Generate a migration checklist" hidePrompt actions={["claude"]}>
  Create a migration checklist for moving from API v1 to v2. Include
  prerequisites, code changes, validation steps, and rollback criteria.
</Prompt>
```

`hidePrompt` nasconde l'anteprima solo quando è impostato `title`. Senza titolo, il prompt resta visibile.

## Prop

<ParamField name="children" type="ReactNode">
  Il contenuto del prompt tra i tag di apertura e chiusura. Jamdesk conserva il Markdown esatto visibile all'utente per Copia e per le azioni di apertura. Mostra anche questo contenuto come anteprima, a meno che `description` non sostituisca l'anteprima o `hidePrompt` non la nasconda. Il filtro di visibilità segue le regole sopra.
</ParamField>

<ParamField name="title" type="string">
  Etichetta mostrata nell'intestazione della scheda. Di default non viene mostrato alcun titolo.
</ParamField>

<ParamField name="description" type="string">
  Anteprima compatta con Markdown inline, accettata per compatibilità con Mintlify. Cambia solo l'anteprima visibile. Le azioni di copia e apertura usano comunque il contenuto visibile all'utente tra i tag.
</ParamField>

<ParamField name="icon" type="string | ReactElement" default="sparkles">
  Icona dell'intestazione. Accetta un nome Font Awesome, un URL o percorso di immagine, oppure un elemento SVG inline.
</ParamField>

<ParamField name="iconType" type="regular | solid | light | thin | sharp-solid | duotone | brands">
  Stile Font Awesome applicato a un'icona stringa senza prefisso. Non modifica URL o percorsi di immagini, nomi già prefissati o elementi SVG inline.
</ParamField>

<ParamField name="actions" type="('copy' | 'cursor' | 'claude' | 'chatgpt' | 'perplexity' | 'gemini' | CustomAction)[]" default="[]">
  Azioni di apertura nell'ordine di visualizzazione. `CustomAction` è `{ label: string; url: string; icon?: string }`. Copia è sempre mostrata. Una voce `copy` esplicita è accettata e deduplicata. Le azioni di apertura non valide, duplicate o troppo lunghe vengono omesse.
</ParamField>

<ParamField name="singleLine" type="boolean | string" default="false">
  Riduce l'anteprima visibile a una sola riga quando è impostato al booleano `true` o alla stringa `"true"`. La stringa `"false"` lo disattiva. Tutte le azioni usano comunque il prompt completo.
</ParamField>

<ParamField name="hidePrompt" type="boolean | string" default="false">
  Nasconde l'anteprima visibile quando è presente un titolo e il valore è il booleano `true` o la stringa `"true"`. Senza titolo, l'anteprima resta visibile. La stringa `"false"` lo disattiva.
</ParamField>

<ParamField name="className" type="string">
  Classi CSS aggiuntive applicate all'elemento radice della scheda Prompt.
</ParamField>
