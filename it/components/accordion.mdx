Gli accordion sono sezioni comprimibili. I lettori vedono il titolo e lo espandono per visualizzare i dettagli. Un accordion può avere un'icona e una descrizione. È inoltre possibile raggruppare più accordion.

Usa gli Accordion quando:
- **FAQ**: i lettori scorrono le domande ed espandono le risposte
- **Elenchi di funzionalità**: ogni funzionalità ha una sezione con i dettagli
- **Opzioni di configurazione**: raggruppa le impostazioni per categoria
- **Guide passo-passo** con dettagli espandibili

## Utilizzo

```mdx
<Accordion title="Advanced Configuration">
  Optional details go here.
</Accordion>
```

## Con descrizione

Aggiungi un sottotitolo con la prop `description`:

<Accordion title="API Reference" description="Authentication endpoints">
  Documentation for authentication API endpoints goes here.
</Accordion>

```mdx
<Accordion title="API Reference" description="Authentication endpoints">
  Documentation for authentication API endpoints goes here.
</Accordion>
```

## Aperta per impostazione predefinita

Avvia espanso con `defaultOpen`:

<Accordion title="Already Expanded" defaultOpen>
  This accordion starts in the open state.
</Accordion>

```mdx
<Accordion title="Already Expanded" defaultOpen>
  This accordion starts in the open state.
</Accordion>
```

## Fisarmonica e contenuto espandibile a confronto

| Feature | Accordion | Expandable |
|---------|-----------|------------|
| Icons | Yes | No |
| Descriptions | Yes (subtitle) | No |
| Grouping | AccordionGroup | Standalone |
| Visual weight | Heavier, section-like | Lighter, inline |
| Best for | FAQs, feature lists | Supplementary content |

**Regola pratica:** Usa Accordion quando le sezioni hanno pari importanza e i lettori scelgono tra di esse. Usa Expandable per i dettagli "utili ma non essenziali" che non richiedono particolare evidenza visiva.

## Proprietà

<ParamField name="title" type="string" required>
  Accordion header text.
</ParamField>

<ParamField name="description" type="string">
  Subtitle displayed below the title.
</ParamField>

<ParamField name="icon" type="string">
  Font Awesome icon name (e.g., "gear", "settings").
</ParamField>

<ParamField name="iconType" type="string" default="light">
  Icon style variant: light, regular, or solid.
</ParamField>

<ParamField name="defaultOpen" type="boolean" default="false">
  Start in expanded state.
</ParamField>
