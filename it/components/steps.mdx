Usa Steps per procedure numerate come i flussi di configurazione e risoluzione dei problemi.

## Utilizzo

```mdx
<Steps>
  <Step title="Install">Add the package.</Step>
  <Step title="Configure">Set your options.</Step>
  <Step title="Run">Start the build.</Step>
</Steps>
```

## Passaggi di base

<Steps>
  <Step title="Installa il pacchetto">
    ```bash
    npm install @jamdesk/cli
    ```
  </Step>
  <Step title="Inizializza il progetto">
    ```bash
    jamdesk init
    ```
  </Step>
  <Step title="Avvia il server di sviluppo">
    ```bash
    jamdesk dev
    ```
  </Step>
</Steps>

## Contenuti avanzati nei passaggi

Ogni passaggio può contenere qualsiasi contenuto:

<Steps>
  <Step title="Configura la tua API">
    Crea un file di configurazione:

    ```json config.json
    {
      "apiKey": "your-api-key",
      "endpoint": "https://api.example.com"
    }
    ```

    <Note>
    Mantieni segreta la tua chiave API! Non committarla mai nel controllo di versione.
    </Note>
  </Step>
  <Step title="Effettua la tua prima richiesta">
    Usa l'SDK per effettuare una richiesta:

    ```javascript
    const response = await client.getData();
    console.log(response);
    ```
  </Step>
</Steps>

## Dimensione del titolo

Controlla la gerarchia dei titoli con `titleSize` sul contenitore Steps:

<Steps titleSize="h3">
  <Step title="Primo passaggio">
    Questo titolo viene renderizzato come elemento h3.
  </Step>
  <Step title="Secondo passaggio">
    Utile per la SEO e la struttura del documento.
  </Step>
</Steps>

```mdx
<Steps titleSize="h3">
  <Step title="First Step">
    This title renders as an h3 element.
  </Step>
  <Step title="Second Step">
    Useful for SEO and document structure.
  </Step>
</Steps>
```

## Proprietà

### Steps

<ParamField name="titleSize" type="p | h2 | h3" default="p">
  Elemento di intestazione per i titoli dei passaggi.
</ParamField>

### Step

<ParamField name="title" type="string">
  Titolo facoltativo del passaggio.
</ParamField>

<ParamField name="icon" type="string">
  Nome dell'icona, URL o percorso (sostituisce il numero del passaggio).
</ParamField>

<ParamField name="iconType" type="solid | regular | light | thin | sharp-solid | duotone | brands" default="solid">
  Stile dell'icona Font Awesome.
</ParamField>

<ParamField name="titleSize" type="p | h2 | h3">
  Sovrascrive il titleSize del Steps padre. Eredita dal padre se non impostato.
</ParamField>

<ParamField name="stepNumber" type="number">
  Imposta manualmente il numero del passaggio (assegnato automaticamente se omesso).
</ParamField>
