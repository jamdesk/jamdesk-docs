Aggiungi testo al passaggio del mouse per definire termini, spiegare acronimi o collegare pagine correlate senza appesantire il contenuto principale.

Usa i Tooltip quando:
- **Definisci termini** in linea senza interrompere la lettura
- **Spieghi acronimi** che alcuni lettori potrebbero non conoscere
- **Fornisci contesto** utile ma non essenziale
- **Colleghi contenuti correlati** con un invito all'azione

## Tooltip di base

Passa il mouse su <Tooltip tip="Un insieme di protocolli che permettono alle applicazioni software di comunicare.">API</Tooltip> per vedere la definizione.

```jsx
<Tooltip tip="A set of protocols for software applications to communicate.">
  API
</Tooltip>
```

## Con intestazione

Aggiungi un titolo sopra il testo del suggerimento:

Passa il mouse su <Tooltip headline="API" tip="Application Programming Interface: un insieme di protocolli che permettono alle applicazioni software di comunicare.">API</Tooltip> per vedere la definizione con un titolo.

```jsx
<Tooltip
  headline="API"
  tip="Application Programming Interface: a set of protocols for software applications to communicate."
>
  API
</Tooltip>
```

## Con collegamento di invito all'azione

Aggiungi un link per approfondire:

Scopri di più sulle <Tooltip headline="API" tip="Application Programming Interface: un insieme di protocolli che permettono alle applicazioni software di comunicare." cta="Scopri di più" href="/it/components/overview">API</Tooltip> nella nostra documentazione.

```jsx
<Tooltip
  headline="API"
  tip="Application Programming Interface: a set of protocols..."
  cta="Learn more"
  href="/components/overview"
>
  API
</Tooltip>
```

## Utilizzo in linea

I Tooltip funzionano in linea con il testo. Puoi spiegare termini come <Tooltip tip="HyperText Markup Language">HTML</Tooltip>, <Tooltip tip="Cascading Style Sheets">CSS</Tooltip> o <Tooltip tip="JavaScript">JS</Tooltip> direttamente nel testo.

```jsx
Explain <Tooltip tip="HyperText Markup Language">HTML</Tooltip>,
<Tooltip tip="Cascading Style Sheets">CSS</Tooltip>, or
<Tooltip tip="JavaScript">JS</Tooltip> terms inline.
```

## Tooltip e altri componenti

| Necessità | Componente |
|------|-----------|
| Definire un termine in linea | **Tooltip** |
| Spiegare un concetto in dettaglio | Expandable o sezione separata |
| Avvisare su qualcosa di importante | Callout (Note, Warning) |
| Mostrare codice contestuale | CodeGroup o codice in linea |

**Regola pratica:** i Tooltip servono per definizioni rapide (1-2 frasi). Le spiegazioni più lunghe vanno nel contenuto principale o in un Expandable.

## Proprietà

<ParamField name="tip" type="string" required>
  Il testo del tooltip mostrato al passaggio del mouse.
</ParamField>

<ParamField name="headline" type="string">
  Testo mostrato sopra il tip.
</ParamField>

<ParamField name="cta" type="string">
  Testo del link di invito all'azione.
</ParamField>

<ParamField name="href" type="string">
  URL per l'invito all'azione (obbligatorio con `cta`).
</ParamField>

<ParamField name="children" type="ReactNode">
  Il testo che attiva il tooltip.
</ParamField>

## Accessibilità

- I Tooltip sono accessibili da tastiera (Tab per mettere il focus, compaiono al focus)
- Usa `role="tooltip"` per gli screen reader
- Il testo che attiva il tooltip ha una sottolineatura tratteggiata per indicare l'interattività
