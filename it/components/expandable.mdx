title: Espandibile
description: >-
  Espandibile nasconde dettagli supplementari, lunghe risposte API e passaggi di
  risoluzione dei problemi dietro un'unica sezione cliccabile, un'alternativa più
  leggera ad Accordion
---

Usa Espandibile per nascondere lunghe risposte API, passaggi di risoluzione dei problemi o dettagli extra che interromperebbero la lettura. Viene visualizzato come un'unica sezione cliccabile. È più leggero di Accordion, che serve invece per sezioni raggruppate e navigabili.

Usa Espandibile quando:
- **I dettagli supplementari** interromperebbero la narrazione principale
- **Le informazioni facoltative** sono utili ad alcuni lettori ma non a tutti
- **I contenuti lunghi** (come le risposte API complete) devono essere compressi per impostazione predefinita

## Utilizzo di base

<Expandable title="Mostra più dettagli">
  Questi dettagli sono nascosti per impostazione predefinita e vengono mostrati al clic.
</Expandable>

```mdx
<Expandable title="Show more details">
  These details are hidden by default and revealed when clicked.
</Expandable>
```

## Aperto per impostazione predefinita

Inizia espanso:

<Expandable title="Espanso per impostazione predefinita" defaultOpen>
  Questa sezione è visibile fin dall'inizio.
</Expandable>

```mdx
<Expandable title="Expanded by default" defaultOpen>
  This section starts visible.
</Expandable>
```

## Casi d'uso comuni

### Dettagli della risposta API

Comprimi le risposte lunghe:

<Expandable title="Visualizza la risposta completa">
```json
{
  "id": "123",
  "name": "Example",
  "metadata": {
    "created": "2024-01-01",
    "updated": "2024-01-15"
  }
}
```
</Expandable>

### Procedura di risoluzione dei problemi

<Expandable title="Problemi di connessione?">
  1. Verifica la connessione di rete
  2. Controlla che l'endpoint API sia corretto
  3. Assicurati che la tua chiave API sia valida
</Expandable>

## Proprietà

<ParamField name="title" type="string" required>
  Testo dell'intestazione della sezione.
</ParamField>

<ParamField name="defaultOpen" type="boolean" default="false">
  Avvia espanso.
</ParamField>

## Expandable e Accordion

| Feature | Expandable | Accordion |
|---------|------------|-----------|
| Purpose | Nascondere contenuti supplementari | Organizzare sezioni di pari importanza |
| Icons | No | Sì |
| Descriptions | No | Sì (supporto sottotitolo) |
| Grouping | Autonomo | Raggruppabile con AccordionGroup |
| Best for | Dettagli facoltativi, esempi lunghi | FAQ, elenchi di funzionalità, navigazione |

**Regola pratica:** se il contenuto è "utile ma non essenziale", usa Espandibile. Se i lettori scelgono tra sezioni, usa Accordion.
