Usa Tabs per alternative parallele: gestori di pacchetti, linguaggi di programmazione o istruzioni specifiche per sistema operativo. Il lettore sceglie una volta e rimane nel contesto. I titoli delle schede uguali si sincronizzano sulla pagina. Seleziona "yarn" in un gruppo e tutti gli altri gruppi npm/yarn/pnpm passeranno allo stesso valore.

Usa Tabs quando:
- **Esistono più implementazioni** dello stesso concetto (npm/yarn/pnpm, JavaScript/Python)
- **Le opzioni parallele** si escludono a vicenda (il lettore ne sceglie una)
- **La coerenza è importante**: la scelta del lettore deve restare valida per tutta la pagina

## Utilizzo

```mdx
<Tabs>
  <Tab title="npm">npm install jamdesk</Tab>
  <Tab title="pnpm">pnpm add jamdesk</Tab>
</Tabs>
```

## Tabs, CodeGroup e Accordion a confronto

| Componente | Ideale per | Sincronizza |
|-----------|----------|--------------|
| **Tabs** | Scelte di contenuto che si escludono a vicenda | Sì (su tutta la pagina) |
| **CodeGroup** | Blocchi di codice in più linguaggi | No |
| **Accordion** | Sezioni comprimibili, FAQ | No |

**Regola pratica:** usa Tabs quando la scelta del lettore (come il gestore di pacchetti preferito) deve restare valida per tutta la pagina. Usa CodeGroup per confronti di solo codice. Usa Accordion per contenuti che possono essere tutti rilevanti.

## Schede sincronizzate

Le schede con titoli uguali si sincronizzano sulla pagina. Clicca "yarn" in un gruppo e tutti i gruppi npm/yarn/pnpm della pagina cambieranno di conseguenza:

**Installazione:**

<Tabs>
  <Tab title="npm">
    ```bash
    npm install my-package
    ```
  </Tab>
  <Tab title="yarn">
    ```bash
    yarn add my-package
    ```
  </Tab>
</Tabs>

**Esecuzione:**

<Tabs>
  <Tab title="npm">
    ```bash
    npm run dev
    ```
  </Tab>
  <Tab title="yarn">
    ```bash
    yarn dev
    ```
  </Tab>
</Tabs>

La sincronizzazione avviene quando i titoli delle schede coincidono (senza distinzione tra maiuscole e minuscole).

## Proprietà

### Tabs

<ParamField name="borderBottom" type="boolean" default="false">
  Aggiunge un bordo inferiore e spaziatura al contenitore del contenuto delle schede. Usalo per separare il contenuto a schede dal resto della pagina.
</ParamField>

### Tab

<ParamField name="title" type="string" required>
  L'etichetta mostrata nella barra delle schede. Le schede con titoli uguali sincronizzano la selezione su tutta la pagina.
</ParamField>

<ParamField name="icon" type="string">
  Nome dell'icona Font Awesome da mostrare prima del titolo (ad es. "react", "code", "terminal").
</ParamField>

<ParamField name="iconType" type="string" default="solid">
  Stile dell'icona Font Awesome. Opzioni: `regular`, `solid`, `light`, `thin`, `sharp-solid`, `duotone`, `brands`.
</ParamField>
