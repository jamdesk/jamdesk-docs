Frame racchiude immagini e demo in un contenitore con bordo e didascalie opzionali.

Usa Frame quando vuoi:
- Dare un aspetto finito a screenshot e immagini dell'interfaccia
- Aggiungere didascalie per spiegare cosa stanno vedendo i lettori
- Distinguere l'output delle demo dal contenuto normale
- Mantenere coerenti gli elementi visivi in tutta la documentazione

> Gli screenshot mostrano l'interfaccia in inglese.

## Utilizzo

```mdx
<Frame caption="Architecture diagram">
  ![Diagram](/images/city-skyline.jpg)
</Frame>
```

</Frame>

## Riquadrare altri contenuti

Frame accetta qualsiasi contenuto, non solo immagini:

<Frame caption="Example code output">
```
✓ Build completed successfully
✓ 42 pages generated
✓ Deployed to production
```
</Frame>

## Quando NON usare Frame

- **Immagini decorative inline**: le normali immagini Markdown vanno bene per le illustrazioni
- **Icone o grafiche piccole**: Frame aggiunge peso visivo non necessario
- **Immagini che scorrono insieme al testo**: Frame crea una pausa visiva. Usalo per elementi visivi autonomi

## Buone pratiche

- **Mantieni le didascalie concise**: una frase che spiega cosa sta vedendo il lettore
- **Usalo in modo coerente**: se incornici uno screenshot, incornicia tutti gli screenshot
- **Non abusarne**: riserva i frame alle immagini importanti, non a ogni immagine della pagina
