Usa i Callout per evidenziare contesto importante come avvisi, suggerimenti o requisiti senza interrompere il flusso di lettura.

## Riquadri disponibili

<Note>
**Note**: Contesto utile o informazioni aggiuntive.
</Note>

<Info>
**Info**: Informazioni neutre o dati di fatto. Usalo per dettagli supplementari.
</Info>

<Tip>
**Tip**: Approcci consigliati o ottimizzazioni.
</Tip>

<Warning>
**Warning**: Avvertenze importanti o requisiti. Usalo quando ignorare qualcosa potrebbe causare problemi.
</Warning>

<Danger>
**Danger**: Avvisi critici. Usalo per azioni che potrebbero causare perdita di dati o problemi di sicurezza.
</Danger>

<Check>
**Check**: Conferme di successo. Usalo per confermare un comportamento corretto o un completamento riuscito.
</Check>

## Utilizzo

```mdx
<Note>
This is helpful context for the reader.
</Note>

<Warning>
This could cause issues if you skip this step.
</Warning>

<Danger>
This action cannot be undone. Proceed with caution.
</Danger>
```

## Con titoli

Aggiungi un titolo personalizzato a qualsiasi callout:

```mdx
<Note title="Did you know?">
You can use **Markdown** inside callouts, including `code` and [links](/introduction).
</Note>
```

<Note title="Did you know?">
Puoi usare **Markdown** all'interno dei callout, inclusi `code` e [link](/it/components/card).
</Note>

## Con blocchi di codice

I callout possono contenere codice:

<Warning title="Breaking Change in v2.0">
La firma della funzione `getData()` è cambiata:

```javascript
// Before (v1.x)
getData(id)

// After (v2.0)
getData({ id, options })
```
</Warning>

## Proprietà

Ogni callout accetta questi props:

<ParamField name="title" type="string">
  Titolo personalizzato (sostituisce quello predefinito).
</ParamField>

## Accessibilità

I callout usano HTML semantico e ruoli ARIA:
- Gli screen reader annunciano il tipo di callout
- Il colore non è l'unico indicatore (sono incluse le icone)
- Contrasto cromatico sufficiente in modalità scura

## Callout personalizzato

Imposta un'icona e un colore personalizzati con il componente `Callout`:

<Callout icon="key" color="#FFC107">
**Custom**: Usa qualsiasi icona e colore per adattarli al tuo contenuto.
</Callout>

<Callout icon="rocket" color="#9333EA">
Distribuisci le tue modifiche con sicurezza tramite la nostra pipeline CI/CD.
</Callout>

<Callout icon="regular/star" color="#EC4899">
Usa i prefissi di stile dell'icona come `regular/`, `light/` o `duotone/` per pesi diversi.
</Callout>

### Utilizzo di Callout personalizzati

```mdx
<Callout icon="key" color="#FFC107">
  This callout uses a key icon with amber color.
</Callout>

<Callout icon="rocket" color="#9333EA">
  This callout uses a rocket icon with purple color.
</Callout>

<Callout icon="regular/star" color="#EC4899">
  Use style prefixes for different icon weights.
</Callout>
```

### Proprietà di Callout personalizzati

<ParamField name="icon" type="string" default="circle-info">
  Nome dell'icona (vedi [Icone](/it/content/icons)).
</ParamField>

<ParamField name="color" type="string">
  Codice colore esadecimale (ad esempio `#FFC107`). Predefinito: colore di accento.
</ParamField>

**Prefissi di stile dell'icona:** aggiungi un prefisso per cambiare il peso dell'icona:
- `solid/` - Icone piene (predefinito)
- `regular/` - Icone con contorno
- `light/` - Icone con contorno sottile
- `duotone/` - Icone a due toni
