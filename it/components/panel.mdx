Pannello mostra contenuti personalizzati nella barra laterale destra al posto dell'indice. I contenuti restano visibili mentre i lettori scorrono la pagina. Usalo per riferimenti rapidi, avvisi importanti o link di supporto.

Usa Pannello quando:
- Le **informazioni critiche** non devono uscire dalla vista durante lo scorrimento
- Il **materiale di riferimento rapido** integra il contenuto principale
- Le **azioni persistenti** devono restare visibili (link di supporto, chiavi API)

## Utilizzo di base

Racchiudi il contenuto in un Pannello per mostrarlo nella barra laterale destra:

```mdx
<Panel>
  <Info>This content appears in the sidebar!</Info>
</Panel>
```

## Casi d'uso comuni

Un Pannello può contenere avvisi fissati, schede di riferimento rapido e link di supporto:

```mdx
<Panel>
  <Warning>
    API rate limits: 100 requests/minute
  </Warning>
  <Card title="Quick Reference" icon="list">
    **Methods:** GET, POST, PUT, DELETE
    **Auth:** Bearer token required
  </Card>
  <Card title="Need Help?" icon="circle-question" href="https://example.com/support">
    Contact our support team
  </Card>
</Panel>
```

## Quando NON usare Panel

- **Pagine brevi**: l'indice aiuta i lettori a orientarsi. Sostituiscilo solo con qualcosa di più utile
- **Documentazione standard**: la maggior parte delle pagine funziona meglio con l'indice predefinito
- **Dispositivi mobili**: il contenuto del Pannello è nascosto sugli schermi più piccoli. Inserisci le informazioni critiche anche nel contenuto principale

## Comportamento

- Appare nella barra laterale destra su desktop (1280px+), nascosto sugli schermi più piccoli
- Un Pannello per pagina. Sostituisce l'indice
- Può contenere qualsiasi componente: Callout, Card, CodeGroup, Accordion, ecc.
