title: Sfondo
description: "Scegli una decorazione (gradiente, griglia di punti, macchie effetto vetro o uniforme), imposta il colore dello sfondo per modalità e regola il gradiente Jam."
---

Il blocco `background` in `docs.json` controlla lo sfondo della pagina. Puoi scegliere uno dei quattro tipi di decorazione, sostituire il colore di base per modalità e regolare il gradiente predefinito.

```json docs.json
{
  "theme": "jam",
  "background": {
    "decoration": "none",
    "color": {
      "light": "#faf7f2",
      "dark": "#0a0a0d"
    }
  }
}
```

Tutti i campi sono facoltativi. Ometti l'intero blocco `background` per usare i valori predefiniti del tema.

## decorazione

Scegli il tipo di sfondo per la modalità chiara del tema Jam. Ogni valore applica un motivo distinto sopra il colore di base `--color-bg-primary`; la modalità scura usa sempre uno sfondo uniforme, indipendentemente dal valore.

```json docs.json
{
  "background": {
    "decoration": "grid"
  }
}
```

| Valore | Comportamento |
|-------|----------|
| `gradient` (predefinito) | Gradiente radiale ancorato in alto. Regolabile tramite il blocco `gradient` seguente |
| `grid` | Motivo a griglia di punti discreto: punti da 1,5 px in `--color-primary` con opacità dell'8% e spaziatura di 24 px |
| `windows` | Due macchie radiali sfumate negli angoli superiori, per un effetto effetto vetro in stile Windows 11 |
| `none` | Riempimento uniforme `--color-bg-primary`, senza decorazioni |

<Note>
`decoration` influisce solo sulla modalità chiara del tema Jam. Nebula e Pulsar usano sfondi uniformi in ogni caso. Nella modalità scura di Jam, tutti i valori producono uno sfondo uniforme.
</Note>

## colore

Sostituisci il colore dello sfondo della pagina per modalità. Accetta qualsiasi colore CSS: esadecimale, `rgb(...)`, `rgba(...)` o `hsl(...)`.

```json docs.json
{
  "background": {
    "color": {
      "light": "#faf7f2",
      "dark": "#0a0a0d"
    }
  }
}
```

| Campo | Si applica a |
|------------|------------|
| `color.light` | Sfondo del corpo in modalità chiara |
| `color.dark` | Sfondo del corpo in modalità scura |

Entrambi i campi sono facoltativi. Imposta solo `light` per sostituire il colore della modalità chiara e mantenere il valore scuro predefinito del tema, o viceversa. Funziona con tutti i temi (Jam, Nebula, Pulsar).

<Tip>
Abbina `decoration: "none"` a una sostituzione `color` per ottenere uno sfondo uniforme e personalizzato. È una configurazione comune nella documentazione editoriale o in stile marketing.
</Tip>

## gradiente

Regola il gradiente radiale in modalità chiara del tema Jam. Tutti e quattro i campi sono facoltativi e vengono applicati indipendentemente. Imposta solo `color` per cambiare il colore, oppure solo `size` per ridurlo o ampliarlo.

```json docs.json
{
  "background": {
    "gradient": {
      "color": "#a855f7",
      "size": "800px",
      "position": "top center",
      "opacity": 0.25
    }
  }
}
```

| Campo | Predefinito | Descrizione |
|-------|---------|-------------|
| `color` | Eredita `colors.primary` | Colore del gradiente (qualsiasi colore CSS) |
| `size` | `500px` | Raggio. Qualsiasi lunghezza CSS (`px`, `rem`, `%`, `vh`) |
| `position` | `top center` | Punto centrale. Parole chiave `top`/`bottom`/`center`/`left`/`right`, percentuali o coordinate in pixel |
| `opacity` | `0.12` | Opacità massima al centro. Numero compreso tra `0` e `1` |

<Note>
`gradient` si applica solo quando `decoration` è `gradient` o non è impostato. Le decorazioni `grid`, `windows` e `none` ignorano questo blocco: `grid` e `windows` usano `--color-primary` per il colore del motivo, quindi personalizzalo tramite il blocco `colors`.
</Note>

### Compatibilità browser

Il gradiente parametrico (che utilizza variabili CSS) usa `color-mix()`, che richiede:

- Chrome / Edge 111+
- Firefox 113+
- Safari 16.2+

I browser meno recenti usano come fallback il gradiente Jam originale: mostrano il valore predefinito del brand e ignorano le sostituzioni di `gradient`. Il fallback ha comunque un aspetto pulito, ma non può essere personalizzato.

## Ricette comuni

<AccordionGroup>
  <Accordion title="Sfondo crema uniforme, senza gradiente">
    ```json docs.json
    {
      "background": {
        "decoration": "none",
        "color": {
          "light": "#faf7f2",
          "dark": "#0a0a0d"
        }
      }
    }
    ```
    Comune nella documentazione in stile editoriale. Funziona con qualsiasi tema.
  </Accordion>

  <Accordion title="Gradiente viola discreto">
    ```json docs.json
    {
      "background": {
        "gradient": {
          "color": "#a855f7",
          "opacity": 0.15
        }
      }
    }
    ```
    Cambia il colore del gradiente Jam senza modificarne dimensioni o posizione.
  </Accordion>

  <Accordion title="Gradiente più grande, decentrato">
    ```json docs.json
    {
      "background": {
        "gradient": {
          "size": "1200px",
          "position": "top left",
          "opacity": 0.2
        }
      }
    }
    ```
    Gradiente più ampio e diffuso, ancorato all'angolo superiore sinistro.
  </Accordion>

  <Accordion title="Griglia di punti discreta">
    ```json docs.json
    {
      "background": {
        "decoration": "grid"
      }
    }
    ```
    Disegna una griglia di punti tenue da 24 px nel colore primario del tema. Legge `--color-primary`, quindi puoi cambiare il colore dei punti impostando `colors.primary` in `docs.json`.
  </Accordion>

  <Accordion title="Effetto vetro in stile Windows 11">
    ```json docs.json
    {
      "background": {
        "decoration": "windows"
      }
    }
    ```
    Due macchie radiali sfumate negli angoli superiori, ancorate al viewport. Legge `--color-primary` per il colore delle macchie.
  </Accordion>

  <Accordion title="Solo sostituzione modalità scura">
    ```json docs.json
    {
      "background": {
        "color": {
          "dark": "#0d0d12"
        }
      }
    }
    ```
    Mantiene i valori predefiniti del tema in modalità chiara e imposta uno sfondo personalizzato in modalità scura.
  </Accordion>
</AccordionGroup>
