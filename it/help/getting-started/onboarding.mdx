## I 5 passaggi

<Steps>
  <Step title="Avvia la prova">
    Jamdesk avvia la tua **prova gratuita di 14 giorni** del piano Pro al primo accesso.

    - Tutte le funzionalità sono attive
    - La prova termina 14 giorni dopo l'attivazione
  </Step>

  <Step title="Crea il progetto">
    Assegna un nome al tuo progetto di documentazione:

    - Usa un nome chiaro e descrittivo (ad esempio "Documentazione API", "Guida utente")
    - Il nome diventa parte dell'URL del tuo sito di documentazione
    - Puoi modificare il nome visualizzato in seguito nelle impostazioni del progetto
  </Step>

  <Step title="Collega GitHub e crea la documentazione iniziale">
    Jamdesk crea un nuovo repository GitHub a partire dal [Starter Template](https://github.com/jamdesk/starter-docs):

    - Pagine di esempio con contenuti e componenti realistici
    - `docs.json` preconfigurato con navigazione e branding
    - Esempio di specifica OpenAPI per la documentazione di riferimento delle API
    - Pronto per essere modificato e pubblicato
  </Step>

  <Step title="Installa la CLI">
    Installa la CLI di Jamdesk per lo sviluppo locale:

    ```bash
    npm install -g jamdesk
    ```

    <Note>
    Questo passaggio è facoltativo. Puoi installare la CLI in qualsiasi momento oppure modificare la documentazione direttamente su GitHub.
    </Note>
  </Step>

  <Step title="Inizia a modificare">
    Modifica la tua documentazione:

    - **Tramite CLI**: modifica i file in locale con `jamdesk dev`
    - **Tramite GitHub**: modifica direttamente i file `.mdx` nel tuo repository
    - **Su Jamdesk**: alcune funzionalità della dashboard sono disponibili (in base al piano)

    Ogni push su GitHub avvia una nuova build.
  </Step>
</Steps>

## Risoluzione dei problemi

### Ho saltato un passaggio: posso tornare indietro?
Sì. Puoi completare l'onboarding in qualsiasi momento dalla scheda di onboarding nella dashboard del progetto.

### Ho scelto il repository GitHub sbagliato
Crea un nuovo progetto con il repository corretto. Puoi eliminare quello vecchio in qualsiasi momento.

### Ho bisogno di aiuto durante l'onboarding
Contatta il [supporto](/it/help/support/contact).
