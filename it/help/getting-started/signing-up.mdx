Crea il tuo account Jamdesk utilizzando l'email, OAuth di Google o OAuth di GitHub.

## Opzioni di registrazione

### Email e password

1. Visita [dashboard.jamdesk.com](https://dashboard.jamdesk.com)
2. Fai clic su **Sign Up**
3. Inserisci il tuo indirizzo email
4. Crea una password sicura
5. Controlla la tua email per un link di verifica
6. Fai clic sul link di verifica per confermare il tuo account

### Google OAuth

1. Visita [dashboard.jamdesk.com](https://dashboard.jamdesk.com)
2. Fai clic su **Sign Up**
3. Seleziona **Continue with Google**
4. Autorizza Jamdesk ad accedere al tuo account Google
5. Jamdesk verifica il tuo account e ti accede

### GitHub OAuth

1. Visita [dashboard.jamdesk.com](https://dashboard.jamdesk.com)
2. Fai clic su **Sign Up**
3. Seleziona **Continue with GitHub**
4. Autorizza Jamdesk ad accedere al tuo account GitHub
5. Jamdesk verifica il tuo account e ti accede

<Note>
L'accesso con GitHub collega la tua identità a Jamdesk. Il collegamento di un repository GitHub al tuo progetto di documentazione è un passaggio separato durante la configurazione del progetto.
</Note>

## Cosa succede dopo la registrazione

Il tuo nuovo account:
- Avvia una prova gratuita di 14 giorni del piano Pro
- Ti porta a creare il tuo primo progetto di documentazione
- Include la guida completa all'onboarding

## Verifica dell'email

Se non ricevi l'email di verifica:
1. Controlla la cartella dello spam
2. Attendi qualche minuto e riprova la registrazione
3. [Contatta il supporto](/it/help/support/contact) se il problema persiste
