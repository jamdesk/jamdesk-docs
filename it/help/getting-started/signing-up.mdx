Crea il tuo account Jamdesk usando email, Google OAuth o GitHub OAuth.

## Opzioni di registrazione

Jamdesk supporta tre metodi di autenticazione:

### Email e password

1. Visita [dashboard.jamdesk.com](https://dashboard.jamdesk.com)
2. Fai clic su **Sign Up**
3. Inserisci il tuo indirizzo email
4. Crea una password sicura
5. Controlla la tua email per trovare il link di verifica
6. Fai clic sul link di verifica per confermare il tuo account

### Google OAuth

1. Visita [dashboard.jamdesk.com](https://dashboard.jamdesk.com)
2. Fai clic su **Sign Up**
3. Seleziona **Continue with Google**
4. Autorizza Jamdesk ad accedere al tuo account Google
5. Il tuo account verrà verificato automaticamente e accederai al dashboard

### GitHub OAuth

1. Visita [dashboard.jamdesk.com](https://dashboard.jamdesk.com)
2. Fai clic su **Sign Up**
3. Seleziona **Continue with GitHub**
4. Autorizza Jamdesk ad accedere al tuo account GitHub
5. Il tuo account verrà verificato automaticamente e accederai al dashboard

<Note>
Il tuo accesso GitHub collega la tua identità a Jamdesk. Questa operazione è separata dal collegamento di un repository GitHub al tuo progetto di documentazione. Lo farai durante la configurazione del progetto.
</Note>

## Cosa succede dopo la registrazione

Dopo aver creato l'account:
- Inizierai una prova gratuita di 14 giorni del piano Pro
- Verrai indirizzato alla creazione del tuo primo progetto di documentazione
- Avrai accesso alla procedura guidata completa di onboarding

## Verifica dell'email

Se non ricevi l'email di verifica:
1. Controlla la cartella dello spam
2. Attendi alcuni minuti e prova a registrarti di nuovo
3. [Contatta l'assistenza](/it/help/support/contact) se il problema persiste
