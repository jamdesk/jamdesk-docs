Collegare il tuo account GitHub associa la tua identità alle build e consente di accedere ai repository privati.

## Perché collegare GitHub?

Collegare il tuo account GitHub ti consente di:

- Collegare repository privati a Jamdesk
- Abilitare le build automatiche al push
- Accedere ai repository delle organizzazioni a cui appartieni

## Collegamento dell'account

<Steps>
  <Step title="Vai a Settings">
    Fai clic sul tuo avatar e seleziona **Settings**.
  </Step>
  <Step title="Seleziona Connections">
    Vai alla scheda **Connections**.
  </Step>
  <Step title="Fai clic su Connect GitHub">
    Seleziona **Connect GitHub Account**.
  </Step>
  <Step title="Autorizza Jamdesk">
    Esamina le autorizzazioni e fai clic su **Authorize** in GitHub.
  </Step>
</Steps>

## Autorizzazioni richieste

Jamdesk richiede autorizzazioni minime:

| Autorizzazione | Scopo |
|------------|---------|
| Read repository contents | Accedere ai file della documentazione |
| Read repository metadata | Elencare i tuoi repository |
| Webhooks | Ricevere notifiche push per le build automatiche |

<Note>
Jamdesk non scrive mai nei tuoi repository. L'accesso è di sola lettura.
</Note>

## Scollegamento dell'account

Per scollegare GitHub:

1. Vai a **Settings** → **Connections**
2. Fai clic su **Disconnect** accanto a GitHub
3. Conferma lo scollegamento

<Warning>
Scollegare GitHub disabiliterà le build automatiche per tutti i tuoi progetti. Dovrai ricollegarlo per riabilitarle.
</Warning>

## Repository delle organizzazioni

Per accedere ai repository di un'organizzazione GitHub:

1. Vai alle impostazioni dell'organizzazione su GitHub
2. Vai a **Third-party access** → **OAuth Apps**
3. Trova Jamdesk e fai clic su **Grant** per concedere l'accesso

Se non visualizzi questa opzione, chiedi a un amministratore dell'organizzazione di approvare Jamdesk.
