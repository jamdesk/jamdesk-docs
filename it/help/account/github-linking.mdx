Collega il tuo account GitHub per attribuire le build a te e accedere ai repository privati.

## Perché collegare GitHub?

- Collega repository privati a Jamdesk
- Attiva le build automatiche a ogni push
- Accedi ai repository delle organizzazioni a cui appartieni

## Collegamento dell'account

<Steps>
  <Step title="Vai alle impostazioni">
    Fai clic sul tuo avatar e seleziona **Settings**.
  </Step>
  <Step title="Seleziona Connections">
    Apri la scheda **Connections**.
  </Step>
  <Step title="Fai clic su Connect GitHub">
    Seleziona **Connect GitHub Account**.
  </Step>
  <Step title="Autorizza Jamdesk">
    Controlla i permessi e fai clic su **Authorize** in GitHub.
  </Step>
</Steps>

## Autorizzazioni richieste

Jamdesk richiede questi permessi:

| Permesso | Scopo |
|------------|---------|
| Lettura dei contenuti del repository | Accedere ai tuoi file di documentazione |
| Lettura dei metadati del repository | Elencare i tuoi repository |
| Webhook | Ricevere notifiche push per le build automatiche |

<Note>
Jamdesk non scrive mai nei tuoi repository. L'accesso è di sola lettura.
</Note>

## Scollegamento dell'account

1. Vai su **Settings** → **Connections**
2. Fai clic su **Disconnect** accanto a GitHub
3. Conferma la disconnessione

<Warning>
Disconnettere GitHub disattiva le build automatiche per tutti i tuoi progetti. Ricollegalo per riattivarle.
</Warning>

## Repository delle organizzazioni

1. Vai alle impostazioni dell'organizzazione su GitHub
2. Apri **Third-party access** → **OAuth Apps**
3. Trova Jamdesk e fai clic su **Grant**

Non vedi l'opzione **Grant**? Chiedi a un amministratore dell'organizzazione di approvare Jamdesk.
