Crea un progetto nella dashboard per configurare un nuovo sito di documentazione. Parti da un template oppure collega un repository GitHub esistente. Jamdesk installa il webhook ed esegue la prima build.

## Crea un nuovo progetto

<Steps>
  <Step title="Apri la dashboard">
    Vai su [dashboard.jamdesk.com](https://dashboard.jamdesk.com) e accedi.
  </Step>
  <Step title="Fai clic su New Project">
    Seleziona **New Project** dalla dashboard.
  </Step>
  <Step title="Scegli la fonte">
    Scegli come iniziare la tua documentazione:

    <Tabs>
      <Tab title="Usa un template">
        Parti dal [Starter Template](https://github.com/jamdesk/starter-docs). Jamdesk crea per te un repository GitHub con contenuti di esempio, componenti e una specifica OpenAPI.
      </Tab>
      <Tab title="Collega un repository">
        Collega un repository GitHub esistente che contiene la tua documentazione.
      </Tab>
    </Tabs>
  </Step>
  <Step title="Configura le impostazioni">
    - **Project name**: visualizzato nella dashboard
    - **Subdomain**: l'URL della tua documentazione (ad esempio `my-docs.jamdesk.app`)
    - **Branch**: il branch Git da distribuire (di solito `main`)
  </Step>
  <Step title="Crea">
    Fai clic su **Create Project** per completare la configurazione.
  </Step>
</Steps>

## Limiti dei progetti

Il tuo piano determina quanti progetti puoi creare:

| Piano | Progetti |
|------|----------|
| Trial | 1 |
| Pro | 1 (espandibile) |

Puoi aggiungere slot di progetto Pro extra nella pagina **Subscription**.

## Cosa viene creato

Jamdesk quindi:

1. Si connette al tuo repository GitHub
2. Installa un webhook per le build automatiche
3. Avvia la tua prima build
4. Assegna un sottodominio `*.jamdesk.app`
