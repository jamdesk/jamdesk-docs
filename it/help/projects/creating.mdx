---
title: Creare progetti nel dashboard
description: Un progetto in Jamdesk rappresenta un singolo sito di documentazione. Ogni progetto si collega a un repository GitHub e viene distribuito al proprio URL.
---

Configura un nuovo sito di documentazione creando un progetto nel dashboard. Puoi partire da un template o collegare un repository GitHub esistente; Jamdesk gestisce automaticamente l'installazione del webhook e il primo build.

## Crea un nuovo progetto

<Steps>
  <Step title="Apri il dashboard">
    Vai a [dashboard.jamdesk.com](https://dashboard.jamdesk.com) ed effettua l'accesso.
  </Step>
  <Step title="Fai clic su New Project">
    Seleziona **New Project** dal dashboard.
  </Step>
  <Step title="Scegli la sorgente">
    Scegli come iniziare la documentazione:

    <Tabs>
      <Tab title="Use a Template">
        Inizia con lo [Starter Template](https://github.com/jamdesk/starter-docs). Jamdesk crea per te un repository GitHub con contenuti di esempio, componenti e una specifica OpenAPI.
      </Tab>
      <Tab title="Connect Repository">
        Collega un repository GitHub esistente che contiene la tua documentazione.
      </Tab>
    </Tabs>
  </Step>
  <Step title="Configura le impostazioni">
    - **Project name** — Visualizzato nel dashboard
    - **Subdomain** — L'URL della documentazione, ad esempio `my-docs.jamdesk.app`
    - **Branch** — Il branch Git da distribuire, generalmente `main`
  </Step>
  <Step title="Create">
    Fai clic su **Create Project** per completare la configurazione.
  </Step>
</Steps>

## Limiti dei progetti

Il tuo piano determina quanti progetti puoi creare:

| Piano | Progetti |
|------|----------|
| Trial | 1 |
| Pro | 1 (espandibile) |

Hai bisogno di altri progetti con Pro? Aggiungi slot per progetti nella pagina **Subscription**.

## Cosa viene creato

Quando crei un progetto, Jamdesk:

1. Si collega al tuo repository GitHub
2. Installa un webhook per i build automatici
3. Avvia il primo build
4. Assegna un sottodominio `*.jamdesk.app`
