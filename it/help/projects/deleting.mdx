L'eliminazione di un progetto lo rimuove definitivamente dal dashboard: la cronologia delle build, i dati analitici e la configurazione del dominio vengono eliminati. Il repository GitHub non viene modificato.

## Eliminare un progetto di tua proprietà

<Warning>
L'eliminazione di un progetto rimuove definitivamente tutti i dati, inclusi la cronologia delle build, i dati analitici e la configurazione del dominio personalizzato. Questa operazione non può essere annullata.
</Warning>

<Steps>
  <Step title="Apri le impostazioni del progetto">
    Vai al progetto e fai clic su **Settings**.
  </Step>
  <Step title="Scorri fino a Danger Zone">
    Individua la sezione **Danger Zone** in fondo alla pagina.
  </Step>
  <Step title="Fai clic su Delete Project">
    Seleziona **Delete Project**.
  </Step>
  <Step title="Conferma l'eliminazione">
    Digita il nome del progetto per confermare, quindi fai clic su **Permanently Delete**.
  </Step>
</Steps>

## Cosa viene eliminato

- Tutta la cronologia delle build e i log
- I dati analitici
- La configurazione del dominio personalizzato
- Le associazioni dei membri del team
- Le integrazioni Webhook

## Cosa NON viene eliminato

- Il repository GitHub (rimane invariato)
- Il tuo account Jamdesk
- Gli altri progetti di tua proprietà

## Lasciare un progetto

Se sei membro, ma non proprietario, di un progetto:

1. Vai a **Settings** → **Members**
2. Individua il tuo nome nell'elenco dei membri
3. Fai clic su **Leave Project**
4. Conferma la tua uscita

Potrai essere invitato di nuovo in seguito, se necessario.

## Prima dell'eliminazione

Valuta queste alternative:

- **Transfer ownership** se i membri del team devono mantenere l'accesso
- **Export analytics** se ti servono i dati analitici storici
- **Annota la configurazione** se potresti dover ricreare il progetto

## Recuperare i progetti eliminati

I progetti eliminati non possono essere recuperati. Se hai eliminato accidentalmente un progetto:

1. Crea un nuovo progetto
2. Collega lo stesso repository GitHub
3. Riconfigura manualmente le impostazioni

Il contenuto della documentazione rimane nel tuo repository GitHub.
