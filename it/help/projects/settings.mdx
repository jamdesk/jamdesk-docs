Configura il nome visualizzato del progetto, il repository collegato, il branch, le variabili d'ambiente, il dominio personalizzato e le opzioni della zona di pericolo dalla pagina **Settings**.

Gli screenshot mostrano l'interfaccia in inglese.

## Accesso alle impostazioni

1. Seleziona il progetto dal dashboard
2. Fai clic su **Settings** nella barra laterale

La pagina delle impostazioni è suddivisa in sezioni per visualizzazione, repository, team, configurazione e notifiche.

## Impostazioni generali

### Nome del progetto

Il nome visualizzato nel dashboard. Non influisce sulla documentazione pubblicata.

### Sottodominio

Il tuo URL predefinito su `*.jamdesk.app`. Per modificarlo:

1. Inserisci un nuovo sottodominio
2. Fai clic su **Save**
3. Attendi la propagazione DNS (di solito istantanea)

<Note>
Le modifiche al sottodominio non interrompono i link esistenti. Il vecchio URL reindirizza al nuovo.
</Note>

## Impostazioni del repository

### Repository collegato

Mostra il repository GitHub collegato. Per cambiare repository, devi eliminare il progetto e crearne uno nuovo.

### Branch

Il branch Git che attiva le build. In genere `main` o `master`.

### Percorso della documentazione

Per le configurazioni monorepo, specifica il percorso del file `docs.json` (ad es. `packages/docs`).

Lascia vuoto se `docs.json` si trova nella radice del repository.

## Impostazioni di build

### Variabili d'ambiente

Imposta le variabili disponibili durante la build della documentazione:

1. Fai clic su **Add Variable**
2. Inserisci la chiave e il valore
3. Fai clic su **Save**

Le variabili sono disponibili durante la build e possono essere utilizzate nella documentazione.

### Ricostruzione

Fai clic su **Rebuild** per avviare una nuova build senza eseguire il push su GitHub. Utile dopo aver modificato le impostazioni.

## Dominio personalizzato

Aggiungi il tuo dominio nella sezione **Domains**. Consulta [Domini personalizzati](/it/deploy/custom-domains) per le istruzioni di configurazione.

## Zona di pericolo

### Eliminazione del progetto

Elimina definitivamente il progetto e tutti i dati associati:

- Cronologia delle build
- Dati di analisi
- Configurazione del dominio personalizzato

<Warning>
Questa azione non può essere annullata. Valuta la possibilità di trasferire la proprietà se i membri del team devono continuare ad accedere al progetto.
</Warning>
