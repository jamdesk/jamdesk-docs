Configura il nome visualizzato del progetto, il repository collegato, il branch, le variabili d'ambiente, il dominio personalizzato e le opzioni della zona pericolosa dalla pagina Impostazioni.

*Gli screenshot mostrano l'interfaccia in inglese.*

## Accesso alle impostazioni

1. Seleziona il progetto dalla dashboard
2. Fai clic su **Settings** nella barra laterale

La pagina delle impostazioni è suddivisa in sezioni per visualizzazione, repository, team, configurazione e notifiche.

## Impostazioni generali

### Nome del progetto

Il nome visualizzato nella dashboard. Non influisce sulla documentazione pubblicata.

### Sottodominio

Il tuo URL predefinito su `*.jamdesk.app`. Per modificarlo:

1. Inserisci un nuovo sottodominio
2. Fai clic su **Save**
3. Attendi la propagazione DNS (di solito immediata)

<Note>
Le modifiche al sottodominio non interrompono i link esistenti. L'URL precedente reindirizza a quello nuovo.
</Note>

## Impostazioni del repository

### Repository collegato

Il repository GitHub collegato. Per cambiare repository è necessario eliminare il progetto e crearne uno nuovo.

### Branch

Il branch Git che attiva le build. Di solito `main` o `master`.

### Percorso della documentazione

Percorso del file `docs.json` in un monorepo (ad esempio `packages/docs`).

Lascia vuoto se `docs.json` si trova nella radice del repository.

## Impostazioni di build

### Variabili d'ambiente

Imposta le variabili di build per la tua documentazione:

1. Fai clic su **Add Variable**
2. Inserisci la chiave e il valore
3. Fai clic su **Save**

Le variabili sono disponibili durante la build. Richiamale nella documentazione.

### Ricostruzione

Fai clic su **Rebuild** per avviare una nuova build senza eseguire push su GitHub. Usalo dopo aver modificato le impostazioni.

## Dominio personalizzato

Aggiungi il tuo dominio nella sezione **Domains**. Consulta [Domini personalizzati](/it/deploy/custom-domains) per le istruzioni di configurazione.

## Zona di pericolo

### Eliminazione del progetto

Elimina definitivamente il progetto e tutti i dati associati:

- Cronologia delle build
- Dati di analisi
- Configurazione del dominio personalizzato

<Warning>
Questa azione non può essere annullata. Valuta il trasferimento della proprietà se i membri del team necessitano ancora di accesso.
</Warning>
