description: Risolvi i problemi di accesso alla dashboard di Jamdesk: password dimenticata, email non riconosciuta, errori OAuth, sessioni in cache e account bloccati.
---

Trova la sezione corrispondente al problema di accesso alla dashboard.

## Password dimenticata

<Steps>
  <Step title="Vai alla pagina di accesso">
    Visita [dashboard.jamdesk.com](https://dashboard.jamdesk.com).
  </Step>
  <Step title="Clicca su Password dimenticata">
    Seleziona il link **Forgot password?**.
  </Step>
  <Step title="Inserisci la tua email">
    Inserisci l'indirizzo email associato al tuo account.
  </Step>
  <Step title="Controlla la posta in arrivo">
    Clicca sul link di reimpostazione nell'email che ti inviamo.
  </Step>
</Steps>

<Note>
I link di reimpostazione scadono dopo 1 ora. Richiedine uno nuovo se il tuo è scaduto.
</Note>

## Email non riconosciuta

Se visualizzi "No account found":

- Controlla che l'indirizzo email non contenga errori di battitura
- Prova altri indirizzi email che potresti aver utilizzato
- Potresti esserti registrato con Google o GitHub

## Problemi di accesso OAuth

### Accesso con Google non funzionante

1. Cancella i cookie del browser
2. Prova con un altro browser
3. Disattiva temporaneamente le estensioni del browser
4. Verifica che i cookie di terze parti siano consentiti

### Accesso con GitHub non funzionante

1. Verifica di aver effettuato l'accesso a GitHub
2. Controlla che Jamdesk sia autorizzato nelle impostazioni di GitHub
3. Revoca e riautorizza, se necessario

## Account bloccato

Più tentativi di accesso non riusciti bloccano temporaneamente l'account.

- Attendi 15 minuti prima di riprovare
- Usa l'opzione di reimpostazione della password
- Contatta il supporto se il problema persiste

## Autenticazione a due fattori

Se hai attivato la 2FA e non riesci ad accedere al tuo authenticator:

1. Prova i tuoi codici di backup
2. Contatta il supporto fornendo una prova della proprietà dell'account

## Problemi del browser

Prova questi passaggi:

1. **Cancella la cache e i cookie** per jamdesk.com
2. **Disattiva le estensioni** che potrebbero interferire
3. **Prova la modalità incognito/privata**
4. **Usa un browser diverso**
