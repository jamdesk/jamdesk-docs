Non riesci ad accedere al dashboard di Jamdesk? Individua qui sotto la tua situazione.

## Password dimenticata

<Steps>
  <Step title="Vai alla pagina di accesso">
    Visita [dashboard.jamdesk.com](https://dashboard.jamdesk.com).
  </Step>
  <Step title="Fai clic su Forgot Password">
    Seleziona il link **Forgot password?**.
  </Step>
  <Step title="Inserisci la tua email">
    Inserisci l'indirizzo email del tuo account.
  </Step>
  <Step title="Controlla la posta in arrivo">
    Fai clic sul link di reimpostazione nell'email che ti inviamo.
  </Step>
</Steps>

<Note>
I link di reimpostazione scadono dopo 1 ora. Richiedine uno nuovo se il tuo è scaduto.
</Note>

## Email non riconosciuta

Se visualizzi "No account found":

- Controlla che non ci siano errori di battitura nel tuo indirizzo email
- Prova altri indirizzi email che potresti avere utilizzato
- Potresti esserti registrato con Google o GitHub

## Problemi di accesso OAuth

### Accesso con Google non funzionante

1. Cancella i cookie del browser
2. Prova un browser diverso
3. Disattiva temporaneamente le estensioni del browser
4. Verifica che i cookie di terze parti siano consentiti

### Accesso con GitHub non funzionante

1. Verifica di aver effettuato l'accesso a GitHub
2. Controlla che Jamdesk sia autorizzato nelle impostazioni di GitHub
3. Revoca l'autorizzazione e autorizza nuovamente se necessario

## Account bloccato

Dopo diversi tentativi di accesso non riusciti, gli account vengono bloccati temporaneamente.

- Attendi 15 minuti prima di riprovare
- Utilizza l'opzione di reimpostazione della password
- Contatta l'assistenza se il problema persiste

## Autenticazione a due fattori

Se hai abilitato la 2FA e non puoi accedere alla tua app di autenticazione:

1. Prova a utilizzare i codici di backup
2. Contatta l'assistenza fornendo una prova della titolarità dell'account

## Problemi del browser

Prova questi passaggi:

1. **Cancella cache e cookie** per jamdesk.com
2. **Disattiva le estensioni** che potrebbero interferire
3. **Prova la modalità in incognito/privata**
4. **Utilizza un browser diverso**
