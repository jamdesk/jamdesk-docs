Jamdesk distribuisce automaticamente la tua documentazione quando esegui il push su GitHub.

<Note>
Per capire come l'app GitHub e il collegamento dell'account personale lavorano insieme, consulta [Informazioni sull'integrazione GitHub](/it/integrations/github).
</Note>

<Tip>
Hai la documentazione su Bitbucket Cloud? Consulta [Collega Bitbucket](/it/setup/connecting-bitbucket). Ogni progetto si collega a un solo provider.
</Tip>

## Installazione dell'app GitHub

Jamdesk ti chiede di installare l'app GitHub di Jamdesk la prima volta che accedi. L'app concede:

- **Accesso al repository**: lettura dei contenuti della documentazione
- **Webhook**: attivazione delle build al push
- **Stato del commit**: visualizzazione dello stato della build sui commit

### Autorizzazioni

L'app GitHub di Jamdesk richiede questi permessi:

| Permesso | Scopo |
|------------|---------|
| Contenuti del repository (lettura e scrittura) | Clonare e leggere i file della documentazione. Le scritture avvengono solo quando salvi nell'editor della dashboard, accetti i suggerimenti di Fix with AI o attivi la traduzione |
| Metadati (lettura) | Elencare repository e branch |
| Webhook | Ricevere notifiche di push |

<Note>
Jamdesk accede solo ai repository a cui concedi esplicitamente l'accesso. Puoi modificare l'accesso in qualsiasi momento nelle impostazioni di GitHub.
</Note>

## Collega un repository

<Steps>
  <Step title="Seleziona repository">
    Fai clic su **Connect Repository** durante la creazione o la modifica di un progetto.

    Scegli tra i repository in cui è installata l'app GitHub.
  </Step>

  <Step title="Scegli il branch">
    Seleziona il branch da distribuire:

    - **main** o **master**: i più comuni per la documentazione di produzione
    - **docs**: se conservi la documentazione in un branch separato
    - Qualsiasi branch: per i deploy di anteprima
  </Step>

  <Step title="Specifica il percorso della documentazione">
    Se il tuo `docs.json` non si trova nella radice del repository, specifica il percorso:

    ```bash
    docs/           # Docs in a subdirectory
    packages/docs/  # Monorepo with docs package
    ```

    Lascia vuoto se `docs.json` si trova nella radice.
  </Step>
</Steps>

La dashboard del progetto mostra quindi il repository e il branch collegati:

## Deploy automatici

Ogni push sul branch configurato attiva una build:

```bash
git add .
git commit -m "Update API documentation"
git push origin main
```

Le build di solito si completano in 30-90 secondi. Visualizza lo stato nella dashboard o sul commit di GitHub.

## Cambiare repository

Per collegare un repository diverso:

1. Vai su **Settings** → **Repository**
2. Fai clic su **Change Repository**
3. Seleziona il nuovo repository e branch

<Warning>
Cambiare repository può influire sulla documentazione attiva. Il nuovo repository deve contenere una configurazione Jamdesk valida.
</Warning>

## Gestire l'accesso della GitHub App

Controlla a quali repository Jamdesk può accedere:

1. Vai su [github.com/settings/installations](https://github.com/settings/installations)
2. Trova **Jamdesk** nell'elenco
3. Fai clic su **Configure**
4. In "Repository access", seleziona repository specifici oppure tutti

### Repository dell'organizzazione

Un amministratore dell'organizzazione deve approvare l'installazione dell'app GitHub per i repository di organizzazione:

1. Richiedi l'installazione dalla tua dashboard Jamdesk
2. Un amministratore riceve una notifica in GitHub
3. I repository dell'organizzazione compaiono nel selettore dei repository dopo l'approvazione

## Collega il tuo account personale

Collega il tuo account GitHub personale in **User Settings** per un'attribuzione affidabile delle build:

1. Fai clic sul tuo avatar → **User Settings**
2. Trova la sezione **GitHub Account**
3. Fai clic su **Link GitHub Account**

Questo collegamento è separato dall'app GitHub. Attribuisce i tuoi commit a te. [Scopri di più](/it/integrations/github#account-github-personale-livello-utente).

## Risoluzione dei problemi

### Il repository non viene visualizzato

- Verifica che l'app GitHub sia installata sul repository
- Per i repository di organizzazione, conferma che un amministratore abbia approvato l'accesso
- Aggiorna l'elenco dei repository nella dashboard

### GitHub continua a reindirizzarti alla pagina dell'app Jamdesk

Probabilmente il tuo account GitHub è gestito dalla tua azienda. GitHub non consente a questi account di installare app autonomamente. Consulta [account GitHub gestiti dall'azienda](/it/help/troubleshooting/github-issues#account-github-gestiti-dallazienda) per risolvere.

### Le build non vengono attivate

- Verifica che il webhook sia attivo nelle impostazioni del repository
- Controlla di eseguire il push sul branch configurato
- Cerca errori di consegna dei webhook in GitHub

### Errori di autorizzazione negata

- Riautorizza l'app GitHub nelle impostazioni di GitHub
- Conferma che l'app Jamdesk possa accedere al repository

<Note>
  Per una risoluzione dei problemi più dettagliata, consulta [Informazioni sull'integrazione GitHub](/it/integrations/github).
</Note>
