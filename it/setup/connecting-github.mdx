Jamdesk si integra con GitHub per eseguire automaticamente il deploy della documentazione quando esegui il push delle modifiche.

Gli screenshot mostrano l'interfaccia in inglese.

<Note>
Per informazioni sul funzionamento congiunto di GitHub App e collegamento dell'account personale, consulta [Informazioni sull'integrazione GitHub](/it/integrations/github).
</Note>

<Tip>
Usi invece Bitbucket Cloud per la documentazione? Consulta [Collega Bitbucket](/it/setup/connecting-bitbucket). Ogni progetto si collega a un solo provider.
</Tip>

## Installazione dell'app GitHub

Quando accedi per la prima volta a Jamdesk, ti verrà richiesto di installare la GitHub App di Jamdesk. Questa app consente di:

- **Accesso al repository** - Leggere i contenuti della documentazione
- **Webhooks** - Attivare le build al push
- **Stato del commit** - Mostrare lo stato della build sui commit

### Autorizzazioni

La GitHub App di Jamdesk richiede queste autorizzazioni:

| Autorizzazione | Scopo |
|------------|---------|
| Contenuti del repository (lettura) | Clonare e leggere i file della documentazione |
| Metadati (lettura) | Elencare repository e branch |
| Webhooks | Ricevere notifiche dei push |

<Note>
Jamdesk accede solo ai repository a cui concedi esplicitamente l'accesso. Puoi modificare l'accesso in qualsiasi momento nelle impostazioni GitHub.
</Note>

## Collega un repository

<Steps>
  <Step title="Seleziona il repository">
    Quando crei o modifichi un progetto, fai clic su **Connect Repository**.

    Scegli tra i repository in cui GitHub App è installata.
  </Step>

  <Step title="Scegli il branch">
    Seleziona il branch su cui eseguire il deploy:

    - **main** o **master** - I più comuni per la documentazione di produzione
    - **docs** - Se mantieni la documentazione in un branch separato
    - Qualsiasi branch - Per i deploy di anteprima
  </Step>

  <Step title="Specifica il percorso della documentazione">
    Se `docs.json` non si trova nella root del repository, specifica il percorso:

    ```bash
    docs/           # Docs in a subdirectory
    packages/docs/  # Monorepo with docs package
    ```

    Lascia vuoto se `docs.json` si trova nella root.
  </Step>
</Steps>

Dopo il collegamento, il dashboard del progetto mostra il repository e il branch collegati:

## Deploy automatici

Dopo il collegamento, ogni push al branch configurato attiva una build:

```bash
git add .
git commit -m "Update API documentation"
git push origin main
```

Le build vengono generalmente completate in 30-90 secondi. Visualizza lo stato nel dashboard o sul commit GitHub.

## Cambiare repository

Per collegare un repository diverso:

1. Vai a **Settings** → **Repository**
2. Fai clic su **Change Repository**
3. Seleziona il nuovo repository e branch

<Warning>
Cambiare repository può influire sulla documentazione pubblicata. Il nuovo repository deve contenere una configurazione Jamdesk valida.
</Warning>

## Gestire l'accesso all'app GitHub

Controlla a quali repository può accedere Jamdesk:

1. Vai a [github.com/settings/installations](https://github.com/settings/installations)
2. Trova **Jamdesk** nell'elenco
3. Fai clic su **Configure**
4. In "Repository access", seleziona repository specifici oppure tutti

### Repository dell'organizzazione

Per i repository dell'organizzazione, un amministratore dell'organizzazione deve approvare l'installazione di GitHub App:

1. Richiedi l'installazione dal dashboard Jamdesk
2. Un amministratore riceverà una notifica in GitHub
3. Dopo l'approvazione, i repository dell'organizzazione appariranno nel selettore dei repository

## Collega il tuo account personale

Per un'attribuzione affidabile delle build, collega il tuo account GitHub personale in **User Settings**:

1. Fai clic sul tuo avatar → **User Settings**
2. Trova la sezione **GitHub Account**
3. Fai clic su **Link GitHub Account**

Questa operazione è separata da GitHub App e garantisce che i tuoi commit siano attribuiti correttamente a te. [Scopri di più](/it/integrations/github#account-github-personale-a-livello-di-utente).

## Risoluzione dei problemi

### Il repository non viene visualizzato

- Verifica che GitHub App sia installata nel repository
- Per i repository dell'organizzazione, conferma che un amministratore abbia approvato l'accesso
- Prova ad aggiornare l'elenco dei repository nel dashboard

### I build non si attivano

- Verifica che il webhook sia attivo nelle impostazioni del repository
- Verifica di eseguire il push al branch configurato
- Cerca gli errori di consegna del webhook in GitHub

### Errori di autorizzazione negata

- Autorizza nuovamente GitHub App nelle impostazioni GitHub
- Assicurati che il repository sia accessibile a Jamdesk App

<Note>
  Per una risoluzione dei problemi più dettagliata, consulta [Informazioni sull'integrazione GitHub](/it/integrations/github).
</Note>
