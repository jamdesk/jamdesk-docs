Jamdesk si integra con GitHub per distribuire automaticamente la documentazione quando invii modifiche.

Gli screenshot mostrano l'interfaccia in inglese.

<Note>
Per capire come collaborano l'app GitHub e il collegamento dell'account personale, consulta [Informazioni sull'integrazione GitHub](/it/integrations/github).
</Note>

<Tip>
Hai la documentazione su Bitbucket Cloud? Consulta [Connetti Bitbucket](/it/setup/connecting-bitbucket). Ogni progetto si collega a un solo provider.
</Tip>

## Installazione dell'app GitHub

Quando accedi a Jamdesk per la prima volta, ti verrà chiesto di installare l'app GitHub di Jamdesk. Questa app consente di:

- **Accedere ai repository** - Leggere i contenuti della documentazione
- **Webhook** - Avviare build a ogni push
- **Stato dei commit** - Mostrare lo stato della build nei commit

### Autorizzazioni

L'app GitHub di Jamdesk richiede le seguenti autorizzazioni:

| Autorizzazione | Scopo |
|------------|---------|
| Contenuti del repository (lettura e scrittura) | Clonare e leggere i file della documentazione. Le scritture avvengono solo quando salvi nell'editor della dashboard, accetti i suggerimenti di Fix with AI o attivi la traduzione |
| Metadata (lettura) | Elencare repository e branch |
| Webhooks | Ricevere notifiche push |

<Note>
Jamdesk accede solo ai repository a cui concedi esplicitamente l'accesso. Puoi modificare le autorizzazioni in qualsiasi momento nelle impostazioni di GitHub.
</Note>

## Collega un repository

<Steps>
  <Step title="Selezionare il repository">
    Quando crei o modifichi un progetto, fai clic su **Connect Repository**.

    Scegli tra i repository in cui è installata l'app GitHub.
  </Step>

  <Step title="Scegliere il branch">
    Seleziona il branch da distribuire:

    - **main** o **master** - I più comuni per la documentazione di produzione
    - **docs** - Se conservi la documentazione in un branch separato
    - Qualsiasi branch - Per le distribuzioni di anteprima
  </Step>

  <Step title="Specificare il percorso della documentazione">
    Se `docs.json` non si trova nella directory principale del repository, specifica il percorso:

    ```bash
    docs/           # Docs in a subdirectory
    packages/docs/  # Monorepo with docs package
    ```

    Lascia il campo vuoto se `docs.json` si trova nella directory principale.
  </Step>
</Steps>

Una volta effettuato il collegamento, nella dashboard del progetto vengono mostrati il repository collegato e il branch:

## Deploy automatici

Una volta effettuato il collegamento, ogni push al branch configurato avvia una build:

```bash
git add .
git commit -m "Update API documentation"
git push origin main
```

Le build vengono completate in genere in 30-90 secondi. Puoi visualizzarne lo stato nella dashboard o nel commit GitHub.

## Cambiare repository

Per collegare un altro repository:

1. Vai a **Settings** → **Repository**
2. Fai clic su **Change Repository**
3. Seleziona il nuovo repository e branch

<Warning>
Cambiare repository può influire sulla documentazione pubblicata. Il nuovo repository deve contenere una configurazione Jamdesk valida.
</Warning>

## Gestire l'accesso della GitHub App

Scegli a quali repository può accedere Jamdesk:

1. Vai a [github.com/settings/installations](https://github.com/settings/installations)
2. Trova **Jamdesk** nell'elenco
3. Fai clic su **Configure**
4. In "Repository access", seleziona repository specifici oppure tutti

### Repository dell'organizzazione

Per i repository dell'organizzazione, un amministratore deve approvare l'installazione dell'app GitHub:

1. Richiedi l'installazione dalla dashboard di Jamdesk
2. Un amministratore riceve una notifica su GitHub
3. Dopo l'approvazione, i repository dell'organizzazione compaiono nel selettore dei repository

## Collega il tuo account personale

Per attribuire correttamente le build, collega il tuo account GitHub personale in **User Settings**:

1. Fai clic sul tuo avatar → **User Settings**
2. Trova la sezione **GitHub Account**
3. Fai clic su **Link GitHub Account**

Questa procedura è separata dall'app GitHub e garantisce che i commit siano attribuiti correttamente a te. [Scopri di più](/it/integrations/github#account-github-personale-livello-utente).

## Risoluzione dei problemi

### Il repository non viene visualizzato

- Verifica che l'app GitHub sia installata nel repository
- Per i repository dell'organizzazione, verifica che un amministratore abbia approvato l'accesso
- Prova ad aggiornare l'elenco dei repository nella dashboard

### GitHub continua a reindirizzarti alla pagina dell'app Jamdesk

Probabilmente la tua azienda gestisce il tuo account GitHub e GitHub non consente a questi account di installare app sul proprio account. Consulta [Account GitHub gestiti dall'azienda](/it/help/troubleshooting/github-issues#account-github-gestiti-dallazienda) per risolvere il problema.

### Le build non vengono attivate

- Verifica che il webhook sia attivo nelle impostazioni del repository
- Verifica di eseguire il push sul branch configurato
- Controlla se GitHub segnala errori di consegna del webhook

### Errori di autorizzazione negata

- Autorizza di nuovo l'app GitHub nelle impostazioni di GitHub
- Assicurati che l'app Jamdesk possa accedere al repository

<Note>
  Per istruzioni più dettagliate sulla risoluzione dei problemi, consulta [Informazioni sull'integrazione GitHub](/it/integrations/github).
</Note>
