Scopri cosa cercano i lettori, quali query non restituiscono risultati e su cosa cliccano.

<Info>
Per le visualizzazioni di pagina e i dati sui visitatori, consulta [Analisi del progetto](/it/setup/project-analytics).
</Info>

<Note>
Se i dati di ricerca mancano o arrivano in ritardo, consulta [Problemi di analisi](/it/help/troubleshooting/analytics-issues).
</Note>

## Visualizzare le analisi delle ricerche

<Steps>
  <Step title="Apri il tuo progetto">
    Vai su [dashboard.jamdesk.com](https://dashboard.jamdesk.com) e seleziona il tuo progetto.
  </Step>

  <Step title="Fai clic su Search Analytics">
    Nella barra laterale, sotto **Analytics**, fai clic su **Search**.
  </Step>

  <Step title="Seleziona un intervallo di date">
    Scegli un periodo con il selettore di date. Il valore predefinito è 30 giorni.
  </Step>
</Steps>

## Metriche principali

| Metrica | Descrizione |
|--------|-------------|
| **Total Searches** | Numero di ricerche effettuate nel periodo selezionato |
| **Unique Queries** | Termini di ricerca distinti utilizzati |
| **Zero Results** | Ricerche che non hanno restituito alcuna corrispondenza |
| **Click-through Rate** | Percentuale di ricerche con un risultato cliccato |

Ogni metrica mostra la variazione percentuale rispetto al periodo precedente.

Esempio di snapshot:

```json
{
  "period": "Last 30 days",
  "total_searches": 940,
  "unique_queries": 312,
  "zero_results": 42,
  "top_queries": [
    { "query": "authentication", "searches": 84, "ctr": 0.82 },
    { "query": "api keys", "searches": 63, "ctr": 0.71 }
  ]
}
```

## Volume delle ricerche

Il grafico del volume di ricerche mostra le ricerche giornaliere nel periodo selezionato. Usalo per:

- Individuare schemi tra giorni feriali e fine settimana
- Individuare picchi dovuti a link esterni o annunci
- Monitorare la crescita nel tempo

## Analisi delle query

### Ricerche principali

I termini di ricerca più comuni mostrano:

- **Argomenti popolari:** ciò di cui i lettori hanno più spesso bisogno
- **Problemi di navigazione:** ricerche di pagine già presenti nella navigazione
- **Lacune terminologiche:** termini diversi da quelli usati nella documentazione

Ogni query mostra:
- Numero di ricerche
- Numero di clic sui risultati
- Click-through rate (CTR)

### Lacune nei contenuti

<Warning>
Le lacune nei contenuti sono ricerche che non hanno restituito alcun risultato. Ognuna corrisponde a un argomento che la tua documentazione non copre ancora.
</Warning>

La scheda Content Gaps elenca le query che non hanno trovato nulla. Cause comuni:

| Causa | Soluzione |
|-------|----------|
| Documentazione mancante | Crea una nuova pagina che copra l'argomento |
| Terminologia diversa | Aggiungi sinonimi o aggiorna i titoli |
| Errori di battitura nei contenuti | Correggi l'ortografia nella documentazione |
| Funzionalità non ancora documentata | Aggiungila alla roadmap della documentazione |

## Approfondimenti sulle ricerche

| Approfondimento | Significato |
|---------|---------------|
| **Avg. Click Position** | Posizione media del risultato cliccato (più basso è meglio) |
| **Searches per Day** | Volume medio giornaliero di ricerche |
| **Top Query** | Il tuo termine di ricerca più comune |
| **Most Missed** | La query senza risultati più frequente da risolvere |

## Procedure consigliate

<Accordion title="Rivedi le lacune nei contenuti ogni settimana">
Imposta un'attività ricorrente per rivedere le ricerche senza risultati.
</Accordion>

<Accordion title="Usa un linguaggio naturale nei titoli">
I lettori cercano con frasi naturali. Scrivi titoli che corrispondano a queste frasi.
</Accordion>

<Accordion title="Aggiungi sinonimi alle pagine importanti">
Se i lettori cercano "setup" ma la tua pagina si chiama "installazione", menziona "setup" nella pagina.
</Accordion>

<Accordion title="Monitora i miglioramenti del CTR">
Controlla i click-through rate dopo aver risolto le lacune nei contenuti. Un CTR basso per query molto frequenti significa che i risultati non corrispondono a ciò che i lettori cercano.
</Accordion>

## Punteggio di qualità delle ricerche

Jamdesk calcola un punteggio di qualità della ricerca in base al click-through rate:

``` text
Score = (Searches with clicks / Total searches) × 100
```

| Punteggio | Valutazione |
|-------|--------|
| 90%+ | Eccellente |
| 70-89% | Buono |
| 50-69% | Da migliorare |
| Sotto il 50% | Scarso |

## Esportazione dei dati

1. Vai su **Analytics** → **Search**
2. Fai clic su **Export**
3. Scegli il formato CSV o JSON

## Disponibilità dei dati

I dati di ricerca compaiono dopo il consolidamento giornaliero delle 2:00 UTC. Le ricerche di oggi compaiono domani.

<Note>
I nuovi siti hanno bisogno di 24-48 ore di dati di ricerca prima che i numeri abbiano davvero significato.
</Note>
