Scopri cosa cercano i lettori, quali query non restituiscono risultati e su cosa fanno clic.

<Info>
Cerchi dati sulle visualizzazioni delle pagine e sui visitatori? Consulta [Analisi del progetto](/it/setup/project-analytics).
</Info>

<Note>
Se i dati delle ricerche mancano o sono in ritardo, consulta [Problemi di Analytics](/it/help/troubleshooting/analytics-issues).
</Note>

## Visualizzare le analisi delle ricerche

Accedi alle analisi delle ricerche dal dashboard del progetto:

<Steps>
  <Step title="Apri il progetto">
    Vai su [dashboard.jamdesk.com](https://dashboard.jamdesk.com) e seleziona il progetto.
  </Step>

  <Step title="Fai clic su Search Analytics">
    Nella barra laterale, sotto **Analytics**, fai clic su **Search** per visualizzare il dashboard delle ricerche.
  </Step>

  <Step title="Seleziona un intervallo di date">
    Usa il selettore delle date per visualizzare i dati delle ricerche relativi a periodi diversi. L'impostazione predefinita è di 30 giorni.
  </Step>
</Steps>

## Metriche principali

Il dashboard delle analisi delle ricerche mostra quattro metriche principali:

| Metrica | Descrizione |
|--------|-------------|
| **Ricerche totali** | Numero di ricerche eseguite nel periodo selezionato |
| **Query uniche** | Termini di ricerca distinti utilizzati |
| **Nessun risultato** | Ricerche che non hanno restituito corrispondenze |
| **Percentuale di clic** | Percentuale di ricerche in cui gli utenti hanno fatto clic su un risultato |

Ogni metrica include un confronto con il periodo precedente, mostrato come variazione percentuale.

Esempio di riepilogo:

```json
{
  "period": "Last 30 days",
  "total_searches": 940,
  "unique_queries": 312,
  "zero_results": 42,
  "top_queries": [
    { "query": "authentication", "searches": 84, "ctr": 0.82 },
    { "query": "api keys", "searches": 63, "ctr": 0.71 }
  ]
}
```

## Volume delle ricerche

Il grafico del volume delle ricerche mostra l'attività quotidiana nel periodo selezionato. Usalo per:

- Identificare i modelli di utilizzo (traffico nei giorni feriali rispetto al fine settimana)
- Individuare picchi insoliti che potrebbero indicare link esterni o annunci
- Monitorare nel tempo la crescita dell'utilizzo della documentazione

## Analisi delle query

### Ricerche principali

Visualizza i termini di ricerca più comuni inseriti dagli utenti. Questo rivela:

- **Argomenti popolari** - Ciò di cui gli utenti hanno più spesso bisogno
- **Problemi di navigazione** - Se gli utenti cercano elementi facilmente reperibili nella navigazione
- **Lacune terminologiche** - Se gli utenti utilizzano termini diversi da quelli presenti nella documentazione

Per ogni query visualizzerai:
- Numero di ricerche
- Numero di clic sui risultati
- Percentuale di clic (CTR)

### Lacune nei contenuti

<Warning>
Le lacune nei contenuti sono ricerche che non hanno restituito risultati. Ognuna rappresenta un argomento che la documentazione non tratta ancora.
</Warning>

La scheda Content Gaps mostra le query per cui gli utenti hanno effettuato una ricerca senza trovare nulla. Cause comuni:

| Causa | Soluzione |
|-------|----------|
| Documentazione mancante | Crea una nuova pagina che tratti l'argomento |
| Terminologia diversa | Aggiungi sinonimi o aggiorna le intestazioni |
| Refusi nei contenuti | Correggi l'ortografia nella documentazione |
| Funzionalità non ancora documentata | Aggiungila alla roadmap della documentazione |

Esamina regolarmente le lacune nei contenuti. La sezione Procedure consigliate qui sotto suggerisce una cadenza settimanale.

## Approfondimenti sulle ricerche

Il pannello degli approfondimenti fornisce risposte rapide:

| Approfondimento | Significato |
|---------|---------------|
| **Posizione media del clic** | Quanto in basso nei risultati fanno clic solitamente gli utenti (più bassa è meglio) |
| **Ricerche al giorno** | Volume medio giornaliero delle ricerche |
| **Query principale** | Il termine di ricerca più comune |
| **Più ignorata** | La query principale senza risultati da risolvere |

## Procedure consigliate

<Accordion title="Esamina settimanalmente le lacune nei contenuti">
Imposta un'attività ricorrente per esaminare le ricerche senza risultati. Anche pochi minuti alla settimana impediscono l'accumulo di debito documentale.
</Accordion>

<Accordion title="Usa il linguaggio naturale nelle intestazioni">
Gli utenti cercano spesso utilizzando frasi naturali. Se le intestazioni corrispondono al modo in cui gli utenti pensano, troveranno i contenuti più rapidamente.
</Accordion>

<Accordion title="Aggiungi sinonimi alle pagine importanti">
Se gli utenti cercano "setup" ma la pagina si chiama "installation", menziona entrambi i termini nei contenuti, così la ricerca potrà trovare la pagina.
</Accordion>

<Accordion title="Monitora i miglioramenti del CTR">
Dopo aver colmato le lacune nei contenuti, verifica se le percentuali di clic migliorano. Un CTR basso per le query ad alto volume indica che i risultati non corrispondono all'intento degli utenti.
</Accordion>

## Punteggio di qualità delle ricerche

Jamdesk calcola un punteggio di qualità delle ricerche in base alla percentuale di clic:

``` text
Score = (Searches with clicks / Total searches) × 100
```

| Punteggio | Valutazione |
|-------|--------|
| 90%+ | Eccellente |
| 70-89% | Buono |
| 50-69% | Da migliorare |
| Below 50% | Scarso |

## Esportazione dei dati

Esporta i dati delle ricerche per ulteriori analisi:

1. Vai su **Analytics** → **Search**
2. Fai clic su **Export**
3. Scegli il formato CSV o JSON

## Disponibilità dei dati

I dati delle analisi delle ricerche diventano disponibili dopo l'esecuzione dell'elaborazione giornaliera alle 2:00 UTC. Le ricerche effettuate oggi appariranno nel dashboard domani.

<Note>
Se hai appena configurato la documentazione, attendi 24-48 ore affinché i dati delle ricerche si accumulino prima di aspettarti approfondimenti significativi.
</Note>
