Prima di scrivere la documentazione, ti serve un progetto. Puoi partire da un modello (Jamdesk crea il repository per te su GitHub o Bitbucket Cloud) oppure collegare un repository esistente che contiene già un `docs.json`. In entrambi i casi, il tuo sito sarà online in pochi minuti.

## Crea un nuovo progetto

<Steps>
  <Step title="Accedi a Jamdesk">
    Vai su [dashboard.jamdesk.com](https://dashboard.jamdesk.com) e accedi con il tuo account GitHub.

    Al primo accesso, ti verrà chiesto di autorizzare l'app GitHub di Jamdesk.
  </Step>

  <Step title="Fai clic su New Project">
    Dalla dashboard, fai clic su **New Project** nell'angolo in alto a destra.
  </Step>

  <Step title="Scegli da dove iniziare">
    <Tabs>
      <Tab title="From Template">
        Inizia con un modello preconfigurato. Jamdesk crea per te un nuovo repository GitHub con contenuti di esempio, navigazione e componenti già configurati.

        Lo [Starter Template](https://github.com/jamdesk/starter-docs) predefinito include pagine di esempio, una specifica OpenAPI e esempi di ogni componente. Sostituisci i contenuti con i tuoi e il gioco è fatto.
      </Tab>
      <Tab title="From Repository">
        Collega un repository GitHub esistente:

        1. Seleziona il repository dal menu a discesa
        2. Scegli il branch da distribuire (di solito `main`)
        3. Indica il percorso di `docs.json` se non si trova nella directory principale

        Hai un repository su Bitbucket Cloud? Inseriscilo nel formato `workspace/repository-slug`. Consulta [Connetti Bitbucket](/it/setup/connecting-bitbucket).
      </Tab>
    </Tabs>
  </Step>

  <Step title="Configura le impostazioni del progetto">
    Imposta le informazioni di base del progetto:

    | Campo | Descrizione |
    |-------|-------------|
    | **Name** | Nome visualizzato nella dashboard |
    | **Slug** | Identificatore adatto agli URL (ad es. `my-docs`) |
    | **Domain** | Sottodominio `*.jamdesk.app` |
  </Step>
</Steps>

## Struttura minima del repository

A un progetto Jamdesk bastano un `docs.json` e almeno una pagina:

```bash
my-docs/
├── docs.json
└── introduction.mdx
```

Esempio di `docs.json`:

```json docs.json
{
  "$schema": "https://jamdesk.com/docs.json",
  "name": "My Docs",
  "theme": "jam",
  "navigation": {
    "groups": [
      {
        "group": "Getting Started",
        "pages": ["introduction"]
      }
    ]
  }
}
```

## Impostazioni del progetto

Dopo la creazione, configura il progetto in **Settings**:

### Generali

- **Name** - Aggiorna il nome visualizzato
- **Slug** - Modifica l'identificatore del progetto
- **Delete Project** - Rimuove definitivamente il progetto

### Repository

- **Branch** - Il branch che attiva i deploy
- **Docs Path** - Posizione di `docs.json` nei monorepo

### Dominio

- **Subdomain** - URL `*.jamdesk.app`
- **Custom Domain** - Aggiungi un dominio personalizzato
- **Host at a subpath** - Pubblica la documentazione in un percorso come `/docs` o `/help` anziché nella radice del sito

### Build

- **Show Jamdesk Branding** - Mostra nel piè di pagina il link "Powered by Jamdesk" (attivo per impostazione predefinita)
- **Rebuild** - Avvia manualmente una nuova build

<Note>
Le modifiche alle impostazioni di build richiedono una nuova build per diventare effettive.
</Note>

## Limiti dei progetti

Il piano Pro include un progetto. Puoi aggiungerne altri con i [componenti aggiuntivi per i progetti](/it/help/billing/project-addons) a $15 al mese ciascuno.
