Ogni sito Jamdesk inizia allo stesso modo: un progetto nel dashboard, un repository GitHub collegato e un file `docs.json` che descrive la navigazione. Questa sezione illustra la configurazione iniziale e le decisioni strutturali da prendere fin dall'inizio. È molto più semplice definire la struttura degli URL, le lingue e il controllo degli accessi prima di avere cinquanta pagine.

Stai effettuando la migrazione da un'altra piattaforma? Vai direttamente alla [guida alla migrazione](/it/setup/migration). Jamdesk può automatizzare gran parte della conversione.

## Dal repository al sito online

<Steps>
  <Step title="Crea un progetto">
    Parti da un template o collega un repository GitHub esistente. Il sito sarà online all'indirizzo `yourproject.jamdesk.app`.
  </Step>
  <Step title="Collega GitHub">
    Installa l'app GitHub per distribuire automaticamente ogni push.
  </Step>
  <Step title="Organizza il repository">
    Un file `docs.json` più le pagine MDX. Questo è tutto ciò che serve.
  </Step>
</Steps>
