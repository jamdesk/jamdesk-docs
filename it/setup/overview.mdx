Un sito Jamdesk è un progetto nella dashboard, un repo GitHub alla base e un file `docs.json` che descrive la navigazione. Questa sezione tratta la configurazione. Definisci presto la struttura degli URL, le lingue e il controllo degli accessi. Sono più difficili da modificare quando hai cinquanta pagine.

Per passare da un'altra piattaforma, consulta la [Guida alla migrazione](/it/setup/migration).

## Dal repository al sito online

<Steps>
  <Step title="Crea un progetto">
    Parti da un template oppure collega un repo GitHub esistente. Il tuo sito sarà online su `yourproject.jamdesk.app`.
  </Step>
  <Step title="Collega GitHub">
    Installa la GitHub App così ogni push viene distribuito automaticamente.
  </Step>
  <Step title="Organizza il repo">
    Aggiungi un file `docs.json` e le pagine MDX.
  </Step>
</Steps>
