## Come accedere

<Steps>
  <Step title="Apri il tuo progetto">
    Vai su [dashboard.jamdesk.com](https://dashboard.jamdesk.com) e seleziona il tuo progetto.
  </Step>
  <Step title="Apri Analytics">
    Fai clic su **Analytics** nella barra laterale per accedere a entrambe le dashboard.
  </Step>
  <Step title="Scegli un intervallo di date">
    Usa il selettore di date per confrontare i periodi e individuare i cambiamenti nel tempo.
  </Step>
</Steps>

## Esempio di riepilogo

Ecco un esempio di riepilogo delle analisi che mostra entrambe le dashboard affiancate:

```json
{
  "period": "Last 30 days",
  "project_analytics": {
    "visitors": 4120,
    "views": 12890,
    "top_pages": ["/quickstart", "/content/mdx-basics", "/deploy/overview"]
  },
  "search_analytics": {
    "total_searches": 940,
    "zero_results": 42,
    "top_queries": ["authentication", "api keys", "custom domains"]
  }
}
```

## Flussi di lavoro comuni

- **Individua le principali pagine di ingresso** e assicurati che presentino rapidamente il prodotto.
- **Trova le lacune nella ricerca** quando gli utenti non ottengono risultati e aggiungi i contenuti mancanti.
- **Monitora l'impatto del lancio** confrontando il traffico prima e dopo una release.
