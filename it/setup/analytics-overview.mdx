## Come accedere

<Steps>
  <Step title="Apri il tuo progetto">
    Vai su [dashboard.jamdesk.com](https://dashboard.jamdesk.com) e seleziona il tuo progetto.
  </Step>
  <Step title="Apri Analytics">
    Fai clic su **Analytics** nella barra laterale per aprire Project Analytics e Search Analytics.
  </Step>
  <Step title="Scegli un intervallo di date">
    Usa il selettore di date per confrontare periodi e individuare cambiamenti nel tempo.
  </Step>
</Steps>

## Esempio di riepilogo

Esempio di riepilogo dei dati di Project Analytics e Search Analytics:

```json
{
  "period": "Last 30 days",
  "project_analytics": {
    "visitors": 4120,
    "views": 12890,
    "top_pages": ["/quickstart", "/content/mdx-basics", "/deploy/overview"]
  },
  "search_analytics": {
    "total_searches": 940,
    "zero_results": 42,
    "top_queries": ["authentication", "api keys", "custom domains"]
  }
}
```

## Flussi di lavoro comuni

- **Identifica le pagine di ingresso principali** e assicurati che spieghino rapidamente il prodotto.
- **Trova le lacune di ricerca** dove le ricerche non restituiscono risultati e aggiungi i contenuti mancanti.
- **Monitora l'impatto di un lancio** confrontando il traffico prima e dopo una release.
