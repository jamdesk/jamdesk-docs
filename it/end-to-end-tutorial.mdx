Vai da un repo vuoto a un sito di documentazione online. Salta i passaggi che hai già completato.

## Prerequisiti

- Un account GitHub
- Un repository con contenuti di documentazione (oppure usa lo [Starter Template](https://github.com/jamdesk/starter-docs))
- Node.js 20+ se vuoi installare la CLI con npm

<Steps>
  <Step title="Crea un progetto e collega GitHub">
    Crea un progetto nella dashboard di Jamdesk e collega un repository.

    - Segui [Creazione dei progetti](/it/setup/creating-projects) per impostare nome del progetto, slug e percorso della documentazione
    - Se richiesto, installa la GitHub App e concedi l'accesso al repository ([Collegamento a GitHub](/it/setup/connecting-github))
  </Step>

  <Step title="Modifica e visualizza le pagine con la CLI">
    Visualizza in anteprima le modifiche alle pagine con la CLI di Jamdesk prima di inviarle a GitHub.

    <Tabs>
      <Tab title="npm">
        ```bash
        npm install -g jamdesk
        cd your-docs
        jamdesk dev
        ```
      </Tab>
      <Tab title="npx">
        ```bash
        cd your-docs
        npx jamdesk dev
        ```
      </Tab>
    </Tabs>

    L'anteprima locale è disponibile su **http://localhost:3000**. Scopri di più in [Anteprima locale](/it/development/local-preview).

    Apri una pagina `.mdx` nel tuo editor. Salva una modifica e aggiorna l'anteprima locale. Pubblicala con il flusso Git nel passaggio successivo.
  </Step>

  <Step title="Esegui il deploy inviando le modifiche a GitHub">
    Ogni push sul branch configurato avvia una build. La build viene pubblicata sul tuo sottodominio Jamdesk.

    ```bash
    git add .
    git commit -m "Add docs content"
    git push origin main
    ```

    Sostituisci `main` con il branch configurato per il tuo progetto.

    La documentazione va online su `your-project.jamdesk.app` al termine della build. Vedi [Deployment](/it/development/deployment) per i dettagli.
  </Step>

  <Step title="Opzionale: aggiungi un dominio personalizzato">
    Pubblica la documentazione dal tuo dominio invece che dal sottodominio Jamdesk.

    1. Vai su **Settings** → **Domains** nella dashboard di Jamdesk
    2. Aggiungi il tuo dominio (ad esempio, `docs.example.com`)
    3. Crea i record DNS mostrati nella dashboard
    4. Attendi il completamento della verifica e del certificato SSL

    Per la risoluzione dei problemi, consulta [Domini personalizzati](/it/deploy/custom-domains).
  </Step>
</Steps>

## Convalida del flusso end-to-end

- Il tuo sottodominio Jamdesk si carica e mostra l'ultima build
- L'anteprima locale riflette gli stessi contenuti e la stessa navigazione
- Se configurato, il dominio personalizzato è verificato e serve HTTPS
- La cronologia delle build mostra l'ultimo commit e l'autore

## Facoltativo: ospita in /docs

Per servire la documentazione su un sottopercorso come `example.com/docs`, consulta [Panoramica del deployment](/it/deploy/overview) e [Hosting su sottopercorso](/it/deploy/subpath-hosting).
