Ogni pagina del tuo sito Jamdesk include un menu Azioni AI, un piccolo menu a tendina sopra il titolo. I lettori possono copiare la pagina in formato Markdown, aprirla in ChatGPT o installare il tuo server MCP in Cursor. Non serve alcuna configurazione.

## Opzioni integrate

Il menu include otto opzioni, tutte attive per impostazione predefinita:

| Opzione | Chiave | Cosa fa |
|--------|-----|-------------|
| **Copy page** | `copy` | Recupera il Markdown grezzo e lo copia negli appunti |
| **View as Markdown** | `view` | Apre il file `.md` in una nuova scheda |
| **Open in ChatGPT** | `chatgpt` | Apre ChatGPT con un prompt per leggere la pagina corrente |
| **Open in Claude** | `claude` | Apre Claude con lo stesso prompt |
| **Open in Perplexity** | `perplexity` | Apre Perplexity con lo stesso prompt |
| **Copy MCP config** | `mcp` | Copia la configurazione JSON per il [server MCP](/it/ai/mcp-server) del tuo sito |
| **Add to Cursor** | `cursor` | Collegamento diretto per installare il server MCP in Cursor |
| **Add to VS Code** | `vscode` | Collegamento diretto per installare il server MCP in VS Code |

Gemini è disponibile anche come `gemini`. Non è incluso tra le opzioni predefinite perché non precompila in modo affidabile i prompt da un URL. Aggiungilo esplicitamente se i tuoi lettori lo utilizzano.

`copy` diventa il pulsante principale quando è presente nell'elenco delle opzioni. Le altre compaiono in un menu a tendina dietro un'icona a freccia. Senza `copy`, il menu si riduce a un unico menu a tendina "AI Actions".

### Download API spec

Le pagine di riferimento API ricevono un'ulteriore voce: **Download API spec**. Questa raccoglie tutte le specifiche OpenAPI a cui il tuo sito fa riferimento in un unico file `api-specs.zip`, incluse le URL di specifiche remote. Puoi passare lo zip a Postman, a un generatore di client o ai tuoi strumenti. Le specifiche composte da più file mantengono la struttura delle cartelle all'interno dello zip. I link `$ref` tra i file continuano a funzionare.

Non c'è nulla da configurare. La voce compare solo nelle pagine basate su una specifica OpenAPI. Jamdesk genera lo zip ogni volta che viene scaricato, quindi corrisponde sempre alle specifiche correnti.

## Configurazione

Modifica `docs.json` solo per cambiare le opzioni visualizzate o per disattivare il menu.

### Mostrare un sottoinsieme di opzioni

```json docs.json
{
  "contextual": {
    "options": ["copy", "claude", "mcp"]
  }
}
```

### Disabilitare il menu

```json docs.json
{
  "contextual": {
    "enabled": false
  }
}
```

### Aggiungere opzioni personalizzate

Combina le opzioni integrate con le tue. Un'opzione personalizzata apre il proprio URL in una nuova scheda.

```json docs.json
{
  "contextual": {
    "options": [
      "copy",
      "claude",
      {
        "title": "Ask on Discord",
        "description": "Get help from the community",
        "icon": "discord",
        "href": "https://discord.gg/your-server"
      }
    ]
  }
}
```

Le opzioni personalizzate accettano un campo `icon` facoltativo. Funziona qualsiasi [nome di icona Font Awesome](/it/content/icons), comprese le icone dei marchi come `discord` o `slack`. Le opzioni senza icona mostrano un'icona di collegamento.

Le opzioni personalizzate accettano anche parametri di query:

```json docs.json
{
  "contextual": {
    "options": [
      "copy",
      {
        "title": "Search in Notion",
        "description": "Find related internal docs",
        "href": {
          "base": "https://notion.so/search",
          "query": [
            { "key": "q", "value": "docs" }
          ]
        }
      }
    ]
  }
}
```

## Come funziona

Il menu viene eseguito lato client. I suoi URL si aggiornano a ogni navigazione tra le pagine, inclusa la navigazione nella barra laterale senza un ricaricamento completo della pagina. Il link "Open in Claude" punta sempre alla pagina corrente.

I link ai servizi AI inseriscono l'URL `.md` della pagina nel prompt. ChatGPT, Claude e Perplexity recuperano la pagina da quel link.

Le opzioni MCP utilizzano l'endpoint `/_mcp` presente su ogni sito Jamdesk. "Copy MCP config" copia il JSON per qualsiasi client MCP. "Add to Cursor" e "Add to VS Code" sono collegamenti diretti che aprono il flusso di installazione dell'editor. Consulta [Server MCP](/it/ai/mcp-server) per sapere cosa possono fare gli strumenti AI con questo server.
