[Cursor](https://cursor.com) è un editor di codice basato su AI, costruito su VS Code. La sua modifica inline (Cmd+K) e la chat (Cmd+L) funzionano bene per la scrittura iterativa in MDX: selezioni un paragrafo, descrivi cosa vuoi e Cursor lo riscrive sul posto.

## Configurazione rapida

<Steps>
  <Step title="Apri il progetto della documentazione">
    Apri la directory della documentazione Jamdesk in Cursor.
  </Step>
  <Step title="Aggiungi le regole di Cursor">
    Crea `.cursor/rules/jamdesk-docs.mdc` con i tuoi standard di documentazione. L'AI di Cursor segue le convenzioni contenute al suo interno.
  </Step>
  <Step title="Collega il server MCP">
    Aggiungi l'endpoint MCP della tua documentazione a `.cursor/mcp.json`. Cursor potrà quindi cercare nella documentazione pubblicata.
  </Step>
</Steps>

## Modello delle regole di Cursor

Crea `.cursor/rules/jamdesk-docs.mdc` nella radice del progetto:

```markdown .cursor/rules/jamdesk-docs.mdc
---
description: Rules for writing Jamdesk documentation in MDX
globs: "**/*.mdx"
---

# Jamdesk MDX Rules

## Page Structure

Every page follows this pattern — no exceptions:

1. Frontmatter with `title` and `description`
2. Opening paragraph (no heading before it)
3. Content sections with ## headings
4. "What's Next?" section at the end with Card links inside Columns

## Components

Only use these — do not invent others:

Layout: Card, Columns, Tabs, Tab, Accordion, AccordionGroup, Steps, Step, Expandable, Frame, CodeGroup
Callouts: Note, Info, Warning, Tip, Check, Danger

| Use | For |
|-----|-----|
| Tabs | Mutually exclusive choices (npm/yarn, OS variants) |
| Steps | Ordered procedures the reader follows |
| Accordion | Optional detail that would clutter the page |
| Card + Columns | Navigation links and feature grids |
| Note/Tip/Warning | Important context — use sparingly |

Cards always go inside Columns: `<Columns cols={2}><Card ... /></Columns>`
Icons are Font Awesome Light names: "rocket", "code", "terminal", "book-open"

## Style

- Active voice: "Run this command" not "This command should be run"
- Start with why, then how
- One idea per paragraph
- Code examples must be complete and copy-pasteable
- Write like a person — no filler ("It's important to note"), no hedging ("you might want to consider"). If it sounds like a chatbot, rewrite it shorter.

## Common Mistakes

- `<CodeBlock>`, `<Alert>`, `<Section>` don't exist — use the components listed above
- `<Card>` without `<Columns>` wrapper won't render correctly
- Missing `description` in frontmatter breaks search and link previews
- Raw HTML tags should be MDX components instead

## New Pages

When creating a page, add it to `docs.json` navigation. Without this, the page won't appear in the sidebar. Read `docs.json` first to understand the group structure.
```

## Configurazione MCP

Crea `.cursor/mcp.json` per collegare la tua documentazione pubblicata:

```json .cursor/mcp.json
{
  "mcpServers": {
    "my-docs": {
      "url": "https://your-project.jamdesk.app/_mcp"
    }
  }
}
```

Sostituisci `your-project` con il tuo sottodominio Jamdesk. Se hai un dominio personalizzato attivo, usalo invece: `"url": "https://docs.acme.com/_mcp"`. Vedi [Server MCP](/it/ai/mcp-server) per i dettagli sugli endpoint.

## Flussi di lavoro

<Tabs>
  <Tab title="Modifica inline (Cmd+K)">
    Seleziona del testo in un file MDX e premi **Cmd+K** per descrivere la modifica desiderata. Funziona bene per:
    - Riscrivere una sezione per chiarezza
    - Aggiungere un esempio di codice
    - Convertire il testo in un componente (ad esempio, racchiudere i passaggi in `<Steps>`)
  </Tab>
  <Tab title="Chat (Cmd+L)">
    Apri la chat con **Cmd+L** e fai domande usando la tua documentazione come contesto:
    - "Quali componenti sono disponibili per questa pagina?"
    - "Scrivi una sezione di risoluzione dei problemi per [funzionalità]"
    - "Verifica questa pagina rispetto ai nostri standard di scrittura"
  </Tab>
  <Tab title="Composer">
    Usa Composer per attività di documentazione su più file:
    - Genera una nuova sezione con più pagine
    - Ristruttura la navigazione tra i file
    - Aggiorna in blocco i pattern di utilizzo dei componenti
  </Tab>
</Tabs>

## Skill `/update-jamdesk`

Installa la skill `/update-jamdesk` per aggiornare automaticamente la documentazione quando il codice cambia:

```bash
npx skills add jamdesk/skills --skill update-jamdesk -a cursor
```

Vedi [Aggiornamenti automatici](/it/ai/automated-updates) per la guida completa.
