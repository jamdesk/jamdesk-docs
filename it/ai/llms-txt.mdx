Se vuoi che strumenti AI come ChatGPT, Claude o Copilot forniscano risposte accurate sul tuo prodotto, hanno bisogno di un accesso strutturato alla documentazione, non solo di ciò che è stato incluso nei dati di addestramento.

Ogni sito Jamdesk genera `llms.txt` e `llms-full.txt` seguendo la specifica [llmstxt.org](https://llmstxt.org). Gli strumenti AI leggono questi file invece di eseguire il crawling delle singole pagine.

<Note>
  Google ora verifica `llms.txt` nell'ambito dei [controlli di navigazione agentica di Lighthouse](https://developer.chrome.com/docs/lighthouse/agentic-browsing/llms-txt). I siti che pubblicano un `llms.txt` valido sono più facilmente individuabili dagli agenti AI e, sempre più spesso, anche da Google quando classifica i contenuti per le risposte basate sull'AI. Jamdesk ti offre questa funzionalità gratuitamente.
</Note>

<Tip>
  **Controlla il tuo punteggio.** Scopri quanto un sito di documentazione è pronto per gli agenti con lo strumento gratuito [AI Score](https://jamdesk.com/ai-score). La pubblicazione di un `llms.txt` valido è uno dei primi elementi verificati. È disponibile anche un'[estensione Chrome AI Score](https://chromewebstore.google.com/detail/jamdesk-ai-score/mhihkkgpcbmapmojnakhjfhjmiagkhlj) per valutare i siti mentre navighi.
</Tip>

## Cosa genera Jamdesk

| File | Contenuto |
|------|---------|
| `llms.txt` | Titoli, descrizioni e URL delle pagine (un indice strutturato) |
| `llms-full.txt` | Contenuto completo della documentazione in un singolo file |

Jamdesk genera entrambi i file durante il build e li distribuisce dalla stessa CDN della documentazione.

## Verifica i file

Verifica che i file esistano dopo il primo build:

<Tabs>
  <Tab title="Dominio principale">
    Se la documentazione si trova nella radice del dominio (ad esempio `docs.acme.com` o `acme.jamdesk.app`):

    ```bash
    curl https://docs.acme.com/llms.txt
    curl https://docs.acme.com/llms-full.txt
    ```
  </Tab>
  <Tab title="/docs come sottopercorso">
    Se la documentazione si trova in `/docs` sul sito principale, come in questo sito su `jamdesk.com/docs`:

    ```bash
    curl https://jamdesk.com/docs/llms.txt
    curl https://jamdesk.com/docs/llms-full.txt
    ```
  </Tab>
</Tabs>

## Formato dei file

Il file `llms.txt` elenca ogni pagina con il relativo titolo, la descrizione e l'URL, raggruppati in sezioni che rispecchiano la navigazione:

```text
# Your Project Documentation

> Documentation for Your Project

## Get Started

- [Getting Started](https://your-project.jamdesk.app/getting-started): Set up your first project in 5 minutes
- [Configuration](https://your-project.jamdesk.app/configuration): Configure your project settings

## API Reference

- [Authentication](https://your-project.jamdesk.app/authentication): How to authenticate API requests
```

Il file `llms-full.txt` contiene il contenuto Markdown completo di ogni pagina, concatenato con i limiti tra le pagine indicati dai titoli.

## Struttura

`llms.txt` segue la proposta [llmstxt.org](https://llmstxt.org/): un titolo H1,
un riepilogo in un blocco citazione e le schede e i gruppi di navigazione come sezioni `##` di
link Markdown.

## Siti multilingue

I siti con più lingue ricevono un set separato di file per ogni
lingua, così uno strumento AI può recuperare solo la lingua necessaria. Per un sito in
inglese (la lingua predefinita) e francese:

| URL | Contenuto |
|-----|---------|
| `/llms.txt` | Indice inglese, con link all'indice di ogni altra lingua alla fine |
| `/fr/llms.txt` | Indice francese, con link alle altre lingue |
| `/llms-full.txt` | Contenuto completo di ogni lingua, una dopo l'altra |
| `/en/llms-full.txt` | Solo il contenuto delle pagine in inglese |
| `/fr/llms-full.txt` | Solo il contenuto delle pagine in francese |

Il file `llms-full.txt` nella radice mantiene tutte le lingue, quindi per gli strumenti che lo leggono già non cambia nulla. Indirizza un agente al file specifico della lingua quando ha bisogno solo di quella lingua:

```bash
curl https://jamdesk.com/docs/fr/llms-full.txt
```

Una lingua riceve i propri file non appena contiene almeno una pagina. I siti con una sola lingua mantengono solo i file nella radice.

## Direttiva per gli agenti su ogni pagina

Ogni pagina contiene anche una nota invisibile e non annunciata agli screen reader per gli agenti AI, che li indirizza a `llms.txt`; inoltre, ogni esportazione Markdown inizia con un blocco citazione che collega all'indice. Gli agenti che arrivano sul tuo HTML trovano il percorso Markdown senza eseguire il crawling.

## Come viene creato

- Generato durante il build insieme al tuo HTML
- Distribuito dalla CDN con la stessa policy di cache della documentazione
- Aggiornato automaticamente a ogni build
- Nessuna configurazione necessaria; tutte le pagine sono incluse per impostazione predefinita

## Disattiva llms.txt

`llms.txt` e `llms-full.txt` vengono pubblicati per impostazione predefinita. Per interromperne la generazione (ad esempio, se non vuoi che gli strumenti AI acquisiscano i tuoi contenuti), imposta `seo.ai.llmsTxt` su `false` nel tuo `docs.json`:

```json docs.json
{
  "seo": {
    "ai": {
      "llmsTxt": false
    }
  }
}
```

Al build successivo, Jamdesk ignora entrambi i file, comprese tutte le copie per lingua, e gli URL attivi `/llms.txt` e `/llms-full.txt` restituiscono `404`.

<Note>
  **L'acquisizione da parte dell'AI e l'indicizzazione della ricerca sono controlli separati.** `seo.ai.llmsTxt` gestisce solo i file `llms.txt`/`llms-full.txt` letti dagli strumenti AI. Non modifica il modo in cui i motori di ricerca indicizzano il sito; questo è gestito dai [metadati `robots` e dal `noindex` per pagina](/it/content/seo#controllo-dellindicizzazione). Una pagina può essere indicizzata da Google pur essendo esclusa dall'acquisizione AI, o viceversa.
</Note>

## Crawler AI

Il file `robots.txt` predefinito di Jamdesk consente l'accesso a tutti i principali crawler AI (Claude, ChatGPT, Copilot, Gemini). La documentazione è accessibile agli strumenti AI senza configurazioni aggiuntive.

<Accordion title="In cosa llms.txt differisce da sitemap.xml">
  `sitemap.xml` elenca gli URL che i motori di ricerca devono sottoporre a crawling e indicizzare. Non include contenuti, ma solo link e metadati come le date dell'ultima modifica.

  `llms.txt` è progettato per i modelli AI. Include i titoli e le descrizioni delle pagine e, in `llms-full.txt`, il contenuto effettivo. Gli strumenti AI possono leggere il file completo per comprendere la documentazione senza effettuare più richieste HTTP.
</Accordion>
