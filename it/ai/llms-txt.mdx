Se vuoi che strumenti di AI come ChatGPT, Claude o Copilot forniscano risposte accurate sul tuo prodotto, devono accedere alla tua documentazione in modo strutturato, non solo utilizzare ciò che è finito nei dati di addestramento.

Ogni sito Jamdesk genera `llms.txt` e `llms-full.txt` seguendo la specifica [llmstxt.org](https://llmstxt.org). Gli strumenti di AI leggono questi file invece di eseguire il crawling delle singole pagine.

<Note>
  Google ora controlla `llms.txt` nell'ambito dei [controlli di navigazione agentica di Lighthouse](https://developer.chrome.com/docs/lighthouse/agentic-browsing/llms-txt). I siti che pubblicano un `llms.txt` valido sono più facilmente individuabili dagli agenti di AI e, sempre più spesso, da Google stesso quando classifica i contenuti per le risposte basate sull'AI. Jamdesk te lo offre gratuitamente.
</Note>

<Tip>
  **Controlla il tuo punteggio.** Scopri quanto è pronto per gli agenti un sito di documentazione qualsiasi con lo strumento gratuito [AI Score](https://jamdesk.com/ai-score). La pubblicazione di un `llms.txt` valido è una delle prime verifiche che esegue. È disponibile anche un'[estensione AI Score per Chrome](https://chromewebstore.google.com/detail/jamdesk-ai-score/mhihkkgpcbmapmojnakhjfhjmiagkhlj) per valutare i siti durante la navigazione.
</Tip>

## Cosa genera Jamdesk

| File | Contenuto |
|------|-----------|
| `llms.txt` | Titoli, descrizioni e URL delle pagine (un indice strutturato) |
| `llms-full.txt` | Contenuto completo della documentazione in un unico file |

Jamdesk genera entrambi durante la build e li distribuisce dallo stesso CDN della documentazione.

## Verifica i file

Verifica che i file esistano dopo la prima build:

<Tabs>
  <Tab title="Dominio principale">
    Se la documentazione si trova nella radice del dominio (ad esempio `docs.acme.com` o `acme.jamdesk.app`):

    ```bash
    curl https://docs.acme.com/llms.txt
    curl https://docs.acme.com/llms-full.txt
    ```
  </Tab>
  <Tab title="Sottopercorso /docs">
    Se la documentazione si trova in `/docs` sul sito principale (come in questo sito, all'indirizzo `jamdesk.com/docs`):

    ```bash
    curl https://jamdesk.com/docs/llms.txt
    curl https://jamdesk.com/docs/llms-full.txt
    ```
  </Tab>
</Tabs>

## Formato dei file

Il file `llms.txt` elenca ogni pagina con il relativo titolo, la descrizione e l'URL, raggruppati in sezioni che rispecchiano la navigazione:

```text
# Your Project Documentation

> Documentation for Your Project

## Get Started

- [Getting Started](https://your-project.jamdesk.app/getting-started): Set up your first project in 5 minutes
- [Configuration](https://your-project.jamdesk.app/configuration): Configure your project settings

## API Reference

- [Authentication](https://your-project.jamdesk.app/authentication): How to authenticate API requests
```

Il file `llms-full.txt` contiene il contenuto Markdown completo di ogni pagina, concatenato con i limiti tra le pagine indicati dai titoli.

## Struttura

`llms.txt` segue la proposta [llmstxt.org](https://llmstxt.org/): un titolo H1,
un riepilogo in blockquote e le schede e i gruppi della navigazione come sezioni `##` di
link Markdown.

## Siti multilingue

I siti con più di una lingua ricevono un set separato di file per ogni lingua, così uno strumento di AI può recuperare solo la lingua necessaria. Per un sito in inglese (predefinito) e francese:

| URL | Contenuto |
|-----|-----------|
| `/llms.txt` | Indice inglese, con link all'indice di ogni altra lingua alla fine |
| `/en/llms.txt` | Stesso file di `/llms.txt` |
| `/fr/llms.txt` | Indice francese, con link alle altre lingue |
| `/llms-full.txt` | Contenuto completo di ogni lingua, una dopo l'altra |
| `/en/llms-full.txt` | Solo contenuto completo delle pagine in inglese |
| `/fr/llms-full.txt` | Solo contenuto completo delle pagine in francese |

Il file radice `llms-full.txt` mantiene tutte le lingue, quindi gli strumenti che già lo leggono non rilevano cambiamenti. Indirizza un agente al file della lingua specifica quando gli serve solo quella lingua:

```bash
curl https://jamdesk.com/docs/fr/llms-full.txt
```

Una lingua riceve file propri non appena contiene almeno una pagina. I siti con una sola lingua mantengono solo i file radice.

## Direttiva per gli agenti su ogni pagina

Ogni pagina contiene anche una nota invisibile e non udibile dagli screen reader per gli agenti di AI, che rimanda a `llms.txt`, e ogni esportazione Markdown inizia con un link all'indice in blockquote. Gli agenti che raggiungono il tuo HTML trovano il percorso Markdown senza eseguire il crawling.

## Come viene creato

- Generato durante la build insieme al tuo HTML
- Distribuito dal CDN con la stessa policy di cache della documentazione
- Aggiornato automaticamente a ogni build
- Nessuna configurazione necessaria; tutte le pagine sono incluse per impostazione predefinita

## Disattiva llms.txt

`llms.txt` e `llms-full.txt` vengono pubblicati per impostazione predefinita. Per interromperne la generazione (ad esempio, se non vuoi che gli strumenti di AI acquisiscano i tuoi contenuti), imposta `seo.ai.llmsTxt` su `false` nel tuo `docs.json`:

```json docs.json
{
  "seo": {
    "ai": {
      "llmsTxt": false
    }
  }
}
```

Alla build successiva, Jamdesk salta entrambi i file, incluse tutte le copie per lingua, e gli URL attivi `/llms.txt` e `/llms-full.txt` restituiscono `404`.

<Note>
  **L'acquisizione da parte dell'AI e l'indicizzazione nei motori di ricerca sono controlli separati.** `seo.ai.llmsTxt` controlla solo i file `llms.txt`/`llms-full.txt` letti dagli strumenti di AI. Non modifica il modo in cui i motori di ricerca indicizzano il sito; questo è controllato dai [metadati `robots` e da `noindex` per pagina](/it/content/seo#controllo-dellindicizzazione). Una pagina può essere indicizzata da Google pur essendo esclusa dall'acquisizione dell'AI, o viceversa.
</Note>

## Crawler AI

Il `robots.txt` predefinito di Jamdesk consente l'accesso a tutti i principali crawler di AI (Claude, ChatGPT, Copilot, Gemini). La documentazione è accessibile agli strumenti di AI senza configurazione aggiuntiva.

<Accordion title="In che modo llms.txt è diverso da sitemap.xml">
  `sitemap.xml` elenca gli URL che i motori di ricerca devono sottoporre a crawling e indicizzare. Non include contenuti, ma solo link e metadati come le date dell'ultima modifica.

  `llms.txt` è progettato per i modelli di AI. Include titoli e descrizioni delle pagine e, in `llms-full.txt`, il contenuto effettivo. Gli strumenti di AI possono leggere il file completo per comprendere la documentazione senza effettuare più richieste HTTP.
</Accordion>
