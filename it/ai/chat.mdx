Ogni sito Jamdesk include un assistente chat che risponde alle domande dei visitatori attingendo alla documentazione. Recupera le sezioni pertinenti, le invia a Claude e trasmette una risposta con link alle pagine di origine. La chat è attiva per impostazione predefinita in tutti i piani, senza costi aggiuntivi.

## Casi d'uso

<Tabs>
  <Tab title="Onboarding API">
    Uno sviluppatore che integra la tua API chiede *"Come autentico le richieste?"* e riceve i passaggi esatti con un esempio di codice, oltre a un link alla pagina di origine.
  </Tab>
  <Tab title="Risoluzione dei problemi">
    *"La build non riesce a causa di un errore di timeout"*

    Invece di consultare più pagine, il visitatore trova in pochi secondi la soluzione pertinente nella guida alla risoluzione dei problemi.
  </Tab>
  <Tab title="Riferimento rapido">
    Gli utenti abituali chiedono, ad esempio, *"Quali parametri accetta l'endpoint /users?"* e la chat recupera la documentazione dell'endpoint e restituisce direttamente la tabella dei parametri.
  </Tab>
</Tabs>

## Come funziona

<Steps>
  <Step title="La build indicizza la documentazione">
    Durante ogni build, Jamdesk suddivide le pagine in sezioni e le archivia come embedding ricercabili.
  </Step>
  <Step title="Il visitatore pone una domanda">
    Il pulsante "Ask AI" (o Cmd+I / Ctrl+I) apre un pannello chat in qualsiasi pagina.
  </Step>
  <Step title="L'AI risponde basandosi sulla documentazione">
    Le sezioni pertinenti vengono recuperate e inviate a Claude come contesto; la risposta viene trasmessa con link alle pagine di origine citate.
  </Step>
</Steps>

## Funzionalità

| Funzionalità | Dettaglio |
|---------|--------|
| Risposte in streaming | Le risposte arrivano in tempo reale |
| Link alle citazioni | Ogni risposta rimanda alle pagine della documentazione da cui è stata ricavata |
| Disambiguazione | Se una domanda corrisponde a più argomenti, l'AI chiede a quale si riferisce il visitatore |
| Contesto della conversazione | Cronologia di 10 messaggi, salvata per scheda del browser |
| Domande suggerite | Generate automaticamente dalla documentazione oppure personalizzabili in docs.json |
| Scorciatoie da tastiera | Cmd+I / Ctrl+I per attivare o disattivare, Escape per chiudere |
| Rendering Markdown | I blocchi di codice, le tabelle e gli elenchi vengono visualizzati nelle risposte |

## Configurazione

La chat funziona subito, senza bisogno di configurazione. Aggiungi un blocco `chat` a `docs.json` solo se vuoi personalizzare le domande suggerite, rinominare il pulsante, cambiarne l'icona o disattivare la chat. Il campo `chat` è facoltativo e ogni impostazione ha un valore predefinito.

```json docs.json
{
  "chat": {
    "enabled": true,
    "starterQuestions": [
      "How do I get started?",
      "What API endpoints are available?"
    ]
  }
}
```

| Campo | Tipo | Predefinito | Descrizione |
|-------|------|---------|-------------|
| `enabled` | boolean | `true` | Imposta su `false` per rimuovere dal sito il pulsante Ask AI, il pannello chat e la scorciatoia da tastiera |
| `starterQuestions` | string[] | auto-generated | Fino a 4 domande visualizzate all'apertura del pannello (da 5 a 200 caratteri ciascuna). Se omesse, vengono generate automaticamente dalla documentazione; imposta `[]` per non mostrarne nessuna |
| `label` | string | "Ask AI" in the page's language | Sostituisce "Ask AI" sul pulsante della chat, nell'intestazione del pannello e nella scorciatoia di ricerca. Fino a 40 caratteri. Si applica a tutte le lingue. |
| `icon` | string | `sparkles` | Un nome di icona Font Awesome, un URL di immagine o il percorso di un'immagine nel progetto. Un'icona Font Awesome segue il colore principale; un'immagine viene mostrata così com'è, quindi scegline una visibile su sfondi chiari e scuri. |

### Domande suggerite

Le domande suggerite sono prompt proposti nel pannello chat prima che il visitatore scriva: esempi selezionabili con un clic che suggeriscono cosa chiedere. Se ometti `starterQuestions` da `docs.json`, Jamdesk le genera automaticamente dalla documentazione a ogni build, così restano pertinenti man mano che la documentazione cresce.

Per impostare le tue domande, inseriscile nell'array `starterQuestions`. È utile quando il team di assistenza riceve spesso le stesse domande e vuoi metterle in evidenza:

```json docs.json
{
  "chat": {
    "starterQuestions": [
      "How do notifications work?",
      "Tell me more about analytics"
    ]
  }
}
```

Puoi impostare fino a 4 domande suggerite, ciascuna da 5 a 200 caratteri. Per non mostrarne nessuna, imposta `starterQuestions` su un array vuoto (`[]`).

### Nome e icona personalizzati

Per impostazione predefinita, il pulsante della chat, l'intestazione del pannello e la scorciatoia di ricerca mostrano "Ask AI" e usano un'icona con scintille. Imposta `label` e `icon` in base al tuo prodotto:

```json docs.json
{
  "chat": {
    "label": "Acme Assistant",
    "icon": "/images/assistant.svg"
  }
}
```

L'etichetta è la stessa in tutte le lingue del sito. Un valore di `icon` come `robot` è un nome Font Awesome. Un valore che inizia con `http://`, `https://` o `/`, oppure termina con un'estensione di immagine, viene trattato come un'immagine.

### Disattivare la chat

La chat è attiva per impostazione predefinita in tutti i piani. Per disattivarla, imposta `enabled` su `false`. In questo modo rimuovi il pulsante Ask AI, il pannello chat e la scorciatoia `Cmd+I` / `Ctrl+I`:

```json docs.json
{
  "chat": {
    "enabled": false
  }
}
```

<Note>
Disattivare la chat non influisce sulla ricerca. La chat AI e la ricerca sono funzionalità separate, quindi la documentazione resta completamente consultabile anche quando la chat è disattivata.
</Note>

## Limiti

| Limite | Valore |
|-------|-------|
| Lunghezza massima del messaggio | 2,000 caratteri |
| Lunghezza massima della risposta | 2,048 token |
| Limite di frequenza | 10 richieste / 60 secondi per visitatore e per sito |
| Cronologia della conversazione | 10 messaggi per scheda |
| Domande suggerite | 4 al massimo |

La chat funziona sui [domini personalizzati](/it/deploy/custom-domains). L'endpoint `/_chat` è della stessa origine, quindi funziona su qualsiasi dominio che ospiti la documentazione.

<Accordion title="Come funziona la pipeline di recupero">
  Durante ogni build, Jamdesk suddivide le pagine in sezioni e archivia embedding vettoriali per ciascuna. Quando un visitatore pone una domanda, il sistema esegue una ricerca ibrida (che combina la corrispondenza delle parole chiave con la somiglianza semantica) per trovare le sezioni più pertinenti nella documentazione. Queste sezioni vengono inviate a Claude come contesto, con istruzioni per rispondere solo in base alla documentazione fornita. Le citazioni vengono estratte confrontando i riferimenti alle pagine nella risposta di Claude con le sezioni recuperate.
</Accordion>
