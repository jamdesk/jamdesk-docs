Aggiungi Google Analytics 4 al tuo sito di documentazione per capire come i lettori usano i tuoi contenuti.

<Info>
L'integrazione accetta ID di misurazione GA4 (Google Analytics 4) che iniziano con `G-`.
</Info>

## Ottenere il tuo ID di misurazione

1. Vai su [Google Analytics](https://analytics.google.com/)
2. Seleziona la tua proprietà (oppure creane una)
3. Vai su **Admin** → **Data Streams**
4. Seleziona il tuo flusso web (oppure creane uno)
5. Copia il **Measurement ID** (inizia con `G-`)

## Aggiungere GA4 alla documentazione

Aggiungi l'ID di misurazione al tuo `docs.json`:

```json docs.json
{
  "name": "My Docs",
  "integrations": {
    "ga4": {
      "measurementId": "G-XXXXXXXXXX"
    }
  }
}
```

Sostituisci `G-XXXXXXXXXX` con il tuo ID di misurazione.

## Visualizzare i dati

Verifica che i dati arrivino:

1. Avvia una nuova build della tua documentazione
2. Visita il tuo sito di documentazione pubblicato
3. In Google Analytics, vai su **Reports** → **Real-time**
4. La tua visita compare entro 30 secondi

<Note>
I dati possono impiegare 24-48 ore per comparire nei report standard. Usa i report Real-time per una verifica immediata.
</Note>

## Utilizzare Google Tag Manager

Se usi già Google Tag Manager, configura GA4 tramite GTM invece di aggiungerlo direttamente. Consulta [Integrazione Google Tag Manager](/it/integrations/google-tag-manager) per i dettagli.

Configura tu stesso i banner di consenso ai cookie per tutti i tag che carichi tramite Google Tag Manager. Jamdesk carica il tuo container GTM per tutti i visitatori senza un vincolo di consenso. Consulta [Consenso ai cookie](/it/integrations/cookie-consent) per bloccare l'analisi finché i visitatori non acconsentono.

<Warning>
Non aggiungere la stessa proprietà GA4 sia direttamente in `docs.json` sia tramite Google Tag Manager. Questo causa un tracciamento duplicato.
</Warning>

## Considerazioni sulla privacy

Google Analytics raccoglie dati dei visitatori. Valuta:

- Aggiungere un banner di consenso ai cookie se si applicano GDPR/CCPA. Jamdesk carica GA4 per ogni visitatore per impostazione predefinita. [Consenso ai cookie](/it/integrations/cookie-consent) lo blocca finché non acconsentono.
- Aggiornare la tua informativa sulla privacy per menzionare l'analisi
- Usare [l'anonimizzazione dell'IP](https://support.google.com/analytics/answer/2763052) se necessario

## Risoluzione dei problemi

<Accordion title="Non vedo alcun dato">
  1. **Verifica il tuo ID di misurazione**: deve iniziare con `G-`
  2. **Controlla gli ad blocker**: potrebbero bloccare gli script di analisi
  3. **Attendi la nuova build**: le modifiche richiedono una nuova build per avere effetto
  4. **Usa i report Real-time**: i report standard hanno un ritardo di 24-48 ore
</Accordion>

<Accordion title="Errore 'Invalid Measurement ID'">
  L'ID deve:
  - Iniziare con `G-`
  - Contenere solo lettere e numeri dopo `G-`
  - Essere copiato esattamente da Google Analytics (senza spazi extra)
</Accordion>
