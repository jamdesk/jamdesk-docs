Aggiungi Google Analytics 4 al tuo sito di documentazione per comprendere come gli utenti interagiscono con i tuoi contenuti.

<Info>
L'integrazione di Google Analytics funziona con gli ID di misurazione GA4 (Google Analytics 4) che iniziano con `G-`.
</Info>

## Ottenere il tuo ID di misurazione

1. Vai a [Google Analytics](https://analytics.google.com/)
2. Seleziona la tua proprietà (oppure creane una)
3. Vai a **Admin** → **Data Streams**
4. Seleziona il tuo flusso web (oppure creane uno)
5. Copia il **Measurement ID** (inizia con `G-`)

## Aggiungere GA4 alla documentazione

Aggiungi l'ID di misurazione al tuo `docs.json`:

```json docs.json
{
  "name": "My Docs",
  "integrations": {
    "ga4": {
      "measurementId": "G-XXXXXXXXXX"
    }
  }
}
```

Sostituisci `G-XXXXXXXXXX` con il tuo ID di misurazione effettivo.

## Visualizzare i dati

Dopo aver aggiunto l'integrazione:

1. Avvia una nuova build della documentazione
2. Visita il sito di documentazione pubblicato
3. In Google Analytics, vai a **Reports** → **Real-time**
4. Dovresti vedere la tua visita entro 30 secondi

<Note>
La visualizzazione dei dati nei report standard può richiedere 24-48 ore. Usa i report Real-time per una verifica immediata.
</Note>

## Utilizzare Google Tag Manager

Se utilizzi già Google Tag Manager, puoi configurare GA4 tramite GTM invece di aggiungerlo direttamente. Consulta [Integrazione Google Tag Manager](/it/integrations/google-tag-manager) per maggiori dettagli.

Se necessario, devi configurare i banner per il consenso ai cookie per tutti i tag caricati tramite Google Tag Manager. Jamdesk carica il tuo container GTM per tutti i visitatori senza un controllo del consenso. Consulta [Consenso ai cookie](/it/integrations/cookie-consent) per bloccare l'analytics finché i visitatori non prestano il consenso.

<Warning>
Non aggiungere la stessa proprietà GA4 direttamente in `docs.json` e tramite Google Tag Manager, perché ciò causerebbe un monitoraggio duplicato.
</Warning>

## Considerazioni sulla privacy

Google Analytics raccoglie i dati dei visitatori. Valuta di:

- Aggiungere un banner per il consenso ai cookie se si applica il GDPR/CCPA. Per impostazione predefinita, Jamdesk carica GA4 per ogni visitatore: usa quindi [Consenso ai cookie](/it/integrations/cookie-consent) per bloccarlo finché non presta il consenso.
- Aggiornare la tua informativa sulla privacy per menzionare l'analytics
- Usare l'[anonimizzazione IP](https://support.google.com/analytics/answer/2763052) se necessario

## Risoluzione dei problemi

<Accordion title="Nessun dato visualizzato">
  1. **Verifica il tuo ID di misurazione** - Deve iniziare con `G-`
  2. **Controlla i blocchi pubblicità** - Potrebbero bloccare gli script di analytics
  3. **Attendi la nuova build** - Le modifiche richiedono una nuova build per diventare effettive
  4. **Usa i report Real-time** - I report standard hanno un ritardo di 24-48 ore
</Accordion>

<Accordion title="Errore «Invalid Measurement ID»">
  L'ID deve:
  - Iniziare con `G-`
  - Contenere solo lettere e numeri dopo `G-`
  - Essere copiato esattamente da Google Analytics (senza spazi aggiuntivi)
</Accordion>
