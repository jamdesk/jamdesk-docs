title: Provider di supporto e chat
description: >-
  Aggiungi Intercom o Front Chat alla documentazione Jamdesk configurando appId o
  snippetId nella sezione integrations di docs.json, con consenso opzionale.
---

Jamdesk può caricare un widget di chat in tempo reale su ogni pagina del tuo sito di documentazione. Aggiungi il blocco del provider in `integrations` in `docs.json` e Jamdesk inserirà automaticamente lo script del widget.

<Info>
Ogni valore viene verificato rispetto a un formato rigoroso prima che Jamdesk carichi il widget. Un valore con formato errato viene ignorato senza notifica e non viene mai visualizzato: nessuna pagina di errore e nessun tag script non funzionante.
</Info>

## Configura dal dashboard

Il modo più rapido per configurare uno dei due: **Dashboard → Integrations**. Seleziona la scheda del provider, incolla il relativo ID e Jamdesk eseguirà il commit del blocco `docs.json` per te, avviando una nuova build (solo per i progetti connessi a GitHub). Le sezioni seguenti servono per modificare direttamente `docs.json` o per i progetti gestiti solo tramite CLI.

## Intercom

**Formato:** l'ID dell'app contiene da 6 a 16 lettere o numeri.

<Info>
Trova l'ID dell'app in **Settings → Installation → Web** in Intercom: è l'ID del tuo spazio di lavoro.
</Info>

```json docs.json
{
  "integrations": {
    "intercom": {
      "appId": "abc12345"
    }
  }
}
```

## Front Chat

**Formato:** l'ID della chat contiene da 8 a 64 caratteri esadecimali minuscoli (`0-9`, `a-f`).

```json docs.json
{
  "integrations": {
    "frontchat": {
      "snippetId": "3f8a2e1c9b6d4a7f"
    }
  }
}
```

## Controllo del consenso

Entrambi i widget rispettano `integrations.cookies`. Quando è impostato, lo script della chat non viene caricato finché il banner del consenso non registra l'approvazione. Consulta [Cookie Consent](/it/integrations/cookie-consent) per la configurazione completa. Senza questa impostazione, il widget viene caricato per ogni visitatore al caricamento della pagina.
