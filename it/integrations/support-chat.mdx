title: Chat di supporto e provider

  Aggiungi Intercom o Front Chat alla documentazione Jamdesk configurando appId o snippetId in integrations nel docs.json, con consenso facoltativo.
---

Jamdesk può caricare un widget di live chat su ogni pagina del tuo sito di documentazione. Aggiungi il blocco del provider sotto `integrations` in `docs.json`. Jamdesk inserisce lo script del widget.

<Info>
Jamdesk verifica ogni valore con un formato rigoroso prima di caricare il widget. Un valore con formato errato viene ignorato silenziosamente. Non ricevi alcun messaggio di errore né un tag script rotto.
</Info>

## Configura dal dashboard

Apri **Dashboard → Integrations**, scegli la scheda del provider e incolla il suo ID. Jamdesk salva il blocco in `docs.json` e avvia una nuova build (solo per i progetti collegati a GitHub). Usa le sezioni seguenti per modificare `docs.json` direttamente, oppure per i progetti gestiti solo tramite CLI.

## Intercom

**Formato:** l'App ID è composto da 6-16 lettere o numeri.

<Info>
Trovi il tuo App ID in **Settings → Installation → Web** in Intercom. È l'ID del tuo workspace.
</Info>

```json docs.json
{
  "integrations": {
    "intercom": {
      "appId": "abc12345"
    }
  }
}
```

## Front Chat

**Formato:** il Chat ID è composto da 8-64 caratteri esadecimali minuscoli (`0-9`, `a-f`).

```json docs.json
{
  "integrations": {
    "frontchat": {
      "snippetId": "3f8a2e1c9b6d4a7f"
    }
  }
}
```

## Controllo del consenso

I widget Intercom e Front Chat rispettano `integrations.cookies`. Se è impostato, lo script della chat attende che il banner del consenso registri l'approvazione. Per la configurazione, consulta [Cookie Consent](/it/integrations/cookie-consent). Senza questa impostazione, il widget si carica per ogni visitatore al caricamento della pagina.
