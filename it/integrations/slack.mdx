Collega Slack per ricevere notifiche di build nel canale del tuo team.

<Note>
L'integrazione Slack è disponibile nei piani Pro.
</Note>

## Configurazione di Slack

<Steps>
  <Step title="Crea un webhook Slack">
    In Slack:
    1. Vai alle impostazioni del tuo workspace
    2. Passa a **Apps** → **Incoming Webhooks**
    3. Clicca **Add to Slack**
    4. Scegli un canale
    5. Copia l'URL del webhook
  </Step>
  <Step title="Aggiungi a Jamdesk">
    Nel tuo progetto Jamdesk:
    1. Vai a **Integrations**
    2. Clicca **Connect Slack**
    3. Incolla l'URL del tuo webhook
    4. Clicca **Save**
  </Step>
  <Step title="Testa la connessione">
    Clicca **Send Test** per verificare che l'integrazione funzioni.
  </Step>
</Steps>

## Preferenze delle notifiche

Scegli quali esiti di build attivano le notifiche:

| Evento | Predefinito | Descrizione |
|-------|---------|-------------|
| Build succeeded | Attivo | Notifica quando una build si completa con successo |
| Build failed | Attivo | Notifica quando una build fallisce |

Attiva o disattiva le caselle e clicca **Update** per modificare le preferenze dopo la configurazione.

## Formato dei messaggi

Le notifiche includono:

- Nome del progetto
- Stato della build
- Messaggio di commit e autore
- Link ai dettagli della build
- Durata (per le build completate)

Esempio:
``` text
✓ Docs build succeeded
Project: My Docs
Commit: "Add authentication guide" by @username
Duration: 45s
View build →
```

## Disconnessione da Slack

Per disconnettere:

1. Vai a **Integrations**
2. Clicca **Disconnect** accanto a Slack
3. Conferma la rimozione

## Risoluzione dei problemi

<Accordion title="Le notifiche non compaiono">
  1. Verifica che l'URL del webhook sia corretto
  2. Controlla che il canale esista ancora
  3. Invia una notifica di test
  4. Controlla le impostazioni dei webhook in entrata di Slack
</Accordion>

<Accordion title="Le preferenze modificate non vengono salvate">
  Clicca il pulsante **Update** che compare dopo aver attivato o disattivato una casella. Le modifiche non vengono salvate automaticamente.
</Accordion>
