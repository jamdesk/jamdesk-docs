Collega Slack per ricevere notifiche dei build direttamente nel canale del tuo team.

<Note>
L'integrazione Slack è disponibile nei piani Pro.
</Note>

## Configurazione di Slack

<Steps>
  <Step title="Crea un Webhook Slack">
    In Slack:
    1. Vai alle impostazioni del tuo workspace
    2. Vai a **Apps** → **Incoming Webhooks**
    3. Fai clic su **Add to Slack**
    4. Scegli un canale
    5. Copia l'URL del Webhook
  </Step>
  <Step title="Aggiungi a Jamdesk">
    Nel tuo progetto Jamdesk:
    1. Vai a **Integrations**
    2. Fai clic su **Connect Slack**
    3. Incolla l'URL del tuo Webhook
    4. Fai clic su **Save**
  </Step>
  <Step title="Testa la connessione">
    Fai clic su **Send Test** per verificare che l'integrazione funzioni.
  </Step>
</Steps>

## Preferenze delle notifiche

Scegli quali risultati dei build attivano le notifiche:

| Evento | Predefinito | Descrizione |
|-------|---------|-------------|
| Build riuscito | On | Invia una notifica quando un build viene completato correttamente |
| Build non riuscito | On | Invia una notifica quando un build non riesce |

Entrambe le opzioni sono abilitate per impostazione predefinita. Per modificare le preferenze dopo la configurazione, attiva o disattiva le caselle di controllo e fai clic su **Update**.

## Formato dei messaggi

Le notifiche includono:

- Nome del progetto
- Stato del build
- Messaggio del commit e autore
- Link ai dettagli del build
- Durata (per i build completati)

Esempio:
``` text
✓ Docs build succeeded
Project: My Docs
Commit: "Add authentication guide" by @username
Duration: 45s
View build →
```

## Disconnessione da Slack

Per disconnettere Slack:

1. Vai a **Integrations**
2. Fai clic su **Disconnect** accanto a Slack
3. Conferma la rimozione

## Risoluzione dei problemi

<Accordion title="Le notifiche non vengono visualizzate">
  1. Verifica che l'URL del Webhook sia corretto
  2. Verifica che il canale esista ancora
  3. Invia una notifica di test
  4. Controlla le impostazioni dei Webhook in entrata di Slack
</Accordion>

<Accordion title="Le preferenze modificate non vengono salvate">
  Dopo aver attivato o disattivato le caselle di controllo delle notifiche, fai clic sul pulsante **Update** visualizzato. Le modifiche non vengono salvate automaticamente.
</Accordion>
