## Sign In

Use the same credentials as the [web dashboard](https://dashboard.jamdesk.com):

- Email and password
- Google Sign-In

Face ID or Touch ID unlocks the app after your first sign-in.

## Push Notifications

Opt in or out under **Settings** in the app:

- **Build success**: a deploy completes.
- **Build failure**: a build breaks. The notification includes the error message.

Notification preferences are per device. Alerts can go to your phone and skip your tablet.

## Read-Only by Design

The mobile app does not trigger rebuilds. Builds start when you push to your Git provider. Start a manual rebuild from the [web dashboard](https://dashboard.jamdesk.com). The app is a monitor, not a control panel.

Use the web dashboard to change project settings, invite members, rotate API keys, or trigger a manual rebuild.

## Privacy

The app talks directly to the same Firebase backend as the web dashboard. There is no separate API layer and no analytics relay collecting your activity. Your project data never leaves Jamdesk infrastructure.
