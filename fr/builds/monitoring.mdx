Chaque build passe par plusieurs phases, de la file d'attente à la mise en ligne. Suivez la progression depuis l'onglet Déploiements.

## Phases de Build

<Steps>
  <Step title="En file d'attente">
    Le build attend de démarrer. La plupart des builds démarrent en quelques secondes.
  </Step>
  <Step title="Clonage">
    Récupération du contenu de votre dépôt depuis GitHub.
  </Step>
  <Step title="Validation">
    Vérification de la configuration `docs.json` et de la syntaxe MDX.
  </Step>
  <Step title="Traitement">
    Analyse des fichiers MDX et résolution des imports.
  </Step>
  <Step title="Compilation">
    Compilation du MDX en HTML, application de la coloration syntaxique.
  </Step>
  <Step title="Déploiement">
    Téléversement vers le CDN et purge du cache.
  </Step>
  <Step title="En ligne">
    Build terminé. Votre documentation est mise à jour.
  </Step>
</Steps>

## Consultation du Statut de Build

### Vue d'ensemble du Dashboard

La page principale de votre projet affiche :

- Le statut du build actuel
- La date du dernier déploiement réussi
- L'historique récent des builds

### Détails du Build

Cliquez sur un build pour voir :

- Les heures de début et de fin
- La durée
- Le déclencheur (push, manuel, CLI)
- Le hash et le message du commit
- Le log de build complet

## Logs de Build

Les logs détaillés aident à déboguer les problèmes :

```text
[12:34:56] Starting build...
[12:34:57] Cloning repository...
[12:34:59] Found docs.json at root
[12:35:00] Validating configuration...
[12:35:01] Processing 45 pages...
[12:35:15] Building search index...
[12:35:18] Deploying to CDN...
[12:35:22] Build complete!
```

## Notifications de Build

Recevez des notifications sur le statut des builds :

### Email

Activez les alertes d'échec de build dans **Paramètres** → **Notifications**.

### Slack

Connectez Slack pour recevoir les notifications de build dans votre canal. Voir [Intégration Slack](/fr/integrations/slack).

## Historique des Builds

Consultez vos 30 derniers builds dans l'onglet **Déploiements** :

- Statut du build (succès, échec, annulé)
- Durée
- Type de déclencheur
- Informations sur le commit

## Annulation des Builds

Pour annuler un build en cours :

1. Accédez à l'onglet **Déploiements**
2. Trouvez le build en cours
3. Cliquez sur **Annuler**

Le précédent build réussi reste en ligne.
