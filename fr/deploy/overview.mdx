Jamdesk déploie automatiquement votre documentation sur un sous-domaine `*.jamdesk.app`. Lorsque vous êtes prêt à déployer sur votre propre domaine, vous pouvez choisir un sous-domaine personnalisé (comme `docs.example.com`) ou héberger sur un sous-chemin `/docs` de votre site principal.

## Options de déploiement

| Option | Idéal pour | Complexité de mise en place |
|--------|----------|------------------|
| **Sous-domaine Jamdesk** (`your-project.jamdesk.app`) | Lancement le plus rapide, aucune configuration DNS | Faible |
| **Sous-domaine personnalisé** (`docs.example.com`) | Documentation en production avec votre marque | Moyenne |
| **Hébergement en sous-chemin** (`example.com/docs`) | Garder la documentation sur le domaine principal | Élevée |

## Hébergement par défaut (aucune configuration)

Chaque projet est mis en ligne sur un sous-domaine Jamdesk dès que vous connectez un repo. C'est l'option la plus simple pour la documentation interne, les previews ou les lancements anticipés.

## Domaine personnalisé (sous-domaine)

Utilisez votre propre sous-domaine (par exemple, `docs.example.com`) pour une URL publique et à votre marque. Vous ajouterez des enregistrements DNS et vérifierez la propriété dans le dashboard Jamdesk.

<Note>
La vérification DNS et le SSL sont gérés automatiquement une fois les enregistrements en place. Voir [Domaines personnalisés](/fr/deploy/custom-domains) pour la configuration.
</Note>

## Hébergement en sous-chemin (/docs)

Hébergez la documentation sur `example.com/docs` en redirigeant le trafic vers Jamdesk via un proxy. C'est idéal lorsque vous souhaitez que la documentation reste sous votre domaine marketing principal.

<Info>
L'hébergement en sous-chemin nécessite une couche proxy ou CDN pour transmettre les requêtes et définir l'en-tête `X-Jamdesk-Forwarded-Host`. Voir [Hébergement en sous-chemin](/fr/deploy/subpath-hosting).
</Info>

### Exemple de configuration de proxy (nginx)

```nginx nginx.conf
location /docs {
    proxy_pass https://YOUR_SLUG.jamdesk.app;
    proxy_set_header X-Jamdesk-Forwarded-Host $host;
}

location /_next/ {
    proxy_pass https://YOUR_SLUG.jamdesk.app;
}

location /_jd/ {
    proxy_pass https://YOUR_SLUG.jamdesk.app;
}
```

Pour une configuration complète avec SSL, en-têtes et conseils spécifiques aux fournisseurs, consultez le guide [Hébergement en sous-chemin](/fr/deploy/subpath-hosting).
