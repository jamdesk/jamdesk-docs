Définissez `theme` dans `docs.json` pour contrôler la mise en page, la typographie, l'espacement et le comportement du mode sombre. Quatre thèmes sont disponibles : `jam` (par défaut), `nebula`, `pulsar` et `halo`.

Les captures d'écran montrent l'interface en anglais.

```json docs.json
{
  "theme": "jam"
}
```

<Tip>
Essayez chaque thème sur cette documentation avant de choisir. Sélectionnez-en un sous **Preview a theme** en haut de la barre latérale. Sur mobile, ouvrez le menu de navigation. Le preview dure jusqu'à la fermeture de votre navigateur.
</Tip>

## Typographie

Chaque thème regroupe des polices chargées depuis Google Fonts :

| Thème | Titres | Corps | Code |
|-------|----------|------|------|
| [Jam](https://jamdesk.com/docs/introduction) | Inter | Inter | JetBrains Mono |
| [Nebula](https://nebula.jamdesk.com) | IBM Plex Mono | IBM Plex Mono | IBM Plex Mono |
| [Pulsar](https://pulsar.jamdesk.com) | Inter | Inter | JetBrains Mono |
| [Halo](https://halo.jamdesk.com) | Figtree | Figtree | JetBrains Mono |

Nous recommandons les valeurs par défaut ; elles sont ajustées à chaque thème. Si vous souhaitez un rendu différent, définissez `fonts` dans `docs.json` pour remplacer la police de l'ensemble du site par une police Google :

```json
{
  "fonts": {
    "family": "Lora"
  }
}
```

Utilisez des polices distinctes pour les titres et le corps de texte :

```json
{
  "fonts": {
    "heading": { "family": "Space Grotesk" },
    "body": { "family": "Inter" }
  }
}
```

N'importe quelle police Google fonctionne. Définissez simplement `family` et le build la récupère automatiquement. Pour héberger vous-même une police personnalisée, ajoutez `source` (URL ou chemin relatif commençant par `/`) et `format` :

```json
{
  "fonts": {
    "family": "AcmeSans",
    "source": "/fonts/acme-sans.woff2",
    "format": "woff2"
  }
}
```

Définissez `weight` pour un corps de texte plus léger (ou plus épais). Cela est utile pour les polices géométriques délicates comme Geist :

```json
{
  "fonts": {
    "family": "Geist",
    "weight": 200
  }
}
```

`weight` ne définit que le poids du texte du **corps** ; les titres conservent les poids plus élevés propres à chaque thème, de sorte que votre hiérarchie typographique reste intacte. Cela fonctionne aussi dans la forme `body` : `"body": { "family": "Geist", "weight": 200 }`.

Pour tout ce qui dépasse le champ `fonts` (remplacement des polices de code, ajustement des poids par niveau de titre, ou chargement de polices web non-Google), consultez [CSS personnalisé](/fr/customization/custom-css#polices-externes).

## Couleurs personnalisées

Remplacez la palette par défaut pour correspondre à l'identité de votre marque :

```json
{
  "theme": "jam",
  "colors": {
    "primary": "#635BFF",
    "light": "#7C75FF",
    "dark": "#4F46E5"
  }
}
```

| Couleur | Utilisation |
|-------|-------|
| `primary` | Liens, boutons, accents |
| `light` | États de survol, mises en évidence |
| `dark` | États actifs, accents du mode sombre |

<Note>
Les couleurs prennent effet après votre prochain build. En développement local, redémarrez le serveur de développement pour voir les changements.
</Note>

<Tip>
Utilisez un outil de couleurs comme [Coolors](https://coolors.co) ou [Realtime Colors](https://realtimecolors.com) pour générer une palette harmonieuse.
</Tip>

<Tip>
**Besoin de plus que des couleurs ?** [CSS personnalisé](/fr/customization/custom-css) vous permet de remplacer les polices, l'espacement, la largeur du contenu, les rayons de bordure, les styles des encadrés et les détails au niveau des composants. Les thèmes définissent les valeurs par défaut ; le CSS personnalisé est la porte de sortie pour tout ce que le CSS peut toucher.
</Tip>

## Mode sombre

Tous les thèmes incluent le mode sombre. Par défaut, Jamdesk suit la préférence système de l'utilisateur et propose un bouton de bascule dans la barre de navigation. Votre palette de couleurs s'adapte automatiquement.

Fixez le site à un mode spécifique avec `appearance` dans `docs.json` :

```json
{
  "appearance": {
    "default": "dark",
    "strict": true
  }
}
```

| Champ | Valeurs | Par défaut | Description |
|-------|--------|---------|-------------|
| `default` | `"system"` \| `"light"` \| `"dark"` | `"system"` | Mode initial pour les visiteurs de première visite |
| `strict` | boolean | `false` | Lorsque `true`, masque le bouton de bascule de la barre de navigation afin que les visiteurs restent sur `default` |

Définissez `default` seul pour suggérer un mode de départ tout en laissant les utilisateurs basculer. Ajoutez `strict: true` pour supprimer entièrement le bouton de bascule et verrouiller le site sur ce mode.

Pour tester le mode sombre pendant le développement, utilisez le bouton de bascule de la barre de navigation ou simulez-le dans les DevTools :

1. Ouvrez les DevTools
2. Appuyez sur Cmd+Shift+P (Mac) ou Ctrl+Shift+P (Windows)
3. Recherchez « Emulate CSS prefers-color-scheme: dark »

Pour un contrôle précis des styles du mode sombre, utilisez [CSS personnalisé](/fr/customization/custom-css).
