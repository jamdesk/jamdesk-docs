Frame place les images et démos dans un conteneur bordé avec légendes optionnelles.

Les captures d'écran montrent l'interface en anglais.

Utilisez Frame lorsque vous souhaitez :
- Donner un aspect fini aux captures d'écran et images d'interface
- Ajouter des légendes pour expliquer ce que voient les lecteurs
- Distinguer le résultat d'une démo du contenu habituel
- Créer une cohérence visuelle dans toute votre documentation

## Utilisation

```mdx
<Frame caption="Architecture diagram">
  ![Diagram](/images/city-skyline.jpg)
</Frame>
```

## Frame de base

<Frame>
  ![Silhouette de la ville](/images/city-skyline.webp)
</Frame>

```mdx
<Frame>
  ![City skyline](/images/city-skyline.webp)
</Frame>
```

## Avec légende

Ajoutez une légende sous le cadre :

<Frame caption="New York au crépuscule">
  ![Silhouette de la ville](/images/city-skyline.webp)
</Frame>

```mdx
<Frame caption="New York City at dusk">
  ![City skyline](/images/city-skyline.webp)
</Frame>
```

## Encadrer d'autres contenus

Frame fonctionne avec tout type de contenu, pas seulement des images :

<Frame caption="Exemple de sortie de code">
```
✓ Build completed successfully
✓ 42 pages generated
✓ Deployed to production
```
</Frame>

## Quand ne pas utiliser Frame

- **Images décoratives en ligne** - les images markdown classiques conviennent pour les illustrations
- **Icônes ou petits graphismes** - Frame ajoute un poids visuel inutile
- **Images qui s'intègrent au texte** - Frame crée une rupture visuelle ; réservez-le aux visuels autonomes

## Bonnes pratiques

- **Restez concis dans les légendes** - une phrase qui explique ce que voit le lecteur
- **Utilisez-le de façon cohérente** - si vous encadrez une capture d'écran, encadrez-les toutes pour la cohérence visuelle
- **N'abusez pas des cadres** - réservez les cadres aux visuels importants, pas à chaque image de la page
