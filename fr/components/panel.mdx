Panel vous permet d'afficher du contenu personnalisé dans la barre latérale droite au lieu de la table des matières par défaut. Le contenu reste visible pendant que les lecteurs font défiler votre page. Utilisez-le pour des informations qui doivent toujours rester visibles : références rapides, avertissements importants ou liens de support.

Les captures d'écran montrent l'interface en anglais.

Utilisez Panel lorsque :
- **Les informations critiques** ne doivent pas disparaître du défilement
- **Le contenu de référence rapide** complète le contenu principal
- **Les appels à l'action persistants** doivent rester visibles (liens de support, clés API)

## Utilisation de base

Enveloppez n'importe quel contenu dans un Panel pour l'afficher dans la barre latérale droite :

```mdx
<Panel>
  <Info>This content appears in the sidebar!</Info>
</Panel>
```

## Cas d'usage courants

Les panels conviennent bien aux avertissements épinglés, aux cartes de référence rapide et aux liens de support :

```mdx
<Panel>
  <Warning>
    API rate limits: 100 requests/minute
  </Warning>
  <Card title="Quick Reference" icon="list">
    **Methods:** GET, POST, PUT, DELETE
    **Auth:** Bearer token required
  </Card>
  <Card title="Need Help?" icon="circle-question" href="https://example.com/support">
    Contact our support team
  </Card>
</Panel>
```

## Quand NE PAS utiliser Panel

- **Pages courtes** - La table des matières aide les utilisateurs à naviguer ; ne la remplacez que si vous avez un contenu plus utile
- **Documentation standard** - La plupart des pages fonctionnent mieux avec la table des matières par défaut
- **Utilisateurs mobiles** - Le contenu du Panel est masqué sur les petits écrans, assurez-vous donc que les informations critiques figurent aussi dans le contenu principal

## Comportement

- Apparaît dans la barre latérale droite sur ordinateur (1280px+), masqué sur les écrans plus petits
- Un seul Panel par page ; remplace entièrement la table des matières
- Prend en charge n'importe quel composant : Callouts, Cards, CodeGroup, Accordions, etc.
