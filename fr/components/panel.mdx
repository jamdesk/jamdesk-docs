Panel vous permet d'afficher du contenu personnalisé dans la barre latérale droite à la place de la table des matières par défaut. Le contenu reste visible pendant que les lecteurs font défiler votre page, ce qui le rend idéal pour les informations qui doivent toujours être accessibles — comme les références rapides, les avertissements importants ou les liens de support.

Utilisez Panel lorsque :
- **Des informations critiques** ne doivent pas disparaître lors du défilement
- **Des documents de référence rapide** complètent le contenu principal
- **Des appels à l'action persistants** doivent rester visibles (liens de support, clés API)

## Utilisation de base

Enveloppez n'importe quel contenu dans un Panel pour le faire apparaître dans la barre latérale droite :

```mdx
<Panel>
  <Info>This content appears in the sidebar!</Info>
</Panel>
```

## Cas d'utilisation courants

Les panels fonctionnent bien pour les avertissements épinglés, les cartes de référence rapide et les liens de support :

```mdx
<Panel>
  <Warning>
    API rate limits: 100 requests/minute
  </Warning>
  <Card title="Quick Reference" icon="list">
    **Methods:** GET, POST, PUT, DELETE
    **Auth:** Bearer token required
  </Card>
  <Card title="Need Help?" icon="circle-question" href="https://example.com/support">
    Contact our support team
  </Card>
</Panel>
```

## Quand NE PAS utiliser Panel

- **Pages courtes** — La table des matières aide les utilisateurs à naviguer ; ne la remplacez que lorsque vous avez du contenu plus utile
- **Documentation standard** — La plupart des pages fonctionnent mieux avec la table des matières par défaut
- **Utilisateurs mobiles** — Le contenu du Panel est masqué sur les écrans plus petits, assurez-vous donc que les informations critiques sont également dans le contenu principal

## Comportement

- Apparaît dans la barre latérale droite sur les écrans de bureau (1280px+), masqué sur les écrans plus petits
- Un seul Panel par page ; remplace entièrement la table des matières
- Prend en charge n'importe quel composant : Callouts, Cards, CodeGroup, Accordions, etc.
