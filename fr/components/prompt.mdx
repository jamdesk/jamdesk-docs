---
title: Prompt
description: Prompt présente des instructions IA réutilisables : copie, actions d'ouverture intégrées, destinations personnalisées, icônes et affichage compact.
---

Le composant `<Prompt>` transforme un ensemble d'instructions réutilisable en une carte que les lecteurs peuvent copier ou ouvrir dans un outil d'IA pris en charge. Les actions Copy et d'ouverture utilisent exactement le contenu rédigé et visible par l'humain entre les balises.

## Utilisation de base

Chaque Prompt inclut une action Copy, la version la plus simple ne nécessite donc aucune prop :

<Prompt>
Expliquez comment fonctionne la rotation des clés API pour un développeur qui utilise notre API REST pour la première fois.
</Prompt>

```mdx
<Prompt>
Explain how API key rotation works for a developer using our REST API for the first time.
</Prompt>
```

## Titre et description

Utilisez `title` pour nommer la tâche. La prop `description`, compatible avec Mintlify, remplace l'aperçu visible par un résumé plus court, tandis que le contenu rédigé et visible par l'humain entre les balises reste le prompt complet utilisé par les actions Copy et d'ouverture.

<Prompt
  title="Rédiger une note de version"
  description="Rédigez une note de version concise pour un public de développeurs."
  actions={["copy", "claude"]}
>
Rédigez une note de version pour le nouvel endpoint de rotation des clés API.

- Adressez-vous aux développeurs backend.
- Commencez par le bénéfice pour l'utilisateur.
- Incluez un exemple de requête.
</Prompt>

```mdx
<Prompt
  title="Draft a release note"
  description="Write a concise release note for a developer audience."
  actions={["copy", "claude"]}
>
Write a release note for the new API key rotation endpoint.

- Address backend developers.
- Lead with the user benefit.
- Include one request example.
</Prompt>
```

L'action `"copy"` explicite est acceptée pour des raisons de compatibilité, mais Copy est toujours présente et n'a jamais besoin d'être listée.

<Note>
  Prompt copie exactement le contenu rédigé et visible par l'humain. Lorsqu'un prompt contient [Visibility](/fr/components/visibility), les balises wrapper réservées aux humains sont omises du texte copié, mais leur contenu est conservé. Les sous-arbres réservés aux agents sont exclus. Visibility avec une prop `for` à valeur d'expression, ou dont l'audience est masquée par un attribut spread ultérieur, est également exclue car son audience ne peut pas être déterminée de manière statique. À l'inverse, Visibility sans prop `for`, avec un `for` abrégé, ou avec une audience littérale invalide reste visible. Un Prompt caché à l'intérieur d'un Visibility réservé aux agents ou masqué par une expression/un spread n'a pas de source copiable.
</Note>

## Actions d'ouverture

Ajoutez `claude`, `cursor`, `chatgpt`, `perplexity` ou `gemini` pour permettre aux lecteurs d'ouvrir le prompt dans ces outils, chacun avec son icône de marque. La première action d'ouverture valide apparaît à côté de Copy ; les actions supplémentaires apparaissent dans le menu More.

<Prompt
  title="Comparer les flux d'authentification"
  actions={["claude", "cursor", "chatgpt", "perplexity", "gemini"]}
>
Comparez les flux d'authentification par jeton de session et par clé API dans ce dépôt. Listez leurs compromis de sécurité et recommandez le flux à utiliser pour chaque type de client.
</Prompt>

```mdx
<Prompt
  title="Compare authentication flows"
  actions={["claude", "cursor", "chatgpt", "perplexity", "gemini"]}
>
Compare the session-token and API-key authentication flows in this repository.
List their security tradeoffs and recommend which flow each client type should use.
</Prompt>
```

<Warning>
  Cliquer sur une action d'ouverture envoie le prompt copiable complet au tiers sélectionné. N'incluez pas de secrets, de données personnelles ou de contenu propriétaire, sauf si vous avez l'intention de les partager selon la politique de confidentialité de ce fournisseur. Copy n'ouvre aucun service tiers.
</Warning>

## Actions d'URL personnalisées

Les actions personnalisées prennent un `label`, une `url` en HTTPS ou HTTP, et une icône optionnelle. Placez `{prompt}` dans un segment de chemin, une valeur de requête ou un fragment pour contrôler où va le prompt encodé en URL. Si vous omettez le placeholder, Jamdesk ajoute un paramètre de requête `prompt`.

<Prompt
  title="Rechercher cette migration"
  actions={[
    {
      label: "Rechercher sur le web",
      url: "https://www.google.com/search?q={prompt}",
      icon: "magnifying-glass",
    },
    "claude",
  ]}
>
Comparez ce plan de migration avec le contrat d'API publique actuel. Identifiez les changements cassants, les étapes de retour en arrière manquantes et les tests nécessaires avant la mise en production.
</Prompt>

```mdx
<Prompt
  title="Research this migration"
  actions={[
    {
      label: "Search the web",
      url: "https://www.google.com/search?q={prompt}",
      icon: "magnifying-glass",
    },
    "claude",
  ]}
>
Compare this migration plan with the current public API contract. Identify
breaking changes, missing rollback steps, and tests needed before release.
</Prompt>
```

Les URL d'actions personnalisées doivent être des URL `http:` ou `https:` sans identifiants. Jamdesk rejette les autres schémas, les placeholders dans les origines ou les clés de requête, ainsi que les URL d'action finales de plus de 8 000 caractères. Copy reste disponible lorsqu'une action d'ouverture est rejetée.

## Icône personnalisée

Définissez `icon` avec un nom Font Awesome, une URL ou un chemin d'image, ou un SVG inline. Utilisez `iconType` pour sélectionner le style d'un nom Font Awesome non préfixé.

<Prompt title="Planifier un tutoriel" icon="pen-nib" iconType="duotone">
Esquissez un tutoriel pratique qui mène un nouvel utilisateur de l'installation à une requête API réussie en moins de dix minutes.
</Prompt>

```mdx
<Prompt title="Plan a tutorial" icon="pen-nib" iconType="duotone">
  Outline a hands-on tutorial that gets a new user from installation to a
  successful API request in under ten minutes.
</Prompt>
```

Consultez [Icônes](/fr/content/icons) pour connaître les noms et styles disponibles.

## Affichages compacts

L'aperçu affiche jusqu'à trois lignes et défile lorsque le prompt est plus long ; le contrôle Expand ouvre le prompt complet. Définissez `singleLine` pour limiter l'aperçu à une seule ligne à la place. Dans tous les cas, le prompt complet et visible par l'humain est toujours copié ou envoyé par une action d'ouverture.

<Prompt title="Résumer l'API">
Résumez l'API publique en cinq points :

- Authentification et durées de vie des tokens.
- Conventions de pagination.
- Limites de débit et conseils de nouvelle tentative.
- Format des erreurs et codes courants.
- Politique de versionnage et de dépréciation.
</Prompt>

Utilisez `hidePrompt` avec un titre lorsque le libellé seul donne suffisamment de contexte aux lecteurs :

<Prompt title="Générer une checklist de migration" hidePrompt actions={["claude"]}>
Créez une checklist de migration pour passer de l'API v1 à v2. Incluez les prérequis, les changements de code, les étapes de validation, les critères de retour en arrière et la validation finale du responsable.
</Prompt>

```mdx
<Prompt title="Summarize the API">
  Summarize the public API in five bullets:

  - Authentication and token lifetimes.
  - Pagination conventions.
  - Rate limits and retry guidance.
  - Error format and common codes.
  - Versioning and deprecation policy.
</Prompt>

<Prompt title="Generate a migration checklist" hidePrompt actions={["claude"]}>
  Create a migration checklist for moving from API v1 to v2. Include
  prerequisites, code changes, validation steps, and rollback criteria.
</Prompt>
```

`hidePrompt` ne masque l'aperçu que lorsque `title` est présent. Sans titre, Jamdesk garde le prompt visible afin que la carte reste compréhensible.

## Props

<ParamField name="children" type="ReactNode">
  Le contenu du prompt entre les balises d'ouverture et de fermeture. Jamdesk préserve exactement le Markdown rédigé et visible par l'humain pour les actions Copy et d'ouverture ; il affiche également ce contenu comme aperçu, sauf si `description` remplace l'aperçu ou si `hidePrompt` le masque. Le filtrage de Visibility suit les règles décrites ci-dessus.
</ParamField>

<ParamField name="title" type="string">
  Libellé affiché dans l'en-tête de la carte. Aucun titre n'est affiché par défaut.
</ParamField>

<ParamField name="description" type="string">
  Aperçu compact en Markdown inline, accepté pour la compatibilité avec Mintlify. Il ne modifie que l'aperçu visible ; le contenu rédigé et visible par l'humain reste le prompt qui est copié ou envoyé.
</ParamField>

<ParamField name="icon" type="string | ReactElement" default="sparkles">
  Icône de l'en-tête. Accepte un nom Font Awesome, une URL ou un chemin d'image, ou un élément SVG inline.
</ParamField>

<ParamField name="iconType" type="regular | solid | light | thin | sharp-solid | duotone | brands">
  Style Font Awesome appliqué à une icône de type chaîne non préfixée. Il ne modifie pas les URL d'image, les chemins, les noms déjà préfixés, ni les éléments SVG inline.
</ParamField>

<ParamField name="actions" type="('copy' | 'cursor' | 'claude' | 'chatgpt' | 'perplexity' | 'gemini' | CustomAction)[]" default="[]">
  Actions d'ouverture dans l'ordre d'affichage. `CustomAction` est `{ label: string; url: string; icon?: string }`. Copy est toujours affichée ; une entrée `copy` explicite est acceptée et dédupliquée. Les actions d'ouverture invalides, en double ou surdimensionnées sont omises.
</ParamField>

<ParamField name="singleLine" type="boolean | string" default="false">
  Limite l'aperçu visible à une ligne lorsqu'il est défini sur le booléen `true` ou la chaîne `"true"`. La chaîne `"false"` reste désactivée et le prompt complet est toujours utilisé par chaque action.
</ParamField>

<ParamField name="hidePrompt" type="boolean | string" default="false">
  Masque l'aperçu visible lorsqu'un titre est présent et que la valeur est le booléen `true` ou la chaîne `"true"`. Sans titre, l'aperçu reste visible. La chaîne `"false"` reste désactivée.
</ParamField>

<ParamField name="className" type="string">
  Noms de classes CSS supplémentaires appliqués à l'élément racine de la carte Prompt.
</ParamField>
