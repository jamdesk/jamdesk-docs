Commencez ici quand quelque chose ne fonctionne pas. Chaque section propose une solution rapide et un lien vers le guide complet dans le centre d'aide.

## Échecs de build

**Symptôme :** le statut du build affiche « Failed » dans le dashboard.

**Vérifications rapides :**
1. Lancez `jamdesk dev` en local pour détecter les erreurs de syntaxe MDX
2. Vérifiez que `docs.json` est un JSON valide (virgules manquantes, virgules traînantes)
3. Assurez-vous que toutes les pages listées dans la navigation existent sous forme de fichiers `.mdx`

<Tip>
Le log du build dans votre dashboard indique le fichier et la ligne exacts où l'erreur s'est produite. Commencez par là.
</Tip>

Voir [Échecs de build](/fr/help/troubleshooting/build-failures) et [Référence des erreurs](/fr/help/troubleshooting/error-reference) pour les codes d'erreur spécifiques.

## La vérification du domaine personnalisé échoue

**Symptôme :** le domaine reste bloqué sur « Pending » après l'ajout des enregistrements DNS.

**Vérifications rapides :**
1. Confirmez que vous avez bien ajouté un enregistrement **CNAME** (et non un enregistrement A) pour les sous-domaines
2. Si vous utilisez Cloudflare, réglez le proxy sur **DNS only** (nuage gris)
3. Vérifiez la propagation sur [whatsmydns.net](https://www.whatsmydns.net/)

```bash
# Verify your CNAME is resolving
dig CNAME docs.yourdomain.com
```

Voir [Dépannage DNS](/fr/help/troubleshooting/dns-issues) pour des instructions adaptées à chaque fournisseur.

## Le dépôt GitHub n'apparaît pas

**Symptôme :** votre dépôt n'apparaît pas lors de la création d'un projet.

**Vérifications rapides :**
1. Vérifiez que la GitHub App Jamdesk est installée sur l'organisation du dépôt
2. Vérifiez que l'accès aux dépôts est configuré sur « All repositories » ou que le dépôt concerné est bien sélectionné
3. Ré-autorisez l'application sur [github.com/settings/installations](https://github.com/settings/installations)

Voir [Problèmes GitHub](/fr/help/troubleshooting/github-issues) pour les soucis de webhook et de permissions.

## Données analytics manquantes

**Symptôme :** le dashboard affiche zéro visiteur ou des données obsolètes.

**Vérifications rapides :**
1. Les analytics peuvent mettre jusqu'à 24 heures à apparaître après le premier déploiement
2. Les bloqueurs de publicités et l'option Do Not Track empêchent la comptabilisation de certaines visites
3. Vérifiez que votre site est bien déployé et accessible publiquement

Voir [Problèmes d'analytics](/fr/help/troubleshooting/analytics-issues) pour les données retardées ou manquantes.

## Problèmes de connexion

**Symptôme :** impossible de se connecter ou redirection répétée vers la page de connexion.

**Vérifications rapides :**
1. Videz le cache et les cookies du navigateur pour `dashboard.jamdesk.com`
2. Essayez en navigation privée
3. Si vous utilisez le SSO GitHub, vérifiez que votre email GitHub correspond à celui de votre compte Jamdesk

Voir [Problèmes de connexion](/fr/help/troubleshooting/login-issues) pour les étapes de récupération de compte.
