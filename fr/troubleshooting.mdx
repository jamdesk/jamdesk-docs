Commencez ici quand quelque chose ne fonctionne pas. Chaque section propose une correction rapide et un lien vers le guide complet dans le Centre d'aide.

## Échecs de build

**Symptôme :** Le statut du build affiche « Failed » dans le dashboard.

**Vérifications rapides :**
1. Exécutez `jamdesk dev` localement pour détecter les erreurs de syntaxe MDX
2. Vérifiez que `docs.json` est un JSON valide (virgules manquantes, virgules en fin de ligne)
3. Assurez-vous que toutes les pages listées dans la navigation existent en tant que fichiers `.mdx`

<Tip>
Le journal de build dans votre dashboard indique le fichier exact et la ligne où l'erreur s'est produite. Commencez par là.
</Tip>

Consultez [Échecs de build](/fr/help/troubleshooting/build-failures) et [Référence des erreurs](/fr/help/troubleshooting/error-reference) pour les codes d'erreur spécifiques.

## Domaine personnalisé non vérifié

**Symptôme :** Le domaine reste bloqué sur « Pending » après l'ajout des enregistrements DNS.

**Vérifications rapides :**
1. Confirmez que vous avez ajouté un enregistrement **CNAME** (pas un enregistrement A) pour les sous-domaines
2. Si vous utilisez Cloudflare, définissez le proxy sur **DNS only** (nuage gris)
3. Vérifiez la propagation sur [whatsmydns.net](https://www.whatsmydns.net/)

```bash
# Verify your CNAME is resolving
dig CNAME docs.yourdomain.com
```

Consultez [Dépannage DNS](/fr/help/troubleshooting/dns-issues) pour des conseils spécifiques à chaque fournisseur.

## Dépôt GitHub non visible

**Symptôme :** Votre dépôt n'apparaît pas lors de la création d'un projet.

**Vérifications rapides :**
1. Vérifiez que l'application GitHub Jamdesk est installée sur l'organisation du dépôt
2. Assurez-vous que l'accès au dépôt est défini sur « All repositories » ou que le dépôt spécifique est sélectionné
3. Ré-autorisez sur [github.com/settings/installations](https://github.com/settings/installations)

Consultez [Problèmes GitHub](/fr/help/troubleshooting/github-issues) pour les problèmes de Webhook et de permissions.

## Données analytiques manquantes

**Symptôme :** Le dashboard affiche zéro visiteur ou des données obsolètes.

**Vérifications rapides :**
1. Les données analytiques mettent jusqu'à 24 heures à apparaître après le premier déploiement
2. Les bloqueurs de publicités et Do Not Track empêchent certaines visites d'être comptabilisées
3. Vérifiez que votre site est déployé et accessible publiquement

Consultez [Problèmes analytiques](/fr/help/troubleshooting/analytics-issues) pour les données retardées ou manquantes.

## Problèmes de connexion

**Symptôme :** Impossible de se connecter ou redirection répétée vers la page de connexion.

**Vérifications rapides :**
1. Effacez le cache et les cookies du navigateur pour `dashboard.jamdesk.com`
2. Essayez une fenêtre de navigation privée/incognito
3. Si vous utilisez GitHub SSO, vérifiez que votre adresse e-mail GitHub correspond à votre compte Jamdesk

Consultez [Problèmes de connexion](/fr/help/troubleshooting/login-issues) pour les étapes de récupération de compte.
