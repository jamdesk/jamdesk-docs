Commencez ici lorsque quelque chose ne fonctionne pas. Chaque section propose un correctif rapide et renvoie vers le guide complet dans le Centre d'aide.

## Échecs de compilation

**Symptôme :** Le statut de compilation affiche « Failed » dans le dashboard.

**Vérifications rapides :**
1. Exécutez `jamdesk dev` localement pour détecter les erreurs de syntaxe MDX
2. Vérifiez que `docs.json` est un JSON valide (virgules manquantes, virgules en trop)
3. Vérifiez que toutes les pages listées dans la navigation existent en tant que fichiers `.mdx`

<Tip>
Le journal de compilation dans votre dashboard indique le fichier et la ligne exacts où l'erreur s'est produite. Commencez par là.
</Tip>

Consultez [Échecs de compilation](/fr/help/troubleshooting/build-failures) et [Référence des erreurs](/fr/help/troubleshooting/error-reference) pour les codes d'erreur spécifiques.

## Le domaine personnalisé ne se vérifie pas

**Symptôme :** Le domaine reste bloqué sur « Pending » après l'ajout des enregistrements DNS.

**Vérifications rapides :**
1. Confirmez que vous avez ajouté un enregistrement **CNAME** (pas un enregistrement A) pour les sous-domaines
2. Si vous utilisez Cloudflare, réglez le proxy sur **DNS only** (nuage gris)
3. Vérifiez la propagation sur [whatsmydns.net](https://www.whatsmydns.net/)

```bash
# Verify your CNAME is resolving
dig CNAME docs.yourdomain.com
```

Consultez [Dépannage DNS](/fr/help/troubleshooting/dns-issues) pour des conseils spécifiques à chaque fournisseur.

## Le dépôt GitHub n'apparaît pas

**Symptôme :** Votre dépôt ne s'affiche pas lors de la création d'un projet.

**Vérifications rapides :**
1. Vérifiez que l'application GitHub Jamdesk est installée sur l'organisation du dépôt
2. Vérifiez que l'accès au dépôt est défini sur « All repositories » ou que le dépôt spécifique est sélectionné
3. Réautorisez sur [github.com/settings/installations](https://github.com/settings/installations)

Consultez [Problèmes GitHub](/fr/help/troubleshooting/github-issues) pour les problèmes de webhook et de permissions.

## Données d'analyse manquantes

**Symptôme :** Le dashboard affiche zéro visiteur ou des données obsolètes.

**Vérifications rapides :**
1. Les données d'analyse peuvent prendre jusqu'à 24 heures pour apparaître après le premier déploiement
2. Les bloqueurs de publicités et Do Not Track empêchent la comptabilisation de certaines visites
3. Vérifiez que votre site est déployé et accessible publiquement

Consultez [Problèmes d'analyse](/fr/help/troubleshooting/analytics-issues) pour les données retardées ou manquantes.

## Problèmes de connexion

**Symptôme :** Impossible de se connecter ou redirection répétée vers la page de connexion.

**Vérifications rapides :**
1. Videz le cache et les cookies du navigateur pour `dashboard.jamdesk.com`
2. Essayez une fenêtre de navigation privée/incognito
3. Si vous utilisez le SSO GitHub, vérifiez que votre adresse e-mail GitHub correspond à votre compte Jamdesk

Consultez [Problèmes de connexion](/fr/help/troubleshooting/login-issues) pour les étapes de récupération de compte.
