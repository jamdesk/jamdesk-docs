Ajoutez votre ID de conteneur GTM à `docs.json` pour charger Google Tag Manager sur chaque page de votre site de documentation. Votre équipe marketing peut ensuite configurer l'analytique, les pixels de conversion et le suivi des événements entièrement depuis GTM.

<Info>
Les ID de conteneur GTM commencent par `GTM-`. Si vous avez uniquement besoin de Google Analytics, consultez l'[intégration Google Analytics](/fr/integrations/google-analytics) pour une configuration plus simple.
</Info>

## Quand utiliser GTM

Utilisez Google Tag Manager lorsque vous avez besoin de :

- **Plusieurs outils de suivi** - GA4, Facebook Pixel, LinkedIn, etc.
- **Contrôle par l'équipe marketing** - Permettre aux marketeurs d'ajouter des tags sans l'aide d'un développeur
- **Déclencheurs avancés** - Suivre les clics sur les boutons, les soumissions de formulaires, les vues de vidéos
- **Intégration de tests A/B** - Connecter des outils comme Google Optimize

Pour une simple analytique, il est plus simple d'ajouter GA4 directement.

## Obtenir votre ID de conteneur

1. Rendez-vous sur [Google Tag Manager](https://tagmanager.google.com/)
2. Sélectionnez votre compte et votre conteneur (ou créez-en de nouveaux)
3. Copiez l'**ID de conteneur** en haut de la page (commence par `GTM-`)

## Ajouter GTM à votre documentation

Ajoutez l'ID de conteneur à votre `docs.json` :

```json docs.json
{
  "name": "My Docs",
  "integrations": {
    "gtm": {
      "tagId": "GTM-XXXXXXX"
    }
  }
}
```

Remplacez `GTM-XXXXXXX` par votre ID de conteneur réel.

## Consentement aux cookies

Il vous incombe de mettre en place des bandeaux de consentement aux cookies si nécessaire. Jamdesk charge votre conteneur GTM sur chaque page, de sorte que tous les tags que vous configurez se déclenchent pour tous les visiteurs. Si vos lecteurs sont soumis au RGPD, au CCPA ou à des réglementations similaires, configurez le [mode de consentement](https://support.google.com/tagmanager/answer/10718549) dans GTM ou utilisez une plateforme de gestion du consentement. Jamdesk peut également conditionner GTM lui-même au consentement — consultez [Consentement aux cookies](/fr/integrations/cookie-consent).

## Configurer GA4 via GTM

Si vous souhaitez utiliser GA4 via GTM plutôt que de l'ajouter directement :

1. Dans GTM, allez dans **Tags** → **Nouveau**
2. Choisissez **Google Analytics : configuration GA4**
3. Saisissez votre ID de mesure GA4 (commence par `G-`)
4. Définissez le déclencheur sur **Toutes les pages**
5. **Publiez** votre conteneur

<Warning>
Si vous configurez GA4 via GTM, ne l'ajoutez pas aussi directement dans `docs.json`. Cela provoque un double suivi.
</Warning>

## Vérifier l'installation

### Utiliser le mode aperçu de GTM

1. Dans GTM, cliquez sur **Aperçu** en haut à droite
2. Saisissez l'URL de votre site de documentation
3. Une fenêtre de débogage affiche les tags qui se déclenchent sur chaque page

### Utiliser les outils de développement du navigateur

1. Ouvrez votre site avec les outils de développement (F12)
2. Allez dans l'onglet **Réseau**
3. Filtrez par `gtm.js` ou `googletagmanager`
4. Vous devriez voir des requêtes effectuées

## Tags GTM courants pour la documentation

### Suivre les liens sortants

Créez un tag pour suivre lorsque les utilisateurs cliquent sur des liens externes :

1. **Tag** : Google Analytics : événement GA4
2. **Nom de l'événement** : `click`
3. **Déclencheur** : Clic - Liens uniquement, où l'URL du clic ne contient pas votre domaine

### Suivre l'utilisation de la recherche

Suivez les interactions des utilisateurs avec la fonctionnalité de recherche :

1. **Tag** : Google Analytics : événement GA4
2. **Nom de l'événement** : `search`
3. **Déclencheur** : Événement personnalisé correspondant à votre interaction de recherche

### Suivre le temps passé sur la page

Comprenez combien de temps les utilisateurs passent à lire :

1. **Tag** : Google Analytics : événement GA4
2. **Nom de l'événement** : `timing`
3. **Déclencheur** : Déclencheur de minuterie (par exemple, toutes les 30 secondes)

## Dépannage

<Accordion title="Les tags ne se déclenchent pas">
  1. **Vérifiez l'ID de conteneur** - Doit commencer par `GTM-`
  2. **Publiez votre conteneur** - Les modifications non publiées n'apparaîtront pas sur votre site
  3. **Utilisez le mode aperçu** - L'aperçu de GTM indique quels tags se déclenchent sur chaque page
</Accordion>

<Accordion title="Données en double dans Google Analytics">
  Si vous avez GA4 configuré à la fois :
  - Directement dans `docs.json` (`integrations.ga4`)
  - Via GTM comme tag GA4

  Vous obtiendrez des pages vues en double. Supprimez l'un des deux.
</Accordion>
