Ajoutez votre ID de conteneur GTM à `docs.json` pour charger Google Tag Manager sur chaque page de votre site de documentation. Votre équipe marketing pourra ensuite configurer l'analytique, les pixels de conversion et le suivi des événements entièrement depuis GTM.

<Info>
Les ID de conteneur GTM commencent par `GTM-`. Si vous avez seulement besoin de Google Analytics, consultez [Intégration Google Analytics](/fr/integrations/google-analytics) pour une configuration plus simple.
</Info>

## Quand utiliser GTM

Utilisez Google Tag Manager lorsque vous avez besoin de :

- **Plusieurs outils de suivi** - GA4, Facebook Pixel, LinkedIn, etc.
- **Contrôle par l'équipe marketing** - Laissez les marketeurs ajouter des tags sans aide développeur
- **Déclencheurs avancés** - Suivre les clics sur boutons, soumissions de formulaires, vues vidéo
- **Intégration de tests A/B** - Connecter des outils comme Google Optimize

Pour une analytique basique uniquement, ajouter GA4 directement est plus simple.

## Obtenir votre ID de conteneur

1. Allez sur [Google Tag Manager](https://tagmanager.google.com/)
2. Sélectionnez votre compte et votre conteneur (ou créez-en de nouveaux)
3. Copiez l'**ID de conteneur** en haut de la page (commence par `GTM-`)

## Ajouter GTM à votre documentation

Ajoutez l'ID de conteneur à votre `docs.json` :

```json docs.json
{
  "name": "My Docs",
  "integrations": {
    "gtm": {
      "tagId": "GTM-XXXXXXX"
    }
  }
}
```

Remplacez `GTM-XXXXXXX` par votre ID de conteneur réel.

## Consentement aux cookies

Vous êtes responsable de la mise en place de bannières de consentement aux cookies si vous en avez besoin. Jamdesk charge votre conteneur GTM sur chaque page, donc tous les tags que vous configurez se déclenchent pour tous les visiteurs. Si vos lecteurs sont soumis au RGPD, au CCPA ou à des réglementations similaires, configurez le [mode de consentement](https://support.google.com/tagmanager/answer/10718549) dans GTM ou utilisez une plateforme de gestion du consentement. Jamdesk peut aussi conditionner GTM lui-même au consentement. Voir [Consentement aux cookies](/fr/integrations/cookie-consent).

## Configurer GA4 via GTM

Si vous souhaitez utiliser GA4 via GTM plutôt que de l'ajouter directement :

1. Dans GTM, allez dans **Tags** → **New**
2. Choisissez **Google Analytics: GA4 Configuration**
3. Saisissez votre ID de mesure GA4 (commence par `G-`)
4. Définissez le déclencheur sur **All Pages**
5. **Publiez** votre conteneur

<Warning>
Si vous configurez GA4 via GTM, ne l'ajoutez pas aussi directement dans `docs.json`. Cela entraîne un suivi en double.
</Warning>

## Vérifier l'installation

### Utiliser le mode Preview de GTM

1. Dans GTM, cliquez sur **Preview** en haut à droite
2. Saisissez l'URL de votre site de documentation
3. Une fenêtre de débogage affiche les tags qui se déclenchent sur chaque page

### Utiliser les outils de développement du navigateur

1. Ouvrez votre site avec les outils de développement (F12)
2. Allez dans l'onglet **Network**
3. Filtrez sur `gtm.js` ou `googletagmanager`
4. Vous devriez voir des requêtes s'effectuer

## Tags GTM courants pour la documentation

### Suivre les liens sortants

Créez un tag pour suivre les clics des utilisateurs sur des liens externes :

1. **Tag** : Google Analytics: GA4 Event
2. **Event Name** : `click`
3. **Trigger** : Click - Just Links, où Click URL ne contient pas votre domaine

### Suivre l'utilisation de la recherche

Suivez les interactions des utilisateurs avec la fonctionnalité de recherche :

1. **Tag** : Google Analytics: GA4 Event
2. **Event Name** : `search`
3. **Trigger** : Custom event correspondant à votre interaction de recherche

### Suivre le temps passé sur la page

Comprenez combien de temps les utilisateurs passent à lire :

1. **Tag** : Google Analytics: GA4 Event
2. **Event Name** : `timing`
3. **Trigger** : Timer trigger (par exemple, toutes les 30 secondes)

## Dépannage

<Accordion title="Les tags ne se déclenchent pas">
  1. **Vérifiez l'ID de conteneur** - Doit commencer par `GTM-`
  2. **Publiez votre conteneur** - Les modifications non publiées n'apparaîtront pas sur votre site
  3. **Utilisez le mode Preview** - Le mode Preview de GTM montre quels tags se déclenchent sur chaque page
</Accordion>

<Accordion title="Données en double dans Google Analytics">
  Si vous avez configuré GA4 à la fois :
  - Directement dans `docs.json` (`integrations.ga4`)
  - Via GTM en tant que tag GA4

  Vous obtiendrez des pages vues en double. Supprimez l'un des deux.
</Accordion>
