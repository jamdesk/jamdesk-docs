Jamdesk charge les scripts de 13 fournisseurs supplémentaires d'analytique, de replay de session et d'identité directement depuis `docs.json`. Ajoutez le bloc du fournisseur sous `integrations`, et Jamdesk injecte son script sur chaque page de votre site de documentation publié.

<Info>
Chaque valeur est vérifiée par rapport à un format strict avant que Jamdesk ne charge le script. Une valeur au mauvais format (caractères en trop, mauvais préfixe, mauvaise longueur) est ignorée silencieusement et n'est jamais rendue — pas de page d'erreur, pas de balise de script cassée. Si un fournisseur ne se charge pas, recopiez la valeur depuis son dashboard et vérifiez-la par rapport au format ci-dessous.
</Info>

## Configurer depuis le Dashboard

La façon la plus rapide de configurer l'un de ces éléments : **Dashboard → Integrations**. Choisissez la carte d'un fournisseur, collez sa clé, et Jamdesk enregistre un commit du bloc `docs.json` pour vous et déclenche un rebuild (projets connectés à GitHub uniquement). Les sections ci-dessous concernent la modification directe de `docs.json`, ou les projets CLI uniquement.

## PostHog

Analytique produit, replay de session et feature flags.

**Format :** La clé API de projet commence par `phc_`, suivie de 8 à 64 lettres ou chiffres. L'hôte API optionnel doit être une URL `https://`.

<Info>
Retrouvez votre clé dans **Settings → Project → Project API key** dans PostHog.
</Info>

```json docs.json
{
  "integrations": {
    "posthog": {
      "apiKey": "phc_Kj8fPqZx92RmNbTeYcWs",
      "apiHost": "https://us.i.posthog.com"
    }
  }
}
```

`apiHost` est optionnel et vaut par défaut `https://us.i.posthog.com`. Définissez-le sur votre hôte cloud EU ou votre URL de reverse-proxy si vous en utilisez un.

## Mixpanel

Analytique d'événements et tunnels de conversion.

**Format :** Le token de projet comporte exactement 32 caractères hexadécimaux en minuscules (`0-9`, `a-f`).

<Info>
Retrouvez votre token dans **Project Settings → Access Keys → Project Token** dans Mixpanel.
</Info>

```json docs.json
{
  "integrations": {
    "mixpanel": {
      "projectToken": "a1b2c3d4e5f6a7b8c9d0e1f2a3b4c5d6"
    }
  }
}
```

## Amplitude

Analytique produit et cohortes comportementales.

**Format :** La clé API comporte exactement 32 caractères hexadécimaux en minuscules (`0-9`, `a-f`).

<Info>
Retrouvez votre clé dans **Settings → Projects → votre projet → API Key** dans Amplitude.
</Info>

```json docs.json
{
  "integrations": {
    "amplitude": {
      "apiKey": "f6e5d4c3b2a1908877665544332211ff"
    }
  }
}
```

## Hotjar

Heatmaps et enregistrements de session.

**Format :** L'ID de site comporte 1 à 12 chiffres. La version du snippet comporte 1 à 4 chiffres (généralement `6`).

<Info>
Retrouvez les deux dans **Sites & Organizations → votre site** dans Hotjar.
</Info>

```json docs.json
{
  "integrations": {
    "hotjar": {
      "hjid": "3482910",
      "hjsv": "6"
    }
  }
}
```

<Warning>
Hotjar enregistre les sessions des visiteurs. Si le RGPD, le CCPA ou des réglementations similaires s'appliquent à vos lecteurs, placez-le derrière [Consentement aux cookies](/fr/integrations/cookie-consent).
</Warning>

## Microsoft Clarity

Heatmaps et enregistrements de session gratuits.

**Format :** L'ID de projet comporte 4 à 32 lettres ou chiffres.

<Info>
Retrouvez votre ID de projet dans **Settings → Overview → Project ID** dans Clarity.
</Info>

```json docs.json
{
  "integrations": {
    "clarity": {
      "projectId": "qbxk2paw9m"
    }
  }
}
```

<Warning>
Clarity enregistre les sessions des visiteurs. Si le RGPD, le CCPA ou des réglementations similaires s'appliquent à vos lecteurs, placez-le derrière [Consentement aux cookies](/fr/integrations/cookie-consent).
</Warning>

## Fathom

Analytique axée sur la confidentialité, sans cookies.

**Format :** L'ID de site comporte 4 à 16 lettres ou chiffres.

<Info>
Retrouvez l'ID de votre site dans **Settings → Sites → votre site** dans Fathom.
</Info>

```json docs.json
{
  "integrations": {
    "fathom": {
      "siteId": "ABCD1234"
    }
  }
}
```

## Pirsch

Analytique sans cookies et respectueuse de la vie privée.

**Format :** Le code d'identification comporte 4 à 64 lettres ou chiffres.

<Info>
Retrouvez votre code dans **Settings → Developer → Identification Code** dans Pirsch.
</Info>

```json docs.json
{
  "integrations": {
    "pirsch": {
      "id": "Jd8fK2pQmZx9AeRt"
    }
  }
}
```

## Heap

Capture automatique des événements, sans instrumentation manuelle.

**Format :** L'ID d'application comporte 6 à 20 chiffres.

<Info>
Retrouvez votre ID d'application dans **Account → Manage → Projects** dans Heap.
</Info>

```json docs.json
{
  "integrations": {
    "heap": {
      "appId": "1234567890"
    }
  }
}
```

## LogRocket

Replay de session avec logs de console et réseau.

**Format :** L'ID d'application se compose de deux segments de slug séparés par une barre oblique — `org-slug/app-slug` — chacun comportant 2 à 64 lettres minuscules, chiffres ou traits d'union.

<Info>
Retrouvez votre ID d'application dans **Settings → Project Setup** dans LogRocket.
</Info>

```json docs.json
{
  "integrations": {
    "logrocket": {
      "appId": "acme-inc/docs-site"
    }
  }
}
```

<Warning>
LogRocket enregistre les sessions des visiteurs, y compris l'activité de la console et du réseau. Si le RGPD, le CCPA ou des réglementations similaires s'appliquent à vos lecteurs, placez-le derrière [Consentement aux cookies](/fr/integrations/cookie-consent).
</Warning>

## Segment

Acheminez les événements de documentation vers chaque outil en aval depuis une seule source.

**Format :** La clé d'écriture comporte 10 à 64 lettres ou chiffres (sans traits d'union ni tirets bas).

<Info>
Retrouvez votre clé d'écriture dans **Connections → Sources → votre source JS → Settings → API Keys** dans Segment.
</Info>

```json docs.json
{
  "integrations": {
    "segment": {
      "key": "hcQ8wK9pXeR2mNq7"
    }
  }
}
```

## Clearbit

Identifiez et enrichissez les visiteurs anonymes.

**Format :** La clé API publique commence par `pk_`, suivie de 6 à 64 lettres ou chiffres.

```json docs.json
{
  "integrations": {
    "clearbit": {
      "publicApiKey": "pk_4f8a2e1c9b6d"
    }
  }
}
```

## Hightouch

Envoyez les événements de documentation directement vers votre data warehouse.

**Format :** La clé d'écriture comporte 8 à 128 caractères (lettres, chiffres, `:`, `.`, `_`, `-`). L'hôte API optionnel comporte 4 à 64 caractères (lettres, chiffres, `.`, `-`).

```json docs.json
{
  "integrations": {
    "hightouch": {
      "writeKey": "wk_prod_4f8a2e1c9b6d",
      "apiHost": "us-east-1.hightouch-events.com"
    }
  }
}
```

`apiHost` est optionnel — nécessaire uniquement pour un endpoint d'événements Hightouch auto-hébergé ou spécifique à une région.

## Koala

Identifiez les visiteurs à forte intention pour les ventes et le marketing.

**Format :** La clé API publique commence par `pk_`, suivie de 6 à 64 lettres ou chiffres.

```json docs.json
{
  "integrations": {
    "koala": {
      "publicApiKey": "pk_7e3a9c1f6b2d"
    }
  }
}
```

## Contrôle par consentement

Les 13 fournisseurs ci-dessus respectent `integrations.cookies`. Lorsqu'il est défini, aucun de leurs scripts ne se charge tant que votre bannière de consentement n'a pas enregistré l'approbation — consultez [Consentement aux cookies](/fr/integrations/cookie-consent) pour la configuration complète. Sans cela, chaque script se charge pour chaque visiteur au chargement de la page.
