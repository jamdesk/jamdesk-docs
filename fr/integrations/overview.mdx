Cette section couvre trois tâches différentes ; il est donc utile de savoir laquelle vous concerne.

**Documenter votre API** consiste à transformer des spécifications OpenAPI en pages d'endpoint que les lecteurs peuvent tester directement dans le navigateur. **L'API de recherche Jamdesk** fonctionne dans l'autre sens : votre documentation devient une source de données que les chatbots, les outils de support et les agents IA peuvent interroger. Et les **intégrations** connectent votre site de documentation aux outils qui l'entourent, des notifications de build dans Slack à l'analytique et à la collecte d'emails.
