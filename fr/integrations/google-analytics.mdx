Ajoutez Google Analytics 4 à votre site de documentation pour comprendre comment les utilisateurs interagissent avec votre contenu.

<Info>
L'intégration Google Analytics fonctionne avec les ID de mesure GA4 (Google Analytics 4) qui commencent par `G-`.
</Info>

## Obtenir votre ID de mesure

1. Accédez à [Google Analytics](https://analytics.google.com/)
2. Sélectionnez votre propriété (ou créez-en une)
3. Allez dans **Admin** → **Flux de données**
4. Sélectionnez votre flux web (ou créez-en un)
5. Copiez l'**ID de mesure** (commence par `G-`)

## Ajouter GA4 à vos docs

Ajoutez l'ID de mesure à votre `docs.json` :

```json docs.json
{
  "name": "My Docs",
  "integrations": {
    "ga4": {
      "measurementId": "G-XXXXXXXXXX"
    }
  }
}
```

Remplacez `G-XXXXXXXXXX` par votre ID de mesure réel.

## Consulter vos données

Après avoir ajouté l'intégration :

1. Déclenchez un rebuild de vos docs
2. Visitez votre site de documentation en production
3. Dans Google Analytics, allez dans **Rapports** → **Temps réel**
4. Votre visite devrait apparaître dans les 30 secondes

<Note>
Les données peuvent mettre 24 à 48 heures à apparaître dans les rapports standard. Utilisez les rapports en temps réel pour une vérification immédiate.
</Note>

## Utilisation avec Google Tag Manager

Si vous utilisez déjà Google Tag Manager, vous pouvez configurer GA4 via GTM plutôt que de l'ajouter directement. Consultez [Intégration Google Tag Manager](/fr/integrations/google-tag-manager) pour plus de détails.

Vous êtes responsable de la mise en place des bandeaux de consentement aux cookies pour les tags que vous chargez via Google Tag Manager si vous en avez besoin — Jamdesk charge votre conteneur GTM pour tous les visiteurs sans gate de consentement. Consultez [Consentement aux cookies](/fr/integrations/cookie-consent) pour conditionner les analytics à l'acceptation des visiteurs.

<Warning>
N'ajoutez pas la même propriété GA4 à la fois directement dans `docs.json` et via Google Tag Manager — cela entraînera un suivi en double.
</Warning>

## Considérations de confidentialité

Google Analytics collecte des données sur les visiteurs. Pensez à :

- Ajouter un bandeau de consentement aux cookies si le RGPD/CCPA s'applique. Jamdesk charge GA4 pour chaque visiteur par défaut, utilisez donc [Consentement aux cookies](/fr/integrations/cookie-consent) pour le conditionner à leur acceptation.
- Mettre à jour votre politique de confidentialité pour mentionner les analytics
- Utiliser [l'anonymisation des IP](https://support.google.com/analytics/answer/2763052) si nécessaire

## Dépannage

<Accordion title="Aucune donnée visible">
  1. **Vérifiez votre ID de mesure** - Il doit commencer par `G-`
  2. **Vérifiez les bloqueurs de publicités** - Ils peuvent bloquer les scripts analytics
  3. **Attendez le rebuild** - Les modifications nécessitent un nouveau build pour prendre effet
  4. **Utilisez les rapports en temps réel** - Les rapports standard ont un délai de 24 à 48 heures
</Accordion>

<Accordion title="Erreur « Invalid Measurement ID »">
  L'ID doit :
  - Commencer par `G-`
  - Contenir uniquement des lettres et des chiffres après `G-`
  - Être copié exactement depuis Google Analytics (sans espaces supplémentaires)
</Accordion>
