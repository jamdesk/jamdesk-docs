Ajoutez Google Analytics 4 à votre site de documentation pour comprendre comment les utilisateurs interagissent avec votre contenu.

<Info>
L'intégration Google Analytics fonctionne avec les identifiants de mesure GA4 (Google Analytics 4) qui commencent par `G-`.
</Info>

## Obtenir votre identifiant de mesure

1. Accédez à [Google Analytics](https://analytics.google.com/)
2. Sélectionnez votre propriété (ou créez-en une)
3. Allez dans **Admin** → **Flux de données**
4. Sélectionnez votre flux web (ou créez-en un)
5. Copiez l'**identifiant de mesure** (commence par `G-`)

## Ajouter GA4 à votre documentation

Ajoutez l'identifiant de mesure à votre `docs.json` :

```json docs.json
{
  "name": "My Docs",
  "integrations": {
    "ga4": {
      "measurementId": "G-XXXXXXXXXX"
    }
  }
}
```

Remplacez `G-XXXXXXXXXX` par votre identifiant de mesure réel.

## Consulter vos données

Après avoir ajouté l'intégration :

1. Déclenchez un rebuild de votre documentation
2. Visitez votre site de documentation en ligne
3. Dans Google Analytics, allez dans **Rapports** → **Temps réel**
4. Votre visite devrait apparaître dans les 30 secondes

<Note>
Les données peuvent prendre 24 à 48 heures pour apparaître dans les rapports standard. Utilisez les rapports en temps réel pour une vérification immédiate.
</Note>

## Utilisation avec Google Tag Manager

Si vous utilisez déjà Google Tag Manager, vous pouvez configurer GA4 via GTM plutôt que de l'ajouter directement. Consultez [l'intégration Google Tag Manager](/fr/integrations/google-tag-manager) pour plus de détails.

<Warning>
N'ajoutez pas la même propriété GA4 à la fois directement dans `docs.json` et via Google Tag Manager — cela entraînera un suivi en double.
</Warning>

## Considérations relatives à la confidentialité

Google Analytics collecte des données sur les visiteurs. Pensez à :

- Ajouter une bannière de consentement aux cookies si requis par le RGPD/CCPA
- Mettre à jour votre politique de confidentialité pour mentionner l'analytique
- Utiliser l'[anonymisation des IP](https://support.google.com/analytics/answer/2763052) si nécessaire

## Dépannage

<Accordion title="Aucune donnée n'apparaît">
  1. **Vérifiez votre identifiant de mesure** - Il doit commencer par `G-`
  2. **Vérifiez les bloqueurs de publicités** - Ils peuvent bloquer les scripts d'analytique
  3. **Attendez le rebuild** - Les modifications nécessitent un nouveau build pour prendre effet
  4. **Utilisez les rapports en temps réel** - Les rapports standard ont un délai de 24 à 48 heures
</Accordion>

<Accordion title="Erreur 'Identifiant de mesure invalide'">
  L'identifiant doit :
  - Commencer par `G-`
  - Ne contenir que des lettres et des chiffres après `G-`
  - Être copié exactement depuis Google Analytics (sans espaces supplémentaires)
</Accordion>
