Ajoutez Google Analytics 4 à votre site de documentation pour comprendre comment les utilisateurs interagissent avec votre contenu.

<Info>
L'intégration Google Analytics fonctionne avec les ID de mesure GA4 (Google Analytics 4) qui commencent par `G-`.
</Info>

## Obtenir votre ID de mesure

1. Accédez à [Google Analytics](https://analytics.google.com/)
2. Sélectionnez votre propriété (ou créez-en une)
3. Accédez à **Administration** → **Flux de données**
4. Sélectionnez votre flux Web (ou créez-en un)
5. Copiez l'**ID de mesure** (commence par `G-`)

## Ajouter GA4 à votre documentation

Ajoutez l'ID de mesure à votre `docs.json` :

```json docs.json
{
  "name": "My Docs",
  "integrations": {
    "ga4": {
      "measurementId": "G-XXXXXXXXXX"
    }
  }
}
```

Remplacez `G-XXXXXXXXXX` par votre ID de mesure réel.

## Consulter vos données

Après avoir ajouté l'intégration :

1. Déclenchez un nouveau build de votre documentation
2. Consultez votre site de documentation en ligne
3. Dans Google Analytics, accédez à **Rapports** → **Temps réel**
4. Votre visite devrait apparaître dans les 30 secondes

<Note>
Les données peuvent mettre 24 à 48 heures à apparaître dans les rapports standards. Utilisez les rapports en temps réel pour une vérification immédiate.
</Note>

## Utilisation avec Google Tag Manager

Si vous utilisez déjà Google Tag Manager, vous pouvez configurer GA4 via GTM au lieu de l'ajouter directement. Consultez [Intégration Google Tag Manager](/fr/integrations/google-tag-manager) pour plus de détails.

Vous êtes responsable de la mise en place de bannières de consentement aux cookies pour les tags que vous chargez via Google Tag Manager si vous en avez besoin—Jamdesk charge votre conteneur GTM pour tous les visiteurs sans dispositif de consentement. Consultez [Consentement aux cookies](/fr/integrations/cookie-consent) pour bloquer l'analytique jusqu'à ce que les visiteurs donnent leur accord.

<Warning>
N'ajoutez pas la même propriété GA4 à la fois directement dans `docs.json` et via Google Tag Manager—cela entraînera un suivi en double.
</Warning>

## Considérations relatives à la confidentialité

Google Analytics collecte des données sur les visiteurs. Pensez à :

- Ajouter une bannière de consentement aux cookies si le RGPD/CCPA s'applique. Jamdesk charge GA4 pour chaque visiteur par défaut, utilisez donc [Consentement aux cookies](/fr/integrations/cookie-consent) pour le bloquer jusqu'à ce qu'ils donnent leur accord.
- Mettre à jour votre politique de confidentialité pour mentionner l'analytique
- Utiliser l'[anonymisation IP](https://support.google.com/analytics/answer/2763052) si nécessaire

## Dépannage

<Accordion title="Aucune donnée ne s'affiche">
  1. **Vérifiez votre ID de mesure** - Il doit commencer par `G-`
  2. **Vérifiez les bloqueurs de publicités** - Ils peuvent bloquer les scripts d'analytique
  3. **Attendez le rebuild** - Les modifications nécessitent un nouveau build pour prendre effet
  4. **Utilisez les rapports en temps réel** - Les rapports standards ont un délai de 24 à 48 heures
</Accordion>

<Accordion title="Erreur « ID de mesure invalide »">
  L'ID doit :
  - Commencer par `G-`
  - Contenir uniquement des lettres et des chiffres après `G-`
  - Être copié exactement depuis Google Analytics (sans espaces superflus)
</Accordion>
