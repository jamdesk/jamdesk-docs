Connectez Slack pour recevoir les notifications de build directement dans le canal de votre équipe.

<Note>
L'intégration Slack est disponible sur les plans Pro.
</Note>

## Configuration de Slack

<Steps>
  <Step title="Créer un webhook Slack">
    Dans Slack :
    1. Accédez aux paramètres de votre espace de travail
    2. Accédez à **Apps** → **Incoming Webhooks**
    3. Cliquez sur **Add to Slack**
    4. Choisissez un canal
    5. Copiez l'URL du webhook
  </Step>
  <Step title="Ajouter à Jamdesk">
    Dans votre projet Jamdesk :
    1. Accédez à **Integrations**
    2. Cliquez sur **Connect Slack**
    3. Collez l'URL de votre webhook
    4. Cliquez sur **Save**
  </Step>
  <Step title="Tester la connexion">
    Cliquez sur **Send Test** pour vérifier que l'intégration fonctionne.
  </Step>
</Steps>

## Préférences de notification

Choisissez les résultats de build qui déclenchent des notifications :

| Événement | Par défaut | Description |
|-------|---------|-------------|
| Build réussi | Activé | Notifie lorsqu'un build se termine avec succès |
| Build échoué | Activé | Notifie lorsqu'un build échoue |

Les deux sont activés par défaut. Pour modifier les préférences après la configuration, activez ou désactivez les cases à cocher puis cliquez sur **Update**.

## Format des messages

Les notifications incluent :

- Nom du projet
- Statut du build
- Message de commit et auteur
- Lien vers les détails du build
- Durée (pour les builds terminés)

Exemple :
``` text
✓ Docs build succeeded
Project: My Docs
Commit: "Add authentication guide" by @username
Duration: 45s
View build →
```

## Supprimer Slack

Pour vous déconnecter :

1. Accédez à **Integrations**
2. Cliquez sur **Disconnect** à côté de Slack
3. Confirmez la suppression

## Dépannage

<Accordion title="Les notifications n'apparaissent pas">
  1. Vérifiez que l'URL du webhook est correcte
  2. Vérifiez que le canal existe toujours
  3. Envoyez une notification de test
  4. Vérifiez les paramètres des webhooks entrants de Slack
</Accordion>

<Accordion title="Les préférences modifiées ne sont pas enregistrées">
  Après avoir modifié les cases à cocher de notification, cliquez sur le bouton **Update** qui apparaît. Les modifications ne sont pas enregistrées automatiquement.
</Accordion>
