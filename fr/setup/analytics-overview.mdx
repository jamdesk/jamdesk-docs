Deux tableaux de bord : **Project Analytics** pour le trafic et **Search Analytics** pour les requêtes de recherche.

## Ce que vous obtenez

  <Card title="Project Analytics" icon="chart-line" href="/fr/setup/project-analytics">

  </Card>
  <Card title="Search Analytics" icon="magnifying-glass" href="/fr/setup/search-analytics">

## Comment y accéder

<Steps>
  <Step title="Ouvrez votre projet">
    Allez sur [dashboard.jamdesk.com](https://dashboard.jamdesk.com) et sélectionnez votre projet.
  </Step>
  <Step title="Ouvrez Analytics">
    Cliquez sur **Analytics** dans la barre latérale pour accéder aux deux tableaux de bord.
  </Step>
  <Step title="Choisissez une plage de dates">
    Utilisez le sélecteur de dates pour comparer des périodes et repérer les évolutions au fil du temps.
  </Step>
</Steps>

## Exemple de synthèse

Voici un exemple de synthèse analytique présentant les deux tableaux de bord côte à côte :

```json
{
  "period": "Last 30 days",
  "project_analytics": {
    "visitors": 4120,
    "views": 12890,
    "top_pages": ["/quickstart", "/content/mdx-basics", "/deploy/overview"]
  },
  "search_analytics": {
    "total_searches": 940,
    "zero_results": 42,
    "top_queries": ["authentication", "api keys", "custom domains"]
  }
}
```

## Flux de travail courants

- **Identifiez les pages d'entrée principales** et assurez-vous qu'elles expliquent le produit rapidement.
- **Repérez les lacunes de recherche** où les utilisateurs obtiennent zéro résultat et ajoutez le contenu manquant.
- **Suivez l'impact d'un lancement** en comparant le trafic avant et après une version.
