Jamdesk prend en charge le Single Sign-On pour le dashboard (où vous gérez vos projets) et vos sites de documentation publiés (où votre équipe consulte la documentation interne). Le SSO est disponible sur les **plans Enterprise**.

## Ce que couvre le SSO

<Columns cols={2}>
  <Card title="SSO du dashboard" icon="gauge">
    Votre équipe se connecte à `dashboard.jamdesk.com` avec votre fournisseur d'identité. Idéal pour centraliser la gestion des comptes, imposer le MFA via votre IdP et révoquer instantanément les accès lors du départ d'un utilisateur.
  </Card>
  <Card title="SSO du site de documentation" icon="book-open">
    Les lecteurs s'authentifient auprès de votre IdP avant de pouvoir consulter la documentation protégée. Remplace le modèle de mot de passe partagé par une connexion par utilisateur, une piste d'audit et une révocation à la suppression.
  </Card>
</Columns>

## À qui s'adresse cette fonctionnalité

- Les entreprises disposant d'un fournisseur d'identité existant (Okta, Google Workspace, Azure AD / Entra ID, Auth0, etc.).
- Les équipes ayant besoin d'une piste d'audit indiquant qui a accédé à quelle documentation.
- Les organisations où la révocation des accès doit être immédiate — supprimer un utilisateur de l'IdP doit instantanément révoquer son accès aux docs.
- Toute personne réticente à partager une même phrase secrète avec un grand nombre de lecteurs.

## Comment l'activer

La configuration du SSO est personnalisée — chaque IdP est configuré différemment, et nous souhaitons nous assurer que les métadonnées, les mappages de claims et les filtres de groupes de votre équipe sont corrects avant d'activer la fonctionnalité.

[**Contacter l'équipe commerciale Enterprise →**](https://www.jamdesk.com/pricing)

La page de tarification présente les niveaux de plans actuels et le chemin de contact pour l'offre Enterprise. Notre équipe vous guidera ensuite dans la configuration de l'IdP, testera l'intégration sur un sous-domaine de staging, puis déploiera en production lorsque vous serez prêt.
