Avant de rédiger votre documentation, vous avez besoin d'un projet. Vous pouvez démarrer à partir d'un modèle (Jamdesk crée le dépôt GitHub pour vous) ou connecter un dépôt existant qui contient déjà un `docs.json`. Dans tous les cas, vous aurez un site en ligne en quelques minutes.

## Créer un nouveau projet

<Steps>
  <Step title="Se connecter à Jamdesk">
    Accédez à [dashboard.jamdesk.com](https://dashboard.jamdesk.com) et connectez-vous avec votre compte GitHub.

    Les nouveaux utilisateurs seront invités à autoriser l'application GitHub Jamdesk.
  </Step>

  <Step title="Cliquer sur Nouveau projet">
    Depuis le dashboard, cliquez sur **Nouveau projet** en haut à droite.
  </Step>

  <Step title="Choisir un point de départ">
    <Tabs>
      <Tab title="À partir d'un modèle">
        Démarrez avec un modèle prédéfini. Jamdesk crée un nouveau dépôt GitHub pour vous avec du contenu, une navigation et des composants déjà configurés.

        Le [modèle Starter](https://github.com/jamdesk/starter-docs) par défaut inclut des pages d'exemple, une spec OpenAPI et des exemples de chaque composant — remplacez le contenu par le vôtre et c'est prêt.
      </Tab>
      <Tab title="À partir d'un dépôt">
        Connectez un dépôt GitHub existant :

        1. Sélectionnez le dépôt dans la liste déroulante
        2. Choisissez la branche à déployer (généralement `main`)
        3. Indiquez le chemin vers `docs.json` s'il ne se trouve pas à la racine
      </Tab>
    </Tabs>
  </Step>

  <Step title="Configurer les paramètres du projet">
    Définissez les informations de base de votre projet :

    | Champ | Description |
    |-------|-------------|
    | **Nom** | Nom affiché dans le dashboard |
    | **Slug** | Identifiant compatible URL (ex. : `my-docs`) |
    | **Domaine** | Votre sous-domaine `*.jamdesk.app` |
  </Step>
</Steps>

## Structure minimale du dépôt

Un projet Jamdesk nécessite uniquement un `docs.json` et au moins une page :

```bash
my-docs/
├── docs.json
└── introduction.mdx
```

Exemple de `docs.json` :

```json
{
  "$schema": "https://jamdesk.com/docs.json",
  "name": "My Docs",
  "theme": "jam",
  "navigation": {
    "groups": [
      {
        "group": "Getting Started",
        "pages": ["introduction"]
      }
    ]
  }
}
```

## Paramètres du projet

Après la création, configurez votre projet dans **Paramètres** :

### Général

- **Nom** - Modifier le nom affiché
- **Slug** - Changer l'identifiant du projet
- **Supprimer le projet** - Supprimer définitivement le projet

### Dépôt

- **Branche** - La branche qui déclenche les déploiements
- **Chemin des docs** - Emplacement de `docs.json` pour les monorepos

### Domaine

- **Sous-domaine** - Votre URL `*.jamdesk.app`
- **Domaine personnalisé** - Ajouter votre propre domaine
- **Héberger à /docs** - Servir la documentation au chemin `/docs` plutôt qu'à la racine

### Build

- **Afficher la marque Jamdesk** - Afficher le lien "Propulsé par Jamdesk" dans votre pied de page (activé par défaut)
- **Reconstruire** - Déclencher manuellement un nouveau build

<Note>
Les modifications des paramètres de build nécessitent un nouveau build pour prendre effet.
</Note>
