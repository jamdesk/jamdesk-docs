Avant de rédiger la moindre documentation, vous avez besoin d'un projet. Vous pouvez partir d'un template (Jamdesk crée le dépôt GitHub pour vous) ou connecter un dépôt existant qui possède déjà un `docs.json`. Dans les deux cas, votre site sera en ligne en quelques minutes.

## Créer un nouveau projet

<Steps>
  <Step title="Se connecter à Jamdesk">
    Rendez-vous sur [dashboard.jamdesk.com](https://dashboard.jamdesk.com) et connectez-vous avec votre compte GitHub.

    Les nouveaux utilisateurs seront invités à autoriser l'application GitHub de Jamdesk.
  </Step>

  <Step title="Cliquer sur New Project">
    Depuis le dashboard, cliquez sur **New Project** en haut à droite.
  </Step>

  <Step title="Choisir un point de départ">
    <Tabs>
      <Tab title="From Template">
        Partez d'un template préconçu. Jamdesk crée un nouveau dépôt GitHub pour vous, avec du contenu d'exemple, une navigation et des composants déjà configurés.

        Le [Starter Template](https://github.com/jamdesk/starter-docs) par défaut inclut des pages d'exemple, une spécification OpenAPI et des exemples de chaque composant. Remplacez le contenu par le vôtre, et c'est terminé.
      </Tab>
      <Tab title="From Repository">
        Connectez un dépôt GitHub existant :

        1. Sélectionnez le dépôt dans le menu déroulant
        2. Choisissez la branche à déployer (généralement `main`)
        3. Indiquez le chemin vers `docs.json` s'il ne se trouve pas à la racine
      </Tab>
    </Tabs>
  </Step>

  <Step title="Configurer les paramètres du projet">
    Définissez les informations de base de votre projet :

    | Champ | Description |
    |-------|-------------|
    | **Name** | Nom d'affichage indiqué dans le dashboard |
    | **Slug** | Identifiant compatible URL (par ex. `my-docs`) |
    | **Domain** | Votre sous-domaine `*.jamdesk.app` |
  </Step>
</Steps>

## Structure minimale du dépôt

Un projet Jamdesk n'a besoin que d'un `docs.json` et d'au moins une page :

```bash
my-docs/
├── docs.json
└── introduction.mdx
```

Exemple de `docs.json` :

```json docs.json
{
  "$schema": "https://jamdesk.com/docs.json",
  "name": "My Docs",
  "theme": "jam",
  "navigation": {
    "groups": [
      {
        "group": "Getting Started",
        "pages": ["introduction"]
      }
    ]
  }
}
```

## Paramètres du projet

Après la création, configurez votre projet dans **Settings** :

### General

- **Name** - Modifier le nom d'affichage
- **Slug** - Changer l'identifiant du projet
- **Delete Project** - Supprimer définitivement le projet

### Repository

- **Branch** - Quelle branche déclenche les déploiements
- **Docs Path** - Emplacement du `docs.json` pour les monorepos

### Domain

- **Subdomain** - Votre URL `*.jamdesk.app`
- **Custom Domain** - Ajouter votre propre domaine
- **Host at a subpath** - Servir la documentation sur un chemin comme `/docs` ou `/help` au lieu de la racine du site

### Build

- **Show Jamdesk Branding** - Afficher le lien « Powered by Jamdesk » dans votre footer (activé par défaut)
- **Rebuild** - Déclencher manuellement un nouveau build

<Note>
Les modifications des paramètres de build nécessitent un nouveau build pour prendre effet.
</Note>
