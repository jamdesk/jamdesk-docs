---

Avant d'écrire de la documentation, vous avez besoin d'un projet. Vous pouvez partir d'un modèle (Jamdesk crée le dépôt pour vous, sur GitHub ou Bitbucket Cloud) ou connecter un dépôt existant qui possède déjà un `docs.json`. Dans les deux cas, vous aurez un site en ligne en quelques minutes.

## Créer un nouveau projet

<Steps>
  <Step title="Se connecter à Jamdesk">
    Accédez à [dashboard.jamdesk.com](https://dashboard.jamdesk.com) et connectez-vous avec votre compte GitHub.

    Les nouveaux utilisateurs seront invités à autoriser l'application GitHub de Jamdesk.
  </Step>

  <Step title="Cliquer sur New Project">
    Depuis le dashboard, cliquez sur **New Project** dans le coin supérieur droit.
  </Step>

  <Step title="Choisir un point de départ">
    <Tabs>
      <Tab title="Depuis un modèle">
        Partez d'un modèle prédéfini. Jamdesk crée un nouveau dépôt GitHub pour vous, avec du contenu d'exemple, une navigation et des composants déjà configurés.

        Le [modèle de démarrage](https://github.com/jamdesk/starter-docs) par défaut inclut des pages d'exemple, une spécification OpenAPI et des exemples de chaque composant. Remplacez le contenu par le vôtre, et c'est terminé.
      </Tab>
      <Tab title="Depuis un dépôt">
        Connectez un dépôt GitHub existant :

        1. Sélectionnez le dépôt dans la liste déroulante
        2. Choisissez la branche à déployer (généralement `main`)
        3. Indiquez le chemin vers `docs.json` s'il n'est pas à la racine

        Dépôt sur Bitbucket Cloud ? Indiquez-le plutôt sous la forme `workspace/repository-slug`. Consultez [Connecter Bitbucket](/fr/setup/connecting-bitbucket).
      </Tab>
    </Tabs>
  </Step>

  <Step title="Configurer les paramètres du projet">
    Définissez les informations de base de votre projet :

    | Field | Description |
    |-------|-------------|
    | **Name** | Nom affiché dans le dashboard |
    | **Slug** | Identifiant convivial pour l'URL (par ex. `my-docs`) |
    | **Domain** | Votre sous-domaine `*.jamdesk.app` |
  </Step>
</Steps>

## Structure minimale du dépôt

Un projet Jamdesk n'a besoin que d'un `docs.json` et d'au moins une page :

```bash
my-docs/
├── docs.json
└── introduction.mdx
```

Exemple de `docs.json` :

```json docs.json
{
  "$schema": "https://jamdesk.com/docs.json",
  "name": "My Docs",
  "theme": "jam",
  "navigation": {
    "groups": [
      {
        "group": "Getting Started",
        "pages": ["introduction"]
      }
    ]
  }
}
```

## Paramètres du projet

Une fois le projet créé, configurez-le dans **Settings** :

### Général

- **Name** - Modifie le nom affiché
- **Slug** - Modifie l'identifiant du projet
- **Delete Project** - Supprime définitivement le projet

### Dépôt

- **Branch** - Branche qui déclenche les déploiements
- **Docs Path** - Emplacement du `docs.json` pour les monorepos

### Domaine

- **Subdomain** - Votre URL `*.jamdesk.app`
- **Custom Domain** - Ajoutez votre propre domaine
- **Host at a subpath** - Servez la documentation à un chemin comme `/docs` ou `/help` au lieu de la racine du site

### Build

- **Show Jamdesk Branding** - Affiche le lien « Powered by Jamdesk » dans votre pied de page (activé par défaut)
- **Rebuild** - Déclenche manuellement un nouveau build

<Note>
Les modifications des paramètres Build nécessitent un nouveau build pour prendre effet.
</Note>
