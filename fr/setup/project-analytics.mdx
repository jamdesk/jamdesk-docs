Suivez les pages vues, les sources de trafic et le contenu populaire grâce à l'analytique intégrée. Aucun cookie requis.

Les captures d'écran montrent l'interface en anglais.

<Note>
L'analytique est axée sur la confidentialité — pas de cookies, données anonymisées. Si les métriques semblent vides, consultez [Problèmes d'analytique](/fr/help/troubleshooting/analytics-issues).
</Note>

## Consulter les analytiques

Accédez aux analytiques depuis le dashboard de votre projet :

<Steps>
  <Step title="Ouvrez votre projet">
    Rendez-vous sur [dashboard.jamdesk.com](https://dashboard.jamdesk.com) et sélectionnez votre projet.
  </Step>

  <Step title="Cliquez sur Analytiques">
    Dans la barre latérale, cliquez sur **Analytics** pour afficher votre dashboard.
  </Step>

  <Step title="Sélectionnez une plage de dates">
    Utilisez le sélecteur de dates pour consulter les analytiques sur différentes périodes :

    - **7 derniers jours** (par défaut)
    - **30 derniers jours**
    - **90 derniers jours**
    - **Plage personnalisée**
  </Step>
</Steps>

## Ce qui est suivi

Le dashboard d'analytique affiche les métriques clés concernant le trafic de votre documentation :

### Métriques générales

| Métrique | Description |
|--------|-------------|
| **Visiteurs** | Sessions uniques sur la période sélectionnée |
| **Vues** | Total des pages consultées |

Chaque métrique inclut une comparaison avec la période précédente, affichée sous forme de variation en pourcentage.

Exemple d'instantané :

```json
{
  "period": "Last 30 days",
  "visitors": 4120,
  "views": 12890,
  "top_referrers": ["google.com", "github.com", "direct"],
  "top_pages": ["/introduction", "/quickstart", "/content/mdx-basics"]
}
```

### Pages populaires

Identifiez les pages de documentation qui reçoivent le plus de trafic. Utilisez ces informations pour :

- Identifier le contenu à forte valeur à maintenir à jour
- Trouver les pages qui pourraient nécessiter des améliorations (faible engagement)
- Comprendre les schémas de navigation des utilisateurs

### Sources de trafic

Suivez la provenance de vos visiteurs :

| Type de source | Exemples |
|-------------|----------|
| **Moteurs de recherche** | Google, Bing, DuckDuckGo |
| **Réseaux sociaux** | Twitter, LinkedIn, Reddit |
| **Direct** | URL saisie ou favoris |
| **Référents** | Liens provenant d'autres sites web |

### Données géographiques

Consultez la localisation des visiteurs sur une carte du monde interactive :

- **Répartition par pays** — Identifiez les pays d'où proviennent vos visiteurs
- **Carte thermique visuelle** — Les couleurs plus foncées indiquent davantage de trafic

Cela vous aide à comprendre votre audience et à prioriser les efforts de localisation.

### Répartition technologique

Comprenez quels appareils et navigateurs utilisent vos visiteurs :

<Tabs>
  <Tab title="Navigateurs">
    - Chrome, Safari, Firefox, Edge
    - Aide à identifier les problèmes spécifiques aux navigateurs
  </Tab>
  <Tab title="Systèmes d'exploitation">
    - Windows, macOS, Linux, iOS, Android
    - Comprenez la part de votre audience sur desktop ou mobile
  </Tab>
  <Tab title="Appareils">
    - Desktop, Mobile, Tablette
    - Guide les priorités en matière de design responsive
  </Tab>
</Tabs>

### Pages d'entrée et de sortie

| Métrique | Ce qu'elle montre |
|--------|---------------|
| **Pages d'entrée** | Première page sur laquelle les visiteurs atterrissent |
| **Pages de sortie** | Dernière page consultée avant de quitter |

Utilisez ces informations pour :
- Optimiser les pages d'atterrissage (points d'entrée)
- Identifier où les utilisateurs abandonnent (sorties)
- Améliorer la navigation pour maintenir l'engagement des utilisateurs

## Fonctionnalités de confidentialité

L'analytique Jamdesk est conçue dans le respect de la confidentialité :

<Columns cols={2}>
  <Card title="Sans cookies" icon="cookie-bite">
    Les sessions sont suivies à l'aide d'empreintes anonymes, sans cookies. Aucune bannière de cookies requise.
  </Card>
  <Card title="Filtrage des bots" icon="robot">
    Le trafic automatisé provenant des robots d'indexation et des bots est automatiquement filtré.
  </Card>
  <Card title="Sans données personnelles" icon="user-shield">

  </Card>
  <Card title="Conforme RGPD" icon="shield-check">
    Conforme au RGPD et aux réglementations de confidentialité courantes par défaut.
  </Card>
</Columns>

## Suivi de la navigation SPA

Jamdesk suit automatiquement la navigation dans les applications monopage (SPA). Lorsque les visiteurs naviguent entre les pages sans rechargement complet de la page, chaque navigation est capturée comme une vue de page distincte.

Cela fonctionne automatiquement pour :
- Les liens internes au sein de votre documentation
- La navigation précédent/suivant du navigateur
- La navigation programmatique

## Conservation des données

Les données analytiques sont conservées selon votre forfait :

| Forfait | Événements bruts | Données agrégées |
|------|-----------|-----------------|
| Gratuit | 30 jours | 1 an |
| Pro | 90 jours | 2 ans |
| Team | 90 jours | Illimité |

Les événements bruts sont automatiquement regroupés en agrégats journaliers pour un stockage à long terme et des requêtes plus rapides.

## Comparaison de périodes

Le dashboard d'analytique compare automatiquement la période sélectionnée à la période précédente équivalente :

- **7 derniers jours** comparés aux 7 jours précédents
- **30 derniers jours** comparés aux 30 jours précédents

Les variations en pourcentage sont affichées avec :
- Badge **vert** pour les augmentations
- Badge **rouge** pour les diminutions

Cela vous aide à identifier rapidement les tendances et à mesurer l'impact des modifications apportées à votre documentation.

## Bonnes pratiques

<Accordion title="Consultez régulièrement les pages populaires">
Vos pages les plus consultées méritent le plus d'attention. Maintenez-les précises, bien entretenues et faciles à parcourir.
</Accordion>

<Accordion title="Surveillez les pages d'entrée">
Si les visiteurs atterrissent fréquemment sur une page spécifique depuis la recherche, assurez-vous qu'elle fournit un bon contexte et des prochaines étapes claires.
</Accordion>

<Accordion title="Vérifiez la répartition par appareil">
Si une part significative du trafic provient de mobiles, testez votre documentation sur des appareils mobiles pour garantir une bonne lisibilité.
</Accordion>

<Accordion title="Suivez les référents">
Lorsque vous partagez des liens de documentation en externe, surveillez les données de référents pour identifier quels canaux génèrent le plus de trafic.
</Accordion>
