Suivez les pages vues, les sources de trafic et le contenu populaire grâce à l'analytique intégrée. Aucun cookie requis.

Les captures d'écran montrent l'interface en anglais.

<Note>
L'analytique respecte la vie privée : aucun cookie, données anonymisées. Si les métriques semblent vides, consultez [Problèmes d'analytique](/fr/help/troubleshooting/analytics-issues).
</Note>

## Consulter l'analytique

Accédez à l'analytique depuis votre dashboard de projet :

<Steps>
  <Step title="Ouvrez votre projet">
    Allez sur [dashboard.jamdesk.com](https://dashboard.jamdesk.com) et sélectionnez votre projet.
  </Step>

  <Step title="Cliquez sur Analytics">
    Dans la barre latérale, cliquez sur **Analytics** pour afficher votre dashboard.
  </Step>

  <Step title="Sélectionnez une plage de dates">
    Utilisez le sélecteur de dates pour afficher l'analytique sur différentes périodes :

    - **7 derniers jours** (par défaut)
    - **30 derniers jours**
    - **90 derniers jours**
    - **Plage personnalisée**
  </Step>
</Steps>

## Ce qui est suivi

Le dashboard d'analytique affiche les métriques clés sur le trafic de votre documentation :

### Métriques générales

| Métrique | Description |
|--------|-------------|
| **Visiteurs** | Sessions uniques sur la période sélectionnée |
| **Vues** | Total des pages vues |

Chaque métrique inclut une comparaison avec la période précédente, affichée sous forme de variation en pourcentage.

Exemple d'aperçu :

```json
{
  "period": "Last 30 days",
  "visitors": 4120,
  "views": 12890,
  "top_referrers": ["google.com", "github.com", "direct"],
  "top_pages": ["/introduction", "/quickstart", "/content/mdx-basics"]
}
```

### Pages populaires

Découvrez quelles pages de documentation génèrent le plus de trafic. Utilisez ceci pour :

- Identifier le contenu à forte valeur à maintenir à jour
- Repérer les pages qui pourraient nécessiter des améliorations (faible engagement)
- Comprendre les schémas de navigation des utilisateurs

### Sources de trafic

Suivez d'où viennent vos visiteurs :

| Type de source | Exemples |
|-------------|----------|
| **Moteurs de recherche** | Google, Bing, DuckDuckGo |
| **Réseaux sociaux** | Twitter, LinkedIn, Reddit |
| **Direct** | URL saisie ou favoris |
| **Référencements** | Liens depuis d'autres sites web |

### Données géographiques

Visualisez l'emplacement des visiteurs sur une carte du monde interactive :

- **Répartition par pays** - Voyez de quels pays viennent vos visiteurs
- **Carte thermique visuelle** - Les couleurs plus foncées indiquent plus de trafic

Utilisez la répartition par pays pour décider quelles langues prioriser pour la localisation.

### Répartition technologique

Comprenez quels appareils et navigateurs utilisent vos visiteurs :

<Tabs>
  <Tab title="Navigateurs">

    - Aide à identifier les problèmes spécifiques à un navigateur
  </Tab>
  <Tab title="Systèmes d'exploitation">
    - Windows, macOS, Linux, iOS, Android
    - Comprenez votre audience desktop par rapport au mobile
  </Tab>
  <Tab title="Appareils">
    - Desktop, mobile, tablette
    - Guide les priorités de conception responsive
  </Tab>
</Tabs>

### Pages d'entrée et de sortie

| Métrique | Ce qu'elle montre |
|--------|---------------|
| **Pages d'entrée** | Première page sur laquelle arrivent les visiteurs |
| **Pages de sortie** | Dernière page avant de quitter |

Utilisez ceci pour :
- Optimiser les pages d'atterrissage (points d'entrée)
- Identifier où les utilisateurs abandonnent (sorties)
- Améliorer la navigation pour garder les utilisateurs engagés

## Fonctionnalités de confidentialité

L'analytique Jamdesk protège la vie privée des visiteurs :

<Columns cols={2}>
  <Card title="Aucun cookie" icon="cookie-bite">
    Les sessions sont suivies à l'aide d'empreintes anonymes, et non de cookies. Aucune bannière de cookies requise.
  </Card>
  <Card title="Filtrage des bots" icon="robot">
    Le trafic automatisé provenant des robots d'indexation et des bots est filtré automatiquement.
  </Card>
  <Card title="Aucune donnée personnelle" icon="user-shield">
    Les informations personnelles comme les adresses IP ne sont pas stockées de façon permanente.
  </Card>
  <Card title="Conforme RGPD" icon="shield-check">
    Conforme au RGPD et aux réglementations courantes en matière de confidentialité par défaut.
  </Card>
</Columns>

## Suivi de navigation SPA

Jamdesk suit automatiquement la navigation dans les applications monopages (SPA). Lorsque les visiteurs naviguent entre les pages sans rechargement complet, chaque navigation est enregistrée comme une vue de page distincte.

Cela fonctionne automatiquement pour :
- Les liens internes au sein de votre documentation
- La navigation avant/arrière du navigateur
- La navigation programmatique

## Conservation des données

Les données d'analytique sont conservées selon votre plan :

| Plan | Événements bruts | Données agrégées |
|------|-----------|-----------------|
| Free | 30 jours | 1 an |
| Pro | 90 jours | 2 ans |
| Team | 90 jours | Illimité |

Les événements bruts sont automatiquement regroupés en agrégats quotidiens pour un stockage à long terme et des requêtes plus rapides.

## Comparaison des périodes

Le dashboard d'analytique compare automatiquement votre période sélectionnée à la période précédente équivalente :

- **7 derniers jours** se compare aux 7 jours précédents
- **30 derniers jours** se compare aux 30 jours précédents

Les variations en pourcentage sont affichées avec :
- Un badge **vert** pour les augmentations
- Un badge **rouge** pour les diminutions

Utilisez la comparaison pour repérer les tendances après une modification de votre documentation.

## Bonnes pratiques

<Accordion title="Examinez régulièrement les pages populaires">
Vos pages les plus consultées méritent le plus d'attention. Gardez-les précises, bien entretenues et faciles à naviguer.
</Accordion>

<Accordion title="Surveillez les pages d'entrée">
Si les visiteurs arrivent fréquemment sur une page spécifique depuis la recherche, assurez-vous qu'elle fournit un bon contexte et des prochaines étapes claires.
</Accordion>

<Accordion title="Vérifiez la répartition par appareil">
Si une part importante du trafic est mobile, testez votre documentation sur des appareils mobiles pour garantir une bonne lisibilité.
</Accordion>

<Accordion title="Suivez les référencements">
Lorsque vous partagez des liens de documentation en externe, surveillez les données de référencement pour voir quels canaux génèrent le plus de trafic.
</Accordion>
