Chaque fois que vous demandez à Claude d'écrire une page Jamdesk, vous finissez par expliquer les mêmes choses : quels composants existent, comment fonctionne `docs.json`, quelles sont les commandes CLI. Ce plugin donne à [Claude Code](https://claude.ai/code) ces connaissances dès le départ, afin que vous puissiez passer directement à la construction sans préambule.

<Note>
  Vous devez d'abord installer Claude Code. Récupérez-le sur [claude.ai/code](https://claude.ai/code).
</Note>

## Installation

<Steps>
  <Step title="Ajouter le marketplace">
    Exécutez cette commande slash dans Claude Code :

    ```text
    /plugin marketplace add jamdesk/jamdesk-claude-plugin
    ```
  </Step>
  <Step title="Installer le plugin">
    ```text
    /plugin install jamdesk@jamdesk-marketplace
    ```
  </Step>
</Steps>

Vous pouvez aussi le trouver en exécutant `/plugin` et en sélectionnant **Discover**.

<Accordion title="Installation manuelle (pour le développement ou les tests)">
  ```bash
  git clone https://github.com/jamdesk/jamdesk-claude-plugin.git
  claude --plugin-dir ./jamdesk-claude-plugin
  ```
</Accordion>

## Ce qui est inclus

Une compétence (`/jamdesk:jamdesk`) avec un hub de référence rapide et trois fichiers de référence détaillés chargés à la demande :

| Référence | Ce qu'elle couvre |
|-----------|---------------|
| **Composants** | 25+ composants MDX (Cards, Steps, Tabs, Callouts, Code Groups, Tables, et plus) avec les props complètes et des exemples |
| **Configuration** | Schéma `docs.json` complet : thèmes, couleurs, image de marque, barre de navigation, pied de page, config API, 20+ intégrations d'analytique |
| **Navigation** | 8 modèles de navigation : plat, groupé, à onglets, multi-produits, versionné, multilingue, menus déroulants, OpenAPI |

Le hub inclut également les 19 commandes CLI, les champs de frontmatter de page, la syntaxe de dimensionnement des images, les standards de rédaction et les erreurs courantes.

## Utilisation

Lorsque vous travaillez sur la documentation Jamdesk, exécutez `/jamdesk:jamdesk`.

Si votre projet a un `docs.json`, Claude peut activer la compétence automatiquement.

Les questions courantes (syntaxe des composants, commandes CLI) trouvent une réponse directement dans le hub. Besoin de tableaux de props complets, de toutes les options de configuration, ou des détails d'un modèle de navigation ? Claude charge le fichier de référence spécifique.

## Association avec CLAUDE.md et MCP

Fonctionne mieux dans le cadre d'une configuration à trois couches :

1. Le plugin enseigne à Claude la plateforme de Jamdesk : composants, configuration, navigation, CLI.
2. [CLAUDE.md](/fr/ai/claude-code) enseigne à Claude les conventions de *votre projet* : style de rédaction, terminologie, structure de page.
3. Le [serveur MCP](/fr/ai/mcp-server) donne à Claude accès à votre documentation publiée, afin qu'il puisse rechercher, lire le contenu et vérifier les pages existantes.

Vous n'avez pas besoin des trois. Le plugin seul est déjà utile. Mais associé à un CLAUDE.md et une connexion MCP, Claude peut écrire des pages qui correspondent à la voix de votre site et créer des liens vers votre contenu existant sans avoir à deviner.

## Mise à jour et source
