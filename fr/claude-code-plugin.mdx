Chaque fois que vous demandez à Claude d'écrire une page Jamdesk, vous finissez par expliquer les mêmes choses : quels composants existent, comment fonctionne `docs.json`, quelles sont les commandes CLI. Ce plugin donne à [Claude Code](https://claude.ai/code) ces connaissances dès le départ, afin que vous puissiez éviter le préambule et passer directement à la construction.

<Note>
  Vous devez d'abord avoir Claude Code installé. Obtenez-le sur [claude.ai/code](https://claude.ai/code).
</Note>

## Installation

<Steps>
  <Step title="Ajouter le marketplace">
    Exécutez cette commande slash dans Claude Code :

    ```text
    /plugin marketplace add jamdesk/jamdesk-claude-plugin
    ```
  </Step>
  <Step title="Installer le plugin">
    ```text
    /plugin install jamdesk@jamdesk-marketplace
    ```
  </Step>
</Steps>

Vous pouvez également le trouver en exécutant `/plugin` et en sélectionnant **Discover**.

<Accordion title="Installation manuelle (pour le développement ou les tests)">
  ```bash
  git clone https://github.com/jamdesk/jamdesk-claude-plugin.git
  claude --plugin-dir ./jamdesk-claude-plugin
  ```
</Accordion>

## Contenu inclus

Une skill (`/jamdesk:jamdesk`) avec un hub de référence rapide et trois fichiers de référence détaillés chargés à la demande :

| Référence | Ce qu'elle couvre |
|-----------|------------------|
| **Composants** | Plus de 25 composants MDX (Cards, Steps, Tabs, Callouts, Code Groups, Tables, et plus) avec les props complets et des exemples |
| **Configuration** | Schéma complet de `docs.json` : thèmes, couleurs, branding, navbar, footer, configuration API, plus de 20 intégrations analytiques |
| **Navigation** | 8 patterns de navigation : plat, groupé, à onglets, multi-produit, versionné, multi-langue, dropdowns, OpenAPI |

Le hub inclut également les 19 commandes CLI, les champs frontmatter de page, la syntaxe de dimensionnement des images, les normes de rédaction et les erreurs courantes.

## Utilisation

Lorsque vous travaillez sur la documentation Jamdesk, exécutez `/jamdesk:jamdesk`.

Si votre projet dispose d'un `docs.json`, Claude peut activer la skill automatiquement.

Les questions courantes (syntaxe des composants, commandes CLI) reçoivent une réponse directement depuis le hub. Vous avez besoin de tableaux de props complets, de toutes les options de configuration ou des détails sur les patterns de navigation ? Claude charge le fichier de référence spécifique.

## Association avec CLAUDE.md et MCP

Fonctionne mieux dans le cadre d'une configuration à trois niveaux :

1. Le plugin enseigne à Claude la plateforme Jamdesk : composants, configuration, navigation, CLI.
2. [CLAUDE.md](/fr/ai/claude-code) enseigne à Claude les conventions *de votre projet* — style d'écriture, terminologie, structure des pages.
3. Le [serveur MCP](/fr/ai/mcp-server) donne à Claude accès à votre documentation publiée, afin qu'il puisse rechercher, lire du contenu et vérifier les pages existantes.

Vous n'avez pas besoin des trois. Le plugin seul est utile. Mais associé à un CLAUDE.md et à une connexion MCP, Claude peut rédiger des pages qui correspondent à la voix de votre site et créer des liens vers votre contenu existant sans avoir à deviner.

## Mises à jour et source

Vérifiez les mises à jour en exécutant `/plugin` dans Claude Code. Vous pouvez également relancer la commande d'installation pour récupérer la dernière version.
