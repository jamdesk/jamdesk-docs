Si vous souhaitez que des outils IA comme ChatGPT, Claude ou Copilot donnent des réponses précises sur votre produit, ils ont besoin d'un accès structuré à votre documentation — pas seulement de ce qui figure dans leurs données d'entraînement.

Chaque site Jamdesk génère `llms.txt` et `llms-full.txt` en suivant la spécification [llmstxt.org](https://llmstxt.org). Les outils IA lisent ces fichiers plutôt que de crawler les pages individuellement.

<Note>
  Google audite désormais `llms.txt` dans le cadre des [vérifications de navigation agentique de Lighthouse](https://developer.chrome.com/docs/lighthouse/agentic-browsing/llms-txt). Les sites qui publient un `llms.txt` valide sont plus facilement découvrables par les agents IA — et de plus en plus, par Google lui-même lors du classement du contenu pour les réponses IA. Jamdesk vous offre cela gratuitement.
</Note>

<Tip>
  **Vérifiez votre score.** Découvrez à quel point n'importe quel site de documentation est prêt pour les agents IA grâce à l'outil gratuit [AI Score](https://www.jamdesk.com/ai-score) — publier un `llms.txt` valide est l'une des premières choses qu'il vérifie. Il existe aussi une [extension Chrome AI Score](https://chromewebstore.google.com/detail/jamdesk-ai-score/mhihkkgpcbmapmojnakhjfhjmiagkhlj) pour évaluer les sites pendant que vous naviguez.
</Tip>

## Ce que Jamdesk génère

| Fichier | Contenu |
|---------|---------|
| `llms.txt` | Titres de pages, descriptions et URLs (une table des matières structurée) |
| `llms-full.txt` | Contenu complet de la documentation dans un fichier unique |

Jamdesk génère les deux au moment du build et les sert depuis le même CDN que votre documentation.

## Vérifier vos fichiers

Vérifiez que vos fichiers existent après votre premier build :

<Tabs>
  <Tab title="Domaine racine">
    Si votre documentation se trouve à la racine de votre domaine (par exemple, `docs.acme.com` ou `acme.jamdesk.app`) :

    ```bash
    curl https://docs.acme.com/llms.txt
    curl https://docs.acme.com/llms-full.txt
    ```
  </Tab>
  <Tab title="Sous-chemin /docs">
    Si votre documentation se trouve sous `/docs` sur votre site principal (comme ce site sur `jamdesk.com/docs`) :

    ```bash
    curl https://jamdesk.com/docs/llms.txt
    curl https://jamdesk.com/docs/llms-full.txt
    ```
  </Tab>
</Tabs>

## Format du fichier

Le fichier `llms.txt` liste chaque page avec son titre, sa description et son URL, regroupés en sections qui reflètent votre navigation :

```text
# Your Project Documentation

> Documentation for Your Project

## Get Started

- [Getting Started](https://your-project.jamdesk.app/getting-started): Set up your first project in 5 minutes
- [Configuration](https://your-project.jamdesk.app/configuration): Configure your project settings

## API Reference

- [Authentication](https://your-project.jamdesk.app/authentication): How to authenticate API requests
```

Le fichier `llms-full.txt` contient le contenu Markdown complet de chaque page, concaténé avec des délimiteurs de page marqués par des titres.

## Structure

`llms.txt` suit la proposition [llmstxt.org](https://llmstxt.org/) : un titre H1,
un résumé en blockquote, et vos onglets et groupes de navigation sous forme de sections `##` de
liens Markdown.

Les sites multilingues obtiennent un index par langue. Le `llms.txt` racine liste votre
langue par défaut et renvoie vers chaque index traduit à la fin — par exemple
`/fr/llms.txt` pour le français. Chaque fichier de langue renvoie vers ses équivalents.

## Directive agent sur chaque page

Chaque page contient également une note invisible et silencieuse pour les lecteurs d'écran, destinée aux agents IA,
pointant vers `llms.txt`, et chaque export Markdown commence par un blockquote
liant l'index. Les agents qui arrivent sur votre HTML trouvent le chemin Markdown
sans crawler.

## Comment c'est construit

- Généré au moment du build en même temps que votre HTML
- Servi depuis le CDN avec la même politique de cache que votre documentation
- Mis à jour automatiquement à chaque build
- Aucune configuration requise ; toutes les pages sont incluses par défaut

## Crawlers IA

Le `robots.txt` par défaut de Jamdesk autorise tous les principaux crawlers IA (Claude, ChatGPT, Copilot, Gemini). Votre documentation est accessible aux outils IA sans configuration supplémentaire.

<Accordion title="En quoi llms.txt diffère de sitemap.xml">
  `sitemap.xml` liste les URLs que les moteurs de recherche doivent crawler et indexer. Il n'inclut aucun contenu, seulement des liens et des métadonnées comme les dates de dernière modification.

  `llms.txt` est conçu pour les modèles IA. Il inclut les titres de pages, les descriptions, et (dans `llms-full.txt`) le contenu réel. Les outils IA peuvent lire le fichier complet pour comprendre votre documentation sans effectuer plusieurs requêtes HTTP.
</Accordion>
