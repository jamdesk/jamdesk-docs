Si vous souhaitez que des outils IA comme ChatGPT, Claude ou Copilot fournissent des réponses précises sur votre produit, ils ont besoin d'un accès structuré à votre documentation, et pas seulement de ce qui a été intégré dans leurs données d'entraînement.

Chaque site Jamdesk génère `llms.txt` et `llms-full.txt` en suivant la spécification [llmstxt.org](https://llmstxt.org). Les outils IA lisent ces fichiers au lieu d'explorer les pages individuellement.

## Ce que Jamdesk génère

| Fichier | Contenu |
|------|---------|
| `llms.txt` | Titres de pages, descriptions et URL (une table des matières structurée) |
| `llms-full.txt` | Contenu complet de la documentation dans un seul fichier |

Jamdesk génère les deux au moment du build et les sert depuis le même CDN que votre documentation.

## Vérifier vos fichiers

Vérifiez que vos fichiers existent après votre premier build :

<Tabs>
  <Tab title="Domaine racine">
    Si votre documentation se trouve à la racine de votre domaine (par exemple, `docs.acme.com` ou `acme.jamdesk.app`) :

    ```bash
    curl https://docs.acme.com/llms.txt
    curl https://docs.acme.com/llms-full.txt
    ```
  </Tab>
  <Tab title="Sous-chemin /docs">
    Si votre documentation se trouve sous `/docs` sur votre site principal (comme ce site sur `jamdesk.com/docs`) :

    ```bash
    curl https://jamdesk.com/docs/llms.txt
    curl https://jamdesk.com/docs/llms-full.txt
    ```
  </Tab>
</Tabs>

## Format des fichiers

Le fichier `llms.txt` liste chaque page avec son titre, sa description et son URL :

```text
# Your Project Documentation

> Documentation for Your Project

## Pages

- [Getting Started](https://your-project.jamdesk.app/getting-started): Set up your first project in 5 minutes
- [Authentication](https://your-project.jamdesk.app/authentication): How to authenticate API requests
- [Configuration](https://your-project.jamdesk.app/configuration): Configure your project settings
```

Le fichier `llms-full.txt` contient le contenu Markdown complet de chaque page, concaténé avec des délimitations de pages marquées par des titres.

## Comment c'est généré

- Généré au moment du build en même temps que votre HTML
- Servi depuis le CDN avec la même politique de cache que votre documentation
- Se met à jour automatiquement à chaque build
- Aucune configuration nécessaire ; toutes les pages sont incluses par défaut

## Robots d'exploration IA

Le fichier `robots.txt` par défaut de Jamdesk autorise tous les principaux robots d'exploration IA (Claude, ChatGPT, Copilot, Gemini). Votre documentation est accessible aux outils IA dès le départ.

<Accordion title="En quoi llms.txt diffère de sitemap.xml">
  `sitemap.xml` liste les URL pour que les moteurs de recherche les explorent et les indexent. Il n'inclut aucun contenu, uniquement des liens et des métadonnées comme les dates de dernière modification.

  `llms.txt` est conçu pour les modèles IA. Il inclut les titres de pages, les descriptions et (dans `llms-full.txt`) le contenu réel. Les outils IA peuvent lire le fichier complet pour comprendre votre documentation sans effectuer plusieurs requêtes HTTP.
</Accordion>
