Lorsque les développeurs interrogent une IA sur votre produit, celle-ci travaille souvent à partir de données d'entraînement obsolètes ou ne peut pas accéder à vos docs. Chaque build Jamdesk génère trois endpoints IA — `llms.txt`, un serveur MCP et des URL Markdown brutes — afin que les outils IA puissent lire directement vos docs actuels, sans scraper le HTML. Vos visiteurs bénéficient également d'un assistant de chat intégré qui répond aux questions directement depuis vos docs.

Cette section couvre ces endpoints, le chat IA intégré, et comment configurer les outils IA pour rédiger et maintenir votre documentation.

<Tip>
  **Découvrez comment vos docs se positionnent.** Jamdesk note vos docs à chaque build — ouvrez [AI Score](/fr/ai/ai-score) dans le dashboard pour voir votre note et les problèmes à corriger. Vous pouvez également soumettre n'importe quel site de documentation à l'outil gratuit [AI Score](https://jamdesk.com/ai-score), noté selon le standard ouvert [AFDocs](https://afdocs.dev), ou noter des sites pendant votre navigation avec l'[extension Chrome AI Score](https://chromewebstore.google.com/detail/jamdesk-ai-score/mhihkkgpcbmapmojnakhjfhjmiagkhlj).
</Tip>

## Fonctionnement

<Steps>
  <Step title="Rédiger en MDX">
    Créez des pages de documentation en Markdown avec des composants React optionnels.
  </Step>
  <Step title="Pousser et builder">
    Jamdesk construit votre site et génère les endpoints IA en même temps que votre HTML.
  </Step>
  <Step title="Connexion des outils IA">
    Claude, Cursor, ChatGPT et d'autres outils peuvent accéder à vos docs via llms.txt, MCP ou des URL Markdown brutes.
  </Step>
</Steps>
