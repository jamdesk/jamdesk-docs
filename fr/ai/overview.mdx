Lorsque les développeurs interrogent l'IA sur votre produit, l'IA travaille souvent à partir de données d'entraînement obsolètes ou ne peut pas accéder à votre documentation du tout. Chaque build Jamdesk génère trois endpoints IA — `llms.txt`, un serveur MCP, et des URL Markdown brutes — afin que les outils IA puissent lire directement votre documentation actuelle, sans scraper le HTML. Vos visiteurs bénéficient également d'un assistant chat intégré qui répond aux questions directement depuis votre documentation.

Cette section couvre ces endpoints, le chat IA intégré, et comment configurer des outils IA pour rédiger et maintenir votre documentation.

## Fonctionnement

<Steps>
  <Step title="Rédiger en MDX">
    Créez des pages de documentation en Markdown avec des composants React optionnels.
  </Step>
  <Step title="Pousser et builder">
    Jamdesk build votre site et génère les endpoints IA en parallèle de votre HTML.
  </Step>
  <Step title="Connexion des outils IA">
    Claude, Cursor, ChatGPT, et d'autres outils peuvent accéder à votre documentation via llms.txt, MCP, ou des URL Markdown brutes.
  </Step>
</Steps>
