Lorsque les développeurs interrogent une IA sur votre produit, celle-ci travaille souvent à partir de données d'entraînement obsolètes, ou ne peut pas du tout accéder à votre documentation. Chaque build Jamdesk génère trois endpoints IA — `llms.txt`, un serveur MCP et des URL Markdown brutes — afin que les outils d'IA puissent lire directement votre documentation à jour, sans scraper le HTML. Vos visiteurs bénéficient également d'un assistant de chat intégré qui répond aux questions directement à partir de votre documentation.

Cette section couvre ces endpoints, le chat IA intégré, ainsi que la configuration des outils d'IA pour rédiger et maintenir votre documentation.

<Tip>
  **Découvrez le score de votre documentation.** Jamdesk évalue votre documentation à chaque build — ouvrez [Score IA](/fr/ai/ai-score) dans le dashboard pour connaître votre note et les problèmes à corriger. Vous pouvez aussi tester n'importe quel site de documentation avec l'outil gratuit [Score IA](https://jamdesk.com/ai-score), noté selon la norme ouverte [AFDocs](https://afdocs.dev), ou noter les sites que vous consultez avec l'[extension Chrome Score IA](https://chromewebstore.google.com/detail/jamdesk-ai-score/mhihkkgpcbmapmojnakhjfhjmiagkhlj).
</Tip>

## Fonctionnement

<Steps>
  <Step title="Rédiger en MDX">
    Créez des pages de documentation en Markdown avec des composants React optionnels.
  </Step>
  <Step title="Push et build">
    Jamdesk construit votre site et génère des endpoints IA en plus de votre HTML.
  </Step>
  <Step title="Les outils IA se connectent">
    Claude, Cursor, ChatGPT et d'autres outils peuvent accéder à votre documentation via llms.txt, MCP ou des URL Markdown brutes.
  </Step>
</Steps>
