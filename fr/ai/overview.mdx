Lorsque les développeurs interrogent une IA sur votre produit, celle-ci s'appuie souvent sur des données d'entraînement obsolètes ou ne peut pas du tout accéder à vos docs. Chaque build Jamdesk génère trois endpoints IA (`llms.txt`, un serveur MCP et des URL Markdown brutes) afin que les outils d'IA puissent lire directement vos docs à jour, sans scraper le HTML. Vos visiteurs bénéficient également d'un assistant de chat intégré qui répond aux questions directement à partir de vos docs.

Cette section couvre ces endpoints, le chat IA intégré, et comment configurer des outils d'IA pour rédiger et maintenir votre documentation.

<Tip>
  **Découvrez le score de vos docs.** Jamdesk note vos propres docs à chaque build. Ouvrez [AI Score](/fr/ai/ai-score) dans le dashboard pour connaître votre note et les problèmes à corriger. Vous pouvez aussi passer n'importe quel site de documentation dans l'[outil AI Score](https://jamdesk.com/ai-score) gratuit, noté selon la norme ouverte [AFDocs](https://afdocs.dev), ou noter les sites au fil de votre navigation avec l'[extension Chrome AI Score](https://chromewebstore.google.com/detail/jamdesk-ai-score/mhihkkgpcbmapmojnakhjfhjmiagkhlj).
</Tip>

## Comment ça marche

<Steps>
  <Step title="Rédiger en MDX">
    Créez des pages de documentation en Markdown avec des composants React optionnels.
  </Step>
  <Step title="Push et build">
    Jamdesk build votre site et génère les endpoints IA en même temps que votre HTML.
  </Step>
  <Step title="Connexion des outils d'IA">
    Claude, Cursor, ChatGPT et d'autres outils peuvent accéder à vos docs via llms.txt, MCP, ou des URL Markdown brutes.
  </Step>
</Steps>
