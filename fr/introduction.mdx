Jamdesk est un [outil de documentation logicielle](https://www.jamdesk.com) qui génère des sites de documentation à partir de vos fichiers Markdown. Connectez un dépôt GitHub, rédigez en MDX, et déployez globalement en quelques secondes. Pas de pipelines de build, pas de DevOps. Chaque site génère un fichier `llms.txt` pour que les outils IA puissent indexer votre contenu.

<Info>
**Rédigez avec l'IA.** Utilisez Cursor, Claude, ou tout autre assistant IA pour générer et modifier votre documentation. MDX est un format texte que les outils IA comprennent nativement, donc aucune invite spéciale n'est nécessaire.
</Info>

## Un projet Jamdesk minimal

```text
my-docs/
├── docs.json
└── introduction.mdx
```

C'est tout ce dont vous avez besoin. Consultez le [Démarrage rapide](/fr/quickstart) pour créer le vôtre.

<Tip>
Parcourez la [source de cette documentation](https://github.com/jamdesk/jamdesk-docs) sur GitHub. C'est un projet Jamdesk fonctionnel que vous pouvez utiliser comme référence.
</Tip>

## Comment ça fonctionne

<Steps>
  <Step title="Rédigez en MDX">
    Créez de la documentation en Markdown avec des composants React optionnels. Utilisez votre éditeur préféré : VS Code, Cursor, ou tout éditeur de texte simple. Les outils IA comme Claude peuvent générer et modifier du MDX nativement.
  </Step>
  <Step title="Poussez vers GitHub">
    Validez vos modifications et poussez. C'est tout. Pas de commandes de build, pas de scripts à déployer.
  </Step>
  <Step title="En ligne en quelques secondes">
    Jamdesk détecte votre push, build votre site et le déploie sur un CDN mondial. Votre documentation est en ligne à `your-project.jamdesk.app`.
  </Step>
</Steps>
