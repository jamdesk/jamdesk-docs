Jamdesk est un [outil de documentation logicielle](https://jamdesk.com) qui génère des sites de documentation à partir de vos fichiers Markdown. Connectez un dépôt GitHub, rédigez en MDX, et laissez Jamdesk déployer votre site globalement en quelques secondes. Vous n'avez pas besoin de configurer un pipeline de build ni de gérer vous-même du DevOps. Chaque site génère un fichier `llms.txt` pour que les outils IA puissent indexer votre contenu.

<Info>
**Rédigez avec l'IA.** Utilisez Cursor, Claude, ou tout autre assistant IA pour générer et modifier vos docs. MDX est un format texte que les outils IA comprennent nativement — aucun prompt spécial n'est nécessaire.
</Info>

## Un projet Jamdesk minimal

```text
my-docs/
├── docs.json
└── introduction.mdx
```

C'est tout ce qu'il vous faut. Consultez le [Quickstart](/fr/quickstart) pour créer le vôtre.

<Tip>
Parcourez le [code source de cette documentation](https://github.com/jamdesk/jamdesk-docs) sur GitHub. C'est un projet Jamdesk fonctionnel que vous pouvez utiliser comme référence.
</Tip>

## Fonctionnement

<Steps>
  <Step title="Rédigez en MDX">
    Créez de la documentation en Markdown avec des composants React optionnels. Utilisez votre éditeur favori : VS Code, Cursor, ou n'importe quel éditeur de texte. Les outils IA comme Claude peuvent générer et modifier du MDX nativement.
  </Step>
  <Step title="Poussez vers GitHub">
    Commitez vos modifications et poussez. Vous n'avez pas besoin d'exécuter une commande de build ni de maintenir un script de déploiement.
  </Step>
  <Step title="En ligne en quelques secondes">
    Jamdesk détecte votre push, génère votre site et le déploie sur un CDN mondial. Vos docs sont en ligne à l'adresse `your-project.jamdesk.app`.
  </Step>
</Steps>
