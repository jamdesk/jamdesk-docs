Jamdesk est un [outil de documentation logicielle](https://www.jamdesk.com) qui construit des sites de documentation à partir de vos fichiers Markdown. Connectez un dépôt GitHub, écrivez en MDX, et déployez globalement en quelques secondes. Vous n'avez pas besoin de configurer un pipeline de build ni de gérer le DevOps vous-même. Chaque site génère un fichier `llms.txt` pour que les outils AI puissent indexer votre contenu.

<Info>
**Écrivez avec l'AI.** Utilisez Cursor, Claude, ou tout assistant AI pour générer et éditer vos docs. MDX est un format texte que les outils AI comprennent nativement, aucun prompt spécial n'est nécessaire.
</Info>

## Un projet Jamdesk minimal

```text
my-docs/
├── docs.json
└── introduction.mdx
```

C'est tout ce dont vous avez besoin. Consultez le [Démarrage rapide](/fr/quickstart) pour créer le vôtre.

<Tip>
Parcourez le [code source de cette documentation](https://github.com/jamdesk/jamdesk-docs) sur GitHub. C'est un projet Jamdesk fonctionnel que vous pouvez utiliser comme référence.
</Tip>

## Comment ça fonctionne

<Steps>
  <Step title="Écrivez en MDX">
    Créez votre documentation en Markdown avec des composants React optionnels. Utilisez votre éditeur favori : VS Code, Cursor, ou tout éditeur de texte. Les outils AI comme Claude peuvent générer et éditer du MDX nativement.
  </Step>
  <Step title="Poussez sur GitHub">
    Committez vos modifications et poussez. Vous n'avez pas besoin d'exécuter une commande de build ni de maintenir un script de déploiement.
  </Step>
  <Step title="En ligne en secondes">
    Jamdesk détecte votre push, construit votre site et le déploie sur un CDN mondial. Vos docs sont disponibles sur `your-project.jamdesk.app`.
  </Step>
</Steps>
