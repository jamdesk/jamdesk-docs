Jamdesk est un [outil de documentation logicielle](https://www.jamdesk.com) qui construit des sites de documentation à partir de vos fichiers Markdown. Connectez un dépôt GitHub, rédigez en MDX et déployez globalement en quelques secondes. Vous n'avez pas besoin de configurer un pipeline de build ni de gérer vous-même une infrastructure DevOps. Chaque site génère un fichier `llms.txt` pour que les outils d'IA puissent indexer votre contenu.

<Info>
**Rédigez avec l'IA.** Utilisez Cursor, Claude ou tout assistant IA pour générer et modifier vos docs. MDX est un format texte que les outils d'IA comprennent nativement — aucun prompt particulier n'est nécessaire.
</Info>

## Un projet Jamdesk minimal

```text
my-docs/
├── docs.json
└── introduction.mdx
```

C'est tout ce dont vous avez besoin. Consultez le [Quickstart](/fr/quickstart) pour créer le vôtre.

<Tip>
Parcourez les [sources de cette documentation](https://github.com/jamdesk/jamdesk-docs) sur GitHub. C'est un projet Jamdesk fonctionnel que vous pouvez utiliser comme référence.
</Tip>

## Comment ça fonctionne

<Steps>
  <Step title="Rédigez en MDX">
    Créez vos docs en Markdown avec des composants React optionnels. Utilisez votre éditeur préféré : VS Code, Cursor ou tout éditeur de texte. Des outils IA comme Claude peuvent générer et modifier du MDX nativement.
  </Step>
  <Step title="Poussez vers GitHub">
    Commitez vos modifications et poussez. Vous n'avez pas besoin d'exécuter une commande de build ni de maintenir un script pour déployer.
  </Step>
  <Step title="En ligne en quelques secondes">
    Jamdesk détecte votre push, build votre site et le déploie sur un CDN mondial. Vos docs sont accessibles à l'adresse `your-project.jamdesk.app`.
  </Step>
</Steps>
