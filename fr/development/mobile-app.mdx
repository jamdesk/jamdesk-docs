Gardez un œil sur votre site de documentation depuis votre téléphone. L'app iOS Jamdesk vous donne une vue en temps réel des analytiques, de l'état des builds, et des notifications push dès qu'un build réussit ou échoue.

## Connexion

Utilisez les mêmes identifiants que le [web dashboard](https://dashboard.jamdesk.com) :

- Email et mot de passe
- Connexion Google

Après la première connexion, Face ID ou Touch ID déverrouille l'app lors des lancements suivants.

## Notifications push

Rendez-vous dans **Paramètres** dans l'app pour activer ou désactiver :

- **Succès de build** — recevez une notification quand un déploiement se termine.
- **Échec de build** — soyez notifié dès qu'un build échoue, avec le message d'erreur.

Les préférences de notification sont par appareil, vous pouvez donc recevoir des alertes sur votre téléphone sans qu'elles apparaissent sur votre tablette.

## Lecture seule par conception

L'application mobile ne déclenche pas de rebuilds. Les builds se lancent automatiquement quand vous poussez vers votre fournisseur Git, et tout rebuild manuel se fait depuis le [web dashboard](https://dashboard.jamdesk.com). L'app est un outil de surveillance, pas un panneau de contrôle — l'objectif est que vous puissiez vérifier votre documentation sans avoir à changer de contexte.

Si vous devez gérer les paramètres du projet, inviter des membres, faire tourner des clés API ou déclencher un rebuild manuel, rendez-vous sur le web dashboard.

## Confidentialité

L'app communique directement avec le même backend Firebase que le web dashboard — pas de couche API séparée, pas de relais analytique. Les données de votre projet ne quittent jamais l'infrastructure Jamdesk.
