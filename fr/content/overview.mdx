Les pages Jamdesk sont des fichiers MDX : du Markdown standard avec des composants React disponibles partout où vous en avez besoin. Une page n'est rien de plus que du frontmatter et du contenu.

```mdx
---
title: Rate Limits
description: How rate limiting works across API tiers.
---

Requests are limited per API key.

<Note>Enterprise plans have custom limits.</Note>
```

La majeure partie de ce que vous écrirez est du Markdown standard. Les pages de cette section couvrent le reste : blocs de code avec coloration syntaxique, images et vidéos, notation mathématique, snippets réutilisables, et les champs du frontmatter qui contrôlent les titres, les icônes et les métadonnées SEO.
