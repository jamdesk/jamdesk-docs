Les en-têtes Markdown (`##`, `###`) divisent votre page en sections que les lecteurs peuvent parcourir rapidement. Jamdesk récupère les en-têtes H2 et H3 pour la table des matières côté droit et génère des liens d'ancre que vous pouvez partager directement.

## Utilisation de base

Utilisez les en-têtes Markdown standard pour structurer votre contenu :

```markdown
## Section Title

Content goes here...

### Subsection

More detailed content...
```

Les en-têtes H2 et H3 apparaissent dans la **Table des matières** côté droit, aidant les lecteurs à naviguer dans les longues pages.

## Liens d'ancre

Chaque en-tête génère automatiquement un identifiant d'ancre à partir de son texte :

| En-tête                   | Ancre générée          |
| ------------------------- | ---------------------- |
| `## Getting Started`      | `#getting-started`     |
| `## API Reference`        | `#api-reference`       |
| `### User Authentication` | `#user-authentication` |

### Partager des liens d'en-tête

Survolez n'importe quel en-tête H2 ou H3 pour révéler une **icône de lien**. Cela facilite le partage de liens directs vers des sections spécifiques :

- **Cliquez sur l'icône de lien** pour copier l'URL dans votre presse-papiers
- **Cliquez sur le texte de l'en-tête** pour copier l'URL et naviguer vers cette section

L'icône de lien apparaît dans une petite boîte encadrée à gauche de l'en-tête. Lorsque vous copiez un lien, l'icône change brièvement de couleur pour confirmer l'action.

<Note>
  Sur les appareils mobiles, l'icône de lien est masquée car il n'y a pas d'état de survol.
  Les en-têtes fonctionnent toujours normalement pour la navigation.
</Note>

### Créer des liens vers des en-têtes

Référencez des sections spécifiques depuis d'autres pages en utilisant l'ancre :

```markdown
See the [headings section](/content/mdx-basics#headings) for details.
```

## Bonnes pratiques

<AccordionGroup>
  <Accordion title="Utilisez une hiérarchie claire" icon="sitemap" defaultOpen>
    Commencez par H2 pour les sections principales, H3 pour les sous-sections :

    ```markdown
    ## Installation

    ### Prerequisites

    ### Quick Install

    ## Configuration

    ### Basic Options

    ### Advanced Options
    ```

    Évitez de sauter des niveaux (par exemple, passer de H2 à H4).

  </Accordion>

  <Accordion title="Gardez les en-têtes concis" icon="text-width">
    Les en-têtes courts sont plus faciles à parcourir :

    ```markdown
    {/* Good */}
    ## Authentication

    {/* Avoid */}
    ## How to Set Up Authentication in Your Application
    ```

  </Accordion>

  <Accordion title="Utilisez la casse de phrase" icon="font">
    Mettez en majuscule uniquement le premier mot et les noms propres :

    ```markdown
    {/* Good */}
    ## Getting started with the API

    {/* Avoid */}
    ## Getting Started With The API
    ```

  </Accordion>
</AccordionGroup>
