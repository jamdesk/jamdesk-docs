Chaque page Jamdesk est un fichier `.mdx` : du Markdown standard avec des composants JSX comme `<Card>`, `<Tabs>` et `<Accordion>`.

## Qu'est-ce que MDX ?

MDX vous permet d'écrire du Markdown standard et d'intégrer des composants JSX dans le même fichier. Rédigez des titres, des listes et des blocs de code en Markdown, puis ajoutez des composants comme `<Card>` ou `<Tabs>` partout où vous avez besoin d'interactivité.

MDX fonctionne également très bien pour la documentation que les outils d'IA doivent lire : c'est du texte brut (ils peuvent donc le lire et l'écrire nativement), versionnable dans Git, et suffisamment structuré pour les composants sans nécessiter de format propriétaire.

```mdx
# Welcome to My Docs

This is regular **Markdown** with a component below:

<Card title="Quickstart" icon="rocket" href="/quickstart">
  Jump right in with our quickstart guide.
</Card>
```

<Tip>
  Deux outils gratuits dans le navigateur vous aident pendant la rédaction : le [MDX Validator](https://jamdesk.com/utilities/mdx-validator)
  détecte les erreurs de syntaxe avant un build, et le [MDX Formatter](https://jamdesk.com/utilities/mdx-formatter)
  nettoie l'espacement et l'indentation. Collez une page pour la vérifier ou la nettoyer sans exécuter le CLI.
</Tip>

## Structure de page

Chaque page MDX commence par du frontmatter - des métadonnées entre triples tirets :

```mdx
---
title: My Page Title
description: A brief description for search and previews
---

Your content starts here...
```

<Note>
Les champs `title` et `description` apparaissent dans les résultats de recherche, les onglets du navigateur et les aperçus sur les réseaux sociaux. Rédigez-les avec soin.
</Note>

## Éléments essentiels de Markdown

### Titres

Utilisez `##` pour les sections principales et `###` pour les sous-sections. Jamdesk génère automatiquement une table des matières à partir de vos titres.

```markdown
## Main Section
Content under the main section.

### Subsection
More detailed content here.
```

<Tip>
Commencez par `##` (h2) pour votre premier titre. Le titre de la page issu du frontmatter sert de h1.
</Tip>

### Mise en forme du texte

| Syntaxe | Résultat |
|--------|--------|
| `**bold**` | **gras** |
| `*italic*` | *italique* |
| `~~strikethrough~~` | ~~barré~~ |
| `` `inline code` `` | `code en ligne` |

### Listes

```markdown
Unordered list:
- First item
- Second item
  - Nested item

Ordered list:
1. First step
2. Second step
3. Third step
```

### Citations

```markdown
> This is a blockquote. Use it for callouts or
> highlighting important information.
```

> Ceci est une citation. Utilisez-la pour des encadrés ou pour mettre en évidence des informations importantes.

## Ajouter des composants

Les composants sont des éléments JSX que vous pouvez utiliser n'importe où dans votre MDX. Ils sont auto-fermants ou entourent du contenu :

```mdx
{/* Self-closing component */}
<Card title="Example" icon="star" href="/introduction" />

{/* Component wrapping content */}
<Accordion title="Click to expand">
  This content is inside the accordion.
</Accordion>
```

## Tableaux

Les tableaux Markdown standard fonctionnent directement :

```markdown
| Feature | Free | Pro |
|---------|------|-----|
| Pages | 10 | Unlimited |
| Custom domain | No | Yes |
```

| Fonctionnalité | Free | Pro |
|---------|------|-----|
| Pages | 10 | Illimité |
| Domaine personnalisé | Non | Oui |

Pour des fonctionnalités avancées comme la mise en évidence de lignes, l'alignement des cellules et la fusion, utilisez le composant Table :

<Table striped>
  <Row header>
    <Cell>Feature</Cell>
    <Cell align="center">Free</Cell>
    <Cell align="center">Pro</Cell>
  </Row>
  <Row>
    <Cell>Pages</Cell>
    <Cell align="center">10</Cell>
    <Cell align="center" highlight highlightColor="success">Unlimited</Cell>
  </Row>
  <Row>
    <Cell>Custom domain</Cell>
    <Cell align="center">No</Cell>
    <Cell align="center" highlight highlightColor="success">Yes</Cell>
  </Row>
</Table>

<Note>
Consultez [Tables](/fr/components/tables) pour la documentation complète du composant, incluant la mise en évidence de lignes/cellules, la fusion de colonnes et les options de style.
</Note>

## Commentaires

Ajoutez des commentaires qui n'apparaîtront pas dans le résultat rendu :

```mdx
{/* This is a comment - it won't be visible to readers */}
```
