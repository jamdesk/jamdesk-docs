Chaque page Jamdesk est un fichier `.mdx` — du Markdown standard avec des composants JSX comme `<Card>`, `<Tabs>` et `<Accordion>`.

## Qu'est-ce que MDX ?

MDX combine la simplicité du Markdown avec la puissance de JSX. Rédigez des titres, des listes et des blocs de code en Markdown, puis insérez des composants comme `<Card>` ou `<Tabs>` là où vous avez besoin d'interactivité.

MDX est également l'un des meilleurs formats pour une documentation qui doit être lisible par les outils d'IA. C'est du texte brut (les outils d'IA peuvent donc le lire et l'écrire nativement), versionnable dans Git, et suffisamment structuré pour les composants sans nécessiter de format propriétaire.

```mdx
# Welcome to My Docs

This is regular **Markdown** with a component below:

<Card title="Quickstart" icon="rocket" href="/quickstart">
  Jump right in with our quickstart guide.
</Card>
```

<Tip>
  Deux outils de navigateur gratuits vous aident pendant la rédaction : le [MDX Validator](https://jamdesk.com/utilities/mdx-validator)
  détecte les erreurs de syntaxe avant un build, et le [MDX Formatter](https://jamdesk.com/utilities/mdx-formatter)
  corrige les espaces et l'indentation. Collez une page pour la vérifier ou la nettoyer sans lancer le CLI.
</Tip>

## Structure d'une page

Chaque page MDX commence par un frontmatter — des métadonnées encadrées par des triples tirets :

```mdx
---
title: My Page Title
description: A brief description for search and previews
---

Your content starts here...
```

<Note>
Le `title` et la `description` apparaissent dans les résultats de recherche, les onglets du navigateur et les previews sur les réseaux sociaux. Rédigez-les avec soin.
</Note>

## Fondamentaux du Markdown

### Titres

Utilisez `##` pour les sections principales et `###` pour les sous-sections. Jamdesk génère automatiquement une table des matières à partir de vos titres.

```markdown
## Main Section
Content under the main section.

### Subsection
More detailed content here.
```

<Tip>
Commencez par `##` (h2) pour votre premier titre. Le titre de la page issu du frontmatter sert de h1.
</Tip>

### Mise en forme du texte

| Syntaxe | Résultat |
|--------|--------|
| `**gras**` | **gras** |
| `*italique*` | *italique* |
| `~~barré~~` | ~~barré~~ |
| `` `code inline` `` | `code inline` |

### Listes

```markdown
Unordered list:
- First item
- Second item
  - Nested item

Ordered list:
1. First step
2. Second step
3. Third step
```

### Citations

```markdown
> This is a blockquote. Use it for callouts or
> highlighting important information.
```

> Il s'agit d'une citation. Utilisez-la pour des encadrés ou pour mettre en avant des informations importantes.

## Ajouter des composants

Les composants sont des éléments JSX utilisables partout dans votre MDX. Ils sont auto-fermants ou encadrent du contenu :

```mdx
{/* Self-closing component */}
<Card title="Example" icon="star" href="/introduction" />

{/* Component wrapping content */}
<Accordion title="Click to expand">
  This content is inside the accordion.
</Accordion>
```

## Tableaux

Les tableaux Markdown standard fonctionnent nativement :

```markdown
| Feature | Free | Pro |
|---------|------|-----|
| Pages | 10 | Unlimited |
| Custom domain | No | Yes |
```

| Fonctionnalité | Gratuit | Pro |
|---------|------|-----|
| Pages | 10 | Illimité |
| Domaine personnalisé | Non | Oui |

Pour des fonctionnalités avancées comme la mise en évidence de lignes, l'alignement de cellules et la fusion, utilisez le composant Table :

<Table striped>
  <Row header>
    <Cell>Fonctionnalité</Cell>
    <Cell align="center">Gratuit</Cell>
    <Cell align="center">Pro</Cell>
  </Row>
  <Row>
    <Cell>Pages</Cell>
    <Cell align="center">10</Cell>
    <Cell align="center" highlight highlightColor="success">Illimité</Cell>
  </Row>
  <Row>
    <Cell>Domaine personnalisé</Cell>
    <Cell align="center">Non</Cell>
    <Cell align="center" highlight highlightColor="success">Oui</Cell>
  </Row>
</Table>

<Note>
Consultez [Tableaux](/fr/components/tables) pour la documentation complète du composant, notamment la mise en évidence des lignes et cellules, la fusion de colonnes et les options de style.
</Note>

## Commentaires

Ajoutez des commentaires qui n'apparaîtront pas dans le rendu final :

```mdx
{/* This is a comment - it won't be visible to readers */}
```
