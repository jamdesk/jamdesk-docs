Jamdesk prend en charge LaTeX pour le rendu des expressions mathématiques et des équations avec [KaTeX](https://katex.org/).

<Note>
La prise en charge des mathématiques nécessite `styling.latex: true` dans votre fichier `docs.json`.
</Note>

## Activer la prise en charge des mathématiques

Ajoutez ceci à votre `docs.json` :

```json
{
  "styling": {
    "latex": true
  }
}
```

## Mathématiques en ligne

Utilisez des signes dollar simples pour les équations en ligne :

```md
The Pythagorean theorem states that $a^2 + b^2 = c^2$.
```

**S'affiche comme :** The Pythagorean theorem states that $a^2 + b^2 = c^2$.

## Équations en bloc

Utilisez des signes dollar doubles pour des équations centrées en mode affichage :

```md
$$
E = mc^2
$$
```

**S'affiche comme :**

$$
E = mc^2
$$

## Équations complexes

KaTeX prend en charge un large éventail de notations LaTeX :

### Fractions

```md
$$
\frac{n!}{k!(n-k)!} = \binom{n}{k}
$$
```

### Intégrales

```md
$$
\int_0^\infty e^{-x^2} dx = \frac{\sqrt{\pi}}{2}
$$
```

### Sommes

```md
$$
\sum_{i=1}^{n} i = \frac{n(n+1)}{2}
$$
```

### Matrices

```md
$$
\begin{bmatrix}
a & b \\
c & d
\end{bmatrix}
$$
```

## Utiliser le composant Latex

Pour plus de contrôle, utilisez le composant `<Latex>` directement :

```mdx
<Latex>E = mc^2</Latex>
```

Pour le mode bloc/affichage :

```mdx
<Latex block>
\int_0^\infty e^{-x^2} dx = \frac{\sqrt{\pi}}{2}
</Latex>
```

## Les blocs de code sont protégés

Les signes dollar à l'intérieur des blocs de code ne sont **pas** traités comme des mathématiques :

```bash
echo $HOME
export PRICE=$100
```

Cela s'affiche comme du code normal, pas des équations.

## Commandes prises en charge

KaTeX prend en charge la plupart des commandes mathématiques LaTeX courantes. Consultez la [documentation KaTeX](https://katex.org/docs/supported.html) pour une liste complète des fonctions prises en charge.

<Tip>
Pour les équations complexes, testez votre LaTeX sur la [page de démonstration de KaTeX](https://katex.org/) d'abord.
</Tip>
