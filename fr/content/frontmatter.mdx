---

Chaque fichier MDX commence par un bloc YAML entre des marqueurs `---`. Ces métadonnées contrôlent le titre de votre page, l'apparence dans la barre latérale, et la façon dont la page s'affiche lorsqu'elle est partagée sur les réseaux sociaux ou dans les résultats de recherche.

## Frontmatter de base

Chaque page nécessite au minimum un titre :

```yaml
---
title: Getting Started
description: Learn the basics in 5 minutes
---
```

## Champs disponibles

### Obligatoires

| Champ | Type | Description |
|-------|------|-------------|
| `title` | string | Titre de la page affiché dans la navigation et l'onglet du navigateur |

### Recommandés

| Champ | Type | Description |
|-------|------|-------------|
| `description` | string | Bref résumé pour le SEO et les résultats de recherche (50-160 caractères) |

### Optionnels

| Champ | Type | Défaut | Description |
|-------|------|--------|-------------|
| `icon` | string | - | Icône Font Awesome affichée à côté du titre de la page dans la barre latérale |
| `sidebarTitle` | string | `title` | Titre plus court pour la barre latérale |
| `mode` | string | - | Définissez à `"wide"` pour une mise en page pleine largeur |
| `hideFooter` | boolean | `false` | Masquer le pied de page social sur cette page |
| `rss` | boolean | `false` | Activer la génération de flux RSS à partir des composants [Update](/fr/components/update) sur cette page |
| `private` | boolean | `false` | Exiger le [mot de passe du site](/fr/setup/password-protection) pour afficher cette page. Activer ceci sur une page active le mode pages spécifiques lors de la prochaine compilation. |
| `public` | boolean | `false` | Exempter cette page de la protection par mot de passe (utilisé lorsque l'ensemble du site est protégé via `auth.password.enabled`). Prend le dessus sur `private: true` si les deux sont définis. |

### SEO et réseaux sociaux

Contrôlez la façon dont la page apparaît dans les résultats de recherche et les aperçus sociaux. Définissez ces valeurs comme clés de premier niveau ou dans un bloc `seo:` imbriqué. Les deux fonctionnent, et les valeurs par page remplacent vos paramètres par défaut `seo.metatags` dans `docs.json`.

| Champ | Type | Défaut | Description |
|-------|------|--------|-------------|
| `keywords` | string[] | - | Mots-clés de recherche, émis sous forme de balise `<meta name="keywords">` |
| `canonical` | string | auto | URL canonique pour cette page, remplaçant celle générée automatiquement |
| `noindex` | boolean | `false` | Exclure cette page des moteurs de recherche et du plan du site |
| `og:*` / `twitter:*` | string | - | Balises de prévisualisation sociale Open Graph et Twitter/X (ex. `og:title`, `og:image`, `twitter:card`) |
| `seo` | object | - | Bloc imbriqué contenant l'un des éléments ci-dessus ainsi que des balises méta personnalisées arbitraires |

```yaml
---
title: API Reference
description: REST endpoints and authentication
"og:image": /images/api-card.png
"twitter:card": summary_large_image
canonical: https://docs.acme.com/api-reference
---
```

Consultez [Optimisation SEO](/fr/content/seo) pour la liste complète des balises prises en charge et des exemples.

## Exemples

### Page de documentation standard

```yaml
---
title: Authentication
description: Secure your API with OAuth 2.0 and API keys
icon: lock
---
```

### Titre long avec remplacement dans la barre latérale

```yaml
---
title: Configuring Single Sign-On with SAML 2.0
sidebarTitle: SSO Setup
description: Set up enterprise SSO for your organization
---
```

Le titre complet apparaît sur la page, tandis que le `sidebarTitle` plus court garde la navigation claire.

### Mise en page large

```yaml
---
title: API Reference
description: Complete API documentation
mode: wide
---
```

Le mode large supprime la table des matières et étend le contenu à toute la largeur. Utile pour les pages de référence API ou le contenu avec des tableaux larges.

### Masquer le pied de page

```yaml
---
title: Custom Landing
description: A focused landing page experience
hideFooter: true
---
```

Utilisez `hideFooter` pour les pages d'accueil, les pages de journal des modifications, ou toute page où vous souhaitez une section inférieure plus épurée sans liens sociaux.

## Bonnes pratiques SEO

<AccordionGroup>
  <Accordion title="Rédigez des titres accrocheurs" icon="heading" defaultOpen>
    Votre titre apparaît dans :
    - Les onglets du navigateur
    - Les résultats des moteurs de recherche
    - La barre latérale de navigation
    - Les partages sur les réseaux sociaux

    Gardez les titres sous 60 caractères. Placez les mots-clés importants en début de titre.

    ```yaml
    # Good - clear and keyword-rich
    title: Deploy to Production

    # Avoid - vague or too long
    title: How to Deploy Your Application to Production Servers
    ```
  </Accordion>

  <Accordion title="Rédigez des descriptions utiles" icon="align-left">
    Les descriptions apparaissent dans les résultats de recherche et les aperçus sociaux. Visez 50-160 caractères qui :
    - Résument le contenu de la page
    - Incluent des mots-clés pertinents
    - Incitent les utilisateurs à cliquer

    ```yaml
    # Good - actionable and specific
    description: Deploy your docs to production in under 2 minutes with zero configuration

    # Avoid - generic or missing
    description: Documentation page
    ```
  </Accordion>

  <Accordion title="Utilisez des icônes cohérentes" icon="icons">
    Les icônes aident les utilisateurs à parcourir la navigation rapidement. Utilisez la même icône pour les pages connexes :

    | Sujet | Icône suggérée |
    |-------|----------------|
    | Démarrage | `rocket` |
    | Authentification | `lock` |
    | Référence API | `code` |
    | Paramètres | `gear` |
    | Facturation | `credit-card` |

    Parcourez les icônes sur [Font Awesome](https://fontawesome.com/icons).
  </Accordion>
</AccordionGroup>

## Validation

Jamdesk valide le frontmatter lors de la compilation. Erreurs courantes :

<Accordion title="Champs obligatoires manquants">
```text
Error: Page "api/auth.mdx" is missing required field: title
```

**Correction :** Ajoutez le champ `title` à votre frontmatter.
</Accordion>

<Accordion title="Syntaxe YAML invalide">
```text
Error: Invalid frontmatter in "guide.mdx": unexpected token
```

**Correction :** Vérifiez :
- Les guillemets manquants autour des chaînes contenant des caractères spéciaux
- L'indentation incorrecte
- Les deux-points manquants après les clés
</Accordion>
