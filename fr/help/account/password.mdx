---

Gérez votre mot de passe Jamdesk, notamment comment le changer ou le réinitialiser si vous l'oubliez.

## Changer votre mot de passe

Si vous connaissez votre mot de passe actuel :

<Steps>
  <Step title="Accéder aux paramètres utilisateur">
    Cliquez sur votre avatar dans la barre latérale et sélectionnez **Paramètres utilisateur**.
  </Step>
  <Step title="Cliquer sur Changer le mot de passe">
    Dans la carte **Informations du compte**, cliquez sur **Changer le mot de passe**.
  </Step>
  <Step title="Remplir le formulaire">
    Une fenêtre modale s'ouvre avec trois champs :

    1. **Mot de passe actuel**
    2. **Nouveau mot de passe**
    3. **Confirmer le nouveau mot de passe**

    Utilisez l'icône œil sur chaque champ pour afficher ou masquer le mot de passe.
  </Step>
  <Step title="Soumettre">
    Cliquez sur **Changer le mot de passe** pour enregistrer. Un message de succès s'affiche et la fenêtre modale se ferme automatiquement.
  </Step>
</Steps>

<Note>
Le bouton Changer le mot de passe n'apparaît que si vous vous êtes inscrit avec une adresse e-mail et un mot de passe. Si vous vous êtes inscrit avec Google ou GitHub, consultez [Comptes OAuth](#comptes-oauth) ci-dessous.
</Note>

## Réinitialiser un mot de passe oublié

Si vous ne vous souvenez plus de votre mot de passe :

<Steps>
  <Step title="Aller à la connexion">
    Rendez-vous sur [dashboard.jamdesk.com](https://dashboard.jamdesk.com) et cliquez sur **Se connecter**.
  </Step>
  <Step title="Cliquer sur Mot de passe oublié">
    Sélectionnez le lien **Mot de passe oublié ?** sous le champ du mot de passe.
  </Step>
  <Step title="Saisir votre adresse e-mail">
    Entrez l'adresse e-mail associée à votre compte. Si vous l'avez déjà saisie dans le formulaire de connexion, elle sera pré-remplie.
  </Step>
  <Step title="Vérifier votre boîte de réception">
    Cliquez sur **Envoyer l'e-mail de réinitialisation**. Vérifiez votre boîte de réception pour un lien de réinitialisation du mot de passe et suivez les instructions.
  </Step>
</Steps>

<Note>
Les liens de réinitialisation du mot de passe expirent après 1 heure. Faites-en une nouvelle demande si le vôtre a expiré.
</Note>

## Exigences du mot de passe

Votre mot de passe doit comporter au moins **6 caractères**.

## Comptes OAuth

Si vous vous êtes inscrit uniquement avec Google ou GitHub, vous n'aurez pas de mot de passe Jamdesk et le bouton **Changer le mot de passe** n'apparaîtra pas dans vos paramètres de compte.

Pour vous connecter avec un mot de passe en plus de OAuth, utilisez le flux **Mot de passe oublié ?** sur la page de connexion pour en définir un pour votre adresse e-mail.
