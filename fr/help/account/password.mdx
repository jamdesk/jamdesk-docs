Gérez votre mot de passe Jamdesk, y compris comment le modifier ou le réinitialiser si vous l'oubliez.

<Note>
  Cette page concerne votre **mot de passe de compte Jamdesk** (celui utilisé pour vous connecter au dashboard). Si vous souhaitez mettre un mot de passe sur votre site de documentation publié, consultez [Protection par mot de passe](/fr/setup/password-protection), ou consultez [Contrôle d'accès](/fr/setup/access-control) pour un aperçu des options publiques, mot de passe et SSO.
</Note>

## Modifier votre mot de passe

Si vous connaissez votre mot de passe actuel :

<Steps>
  <Step title="Accédez aux paramètres utilisateur">
    Cliquez sur votre avatar dans la barre latérale et sélectionnez **Paramètres utilisateur**.
  </Step>
  <Step title="Cliquez sur Modifier le mot de passe">
    Dans la carte **Informations du compte**, cliquez sur **Modifier le mot de passe**.
  </Step>
  <Step title="Remplissez le formulaire">
    Une fenêtre modale s'ouvre avec trois champs :

    1. **Mot de passe actuel**
    2. **Nouveau mot de passe**
    3. **Confirmer le nouveau mot de passe**

    Utilisez l'icône en forme d'œil sur chaque champ pour afficher ou masquer le mot de passe.
  </Step>
  <Step title="Valider">
    Cliquez sur **Modifier le mot de passe** pour enregistrer. Un message de succès s'affiche et la fenêtre modale se ferme automatiquement.
  </Step>
</Steps>

<Note>
Le bouton Modifier le mot de passe n'apparaît que si vous vous êtes inscrit avec un email et un mot de passe. Si vous vous êtes inscrit avec Google ou GitHub, consultez [Comptes OAuth](#comptes-oauth) ci-dessous.
</Note>

## Réinitialiser un mot de passe oublié

Si vous ne vous souvenez plus de votre mot de passe :

<Steps>
  <Step title="Accédez à la connexion">
    Rendez-vous sur [dashboard.jamdesk.com](https://dashboard.jamdesk.com) et cliquez sur **Sign In**.
  </Step>
  <Step title="Cliquez sur Mot de passe oublié">
    Sélectionnez le lien **Forgot password?** sous le champ du mot de passe.
  </Step>
  <Step title="Saisissez votre email">
    Saisissez l'adresse email associée à votre compte. Si vous l'avez déjà saisie sur le formulaire de connexion, elle sera pré-remplie.
  </Step>
  <Step title="Consultez votre boîte de réception">
    Cliquez sur **Send reset email**. Consultez votre boîte de réception pour un lien de réinitialisation du mot de passe et suivez les instructions.
  </Step>
</Steps>

<Note>
Les liens de réinitialisation du mot de passe expirent après 1 heure. Demandez-en un nouveau si le vôtre a expiré.
</Note>

## Exigences de mot de passe

Votre mot de passe doit comporter au moins **6 caractères**.

## Comptes OAuth

Si vous vous êtes inscrit uniquement avec Google ou GitHub, vous n'aurez pas de mot de passe Jamdesk et le bouton **Modifier le mot de passe** n'apparaîtra pas dans les paramètres de votre compte.

Pour vous connecter avec un mot de passe en plus de l'OAuth, utilisez le flux **Forgot password?** sur la page de connexion pour en définir un pour votre adresse email.
