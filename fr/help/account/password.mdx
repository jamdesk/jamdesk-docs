Gérez votre mot de passe Jamdesk : comment le modifier ou le réinitialiser si vous l'oubliez.

<Note>
  Cette page concerne votre **mot de passe de compte Jamdesk** (utilisé pour vous connecter au dashboard). Si vous souhaitez protéger votre site de documentation publié par un mot de passe, consultez [Protection par mot de passe](/fr/setup/password-protection) — ou [Contrôle d'accès](/fr/setup/access-control) pour un aperçu des options public, mot de passe et SSO.
</Note>

## Modifier votre mot de passe

Si vous connaissez votre mot de passe actuel :

<Steps>
  <Step title="Accéder aux paramètres utilisateur">
    Cliquez sur votre avatar dans la barre latérale et sélectionnez **Paramètres utilisateur** (User Settings).
  </Step>
  <Step title="Cliquer sur Change Password">
    Dans la carte **Informations du compte** (Account Information), cliquez sur **Changer le mot de passe** (Change Password).
  </Step>
  <Step title="Remplir le formulaire">
    Une fenêtre modale s'ouvre avec trois champs :

    1. **Mot de passe actuel**
    2. **Nouveau mot de passe**
    3. **Confirmer le nouveau mot de passe**

    Utilisez l'icône en forme d'œil sur chaque champ pour afficher ou masquer le mot de passe.
  </Step>
  <Step title="Valider">
    Cliquez sur **Changer le mot de passe** (Change Password) pour enregistrer. Un message de succès s'affiche et la fenêtre modale se ferme automatiquement.
  </Step>
</Steps>

<Note>
Le bouton **Change Password** n'apparaît que si vous vous êtes inscrit(e) avec un e-mail et un mot de passe. Si vous vous êtes inscrit(e) avec Google ou GitHub, consultez [Comptes OAuth](#comptes-oauth) ci-dessous.
</Note>

## Réinitialiser un mot de passe oublié

Si vous ne vous souvenez plus de votre mot de passe :

<Steps>
  <Step title="Aller à la page de connexion">
    Rendez-vous sur [dashboard.jamdesk.com](https://dashboard.jamdesk.com) et cliquez sur **Se connecter**.
  </Step>
  <Step title="Cliquer sur Forgot password?">
    Sélectionnez le lien **Mot de passe oublié ?** (Forgot password?) sous le champ mot de passe.
  </Step>
  <Step title="Saisir votre adresse e-mail">
    Entrez l'adresse e-mail associée à votre compte. Si vous l'avez déjà saisie dans le formulaire de connexion, elle sera pré-remplie.
  </Step>
  <Step title="Vérifier votre boîte de réception">
    Cliquez sur **Envoyer l'e-mail de réinitialisation**. Consultez votre boîte de réception pour trouver le lien de réinitialisation et suivez les instructions.
  </Step>
</Steps>

<Note>
Les liens de réinitialisation de mot de passe expirent après 1 heure. Faites-en une nouvelle demande si le vôtre a expiré.
</Note>

## Exigences relatives au mot de passe

Votre mot de passe doit comporter au moins **6 caractères**.

## Comptes OAuth

Si vous vous êtes inscrit(e) uniquement avec Google ou GitHub, vous n'avez pas de mot de passe Jamdesk et le bouton **Changer le mot de passe** (Change Password) n'apparaît pas dans vos paramètres de compte.

Pour vous connecter avec un mot de passe en plus de OAuth, utilisez le processus **Mot de passe oublié ?** (Forgot password?) sur la page de connexion afin d'en définir un pour votre adresse e-mail.
