Mettez à jour les paramètres de votre profil Jamdesk et les préférences de votre compte.

## Accéder aux paramètres

1. Cliquez sur votre avatar dans le coin supérieur droit
2. Sélectionnez **Paramètres** dans le menu déroulant

## Informations de profil

Mettez à jour votre nom d'affichage et votre adresse e-mail :

<Steps>
  <Step title="Accéder au profil">
    Dans Paramètres, sélectionnez l'onglet **Profil**.
  </Step>
  <Step title="Mettre à jour vos informations">
    Modifiez votre nom d'affichage ou votre adresse e-mail.
  </Step>
  <Step title="Enregistrer les modifications">
    Cliquez sur **Enregistrer** pour appliquer vos modifications.
  </Step>
</Steps>

<Note>
La modification de votre adresse e-mail nécessite une vérification. Consultez votre boîte de réception pour un lien de confirmation.
</Note>

## Préférence de thème

Basculez entre le mode clair et le mode sombre :

- **Clair** — Thème clair par défaut
- **Sombre** — Thème sombre pour les environnements à faible luminosité
- **Système** — Correspond automatiquement aux préférences de votre système d'exploitation

Le paramètre de thème s'applique au dashboard Jamdesk. Le thème de votre site de documentation est contrôlé séparément dans `docs.json`.

## Préférences de notification

Contrôlez les e-mails que vous recevez :

| Notification | Description |
|--------------|-------------|
| Alertes de build | E-mail en cas d'échec des builds |
| Invitations d'équipe | E-mail lors d'une invitation à un projet |
| Mises à jour produit | Actualités et conseils produits occasionnels |
