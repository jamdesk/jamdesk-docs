Lier votre compte GitHub connecte votre identité pour l'attribution des builds et permet l'accès aux dépôts privés.

## Pourquoi lier GitHub ?

Lier votre compte GitHub vous permet de :

- Connecter des dépôts privés à Jamdesk
- Activer les builds automatiques lors d'un push
- Accéder aux dépôts des organisations dont vous faites partie

## Lier votre compte

<Steps>
  <Step title="Accéder aux paramètres">
    Cliquez sur votre avatar et sélectionnez **Paramètres**.
  </Step>
  <Step title="Sélectionner Connexions">
    Accédez à l'onglet **Connexions**.
  </Step>
  <Step title="Cliquer sur Connecter GitHub">
    Sélectionnez **Connecter le compte GitHub**.
  </Step>
  <Step title="Autoriser Jamdesk">
    Vérifiez les autorisations et cliquez sur **Autoriser** dans GitHub.
  </Step>
</Steps>

## Autorisations demandées

Jamdesk demande des autorisations minimales :

| Autorisation | Objectif |
|------------|---------|
| Lire le contenu du dépôt | Accéder à vos fichiers de documentation |
| Lire les métadonnées du dépôt | Lister vos dépôts |
| Webhooks | Recevoir des notifications de push pour les builds automatiques |

<Note>
Jamdesk n'écrit jamais dans vos dépôts. Tout accès est en lecture seule.
</Note>

## Dissocier votre compte

Pour déconnecter GitHub :

1. Accédez à **Paramètres** → **Connexions**
2. Cliquez sur **Déconnecter** à côté de GitHub
3. Confirmez la déconnexion

<Warning>
Déconnecter GitHub désactivera les builds automatiques pour tous vos projets. Vous devrez vous reconnecter pour les réactiver.
</Warning>

## Dépôts d'organisation

Pour accéder aux dépôts d'une organisation GitHub :

1. Accédez aux paramètres de l'organisation sur GitHub
2. Naviguez vers **Accès tiers** → **Applications OAuth**
3. Trouvez Jamdesk et cliquez sur **Accorder** l'accès

Si vous ne voyez pas cette option, demandez à un administrateur de l'organisation d'approuver Jamdesk.
