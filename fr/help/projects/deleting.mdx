---
title: Suppression de projets
description: "Supprimez définitivement un projet du dashboard -- historique, analytiques et config de domaine effacés. Votre dépôt GitHub reste intact."
---

La suppression d'un projet le retire définitivement de votre dashboard — l'historique des builds, les analytiques et la configuration de domaine sont tous supprimés. Votre dépôt GitHub n'est pas affecté.

## Supprimer un projet dont vous êtes propriétaire

<Warning>
La suppression d'un projet efface définitivement toutes les données, y compris l'historique des builds, les analytiques et la configuration de domaine personnalisé. Cette action est irréversible.
</Warning>

<Steps>
  <Step title="Ouvrir les paramètres du projet">
    Accédez à votre projet et cliquez sur **Paramètres**.
  </Step>
  <Step title="Faire défiler jusqu'à la Zone de danger">
    Trouvez la section **Zone de danger** en bas de la page.
  </Step>
  <Step title="Cliquer sur Supprimer le projet">
    Sélectionnez **Supprimer le projet**.
  </Step>
  <Step title="Confirmer la suppression">
    Saisissez le nom du projet pour confirmer, puis cliquez sur **Supprimer définitivement**.
  </Step>
</Steps>

## Ce qui est supprimé

- Tout l'historique des builds et les journaux
- Les données analytiques
- La configuration de domaine personnalisé
- Les associations de membres de l'équipe
- Les intégrations Webhook

## Ce qui n'est PAS supprimé

- Votre dépôt GitHub (reste inchangé)
- Votre compte Jamdesk
- Les autres projets dont vous êtes propriétaire

## Quitter un projet

Si vous êtes membre (et non propriétaire) d'un projet :

1. Accédez à **Paramètres** → **Équipe**
2. Trouvez votre nom dans la liste des membres
3. Cliquez sur **Quitter le projet**
4. Confirmez votre départ

Vous pouvez être réinvité ultérieurement si nécessaire.

## Avant de supprimer

Envisagez ces alternatives :

- **Transférer la propriété** si des membres de l'équipe ont besoin d'un accès continu
- **Exporter les analytiques** si vous avez besoin de données historiques
- **Noter votre configuration** si vous pourriez recréer le projet

## Récupération de projets supprimés

Les projets supprimés ne peuvent pas être récupérés. Si vous avez accidentellement supprimé un projet :

1. Créez un nouveau projet
2. Connectez le même dépôt GitHub
3. Reconfigurez les paramètres manuellement

Le contenu de votre documentation reste dans votre dépôt GitHub.
