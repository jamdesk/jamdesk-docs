---
title: Créer des projets dans le dashboard
description: Un projet dans Jamdesk représente un site de documentation unique. Chaque projet est connecté à un dépôt GitHub et déployé sur sa propre URL.
---

Configurez un nouveau site de documentation en créant un projet dans le dashboard. Vous pouvez démarrer à partir d'un modèle ou connecter un dépôt GitHub existant, et Jamdesk gère automatiquement l'installation du webhook et le premier build.

## Créer un nouveau projet

<Steps>
  <Step title="Ouvrir le dashboard">
    Accédez à [dashboard.jamdesk.com](https://dashboard.jamdesk.com) et connectez-vous.
  </Step>
  <Step title="Cliquer sur Nouveau projet">
    Sélectionnez **Nouveau projet** dans le dashboard.
  </Step>
  <Step title="Choisir votre source">
    Choisissez comment démarrer votre documentation :

    <Tabs>
      <Tab title="Utiliser un modèle">
        Démarrez avec le [Starter Template](https://github.com/jamdesk/starter-docs). Jamdesk crée un dépôt GitHub pour vous avec du contenu exemple, des composants et une spec OpenAPI.
      </Tab>
      <Tab title="Connecter un dépôt">
        Connectez un dépôt GitHub existant contenant votre documentation.
      </Tab>
    </Tabs>
  </Step>
  <Step title="Configurer les paramètres">
    - **Nom du projet** — Affiché dans le dashboard
    - **Sous-domaine** — L'URL de vos docs (ex. : `my-docs.jamdesk.app`)
    - **Branche** — La branche Git à déployer (généralement `main`)
  </Step>
  <Step title="Créer">
    Cliquez sur **Créer le projet** pour terminer la configuration.
  </Step>
</Steps>

## Limites de projets

Votre plan détermine le nombre de projets que vous pouvez créer :

| Plan | Projets |
|------|---------|
| Trial | 1 |
| Pro | 1 (extensible) |

Besoin de plus de projets en Pro ? Ajoutez des créneaux de projet supplémentaires sur la page **Abonnement**.

## Ce qui est créé

Lorsque vous créez un projet, Jamdesk :

1. Se connecte à votre dépôt GitHub
2. Installe un webhook pour les builds automatiques
3. Déclenche votre premier build
4. Attribue un sous-domaine `*.jamdesk.app`
