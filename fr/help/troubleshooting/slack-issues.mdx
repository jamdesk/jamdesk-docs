Les notifications Slack nécessitent un webhook entrant valide. Si les notifications cessent d'arriver, vérifiez la configuration du webhook ci-dessous.

## Les notifications n'apparaissent pas

<Steps>
  <Step title="Vérifier le webhook">
    1. Allez dans **Integrations**
    2. Vérifiez que Slack apparaît comme connecté
    3. Cliquez sur **Send Test** pour tester la connexion
  </Step>
  <Step title="Vérifier le canal">
    Le canal Slack a peut-être été supprimé ou renommé. Créez un nouveau webhook si nécessaire.
  </Step>
  <Step title="Vérifier les paramètres de notification">
    Vérifiez que vous avez activé les types de notifications souhaités (build démarré, réussi, échoué).
  </Step>
</Steps>

## Erreurs de Webhook

### "Invalid webhook URL"

Le format de l'URL est incorrect ou le webhook a été supprimé.

**Solution :**
1. Créez un nouveau webhook dans Slack
2. Copiez l'URL complète, y compris `https://`
3. Mettez à jour le webhook dans Jamdesk

### "Channel not found"

Le canal cible n'existe plus.

**Solution :**
1. Créez un nouveau webhook pointant vers un canal existant
2. Mettez à jour l'URL du webhook dans Jamdesk

### "Posting to channel failed"

Le webhook a peut-être été révoqué ou le bot a été supprimé.

**Solution :**
1. Vérifiez les paramètres de l'espace de travail Slack pour Jamdesk
2. Recréez le webhook si nécessaire

## Notifications en double

Vous avez peut-être plusieurs webhooks configurés :

1. Allez dans **Integrations**
2. Supprimez les connexions Slack en double
3. Ne conservez qu'un seul webhook par canal

## Notifications retardées

Les notifications arrivent généralement en quelques secondes. Les retards peuvent être causés par :

- Des problèmes de service Slack (vérifiez le [Slack Status](https://status.slack.com))
- Une congestion réseau
- De longues files d'attente de build

## Reconnecter Slack

Pour réinitialiser votre intégration Slack :

<Steps>
  <Step title="Déconnecter">
    Dans Jamdesk, allez dans **Integrations** → **Disconnect Slack**
  </Step>
  <Step title="Créer un nouveau webhook">
    Dans Slack, créez un nouveau webhook entrant pour votre canal
  </Step>
  <Step title="Reconnecter">
    Ajoutez la nouvelle URL de webhook dans Jamdesk
  </Step>
  <Step title="Tester">
    Cliquez sur **Send Test** pour vérifier que cela fonctionne
  </Step>
</Steps>

## Problèmes de format des notifications

Si les messages semblent mal formés :

- Assurez-vous d'utiliser des Incoming Webhooks (et non l'API Slack)
- Vérifiez que votre espace de travail Slack autorise les webhooks externes
