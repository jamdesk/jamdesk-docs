Résolvez les problèmes de facturation tels que les paiements échoués ou les factures manquantes.

## Paiement échoué

<Steps>
  <Step title="Vérifiez votre carte">
    Vérifiez que votre carte n'est pas expirée et qu'elle dispose de fonds suffisants.
  </Step>
  <Step title="Mettre à jour le moyen de paiement">
    Allez dans **Paramètres** → **Facturation** → **Gérer l'abonnement** pour mettre à jour votre carte.
  </Step>
  <Step title="Réessayer le paiement">
    Après la mise à jour, nous réessaierons automatiquement le débit.
  </Step>
</Steps>

### Raisons courantes d'échec

| Raison | Solution |
|--------|----------|
| Carte expirée | Mettre à jour avec une nouvelle carte |
| Fonds insuffisants | Ajouter des fonds ou utiliser une autre carte |
| Carte refusée | Contacter votre banque ou utiliser une autre carte |
| Numéro de carte invalide | Ressaisir les informations de carte avec soin |

## Impossible de mettre à jour le moyen de paiement

Si le portail de facturation ne se charge pas :

1. Essayez un autre navigateur
2. Désactivez les bloqueurs de publicités
3. Effacez les cookies pour jamdesk.com
4. Contactez le support si le problème persiste

## L'abonnement affiche « En retard »

Votre abonnement est en retard lorsque le paiement échoue plusieurs fois.

**Pour résoudre :**
1. Mettez à jour votre moyen de paiement
2. Allez dans **Paramètres** → **Facturation**
3. Cliquez sur **Payer maintenant** pour régler le solde

Vos projets peuvent être limités jusqu'à ce que le paiement soit résolu.

## Charges inattendues

Consultez vos charges :

1. Allez dans **Paramètres** → **Facturation** → **Voir les factures**
2. Vérifiez chaque élément de ligne

Causes courantes de charges inattendues :
- Emplacements de projets supplémentaires
- Charges au prorata lors de modifications en cours de cycle
- Renouvellement annuel après un essai mensuel

## Demandes de remboursement

Nous offrons des remboursements dans les 30 jours suivant votre premier paiement.

## Problèmes d'annulation

### Impossible de trouver le bouton d'annulation

1. Allez dans **Paramètres** → **Facturation**
2. Cliquez sur **Gérer l'abonnement**
3. Sélectionnez **Annuler l'abonnement** dans le portail

### L'annulation ne se traite pas

Si l'annulation semble bloquée :
1. Actualisez la page
2. Vérifiez votre e-mail pour la confirmation
3. Contactez le support si non résolu dans les 24 heures

## Problèmes de factures

### Facture manquante

Les factures sont envoyées à l'e-mail de votre compte. Vérifiez les dossiers spam.

Pour télécharger les factures :
1. Allez dans **Paramètres** → **Facturation**
2. Cliquez sur **Voir les factures**
3. Téléchargez le PDF

### Informations de facturation incorrectes

Mettez à jour vos informations de facturation :
1. Allez dans **Paramètres** → **Facturation**
2. Cliquez sur **Gérer l'abonnement**
3. Mettez à jour votre adresse de facturation
