Vous n'arrivez pas à vous connecter au dashboard Jamdesk ? Trouvez votre situation ci-dessous.

## Mot de passe oublié

<Steps>
  <Step title="Accéder à la page de connexion">
    Rendez-vous sur [dashboard.jamdesk.com](https://dashboard.jamdesk.com).
  </Step>
  <Step title="Cliquer sur Mot de passe oublié">
    Sélectionnez le lien **Mot de passe oublié ?**.
  </Step>
  <Step title="Saisir votre email">
    Entrez l'adresse email associée à votre compte.
  </Step>
  <Step title="Vérifier votre boîte de réception">
    Cliquez sur le lien de réinitialisation dans l'email que nous vous envoyons.
  </Step>
</Steps>

<Note>
Les liens de réinitialisation expirent après 1 heure. Faites-en une nouvelle demande si le vôtre a expiré.
</Note>

## Email non reconnu

Si vous voyez « Aucun compte trouvé » :

- Vérifiez les fautes de frappe dans votre adresse email
- Essayez d'autres adresses email que vous avez pu utiliser
- Vous vous êtes peut-être inscrit avec Google ou GitHub à la place

## Problèmes de connexion OAuth

### La connexion Google ne fonctionne pas

1. Effacez les cookies de votre navigateur
2. Essayez un navigateur différent
3. Désactivez temporairement les extensions du navigateur
4. Vérifiez que les cookies tiers sont autorisés

### La connexion GitHub ne fonctionne pas

1. Vérifiez que vous êtes connecté à GitHub
2. Vérifiez que Jamdesk est autorisé dans les paramètres GitHub
3. Révoquez et reconfigurez l'autorisation si nécessaire

## Compte verrouillé

Après plusieurs tentatives de connexion échouées, les comptes sont temporairement verrouillés.

- Attendez 15 minutes avant de réessayer
- Utilisez l'option de réinitialisation du mot de passe
- Contactez le support si le problème persiste

## Authentification à deux facteurs

Si vous avez activé la 2FA et ne pouvez pas accéder à votre application d'authentification :

1. Essayez vos codes de secours
2. Contactez le support en fournissant une preuve de propriété du compte

## Problèmes de navigateur

Essayez ces étapes :

1. **Effacez le cache et les cookies** pour jamdesk.com
2. **Désactivez les extensions** qui pourraient interférer
3. **Essayez le mode incognito/privé**
4. **Utilisez un navigateur différent**
