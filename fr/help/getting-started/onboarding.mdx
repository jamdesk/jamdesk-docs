## Les 5 étapes

<Steps>
  <Step title="Démarrer l'essai">
    Lors de votre première connexion, Jamdesk démarre automatiquement votre **essai gratuit de 14 jours** du plan Pro.

    - Accès complet à toutes les fonctionnalités
    - L'essai se termine 14 jours après l'activation
  </Step>

  <Step title="Créer un projet">
    Donnez un nom à votre projet de documentation :

    - Utilisez un nom clair et descriptif (par exemple, « Documentation API », « Guide utilisateur »)
    - Il fera partie de l'URL de votre site de documentation
    - Vous pouvez modifier le nom affiché ultérieurement dans les paramètres du projet
  </Step>

  <Step title="Connecter GitHub et créer la documentation de démarrage">
    Jamdesk crée un nouveau dépôt GitHub à partir du [modèle de démarrage](https://github.com/jamdesk/starter-docs) :

    - Des pages d'exemple avec un contenu et des composants réalistes
    - Un fichier `docs.json` préconfiguré avec la navigation et l'image de marque
    - Un exemple de spécification OpenAPI pour la documentation de référence API
    - Prêt à être modifié et poussé immédiatement
  </Step>

  <Step title="Installer le CLI">
    Le CLI Jamdesk permet le développement local :

    ```bash
    npm install -g jamdesk
    ```

    <Note>
    Vous pouvez ignorer cette étape pendant l'intégration et installer le CLI à tout moment. Si vous l'ignorez, vous pouvez toujours modifier la documentation directement sur GitHub.
    </Note>
  </Step>

  <Step title="Commencer à modifier">
    Vous êtes prêt à construire ! Modifiez votre documentation :

    - **Via le CLI** : modifiez les fichiers localement avec `jamdesk dev`
    - **Via GitHub** : modifiez les fichiers `.mdx` directement dans votre dépôt
    - **Sur Jamdesk** : certaines fonctionnalités du dashboard sont disponibles (selon le plan)

    Les modifications déclenchent automatiquement la reconstruction de la documentation lorsque vous les poussez vers GitHub.
  </Step>
</Steps>

## Dépannage

### J'ai ignoré une étape, puis-je revenir en arrière ?
Vous pouvez terminer l'intégration à tout moment depuis le dashboard de votre projet. Recherchez la carte d'intégration pour continuer là où vous vous étiez arrêté.

### J'ai choisi le mauvais dépôt GitHub
Créez un nouveau projet avec le bon dépôt — vous pouvez supprimer l'ancien à tout moment.

### J'ai besoin d'aide pendant l'intégration
Contactez le [support](/fr/help/support/contact) à tout moment pendant le processus.
