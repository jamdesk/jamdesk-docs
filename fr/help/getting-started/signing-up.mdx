Créez votre compte Jamdesk en utilisant l'e-mail, Google OAuth ou GitHub OAuth.

## Options d'inscription

Jamdesk prend en charge trois méthodes d'authentification :

### E-mail et mot de passe

1. Visitez [dashboard.jamdesk.com](https://dashboard.jamdesk.com)
2. Cliquez sur **Sign Up**
3. Saisissez votre adresse e-mail
4. Créez un mot de passe sécurisé
5. Consultez votre e-mail pour trouver un lien de vérification
6. Cliquez sur le lien de vérification pour confirmer votre compte

### Google OAuth

1. Visitez [dashboard.jamdesk.com](https://dashboard.jamdesk.com)
2. Cliquez sur **Sign Up**
3. Sélectionnez **Continue with Google**
4. Autorisez Jamdesk à accéder à votre compte Google
5. Vous serez automatiquement vérifié et connecté

### GitHub OAuth

1. Visitez [dashboard.jamdesk.com](https://dashboard.jamdesk.com)
2. Cliquez sur **Sign Up**
3. Sélectionnez **Continue with GitHub**
4. Autorisez Jamdesk à accéder à votre compte GitHub
5. Vous serez automatiquement vérifié et connecté

<Note>
Votre connexion GitHub relie votre identité à Jamdesk. Ceci est distinct de la connexion d'un dépôt GitHub à votre projet de documentation. Vous ferez cela lors de la configuration du projet.
</Note>

## Que se passe-t-il après l'inscription

Après la création du compte, vous allez :
- Démarrer un essai gratuit de 14 jours du plan Pro
- Être dirigé vers la création de votre premier projet de documentation
- Avoir accès au parcours d'onboarding complet

## Vérification de l'e-mail

Si vous ne recevez pas d'e-mail de vérification :
1. Vérifiez votre dossier spam
2. Attendez quelques minutes et réessayez de vous inscrire
3. [Contactez le support](/fr/help/support/contact) si le problème persiste
