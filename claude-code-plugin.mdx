The Jamdesk plugin gives Claude Code deep knowledge of the Jamdesk platform — components, configuration, navigation, and CLI — so it can help you build and maintain documentation sites faster.

Instead of explaining Jamdesk conventions in every prompt, the plugin loads the right reference automatically based on what you're working on.

## Installation

<Steps>
  <Step title="Add the marketplace">
    In Claude Code, run:

    ```
    /plugin marketplace add jamdesk/jamdesk-claude-plugin
    ```
  </Step>
  <Step title="Install the plugin">
    ```
    /plugin install jamdesk@jamdesk-marketplace
    ```
  </Step>
</Steps>

Or browse for it in `/plugin > Discover`.

<Accordion title="Manual install (for development or testing)">
  ```bash
  git clone https://github.com/jamdesk/jamdesk-claude-plugin.git
  claude --plugin-dir ./jamdesk-claude-plugin
  ```
</Accordion>

## What's included

The plugin provides one skill (`/jamdesk:jamdesk`) with a quick-reference hub and three detailed reference files that load on demand:

| Reference | What it covers |
|-----------|---------------|
| **Components** | 25+ MDX components — Cards, Steps, Tabs, Callouts, Code Groups, Tables, and more — with complete props and examples |
| **Configuration** | Full `docs.json` schema — themes, colors, branding, navbar, footer, API config, 20+ analytics integrations |
| **Navigation** | 8 navigation patterns — flat, grouped, tabbed, multi-product, versioned, multi-language, dropdowns, OpenAPI |

The hub also includes all 19 CLI commands, page frontmatter fields, image sizing syntax, writing standards, and common mistakes.

## Usage

Invoke the skill when working on Jamdesk documentation:

```
/jamdesk:jamdesk
```

Claude reads only the sections relevant to your task. For common questions (component syntax, CLI commands), the hub answers directly. For deep dives (full props tables, all config options, navigation pattern details), it loads the specific reference file.

## Pairing with CLAUDE.md and MCP

The plugin works best alongside two other features:

- **CLAUDE.md** — Add a project-specific context file to your docs repo. Claude uses it to match your writing style and conventions. See [Claude Code](/ai/claude-code) for a ready-made template.
- **MCP Server** — Connect Claude to your published docs so it can search and read your live content. See [MCP Server](/ai/mcp-server) for setup.

Together: the plugin teaches Claude about Jamdesk's platform, CLAUDE.md teaches it about your project's conventions, and MCP gives it access to your published content.
