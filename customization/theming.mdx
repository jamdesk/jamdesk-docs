Set `theme` in `docs.json` to change the overall look of your site. Each theme controls layout structure, typography, spacing, border radius, and dark mode behavior.

```json
{
  "theme": "jam"
}
```

Three themes are available: `jam` (default), `nebula`, and `pulsar`.

## Typography

Each theme bundles specific fonts loaded via Google Fonts CDN:

| Theme | Headings | Body | Code |
|-------|----------|------|------|
| [Jam](https://jamdesk.com/docs) | Inter | Inter | JetBrains Mono |
| [Nebula](https://nebula.jamdesk.com) | IBM Plex Mono | IBM Plex Mono | IBM Plex Mono |
| [Pulsar](https://pulsar.jamdesk.com) | Inter | Inter | JetBrains Mono |

Custom font support is coming soon. Currently, themes use the font stacks listed above with system font fallbacks.

## Custom Colors

Override the default palette to match your brand:

```json
{
  "theme": "jam",
  "colors": {
    "primary": "#635BFF",
    "light": "#7C75FF",
    "dark": "#4F46E5"
  }
}
```

| Color | Usage |
|-------|-------|
| `primary` | Links, buttons, accents |
| `light` | Hover states, highlights |
| `dark` | Active states, dark mode accents |

<Note>
Color changes take effect immediately in production after your next build. In local development, restart the dev server to see updated colors.
</Note>

<Tip>
Use a color tool like [Coolors](https://coolors.co) or [Realtime Colors](https://realtimecolors.com) to generate a harmonious palette.
</Tip>

## Dark Mode

All themes include automatic dark mode. Jamdesk respects the user's system preference and provides a toggle in the navbar.

To test dark mode during development, use the theme toggle in your docs navbar or emulate it in your browser's developer tools:

1. Open DevTools
2. Press Cmd+Shift+P (Mac) or Ctrl+Shift+P (Windows)
3. Search for "Emulate CSS prefers-color-scheme: dark"

Your color palette automatically adapts to dark mode. For fine-grained control over dark mode styles, use [Custom CSS](/customization/custom-css).
