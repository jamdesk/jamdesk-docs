Pick a theme in `docs.json` to set the overall look of your site -- typography, spacing, color defaults, and dark mode behavior all change together. You can further override the color palette to match your brand.

## Choosing a Theme

Set your theme in `docs.json`:

```json
{
  "theme": "jam"
}
```

## Custom Colors

Override the default palette to match your brand:

```json
{
  "theme": "jam",
  "colors": {
    "primary": "#635BFF",
    "light": "#7C75FF",
    "dark": "#4F46E5"
  }
}
```

| Color | Usage |
|-------|-------|
| `primary` | Links, buttons, accents |
| `light` | Hover states, highlights |
| `dark` | Active states, dark mode accents |

<Tip>
Use a color tool like [Coolors](https://coolors.co) or [Realtime Colors](https://realtimecolors.com) to generate a harmonious palette.
</Tip>

## Dark Mode

All themes include automatic dark mode. Jamdesk respects the user's system preference and provides a toggle in the navbar.

### Testing Dark Mode

In your browser's developer tools:
1. Open the **Elements** panel
2. Press Cmd+Shift+P (Mac) or Ctrl+Shift+P (Windows)
3. Search for "Emulate CSS prefers-color-scheme: dark"

Or use the theme toggle in your docs navbar.

### Dark Mode Colors

Your color palette automatically adapts to dark mode. The `light` color often becomes more prominent in dark mode for better contrast.

## Typography

| Nebula | Inter | System monospace |

Custom font support is coming soon. For now, themes use system fonts that load instantly.
